# 157 首局聚光框引导 + 到点小提示

状态：已实现，待用户看实机（10-26，分支 `claude/spotlight-tour`）。起因：协调人转用户 10-25「开局指南不要写太多」，10-26 用户同意方向：开局改成进局后的聚光框引导，其余知识点改到点小提示；翻页式指南（`data/guide.json` / `screens/intro.gd`）保留在暂停菜单「指南」里重看，不再在开局强制弹。

## 1. 聚光框引导（只在第一局）

- 触发：开场动画结束（`intro.end_opening`）时存档 `Cfg.seen_intro` 为假 → `g.tour.start()`。看完 / 跳过后置 `seen_intro`，以后不再出现。测试局 / 批跑没有开场，不触发。
- 借用 `state INTRO` 暂停局内；整屏压暗（0.68），用方框（淡黄底 + 四角 L 括号，呼吸）框住 HUD 元素，旁边一块斜切说明板（黄条、`GUIDE 01 / 03 · HEALTH · LAMP` 小标、标题、一两句正文）。
- 步骤（3 步，用户 10-26「生命和灯火可以一起介绍」；`command/on = 0` 时没有第 3 步）：① 生命与灯火（一个框圈住两条，归零失败、灯火受击下降、低于 30 受到伤害更多、灯油 / 灯标补）② 移动与冲刺（桌面框玩家，触屏框摇杆区 + 冲刺键）③ 指挥（桌面框右下「指挥 · 随行」，触屏框指挥键；讲队形与突击）。
- 操作：点击 / 任意键下一步，右键 / ← / Backspace 上一步，Esc 或底部「跳过引导」结束；手柄 Ⓐ 下一步、Ⓑ 跳过；触屏点任意处下一步（按钮点击区上下左右外扩）。
- 触屏按键、指挥状态原本只在 `state PLAY` 画：新增 `Game.hud_live()`（PLAY 或引导中），`touch.gd` / `hud_banners.draw_command` 改用它，引导期间 `touch.handle` 不吃输入。
- 框的位置：桌面 = `hud_bars.draw_top_left` 的固定坐标（生命 + 灯火合一个框 `Rect2(70,4,310,66)`）与 `hud_squad.squad_top()`；触屏 = `touch.layout()` 的 stick / dash / cmd。改 HUD 布局时同步 `tour.gd _build`。

## 2. 到点小提示

第一次遇到精英（600 像素内）、第一次 Boss 在场、灯火第一次低于 30（对局 15 秒后）、第一次升级选卡（state CHOICE，kind level）：左上角（y 112）弹一个不暂停的小框，8 秒，滑入 / 淡出，不拦输入，同时只弹一个（其余排队）。每样只弹一次，弹的同时记进存档 `[progress] seen_tips`。只在真人对局里弹（`mode == PLAY`、非演练 / 图鉴演示 / 练习）。老存档（已看过旧指南、没有 `seen_tips` 键）读入后按「都看过」处理，不再弹。文案在 `tour.gd TIPS`（docs/76）。

## 4. 主界面引导（10-26 协调人转用户：新手十连之后）

新玩家开局名册为空，先做新手十连（寻访会话）。十连做完回到主界面后，再用聚光框指引三步：① 点「图鉴」（看抽到的干员）→ ② 点图鉴右上「返回」→ ③ 点「集结出发」。每步一句，文案在 `screens/title_tour.gd STEPS`。

- 触发：`Roster.redeem_ten()` 成功时置存档 `[progress] title_tour = 1`；标题页（开场结束、无叠层、不在转场）等 0.7 秒后开始；走完 / 跳过置 2。老存档没做过新手十连，恒为 0，不弹；中途退出游戏时仍为 1，下次启动再引导。
- 实现：聚光框画法抽到 `screens/spotlight.gd`（局内引导 `tour.gd` 与这里共用）；`title_tour.gd` 是标题页的最后一个子节点（`title._add_title_tour` 延后加），`_input` 先于图鉴 / 标题：点在高亮外的点击被吞掉，点在高亮内原样交给标题 / 图鉴；第 ② 步不压暗、不画「跳过」（玩家要看图鉴，Esc 自然关图鉴）；图鉴「返回」键的位置取 `gallery.back_screen_rect()`（桌面 / 手机各一份）。第 ③ 步点「集结出发」或 Enter（选中项被强制设成被框的那一项）；Esc / 「跳过引导」结束。
- 演示：`--titletour --roster=full`（名册非空）自动走完三步，真实输入通路：先点高亮外（断言被吞）、再点高亮内；触屏演示因标题页按 `ui_k` 放大、合成事件坐标对不上，直接 `_activate`。配 `--fixed-fps 30 --shotdir=…` 存帧。
