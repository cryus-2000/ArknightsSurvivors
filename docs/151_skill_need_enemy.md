# 151 · 自动技能「范围内没有敌人不放」全员统一（10-25）

> 用户 10-25：「发现推进之王一直在自己放二技能，所有干员设置成范围内没有敌人就不开技能」。分支 `claude/skill-need-enemy`。

## 1. 规则

`data_operator.skill_gate_ok(i)`（自动技能满技力后、起手前查；手动技能 `is_manual` 不走）：以干员当前位置为圆心，**门槛距离 × op_range** 内要有敌人，没有就不放，技力保留满格，有敌人那一帧再放。门槛距离由 `ObCore.skill_gate_base` 推（`ob_core.gd`）：

1. 技能自己写的 `need_enemy`（显式，原有 31 处保留，推进之王 S2 的 150 删掉改走第 2 条）；
2. 技能 `do` 里会打到敌人的积木（cone / cleave / circle / wave / shell / hookshot / tether / leap_slam / fan / lock / barrage / cast_push / fx_rain / mark / followup / taunt_guard）的最大作用半径（r / aim_r / range / wave_dist / dist / len）+ 20（敌人体型）；
3. 该干员普攻的 range / r / len（纯治疗、增益、召唤类技能走这一条，用户原话「射程内有敌人才放」）；
4. 普攻 r = zone（斯卡蒂系）用区域半径；仍推不出用 180。

校验（`ob_check.gd`）：每个技能必须能由 1–3 推出门槛（普攻 r = zone 除外）；凯尔希 S1 / S2（200）、斯卡尔特 S1–S3（`$aura`）补了显式值。回归：`test_core.gd` `test_skill_gate`（60 个技能门槛都在 30–700，推进之王 S2 = s2_r + 20 = 130），`GATE_TABLE=1` 打印全表。

## 3. 复现（推进之王）

探针 `tools/probes/skill_gate_probe.py <队长> <被测干员>`（`game/tests/skill_gate_probe.gd`：队长站定，20 秒空场 / 20 秒敌人逼近交替，记每次放技能时的最近敌人距离）：推进之王当队长 / 队友各 120 秒，门槛修改后**空场 0 次**自动放技能，放出时最近敌人距离都 ≤ 92（S1 门槛）。注意：推进之王精零只有 S1（S2 精一、S3 精二才解锁），没精英化时看到的是 S1「冲锋号令·γ型」；改前的 S2 门槛 150 > 跃空锤半径 110，圈外 40 像素也会起跳，现收到 130。

## 4. 影响与风险

治疗 / 增益 / 永久类技能（塞雷娅、流明、凯尔希、斯卡尔特、铃兰、德克萨斯 S2 等）现在要等普攻射程内有敌人才放，战斗外 / 敌人还远时不再提前放，胜率可能略降（医疗类首次开技能晚到接敌），**需云端同 seed 配对复测**（未跑，本机只跑相关项 + core）。
