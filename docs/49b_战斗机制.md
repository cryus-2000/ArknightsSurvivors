### 1.2 医疗分支（本作治疗多样性的主要参照）

| 分支 | 特性（转述） | 本作可对应的形态 |
|---|---|---|
| 医师 | 单体治疗，射程远 | 凯尔希普攻 |
| 群愈师 | 同时治疗 3 个友方单位 | 本作只有主控受击，无直接意义；可改为「治疗溢出转护盾」 |
| 疗养师 | 范围大，但对较远目标治疗量打折 | 光域型：站在光域中心回复更多 |
| 行医 | 治疗生命的同时回复元素损伤（攻击力 50%），可以治未受伤的友方 | 流明「清神经损伤 / 侵蚀」已是这一路 |
| 咒愈师 | 普攻打敌人（法伤），并把伤害的 50% 转成治疗给范围内友方 | 吸血型：打得越多回得越多 |
| 链愈师 | 治疗在 3 个友方间跳跃，每跳 -25% | 无对应 |
| 守望者 | 治疗 + 可以起飞 | 无对应 |

治疗之外的回复来源：**守护者**（技能治疗）、**护佑者**（平时法伤，开技能后改为治疗 75% 攻击力）、**吟游者**（不攻击，持续给范围内全部友军每秒回复攻击力 10%，自身不吃鼓舞）、**近卫·武者 / 收割者**（命中自回血，但不接受治疗）。

### 1.3 辅助分支与「减伤 / 护盾」提供者

| 分支 | 特性 | 典型效果 |
|---|---|---|
| 凝滞师 | 法伤 + 短暂停顿 | 停顿（移速 -80%）、寒冷 |
| 削弱者 | 法伤 | 虚弱、脆弱、降防 / 降法抗 |
| 召唤师 | 法伤 + 召唤物 | 召唤物挡怪 |
| 巫役 | 法伤 + 造成元素损伤 | 凋亡 / 灼燃等损伤 |
| 吟游者 | 不攻击，群体持续回复 | 鼓舞（额外基础属性） |
| 护佑者 | 平时法伤，技能改治疗 | 庇护（物理与法术减伤） |
| 工匠 / 游击手 | 阻挡 2 / 触发型效果 | 协助作战 |

减伤 / 护盾的原作载体：重装（高防、守护者治疗、驭法铁卫法抗）、护佑者与部分辅助的「庇护」、各类「护盾（次数）」「屏障（数值）」「伤害减免（固定值）」buff。定义见 §2。

### 1.4 关键部署与技能机制

| 机制 | 原作规则 | 备注 |
|---|---|---|
| 阻挡 | 干员同时拦住的敌人数；先锋·尖兵 2、重装 3、多数远程 1；敌人可能占用多个阻挡数（如深溟引痕者半血后提高） | 被阻挡的敌人停下并攻击阻挡者 |
| 部署费用 | 关卡中自然增长，部署消耗；冲锋手击杀回 1 费，行商在场每 3 秒扣 3 费 | 官方另有「部署费用下限」：费用可降到下限，低于 0 时自然回费速度 -50% |
| 再部署 | 撤退或倒下后需等待再部署时间；处决者、情报官缩短 | 撤退一般返还一半费用（待核），冲锋手返还全额 |
| 技力回复 | skill_table 枚举：**自动回复**（随时间，1028 条）、**攻击回复**（每次攻击，120 条）、**受击回复**（受到攻击，33 条），其余为被动 / 不用技力 | 决战者只在阻挡时回技力；「蓄力」允许技力攒到上限 2 倍触发额外效果 |
| 技能触发 | **手动** 741、**自动** 500、**被动** 569（skill_table 末级计数） | 「过载」技能分两段计量；「吟唱」停手一段时间后尝试开技能，被打断就中止 |
| 伤害类型 | 物理（减防御）、法术（按法抗百分比减）、真实（无视两者）、元素（爆发伤害） | 物理 / 法术都有保底伤害，通称攻击力 5%（待核） |

## 2. 异常状态与战斗术语

「方向」：敌→我 = 敌人给干员上，我→敌 = 干员给敌人上。定义取自 const 术语表（`ba.*`），PRTS 补充标注。

### 2.1 控制类

| 状态 | 官方定义（转述） | 叠加 / 刷新 | 抵抗与免疫 | 方向 |
|---|---|---|---|---|
| 停顿 | 移速 -80% | 同名不叠加（PRTS：最终乘算） | 部分敌人免疫（深溟巢涌者「抵抗且免疫停顿」） | 我→敌为主（凝滞师、链术师） |
| 迟钝 | 移速、攻速、部分技能施放与冷却、部分异常恢复速度按比例降低 | 同名取最高 | — | 双向 |
| 束缚 | 无法移动（仍可攻击） | 刷新时长（待核） | — | 双向 |
| 缚地 | 变为地面单位且无法移动；能把部分近地悬浮敌人打下来 | — | 对重量 >3 的单位时长减半；有 `groundBoundImmune` | 我→敌 |
| 晕眩 | 无法移动、阻挡、攻击和使用技能 | 刷新时长（待核） | **抵抗**：时长减半；`stunImmune` 292 条敌人数据 | 双向 |
| 寒冷 | 攻速 -30；持续期间**再次**受寒冷会变成冻结 | 寒冷→冻结，不是数值累加 | 抵抗：时长减半 | 双向（冰原术师每 2 次攻击上寒冷） |
| 冻结 | 无法移动、攻击和使用技能（只能由寒冷触发）；敌人被冻结时法抗 -15 | — | 抵抗减半；`frozenImmune` 274 条 | 双向；PRTS：友方需两次寒冷配对才冻结 |
| 沉睡 | 无敌且无法行动 | — | `sleepImmune` 296 条 | 双向 |
| 浮空 | 变成空中单位，无法移动、攻击、使用技能 | — | 对重量 >3 的单位时长减半；`levitateImmune` 317 条 | 我→敌 |
| 沉默 | 无法开启技能；敌人被沉默时，「可沉默」的能力、光环、buff 暂时失效（PRTS 特殊机制；const 术语表未收录） | — | `silenceImmune` 737 条，数据里最常见的免疫标记 | 双向 |
| 恐惧 | 无法被阻挡并四散逃跑 | — | 抵抗减半；`fearedImmune` | 我→敌 |
| 诱导 | 无法被阻挡并朝指定位置移动 | — | 抵抗减半；`attractImmune` | 我→敌 |
| 战栗 | 被阻挡后无法普攻 | — | — | 我→敌 |
| 麻痹 | 每层可在敌人普攻时打断这次攻击，上限 3 层；未消耗前持续无限 | 叠层 | 有抵抗的单位每 5 秒掉 1 层；`palsyImmune` | 我→敌 |
| 重伤 | 移速下降、无法被阻挡，10 秒后自然死亡；被击杀时让击杀者回几点技力 | — | — | 我→敌 |

**抵抗**（`ba.buffres`）：晕眩、寒冷、冻结、恐惧、诱导等异常的**持续时间减半**；麻痹等叠层状态每 5 秒掉 1 层；同名的抵抗不叠加。敌人通常写作「拥有抵抗」（冰原术师、爪兽等）。敌人数据里还有 10 种独立免疫标记：沉默 737、浮空 317、沉睡 296、晕眩 292、冻结 274、恐惧 136、诱导 104、缴械 98、麻痹 53、缚地 6（enemy_database 共 2163 条数据）。

| 术语 | 规则 | 叠加 |
|---|---|---|
| 脆弱 | 受到的物理、法术、真实伤害按比例提高 | 同名取最高；不同名之间相乘（待核） |
| 法术脆弱 / 物理脆弱 / 元素脆弱 | 只放大对应类型 | 同名取最高 |
| 虚弱 | 攻击力按比例降低 | 同名取最高 |
| 庇护 | 受到的物理和法术伤害按比例降低（真实伤害不减） | 同名取最高 |
| 对空庇护 | 只减来自空中的物理和法术伤害 | 同名取最高 |
| 伤害减免 | 受到的伤害减少一个固定数值 | 同名取最高 |
| 护盾 | 每层抵挡一次伤害（按次数） | 叠层 |
| 物理护盾 | 每层抵挡一次物理伤害 | 叠层 |
| 屏障 | 吸收一定**数值**的伤害（血条外的额外生命） | — |
| 损伤屏障 | 吸收一定数值的**元素损伤** | — |
| 闪避 | 物理闪避 / 法术闪避按概率让一次伤害失效；伏击客 50%；部分伤害「无视闪避」 | 真实伤害能否闪避（待核） |
| 真实伤害 | 无视防御与法抗，但仍吃脆弱，仍会被护盾 / 屏障吸收 | — |
| 无敌 | 无法被对立阵营选中，受到的伤害和元素值变化归零 | PRTS 特殊机制 |
| 禁疗 | 不能成为治疗目标，受到的治疗量为 0（不屈者、收割者分支特性同理） | PRTS 特殊机制 |
| 鼓舞 / 精力充沛 / 坚忍 / 偷取 | 额外基础属性；高血加成；按已损生命加成；偷对方属性 | 同类属性取最高 |

### 2.4 元素损伤与元素爆发

元素损伤（const `ba.dt.element`）包括 **神经、侵蚀、灼燃、凋亡、狂躁** 五种。机制（PRTS [元素损伤](https://prts.wiki/w/元素损伤)）：

- 每个单位每种元素有独立的元素值，默认上限 1000，初始满；受到的损伤 = 损伤值 × (1 − 损伤抵抗%)，直接扣元素值。
- 某一种扣到 0（UI 上是条攒满 1000）就**爆发**。爆发期间元素值不再变化（不继续累积、也不能被回复），结束后回满。
- **自然恢复**：默认每秒恢复为 0，干员身上的损伤不会自己消失，要靠行医等手段回复（我方干员会不会在一段时间不受损伤后自然恢复：待核）。
- 敌人有两项独立属性：`epDamageResistance`（损伤抵抗，减累积量）与 `epResistance`（元素抗性，推测减爆发的元素伤害，待核；数据里 18 条敌人非 0）；另有 `epBreakRecoverSpeed`（爆发后恢复速度，待核）。
- **元素伤害**是爆发时结算的固定伤害，和「元素损伤」（累积量）不是一回事。

| 损伤 | 干员爆发（敌人造成，阈值 1000） | 敌人爆发（干员造成，普通 / 精英 1000、领袖 2000） |
|---|---|---|
| 神经 | 受 1000 真实伤害并晕眩 10 秒 | 立即受 6000 元素伤害并获得 3 层麻痹；10 秒冷却 |
| 侵蚀 | 永久 -100 防御并受 800 物理伤害 | 立即受 5000 元素伤害并永久 -120 防御（可叠加）；8 秒冷却 |
| 灼燃 | 10 秒内法抗 -20 并受 1200 法术伤害 | 立即受 7000 元素伤害，期间法抗 -20；10 秒冷却 |
| 凋亡 | 15 秒内无法开技能，每秒失去 1 技力并受 100 法术伤害 | 附加 50% 虚弱（期间逐渐恢复），每秒受 800 元素伤害；15 秒冷却 |
| 狂躁 | 15 秒内攻速 +50，但每秒受 100 真实伤害（每次攻击时递增 50，最多 600） | （无我方版本） |

设计要点：**同一个阈值在敌我两侧效果不同**——敌人爆我方是「控制 + 削弱」，我方爆敌人是「大额固定伤害 + 附带减益」；领袖阈值翻倍，防止一次爆发秒 Boss。

## 4. 原作 → 本作对照

本作前提：幸存者类，**只有主控会受伤**；敌人追主控；三技能自动充能（手动技能只在当主控时生效）；Boss 存活期间主控「永不硬控」（僵直、攻速减缓改成减速，合计移速不低于 0.7）。

### 4.1 状态与伤害

### 4.4 优先级建议（按实现成本从低到高）

1. **凋亡损伤**（敌→主控，充能暂停 / 倒扣）：只动充能逻辑，和三技能制直接咬合，是原作里本作最缺的一种。
