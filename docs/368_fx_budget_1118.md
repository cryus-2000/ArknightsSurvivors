### C. 画面规则（审片时人眼查，部分写进 `fx_elements` 声明）

1. **同一招元素 ≤ 3 种**（推荐 2 种）：主形一种（pixelfx 实心形），质感一种（Noita 颗粒 / 光），最多再加一种点缀；E0 → E1 → E2 每级只加一个新元素（docs/25、memory fx-style-pixelfx-noita / fx-recipe-direction）。
2. **覆盖面积**：普攻、技能按 B 表；大面积只许实心主形一闪而过，不许长时间铺半透明盘、细环（memory gif-not-ingame；docs/293 最占屏的是半透明填充）。持续型技能（逻各斯 S3 咒域、维什戴尔 S3 这类）用「生效时平均覆盖」管，不用峰值。
3. **亮度**：普攻 / 技能生效时全屏平均亮度增量 ≤ 1.0（0–255）；红色只给危险，不许大面积铺红（memory gif-not-ingame）；队友特效后期变薄 / 减量，不降亮度（memory late-fx-ctrl A 版）。
4. **持续时间**：普攻每次出手的特效 ≤ 0.5 秒；技能单次 ≤ 1.5 秒，持续型技能的常驻层按「生效时平均覆盖」管；终结技按 docs/198（瞬发 ≤ 1.2 秒 / 短持续 ≤ 3.5 秒）。
5. **终结技例外**：冲击帧整屏白 + 黑剪影一瞬（≤ 6 帧，memory ult-impact-frame，巡检别报）、舞台压暗（共用框架，不算本人覆盖）、立绘切入条，这三样不计入覆盖上限；轻微镜头震动 3 px / 0.12 s 级可用（memory light-shake-ok）。终结技本人特效仍按 B 表「实心覆盖」管。
6. **力量感手法**（memory impact-fx-power）：不规整分叉裂网 + 爆亮冷却 + 隆起尘墙 + 预兆余震；规整放射 / 同心圈被否。
7. **合批**：圆 / 环 / 线用 `world.tb_*`，贴图走帧条合批（memory godot-draw-batching）；绘制调用增量按 B 表。

## 1. 量法

### 1.1 资源（静态，`python tools/fx_budget.py scan`，不开 Godot）

- **归属**：转平面帧条 `game/art/fx/pxp/pxp_<代号>_<键>.png` 按代号定人（斯卡蒂无代号）、按「键干」查 `tools/fx_budget_map.json` 定招（普攻 / 技能 / 终结技 / 连携 / 召唤物 / 天赋成长 / 原样贴备用）。表由子代理逐人读 `fx_pxplane_*.gd`、`ult_px_*.gd` 的事件分支定的，低把握的归类写在表的 `notes` 里（安洁莉娜绸带、逻各斯 exec/tick、铃兰 fl 等）。旧帧条 `fx_<前缀>_*`（含 `_optical/`）按前缀表定人；受击、预警、寻访界面这类共用件不算进任何人（共用 196 张、0.71 MB）。
- **包体** = 导入后的 `.ctex`（`game/.godot/imported`，进 pck 的就是它）；**显存** = PNG 宽 × 高 × 4（导入设置 compress/mode = 0 无损、无 mipmap），按「全部帧条同时载入」算上限，实际按需载入（例如斯卡蒂终结技 8 个方向只载用到的那一张，`PF SDLOAD` 一张 27.8 MB）。
- **音效** = `audio/sfx/op_<id>_*` + `ult_<id>_*`。

### 1.2 帧时（`python tools/fx_budget_runtime.py perf`，本机）

- 该干员当队长、不招募、满局外成长、不死，**8:00 起实时跑 90 秒**；同局每 30 帧轮换「该干员特效画成全透明 / 正常」（新加的量测开关 `--clutterdbg=noop_<id>,abop --clutterab=30`：只切按人静音、不动降噪档，代码与随机数照跑），`--perf` 分 `/d0`（关）、`/dN`（开）两桶，净差就是这名干员特效的**绘制**开销。
- 本机同时有别的会话在跑 4 个 Godot，帧间隔噪声 ±5 ms，没法用。主指标改用 `--prof` 的「世界绘制」分段 CPU 时间，并用与特效无关的分段（HUD、敌人）开 / 关之比校正机器负载漂移（`fx_budget_runtime.draw_delta`）。**探针约把各段放大 2 倍**（memory perf-probe-overhead），所以表里的 ms 是「--prof 口径」，真实约一半；噪声底约 ±1.5 ms（艾丽妮量出 −1.2）。GPU、渲染 CPU 的开 / 关差都在 ±0.3 ms 内：**干员特效的开销在 GDScript 绘制，不在 GPU**，与 memory desk-web-perf 一致。
- 静音只省绘制，不省特效逻辑（颗粒推进、条目更新），这部分没算进来。
- 单人队长局的同屏敌人中位 25–77 只（不到 4 人队后期的 120 只）：后期满屏时的增量会更大，按比例看「占世界绘制 %」更稳。
- **手机网页组没测**：要用 `tools/perf_web.py` 导出测量副本、在 Edge 里跑，本机 E 盘紧、机器忙，这一轮没做，列为待办（§6）。按 memory desk-web-perf，网页卡在 GDScript（wasm 约 89%），桌面 CPU 增量大的干员在手机网页上也会是同一批。

### 1.3 画面占比（`python tools/fx_budget_runtime.py cover`，GCP 5 台）

- 图鉴演示（`tests/fx_audit_shot.tscn`，精二、1280×720、seed 11），每招（普攻 / S1 / S2 / S3 / 终结技）三遍：正常、该干员静音（终结技另加新开关 `noult`：终结技画面层 + 立绘切入条整层不画，只量测、发布版恒关）、敌人隐藏。逐帧（30 帧 6 秒，终结技 8 秒）逐像素差：
  - **覆盖** = 差 > 0.06 的像素占全屏比例（docs/243 §1.3 口径，含照地光 / 辉光淡染色）；**实心覆盖** = 差 > 0.3；
  - **整屏帧** = 覆盖 > 80% 的帧（冲击帧、舞台压暗起落），单独计，峰值另报「去整屏帧」；
  - **敌人被实心盖住** = 敌人像素里实心覆盖的比例；**亮度增量** = 全屏平均亮度开减关（0–255）；
  - **生效时长** = 覆盖 > 0.1% 的帧数（底噪约 0.05%，是本人身上的照地光）。普攻在演示里连发，所以普攻 / 技能的「生效时长」其实是 6 秒窗口里的占空比，不是单次时长。
- 终结技的「覆盖峰值」几乎人人约 53%：那是共用的舞台压暗，不是本人特效，所以终结技的上限只看实心覆盖。

## 5. 交给新干员特效会话

- **出发点**：每名新干员设计稿里的「特效需求要点」。先按速查表定每招的元素（≤ 3）、覆盖档、时长，写进转平面文档的自查表和 `characters/<id>.json` 的 `fx_elements`，再动手做。
- **设计稿位置**：令在 `ling-design` 分支；傀影、史尔特尔在 `claude/op-phantom-surtr`；夕、黍、菲亚梅塔在 `claude/op-dusk-shu-fiammetta`。
- **登记**：新帧条代号与键干登记进 `tools/fx_budget_map.json`（`codes` / `stems`）；没登记的无前缀帧条快检直接报错，不会被算到斯卡蒂头上。
- **交付验收**（new-operator 技能 ④ 已写）：
  ```bash
  python tools/check.py --only fx_budget > build/chk_fxb.txt 2>&1; echo rc=$?
  python tools/fx_budget_runtime.py new --op <id> --no-cover        # 本机：帧时（1 个 Godot，约 7 分钟）
  python tools/gcp_render.py --branch HEAD --job custom --name fxb-<id> --cmd 'GODOT_MAX_PROCS=8 python3 tools/fx_budget_runtime.py cover --jobs 8 --out $OUT --ops <id>'
  ```
  把 GCP 回来的 `cover.json` 放进 `build/fx_budget/` 后再跑一次 `new --op <id> --no-cover`，打印超限项；超限写进设计稿 §7 并报用户，不许自行放宽。
- **方向性提醒**（从现有超限看出来的）：大件帧条按方向烤 8 张是包体 / 显存大头（斯卡蒂终结技）；整屏级的东西用运行时程序画（多数终结技 ≤ 0.05 MB 就是这么做的）；绘制开销大的都是「每帧逐格画很多运行时件」（乌尔比安、逻各斯、歌蕾蒂娅），新干员的运行时线状件要合批、要设同屏上限。

| `tools/fx_budget.py` | 静态账 `scan` / 快检 `check` / 现有超限 `over` / 写基线 `baseline` |
| `tools/fx_budget.json` | 预算数值（推荐 / 硬上限 / 现有 20 人基线 / 运行时上限） |
| `tools/fx_budget_map.json` | 帧条归属表（代号 → 干员，键干 → 招，旧帧条前缀） |
| `tools/fx_budget_runtime.py` | 帧时 `perf`、画面占比 `cover`、新干员交付 `new` |
| `tools/fx_budget_report.py` | 本文 §2 的表 |
| `tools/check.py`、`tools/check_map.json` | 快检项 `fx_budget`（不开 Godot，每次快检都跑） |
| `game/scripts/render/declutter.gd` | 量测开关 `abop`（同局轮换按人静音） |
| `game/scripts/run/ult.gd`、`game/scripts/screens/hud_ult.gd` | 量测开关 `noult`（终结技画面层不画） |
| `.claude/skills/new-operator/SKILL.md` | ④ 特效：开工前对预算、完成标准加特效预算两项 |

三个量测开关都只在调试版读命令行（`declutter.dbg` 走 `OS.is_debug_build()`），发布版恒关；不影响玩法、TRACE。
