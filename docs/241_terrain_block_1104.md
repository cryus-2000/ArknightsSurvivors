# 241 地形阻挡：敌我口径统一（11-04）

起因：用户实玩「地形上的障碍会阻挡干员的攻击，但是不能阻挡 boss 的攻击」；上一局 `terrain = {bul: 0, dash: 1, ebul: 23}`（普通敌弹被挡 23 次，Boss 弹 0）。
分支 `claude/terrain-block-1104`（基于 integ-1105 ac7345d29）。开关 `combat/terrain_block_rule`：0 = 旧口径（缺省），1 = 统一规则。

判定都在 `game/scripts/world/map.gd`：`point_blocked`（点在景物底座椭圆内）、`segment_blocked`（线段穿过底座）、`bullet_blocked`（弹体「先在底座外、后进底座」才算撞上，出生在底座里的先放行；撞上播石屑、记 `tb_log`）。旧旋钮在 balance `terrain` 段（10-13 用户批准）：`block_bullets` 1、`block_enemy_bullets` 1、`block_boss_bullets` **0**（注释「Boss 弹幕按预警设计」）、`aim_los` 1、`dash_stop` 1。

## 2. 开关 1 改了什么（代码）

- `map.gd`：`tb_rule` / `tb_home` / `tb_fly`；规则 1 时 `tb_boss = tb_ebul`（Boss 直线弹跟普通敌弹一起挡）。新函数 `fly_blocked(b, p)`：`tb_fly` 关时恒 false，不碰弹体字典、不抽随机数——开关 0 与改前逐帧相同。
- `shot_pool.gd:257`、`weapons.gd:85`：追踪弹豁免改成 `tb_home or not home`。
- 我方原来不查的飞行物各加一行 `fly_blocked`：seg_skadi `_hw_waves`（只对剑气 `ll` 和弹体式潮刃 `proj`）、seg_specter 水刃、seg_logos 咒文弹（判定点下移 12 到地面）、vis_growth 散射 / 连发弹与剑气。

## 3. 例外（请协调人定）

1. **Boss 弹幕本来就是故意不挡**：`terrain/block_boss_bullets` 缺省 0，10-13 用户批地形阻挡时就这么定的（注释「Boss 弹幕按预警设计」）。开关 1 推翻的正是这一条，用户确认时要知道这是改原决定，不是修 bug。
2. **预警类弹幕（`no_rock`）故意穿墙**：地面预警放出的环形 / 扇形弹（telegraph.gd:364 注释「预警类攻击不受地形阻挡」），以及偏执泡影二阶段海嗣滴。它们是「先给预警、再放弹」的读招，开关 1 仍不挡；要不要也挡请定。
3. **抛物 / 定时落点**（敌我都有：吐酸、熔岩块、维什戴尔炮击、重力弹、钩索 / 掷锚）按「范围类」处理不挡——它们飞在空中、按落点结算。
4. **剑气算飞行物**（拉普兰德、可见成长剑气、斯卡蒂潮刃、幽灵鲨水刃），开关 1 挡；斯卡蒂**浪墙**是宽的移动浪，按范围不挡。
5. **终结技 / 连携**（含能天使终结技爆裂弹）一律不挡。
6. 水月的水母是追着目标飞的召唤生物，不算弹，不挡。

## 4. 开关 0 与改前一致

同参数在 integ-1105 基线（ac7345d29）检出和本分支各跑一次 `--trace=1`（4 局：拉普兰德 + 逻各斯 + 幽灵鲨 420 秒、斯卡蒂 + 铃兰 + 能天使 420 秒、水月 + 塞雷娅 + 流明 600 秒、艾雅法拉 + 维什戴尔 + 德克萨斯 720 秒，seed 1–4，expert）：TRACE 逐行相同；BALANCE 只差 `bot/peak` 第 4 项（同屏特效数峰值，画面随机），基线自己跑两遍也差（135 / 129），属噪声。积木等价金样在 integ-1105 上本来就过期（28 份），不能用来比。另外开关 1 下用这几位干员各跑 240 秒，无脚本错误。
