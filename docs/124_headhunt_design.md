# 124 · 干员寻访（局外解锁）：界面、动效与美术（设计稿）

> 状态：**设计稿，待用户审**（2026-10-22，分支 `claude/headhunt-design`）。审过再实现。
> 规则来源：docs/109 §12（开局 5 人、寻访凭证 / 招募券 / 人事调度函、意向干员 3 张保底、临时招募）。本文只管表现层；兑换逻辑、存档、保底由局外成长会话（`claude/meta-unlock`，`screens/headhunt.gd` 骨架）负责，接口见 §7。
> 样张：`python -X utf8 tools/concept_headhunt.py` → 主仓库 `build/headhunt_design/`（不入库）。干员像用游戏里的 @2x 待机帧，未解锁画剪影；特效是程序画法占位（§6 特效单交 Codex 后替换）。

## 1. 流程

```
局终结算（胜利 / 撤离 / 失败，docs/77）
  └─ 本局得到的券：寻访凭证 ×1（存活 ≥ 2:00）、通关 + 招募券 ×1、首通 + 人事调度函 ×1
       ├─ 有招募券 → 招募券界面（选职业，§3.1）──┐
       ├─ 有人事调度函 → 调度函界面（选干员，§3.2）┤   每张券兑换一次（逻辑层 redeem_*）
       └─ 寻访凭证 → 直接兑换 ────────────────────┘
  └─ 寻访揭示（§2）：每名新干员一轮 等待 → 信号 → 解码 → 定格 → 台词（4–5 秒，可跳过）
  └─ 汇总（§2.3）：本次加入名册的干员一排；「前往干员名册」/「返回」
  └─ 选人页 / 图鉴 / 封面干员：新加入的卡带一次高亮（§4.4）
```

- 券可以留着不用：结算页「寻访凭证 ×1 —— 前往干员名册使用」（docs/109 §12.4）也行；选人页顶栏放一个「寻访」入口（有未用券时显示数量），从这里进同一套 §3 / §2。**推荐结算后直接演**（每局都有一次揭示，是这套系统的爽点），另保留选人页入口补用。待用户定（§8 第 1 项）。
- 全部解锁之后不再演，结算行改「寻访凭证 ×1 → 生机细胞 +5」。

## 2. 寻访揭示

主动作 **「信号解码」**：一道横向扫描线自上而下扫过干员剪影，扫过的行由剪影解码成彩色像素，扫描线附近有 4 像素一格的噪点块（docs/62 §2.8：全游戏不复用；现有的光柱托起 / 声呐揭开 / 由糊到清都没用这个）。
节奏参照原作寻访（等待 → 光效 → 立绘 → 名字与职业 → 台词），换成本作的像素立绘与局外 T5s 语言（docs/37 §8：藏青三阶 Bayer 抖动、像素阶梯切角、青细边、5×7 像素字）。

### 2.1 分镜（`reveal_storyboard.png`，单张 `reveal_<阶段>.png`）

| 阶段 | 时刻 | 画面 | 缓动 |
|---|---|---|---|
| ① 等待 WAIT | 0–0.6 s | 舞台中央一张凭证卡（券名 + 英文 + 本作徽记「菱形 + 一道浪」），四周星屑缓慢聚拢；地面三圈压扁的投影环；右上「意向 水月 · 保底 2/3」（只在设了意向时显示） | out_cubic |
| ② 信号 SIGNAL | 0.6–1.4 s | 凭证卡沿水平中线压扁成一道发光信号缝（steps(4) 压扁），向两侧拉开到舞台宽；星屑被吸向缝；缝上方亮出**职业图标**（职业色）、下方像素字 `SIGNAL 03/13`（第几名 / 未解锁总数） | in_out_cubic + steps(4) |
| ③ 解码 DECODE | 1.4–2.6 s | 剪影落位（脚底贴投影环中心），信号缝变成扫描线从头顶扫到脚底（linear，1.0 s），扫过的行解码成彩色；扫描线下沿 3 行噪点块 | linear |
| ④ 定格 NAME | 2.6–3.6 s | 扫完一帧白闪（≤ T1、面积 < 25%，docs/62 §2.3）；左侧名字块 T2 依次进：`NO.xx // 职业英文` → 中文名（40 号）→ 英文名像素字 → 职业片（职业色描边）→「已加入名册」；意向保底命中时多一片紫色「意向干员 · 第 3 张必出」（`reveal_pity.png`） | out_cubic，错开 90 ms |
| ⑤ 台词 LINE | 3.6–5.0 s | 底部台词条：一句**招聘合同「干员简介」原文**（lore.json 每人首句，已按 PRTS 核对过，docs/76 §4）；右侧暗色像素字 `R.I. RECRUITMENT FILE`；之后停在这一帧等输入 | out_cubic |

- 立绘倍数：桌面 4 倍（@2x 贴图像素 × 4 × `draw_scale`，同 docs/108 / 选人立绘口径），手机 2 倍；待机帧循环播放（解码阶段停在 f0）。
- 多名干员：一名一轮；第二名起 ① 缩到 0.3 s（凭证卡直接换下一张）。
- 声音：② 信号缝一声低频上扫，③ 扫描每 0.25 s 一下轻「嘀」（steps），④ 定格一声短促的确认音；台词条不配语音（没有可查证的语音文本与音频授权）。素材找音频会话出候选。

### 2.2 跳过与输入（docs/62 §2.5）

- 任何阶段点按 / Enter / Ⓐ：跳到 ⑤ 的终态（本名干员全部显示）；在 ⑤ 再按：下一名，或进汇总。
- 长按 0.5 s / Esc / Ⓑ：跳过全部，直接汇总。
- 减少动态效果：①–③ 合成一次 T1 淡入（剪影 → 彩色直接到位，无扫描线、无星屑），④⑤ 只淡入。
- 无头批跑 / 测试局不演（直接汇总终态）。计时用真实时间，不读写 `g.rng`（星屑用固定表）。

### 2.3 汇总（`summary.png`）

本次加入名册的干员一排卡（职业色顶条、立绘 2 倍、名字、职业 · 来源券），标题「本次寻访」+ 一行「3 名干员已加入名册」。按钮：前往干员名册（选中）/ 返回。

### 2.4 手机

- 横屏（主）：`phone_reveal_decode.png` / `phone_reveal_line.png`，设计尺寸 740 × 360，界面层按 `Cfg.ui_k` 放大；立绘 2 倍；名字块在左、台词条贴底。
- 竖屏（`portrait_reveal_line.png`，360 × 740 示意）：本体是横屏游戏（B站 Toy 横屏容器），竖持时这一屏单独排成上下：立绘居中偏上 → 名字块 → 台词条贴底（自动换行）。只有这一屏需要竖排，其余界面沿用现有横屏缩放。

## 3. 定向：招募券 / 人事调度函

### 3.1 招募券：选职业（`pick_class.png`、`phone_pick_class.png`）

- 4 × 2 职业格：职业图标（职业色）、中文名（24 号）、英文像素字、「未解锁 n 名」+ 该职业未解锁干员的剪影一排。
- 已全部解锁的职业灰掉，写「已全部解锁」，不能选（docs/109 §12.2）。
- 还没有任何干员的职业右上角紫色「新职业」片；职业顺序按 docs/109 §12.1，未拥有的排前面。
- 选中 = 反白 + 细青边（T5s S4）。右下主按钮「使用招募券 · 近卫」；左下一行持有数。
- 确认后进 §2 揭示（职业图标在 ② 就亮出来，和所选一致）。

### 3.2 人事调度函：指定干员（`pick_letter.png`）

- 左：未解锁干员的格子（剪影 + 职业图标 + 名字；意向干员右上角「意向」）。名字可以写：这是「指定」，不写就选不了；**立绘不剧透**，用剪影。
- 右：选中干员的大剪影 + 名字 + 英文 // 职业 + 三个技能名（可翻看，同 docs/109 §12.1「未解锁也能看技能」），底部一行「立绘在解锁后显示」。
- 主按钮「使用人事调度函」。确认后进 §2（① 的凭证卡换成调度函，② 直接亮职业图标）。

### 3.3 意向与保底

- 选人页未解锁干员的舞台下方：「设为意向」按钮 + 「寻访凭证保底 ■■□ 2/3」（`locked_oppick.png`）。同时只有一名意向；换人时提示「保底计数会清零」（逻辑层规则）。
- 揭示 ① 右上角显示当前意向与计数；保底命中时 ④ 多一片紫色标签。

## 5. 文案（docs/76）

- 券名用原作名：寻访凭证、招募券、人事调度函（docs/109 §12.2）。界面标题：「寻访」「招募券」「人事调度函」「本次寻访」。
- 揭示：「已加入名册」；意向命中「意向干员 · 第 3 张必出」。不写「恭喜」「全新」「欢迎加入」。
- 台词只用 lore.json 里已核对的招聘合同首句；以后换成原作「干员报到」语音文本时，须按 docs/76 §4 逐句标 PRTS 来源。
- 英文像素字只做装饰标签（HEADHUNT // 01、SIGNAL 03/13、R.I. RECRUITMENT FILE），不承载信息。

### 9.3 没有星级怎么分档（建议）

建议**两档**，按「这次解锁对玩家意味着什么」分，而不是按干员强弱（本作不分稀有度，给干员定星级会和平衡口径冲突）：

| 档 | 颜色 | 条件 | 对应原作 |
|---|---|---|---|
| 金 | #FFC450 / #FFF0B4 | 补上一个**还没有人的职业**（新职业），或**意向干员保底命中** | 5★ 以上的金光 |
| 青白 | #60E0E8 / #C8FFFF | 其余 | 3–4★ 的白光 |

- 不设第三档「火光彩虹」：本作没有对应「最稀有」的东西；若以后加限定 / 联动干员，再给它们留这一档。
- 招募券 / 人事调度函是玩家自己选的，结果事先知道一半，不需要靠光色吊胃口：**定向券按青白档演；但抽到的是新职业时照样升金**。
- 一次开多张时（全部使用），匣子的光按本次最高档（同原作）。
