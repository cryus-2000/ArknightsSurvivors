# 312 触屏指挥：点选 → 预选 → 再点确认（11-07）

用户 11-07 反馈：手机端指挥圆盘的操作「现在一点不明确」。协调人派活。

用户要的流程：点「集火」后，场上有精英就直接点它。被点中的那只框变色（选中），再点一下才下令。「部署」也一样：点地面，落点标记变色，再点一下确认。

## 1. 现状（改前，`command/touch_confirm = 0` 仍可切回）

代码在 `screens/command_wheel.gd` 和 `screens/command_pick.gd`，设计见 docs/196 §6.3。

1. 点右侧「指挥」键，弹出圆盘，局内放慢（`command/wheel_slow` 0.2）。
2. 点「部署」或「集火」扇区，**按下那一刻**就进入选点。设计上手指不抬起，拖到目标后松手确认。准星在手指上方 96 像素。
3. 信息板写「松手确认 · 拖回圆盘处取消」。选点最多 3 秒（`command/pick_cap`），到时按准星所在处下令。

不明确的地方：

| # | 问题 | 后果 |
|---|---|---|
| a | 玩家的自然动作是「点一下」，而抬起手指就等于「松手确认」。这时准星落在扇区上方 96 像素处 | 集火：那里一般没有目标，直接取消，只有一声轻响，玩家不知道发生了什么。部署：在圆盘附近下了一个不是自己选的落点 |
| b | Godot 缺省把触点模拟成鼠标键（`emulate_mouse_from_touch`），而且模拟出来的鼠标键**比触点本身先到**。圆盘先被这一下模拟左键确认；接着到的真实触点因为圆盘已经关了，转进了选点阶段 | 旧流程里选点是从模拟键开始的，没有绑定手指。手指一抬就按抬起处上方 96 像素下令，按住拖的设计实际走不通。新流程起初也被这一下打乱（集火当成点空白取消，部署在圆盘位置预选），回归测试用真实触点复现了这个问题。现在圆盘遇到模拟鼠标键直接吞掉，选点也不收开始那一帧的点按 |
| c | 准星在手指上方 96 像素 | 点哪儿不是哪儿，和「直接点精英」的直觉相反 |
| d | 信息板下的「最近的 Boss / 精英」只画了，没有接点按 | 点了没反应 |
| e | 可选目标的框是 55% 透明、1.6 像素的细角标；没有剩余时间显示 | 1 倍下看不清哪些能点；3 秒到时自动下令也没有预告 |

## 2. 新流程（`command/touch_confirm = 1`，缺省）

只改触屏。桌面键鼠、手柄不变：鼠标仍是准星跟随、左键确认。

1. 点「指挥」键，弹出圆盘，局内放慢（不变）。
2. 点「集火」或「部署」，进入选点，放慢保持。**手指抬起不下令**，模拟鼠标键也被吃掉。
3. **集火**
   - 场上可选的精英 / Boss 框常亮：深色衬底加亮角标，呼吸闪，头顶标 ELITE / BOSS。屏外的目标在屏幕边缘有标签，也能点。
   - **点一只 = 预选**：框变金色，弹一下，头顶出现「再点一次确认」。
   - **再点同一只 = 下令**。点另一只 = 换预选；点空白处 = 取消（落在摇杆区时，这一下同时起摇杆）。
   - 信息板右侧有两个键：「最近目标」（预选离队长最近的一只）和「取消」。
4. **部署**
   - **点虚线圈内的地面 = 预选落点**：金色标记加光圈，队友到落点的虚线，标记上方写「再点一次确认」。
   - **再点标记 = 下令**（64 像素内都算）。点别处 = 换落点；点圈外 = 不预选，信息板提示「超出指挥范围，请点虚线圈内」。
   - 用信息板的「取消」键或再点「指挥」键退出。
5. 冲刺、技能、终结技、暂停这些键在选点中照常可按。
6. 信息板写当前这一步该做什么；底边细条是剩余选点时间，预选后变金色。时限 `command/pick_cap_touch` 6 秒（触屏要点两下，比键鼠的 3 秒长）。到时有预选就按预选下令，没有就取消。选点期间每秒扣 3% 作战时限，不变。

配色：可选目标保持原色（精英青、Boss 红），预选统一用金色 `PRE_COL`，和两者都分得开。

## 3. 配置与测试

- `balance.json` → `command`：
  - `touch_confirm`：1 = 新流程，0 = 旧的按住拖；
  - `pick_cap_touch`：触屏选点时限，6 秒。
- **回归** `check.py --only touch_command`（`tests/touch_command_test`）：全程用真实触点，含模拟鼠标键。覆盖：
  - 点「指挥」→ 选集火 → 抬手不下令；
  - 点 B 预选 → 点 A 换预选 → 再点 A 下令；
  - 集火时点空白取消；
  - 部署：预选 → 换落点 → 再点下令；
  - 圈外的地面不预选，「取消」键能退出。
- **示意截图** `tools/probes/touch_command_shots.py [mode=focus,point] [res=phone] [old]`：每种模式出 6 张关键帧（圆盘 / 选点 / 预选 / 换预选 / 下令 / 生效）。
  - 截图要刷精英：autotest 的 `--spawnat=<秒>:<敌人>@<dx>:<dy>;…`；
  - 选点计划 `--pickplan` 新增 `tap / tapf / tapsnap / tappre / tapdeploy`。
