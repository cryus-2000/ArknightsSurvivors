# 219 新手引导：演示局 + 当下提示卡 + 实时小演示（11-01）

## 1. 需求

用户 11-01 提出：

- 新手引导分两条线：「熟悉类幸存者」和「不熟悉类幸存者」。
- 指挥圆盘这类本作特有的系统，要有演示介绍。

同日补充（改口径）：「没玩过」那条线改成一段非常简短的演示局，总长 1–2 分钟以内。

- 演示局只教四件事：移动 / 自动攻击、捡经验升级三选一、招募一名队友、按一次终结技。教完就进正式局。
- 灯火、商人、Boss 不在演示局里教。改成正式局里第一次碰到时弹提示卡，和「玩过」那条线共用。
- 指挥圆盘的演示照旧放在提示卡里。

总口径不变：10-24 用户定过「开局指南不要写太多」。这次的做法是「少字 + 演示 + 在当下教」：

- 每张卡一句话，配一段动态演示。
- 细节仍在暂停菜单的「指南」完整版里（guide.json 的 more）。

## 2. 现状（改前）

- 开局指南 guide.json：5 页（灯火 / 指挥 / 商人 / 节点卡 / 操作）。首次精简，完整版在暂停菜单「指南」。
- 首局聚光框引导（screens/tour.gd）：
  - 开场结束后暂停局内，依次框生命与灯火 / 移动 / 指挥 / 队友生命。
  - 存档 `Cfg.seen_intro`。
- 到点小提示（tour.gd TIPS）：精英 / Boss / 灯火不足 / 升级，各弹一次，存档 `Cfg.seen_tips`。
- 主界面引导（title_tour.gd）：新手十连之后，指引图鉴 → 返回 → 集结出发。这次不动。

## 3. 方案

### 3.1 问一次

第一局开场结束时（原聚光框引导的位置），暂停局内，弹出问题框：

> 玩过《吸血鬼幸存者》这类游戏吗？

| 选项 | 小字 | 走向 |
|---|---|---|
| 玩过 | 直接开始，遇到本作特有的系统时再提示 | 正式局 + 提示卡 |
| 没玩过 | 先走一段约 1 分钟的演示局 | 演示局 → 正式局 + 提示卡 |
| 跳过引导 | 之后可在「设置 · 操作」里重新打开 | 不引导 |

- 结果存 `Cfg.onboard`：`""` 未问 / `"new"` / `"vet"` / `"off"`。
- 老存档同样问一次，方便测试者体验。
- 「设置 → 操作 → 新手引导」三格：没玩过 / 玩过 / 关闭。改成前两档时清掉已出过的卡，下局重新教。
- 选了任一项，旧的聚光框引导都不再弹（`seen_intro = true`）。
- 重看：暂停菜单新增「演示」（H），打开演示图鉴，←/→ 翻全部卡，每张都带演示。标题页图鉴的入口放第二版。

### 3.2 「没玩过」：演示局（1–2 分钟）

第一局就是演示局：

- 怪物密度 ×0.5（`onboard/density`），敌人伤害 ×0.5（`onboard/enemy_dmg`）。
- 卡片依次出现，做完动作才进下一张。
- 每张至少显示 4 秒，这段时间里做完的动作照算。

| # | 卡 | 出现时 | 怎样算做完 |
|---|---|---|---|
| 1 | 移动（攻击自动） | 开局 | 累计移动 450 像素 |
| 2 | 经验与升级 | 移动做完；队长身边放一圈经验结晶，正好够升一级 | 升一级（三选一选完） |
| 3 | 招募 | 升级做完；下一个升级面板直接弹保底招募画面 | 编队 ≥ 2 人 |
| 4 | 终结技 | 招募做完；终结技直接充满 | 放出一次终结技 |
| 5 | 演示结束 | 终结技放完 | 2.5 秒后重开进正式局 |

- 第 5 张后重开的正式局，开局配置和演示局相同。
- 实测：机器人代打约 30 秒走完（真人估计 1 分钟上下）。
- 兜底：演示局到 2:30（`onboard/drill_max`）还没走完，直接弹「演示结束」。
- 演示局卡片右上角是「跳过演示」，点了直接进正式局。
- 招募不了（名册没人可招）时，跳过招募；没有终结技（`ult/on = 0`）时，跳过终结技。

### 3.3 正式局：第一次碰到时弹提示卡（两条线共用）

| 卡 | 何时出现 | 怎样算做完 |
|---|---|---|
| 灯火 | 灯火第一次掉到 75 以下 | 看 9 秒自动收起 |
| 商人 | 商人出现 | 打开商店，或商人离开 |
| Boss | Boss 出现 | 看 9 秒自动收起 |
| 小队与队长 | 第一次招募后（演示局招募过就不出） | 看 9 秒自动收起 |
| 指挥圆盘 | 编队 ≥ 2 人后 8 秒 | 用圆盘下一次命令，或 40 秒 |
| 终结技 | 终结技第一次充满（演示局教过就不出） | 放出一次终结技，或 40 秒 |
| 连携 | 第一次连携 | 看 9 秒自动收起 |
| 溟痕与引航灯标 | 第一次踩进溟痕，或灯标进入 520 像素内 | 点亮一座灯标，或 25 秒 |
| 节点卡 | 第一次翻完节点卡 | 看 9 秒自动收起 |

旧的到点小提示里，「升级」「灯火不足」「Boss」三条在开启引导时不再弹（由演示局 / 提示卡覆盖），「精英」照弹。

认知塑造（局外）放第二版：第一次结算回到标题、有可用点数时提示。

### 3.4 提示卡

- 位置：桌面和手机都在左上，生命 / 灯火条下方，不拦输入。
  - 手机试过顶部居中，会盖住屏幕中央的队长，所以改回左上。
- 卡片构成：
  - 左边是实时小演示，循环几秒。
  - 右边：英文小标、标题、一句话、做完条件（移动有进度条）。
  - 英文小标：演示局里是 `TUTORIAL n / 4`，正式局里是 `NEW`。
  - 右上角：正式局是「跳过」，只跳这一张；演示局是「跳过演示」。
- 只在局内 PLAY 状态显示。选卡、商店、暂停时隐藏，回来再出现。
- 文案按 docs/76，「队长」「编队」「源石锭」「灯火」「引航灯标」「溟痕」「终结技」「连携」照本作用语。
- 样式按 docs/37：斜切面板、黄条、英文小标。

### 3.5 演示

每张卡里画一段游戏内实时小演示，不录视频，网页包不变大：

- 干员用真实待机帧条（choice_panel.op_idle + op_figure）。
- 怪物、经验、灯油用局内同色的程序画法。
- 指挥圆盘直接调真圆盘的画法，缩小画（command_wheel.draw_demo）。缩小画时不吃手机的正文放大。

各卡演示：

- 移动：键帽 WASD 按方向亮起（触屏：左下摇杆拖动），队长走位，子弹自动飞向怪。
- 经验与升级：结晶被吸过来 → 经验条涨满 → 三张小卡弹出，选中一张。
- 招募：三选一里出现干员卡 → 选中 → 干员从天而降，落在队长身边。
- 终结技：键帽 Q 按住（触屏：终结技键），地面出现范围圈 → 松开，闪白冲击，圈内的怪倒下。
- 演示结束：队长带着队友前进。
- 灯火：怪撞上队长，灯火条掉一截、光圈缩小 → 走到灯油上，灯火回满、光圈放大。
- 商人：屏幕边缘的金色箭头 → 顺着走 → 商人和 60 秒倒计时。
- Boss：地面预警圈扩大 → 队长冲刺（残影）躲出圈外 → 圈里爆开。
- **指挥圆盘**（8 秒一轮，每段约 2 秒）：
  1. 按 F / 指挥键，打开圆盘，选「突击」。
  2. 队友冲出去打怪。
  3. 再开圆盘选「部署」，点落点。
  4. 队友落位，挡住涌来的怪（怪停在阻挡线前）。
- 连携：队长放技能（光环）→ 队友头像亮起 → 队友接一招。
- 溟痕与引航灯标：紫黑溟痕铺地 → 队长站到灯标旁读条 → 灯标亮起，溟痕退散。
- 节点卡：三张卡背 → 选中一张翻开。

触屏版：

- 文案换成「拖动」「点」「终结技键」「指挥键」。
- 演示里的键帽换成虚拟摇杆 / 圆按钮。

### 3.6 机器人与批跑

- 引导只在 `Mode.PLAY`、非演练 / 练习 / 图鉴演示的真人局里生效。
- 机器人、自动测试、批跑一律不进引导。`spawner.density` 乘 1，同 seed 结果不变。

录片 / 截图开关：

| 开关 | 作用 |
|---|---|
| `--onboard=new\|vet\|ask\|view` | 自动测试局里也走引导：演示局（结束时直接退出，不重开）/ 问题框 / 演示图鉴逐张截图 |
| `--onboarddemo=<卡 id>` | 进局直接出这张卡 |

## 4. 实现

| 文件 | 内容 |
|---|---|
| `game/data/onboard.json` | 问题框与各卡文案；`drill` 演示局步骤，`tips` 正式局提示卡 |
| `game/scripts/screens/onboard.gd` | 状态机：问题框、演示局（放经验 / 强制招募 / 充满终结技 / 重开）、提示卡队列、做完判定、演示图鉴 |
| `game/scripts/screens/onboard_demos.gd` | 各卡的小演示画法（纯画面，不碰随机数） |
| `game/scripts/screens/command_wheel.gd` | `draw_demo`：缩小画真圆盘 |
| `game/scripts/run/build_guide.gd` | `must_recruit` 认演示局的招募步 |
| `game/scripts/settings.gd` | `Cfg.onboard` / `onboard_seen` 存档 |
| `game/scripts/settings_panel.gd` | 「操作」页加「新手引导」行 |
| `game/data/balance.json` | `onboard` 段：density / enemy_dmg / drill_max |

钩子：

- `intro.end_opening` 启动引导。
- `wheel.confirm` 记下令。
- `spawner.density` 乘演示局修正。
- `hud` 画卡。
- 暂停菜单「演示」。
