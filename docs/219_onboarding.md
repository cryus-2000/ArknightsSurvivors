# 219 新手引导：两条线 + 当下教 + 实时小演示（11-01）

## 1. 需求

用户 11-01 提出：

- 新手引导分两条线：「熟悉类幸存者」和「不熟悉类幸存者」。
- 指挥圆盘这类本作特有的系统，要有演示介绍。

口径不变：10-24 用户定过「开局指南不要写太多」。这次的做法是「少字 + 演示 + 在当下教」：

- 每张卡一句话，配一段动态演示。
- 细节仍在暂停菜单的「指南」完整版里（guide.json 的 more）。

## 2. 现状（改前）

- 开局指南 guide.json：5 页（灯火 / 指挥 / 商人 / 节点卡 / 操作）。首次精简，完整版在暂停菜单「指南」。
- 首局聚光框引导（screens/tour.gd）：
  - 开场结束后暂停局内，依次框生命与灯火 / 移动 / 指挥 / 队友生命。
  - 存档 `Cfg.seen_intro`。
- 到点小提示（tour.gd TIPS）：精英 / Boss / 灯火不足 / 升级，各弹一次，存档 `Cfg.seen_tips`。
- 主界面引导（title_tour.gd）：新手十连之后，指引图鉴 → 返回 → 集结出发。这次不动。

## 3. 方案

### 3.1 问一次

第一局开场结束时（原聚光框引导的位置），暂停局内，弹一个问题框：

> 玩过《吸血鬼幸存者》这类游戏吗？

三个选项：玩过 / 没玩过 / 跳过引导。

- 结果存 `Cfg.onboard`：`""` 未问 / `"new"` 没玩过 / `"vet"` 玩过 / `"off"` 跳过。
- 老存档同样问一次（`onboard` 缺省 `""`），方便测试者体验。以后要改，去「设置 → 操作 → 新手引导」。
- 选了任一项，旧的聚光框引导都不再弹（`seen_intro = true`）。新引导的卡片取代它。
- 重看：暂停菜单新增「演示」，打开演示图鉴，←/→ 翻全部卡片，每张都带演示。图鉴（标题页）入口放第二版。

### 3.2 「没玩过」：引导局

第一局按引导局走，引导到第一只 Boss 倒下（最晚 4:00）为止：

- 怪物密度 ×0.6（`onboard/density`）。
- 敌人伤害 ×0.7（`onboard/enemy_dmg`）。
- 商人、Boss 的时间不变。

基础卡依次在当下弹出，做完动作才进下一张：

| # | 卡 | 何时出现 | 怎样算做完 |
|---|---|---|---|
| 1 | 移动 | 开局 | 累计移动 450 像素 |
| 2 | 经验与升级 | 移动做完 | 选完第一次升级三选一 |
| 3 | 灯火 | 升级做完；身边 260 像素处放一桶灯油 | 拾取灯油 |
| 4 | 招募 | 灯火做完，且 Lv.3 以上 | 编队 ≥ 2 人 |
| 5 | 商人 | 商人出现 | 打开商店，或商人离开 |
| 6 | Boss | Boss 出现 | Boss 倒下，或 30 秒 |

每张卡至少显示 4 秒；这段时间里做完的动作照算。

做完一张后，接着走 §3.3 的特有系统卡。小队卡和招募卡重复，「没玩过」不出小队卡。

旧的到点小提示里，「升级」「灯火不足」「Boss」三条在「没玩过」时不弹（新卡已覆盖）。「精英」照弹。

### 3.3 「玩过」：只教本作特有的

都是第一次碰到时弹：

| 卡 | 何时出现 | 怎样算做完 |
|---|---|---|
| 小队与队长 | 第一次招募后 | 看 9 秒自动收起 |
| 指挥圆盘 | 招募后 8 秒 | 用圆盘下一次命令，或 40 秒 |
| 终结技 | 终结技第一次充满 | 放出一次终结技，或 40 秒 |
| 连携 | 第一次连携 | 看 9 秒自动收起 |
| 溟痕与引航灯标 | 第一次踩进溟痕，或灯标进入 520 像素内 | 点亮一座灯标，或 25 秒 |
| 节点卡 | 第一次翻完节点卡 | 看 9 秒自动收起 |

认知塑造（局外）放第二版：第一次结算回到标题、有可用点数时提示。

### 3.4 提示卡

- 位置：桌面和手机都在左上，生命 / 灯火条下方，不拦输入。
  - 手机试过顶部居中，会盖住屏幕中央的队长，改回左上。
- 卡片构成：
  - 左边是实时小演示，循环几秒。
  - 右边：英文小标、标题、一句话、进度（移动的进度条 / 「做完继续」）。
  - 右上角有「跳过」，只跳这一张。
  - 「关闭引导」放在演示图鉴和设置里。
- 只在局内 PLAY 状态显示。选卡、商店、暂停时隐藏，回来再出现。
- 文案按 docs/76：
  - 「队长」「编队」「源石锭」「灯火」「引航灯标」「溟痕」「终结技」「连携」照本作用语。
  - 键名用 keycap 画，不在句子里写 `KEY_`。
- 样式按 docs/37：斜切面板、黄条、英文小标。

### 3.5 演示

每张卡里画一段游戏内实时小演示，不录视频，网页包不变大：

- 干员用真实待机帧条（choice_panel.op_idle + op_figure）。
- 怪物、经验、灯油用局内同色的程序画法。
- 指挥圆盘直接调真圆盘的画法，缩小画（command_wheel.draw_demo）。

各卡演示：

- 移动：键帽 WASD 逐个亮起（触屏：左下摇杆拖动），队长走位，子弹自动飞向怪。
- 经验与升级：结晶被吸过来 → 经验条涨满 → 三张小卡弹出，选中一张。
- 灯火：怪碰到队长，灯火条掉一截、光圈缩小 → 走到灯油上，灯火回满、光圈放大。
- 招募：升级三选一里出现干员卡 → 选中 → 干员从天而降，落在队长身边。
- 商人：屏幕边缘的金色箭头 → 队长顺着箭头走 → 商人和 60 秒倒计时。
- Boss：地面预警圈慢慢扩大 → 队长冲刺（残影）躲出圈外 → 圈里爆开。
- **指挥圆盘**（约 8 秒一轮，每段约 2 秒）：
  1. 打开圆盘，指针转到「突击」，选中。
  2. 队友冲出去打怪。
  3. 再开圆盘选「部署」，落点标记落地。
  4. 队友走到落点，挡住怪群（怪停在阻挡线前）。
- 终结技：键帽 Q 按住，地面出现范围圈 → 松开，冲击闪光，圈内怪倒下。
- 连携：队长放技能（光环）→ 队友头像亮起 → 队友接一招。
- 溟痕与引航灯标：紫黑溟痕铺地 → 队长站到灯标旁，读条 → 灯标亮起，溟痕退散。
- 节点卡：三张卡背 → 选中一张翻开。

触屏版：

- 文案换成「拖动」「点」「终结技键」「指挥键」。
- 演示里的键帽换成虚拟摇杆 / 圆按钮。

### 3.6 机器人与批跑

- 引导只在 `Mode.PLAY`、非演练 / 练习 / 图鉴演示的真人局里生效。
- 机器人、自动测试、批跑一律不进引导，同 seed 结果不变。
- 引导局的密度 / 伤害修正只在 `onboard == "new"` 的第一局生效。

录片 / 截图开关：

| 开关 | 作用 |
|---|---|
| `--onboard=new\|vet\|ask\|view` | 自动测试局里也走引导：问题框 / 引导局 / 演示图鉴逐张截图 |
| `--onboarddemo=<卡 id>` | 进局直接出这张卡 |
