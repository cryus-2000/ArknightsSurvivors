# 219 新手引导：演示局 + 当下提示卡 + 实时小演示（11-01）

## 1. 需求

用户 11-01 提出：

- 新手引导分两条线：「熟悉类幸存者」和「不熟悉类幸存者」。
- 指挥圆盘这类本作特有的系统，要有演示介绍。

同日补充（改口径）：「没玩过」那条线改成一段非常简短的演示局，总长 1–2 分钟以内。

- 演示局只教四件事：移动 / 自动攻击、捡经验升级三选一、招募一名队友、按一次终结技。教完就进正式局。
- 灯火、商人、Boss 不在演示局里教。改成正式局里第一次碰到时弹提示卡，和「玩过」那条线共用。
- 指挥圆盘的演示照旧放在提示卡里。

总口径不变：10-24 用户定过「开局指南不要写太多」。这次的做法是「少字 + 演示 + 在当下教」：

- 每张卡一句话，配一段动态演示。
- 细节仍在暂停菜单的「指南」完整版里（guide.json 的 more）。

## 2. 现状（改前）

- 开局指南 guide.json：5 页（灯火 / 指挥 / 商人 / 节点卡 / 操作）。首次精简，完整版在暂停菜单「指南」。
- 首局聚光框引导（screens/tour.gd）：
  - 开场结束后暂停局内，依次框生命与灯火 / 移动 / 指挥 / 队友生命。
  - 存档 `Cfg.seen_intro`。
- 到点小提示（tour.gd TIPS）：精英 / Boss / 灯火不足 / 升级，各弹一次，存档 `Cfg.seen_tips`。
- 主界面引导（title_tour.gd）：新手十连之后，指引图鉴 → 返回 → 集结出发。这次不动。

## 3. 方案

### 3.1 问一次

第一局开场结束时（原聚光框引导的位置），暂停局内，弹出问题框：

> 玩过《吸血鬼幸存者》这类游戏吗？

| 选项 | 小字 | 走向 |
|---|---|---|
| 玩过 | 直接开始，遇到本作特有的系统时再提示 | 正式局 + 提示卡 |
| 没玩过 | 先走一段约 1 分钟的演示局 | 演示局 → 正式局 + 提示卡 |
| 跳过引导 | 之后可在「设置 · 操作」里重新打开 | 不引导 |

- 结果存 `Cfg.onboard`：`""` 未问 / `"new"` / `"vet"` / `"off"`。
- 老存档同样问一次，方便测试者体验。
- 「设置 → 操作 → 新手引导」三格：没玩过 / 玩过 / 关闭。改成前两档时清掉已出过的卡，下局重新教。
- 选了任一项，旧的聚光框引导都不再弹（`seen_intro = true`）。
- 重看：暂停菜单新增「演示」（H），打开演示图鉴，←/→ 翻全部卡，每张都带演示。标题页图鉴的入口放第二版。

### 3.2 「没玩过」：演示局（1–2 分钟）

第一局就是演示局：

- 怪物密度 ×0.5（`onboard/density`），敌人伤害 ×0.5（`onboard/enemy_dmg`）。
- 卡片依次出现，做完动作才进下一张。
- 每张至少显示 4 秒，这段时间里做完的动作照算。

| # | 卡 | 出现时 | 怎样算做完 |
|---|---|---|---|
| 1 | 移动（攻击自动） | 开局 | 累计移动 450 像素 |
| 2 | 经验与升级 | 移动做完；队长身边放一圈经验结晶，正好够升一级 | 升一级（三选一选完） |
| 3 | 招募 | 升级做完；下一个升级面板直接弹保底招募画面 | 编队 ≥ 2 人 |
| 4 | 终结技 | 招募做完；终结技直接充满 | 放出一次终结技 |
| 5 | 演示结束 | 终结技放完 | 2.5 秒后重开进正式局 |

- 第 5 张后重开的正式局，开局配置和演示局相同。
- 实测：机器人代打约 30 秒走完（真人估计 1 分钟上下）。
- 兜底：演示局到 2:30（`onboard/drill_max`）还没走完，直接弹「演示结束」。
- 演示局卡片右上角是「跳过演示」，点了直接进正式局。
- 招募不了（名册没人可招）时，跳过招募；没有终结技（`ult/on = 0`）时，跳过终结技。

### 3.3 正式局：第一次碰到时弹提示卡（两条线共用）

| 卡 | 何时出现 | 怎样算做完 |
|---|---|---|
| 灯火 | 灯火第一次掉到 75 以下 | 看 9 秒自动收起 |
| 商人 | 商人出现 | 打开商店，或商人离开 |
| Boss | Boss 出现 | 看 9 秒自动收起 |
| 小队与队长 | 第一次招募后（演示局招募过就不出） | 看 9 秒自动收起 |
| 指挥圆盘 | 编队 ≥ 2 人后 8 秒 | 用圆盘下一次命令，或 40 秒 |
| 终结技 | 终结技第一次充满（演示局教过就不出） | 放出一次终结技，或 40 秒 |
| 连携 | 第一次连携 | 看 9 秒自动收起 |
| 溟痕与引航灯标 | 第一次踩进溟痕，或灯标进入 520 像素内 | 点亮一座灯标，或 25 秒 |
| 节点卡 | 第一次翻完节点卡 | 看 9 秒自动收起 |

旧的到点小提示里，「升级」「灯火不足」「Boss」三条在开启引导时不再弹（由演示局 / 提示卡覆盖），「精英」照弹。

认知塑造（局外）放第二版：第一次结算回到标题、有可用点数时提示。

### 3.4 提示卡

- 位置：桌面和手机都在左上，生命 / 灯火条下方，不拦输入。
  - 手机试过顶部居中，会盖住屏幕中央的队长，所以改回左上。
- 卡片构成：
  - 左边是实时小演示，循环几秒。
  - 右边：英文小标、标题、一句话、做完条件（移动有进度条）。
  - 英文小标：演示局里是 `TUTORIAL n / 4`，正式局里是 `NEW`。
  - 右上角：正式局是「跳过」，只跳这一张；演示局是「跳过演示」。
- 只在局内 PLAY 状态显示。选卡、商店、暂停时隐藏，回来再出现。
- 文案按 docs/76，「队长」「编队」「源石锭」「灯火」「引航灯标」「溟痕」「终结技」「连携」照本作用语。
- 样式按 docs/37：斜切面板、黄条、英文小标。

### 3.5 演示

每张卡里画一段游戏内实时小演示，不录视频，网页包不变大：

- 干员用真实待机帧条（choice_panel.op_idle + op_figure）。
- 怪物、经验、灯油用局内同色的程序画法。
- 指挥圆盘直接调真圆盘的画法，缩小画（command_wheel.draw_demo）。缩小画时不吃手机的正文放大。

各卡演示：

- 移动：键帽 WASD 按方向亮起（触屏：左下摇杆拖动），队长走位，子弹自动飞向怪。
- 经验与升级：结晶被吸过来 → 经验条涨满 → 三张小卡弹出，选中一张。
- 招募：三选一里出现干员卡 → 选中 → 干员从天而降，落在队长身边。
- 终结技：键帽 Q 按住（触屏：终结技键），地面出现范围圈 → 松开，闪白冲击，圈内的怪倒下。
- 演示结束：队长带着队友前进。
- 灯火：怪撞上队长，灯火条掉一截、光圈缩小 → 走到灯油上，灯火回满、光圈放大。
- 商人：屏幕边缘的金色箭头 → 顺着走 → 商人和 60 秒倒计时。
- Boss：地面预警圈扩大 → 队长冲刺（残影）躲出圈外 → 圈里爆开。
- **指挥圆盘**（8 秒一轮，每段约 2 秒）：
  1. 按 F / 指挥键，打开圆盘，选「突击」。
  2. 队友冲出去打怪。
  3. 再开圆盘选「部署」，点落点。
  4. 队友落位，挡住涌来的怪（怪停在阻挡线前）。
- 连携：队长放技能（光环）→ 队友头像亮起 → 队友接一招。
- 溟痕与引航灯标：紫黑溟痕铺地 → 队长站到灯标旁读条 → 灯标亮起，溟痕退散。
- 节点卡：三张卡背 → 选中一张翻开。

触屏版：

- 文案换成「拖动」「点」「终结技键」「指挥键」。
- 演示里的键帽换成虚拟摇杆 / 圆按钮。

## 6. 第一次进游戏强制走完（11-02）

用户 11-02：「第一把开局的指南我觉得可以设置成不能跳过，给第一次玩的人展现出我们的特色」。

协调人定的边界：

- 强制部分总长 ≤ 90 秒，节奏紧凑。
- 必须展示本作特色：小队（招募入队、换队长）、终结技（立绘切入 + 冲击帧）、连携 / 羁绊、指挥圆盘。
- 「熟悉幸存者」那条线也要看到这几样，只是更快。
- 暂停菜单照常可用。中途退出不算跳过，下次进来从头走。手机触屏同样适用。

### 6.1 什么时候强制

- 判定：`Cfg.onboard_done` 为 false，即本机和云存档都没有完成记录。
- 存档：`progress/onboard_done`。云存档字段 `prog.onb`，合并取或，旧正文里没有就不补。
- 旧档迁移：`onboard_seen` 里有 `drill`（走完过旧演示局）的算完成，其余老玩家会被强制一次。
- 强制时有这些变化：
  - 不管设置里选了什么，都从问题框开始。
  - 问题框只有「玩过」「没玩过」两项，没有「跳过引导」；Esc 不选任何一项。
  - 演示局卡片上没有「跳过演示」，`skip_all` 不生效。
  - 上次中途退出时留下的演示局步骤记录清掉，从头走。
- 走完「演示结束」记 `onboard_done = true`，之后和以前一样可跳过。

### 6.2 两条线都走演示局

| 线 | 步骤 | 机器人代打实测 |
|---|---|---|
| 没玩过 `drill` | 移动 → 经验与升级 → 招募 → 连携与羁绊 → 终结技 → 指挥 · 部署 → 指挥 · 随行 → 演示结束 | 约 34 秒（真实秒，含问题框 2.4 秒、指挥段约 11.4 秒） |
| 玩过 `drill_vet` | 招募 → 连携与羁绊 → 终结技 → 指挥 · 部署 → 指挥 · 随行 → 演示结束 | 约 27 秒（指挥段约 11.4 秒） |

- 真人做每一步要更久。上限 `onboard/drill_max`：150 → 90 秒（从演示局开始算局内时间）。到点直接出「演示结束」，没教到的照旧在正式局第一次碰到时弹提示卡。
- 节奏：演示局里每张卡至少显示 2.5 秒（正式局提示卡仍 4 秒），卡间隔 0.6 秒（正式局仍 1.6 秒）。
- 招募：「玩过」那条线一开局就弹保底招募画面。卡上补一句「出发前可在编队界面更换队长」。
  - 局内换队长的玩家入口 10-29 已删（squad.swap_leader 只剩测试用），所以「换队长」只在卡上说明，不做局内操作。
- 连携与羁绊：
  - 卡出现时充满队长技力，在队长身边 210 像素放 8 只怪（`LINK_PACK`），保证技能和连携都有目标。
  - 3 秒（`LINK_NUDGE`）内队长还没放出技能，就按「队长放了技能」直接触发一次连携。水月这类技能是蓄进下一次普攻的，不会马上放。
  - 搭档和队长有羁绊时自动换成专属合击（link_bond）。等 10 秒还没连携就往下走。
- 终结技：直接充满，要玩家自己按 Q（触屏按终结技键）放出一次。立绘切入 + 冲击帧走正常终结技演出。
- 指挥圆盘：改成情境演示，见 §6.5。
- 演示结束：文案改为「小队、连携、终结技、指挥就是这些……」。2.5 秒后重开进正式局。

### 6.5 指挥段改成情境演示（11-02 第二轮）

用户批「按这个改」：原来「下达一次指挥就往下走」学不到东西，改为情境演示，约 15 秒。整个强制部分仍 ≤ 90 秒，两条线都带。卡片样式没动，等 HUD 重设计方向稿出来后统一。

指令名和效果照现行指挥 v2 圆盘（docs/209 §1.6，command_wheel.ITEMS_V2）：

| 扇区 | 圆盘上的说明 |
|---|---|
| 随行 | 护卫阵型：队长身边安全，队友不受伤 |
| 突击 | 按职业分工出击：会受伤，限时行动 |
| 部署 | 点一个位置落位：重装、近卫阻挡敌人 |
| 集火 | 点精英或 Boss：全队集火该目标 |

**第 1 步「指挥 · 部署」**

- 卡片出现时（终结技演出完之后），从队长一侧 400 像素外放一群怪（10 只，`PACK_N`），怪朝队长涌来。屏内靠边，看得见怪涌来，也看得见队友过去挡。
  - 默认右侧，右侧放不下就放左侧。
  - 队友在突击中的话先改回随行。
- 打开圆盘时：
  - 世界放慢（原有的 `command/wheel_slow` 0.2）。
  - 各扇区每 0.8 秒（`TOUR_STEP`）依次亮起，下方说明板显示该项的说明。
  - 转完一圈停在「部署」上，提示该选这个。
  - 玩家悬停或点选时，以玩家的选择为准。
- 选「部署」后进入选点，点在敌人来的方向。
- **做完判定以指令实际生效为准**，以下三条同时满足才算：
  - 部署指令在生效（`squad.order_kind == "point"`）；
  - 落点在怪群那一侧；
  - 至少一名队友已经走到驻扎位（48 像素内）。

  只点了扇区、还在选点、部署到反方向、队友还没走到，都不算。

**第 2 步「指挥 · 随行」**

- 再开圆盘选「随行」。
- 判定：这一步里确实下过令，部署已撤销（`order_kind == ""`），姿态不再是突击。队友离得远时，「随行」会先闪回集合，这也算生效。

**其余规则**

- 两步都没有超时，由 90 秒上限兜底。
- 触屏（「指挥」键 + 点扇区 + 拖准星）、手柄（LB + 摇杆）走的都是圆盘和选点本身的输入，引导不另加入口。
- 正式局里演示局教过「部署」的，不再弹「指挥圆盘」提示卡。

**实测（机器人代打，真实秒）**

| 线 | 指挥段 | 强制部分总长（含问题框） |
|---|---|---|
| 没玩过 | 约 11.4 秒（部署 8.2 + 随行 3.2） | 约 34 秒 |

## 7. 演示局加「引航灯标」「集火」两步（11-07，用户 11-06「玩家还不知道灯塔的效果……集火之类的也加上，同时防止卡死在教程关里」）

「灯塔」在游戏里就是**引航灯标**（`run/beacon.gd`）。两步都排在「指挥 · 随行」之后、「演示结束」之前，没玩过 / 玩过两条线都有：`drill`、`drill_vet` = …、`deploy`、`regroup`、**`beacon`**、**`focus`**、`drill_end`。

| 步 | 放什么 | 做完条件 | 兜底（防卡死） |
|---|---|---|---|
| `beacon` 引航灯标 | 队长身边 240 像素放一座灯标 + 3 片溟痕（`beacon.spawn_demo`，不取随机数）；卡上演示 = 溟痕卡画法 + 点燃后「灯火 +5」「溟痕退散 · 灯标庇护 30 秒」 | 灯标点燃（光圈里读条约 3 秒） | ① 24 秒没点燃：引导代点亮（`beacon.light_demo`，同样的光爆 + 驱散）；② 灯标被熄灭 / 清掉：重放，最多 2 次；③ 8 个方向都放不下（地形 / 缩圈）：这一步直接跳过 |
| `focus` 指挥 · 集火 | 队长身边 380 像素放一只精英（生命 ×4，别被自动攻击提前打死）；文案里的键名按 `play_keys` 取（`{cmd}` = 指挥键，手柄 LB、触屏用「指挥」键文案）；卡上演示 = 开圆盘选「集火」→ 点中精英（洋红锁定角标）→ 全队攻击 → 倒下 | 下了一次集火指令（`squad.order_kind == "focus"`） | ① 24 秒没下：引导代下（`apply_order("focus")`）；下不了令（作战时限没恢复）直接跳过；② 精英被打掉：重放，最多 2 次，再不行跳过；③ 编队只有 1 人 / 圆盘没有「集火」项：这一步直接算已教过（`_moot`） |
