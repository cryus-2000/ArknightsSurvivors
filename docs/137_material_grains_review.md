# 137 材质颗粒验收（Codex codex/particle-materials @ 7289a73dc，10-24）

粒子化会话（分支 `claude/particles-8d10a8`）验收 Codex 的「材质颗粒」未验收草稿：共享材质颗粒池、艾雅法拉火球 / 熔岩 / 点燃爆燃、拉普兰德剑气转碎片。模板规范见 docs/136，Codex 交接说明 `art/incoming/codex_material_grains_1024.md`。

## 1. 结论

- **可以合**（开关 `fx/material_grains` 缺省关，关时与 main 逐行相同，开时也逐行相同）。合入的是本分支（含修复），不要直接合 7289a73dc。
- **缺省仍关**：桌面帧时代价小（§4），但观感还没定：艾雅三项用户已给阶段性方向认可，拉普兰德后半段偏暗、用户要的「明显差异」不够（§3）。等 Codex 第 2 轮（`art/incoming/codex_order_material_grains_r2.md`）+ 用户看 gif 后再决定哪几项缺省开。
- 建议拆两档开：艾雅三项与通用命中（火 / 水 / 体液）先开；拉普兰德等第 2 轮。现在只有一个总开关，第 2 轮时顺手拆成按效果开（不改预算）。

## 2. 代码审查

| 项 | 结论 |
|---|---|
| 只用 `g.vrng`、不碰命中 / 伤害 / 周期 | 是。材质代码只在画面路径（`vfx.fx_sprite`、`MagmaProjectile` 画法与 `material_trail`、`fx_grains._lappland_step`）读 `g.vrng`；`fireball_impact` 开着时用帧条代替程序爆点、`ignite_hit` 少喷程序火星，都是 `o.fx` / `g.fx` 画面项。同 seed 证据见 §5。 |
| 开关缺省关 | 是。`Bal.v("fx/material_grains", 0.0)`，balance.json 未加键。 |
| 预算 900 / 450 共用，低画质回退 | 是。材质与刀光第四版同一个池（`budget()` 只读 slash 档），延迟出生的颗粒也占预算；`material_burst` 整批先验预算，不够就整条退回原帧条（不会先藏本体再漏发）；低画质 `on()` 为假。 |
| 误改别的干员 | 没有专门改别人，但 `MATERIAL_FX` 按**帧条名**接管：`fx_water_splash`（敌方水柱预警 telegraph.gd）、`fx_corrode_hit`（漂移体命中 shot_pool.gd）、`fx_flam_hit`（艾雅普攻）也会被材质化。开关开时敌方这两条效果一起变，验收时要一起看（`hit_1.gif` / `hit_2.gif`）。 |
| `.gd.uid` | 漏了：`render/fx_grains.gd.uid`（main 的刀光第四版就漏了）、`tests/material_movie.gd.uid`。已补（16cee4c8）。main 另有 7 个测试脚本缺 uid，不属本项，记在 §6。 |
| 退出时 GL texture / ObjectDB 泄漏 | **不是它引入的**。同一局开窗口：main 68538a38、本分支开关关、开关开，三者退出日志一字不差（15 个 GLES3 Texture RID、36 个资源仍在用、VariantPools 页），是 main 原有的。 |

修掉的问题（16cee4c8）：
1. **快检报错**：`MagmaProjectile.material_on` 直接读 `o.g.optical`，`eyja_volcanic_weight` 测试的假 g 是 Dictionary → SCRIPT ERROR。改成 `o.g.get("optical")` 并统一走 `fx_grains.material_on()`。
2. **16×16 点阵**：`material_burst` 在固定 16×16 格点采样且不抖动，颗粒出生时排成整齐的点阵（Codex 自己的录像 `material_grains_movie` 第 0–1 帧可见）。改为格内用 `g.vrng` 抖开半格。
3. **契约脚本跑不了**：`material_grains_contract.py` 只要机器上有任何 Godot 就退出（Codex 交付前检查卡死的原因）；改由 `godot_runner` 自己排队。契约 `MATERIAL_CONTRACT_PASS`。
4. 加 `--matab=N` 同局轮换（`grains.mat_off`，PERF 分 /m1 /m0），只关材质、刀光第四版照旧。

## 3. 观感（同帧左原版 / 右材质，1/3 速 gif）

本分支重录（`tests/material_movie.gd` 固定演示，960×540，20 帧/秒采、150 毫秒/帧放 = 1/3 速）。gif 在粒子化会话 scratchpad（不进 git），要看时由该会话发出。

- 火（`fx_flam_hit`）：保留缩到 0.78 的火核 + 上升余烬，最后冷成灰；去点阵后读起来像「火炸开再散成火星」。可以。
- 水（`fx_water_splash`）：核心缩到 0.72、半透明，外围碎成水珠下落。可以，但这是敌方水柱预警的落点效果，要和歌蕾蒂娅的水分开看。
- 体液（`fx_corrode_hit`）：帧条整条换成颗粒 + 一盏短光，本体不画。偏弱，敌方命中本来就小，问题不大。
- 艾雅火球 / 熔岩 / 点燃：用户已给阶段性方向认可；画面里本体偏小，需在实战缩放下再看一次。
- **拉普兰德**：前 0.16 秒和原版一模一样，交接后碎片约 0.15 秒就落到暗青色、和地面同色（Codex 已知问题「后半段偏暗」），用户要的「明显差异」不成立 → 返工单 `codex_order_material_grains_r2.md`。

## 4. 帧时
