# 75 游戏内文案「AI 味」排查（只审计，不改文件）

2026-10-12，用户：「游戏内部的文案是否还有显得非常 AI 的文案，包括藏品和说明介绍，排查一下」。
背景：商店页文案「灯火：灯越亮，干员越稳；灯转暗，敌方更活跃……」「从众多干员池中选择您的心爱干员！」被否；凯尔希说「你会在实战里学会」被指 OOC。

**本轮不改任何游戏文件。** 下面的行号以 origin/main（732134ca）为准。

## 0. 方法

- 用脚本把 `game/` 下全部 `.gd` / `.json` 里含汉字的字符串抽出来（共 4614 行，去掉 tests / tools / addons 和 `#` 注释），再按下面的模式做关键词扫描，最后人工逐条读：lore.json 全文、50 条图鉴介绍、18 名干员的普攻 / 技能 / 天赋 / 成长 / 图鉴描述、262 件藏品实际显示的效果文字（relic_effects.json 的 `desc`，没写 desc 时用 relics.json 的 `adapt`）、waves.json 的结局与祭坛事件、开局指南、操作说明、难度、商人、横幅、图鉴、设置、致谢。
- 只读玩家能看到的字符串。`_doc`、报错信息、`balance.json` 说明、motion_shot 这类开发用文字不算。
- 干员语音是剪辑的原作录音（voice_manifest.json），没有台词文本，所以「OOC 台词」只出现在图鉴档案的引言和正文里。
- 商店页文案在 `art/promo/xhs/post.md`，不在游戏内，不在本轮范围。

## 1. 总结

**总的结论**：藏品效果、技能说明、操作说明、设置这几块基本是平实的数值写法，没有营销腔；全文没有「您」，也没有「心爱 / 尽情 / 全新体验 / 随您搭配」这类词。AI 味集中在**叙事文字**：第三批 5 名干员的档案（自己编的引言和总结腔正文）、四个结局的收尾句、开局指南第一页、难度副标题、开场标语。另一个问题是**同一机制叫法不统一**（灯火档位、照亮范围、眩晕 / 晕眩、熔岩弹 / 火山弹等）。

## 3. 文案风格规范（以后写新文案照这个来）

### 3.1 各类文字的语气

| 文字类型 | 语气 | 要点 |
|---|---|---|
| 藏品 / 技能 / 天赋 / 成长节点效果 | 平实、精确 | 「对象 + 数值 + 条件 + 例外」，例如「主控生命低于 50% 时，全队攻击速度 +50%（Boss 除外）」。不写形容词，不写「越…越…」，写阈值。随时间缩放的写出起止值。指代干员一律用「该干员」，不用「她」 |
| 图鉴「本作定位」描述 | 短、说清楚玩法 | 一句话说清楚这个干员怎么打、靠什么，数字可以省，但不要对仗句和口号。现有的「持续治疗主控，Mon3tr 在身边撕碎靠近的敌人」就是好例子 |
| 干员档案（lore.json） | 罗德岛档案的口吻 | 首句只用原作招聘语（handbook_info_table），不能编，没查到就不写引言；正文只写档案里有的事实，第三人称、陈述句；不写本作机制、数值、「本作中」；不替角色编台词，也不写「她说过……」 |
| 敌人 / Boss 档案 | 场景内的观察记录 | 写它是什么、长什么样、做什么，用具体画面结尾，不加感悟句。机制放图鉴的机制说明（gallery.gd 的说明行） |
| 结局 / 祭坛事件 | 叙事，克制 | 写发生了什么（谁、在哪、做了什么），一两句就够。不用「代价是……」「有些……才……」这类收尾感悟，不把结局名再念一遍，不替 Boss 写心理 |
| 商人台词 | 角色口语 | 现有 4 句（shop_screen.gd:19）口吻合适，可以作为参照：短、有角色感、不说教 |
| 界面 / 横幅 / 提示 | 短、动作导向 | 用「你」，不用「您」。先说发生了什么，再说该做什么：「商人出现了 —— 去找他交易源石锭」。横幅里的「——」只用作「事件 —— 指示」这一种分隔，叙事文字里尽量少用破折号 |
| 难度 / 模式副标题 | 说清楚区别 | 写这一档比上一档多了什么，不写氛围标语 |

### 3.2 写完自查（看到就改）

- 对仗 / 排比：「X 越…，Y 越…」「A 时是…，B 时是…」「永远…永远…」「更快更凶更多」
- 铺垫：「不是…而是…」「不仅…更…」「让你…」「你的抉择，会……」
- 段尾感悟：「有些……才……」「代价是，……」「……的一部分」「……的邀请」
- 空洞词：极强、顶尖、中流砥柱、全方位、强大的、少量、较高、更强
- 宣传词：您、心爱、尽情、全新、旅程、体验、随心搭配
- 元叙述：「本作中」「在游戏里」
- 编造台词：「」里的话不是原作原文，或者「她说过……」
