# 136 像素粒子模板（特效粒子化规范，样板：刀光第四版）

2026-10-24 协调人单 / 用户「先做能稳做的，考虑到网页端性能」。第三版只多了光晕和零星光点，本体仍是实心月牙；第四版把月牙本体改成像素颗粒。本页是之后火 / 水 / 电 / 海嗣体液等特效「粒子化」的统一做法。

## 1. 模板积木（`game/scripts/render/fx_grains.gd`）

一个模板 = `TEMPLATES` 里的一条参数表；调用方每帧把发射点推进来（`push(模板, 位置, 初速方向, 颜色)`），颗粒立刻生成，由本节点逐帧积分并在一次 `_draw` 里批绘。

| 参数 | 含义 | 刀光（slash）取值 |
|---|---|---|
| `ramp` | 颜色阶：[年龄比例阈值, 颜色] 列表，按年龄落在哪一段就整段用那个色（硬边，不插值）；颜色乘在调用方给的本色上，分量 > 1 的部分往白里提 = 发光 | 热白 2.0 → 亮 1.35 → 本色 0.9 → 冷暗 0.45（α 0.9） |
| `life` / `life_rand` | 寿命（秒）/ 寿命散布（按比例随机缩短，造成「逐颗熄灭」） | 0.30 / 0.45 |
| `speed` | 初速区间（世界像素 / 秒） | 10–46 |
| `spread` | 在调用方给的方向上随机散开的角度（度） | 26 |
| `grav` | 重力（向下，世界像素 / 秒²） | 80 |
| `drag` | 阻力（每秒衰减比例；小 = 惯性大、飘得远） | 5 |
| `per_frame` | 单帧新增上限（超出由调用方均匀抽稀） | 140 |
| `budget` | 同屏颗粒上限：[高, 中]；低画质不开 | 900 / 450 |

- **颗粒尺寸**：一律 2×2 世界像素（= 640×360 世界格上的 1 格），位置吸附到 2 px 格；不缩放、不旋转。
- **随机**：只用 `g.vrng`（画面随机流），不碰玩法随机数，同 seed TRACE 不变。
- **超预算**：同屏到上限后新颗粒直接丢（不挤掉旧的），所以大混战时自动变稀而不是掉帧。
- **低画质 / 关光学观感**：`on()` 为假，调用方退回非粒子画法（刀光退回第二版实心月牙）。

另带 **CPU 火星** `spark(位置, 地面 y, 颜色, 颗数)`：带重力迸出，落到「地面高度」停住（俯视游戏没有真碰撞，地面 = 物体脚底 y），冷却三阶（热白 → 本色 → 暗，落地直接进暗阶）后熄灭；同屏上限 中 120 / 高 240。

## 2. 为什么是 CPU 颗粒，不用 GPUParticles2D

- 实测：GPUParticles2D 挂在世界节点下时，在光学观感的**低分辨率层**（与主视口共享 World2D 的 SubViewport）里**不画**；关掉低分辨率层（`render/optical_lowres=0`）才看得见。光学观感已在网页和桌面缺省开，所以 GPU 发射器在本作的世界层不可用。
  - 已有的击杀碎屑（`optical_particles` 的 debris 池，也挂在世界节点下）很可能有同样问题，待查。
  - 发光层的颗粒（孢子、余烬、拖尾）挂在 glow 层，不受影响。
- CPU 颗粒 + 一次 `_draw` 批绘：draw_rect 不带贴图，Godot 会合成一批；网页 / 桌面行为一致，不依赖 WebGL2 的 transform feedback。
- 代价：GDScript 逐颗积分。预算 900 颗时，见 §4 帧时。

## 3. 刀光第四版怎么用这个模板（`render/world.gd` `_marc_grains`）

- 每帧把前沿**新扫过**的角度段（上帧前沿 → 本帧前沿）按月牙剖面（外沿到内沿，每 2 世界像素一格）取样成发射点，初速方向 = 挥刀切线（惯性），颜色 = 干员本色 × 命中档亮度。整体仍读得出月牙形状，范围仍是判定半径 × 0.7、最多 105°。
- 前沿另画一道 2 px 热白细线（刀口），尾部不画实体，由颗粒冷却熄灭。
- 命中火星：`vfx._tier_fx` 在粒子开着时改调 `spark`（颗数 3 / 6 / 12 按命中档，干员本色）。
- 挥刀瞬间照明：`optical._dyn_lights` 把刀光寿命前段（约 0.08–0.12 秒）当作一盏光，在 12 灯预算内排序。
- 开关：`fx/grains`（缺省 1）；同局轮换量帧 `--grainab=N`（分 /g1、/g0 两桶）。

## 5. 推广到其他特效（之后）

- 火：`ramp` 热白 → 橙 → 暗红 → 烟灰，`grav` 取负（上升），`drag` 大；发射点取火焰帧条的亮像素。
- 水：本色青蓝，`grav` 正、`drag` 小，`spread` 大；溅起的颗粒用 `spark`（落到地面停住）。
- 电：`life` 很短（0.08–0.12）、`speed` 0、沿电弧折线逐段发射。
- 海嗣体液：青蓝发光（敌方本体色），`grav` 正，落地用 `spark` 冷却变暗。
- 每加一个模板只改 `TEMPLATES` 一条和调用点，不新建节点、不新增绘制路径；预算按模板分配，加起来不超过画质档的总上限。
- 冰（10-27 骑士特效打磨，`MATERIALS.ice` / `frost_mist`）：参照常见冰系特效分层——白闪 → 有棱角的主碎片 → 低处冷雾 → 地面霜 / 冰面 → 零星碎屑落地。碎片少而大：按速度方向画 2 格 + 下方 1 格暗面，头 10% 寿命全白，`grav` 220、`push(..., ground)` 落地弹一次后停住、淡出（不留暗点）；冷雾 4×4 低 α 慢慢上飘。单一种细小均匀的点会读成「闪粉 / 水晶」，不像冰。地面冰面不用颗粒：按到达时间显露的固定图案（boss_attack_draw._dash_frost），不每帧重抽。`push` 新增可选 `ground`（落地高度，缺省 INF = 原行为）。

## 6. 子弹出现 / 消失（10-27 用户「子弹的出现和消失都要有对应的动画或者粒子效果，开销自己想办法」，`render/bullet_fx.gd`）

公共层，挂在 `world.bulfx`。纯画面：只往弹字典里写下划线字段（`_bid` / `_bt` 由本层写，`_die` 由结算处写原因），同 seed TRACE 逐行相同。

**怎么认出生成 / 消失**：不在各个生产点加调用，而是 `world.draw_world` 开头 `bulfx.frame()` 对弹表做「上一帧 / 这一帧」比对（按 `_bid` + `is_same` 认同一颗）。敌弹 `g.ebullets`、我方 `g.bullets` 每帧自动观察；干员自管的弹表在画弹处调 `bulfx.observe("渠道名", 表, 位置字段, 是否敌弹, 突然消失是否自带命中画面, 本色)`（能天使已接）。

| 路径 | 原因 | 画面 |
|---|---|---|
| 新出现 | 各生产点（enemy_ai / boss_patterns / telegraph / Boss 脚本 / 干员） | 0.09 秒 0.3 → 1.15 → 1 倍缩放（绘制处乘 `bulfx.k(b)`，判定半径不变）+ 亮芯闪 + 本色晕；同帧 40 px 格内成批出现 = 一个出膛环 + 至多 8 颗沿弹道颗粒，单发 = 2 颗 |
| 命中队长 / 撞景物 / 被骑士挡下 / 未标原因的突然消失 | `_die` = hit / rock / block，或 life 恰为 0 | 白芯一闪 + 本色细环外扩 + 爆散颗粒（Boss 弹 6、大弹 8、普通 4、景物 3） |
| 寿命到期 | life < 0 | 缩小淡出 0.12 秒 + 2 颗冷却颗粒 |
| 干员消弹 `shots.cancel_in` / 清屏（胜利清弹等，仍有寿命却被移出弹表） | `_die` = cancel，或 life > 0 | 统一溶解：缩小褪成冷白 + 向上飘的颗粒；同帧 > 6 颗时按离队长距离依次扫过（`render/bullet_fx_sweep` 1600 px/秒，最多延 0.25 秒），颗粒只给最近的 40（中档 24）颗，远的只做缩放淡出 |
| 读条光圈吞弹 | `_die` = eaten | 不叠（已有 eat_fx） |
| 出界 | 没有这条路径（弹只按寿命走）；屏外的消失不出画面 | — |
| 专属命中帧条（`hit_fx`）/ 酸团溅开 / 我方弹命中（爆炸、命中帧条） | — | 不叠，用各自已有的 |

**Boss 覆盖钩子**：`g.world.bulfx.set_hook(src_type, func(b, reason, pos) -> bool)`、`set_spawn_hook(src_type, func(b, pos) -> bool)`，返回 true = 这只 Boss 自己画了，公共层不画（例如偏执泡影的泡泡碎裂）。

**开销**：颗粒走本页模板 `bul_spawn` / `bul_pop` / `bul_cool` / `bul_dis`，共用 slash 总预算；另有本层令牌桶 `render/bullet_fx_rate`（700 颗 / 秒）、`render/bullet_fx_burst`（160），手机网页再乘 `grains.adapt_k`；颗粒层用到上限 85% 时不再要。要不到 = 只剩缩放 / 残影（world 的无贴图合批，1 次提交）。低画质、关光学观感、`fx/bullet_grains` = 0 只做缩放淡出；`render/bullet_fx` = 0 整层关。同局轮换量帧 `--bulfxab=N`（/b1 /b0）。帧时见 docs/50 §41。
