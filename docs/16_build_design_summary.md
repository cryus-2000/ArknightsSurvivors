## 0. 一局的骨架

- 10 分钟一局，固定节奏：3:30 / 7:00 中期 Boss（从 5 组里各抽一个不重复），10:00 最终 Boss「偏执泡影」。
- 商人 1:40 / 5:30 / 8:40 出现，停留 60 秒，交易一次即离开，每次只能刷新一次。
- 黑潮缩圈 2:30 起，之后每 90 秒预告 20 秒 → 收缩 25 秒。圈外掉血 + 熄灯。
- 精英按威胁等级间隔出现（45 → 32 秒），击败掉藏品箱；补给箱每 35–50 秒（15% 是箱形恐鱼）；大群按威胁等级 120 → 80 秒一次。
- 溟痕随时间增多变大，站上去掉血 + 减速。

## 1. 角色本体：水月

### 1.1 基础攻击「伞击」
- 自动攻击最近敌人：扇形 150°、半径 95、基础伤害 18、间隔 0.9 秒。**近战 · 物理**。
- 每次挥伞后，天赋一触发触手追击。

### 1.2 天赋
| 天赋 | 何时 | 效果 |
|---|---|---|
| 创伤性癔症（天赋一） | 开局 | 每次伞击后，命中目标中**生命最低**的 1 名被触手追击（60% 伞击伤害，**近战 · 法术**）。囚徒困境 +1 目标，镜花水月 +1/+2，藏品可再加 |

### 1.3 三个自动技能（按等级解锁，不占升级三选一）

| 技能 | 解锁 | 基础 | 进阶 Ⅰ | 进阶 Ⅱ |

## 2. 支援系统

### 2.1 唯一武器：支援无人机（升级卡，概率出现）
Lv.1 子弹（8，远程物理）→ Lv.2 激光（每 0.1s 3.4，贯穿直线，**远程法术**）→ Lv.3 追踪导弹（26，爆炸）→ Lv.4 第二架 → Lv.5 导弹 +1、频率 +25%。
设计意图：与两条路线正交的补短板手段（潮刃缺法术就靠激光，群触缺物理就靠子弹 / 导弹）。

## 5. 伤害类型与弱点（构筑分岔的底层）

- 每个伤害来源：**近战 / 远程 × 物理 / 法术 / 真实**。伞击 = 近战物理；触手 / 桩 / 阵 / 巨触 / 唤醒冲击 = 近战法术；水刃 = 远程物理；潮汐弹 / 激光 / 术师 / 辅助 = 远程法术；处决、扣挠之手 = 真实。
- 玩家防御：护甲只减物理、法抗只减法术、真实无视；闪避分物理 / 法术加成。
- 敌人**没有防御**（爽游原则），只有**弱点**：对应类型 +50%（金字提示），打错不吃亏。法术弱点：撕裂者、巨骸、囊海爬行者、塑路者、蔑死体、架起的凿石者；物理弱点：裂魔、喷吐者、掠海漂移体、育母、主教、斥亡体、泡影二阶段。
- 于是：潮刃路线（物理）对 Ⅴ 级的撕裂者 / 巨骸吃力，群触路线（法术）对裂魔 / 喷吐者和终 Boss 吃力，靠无人机、援护、藏品补短板。

## 8. 自测数据（bot 会躲预警 / 溟痕 / 弹幕，但不会拉扯）

- 不死模式 10 分钟造成伤害占比（潮刃路线）：伞击 ≈ 水刃 > 援护 ≈ 无人机 > 技能；群触路线：伞击 ≈ 触手 ≈ 巨触 > 触手桩 > 技能 > 援护。
- 正常模式 bot 通常死在 2:30–4:30（远程弹幕 + 撕裂者猛扑），真人应远好于此，但说明前中期远程压力不小。

## 9. 我认为值得讨论的问题

1. **两条路线的"手感"差异大于"决策"差异**。潮刃 = 直线远斩，群触 = 原地留桩；但两者的成长卡结构几乎对称（+数量 / +范围 / +伤害 / +特殊）。要不要让一条路线走"少而重"（巨刃、巨触）、另一条走"多而快"，而不是各自都有 E2-A / E2-B 的对称？
2. **S1 / S2 / S3 与路线的联动太弱**。技能改的是伞击本身，路线改的是伞击的"副产物"，两者只通过"每次挥伞"这个触发点相连。比如囚徒困境的攻速翻倍对群触是双倍触手桩，对潮刃是双倍水刃——是自然的，但没有任何"潮刃 + S3 = 三向水刃"这种专属联动。
3. **通用卡 12 种、路线卡 5–6 种、技能进阶 6 张、藏品 78 件**：藏品已经是数量最多的一层，但真正改变规则的（国王套装、郁金香、复活、四选一、极速之手独行流）只有十来件，其余是数值。原作的"跨技能联动"（唤醒 × 束缚 × 倒影）一件都没做。
4. **无人机作为唯一武器**是否合理：它现在是"补伤害类型短板"的工具，但它出现在升级池里抢通用卡的位置，且 Lv.1–5 是线性增强，没有分支。
5. **援护干员**被压到 6–12% 伤害占比之后，除了医疗，另外三个的存在感是否够？招募是固定 Lv.5 / 10 / 15，没有选择成本。
6. **灯火**现在是"少挨打就能保住"的资源，但"低灯火流"（逆光之瞳、火油与药膏、无字珊瑚）只有藏品在推，升级卡里没有任何一张鼓励低灯火。要不要把它做成真正的第三条路（高风险高收益）？
7. **弱点制**已经替代了敌人防御，但目前弱点分布是"按怪种固定"，玩家没有手段改变它（除了升华的迷迭香之拥）。要不要把"赋予弱点"做成技能进阶或路线效果（比如触手束缚的敌人获得物理弱点 → 群触路线自己补物理）？
8. **难度**已经改成规则型，但 0–10 逐级叠加意味着高难度玩家同时承受全部规则；原作是可选择的负面组合。要不要改成"选 3 条规则"式？
9. **后期（Ⅴ–Ⅵ）**靠进化体比例、敌速、大群频率撑压力，本质仍是数量和速度。有没有更"质变"的后期事件（例如 8:40 之后黑潮永久收缩、Boss 招式二段化、精英带词缀）？
10. **升华藏品**（第二 Boss 专属奖励）、**遭诅古物的收益面**、**Boss 三选一奖励**、**排异反应**都还没做，这些在原作里是构筑深度的主要来源。
