## 1. 为什么要这一条

用户 10-11 看了 `build/skalter_fx/` 的截图后说「饱和度太高了」，并给了原作 S3 的截图作参考（只在本机 `build/ref/`，不进仓库、不要嵌进素材）。
对照结论：我们的 S3 是一小圈高饱和、硬边的蓝 / 红环紧贴人物；原作是**大片、柔和、半透明的青色水流漩涡铺在地面上**。

参考画面的文字描述（代替截图）：

- 漩涡铺在地面上，透视压扁成椭圆，直径大约是干员身高的 5–6 倍，覆盖她周围好几格地板，而不是缠在身上；
- 由许多**细的弧形水流线**构成，按同一方向螺旋着绕中心转，外圈稀疏、内圈更密更亮，线条两端渐隐；
- 主色是低饱和的青 / 水蓝，像透过浅水看到的反光；**少量暗红 / 绯红的细流线**夹在里面做点缀（数量约青色的十分之一，更淡）；
- 零星的小光点 / 水滴散在漩涡里，有的在缓慢上飘；
- 整体半透明，地板纹理、敌人、其他干员都清楚可见；干员本人在中心，只带一层柔和的光，不被特效盖住。

## 2. 要交的素材

### 2.1 `fx_skalter_vortex_floor`（必做）

| 项 | 规格 |
|---|---|
| 帧尺寸（1x） | **≥ 320 × 160**（建议 320 × 176：椭圆 320 × 160 + 上下各留 8 px 给飘起的水滴）；宽高比约 2 : 1，对应游戏的地面透视 y × 0.55 |
| 帧数 / fps | **8–12 帧循环，10–12 fps**；首尾无缝（最后一帧接第一帧不跳），整体看起来是在缓慢旋转 + 向内卷 |
| 排列 | 横排一条：1x 宽 = 帧宽 × 帧数；@2x 每帧 2 倍，最近邻放大 |
| 原点 | **椭圆中心**（1x 例：320 × 176 帧 → (160, 88)）；manifest 写明 1x / @2x 的原点像素 |
| 线条 | 水流线 **1 px 宽**（1x），弧形、螺旋；外圈稀疏、内圈密；线端用抖动（dither）渐隐，不要突然截断 |
| 柔和感 | 二值透明（每个像素要么不透明、要么全透明，项目统一规则）——**柔和靠抖动的疏密表现**，不要半透明像素；游戏里整体按透明度约 **0.5** 画，所以素材本身可以画得比最终效果亮、实 |
| 颜色 | 青色为主（参考：亮 `#bff4ff`、中 `#6fd6ee`、暗 `#2f7f9e`，4–6 级），暗红点缀（`#c2405a` / `#7a2238` 两级）只占 ≤ 10% 的线；24 色以内色板 |
| 中心 | 中心约 1/4 半径内留空或只有很稀的光点——人物站在这里，不要在人物身上叠实色 |
| 不要 | 不画人物、不画音符、不画硬边整圈外环（区域边界游戏里另有程序线）；不画投影 |

接入方式（Claude 侧，供 Codex 了解尺寸怎么用）：画在**地面层、单位下面**（与歌域椭圆同层，docs/61 §5.6 `layer: floor`）；
按歌域半径等比缩放：每个 1x 像素 = `区域外半径 / 160` 世界像素（S3 外半径约 240–330 世界像素 → 每 1x 像素约 1.5–2 世界像素，与人物的 2 px 美术像素同量级，所以 1 px 线不会变成粗方块）；
modulate 透明度约 0.5、略压蓝；S3 生效期间循环，开关 0.4–0.5 秒淡入淡出。

### 2.2 `fx_skalter_motes`（可选）

小光点 / 水滴：**4–6 帧、8 fps、每帧 16 × 16**（原点 (8, 12)），一颗 1–2 px 的亮点闪烁 + 一点上飘拖尾；青白色为主，可另做一帧暗红变体。
游戏里在漩涡范围内随机散 20–40 颗、循环播放；没有这条时用程序光点。
