# 94 · Codex 美术单：普通怪物与精英怪物重画（2026-10-14）

> 用户 10-14：「想让 codex 那里重新画一下普通怪物和精英怪物，给他对应的规格」。
> 背景：10-13 为了帧率，**普通怪与精英怪已经不再由程序画轮廓光**（docs/50 §12，只有 Boss 保留）。后期地面很暗，小怪靠帧条本身就要一眼看清。这次重画的首要目标是**暗处可读**，其次是和干员同一套像素规范、补齐动作。
> 范围：下表 17 种普通 / 精英怪。**不含** Boss、最后的骑士（ending 2 已在 Codex V13 重做）、事件 / 宝箱类贴图。Codex 只交素材，不改 `game/`。

## 0. 通用规格

沿用 docs/87 §1 中敌人适用的条款，以及下面的补充：

| 项 | 要求 |
|---|---|
| 朝向 | **只画朝右**（朝左由程序镜像），所有动作同向 |
| 透明 | alpha 只有 0 / 255，不画阴影、不画半透明、不画辉光（影子与受击白闪由程序画） |
| 描边 | 1px `#080E18` 外描边（@2x 2px）。**游戏里不再额外加轮廓光**，所以描边必须完整闭合 |
| **暗处可读（重点）** | 后期地面接近 `#0a1020`～`#1b1f45`。每只怪的**顶部 / 背光一侧加 1px 本体色的亮边**（比本体主色亮 2–3 阶，@2x 2px），让剪影从暗底里跳出来；主体明度不要整体压黑（近黑像素 ≤ 25%）；眼点 / 发光器官保持高亮，作为远处识别点 |
| 敌我区分 | 敌方配色：深海青灰、骨白、腐蚀紫、暗红眼点为主。**不用友方专属色**：灯火金 `#F4C04E`、UI 青 `#36E2DC` 的高饱和版本（docs/48 撞色规则） |
| **精英标识** | 程序不再给精英画橙色轮廓，所以精英要在画面上自带标识：统一用**暖橙色发光器官 / 纹路**（`#ff9a3c` 一类，2–6 个像素点，@2x 相应），并且剪影比同体型普通怪更有压迫感（更多棘刺 / 甲壳层次）。同一套标识四只精英通用，玩家一眼认出「这是精英」 |
| 色数 | 每种怪全部动作合计 ≤ 16 色（1x、@2x 各算） |
| 1x 与 @2x | **两套都要交**（现在多数只有 1x）。以 @2x 为主绘制，1x 由 @2x 对应缩出并修像素；逐帧对应、剪影一致 |
| 尺寸 / 帧数 / 锚点 | **与现有帧条完全一致**（见 §1 表；游戏按尺寸切帧、拼图集，改尺寸要先找 Claude）。脚底贴画布底边，水平居中 |
| 原作参照 | 造型取自《明日方舟》集成战略「水月与深蓝之树」对应海嗣（PRTS 敌人页可查名称与外形）。**按本作 Q 版像素风重新绘制**，不描摹、不使用官方图 |
| 命名 | `e_<id>.png` / `e_<id>@2x.png`，动作加后缀 `_move` / `_attack` / `_dormant` / `_awaken` / `_enraged`。前三种怪旧文件名是 `drifter / dart / crawler / shell`，**新图一律交 `e_bone` / `e_slider` / `e_stone` / `e_pocket`**（游戏优先读新名，旧图留着不删） |

### 动作约定

| 动作 | 帧数 | 游戏怎么播 | 要求 |
|---|---|---|---|
| 基础（无后缀） | 2 | 待机 / 漂移循环，约 2–4 fps | 两帧之间有起伏（1–2px）或器官开合，不要两帧一样 |
| `_move` | 4 | 移动循环，约 5 fps | 有明显的行进节奏（爬行、摆尾、漂浮起伏），首尾可循环 |
| `_attack` | 4 | 按出招进度播：f0–f1 前摇 → **f2 = 命中帧**（游戏在出手瞬间停在 f2）→ f3 收势 | f2 要有最大的张开 / 前伸；f3 接近基础 f0 |
| `_dormant` / `_awaken` / `_enraged` | 见表 | 特殊状态 | 见各怪说明 |

## 2. 交付与自检

- 只动 `art/incoming/`；**按批交付，每批一个提交**（第 1 批先交）。
- 每批附：
  - `enemy_redraw_<批号>_manifest.json`：每条帧条的帧数、每帧尺寸、色数、命中帧、1x / @2x 对应；
  - `enemy_redraw_<批号>_handoff.md`：逐只说明造型依据（原作名称 + PRTS 出处）与暗处可读的处理；
  - 预览：
    - `enemy_redraw_<批号>_preview.gif`：深色地面 `#0e1428` 底，按游戏比例（1 美术像素 = 2 屏幕像素）逐只播放基础 → move → attack；
    - `enemy_redraw_<批号>_lineup.png`：本批怪与两名干员（例如 `op_skadi_idle@2x`、`op_texas_idle@2x`）并排，比例同游戏，分「灯火亮」（原色）与「暗」（整体乘 0.55）两行，用来检查暗处是否还看得清。
- 自检：尺寸 / 帧数与 §1 表完全一致；alpha 只有 0 / 255；外描边闭合；无洋红残留；1x 与 @2x 逐帧对应；精英四只都带暖橙标识。
- 交回时告诉 Claude 提交号。Claude 接入时会核对图集容量、跑同帧截图对比，并在图鉴「敌人 / 精英」页演示。

## 补单（10-14）：精英暖橙标识在实战缩放下太小

验收（协调人本机，截图 scratchpad/enemy_redraw/late_zoom_7200_elite.png、late_zoom_8200_elite.png）：重画后的 17 种怪整体通过（尺寸 / 帧数 / 透明 / 描边 / 配色都对，图集 51 条全进）。但**照亮圈外 / 黑潮里的精英**本体几乎看不见，暖橙点在实战缩放下只剩 1–2 个屏幕像素，现在全靠程序画的头顶橙色 ▼ 和血条辨认。

请只改四只精英（pocket、skimmer、mother、mimic）的全部帧条（+ @2x），**尺寸、帧数、脚底锚点不变**：
- 暖橙发光器官 / 纹路放大：@2x 每帧至少 40–80 个暖橙像素，集中成 2–3 处明显的块（眼 / 核 / 背脊），不要散成单点；
- 背光一侧的亮边改为暖橙（普通怪仍是本体色亮边），让精英在暗处的剪影带一圈暖色轮廓；
- 另外两处小问题顺手修：mother 的 move 帧条整体比基础帧偏右约 2 像素；skimmer 的 move 帧水平晃动约 3 像素（常态 ↔ 移动切换会跳）。
- 交一张 lineup：四只精英与两只普通怪并排，亮 / 暗（整体乘 0.55）两行。
