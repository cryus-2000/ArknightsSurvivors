- 没有四列对照图、眼部放大或设定色清单，或者出处写不清。
- 瞳色和立绘不同色相，或者任何一帧丢了瞳色（并进头发 / 服装色）。
- `hue` WARN 没有写理由，或者是整体变灰 / 变暗。
- 上表细节项缺失，或缩到 48 px 认不出。
- 未豁免 FAIL 不为 0；技能末帧 ≠ 待机 f0。
- 同一人四组动作不是一套画法（像水月 B 批攻击帧那样）。
