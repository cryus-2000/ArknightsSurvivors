### 四、docs/94 补单：怪物色板返修的验收

范围：**只改配色与明暗分布，尺寸 / 帧数 / 锚点 / 剪影不变**，1x + @2x 都交（docs/94「补单（10-14 晚）」）。量测口径同 docs/94 与 art_lint tone：描边（#080E18）外的不透明像素，@2x，该怪全部帧条合计，luma 按 Rec.709。工具 `python tools/enemy_tone.py`（`--base <上一版提交>` 同时比剪影与前后指标，`--art` 量 Codex 工作树），基线在 `build/enemy_tone/report.md`。

| 档 | 对象 | 收的标准 |
|---|---|---|
| 必修 | fractal 塑路者分形 | 最暗一阶 luma ≤ 35，近黑 10–25%；中灰段（luma 60–140）≤ 40%（现 98%）；luma 标准差 ≥ 35（现 12）；主色饱和 ≥ 0.35（现 0.20）；顶部亮边比主色亮 2–3 阶 |
| 全项 | tracer 深溟引痕者、founder 深溟奠基者、nest 深溟巢涌者、stone 固海凿石者、runner 壳海狂奔者 | 同上四项（最暗一阶 / 中灰段 / 主色饱和 / 亮边）。runner 主色饱和现 0.14，重点看它在骨海背景上能和漂流体分开 |
| 只加一个有色暗阶 | reaper / mimic / slider / floater | 新增暗阶 luma ≤ 35、HSL 饱和 ≥ 0.2（深海青灰或腐蚀紫），占描边外像素 ≥ 5%；整体饱和从 0.13–0.18 提到 ≥ 0.2；其余层次不动 |

每只都要核：

1. **剪影不变**：新旧帧条逐像素比 alpha，不透明像素集合完全相同（1x、@2x 各比一次）；帧数、尺寸、manifest 锚点不变。
2. **指标**：上表各项，`tools/enemy_tone.py --base <上一版>` 出表（判定列直接写未达标项），结果贴进验收记录。不改 art_lint 的干员检查。
3. **和祛雾叠加**：程序侧祛雾（`render/enemy_pop`，现缺省 0.08 / 1.28 / 0.25）对新色板会再拉一次。图鉴「敌人」页和局内各截一张，看新暗阶有没有被压成死黑、亮边有没有爆白；如果有，记下来交协调人定（给返修过的怪单独降祛雾，或整体调旋钮），不改美术。
4. **精英标识**：精英版的暖橙标识（docs/94「补单：精英暖橙标识」）不能被新色板吃掉，局内实战缩放下仍可见。
5. **move 帧对位**：mother / skimmer 的 move 质心问题在另一张补单里，本次如果一并交，质心偏移 ≤ 1 像素。
