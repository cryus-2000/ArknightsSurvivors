# 247 · 单 C：自动招募可婉拒 + 单人局胜率小样（11-05）

1. **已做**：人事部铜印、博士银印和立即招募类事件现在会先弹「接受入队 / 婉拒」二选一并暂停游戏。婉拒时，铜印和事件换一次成长三选一；银印换全队各推进 1 个成长节点，再加一次成长三选一。编队已满时沿用原来的处理，不弹窗。
2. **默认行为不变**：机器人在同一帧自动接受，随机数消耗不变。8 局同种子 TRACE 逐行一致，复核 4 局，结果相同；BALANCE 只有画面峰值 `bot.peak` 不同。
3. **单人局偏弱（趋势）**：normal 机器人 160 局，两组胜率都是 0%（贴地），单人组平均早倒 35 秒（2:45 / 3:20），平均等级低 2.3 级。高手机器人小样（5 名队长 × 种子 11 × 潮位 0，同种子）普通 3/5 胜，单人 0/5，平均存活 7:41 / 10:45。
4. **不下结论**：normal 两组都是 0%，胜率差是 0 点；高手小样只有 10 局，不够用。补偿开关「独行」`squad/solo_buff` 已经写好，缺省 0，A/B 还没跑（协调人 11-05 收窄范围）。
5. **需要用户定**：Lv.5 仍只有 1 人、Lv.9 不满 3 人时，升级面板是「强制招募」画面，玩家没有办法拒绝。真人单 C 目前躲不掉这一步，机器人 `--bot_solo=1` 是绕过它测的。要不要给这个画面也加一个「婉拒」，请用户决定。

**界面**：沿用升级三选一的卡片。接受卡是这名干员的招募卡，显示待机像素头像、名字，说明第一行写档位：铜印「以精英零加入 / 成长节点 1/N」，银印「以精英一加入」，事件「以精英零加入」，下面接干员简介。婉拒卡写替代的成长。标题是来源名，说明行是「选择是否加入编队 · 入队加成：……」。键盘按 1 / 2、方向键加回车（手柄由 Pad 转成同样的按键）、鼠标和触屏点卡都可以选。截图：`docs/assets/solo_carry/desktop_silver.png`、`desktop_copper_focus.png`（键盘焦点在婉拒上）、`phone_copper.png`。

**TRACE 怎么对齐的**：玩家局多一次暂停，但机器人和测试局（`--balance`、`--autotest`、演示、Boss 演练，`g.bot != null`）不弹面板，在触发的同一帧直接走接受分支。抽人的那次 `g.rng.randi()` 还在原来的位置，接受分支和改前一样（铜印推进 1 节点、银印推到精一、事件播入队光效）。所以随机数序列和局面都不变。

## 3. 单人局批跑

工具：`tools/solo_carry_batch.py`（`run` 断点续跑，`sum` 出表）。普通组 = 缺省策略；单人组 = `--bot_solo=1`，会婉拒邀请、不选招募卡、不进强制招募画面、避开挑人招募事件。160 局全部是纯单人，共婉拒 6 次。

- 两组都没有打到最终 Boss（0%）。normal 机器人在当前难度下普遍 2–4 分钟就倒，胜率贴地，用它比胜率没有意义。

## 4. 建议

- **方向**：单人局机制上偏弱，原因是生命和回复按入队人数上台阶，单人拿不到。高手小样差了 3 局胜利。但按「胜率差小于 10 个点、或样本不足不下结论」的口径，现在还不能定补偿量。
- **下一步（等额度）**：用高手机器人跑 20 名队长 × 2 种子 × 潮位 0 的三组：普通 / 单人 / 单人 + `--bal=squad/solo_buff=1`（共 120 局），命令如下：
  ```
  python tools/solo_carry_batch.py run --bot expert --seeds 11,23 --tides 0 --groups squad,solo,solo_buff --buff "--bal=squad/solo_buff=1" --out build/solo_carry/ab.jsonl
  ```
  目标是「能打」：单人胜率落在普通组的一半左右即可，不追平。不够再调 `solo_steps` = 2（相当于两名队友的生命和回复）。
- **强制招募画面**（结论第 5 条）：真人单 C 现在 Lv.5 / Lv.9 必须招人。给它加「婉拒」需要用户点头。
- 开关上线前还缺玩家可见的状态提示（例如状态栏「独行」）。A/B 有了结论再做。
