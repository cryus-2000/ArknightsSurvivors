# 12 · Boss 攻击与技能设计（v1.3）

> 开发方（Claude）实现文档，2026-09-24。对应 `game/scripts/game.gd` 的 `_boss_ai` / `_warn` 系列。
> 立绘与移动循环已接入（`e_<boss>.png` / `e_<boss>_move.png`）。本轮新增的是招式、预警与命中表现；攻击动作暂由程序对本体做姿态变形，**若后续交付 `e_<boss>_attack.png`（4 帧横向帧条，与本体同尺寸、同脚底）会自动改用帧条**。

## 1. 通用规则

- 每个 Boss 有 2–3 个招式，全部**先预警后结算**。预警由程序绘制：
  - `circle` 地面椭圆（压扁 0.72）；`line` 长条；`cone` 扇形。
  - 预警期间外框脉动、内部从中心逐渐填满，填满即结算；结算瞬间整块闪白 0.25 秒。
- 预警期间 Boss **停步蓄力**（`wind`），姿态：后仰、变亮闪烁；结算瞬间前倾拉伸。
- 招式伤害走 `_enemy_hit`，享受闪避、护盾、侵蚀等既有规则；`dmg_src = boss_<type>` 便于结算统计。
- 冷却用 `_cd(e, key, dur)`，各招式独立；开场 2 秒不放招（`e.age > 2`）。
- 圈内命中判定以水月胸口（`ppos + (0,-14)`）为准，容错 +10 像素。

## 3. 程序特效（`fx.kind`）

`wpillar` 潮汐柱、`quake` 震地 / 跳砸裂纹、`tracer` 狙击 / 裁决弹道、`bbeam` 凝视光束、`bslash` 横扫刀光；泡影爆裂复用 `explode`（紫）。

## 4. 测试

- `--autotest --bosstest=<type>[,<type>]`：在水月旁刷出指定 Boss（`paranoia2` = 二阶段），每 0.5 秒截图到 `/tmp/claude-0/shot_boss_<type>_<帧>.png`，10 秒后退出。
- `--balance --seed=N [--evoblade|--evotendril]` 输出的 `dmg` 里新增 `boss_<type>` 项。
