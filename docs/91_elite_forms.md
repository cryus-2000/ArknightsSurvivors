## 0. 总览

### 0.1 现状一句话

成长线统一是「节点 节点 **精一** 节点 节点 **精二**」（character.gd `advance`）。

- **精一**现在只做两件事：解锁二技能、解锁天赋。普攻**没有任何变化**，精英化节点也不给 +6% 攻击（只有普通节点给）。
- **精二**解锁三技能 + 一条「普攻质变」。18 人都有，但强弱差很多：有的已经是形态变化（推进之王「破阵」地裂、铃兰「九尾祈愿」、维什戴尔「死魂灵的余息」、塞雷娅「莱茵充能护服」），有的只是「多一发 / 多打一个」（能天使「子弹数 +1」、逻各斯「额外攻击打 2 名」、艾雅法拉「投 3 发」），还有的触发条件太窄、平时看不到（乌尔比安「击杀精英后下一次大爆破」、艾丽妮「只对受控敌人追加」）。

### 0.2 本文的做法

| 阶段 | 目标 | 预算（对本人 E2 木桩 / 怪群秒伤，docs/79 口径） |
|---|---|---|
| 精一 | 普攻**追加一个可感知的机制**（多一段、附带控制、弹道小变、命中标记），画面上有一个小的新元素 | 输出位 ≤ +8%；控制 / 治疗位以控制量、治疗量计，不额外加伤 |
| 精二 | 普攻**形态变化**，一眼能认出「她精二了」：新弹体 / 新轨迹 / 新的出手形状 / 召唤物行为变化。替换或升级现有「普攻质变」 | 相对现有精二 ±10% 以内；超出的部分按各节「配合下调」收回 |

精二质变的 18 个「动词」互不重复（§0.4），避免 18 个人都变成「多一发子弹」。

3. **画面一律先用程序画**（`world.tb_*` 圆 / 环 / 线 / 弧 / 多边形 + 现有 `fx_*` / `proj_*` 帧条）。docs/06：特效与弹体本来就归 Claude；人物 / 召唤物本体帧条归 Codex。只有浊心斯卡蒂的海嗣（伊莎玛拉形象）必须 Codex 出正式召唤物帧条（实现先用 Boss 帧条缩小占位），其余 Codex 项都是「有了替换程序版」；全套 Codex 单见 docs/93。
4. **Codex 单格式**按 docs/06 第 38 行 + docs/archive/66（文件名、帧数 / fps、帧尺寸、原点、`_back` / `_front` 分层与 `_orbit` 回退、何时播放）；人物类帧条另按 docs/87 §1（二值透明、`#080E18` 外描边、@2x 逐帧对应、只画朝右）。

## 1. 安洁莉娜 `angelina`（辅助 · 积木）

**现状**
- 普攻「重力弹」：1.1 秒一发，打射程 320 内最密处；落点 r75 法伤，r100 内拉拢 40。
- S1 速充模式（3 发强化）/ S2 微粒模式（永久重力场环带）/ S3 反重力模式（10 秒悬浮）。天赋「加速力场」：被拉过的敌人 2 秒失重。
- 精一：解锁 S2 + 天赋。精二：解锁 S3 + 「失重」：落点中心 r30 的敌人悬浮 0.6 秒（`blocks.attack.then` 里 `cond: elite >= 2` 的 `st.airborne`）。
- 问题：r30 悬浮 0.6 秒在怪堆里几乎看不出来。

**精一 · 重力停顿**
- 落点 r75 内的敌人停顿 0.25 秒（精英 0.12 秒，Boss 除外）。S1 的 0.6 秒停顿照旧覆盖。
- 依据：原作特性「攻击造成法术伤害，并对敌人造成短暂的停顿」；模组「重力校准模块」改为「较长的停顿」。
- 视觉：落点敌人身上一圈 2px 紫色细环，0.25 秒缩没（`tb_ring`）。

**精二 · 失重井**（取代「失重」）
- 重力弹落地后，落点留下一口**失重井** 1.2 秒（r60）：每 0.4 秒把 r90 内的敌人往井心拉 12，井心 r30 内的敌人悬浮（同 `st.airborne`，悬浮时间刷新到井消失为止）；井内**处于失重或悬浮**的敌人每 0.4 秒受到重力弹 15% 的法伤。同时最多 3 口井。
- 依据：原作「安洁莉娜特限证章」天赋：集成战略中，失衡、浮空的敌人每 0.5 秒受到 60% 攻击力的法伤；技能期间攻击使目标浮空 3 秒并刷新。原作 S3「全场所有敌人失重」。
- 视觉：落点一团离地 12px 的紫色球核（`proj_angelina_orb` 放大 1.4 倍、慢转），下面一圈地面椭圆引力环（`tb_ring` 两层反向转），井心敌人整体抬高 8px 并上下浮动（复用 `st.airborne` 的抬高绘制），井消失时向内收缩一闪。
- Codex（可选）：`fx_angelina_well_back` / `_front` / `_orbit`，96×64（1x），8 帧 10fps 循环，原点 = 椭圆中心；back 是地面引力环，front 是飘起的碎屑与球核光晕。没有时用上面的程序版。
- 强度：怪群里每口井约 3 跳 × 15% × 被拉进来的敌人；她攻击力低（atk 20），怪群秒伤预计 +25–35%，木桩 +0–45%（木桩被悬浮时吃满）。配合下调：S3 期间井的伤害减半（全场已失重，不减会翻倍）。控制量上升是主要收益。
- 实现（积木，中）：`shape.point_aoe.then` 追加 `verb.field {center: target, r: 60, dur: 1.2, every: 0.4, do: [...]}`（瞬时力场已有，docs/61 line 644）。新增：力场 `do` 里的伤害要能按状态筛选（`only: weightless|airborne`，新参数）；井数上限 3（`cap` 新参数）。

**玩家可见文字（草稿）**
- 精英一节点：「解锁二技能「秘杖·微粒模式」；解锁天赋「加速力场」：被拉过的敌人失重，更容易被击退，照亮范围内的敌人拉得更远；重力弹落点的敌人停顿 0.25 秒（精英 0.12 秒，Boss 除外）」

## 2. 能天使 `exusiai`（狙击 · 积木）

**现状**
- 普攻「速射」：0.35 秒一发，射程 300，穿透 2，子弹数可成长（节点「双枪」）。节点「跳弹」50% 弹射。
- S1 冲锋模式 / S2 扫射模式 / S3 过载模式（4 连射）。天赋「快速弹匣」：击杀攒弹匣，满了倾泻 8 发。
- 精二质变「天使的弹幕」：子弹数再 +1，弹匣上限 8 → 12。**正是「多一发子弹」**，画面上只是弹幕稍密。

**精一 · 穿甲连射**
- 连续命中同一名敌人时，每发伤害 +3%（最多 +30%，10 发叠满）；换目标或 1.5 秒没打中它就清零。只算普攻。
- 依据：原作模组「欢迎光临，企鹅物流」天赋「快速弹匣」：连续造成伤害时逐渐无视敌人防御力，最高 250 点，5 秒内未攻击则失去加成。本作没有防御力，改成增伤。
