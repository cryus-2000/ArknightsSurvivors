# 37 · 界面风格：方案 A「潮汐航线」

> 2026-09-26 用户在三套样例里选定 A（仿《水月与深蓝之树》局内界面），事件选择沿用 C 的版式，商人另做一版 A。
> 样例画布：https://claude.ai/artifact/HNMQLaWu1SBFcEg5myY2k2 （A1–A5）。做新界面前先看这里和 `scripts/ui.gd`。

## 1. 原则

- **像原作的局内界面**：炭灰半透明平面板、白色线性图标、数值上方的彩色小标签头（原作「目标生命值 / 指挥等级」）、
  「英文压缩斜体 + 中文」的节点标签条（原作地图上的 `COMBAT OPS. ✕ 虫群横行`）。
- **不画深海藤蔓、切角、像素角括**（旧 v1.2 风格已退役；`UI.frame` 的 `vines / cut / bracket` 参数仍接受但不再画）。
- **不用原作的标志与素材**：集成战略菱形标志、原作 Logo、截图一律不用；本作徽记是「菱形 + 一道浪」（title.gd `_draw_emblem`）。

### 6.2 格式

- 标点全角（，。：；「」（）），数字、英文、百分号半角；中文与数字 / 英文之间空一格（「攻击力 +20%」「持续 5 秒」），百分号前不空。
- 引号只用「」，嵌套用『』；不用 "" 或 “”。
- 负号 / 减少统一 ASCII「-」（-15%），不用 U+2212「−」。
- 等级写「Lv.5」。
- 按键：单键写「1」，范围写「1–4」（en dash），并列写「1 / 2 / 3」；按钮牌上的键名用大写英文（SPACE / ESC）。
- 一句只用一个全角冒号；多个效果并列用「；」，同一效果的几项参数用「，」。
- 数量：会随数值变化、与数据字段对应的数写阿拉伯数字（「多 1 只」「最多 3 名」「+2」）；固定的「一」作量词写汉字（「一名干员」「一颗」「一次」「一件藏品」）；剧情句可用汉字。
- 序数一律汉字：精英一 / 精英二、结局三、其二、第二次、威胁等级用罗马数字 Ⅰ–Ⅵ（界面已有，保留）。
- 语气：说明写客观效果，不写开发口吻（「打 Boss 用」）；剧情 / 台词可以有角色语气。

## 7. 特效与素材（2026-09-26 用户通用要求）

- 特效**优先用已购买 / 已下载的素材**（`art/third_party/`，目录见各包 `_catalog.json` 与 README），能直接用就不要程序绘制；
  素材本体不入库，魔改成帧条后放 `art/incoming/fx_*` 再提交。许可未确认的包（README 里注明）只能本地试做，不进发布包。
- 例外：**按数值精确画的几何指示**（技能落点圈、攻击范围、瞄准线、进度环等）仍用程序绘制——像素素材放大到任意半径会糊边、
  对不上真实判定范围。这类指示用 `UI.CYAN` 系细线 + 很淡的填充，不做粒子。

### 7.1 后期画面降噪（EA 1.1，2026-09-27）

8:00–10:00 大群 + Boss 同屏时的层级：**敌方危险（弹幕、Boss 预警）> 敌人 > 掉落 > 友方特效 > 地面**。实现在 `render/world.gd`（`crowd` / `fx_dim`）：

- **友方特效限流**：世界特效 + 干员粒子总数超过 80 起，按总数平滑降透明度，到 300 降到 0.45（`DIM_KINDS` 里的爆炸、刀光、帧条特效等；
  干员粒子走 `character.draw_pfx` 的同一系数）；加色发光层 `fx_add` 降到 0.6，全屏辉光减半（`post_fx.crowd`）。图鉴演示不降。
- **敌方弹幕**：深色外圈垫底 + 亮洋红描边，画在友方特效之上。
- **Boss 预警**：地面层填色不变，另在特效之上描一遍轮廓（深色 + 预警色两道）。
- **掉落物**：经验结晶加深色底；满地结晶（> 60）时离主控 170 以外的不画辉光和闪光、本体压暗到 0.7。
- **飘字**：0.25 秒内、28 像素内同色同字号的纯数字合并（数字相加、字号略放大），总数上限 48。
- **横幅**：同一局第二次起的同一句（反复放的技能名）改成窄暗带小字、1.5 秒。
