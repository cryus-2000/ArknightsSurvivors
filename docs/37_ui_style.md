# 37 · 界面风格：方案 A「潮汐航线」

> 2026-09-26 用户在三套样例里选定 A（仿《水月与深蓝之树》局内界面），事件选择沿用 C 的版式，商人另做一版 A。
> 样例画布：https://claude.ai/artifact/HNMQLaWu1SBFcEg5myY2k2 （A1–A5）。做新界面前先看这里和 `scripts/ui.gd`。

## 1. 原则

- **像原作的局内界面**：炭灰半透明平面板、白色线性图标、数值上方的彩色小标签头（原作「目标生命值 / 指挥等级」）、
  「英文压缩斜体 + 中文」的节点标签条（原作地图上的 `COMBAT OPS. ✕ 虫群横行`）。
- **不画深海藤蔓、切角、像素角括**（旧 v1.2 风格已退役；`UI.frame` 的 `vines / cut / bracket` 参数仍接受但不再画）。
- **不用原作的标志与素材**：集成战略菱形标志、原作 Logo、截图一律不用；本作徽记是「菱形 + 一道浪」（title.gd `_draw_emblem`）。

## 3. 组件（都在 `scripts/ui.gd`）

| 线性图标 | `icon` | enemy / clock / box / ingot / pause / refresh / exit |

## 4. 画面

- **战斗 HUD**：左上等级圆（外圈经验）+「生命值」「灯火」；顶部中央明日方舟战斗顶栏「击杀 | 时间」+ 楼层条；右上暂停按钮（鼠标可点）+ 收藏品栏；
  右下部署卡式编队（左上职业、右上精英阶段、上方三枚技能格、队长紫色标签）+ 源石锭费用框；左下声呐；底部中央冲刺按键牌。
- **选卡（升级 / 藏品 / 招募）**：背后战场用 `shaders/ui_band.gdshader` 去饱和压暗（顶栏底栏保持清楚），卡片 272×382。
- **作用对象标签**（2026-09-26 用户要求：选升级时知道影响哪个角色，按当前编队算）：卡片操作条上方一行「影响」+ 标签片，
  由 `scripts/run/affects.gd` 按效果数据和干员的伤害来源推算。干员色 = 点名的干员；青「全队」；「主控 · 名字」= 主控干员
  （唯一受击体：生命、减伤、闪避、回复、移速、拾取）；洋红加「↓」= 对它只有坏处（诅咒、代价）；暗洋红 = 条件没人满足
  （「编队无近卫」）；只和源石锭 / 灯火 / 商店有关的卡不画。近战 / 远程、物理 / 法术、追击、单体按 `hit_sources` 判断：
  常驻来源（core / talent）一直算，技能与分支来源（skill / route）本局打出过伤害才算；控制看整套技能有没有标 control / stun。
  招募卡改画灰色「特性」（这名干员的近战 / 远程、物理 / 法术、追击、控制），方便对照已有藏品。
- **技能图标**（2026-09-26 用户要求参考原作技能图标）：每名干员三枚 32×32（`art/incoming/skill_<id>_s1–3.png`，水月沿用
  `skill_s1–3`），`tools/make_skill_icons.py` 生成。按原作构图重画：方形底（输出用深灰渐变 + 朱红放射 / X / 五边形，治疗蓝、
  防御金、充能绿）+ 常见的 2px 白框 + 扁平白色主体，每个函数注明参考了原作哪个技能；不用原作图片。
  用在：HUD 技能格（图标铺满格子；充能中没充满的上半截压暗，充满时边框变干员色，生效中白框 + 倒计时）、Tab 面板技能行

- **商人**：左侧商人立绘框（暖色提灯光，台词 `MERCHANT_LINES`）+ 右侧货品卡（作用对象标签至多两行，不带「影响」小字）与价格条

- **事件（C 版式）**：整屏灰阶；左边撕纸边墨色插画（海嗣祭坛是唯一的彩色物件）+ 事件名（`fonts/serif.ttf`）+ 剧情一句

- `fonts/ui.ttf`：Noto Sans CJK SC Bold（原有）。
- `fonts/serif.ttf`：Noto Serif SC Black 子集（GB2312 一级字 + 数据里出现的字，约 3900 字，1.6 MB；OFL，授权写在字体文件里）。

### 6.1 术语

| 统一写法 | 不再用 | 说明 |
| --- | --- | --- |
| 眩晕 | 晕眩 | |
| Boss 免疫 | 首领无效、对首领无效 | 「Boss」保留英文，前后空一格 |
| 主控 | 你、玩家（指受击体时） | 唯一受击体。一段说明里第一次出现可写「主控干员」；只作用于主控的效果（生命、减伤、闪避、回复、移速、拾取）必须写明「主控」 |
| 全队伤害 | 所有伤害、伤害（指全队加成时） | 只影响某名干员 / 某类伤害时写明对象 |
| 攻击范围 | 射程 | |
| 治疗量 | 回复效果 | 「回复」只作动词：「回复 3% 生命」 |
| 受到的伤害 | 受到伤害、你受到的伤害 | 不用第二人称 |
| 敌人造成的伤害 | 敌人攻击 -X% | 实际改的是伤害就写伤害 |
| 藏品 | 收藏品 | |

| 【遭诅】藏品 | 遭诅古物、负面藏品 | |
| 精英一 / 精英二 | 精一、精英化一、精英化%s | 动词仍说「精英化」：「精英化后解锁」 |
| 补给箱 | 宝箱 | |
| 猎潮的骑士 | 猎潮骑士 | |
| 归溟幽灵鲨 | 幽灵鲨（指本作干员时） | 原作「幽灵鲨」是另一名干员 |

### 6.2 格式

- 标点全角（，。：；「」（）），数字、英文、百分号半角；中文与数字 / 英文之间空一格（「攻击力 +20%」「持续 5 秒」），百分号前不空。
- 引号只用「」，嵌套用『』；不用 "" 或 “”。
- 负号 / 减少统一 ASCII「-」（-15%），不用 U+2212「−」。
- 等级写「Lv.5」。
- 按键：单键写「1」，范围写「1–4」（en dash），并列写「1 / 2 / 3」；按钮牌上的键名用大写英文（SPACE / ESC）。
- 一句只用一个全角冒号；多个效果并列用「；」，同一效果的几项参数用「，」。
- 数量：数值字段用阿拉伯数字（「1 个」），剧情句可用汉字。
- 语气：说明写客观效果，不写开发口吻（「打 Boss 用」）；剧情 / 台词可以有角色语气。
