# 37 · 界面风格：方案 A「潮汐航线」

> 2026-09-26 用户在三套样例里选定 A（仿《水月与深蓝之树》局内界面），事件选择沿用 C 的版式，商人另做一版 A。
> 样例画布：https://claude.ai/artifact/HNMQLaWu1SBFcEg5myY2k2 （A1–A5）。做新界面前先看这里和 `scripts/ui.gd`。

## 1. 原则

- **像原作的局内界面**：炭灰半透明平面板、白色线性图标、数值上方的彩色小标签头（原作「目标生命值 / 指挥等级」）、
  「英文压缩斜体 + 中文」的节点标签条（原作地图上的 `COMBAT OPS. ✕ 虫群横行`）。
- **不画深海藤蔓、切角、像素角括**（旧 v1.2 风格已退役；`UI.frame` 的 `vines / cut / bracket` 参数仍接受但不再画）。
- **不用原作的标志与素材**：集成战略菱形标志、原作 Logo、截图一律不用；本作徽记是「菱形 + 一道浪」（title.gd `_draw_emblem`）。

## 2. 语义色（`ui.gd` 常量）

| 颜色 | 常量 | 用在 |
| --- | --- | --- |
| 青 #36e2dc | `UI.CYAN` | 可选 / 悬停 / 主操作按钮、技能生效 |
| 紫 #7c6bff | `UI.VIOLET` | 当前（队长标签）。`UI.PURPLE` 是旧淡紫，水月特效等还在用，别改 |
| 洋红 #ff3d8b | `UI.RED` | 危险：Boss、低血、买不起、遭诅 |
| 金 #f4c04e | `UI.GOLD` | 灯火、核心稀有度 |
| 绿 #2fd3a0 | `UI.GREEN` | 源石锭（费用框左侧色条） |
| 钢蓝 #7e98b8 | `UI.STEEL` | 普通按钮 / 操作条底色（半透明） |

正文 `UI.TEXT`，次要文字 `UI.SUB`。小标签头底色：生命值 `UI.TAB_HP`、灯火 `UI.TAB_LAMP`。

## 3. 组件（都在 `scripts/ui.gd`）

| 组件 | 函数 | 说明 |
| --- | --- | --- |
| 面板 | `frame` / `panel` | 上亮下暗的炭灰平面 + 顶部一线高光 + 1px 细边；左上角一小段强调色；`glow > 0.4` 时细边换强调色并加外晕 |
| 小标签头 | `tab` | 彩色底白字，放在数值正上方 |
| 节点标签条 | `strip` / `strip_width` | 左段彩色底 + 压缩斜体英文，右段暗底中文 |
| 标签片 | `chip` | 暗底 + 左侧色条（状态效果、稀有度等） |
| 按键牌 | `keycap` | 细边框里的按键名（SPACE / ESC / 1） |
| 按钮 | `button` | `primary` 青底深字 / `normal` 钢蓝 / `outline` 暗底细边 / `off` |
| 标题 | `heading` | 居中白字，两侧渐隐细线 + 靠近文字的短粗白线（原作「选择支援」） |
| 光环 | `halo`（旧名 `pedestal`） | 细圆环 + 放射细线，卡片图标用 |
| 条 / 环 | `gbar` / `ring` | 暗槽 + 实色填充 + 顶部高光；圆环进度在外圈 |
| 压缩英文 | `cond` / `ctext` / `en` | 没有额外字体文件：`FontVariation` 把 UI 字体横向压到 0.82 并略加粗；`en` 带字距 |
| 线性图标 | `icon` | enemy / clock / box / ingot / pause / refresh / exit |
| 其他 | `fade_band` / `hairline` / `quatrefoil` | 两端渐隐的暗带、渐隐细线、四叶环（楼层名背后） |
| 墨痕（C 版式） | `jag_rect` / `brush_poly` / `enso` / `blob` / `curly_lines` / `curly_emblem` | 事件画面的撕纸边、笔刷、墨圈、卷须徽记 |

## 4. 画面

- **战斗 HUD**：左上等级圆（外圈经验）+「生命值」「灯火」；顶部中央明日方舟战斗顶栏「击杀 | 时间」+ 楼层条；右上暂停按钮（鼠标可点）+ 收藏品栏；
  右下部署卡式编队（左上职业、右上精英阶段、上方三枚技能格、队长紫色标签）+ 源石锭费用框；左下声呐；底部中央冲刺按键牌。
- **选卡（升级 / 藏品 / 招募）**：背后战场用 `shaders/ui_band.gdshader` 去饱和压暗（顶栏底栏保持清楚），卡片 272×368。
- **商人**：左侧商人立绘框（暖色提灯光，台词 `MERCHANT_LINES`）+ 右侧货品卡与价格条 + 刷新 / 离开按钮。
- **事件（C 版式）**：整屏灰阶；左边撕纸边墨色插画（海嗣祭坛是唯一的彩色物件）+ 事件名（`fonts/serif.ttf`）+ 剧情一句
  （`data/waves.json` 事件的 `text`，目前是草稿）；右边竖排选项条，效果小牌由 `endings.gd` 按选项效果生成。
- **标题页**：保留像素 Logo；纵向时间轴菜单 + 右下「READY TO DEPLOY / 选择干员 》」。

## 5. 字体

- `fonts/ui.ttf`：Noto Sans CJK SC Bold（原有）。
- `fonts/serif.ttf`：Noto Serif SC Black 子集（GB2312 一级字 + 数据里出现的字，约 3900 字，1.6 MB；OFL，授权写在字体文件里）。
  只用于事件标题。缺字会回落到 UI 字体；事件文字里出现生僻字时，用本机的 NotoSerifSC-VF 重新截取（见提交 `ui/is3-a` 的说明）。
