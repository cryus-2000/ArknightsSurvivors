## 3. 实现

- `game/scripts/render/fx_pxplane.gd`：`IDS` 加星熊，帧条元数据两份合并（`METAS`），星熊事件 `_ev_hsg`、地面层 `_floor_hsg`、锯盾读玩法状态 `o.el.boom`（距离公式同 `ob_elite._el_boom_d`，只读；画面位置按 15 fps 跳格，记在弹体字典的画面专用键 `_pxq`）。排序项加 `sk`（地刺身后半圈往前排）。
- 钩子：`seg_hoshiguma.exec_line` 结算后一行 `_FXR.ev(o, "shape", {line: true, ...})`（力之锯直线斩）。普攻 / S1 / 成长节点圆环走斯卡蒂已加的 `ob_core.exec_shape` 钩子；热砂每跳结算的圆形不画（区域本身画）。
- 接管时跳过的原画面：S1 重斩画面 `s1_slash_fx`、锯盾 `el_draw_over`、热砂外缘橙椭圆（`gm_draw` 热砂段）；`character.draw_pfx` 接管时只画 `KEEP_PFX` 里的帧条。
- 帧条：`game/art/fx/pxp/pxp_hsg_*.png` + `game/data/pxp_hoshiguma.json`；效果源 `tools/pixelfx_fx/melee/ak-hoshiguma-pp.js`；重新生成 `python tools/pxplane_bake.py --op hoshiguma`（之后 Godot `--import` 一次）。颜色组 `data/fx_pxplane/hoshiguma.json`（只给颗粒 / 照地光 / 受击反应）。
- 看图：`python tools/pxplane_shots.py demo|rec|trace --op hoshiguma`（输出在 `build/pxplane_hoshiguma/`）。
