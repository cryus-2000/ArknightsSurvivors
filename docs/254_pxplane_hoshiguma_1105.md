## 3. 实现

- 钩子：`seg_hoshiguma.exec_line` 结算后一行 `_FXR.ev(o, "shape", {line: true, ...})`（力之锯直线斩）。普攻 / S1 / 成长节点圆环走斯卡蒂已加的 `ob_core.exec_shape` 钩子；热砂每跳结算的圆形不画（区域本身画）。
- 接管时跳过的原画面：S1 重斩画面 `s1_slash_fx`、飞盾 `el_draw_over`、热砂外缘橙椭圆（`gm_draw` 热砂段）、剑气（`vis_growth.draw` 的剑气段）、连携「举盾」的 `link_fx_b.hs_shield / hs_plant` 与程序占位扇形、「举盾推挡」的通用拖影与圆环；`character.draw_pfx` 接管时只画 `KEEP_PFX` 里的帧条。

- 本分支合入了 `claude/integ-1105`（为了 `late_shape`）：冲突 6 处，`optical.gd` 照地光合并为「先留配方 / 转平面份额，其余走 V4 light_share 分账或按亮度取」，配方候选补成 V4 的 6 元格式。

## 6. 看图判断（Claude）

- **成了的**：普攻是一道钝头青绿刀痕，和斯卡蒂的针尖月牙一眼可分；S1 下劈弧 + 裂网冲击环 + 碎石是最有力量感的一招，三档差别最清楚（精一尘墙、精二裂缝熔成暖金）；力之锯白热锯线 → 青 → 暗沟的冷却读得清；飞盾改成鬼面盾后一眼是盾；连携「举盾」大盾立在队长身侧，比原来的琥珀贴图更贴本作像素格。
- **还不够的**：
  - 普攻 E0 → E1 的差别只在盾缘钢屑，1 倍下不明显；E2 的质变主要靠「般若回旋」飞盾，不是刀痕本身。
  - 荆棘地刺在怪群里偏小，被白色伤害数字和受击闪白盖住；热砂只画边，后期密集时容易看不见。
  - 连携「举盾」盾面 64 世界像素高，比原来的琥珀贴图小一圈。
- 结论：做法沿用斯卡蒂口径没问题；建议用户先看 S1 / 力之锯 / 飞盾 / 连携，普攻精一差别和荆棘体量可能要再加。
