# 298 能天使成长节点 01「对空优先」看得见（11-06）

**结论（5 行）**
1. 用户原话「能天使的成长第一个是不是没有什么用，玩家选择之后看不出来什么变化」。量下来确实如此：没有控制型队友时，射程内有受控目标的出手只占 5–15%，定身每分钟 1.4–4 次（每 15–40 秒一次 0.3 秒），画面上只有一圈 0.25 秒的细金环；只有安洁莉娜 + 德克萨斯这种双控队，才到 35–39%、每分钟 9–15 次。
2. 节点里唯一一直生效的是隐藏的伤害 ×1.48，看不出来。
3. 做了三个改法的原型，都走开关 `growth_nodes/exu_prefer`（缺省 0 = 原样）：A 锁定框 + 定身金星 + 精英兜底；B 再加每 6 发一发眩晕弹；C 再加每 4 秒一发重弹打精英。
4. 我推荐 **B**：不靠队友就能自己造出受控目标，接上原来的优先与定身。它每分钟出 7–15 发金色大弹，画面上一直看得见。代价是多了控制，生存会略好。
5. 用户挑定后再跑同种子机器人对照（高手、普通各 4 个种子），开关开 / 关两边比较，数值按结果再调。

分支 `claude/exu-prefer`（基于 main a6b030e8a）。

## 1. 量测（机器人局，开局到 5:00）

- 做法：`--exupf` 只计数、不改模拟，每分钟打一行 `EXUPF`。
- 设置：`--prog=1` 开局直接点出节点 1；普通、高手机器人各 4 个种子；GCP `exupf1` / `exupf2`。
- 统计口径：
  - 「受控在射程」= 能天使每次选目标时，候选里至少有一只受控（眩晕 / 浮空 / 失重）的比例；
  - 「命中受控」= 主弹命中时目标正受控的比例（含她自己的定身）；
  - 「伤害占比」= 能天使主弹打在受控目标上的伤害 ÷ 她的主弹总伤害。

| 编队（能天使当队长） | 机器人 | 受控在射程 | 命中受控 | 伤害占比 | 定身 / 分钟 |
|---|---|---|---|---|---|
| 单人开局（之后自然招募） | 普通 | 6.6% | 6.5% | 6.3% | 2.1 |
| | 高手 | 13.2% | 16.6% | 14.5% | 4.3 |
| + 维什戴尔 + 艾雅法拉（无控） | 普通 | 4.4% | 5.7% | 4.8% | 1.4 |
| | 高手 | 17.3% | 16.5% | 14.3% | 4.4 |
| + 塞雷娅 + 铃兰（无硬控） | 普通 | 5.9% | 8.4% | 6.7% | 2.5 |
| | 高手 | 10.9% | 15.9% | 13.5% | 4.3 |
| + 艾丽妮 + 星熊 | 普通 | 13.1% | 16.6% | 15.4% | 6.4 |
| | 高手 | 18.5% | 21.4% | 20.4% | 7.8 |
| + 安洁莉娜 + 德克萨斯（双控） | 普通 | 34.9% | 33.6% | 35.1% | 9.3 |
| | 高手 | 38.5% | 38.9% | 38.7% | 15.3 |

读法：
- 多数编队里，「打受控目标」只占她输出的 5–15%。
- 定身只有 0.3 秒，精英减半，同一只 1 秒内至多一次，玩家几乎注意不到。
- 节点的效果基本只剩伤害 ×1.48，而这一项看不出来。

## 2. 三个改法（开关 `growth_nodes/exu_prefer`，缺省 0）

三个改法共用同一套画面，颜色用能天使转平面的金阶 `g`：
- **锁定框**：头号目标是受控目标时（A 另含精英兜底），目标四角出现金色折角，按美术像素格对齐。锁上的瞬间从外 10 像素收紧，用时 0.12 秒，之后按拍轻闪。
- **小括号**：受控但没被锁定的目标，照旧画头顶金色小括号。
- **定身金星**：定身时一圈 6 颗金色四角小星往外飞，持续 0.35 秒。眩晕弹 / 重弹命中时是 8 颗，更大。
- 原来那圈 0.25 秒的细金环保留。

### A：保留机制，加表现 + 精英兜底（`exu_prefer 1`）

- 机制：
  - 射程内有受控目标时，与原版完全相同；
  - 射程内没有受控目标时，改成优先打精英 / Boss；
  - 伤害 ×1.48 不变。
- 看得见：锁定框跟着她的头号目标走，有受控或精英时就一直在。
- 平衡：输出总量不变，只是更集中打精英。高手局「命中精英占比」单人 24.8% → 34.3%，其余编队差异在噪声内。
- 不足：没有控制型队友、场上也没有精英时（前 2 分钟大部分时间），锁定框不出现，依旧看不出。

### B：自带控制（`exu_prefer 2`，推荐）

- 机制：
  - 在 A 的画面之上，每第 `exu_stun_every` = 6 发主弹是一发眩晕弹；
  - 眩晕 `exu_stun` = 0.6 秒，精英减半，Boss 不受，走成长节点控制递减；
  - 眩晕弹命中即停；
  - 被眩晕的目标立刻成为受控目标，后面的子弹优先打它，接原来的定身 0.3 秒。
- 看得见：
  - 眩晕弹是金色大弹，曳光弹体画两遍 = 6 宽，弹头加亮光；
  - 命中弹出 8 颗金星，目标被框住，随后子弹往它身上集中。
- 量测：眩晕弹每分钟 7–15 次，定身次数也跟着涨（塞雷娅 + 铃兰普通局 2.5 → 5.8 / 分钟）。

| 编队 | 机器人 | 受控在射程 原样 → B | 眩晕弹 / 分钟 |
|---|---|---|---|
| 单人开局 | 普通 | 6.6% → 9.0% | 6.9 |
| | 高手 | 13.2% → 20.7% | 10.7 |
| + 塞雷娅 + 铃兰 | 普通 | 5.9% → 13.8% | 8.3 |
| | 高手 | 10.9% → 14.0% | 9.8 |
| + 安洁莉娜 + 德克萨斯 | 普通 | 34.9% → 36.0% | 9.4 |
| | 高手 | 38.5% → 35.8% | 14.8 |

- 平衡：
  - 伤害不变；
  - 多出来的是每分钟约 10 次、每次 0.6 秒的单体眩晕，对小怪清场速度影响小，对被围时的生存略有帮助；
  - 要压就调 `exu_stun_every`（8 = 少 25%）或 `exu_stun`。

### C：定时重弹打精英（`exu_prefer 3`）

- 机制：
  - 在 A 的画面之上，每 `exu_hv_cd` = 4 秒，下一轮射击的第一发换成一发重弹；
  - 目标是射程内最近的精英 / Boss，没有就打最近的敌人；
  - 伤害 × `exu_hv_mult` = 2，眩晕 `exu_hv_stun` = 1 秒，精英减半即 0.5 秒，Boss 只吃伤害。
- 看得见：节奏固定的一发金色大弹专打大怪。
- 量测：实际每分钟 2.5–3 发，因为没目标、不在射击时不发，所以比 B 稀疏得多。
- 平衡：
  - 对精英的爆发略涨（每 4 秒一发 2 倍伤害，约等于主弹总伤害 +2–4%）；
  - 控制量约为 B 的四分之一；
  - 节奏慢，开局几乎碰不到精英，「选完马上看出区别」不如 B。

### 推荐理由

- B 满足 docs/249 的口径：选完下一轮射击就能看到金色大弹和金星，不依赖队友。
- B 让原来的「优先 + 定身」有了自己的来源，还保留了与安洁莉娜 / 艾丽妮 / 德克萨斯的联动：双控队里受控目标本来就多，B 几乎不加量（35–36%）。
