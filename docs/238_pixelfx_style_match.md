# 238 本作 pixelfx 特效与原作风格对照（11-02）

用户问：「看一下我们生成的特效是否跟 pixelfx 的特效风格一致？因为我是喜欢他们的风格才拿来用的。」

对照图：`Claude outputs/pixelfx_eval/style_match.png`。六类特效（斩击、火 / 法术、水、雷 / 能量、爆炸 / 砸地、命中），每类左边是 pixelfx 原作 2 个，右边是本作已出的 2–3 个。每条取 10 帧，同一底色上下两排：深海底 #06142a 和中性灰底。
- 原作用 `render.mjs --sheet --no-actor` 原样导出，并做了反预乘。
- 本作取各组工作树里游戏实际用的帧条（时间 11-02 21:20 前后）。
- 脚本在组长会话的 scratchpad 里（`style_match.py`），可重跑。

## 0 结论

**手法对了，但有四处把 pixelfx 的味道压没了。** 骨架是对的：不规整分叉、首帧爆亮后冷却、粒子带重力、烟团。原作的味道主要来自三样东西：
- 硬阶梯的颜色层，加一层**柔和的加色光晕（light 层）**；
- 1:1 的细像素；
- 拖得较长的余韵（火星、烟、焦痕）。

规范有四条把这三样压掉了。按影响从大到小：

1. **光晕被 32 色量化吃掉了（影响最大）。**
   - pixelfx 的特效是两层：color 层用硬色阶，light 层是加色辉光，柔和感只放在 light 和半透明烟里（它的 SKILL.md 原话："hard ramp steps in color; softness only in light and in translucent smoke"）。
   - 我们把两层合成后再整体量化到 32 色，light 的渐变变成了几圈色带，或者干脆被裁掉。
   - 实测半透明像素占比：原作 65–91%；本作普攻只有 5–23%（拉普兰德 5%、能天使 23%、艾雅法拉命中 6%），技能 31–100%。
2. **像素块大了一倍。**
   - house.js 用 `PX = 2`（1 个美术像素 = 2 世界像素）。实测本作帧条里水平相邻两像素相同的比例是 0.36–0.89，原作只有 0.06–0.13。也就是说，本作是半分辨率画好再放大 2 倍。
   - 结果比 pixelfx 原作粗一倍，也比 @2x 干员精灵粗。docs/228 实测的结论本来是「pixelfx 按 1:1 世界像素，与 @2x 精灵同密度」，规范 §2.1 改成了 2 倍。
3. **余韵被时长上限截掉了。**
   - 原作命中总长 0.47–0.9 s，斩击 0.6–1.8 s，爆炸 5–7 s。核心在 0.1–0.3 s 内打完，之后是火星落地、烟团散开、焦痕慢慢淡掉。
   - 本作普攻上限 0.2 s，技能上限 0.6 s，实测 0.17–0.6 s，只剩核心那一下。
4. **近白太多，暗部太暗。**
   - 原作近白像素 3–21%，白色只给最烫的核心。本作有三条明显超标：推进之王砸地 59%、拉普兰德普攻 41%、能天使普攻命中 29%。规范上限本来是 12%，是执行时没守住。
   - 本作有的特效暗部占比偏高：艾雅法拉 52%、逻各斯 43%。原因是规范 §2.2「最暗一阶往 #06142a 靠」，发光特效边缘一圈深蓝黑，像描了黑边。原作发光特效的暗部接近 0%，变淡靠 alpha，不靠暗色。

比较像原作的：斯卡蒂刀光（A 组）、能天使技能爆炸（D 组）、凯尔希砸地的裂纹部分（C 组）。

偏离最大的：
- 拉普兰德普攻：全不透明的白弯月，没有光晕；
- 推进之王砸地：首帧是一个白椭圆；
- Lumen 光柱：六边形底座，太规整、太几何；
- 能天使普攻命中：太小、太白。

## 1 逐要素对照

| 要素 | pixelfx 原作 | 本作现状 | 偏离来源 |
|---|---|---|---|
| 像素块 | 1:1 细像素（2x 块比例 0.06–0.13） | 2x 粗块（0.36–0.89） | §2.1 密度、house.js `PX = 2` |
| 颜色层 | 硬色阶，5–8 阶，饱和度 0.5–0.7 | 硬色阶，16–25 色；部分饱和度偏低（拉普兰德 0.16、能天使命中 0.29） | 基本一致；低饱和是色阶取得太白 |
| light 发光层 | 加色辉光，半径约为核心的 2–3 倍，柔和渐变 | 合成后量化，变成色带或被裁掉 | §0「32 色」用在了合成图上；§2.7 k ≤ 0.3 |
| 核心高光 | 白色只在最烫的 1–2 帧核心；近白 3–21% | 首帧常见整块白（白椭圆、白弯月）；近白最高 59% | §2.4 执行过头（「最亮两阶 ≥ 40%」被理解成大块白） |
| 外缘 | 靠 alpha 淡出，暗部约 0% | 深蓝黑一阶描边，暗部最高 52% | §2.2「最暗一阶往 #06142a 靠」 |
| 节奏 | 快进慢出：核心 0.1–0.3 s，余韵 0.3–1 s 以上；近战有 0.1–0.4 s 前摇（由人物出，本作不需要） | 只有核心，0.17–0.6 s | §2.5 时长档 |
| 粒子 | 火星带重力、有拖尾；烟团是半透明圆团；焦痕留在地上 | 有火星和小点，烟团少，焦痕少 | 时长截断 |
| 形状 | 有机、不对称 | 大多不规整；少数几何化（Lumen 六边形、凯尔希外圈轮廓） | 个例，验收时抓 |

## 2 修正建议

原则：**保留 pixelfx 的风格手感，只在配色上服从干员设定色和敌我可读性。**

### 2.1 规范要改的条款（docs/229）

1. **§2.1 密度：不改，保持 `PX = 2`（11-02 复核后撤回细像素建议）。** 实测战场上其余画面的 2x 块比例：敌人精灵约 1.0、旧 Codex 特效帧条约 0.87、终结技 pixfx 大图约 0.89，都是 2 倍粗块；只有干员精灵是细像素（约 0.21）。新特效改细像素只和干员一致，和敌人、终结技、敌方特效都对不上，反而不统一。pixelfx 的味道主要靠光晕、余韵和白色用量补回来；光晕层本身是柔和渐变，受像素块大小影响很小。
2. **§0 色数 / §2.7 发光：**
   - 32 色只约束 color 层。
   - light 层**单独导出成一张灰度帧条**（L8，不量化），游戏里用加色混合叠画，tint 用干员色阶第 4–5 阶。
   - 光晕强度 k 从 ≤ 0.3 改为 0.4–0.6。pixelfx 自己的建议是 0.2–0.5；我们是深海暗底，加色光晕最出效果。
3. **§2.2 色板：**
   - 发光特效（刀光、法术、能量、命中）的最暗一阶不再往 #06142a 靠，改为「设定色 × 35% 明度、饱和度不降」。淡出交给 alpha。
   - 深海暗阶只留给烟、碎石、焦痕。
   - house.js `OP` 七阶要按这个重新生成，浊心斯卡蒂的暗色阶是用户定的，例外保留。
4. **§2.4 亮暗：**
   - 「最亮两阶 ≥ 40%」改为「首帧核心最亮，白色只在核心」。
   - 近白 ≤ 12% 改成验收硬卡（vreview 自动项）。现有三条超标的要返工。
5. **§2.5 时长：** 拆成「主体」和「余韵」两段。
   - 主体上限不变：普攻 0.2 s，技能 0.6 s，敌方落点 0.4 s。
   - 余韵另给：普攻 +0.25 s，技能 +0.6 s。余韵的 alpha ≤ 40%，像素稀疏，帧率可降到 12–15。
   - 敌方余韵不得遮挡预警。
   - 普攻余韵仍走三档限频；满屏时第三档砍掉余韵，只留主体。

### 2.2 house.js 常量

- `heat()` 默认 `cool` 0.25 → 0.35（余韵更慢）
- 新增 `GLOW = {k: 0.5, ring: 2.5}`（光晕强度、半径倍数）
- `FPS` 加 `tail: 15`
- `DUR` 加 `basicTail: 0.25, skillTail: 0.6`
- `OP` 七阶按 §2.1 第 3 条重新生成（低阶提亮、饱和度不降）

### 2.3 工具 / 引擎（组长做）

- `tools/pixelfx_export.py`：分层导出 `<名>.png`（color，32 色调色板 PNG）和 `<名>_glow.png`（light，L8 灰度）。用库的 `renderFrames` 直接取 `color` / `light` 两个缓冲，不再从合成图拆分，这样也就不需要反预乘了。
- 游戏侧：Art / ob_fx / vfx 画帧条时如果有同名 `_glow` 条，就用加色材质叠一层（tint = 干员色）。这一处改公共文件，只能组长改；改完各组重导即可，不用改各自代码。

### 2.4 包体与帧时（估算，未实测）

| 改动 | 包体 | 帧时 |
|---|---|---|
| 光晕灰度层 | 约 +30–50% | 每个特效多一次加色绘制 |
| 余韵帧 | 约 +20–40% | — |

- 合计可能略超原定 1.2 MB 总预算，估计到 1.4–1.7 MB。办法有两个：
  1. 用音频腾出的 1.39 MiB 补；
  2. 余韵改由程序粒子画，不进帧条。
- 帧时：加色叠画多一次绘制，要在 --mobilecap 下复量。

## 3 用户 11-02 定

**光晕 + 余韵两条都改**（用户原话「都按建议改」；普攻余韵收短到 0.15 s 并限频），细像素不改。已落地：docs/229 §0 / §2.2 / §2.4 / §2.5 / §2.7、house.js（`GLOW`、`FPS.tail`、`DUR.*Tail`、`TAIL_ALPHA`、`heat` cool 0.35、`OP` 低三阶）、`Art.OP_RAMP`、`tools/pixelfx_export.py` 分层导出（`tools/pixelfx_fx/ak_layers.mjs`）、游戏侧 `vfx.glow` 加色叠画。总增量预算 1.2 → 1.7 MB。
