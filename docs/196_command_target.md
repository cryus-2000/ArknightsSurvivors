# 196 指挥模式「指点」：指定地点 / 目标进攻（方案，10-29）

状态：**方案稿，等用户拍板**；不进主线。分支 `claude/command-target`（基于 `claude/integ-1029` 头 ba5c4d658）。
本稿只写方案；唯一的代码是一个**默认关的示意原型**（`command/target_proto`，§12），只为录一段操作示意录像，不改缺省玩法、不合 main。
用户 10-29 原话（经协调人转达）：想给指挥模式加「指定地点 / 目标进攻」；「选定位置的时候也可以慢动作，这样不影响对局」。

## 0. 结论与推荐

1. **做成一个动作「指点」**：突击中，玩家指一个**地点**（全队去那里、在半径 R 内作战）或一个**精英 / Boss**（全队集火）。不指 = 现在的自动突击。
2. **用它取代「清杂优先 / Boss 优先」**：这两项在圆盘里占两格、机器人从不切、玩家基本不切（docs/114 §13、§15；设计总纲草稿 §2 A）。圆盘仍是 5 格：**随行 / 突击 / 归队 / 点位 / 集火**，按钮数不增。清杂逻辑留作队友自动选敌的缺省，Boss 优先整支删掉（§4）。
3. **慢动作沿用圆盘的 ×0.2，选点阶段不断档**；防滥用靠「选点每真实秒扣一点作战时限 + 单次上限 3 秒 + 下令冷却 3 秒」（§5）。
4. **共用现有作战时限（耐力）**，不新增资源；耐力尽 / 归队 / 点位清空 / 目标死亡，指令都结束（§7）。
5. **手机**：圆盘里按住「点位 / 集火」不抬手，拖到目标松手；**电脑**：鼠标点；**手柄**：右摇杆移光标、吸附精英 / Boss（§6）。屏外目标：不动镜头，用屏幕边缘标签（缩放留作可选，§6.4）。
6. **机器人要会用**，否则难度校准失真：分三档（P0 不用 = 现状 / P1 规则脚本 / P1×0.5 = 拟人），校准按 P1×0.5 看，P0 当下限（§8）。
7. 对**支柱 A（小队代入感）**是正向：多一个只属于博士的决定；对支柱 C 有风险（队友不吃弹幕，集火 Boss 近乎免费），要先量再定（§9、§10）。

## 2. 设计总纲四问（草稿 §1 的门槛）

1. **服务哪条支柱？** A：博士指挥小队。同时让 B（割草爽感）里「把输出砸到一点」有手感。
2. **多了什么决定？** 指哪打哪：①现在要不要出击（作战时限够不够）；②指**哪里 / 哪个目标**（不是点灯标就是点精英，要看画面）；③什么时候撤（归队 / 等时限尽）。原来的「清杂 / Boss 优先」只是一个静态偏好，没有这种「看局势下令」。
3. **一局碰几次？** 作战时限 25 秒、50 秒回满：满打满算每 75 秒一轮，10 分钟 ≤ 8 次突击；每次突击 1–2 道指令 → **约 6–12 次指点**，每次选点实际 1–2 秒。要上遥测：每局指令数、类型分布、选点总真实秒、指令存活秒、指令后 10 秒的输出 / 承伤。
4. **替代 / 合并了什么？** 替掉圆盘两格（清杂 / Boss 优先）、`squad.priority` 一整套、`boss_rush`、Boss 优先在 `op_api` / `roam_target` / `seg_exusiai` / `seg_texas` 里的分支、HUD 后缀、指南文案、`command_wheel` 19 项测试里的相关部分。净增：一个选点阶段 + 一种「指令」状态。这是「加一个换两个」，不是只加不减。

## 3. 规则

### 3.1 指令的两种形态

| | 点位 | 集火 |
|---|---|---|
| 指什么 | 地面一点 P | 一只精英 / Boss / Boss 部件 T |
| 队友怎么动 | 到 P，在**以 P 为圆心、半径 R（缺省 240）**的圈里选最近的敌人打；圈里没怪就站在 P 附近（编队位散开） | 直接追 T、进自己的射程（沿用 `stop_range_k`、局部绕行、卡住检测），不做紧急护主 |
| 范围限制 | P 离队长 ≤ `order_r`（缺省 560）；超出显示红圈「太远了」，不能确认 | T 离队长 ≤ `order_r × 1.6`（屏外也行，见 §6.4） |
| 结束 | ①作战时限尽 ②玩家归队 / 随行 ③圈里没敌人 `order_idle`（2.5）秒 → **自动归队** ④队长走出 P `order_break`（1400）以外 ⑤新指令覆盖 | ①②⑤同左 ③目标死了 = 指令结束，**继续自动突击**（不撤）④目标离队长 > `order_r × 2.2`（追丢）也结束 |
| 医疗 / 辅助 | `roam:false` 的照旧随行，不接指令 | 同左 |

- 指令只在**突击**中存在：选「点位 / 集火」时若还没突击，先进突击（耐力够才行，不够飘「作战时限未恢复」）；一退出突击，指令清掉。
- **和现有机制接上的点**：下令那一刻触发 §14 的冲锋（朝指令目标冲，不再朝「自己的最近敌」）；语音走现有指挥语音轮换；倒地 / 归队闪回 / 耐力规则一行不动。
- **安全约束**：P 必须在黑潮安全区内（`zone_r` 内，超出自动夹回）；不能指到不可达的封闭区域外（用现有 `segment_blocked` 判，指不过去就给红圈）。
- 指令生效中，HUD 右下标签「指挥 · 突击 · 点位 / 集火」；点位在地面画一圈 + 每名突击队友一条虚线，集火在目标上画括号（原型已画，见录像）。

### 3.2 自动行为保持

不指点 = 现在的突击（`roam_target` 自动选敌，缺省清杂优先）。指点是**可选的覆盖**，不是必须操作——保证不玩指点的人体验不降。

## 5. 慢动作选点与防滥用

**用户要求**：选点时也慢动作，不影响对局。**沿用**圆盘的 `wheel_slow` ×0.2：圆盘打开 → 选「点位 / 集火」→ 选点阶段，一路 ×0.2，**中间不回到正常速度**（原型已这么做）。队长移动也被放慢，同现有圆盘口径。

**滥用面**：①把圆盘 / 选点当「暂停」躲弹幕（队长在慢动作里也能走，但世界慢 5 倍，躲避窗口被放大）；②每秒下令微操；③长时间慢动作想对策。

| 手段 | 缺省建议 | 说明 |
|---|---|---|
| **选点扣作战时限** | 选点阶段每**真实秒**扣 3%（`command/pick_cost` 0.03）= 约 0.75 个「突击秒」；**取消也扣** | 慢动作和耐力挂钩（协调人方向）。1 秒选点 ≈ 3% ≈ 0.75 秒突击，便宜但不是白拿 |
| **选点上限** | 3 秒真实时间（`pick_cap`）；到点自动确认（落在有效目标上）或取消 | 防止挂着想；3 秒 ×0.2 ≈ 游戏里 0.6 秒，躲弹幕没意义 |
| **下令冷却** | 确认一道指令后 3 游戏秒内不能再下新令（`order_cd`，HUD 在指挥键上转圈） | 防微操连点；3 秒 = 一次冲锋的时间 |
| **作战时限不足** | 耐力低于 `min_start`（0.3）：圆盘照开但慢动作系数降到 ×0.5、上限 1.5 秒，且不能选「点位 / 集火」 | 没耐力时圆盘只剩随行 / 归队的「确认」功能，不当暂停键 |
| **圆盘重开冷却** | 取消后 0.8 真实秒内不能再开 | 防「开 → 关 → 开」当暂停 |

要量的：每局慢动作总真实秒（遥测 `cmd.slow_real_s`），若玩家均值 > 20 秒 / 局或出现「圆盘里躲招」的录像，就收紧 `pick_cap` / 提高 `pick_cost`。数值都是起点，只在 `balance.json`。

## 6. 操作

圆盘 5 格（顺时针从左上）：**随行 · 突击 · 归队 · 点位 · 集火**，上半圈队形、下半圈指点；「点位」「集火」旁边的说明写在圆盘下方一行（「点地面：全队前往，在那里作战」「点精英或 Boss：全队集火该目标」）。

### 6.1 电脑（键鼠）

- **慢路**：F 轻点 → 圆盘 → 鼠标点「点位」/「集火」→ 准星跟鼠标 → **左键确认**；右键 / Esc 取消。
- **快路（建议做）**：F 按住 → 往「点位」/「集火」方向挪鼠标 → 松开 F → 立刻进入选点（准星在鼠标处）→ 左键确认。松 F 不算确认，只是进选点阶段。
- 集火时，准星 64 像素内的精英 / Boss 自动吸附（括号变粗），不用点准；点位时不吸附，超出虚线圈变红。

### 6.2 手柄

- LB 按住 → 右摇杆指向「点位」/「集火」→ 松 LB → 进选点：**右摇杆移光标**（慢速，按真实时间走），**A 确认 / B 取消**；集火时 **LB / RB（或十字键左右）按距离在精英 / Boss 之间循环吸附**，不用瞄。

### 6.3 手机（触屏，用户要求：拖到目标点松手）

- 点「指挥」键 → 圆盘（轻点式）→ **手指点在「点位」/「集火」上不抬起**，直接拖出圆盘：圆盘淡出，出现准星；**准星在手指上方 96 像素**（不被手指挡住），手指处画一个半透明圆。
- **松手 = 确认**；拖回圆盘位置再松 = 取消。左手的移动摇杆不受影响（两根手指各管各的，圆盘不吞摇杆的按下 / 抬起——10-26 已修过这个坑）。
- 集火时准星吸附半径放大到 100 像素；选点界面底部多一个大按钮「**最近的 Boss / 精英**」，手指拖到上面松手 = 直接锁最近的，不用瞄。
- 触屏圆盘现在在屏幕正中，离右手拇指远；实现时圆盘可改为以「指挥」键为锚点展开（待 UI 会话定，不影响本方案规则）。

### 6.4 屏外目标怎么选

1. **边缘标签（推荐，不动镜头）**：选「集火」时，范围内屏外的精英 / Boss 在屏幕边缘出圆形标签（「Boss」「精英」+ 方向）；准星 / 手指 / 光标移到标签上 = 锁定它（手机上手指拖到边缘标签再松手）。已有的 Boss 屏外指示（`draw_boss_pointers`）可直接复用成可选中的。
2. **「最近的 Boss / 精英」一键**（手机）/ **循环吸附**（手柄）：不管在不在屏内。
3. **范围虚线圈**：选点时在队长周围画一圈虚线（`order_r`），超出的点位变红「太远了」，目标超出的标签变灰。
4. **镜头拉远（可选，不建议先做）**：选点时把镜头缩到约 ×0.8，让 `order_r` 整圈入画。风险：光学管线用整数像素镜头（`optical.gd`、docs/139 的整数缩放试验），中途改缩放会动一整套取整和低分辨率画布；而且选点时屏内实体数增加约 1.6 倍。先不做；若实测边缘标签不够用再单独立项。

## 7. 耐力与生命周期

不新增资源：**作战时限**（耐力）照旧，指点只是它的一个消耗者（选点扣 3%/真实秒，之后突击照常按时间扣）。

```
随行 ──选突击 / 点位 / 集火──▶ 突击（自动）──点位 / 集火──▶ 突击（有指令）
  ▲                              │                              │
  │      作战时限尽 / 归队 ◀──────┴──────────────────────────────┘
  └──── 归队闪回 + 集合 0.4 秒 ────┘      （点位清空 2.5 秒 / 队长走远 → 自动归队；
                                          集火目标死了 → 指令结束，回到自动突击）
```

- 指令存活中耐力照扣；耐力尽 = 自动归队（走集合那套），指令清掉，进入冷却线（回到 30% 才能再突击）。
- 点位清空自动归队是为了「打完就回来」：一次指点 = 一次完整的「去 → 打 → 回」，不让玩家忘了撤白白烧耐力。
- 队友倒地期间不接指令；归队时倒地者留在原地的规则（docs/114 §11）不变。
- 指令不跨突击：每次进突击重新指。

## 8. 机器人策略与校准

**问题**：现在所有批跑 / 校准 / 难度目标（docs/36、「初见打不过」目标 30–40% / 50–60%）都是机器人**从不指挥**时量的。指点上线后真人胜率会上升，机器人看不到——要么校准偏难，要么哪天有人开 `bot_roam` 又偏易。必须让机器人会指，并且把「指挥能力」当成一个显式的档位。

| 档 | 行为 | 用途 |
|---|---|---|
| **P0 不指挥**（现状） | 不突击、不开圆盘 | 保持历史口径、做下限 |
| **P1 规则脚本** | 见下，按 0.5 秒节拍判断 | 衡量「会用指点的人」的上限 |
| **P1×q（拟人）** | P1 的每个机会按概率 q 执行（缺省 0.5），执行前延迟 0.6–1.5 秒（用 bot 自己的 rng 流，不碰对局随机数） | 真人的现实水平，**难度目标按它看** |

**P1 规则**（全部只读已有信息，写在 `bot.gd` 里，开关 `bot/command_policy`）：

1. **前提**：作战时限 ≥ 0.6、队长生命 ≥ 45%、没有下令冷却、队长不在敌方预警区里。
2. **集火 Boss / 精英**：Boss / 部件在队长 900 内（或 Boss 登场后）→ 集火它；精英在 650 内且还有 > 40% 生命、至少 2 名队友能突击 → 集火它。
3. **点位**：队长周围 500 内杂兵 ≥ 28 只且队长生命 < 60% 时**不出击**（护主）；队长生命 ≥ 60% 且最密的一团离队长 250–500 → 点那一团（模拟「去压怪群」）。
4. **点灯标**（仅当 M5 的「队友可涨灯标进度」上线）：未点燃灯标在 1000 内、寿命 < 35 秒、队长没在往那走 → 点位到灯标。
5. **撤**：作战时限 < 0.12 / 队长生命 < 35% / 队长进预警区 → 归队。

**校准方法**（沿用现有口径：木桩表 + 同种子配对 + 云端，docs/36、docs/80；胜率差 < 10 点不下结论）：

- 云端三组配对：P0 / P1 / P1×0.5，各 ≥ 56 对同 seed，三份独立实现均值（同 10-16 起的口径）。
- **判据（建议，待定）**：P1×0.5 相对 P0 的胜率增幅 ≤ 6–8 点（指点是「加深」不是「变强」）；Boss 战用时缩短 ≤ 25%；倒地出击比例仍在 10–20%（docs/114 §8.4）。超了就调：先收 `order_pt_r` / 提高 `pick_cost`，再考虑让部分 Boss 招式能打到队友（§10 风险 1）。
- **难度目标换口径的问题要用户定**：以后「无认知高手 30–40%」按 P0 还是按 P1×0.5？我的建议是按 P1×0.5（更接近真人），P0 留作回归基线；定之前所有新数字同时报两个口径。

## 9. 与设计总纲 / 三条支柱的关系

- **支柱 A**：草稿 §2 说「现在真正属于博士的决定只有指挥模式一个」，§3 A 第 4 条要求「清杂 / Boss 优先要么让它变得值得切，要么砍掉只留队形」。本方案的取舍是**砍掉旧的、换一个有决定的**：指点让指挥模式从「开关」变成「下令」，每次都要看局面。
- 草稿的**大招**（只给队长）+ 本方案的**指点**（只给队友）正好互补：队长有自己的招，队友的存在感靠「被博士点名」。实现上联动框架（草稿 §3 A 第 2 条）以后可以加一个触发源「博士下令」（`trig.on_order`），队友被指点时出专属反应——这是可选延伸，不在本方案范围。
- **支柱 B**：集火让「把输出砸向一点」有手感；点位给清杂 / 压怪群一个决策点。不新增构筑数值。
- **支柱 C**：集火 Boss 在现状下近乎免费（队友吃不到敌弹 / Boss 招式），会**削弱**最终 Boss 的弹幕紧张（草稿 §3 C）。见 §10 风险 1：不先处理，指点上线后 Boss 战会更短更松。
- **新机制门槛**：四问见 §2，答得上。「加一个换两个」符合草稿 §1 的要求。
- **和切换队长（草稿列为死开关，建议清理）**：互不依赖；若保留，切换后指令随队长位置重新计算（点位以队长为准的距离检查），不需要特殊处理。

## 10. 风险与未决

1. **队友吃不到敌弹 / Boss 招式**（最大）：集火 Boss 只受作战时限约束。选项：A 维持（先量）；B Boss 地面预警区对**指令中的队友**生效、伤害按队友血量折算（比如 35%）；C 集火时 Boss 的仇恨有概率转向队友（现有 `aggro` 机制排除了 Boss）。建议先 A，用 P1 档在云端看 Boss 战用时，超判据再上 B。
2. **灯标队友点灯**：点灯标是「点位」最自然的用途，但灯标现在只认队长（`beacon.gd` 按 `g.ppos`）。要做就得让「站在灯标圈里的突击队友」也涨进度（缺省 ×0.5？），这会改 docs/56 的去不去规则和灯标收益，**要和「灯火体系瘦身」（草稿 §3 辅助系统）一起定**，所以放 M5，不是本方案的前置。没有它，点位的主要用途是「压怪群」和「守点」。
3. **手机误触**：圆盘拖拽和移动摇杆同屏。用「按在扇区上不抬起」触发 + 取消区回拖降低误触；实机手感未验（只有示意）。
4. **指令被放大的风险**：队长独自留在原地（用户 10-27 已接受「不用特意保护队长」）；若点位离队长远又碰上高压，队长孤身面对。`order_r` 560 + 点位清空自动归队是缓冲。
5. **性能**：指点只在选点期间多画一层覆盖；`roam_target` 以点为圆心选敌，复杂度同原来；无新素材、无新贴图（和「不崩溃优先于加载速度」不冲突）。
6. **和 §14 爆发窗口 / §15 放远的叠加**：指点后冲锋朝指令目标，活动圈改以 P 为心 R 为半径，`roam_r` 840 只在无指令时用。需要在实现时重跑一遍 §15.3 的云端配置。
7. **文案**：见 §11。
