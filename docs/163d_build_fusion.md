## 2. 两边一致、直接沿用的规则

- **叠层**：163B §9「原来 3 级的显式保留 3 级，增量 100% / 70% / 50%」——我们的数值部分（`stat`）照旧走这条；额外弹 / 剑气 / 副体数量走 `count_decay 0.7`、范围走 `size_decay 0.8`。163B「#129 数量不随升级增加」与我们「E 向下取整：1 层 1、2 层 1、3 层 2」只在 3 级时差 1 个 → 并进 §4 第 2 条一起问。
- **额外弹边界**（163B §2）：不重放出手函数、不吃技能弹药、不进技能 / 天赋计数、不再触发挂标 / 殉爆 / 余震；穿透沿用底穿、不继承穿甲弹「穿全部」——我们的实现（独立小弹实体、`growth` 标签、不带 `basic`）已满足。
- **画质不改玩法**（163B §9 末条）：⚠ 我们 §6 的「低画质档超出同屏上限的额外弹不生成实体、伤害直接结算」**不改总伤，但改了命中时刻 / 目标**（直接结算到目标）。163B 要求不同画质同玩法。这是 §4 第 5 条的另一半。
- **Mon3tr / 海嗣唯一**、**移出编队实体按原生命周期退出**：一致。
- **随机**：两边都只用 seeded RNG（我们用累加器，零随机）。

以下为拍板前的原问题与推荐，留作记录。

1. **近战线：剑气 / 范围走哪条？**
   - A（现状，用户 10-27 已拍）：#63 剑气、#56 剑气·锋芒、#64 范围 +18%。
   - B（163B）：#63 / #64 不动；#56 改「近战 +20%，一个主判定命中 ≥3 名时 ×1.25」，范围只靠 #81 / #140。
   - C（融合）：#63 剑气、#64 范围（看得见的两件保留），#56 改用 163B 的「≥3 名 ×1.25 + 近战 +20%」（清群取舍、不再出第二种剑气）。
   - **推荐 C**：用户要的「近战范围扩大 + 普攻额外剑气」由 #63 / #64 保住；#56 两种剑气档位重叠、玩家分不清，改成清群倍率让近战线多一个取舍。
2. **#129 副体拆伤要不要撤？**
   - A（现状，§9 第 4 问已认可）：多出来的魂灵是副体，伤害 ×0.6、体型 ×0.85、偏浅；3 级时 2 个副体。
   - B（163B）：多出来的就是普通魂灵（同伤害、可挂标 / 魂炮），不随升级再加；魂灵自身伤害加成 +20%，其余追击 +35%。
   - **推荐 A 保留副体 + 采纳 B 的「不随升级再加」**：副体让「多出来的那只」一眼看得出，且魂灵会挂标 / 魂炮，满强度 +1 的收益不好估；数量封在 +1 避免 3 级 2 个副体刷屏。
3. **#130 要不要延长时长、要不要削数值？**
   - A（现状）：体型 +15%、限时召唤物时长 +20%、追击 +10%（原 25%）。
   - B（163B）：保留原追击 +25%、只加覆盖 +15%，不延寿。
   - **推荐 B**：现有召唤物里限时的很少（Mon3tr / 魂灵 / 海嗣都是常驻），时长 +20% 几乎没人吃到，却拿走了 15% 伤害；改回 +25% + 覆盖 +15% 更实在。
4. **163B 另外 4 条流派（控场引爆 / 弱点收割 / 护盾反击 / 治疗转伤，共 10 件 + 胸针 / 护戒获取条件）是否进入本轮？**
   - **推荐：本轮先合可见成长 7 件（含本稿修订）上云校准；四条新流派作为第二批，按 163B 的定义直接实施**（163B 已写清结算顺序和防循环），不再另出设计稿。理由：一次改 20 件，云端配对很难归因。
5. **手机降级与「画质不改玩法」**：现状低画质档超出同屏上限时额外弹不生成实体、伤害直接结算（总伤守恒但命中目标 / 时刻变）。
   - **推荐改成固定玩法上限**（不随画质变，例如同屏额外弹 48、剑气 18），超出时并入主弹；画质只减拖尾 / 光弧。顺带：#58 侧弹按 163B 改成左右 2 发（各 7.5%）还是维持 1 发（15%）——推荐维持 1 发（打另一名敌人，覆盖更明显，实体数减半）。
