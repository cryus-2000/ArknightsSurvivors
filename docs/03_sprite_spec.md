# 03 · 主角像素小人规格（给画师）

游戏整体是像素风：美术按原始像素绘制，游戏里统一放大 2 倍、最近邻采样显示（不做平滑）。

## 基本规格
| 项目 | 要求 |
|---|---|
| 单帧画布 | **32 × 32 像素**（角色本体约 24–28 像素高，脚底贴近画布底部，左右居中） |
| 比例 | Q 版，头身比约 1 : 1.5 ~ 1 : 2 |
| 朝向 | 只画**朝右**；朝左由程序镜像 |
| 背景 | 透明 PNG |
| 描边 | 建议 1 像素深色外描边（接近 #080E18），和场景里的怪物保持一致 |
| 颜色 | 每个角色建议不超过 16–24 色；不要半透明像素（阴影由程序画） |
| 武器 | 雨伞画在角色手上，属于角色本体；挥砍的刀光、触手特效由程序绘制，不用画 |

## 动作与帧数
每个动作做成一行横向排列的帧条（sprite sheet），每帧 32×32，从左到右依次排列。

| 文件名 | 动作 | 帧数 | 说明 |
|---|---|---|---|
| `player_idle.png` | 待机 | 4 | 轻微呼吸、衣摆飘动 |
| `player_run.png` | 移动 | 6 | 小跑循环 |
| `player_attack.png` | 挥伞 | 4 | 抬伞 → 横挥 → 收势；第 2–3 帧是出招帧 |
| `player_hurt.png` | 受击 | 2 | 后仰 |
| `player_death.png` | 倒下 | 4 | 最后一帧停住 |

整合成一张大图也可以：每个动作一行，按上表顺序从上到下排列（最宽的一行是 6 帧，即 192 × 160 像素）。
