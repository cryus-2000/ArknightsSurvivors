## 5 去蓝紫环（11-02，用户「维什戴尔的蓝紫色圆环是不是也可以不用了」）

逐个查了她普攻 / 技能 / 爆炸会画的东西，蓝紫色的环只有一种：

| 来源 | 样子 | 处理 |
|---|---|---|
| 炮击爆炸帧条 `fx_wisadel_cannon` 第 2 帧（最大那帧）| 一圈蓝紫描边 + 半透明蓝紫填充，普攻 / 礼尚往来 / 魂炮 / 残影殉爆 / 巨炮 / 处刑 / 连环爆外圈都用这条 | **去掉**：换成 `fx_wd_cannon_nr` |

`fx_wd_cannon_nr` = 终结技已在用的 `fx_wd_cannon`（10-30 去掉蓝色描边）再把残留的蓝紫填充（b > g + 10 且 b > 0.62 r）压成暗烟色；
同尺寸 / 同帧数 / 同帧率，红色晶刺、黑烟、落点红盘、地面旋涡不动。光学压阶版 `_optical/fx_wd_cannon_nr` 按原帧条同口径生成（第 0、3 帧掏空成描边）。
终结技那边仍用 `fx_wd_cannon`，没动。

旋钮 `fx/wd_ring`：缺省 0 = 用去环帧条；1 = 回原帧条（`fx/wd_calm = 0` 时也回原帧条）。

其余查过、不是蓝紫环的：余震 / 巨炮收边 / 续燃落点 / 回馈的 `ring` 都是暗红 / 橙；魂炮炮口那团暗紫烟（`fx_muzzle_flash` 染紫，10-21 用户定的）是一团烟不是环，保留；
好礼标记 `fx_wisadel_gift_mark`、魂灵之影本体里有少量蓝紫像素，是角色 / 标记本身的配色，不是环。

验证：同 seed（5，240 秒，当队长满成长）`fx/wd_ring = 1 / 0` TRACE 逐行相同；对照录像 `Claude outputs/wisadel_calm_1101/wisadel_ring.mp4`（当队长后期 30 秒，左改前右改后）。
