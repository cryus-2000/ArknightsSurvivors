## 2. 本作改编

定位：**特种 · 节奏型刺客（专挑 Boss 与精英，瞬身切入、虚影复刻出手）**。直接秒伤预算 85%（节奏位），补偿是位移与控制。

与现有三名特种的区分：

| 干员 | 核心动词 | 傀影不做的 |
|---|---|---|
| 水月 | 伞击 + 触手追低血、深蓝之籽游猎 | 不追低血、不做束缚召唤物 |
| 歌蕾蒂娅 | 钩索把敌人拖到身前 | 不拉人 |
| 归溟幽灵鲨 | 贴身环斩、倒下留替身、精二人偶闪现 | 不环斩；虚影是常驻复刻，不是一次性闪现 |
| **傀影** | **自己瞬身过去**（再部署）+ 虚影同步出手 | — |

另与先锋德克萨斯区分：德克萨斯的冲刺跟着队长冲刺走、是「跑过去」（0.18 秒，可见位移）；傀影的切入是自行触发的「消失 → 出现」（0.06–0.07 秒），目标是刀锋够不到的敌人，精二后普攻本身就是瞬身。

### 2.1 普攻「影刃」与特性「处决者」

- 影刃：每 0.8 秒朝最近的敌人（Boss → 精英优先，`nearest_enemies`）刺一刀；近身窄扇形，半径 80、半角 0.7 弧度，**最多命中 4 名**，击退 20。单体高、清群弱（与环斩的幽灵鲨相反）。
- 特性「处决者」（原作：再部署时间大幅减少 → 本作：自行「再部署」）：**不是队长时**，每 2.2 秒检查一次：若 300 内最近的敌人在 110 以外（刀锋够不到），瞬身切到它身边（`shape.dash_line`，长 ≤ 260、用时 0.07 秒、沿途 90% 伤害）。是队长时不切入（队长本体不被自动拉走）。
- 帧条契约：先借拉普兰德 `combat` 条（占位，见 §6）；原作 Attack 0.867 s（OnAttack 0.267）/ Attack_2 0.9 s（OnAttack 0.4），本作普攻用 Attack，出手帧 ≈ 第 2 帧。

### 2.2 天赋「镜中虚影」（精一）

- 精一起召出一个虚影（`blocks.summons.shadow`，常驻、无敌、上限 1）：`chase` 模式，优先追 Boss → 精英 → 其余（`target: elite`），离傀影 260 内活动；每 0.8 秒以 70% 伤害复刻一刀影刃（半角 40°）。
- 「虚影拥有和自己一样的技能」：傀影放「暗夜魅影」时虚影在原地斩一圈（100%）；放「夜幕突袭」时虚影在它的位置同样炸开一次（60%，同样眩晕）；「血色乐章」期间虚影出手速度 ×1.5。
- 精二起虚影伤害 ×1.8（原作天赋精二档「属性更强的虚影」）。原作第二天赋「虚影精通」（再部署缩短）本作没有再部署，改作节点 5B 的名字（§2.5）。
- Boss / 精英口径：虚影只造成伤害，不控制；追 Boss 是选目标规则，不是加伤。

### 2.3 三技能（三技能全自动，memory manual-skill-leader-only）

| 技能 | 技力 / 时长 | 效果 | 积木 |
|---|---|---|---|
| S1「暗夜魅影」 | 9 / 6 s | 瞬身切入最近的敌人（100%，队长时不切）；队长获得 12% 最大生命的屏障（上限 20%）；6 秒内影刃间隔 ×0.7 | `shape.dash_line` + `verb.shield` + `buff_self interval` |
| S2「血色乐章」 | 15 / 8 s | 攻击 ×1.5；不是队长时每一刀之后瞬身跳到 220 内下一名敌人（沿途 80%）——原作「每攻击一次消耗一层」改成「每一刀换一个舞台位置」；虚影出手速度 ×1.5 | `buff_self atk` + `trait every_n 1 cond skill_active:1` → `dash_line` + `summon_mod aspd` |
| S3「夜幕突袭」（精二） | 20 / 瞬发 | 瞬身切入附近敌人最密处（`aim: densest`），落地半径 170 内 300% 伤害、推开、眩晕 2 秒（精英减半，Boss 除外）；虚影同时在它的位置炸开（60%） | `dash_line densest` + `trig.on_dash_end src 夜幕突袭` → `circle` + `st.stun` |

原作 S3「随机施加停顿 / 束缚 / 晕眩之一」：本作统一为眩晕（三种在本作里的玩家感受差不多，随机反而读不懂），见 §3 妥协。

### 2.4 精英化（docs/91 §0.2）

- **精一 · 普攻「背刺」**：每第 3 次影刃，影子从目标身后补一刀（30%），停顿 0.4 秒（精英减半，Boss 除外）。画面新元素：目标背后一道暗红短斩线 + 一缕黑烟（与正面刀光方向相反）。预算：+30% / 3 ≈ +10% 单体，略高于 +8%，用停顿换掉一部分，待木桩表定（§5）。
- **精二 · 普攻质变「瞬影」**（新动词：**普攻本身变成瞬身穿透**，不在 docs/91 §0.4 表里）：不是队长时，影刃整个换成瞬身斩——每一刀从原地消失、沿直线穿过目标出现在它身后（长 150、宽 36、0.06 秒、160% 伤害，沿途全部命中、停顿 0.3 秒）。一眼可认：傀影不再站着刺，而是在敌群里来回闪。是队长时（本体不能自己乱闪）改为每第 4 刀附带一道穿身影刺（直线 170 × 30，70%）。另：虚影伤害 ×1.8。

### 2.7 终结技 Q / 连携（docs/198 / 209；只设计，未接代码）

## 3. 积木落地

- 用到的积木：`shape.cone`（`max_n`）、`shape.dash_line`（德克萨斯段：`aim nearest / densest`、`need_target`、`min_d`）、`trig.tick`、`trig.every_n`、`trig.on_dash_end`（`src`）、`trig.on_skill_start / on_skill_end`（`at: summon:shadow`）、`trig.on_deploy`、`verb.shield`、`verb.buff_self`、`verb.summon` + `blocks.summons`（`chase target elite`）、`verb.summon_mod`（`aspd / dmg / then`）、`trig.every_n replace`（精二把每一刀换成 `dash_line`）、`shape.line`、`st.stun / st.pause`。
- **0 个新积木、0 个 custom、不写 seg 段**（不改 `op_blocks.gd` 继承链，避开与令的冲突）。
- 已知妥协：
  - 原作 S3 随机三选一控制 → 统一眩晕（`g.rng` 也不多取，老干员同种子不变）。
  - 原作「物理闪避」→ 影刃加速（本作队长闪避是全局属性 `g.dodge`，不走干员作用域；为不新增全局属性，改成节奏收益）。
  - 「血色乐章」层数 → 限时 + 每刀换位；层数制需要 `dur.next_n` 与 `every_n` 联动的条件（`skill_pending`），现有条件表没有，没必要为此加积木。
  - 切入是 `dash_line` 0.07 秒的极短冲刺，不是真正的瞬移；画面上靠转平面把中间帧藏掉（§4.5 特效需求）。
