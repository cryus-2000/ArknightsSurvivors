## 2. 本作改编

定位：**近卫 · 主输出（控制向）**。全队唯一的「封印」（`st.seal`，docs/61 §15.3：敌人不起新招、不开火、甲壳 / 潮盾失效）干员；中近距离，近身横扫 + 隔两刀一道穿透剑气。与斯卡蒂（高频横扫 + 连斩）、艾丽妮（直线穿刺 + 浮空）、乌尔比安（锚击 + 拖拽）区分开：她的卖点是「让敌人闭嘴」，不是面板。

### 2.1 普攻「双刃」（docs/108 attack / attack_timing 契约）

- `shape.cone`：队长身边横扫，半径 `reach` 118、攻击 `atk` 34（10-22 从 30 调到 36、云端复核偏高后回到 34，见 §5）、半角 1.3 rad（约 150°）、击退 50、间隔 `cd` 0.8 秒；前压 `follow {leash 200, gap 30}`（同斯卡蒂）。
- **远近切换**（10-22 用户定，通用积木 `attack.far`）：出手那一刻触及 `reach` 118 内没有敌人、而 260 内有，这一下横扫改为朝 260 内最近的敌人掷一道剑气（攻击 `far_mult` **80%**，飞出 200、宽 50、穿透，`src 远掷`，同剑气弹体）；近身有敌人照常横扫。「领主」每第 2 刀附带剑气的计数照旧（远掷也算一次普攻）。
- **特性「领主」**（写成 `trait` 的 `trig.every_n {n: blade_every 2}` → `shape.wave from self`）：每第 2 次横扫额外朝 260 内最近的敌人掷出一道剑气：飞出 200、宽 50、速度 500、穿透全部、横扫 **80%** 伤害（= 原作「远程攻击攻击力降至 80%」）。精二起由「双生刃」取代。
- 帧条契约：占位期借斯卡蒂 `attack` 槽（96 画布、动作窗口 5/14 秒、出手 2.5/14 秒）；正式帧条到了写 `attack_timing {duration 0.36, fire_time 0.18, active_ratio 0.9, windup_ratio 0.45}`（docs/108 §9 参考值）。

### 2.2 天赋「精神摧毁」（精一）

横扫（含连斩补刀、旋身斩）命中的敌人**封印 1.5 秒**：普通怪不起新的特殊招式、不远程开火、甲壳 / 潮盾失效；精英 ×0.5；Boss 只推迟出招（×0.3、封顶 1.5 秒、之后 10 秒免疫）。
实现：`blocks.attack.on_hit` 挂 `st.seal`，`cond: "elite >= 1"`（天赋精一生效）。原作的「1 秒 → 5 秒」改成固定 1.5 秒，因为本作每 0.8 秒一刀会刷新。

### 2.3 三技能

| 技能 | 技力 / 时长 | 效果 | 积木 |
|---|---|---|---|
| S1「日晷」 | 10，充能一次后永久 | 攻击 ×1.25（吃技能强度）；队长受到的攻击有 **20%** 概率被她格挡（完全抵消那一下；原作「20% 概率抵抗物理伤害」） | `verb.buff_self atk mult` + `trait` 的 `trig.on_hurt {chance 0.2, negate, cond skill_active:0}`（星熊「战术装甲」同款，概率走 `g.rng`） |
| S2「狼魂」 | 14，12 秒 | 攻击 ×1.4（吃技能强度）；每次横扫额外掷一道**法术**剑气（横扫 60%，飞出 200，穿透）= 原作「伤害变法术、额外攻击一个目标」 | `verb.buff_self` + `trait every_n {n 1, cond skill_active:1}` → `shape.wave`（`src 狼魂` kind 法术） |
| S3「群狼之噬」（本作自创名） | 24，8 秒 | 每 0.6 秒朝最近敌人掷 3 道剑气（±18°，各攻击 70%，飞出 220，穿透，每名敌人每轮只受一道），同时封印周围 180 内敌人 2 秒；普攻照常 | `trait tick {every 0.6, countdown, cond skill_active:2}` → `shape.wave fan [-18,0,18] fan_once basis atk` + `verb.affect {r 180, on_hit st.seal}` |

S3 预算：8 秒 × 13 轮 × 0.7 ≈ 9.3 次普攻伤害（单体），群体 3 倍覆盖；加上 8 秒普攻不停 ≈ 「10 秒普攻伤害 + 全场封印」，在 docs/27 §3.3「S3 ≈ 8–14 秒形态变化」区间下沿，控制价值补足。

### 2.4 精英化（docs/91 §0.2 口径）

- **精一 · 普攻「狼之舞」**：每第 5 次横扫改为旋身斩：以自身为中心半径 120 内 ×1.3 伤害、击退 90、命中封印 2 秒（「群狼之噬」期间不换）。`progression.elite1 = every_n {n 5, replace}` → `shape.circle center self`。预算 +6%（每 5 刀多 0.3）。画面：全向圈 + 封印紫锁。
- **精二 · 普攻质变「双生刃」**：每次横扫都掷出**两道交叉剑气**（±12°，各横扫 55%，飞出 200，穿透；每名敌人每轮只受一道），取代「领主」的隔刀单刃。`progression.elite2 = every_n {n 1}` → `shape.wave fan [-12, 12] fan_once`。动词「交叉双弹体」在 docs/91 §0.4 的 18 个动词里没有重复（星熊是往返、斯卡蒂是收尾单道、艾雅法拉是低抛三角）。单体 +15%（0.4 → 0.55 每刀）、群体覆盖 ×2，视觉上一眼能看出「她精二了」。

### 2.6 响应动作（docs/118，设计，本阶段不实现）

触发源选**开技能**（docs/118 §2 的四类里「开技能」给辅助 / 医疗，但拉普兰德的卖点是封印，和队长的技能节奏绑定最顺手）：

- **「噤声」**：队长开技能那一刻，她以队长为中心放一圈封印冲击（半径 160，横扫 50% 伤害，封印 2 秒，Boss 推迟出招）；冷却 4 秒（不位移，不受 §1.4 机动约束）。
- 论证：队长开技能通常是「要打一波」的时刻，先封住周围敌人的招式（吐酸 / 冲刺 / 环弹 / 潮盾）让这一波打得安稳，玩家能直接感觉到「我开技能她就跟着喝一声」。冲刺触发不合适（她不位移），站定给了重装 / 炮手，指挥依赖 docs/114。
- 积木：`blocks.response = {trig: on_leader_skill, cd: 4, do: [shape.circle center leader r 160 basis atk mult 0.5 on_hit [st.seal 2]]}`；需要 docs/118 §3.1 的 `trig.on_leader_skill` 触发器（新，全员共用），其余都是现有积木。

## 3. 积木落地

**全部用现有积木**（纯数据干员，0 个 `custom`，无脚本）：`shape.cone / circle / wave`、`attack.combo`、`trig.every_n / tick / on_hurt / passive`、`verb.buff_self / affect`、`st.seal`。`validate_operator` / `test_core` 干员契约通过。

**需要新积木 / 新参数的清单（本阶段没做，列给积木会话）**：

| 需求 | 现状 | 用处 |
|---|---|---|
| `trig.on_leader_skill` | docs/118 §3.1 规划，未实现 | 响应动作「噤声」 |
| `shape.wave` 支持 `on_hit`（命中状态） | 浪墙 / 潮刃没有 on_hit | 剑气命中封印（现在只有横扫 / 旋身斩封印，剑气不封） |
| 普攻「远程兜底」：`attack.far {shape, mult}`（触及内没有敌人时改用远程形状） | **10-22 已做**（`data_operator._release` 通用，docs/61 §21.3） | 远近切换：触及内没人 → 朝 260 内最近敌人掷剑气 80% |
| `verb.swap_attack` 允许 `wave` | 只许 circle / cone（docs/108 F9） | 狼魂期间把普攻整体换成法术剑气（现在用追加法术剑气近似） |
| 封印中敌人受伤加成（`verb.ctrl_bonus` 认 seal） | ctrl_bonus 只认浮空 / 眩晕 / 束缚 | 路线 A 更有「控制 → 收益」的闭环 |

**已知妥协**：原作 S1 是「抵抗物理伤害」概率，本作只有队长受击 → 改成她替队长格挡 20%；原作 S2「远程攻击不降攻击」在本作没有远近之分 → 以法术追加剑气表达。
