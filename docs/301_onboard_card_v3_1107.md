# 开局指南卡按属性面板画（11-07）

用户原话：「开局指南卡要不要改成面板风格 要的」。

v3 卡比旧卡小一号（桌面 500 → 440、手机 540 → 470，演示区占 40%、内边距 12），11-07 用户「新手引导的格子能不能小一点」。

参照的是 main 上现在的属性面板，也就是指挥台风格：桌面看 `stats_panel.draw_v3`，手机看 `draw_phone_v3`。只在指挥台开着时（`hud_v3.on()`）换画法；关着时仍是旧版金边卡。卡片的位置、大小、出入场时机、不暂停、不拦输入、「跳过」的点击区，这些都不变。

代码在 `screens/onboard.gd`：`_card_v3`、`_draw_ask_v3`，共用 `_head_v3`、`_hair_v3`、`_brackets`。

| 部件 | 现在（v3） | 对齐属性面板的哪一处 |
|---|---|---|
| 底 | 深底 0.92，两角白直角刻度，去掉左侧白竖条 | `draw_v3` 的整屏底与两角刻度 |
| 标题行 | 中文标题用思源 Heavy（桌面 18 / 手机 22 / 图鉴大卡 24），右边跟灰英文小签（桌面 6.5 / 手机 7.5），下面一道 20% 细线，左端一段 18 像素白短条 | `_v3_head`；手机字号按手机面板 |
| 正文 | 白 90% | 面板正文白 |
| 演示框 | 外面一圈 20% 细框 | 面板分隔线亮度 |
| 做完条件 | 青色方点 + 青字。「移动」的进度条改成细线条（1.6 底轨 + 3.2 青条） | 指挥台里青色表示「可操作」；`_v3_hair` |
| 自动收起读条 | 细线条，白 | `_v3_hair` |
| 「跳过」 | 深底 + 35% 白框 + 灰字 | 面板等级牌 |
| 做完打勾 | 青方块 + 勾 | 指挥台没有圆，青色表示「可用」 |
| 问题框 | 深底 + 两角刻度；标题行同上（BRIEFING 小签）；选项平时是 3% 白底加 20% 白框，选中是青框 + 淡青底 + 左青竖条 | 手机面板页签当前项用青 |

手机卡比较窄。右上角有「跳过」时，英文小签如果放不下就不画，免得压到按钮。
