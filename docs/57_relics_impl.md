**解读**
1. **两档都在 50–70 框内，新池不需要校准**：Ⅷ 46.4 → 50.0%（p 0.66，翻转 +14/−12 对称），标准 71.4 → 55.4%（p 0.078，翻转 +5/−14）。方向出乎预期——129 件新藏品让局面**更难**而不是更白给，标准从框上沿（71.4% 本来就略超 70）压回框中；Ⅷ 贴下沿，但 bg8-D 的 54.5% 说明 Ⅷ 的底座本身在 46–55% 之间晃，新池 50.0% 没有超出这个区间。
2. **变难的机制是稀释，不是哪件新藏品太强**：三选一里 60% 的位置被新池占了（基础 24 → 79 件、稀有 47 → 94、核心 39 → 60，核心在权重里的份额 15% → 9%），旧池核心藏品每局拿取 Ⅷ 2.64 → 1.49、标准 4.45 → 1.70，藏品直伤占比 3.8 → 1.7% / 3.4 → 1.8%；掉得最狠的是镶金骨骰 0.41 → 0.12、羽兽肝酱 0.27 → 0.05、高闪相机 0.20 → 0.02、损坏的左轮弹巢 0.20 → 0.02（每局）。前 5 分钟等级 / 击杀 / 灯火两组逐点相同（15.2 对 15.4 级、1748 对 1742 杀），差别全在 7 分钟以后：终局击杀 −104 / −286，等级 −0.1 / −0.7，承伤/分 +8 / +12，死亡分钟的峰从 7 分挪到 8–10 分（标准 10+ 分死亡 5 → 9）。即机器人拿到的藏品件数一样多，含金量低了，后期打不动。
3. **标准掉的 9 胜集中在深蓝结局**：按结局拆，standard 9/12 → 12/16、knight 8/13 → 8/18、resolve 5/5 → 2/3，deep 18/26 → 9/19（69 → 47%）。F 流派（深蓝·低灯火）每局拿取 0.32 → 0.12（新池只有 2 件 F，而通用件从 66 → 121），走深蓝线的局更难凑齐低灯火配套。Ⅷ 的 deep 8/18 → 18/33 没有这个现象。
4. **死因里腐蚀（corrode）份额涨了**：Ⅷ 3/25 → 14/44（12 → 32%），标准 0/16 → 6/25——死亡时间后移、后期接潮系精英 / Boss 在场的局多了（Boss 在场死亡 18/25 → 27/44、7/16 → 13/25），不是新藏品直接造成；但若下一轮要动腐蚀抗性类藏品的权重，这是基线。
5. **#103 安洁莉娜的创想是唯一值得盯的单件**：稀有、C 流派，两档合计拿 29 局胜 24（83%），取率 74% / 38%，效果是全局敌人移速 −15%（Boss 除外）——与 #230 的移速部分叠加可到 −30%，机器人一旦拿到就明显好风筝。眼下它抬胜率、不是问题；它是新池里少数会把胜率**往上**推的件，将来若新池整体往上偏，先看它。#25 万能钥匙（+18 源石锭、基础、通用）是典型的占位废卡（标准 7 局 29%），同类一次性资源件（夜阳草例外）在 6:00 后已有 `late_weight` 降权，可以考虑把它们的 `late_weight` 再压。

**建议**
- **不校准**：两档都在框内；收紧与放松都不动。Ⅷ 50.0% 贴下沿是底座本身的位置（bg8-D 54.5%、rp-x-np0 46.4%），不是新池造成的。
- **若后续 Ⅷ 复测跌破 50**（例如下一轮灯标 edge 改动的基线里），最便宜、不碰敌人数值、也不白送玩家的一刀是**恢复池子的稀有度配比**，而不是削某件新藏品：`progression.gd relic_pool_ids` 的稀有度权重按件数归一（基础 60 → 60 × 24/79 ≈ 18、稀有 26 → 26 × 47/94 = 13、核心 12 → 12 × 39/60 ≈ 8），让每档稀有度在三选一里的份额回到旧池水平——这只改「出现什么」，不改任何一件的数值，同 seed 结果会分叉。做成 `balance.json relic/rarity_w_*` 旋钮再 A/B，不直接改常数。
- 标准 71.4 → 55.4% 这一步不追：旧池的 71.4% 是 seed 5–8 偏好（seed 1–4 为 61%），新池 seed 1–4 与 bg-t0-D 持平；要确认再跑 seed 9–16 的 56 局（新旧池各一份）。
- 解析脚本仍是一次性 python（scratchpad `np_analyze.py` / `np_more.py`，复用 docs/56 的配对 / 符号检验 / 两比例函数）；藏品拿取榜用的是记录里现成的 `relic_take` / `relic_offer` 字段，不需要 `--keep`。下次同格式再跑时与 docs/56 §7 的建议一样沉淀到 tools/。
