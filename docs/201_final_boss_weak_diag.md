# 201 最终 Boss「太弱」诊断与加伤（10-29）

用户实测 Boss 试炼（成品分队）：「boss 太弱了，攻击频次低，弹幕少并且慢，并且一直在播放受击动画，现在就是个沙包」。
协调人转用户 10-29 决定：最终 Boss 加伤、血量不动；普通一发约最大生命 12–15%（10:00 队长约 157 血 → 约 20–24），重招 25–35%；与「敌弹只按弹芯判定」（claude/bullet-core-hit）配套。

基线 claude/integ-1029 bfa2bcd07，分支 claude/final-boss-dmg。测量用临时探针 `game/scripts/run/boss_diag.gd`（`--bossdiag`，只统计不改玩法；在 a7e514a31 / 9db987b21 里，正式提交已删）。
数据与脚本在 `docs/201_data/`：`run_diag.py`（trial = 试炼 + 机器人 expert；idle = 试炼 + afk 机器人，队长不动吃满每一招；normal = 正常局打到 10:00）、`agg_diag.py`、`agg_dmg.py`。
复跑要先 `git show a7e514a31` 把探针取回来。云端结果：`cloud-results/final-boss-dmg-before` / `-after`。

## 1. 根因

1. **受击动画不打断出招**：四只 Boss 的眩晕 / 封印时间都是 0；Boss 出招只被自己的破绽（16–32%）和卡点停留挡。「一直在播受击动画」是画面问题：每次命中都触发受击抖动（fx/boss_shake_px 4、只隔 0.1 秒，4c8c10a08 加的）。试炼里没有杂兵分火，每秒约 10 下命中，Boss 31–39% 的时间在抖（正常局 12–16%）。白闪已经限频（9–11%）。
2. **试炼没有额外节流，也不偏强**：试炼和正常局 10:00 的 Boss 出招数、弹数、弹速基本一样。试炼只是不跑 spawner / endg（没有杂兵），场上只剩 Boss 的弹。成品分队取的是测试台到场中位快照：等级 24–26、队长最大生命 115–186、藏品 7–14；正常局 10:00 是等级 26–27、161–250 血、藏品 12–21。
3. **真正偏弱的是设计值**：
   - 新弹 1.8–5.7 发 / 秒，弹速 120–180。
   - 单发伤害也低。实测未减伤的普通一发只有 3.7–6.6（协调人估的 11–13.5 偏高），护甲后约为最大生命的 2–4%。
   - 机器人打试炼时，按承伤速率打死队长要 2–28 分钟。

## 5. 没改、建议下一步（要用户 / 各 Boss 会话定）

- **伊祖米克**：加伤后机器人打试炼仍要 7 分钟才打死队长。它每分钟只有 7–10 个有伤招，机器人每分钟只被打中 1.3 下。问题在出招密度，不在伤害，建议伊祖米克会话加招式频率（加难）。
- **弹速**：伊莎玛拉 105–120、骑士 135–160，偏慢。配合判定改按弹芯以后，可以考虑提到 150–200（加难，影响图案几何，要各 Boss 会话自己调）。
- **试炼没有杂兵**：这是设计。想让试炼更接近正常局，可以在试炼里打开 final/escort 小怪（改试炼规则）。
- 不跑整局校准（等终结技落地后统一校准）；胜率会因加伤下降，留给那次校准。

## 9. 第五批：Boss 弹判定放大 + 对齐画面 + 泡影 / 骑士加层（用户 10-30「判定范围可以做大一点」「多几层、全方位一点，但要给预警；子弹略放慢」，claude/bullet-hitbox）
