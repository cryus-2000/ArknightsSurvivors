## 5. 要用户定的对位口径

1. **原作 5 层 ↔ 本作 5 次翻卡**：途中一 = Ⅰ、途中二 = Ⅱ、路口一 = Ⅲ、途中三 = Ⅳ、路口二 = Ⅴ。事件按原作 `floor` 只在对应的翻卡里出。数量刚好一一对应，建议照这个做。
2. **「希望」怎么折算 → 照水月现行口径，不另定**（docs/154 §3、docs/184 §4 折算口径）：希望 → 源石锭；进阶券 → 一名干员精英化一级；招募券 / 调度函 → 一次招募；掷骰 → 概率或源石锭。水月实例：得 +2 希望 → 源石锭 +10（狂徒妄念「沉默」；残存微光「攀谈」+10，docs/184 §10 后压到 +6），得 +3 希望 → 源石锭 +8（紧急调遣），即**得 1 希望 ≈ 源石锭 3–5**；付「N 希望及等量上限」→ 队长最大生命 −5% × N（狂徒妄念「愤怒」付 2 → −10%）。傀影照搬。
3. **幕间余兴**：作为第 7 种翻卡卡种加进傀影主题的卡组（权重和诡意行商同档 15），同意吗？
4. **「目标生命」代价按水月现行（docs/184）口径**：得目标生命 → 回复 / 最大生命 +%（+3 ≈ +5%，安全屋原作 +3 上限 → 最大生命 +5%）；付目标生命 → 队长生命 −%。docs/154 初版按 −1 ≈ −5%，docs/184 嫌代价太轻改重（观潮者 −1 目标生命：−5% → −15%；苦路 −2 → −12%；相逢 −3 → −15%），现行大约**每点 −6%、单项至少 −10%**。待用户确认傀影用现行口径。

**11-17 用户定**：§5 四条全部照推荐——5 层对 5 次翻卡；希望、目标生命按水月现行口径；幕间余兴做成傀影第 7 种翻卡卡种。
