## 5. 要用户定的对位口径

1. **原作 5 层 ↔ 本作 5 次翻卡**：途中一 = Ⅰ、途中二 = Ⅱ、路口一 = Ⅲ、途中三 = Ⅳ、路口二 = Ⅴ。事件按原作 `floor` 只在对应的翻卡里出。数量刚好一一对应，建议照这个做。
2. **「希望」怎么折算**：本作没有希望。原作希望用于招募 / 进阶干员。候选：
   - (a) 希望 → 源石锭（1 希望 ≈ 5 源石锭；docs/358 草案写的 −1 希望 = −10 源石锭偏重）；
   - (b) 傀影主题新加一个「希望」计数，用来抵招募 / 精英化（等于把原作资源搬进来，进主题机制槽位 S1）；
   - 推荐 (a)，不加新资源（docs/359 §6「不新建货币」）。
3. **幕间余兴**：作为第 7 种翻卡卡种加进傀影主题的卡组（权重和诡意行商同档 15），同意吗？
4. **「目标生命」**：沿用 docs/154 的折算（目标生命 +3 ≈ 回复 / 最大生命 +5%，代价 −1 目标生命 ≈ 队长生命 −5%）。docs/184 后来把代价口径整体调重过（例如 −5% 改 −15%），傀影要不要同样调重？
