# 分支成长节点卡面写两条路线（11-07）

用户原话：「成长节点这里我说的还有一点是卡面上的文字只描述了第一个效果，但是点进去是两个分支，我觉得这个描述得修改啊，而且所有干员都有这个问题」。

## 原因

20 名干员的第 4 个成长节点都是二选一的分支节点。外层先出一张卡，选中后再进入二选一。这张外层卡以前有两个问题：

- **标题**用的是节点名，而节点名就是第一条路线的名字，比如「浊心斯卡蒂 · 潮汐和声」。
- **说明**：手机卡和电脑上的干员卡都只写一句话（`choice_panel.brief`），截到 `branch_desc` 的第一个「；」为止，所以只剩第一条路线。

## 改法

改在 `character.gd`：`deep_cards` 的分支分支，加上新函数 `branch_lines`。

- **标题**：「<干员> · 选择成长路线」。
- **卡面一句话**（brief）：两行，每条路线一行「「路线名」：一句效果」。
  - 每行的文字从 `branch_desc` 按「；」切段，段首是路线名的那段就归这条路线，开头的「使」去掉。
  - 对不上、或没写 `branch_desc` 时，取这条路线自己说明的第一句兜底。
  - 卡面上每条效果超过 16 个字时，压到第一个「，」之前；压完还超过 18 个字的，就各自截断并加「…」。这样两条路线各占一半版面，手机上第二条不会被整段挤掉。完整的那句在详情里看。
  - 字数按显示长度算：数值占位 `{$key}` 当 2 个字，截断时也不会切开它。
- **完整说明**（悬停 / 详情）：上面两行，加一行「选定后，之后的节点沿该路线强化」和节点攻击加成，有条件的话再写条件。
- 选中后的二选一不变：两张卡各写自己完整的说明。

## 清点

`python tools/branch_card_audit.py` 会列出全部分支节点，对照以前和现在的卡面。规则和 `branch_lines` 相同。

截图时用了 `--prog=3`，需要它不再播精英化全屏演出：那段演出内嵌一局演示游戏，会读到同一组截图参数，把 540×300 的演示画面存成截图。所以 `run_setup` 里在 `--prog` 后面清空 `show_queue`，只对开发参数生效。

结果：20 个节点都写了 `branch_desc`，也都按路线名对上了，没有一个用到兜底。
