## 2. 圆盘方案（定稿：终末地蓝）

第一版出了三套配色（a 工业黄暗底 / b 白色终端浅底 / c 本作 HUD 青），用户看 a 之后定：**黄换蓝 + 多叠层次 + 加动效**。b / c 未再出图，代码已删。

### 2.1 颜色

| 用途 | 色值 | 说明 |
|---|---|---|
| 强调（选中块、指针、刻度游标、斜纹高亮、「当前」） | 终末地蓝 #1FA8F0 `C_ACC` | 取个人页的天蓝；和 HUD 的青 #36E2DC 同属冷色、色相不同，圆盘一眼看得出是另一层 |
| 选中块外沿亮带 | #7DD1FA `C_ACC_HI` | |
| 蓝底上的字 / 图标 | 深墨蓝 #08121C `C_INK` | 白字在这档蓝上对比只有约 2.6，深字约 7 |
| 底盘 / 中心外圈 | #0E0F11 | |
| 扇区外层 / 内层 | #1E1F21 / #141517 | 内层是靠圆心 24 % 深度那一圈 |
| 细线 / 正文 / 刻度 | #9EA1A6 / #F0F0ED / #DBDEE0 | |
| 各项的属性色条 | 沿用 `ITEMS[i].col` | 扇区内沿一道 3 px 弧，呼应规则 5 |

不用黄（docs/37：警示黄只给图鉴）；`UI.PURPLE` 未碰。

### 2.2 层次（从下往上）

1. 全屏压暗 50 %。
2. **底盘**：一个比刻度环略大的暗色圆 + 细边；扇区外沿再一圈极淡细环。
3. **取景框**：四角 L 形角标；上下两段竖准线。
4. **刻度环**：一圈细环，细刻度每 5° 一根（慢转），扇区分界每 60° 一根长刻度（不动）。
5. **斜纹带**：扇区外沿与刻度环之间一圈 `//////` 短斜线；悬停项那一段描蓝。
6. **分组线**：从 0° / 180° 两条缝里穿过的水平细线，末端蓝色小方块；左侧标「队形 / FORMATION」（上半圈）与「索敌 / TARGETING」（下半圈）。
7. **扇区**（五块：上半圈三块各 60°、下半圈「清杂优先 / Boss 优先」两块各 90°（10-24 去掉「就近」，docs/114 §13.2）；外沿两角切角 9 px，块间留缝；中心角 `ANG`、半宽 `HALF`）：投影（下移 4 px、黑 40 %）→ 外层 → 内层 → 顶边 1 px 高光 → 内沿属性色条 → 1 px 细边；内容：中文名 17 号 + `0N // ENGLISH` 9 号压缩字，居扇区中部（原有的程序画线性图标 10-24 用户定去掉，图标函数已删）。
8. **选中块**：蓝色整块（从内往外推满）+ 外沿 12 % 亮带 + **外推虚框**（扇区外 30 % 的轮廓往外推 9 px，蓝色细线）+ 蓝色粗边；扇区整体外移 6 px；字换深墨蓝。
9. **当前**：黑底蓝字「当前」小标签，左端一道蓝条，放在英文行下方。
10. **指针游标**：刻度环上一段 22° 的蓝色粗弧 + 环外一个蓝色小三角，指向悬停项。
11. **中心**：外圈暗盘 + 反向慢转的刻度圈 + 内圆 + 四段断开的蓝色细弧 + 朝悬停方向的一段蓝色粗弧；文字「指挥」/ 悬停项名字（蓝，18 号）/ `COMMAND`。
12. **底部说明板**：圆盘下方一块暗底板（左端蓝条、底边细线），上行是悬停项说明，下行是操作提示；底板顺带盖住开局操作提示等底部 HUD 字（之前会叠字）。

### 2.3 动效（真实秒；圆盘打开时局内放慢 0.2，动效不受影响）

| 时机 | 动作 | 时长 |
|---|---|---|
| 打开 | 整体淡入；底盘 0.9 → 1 放大；刻度环从正上方顺时针画开；五块扇区按顺时针错开 0.025 秒、从里往外推 18 px 淡入；取景框从外往里收 16 px | 0.12 / 0.18 / 0.22 / 每块 0.14 / 0.2 |
| 常驻 | 细刻度顺时针 4°/秒、中心刻度圈逆时针 8°/秒、斜纹带往前走 3°/秒 | 持续 |
| 换悬停 | 蓝色从内沿推到外沿（out_cubic）；外推虚框 out_back(1.4) 推出；指针游标沿环滑过去（指数逼近，约 0.1 秒到位）；中心名字与底部说明上浮 6 px 淡入 | 0.09 / 0.16 / ~0.1 / 0.12 |
| 确认 / 取消 | 整盘淡出；确认的那块虚框继续外扩 26 px 淡出（取消则没有留影） | 0.16 |

- **不闪**：没有任何明暗脉动、白闪、颜色往返；所有变化都是单向缓动到终态。转动只有细刻度和斜纹（低透明度，每秒几度）。
- **减少动态效果**（设置「减少动态效果」/ `Cfg.reduce_motion`）：只保留 0.12 秒整体淡入；底盘 / 刻度环 / 扇区 / 取景框直接到位，刻度与斜纹不转不走，选中直接满块、虚框直接在终点，指针直接跳到悬停项，没有收起动画。终态与正常模式只差转动部件的角度（桌面截图对比：仅刻度 / 斜纹位置不同）。

### 2.4 手机

- 尺寸沿用原来的 `_k()`（按 UI 逻辑短边 / 600，0.62–1.1）与点选判定 `_hit()`，扇区大小、可点范围不变；字号经 `UI.fs` 在手机横屏放大 1.18 倍。
- 1560×720（19.5:9）截图：名字 / 英文 / 「当前」标签互不重叠，左侧分组字不出屏，底部说明板在屏内。

## 3. 只用在圆盘，还是延伸到别处（建议，未改别的界面）

- **建议只用在圆盘**（以及以后同类的「局内临时指令层」，比如若再加快捷指令）。理由：局内 HUD 是 docs/37 水月方案 A（炭灰平面 + 青），标题 / 局外是 T5s 深海水母方向，图鉴是 C4′、选人是 B+；圆盘是盖在 HUD 上、放慢时间的一层，用另一套视觉语言反而让玩家明确「现在在下指令」。
- 圆盘和 HUD 的协调点：冷色、暗底、细线、压缩英文小字都和方案 A 相通；蓝和青色相不同但不打架。
- 不建议延伸到 HUD 本体（会和水月 / 深海题材冲突）。如果以后要延伸，候选是「作战记录」的数据区（终末地的大数字 + 小标签 + 取景框），需要另出对照图给用户挑。
