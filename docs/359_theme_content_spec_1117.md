### 1.2 数值区间

**公式**（`balance.json enemy._doc`、`spawner.gd:1076`）：
- 普通怪生命 = 基础 × 时间曲线 × 密度换算 × 难度。时间曲线 = 1 + min(t,480)/110 + max(t−480,0)/120（0:00 → 1.0，3:00 → 2.64，5:00 → 3.73，7:00 → 4.82，9:00 → 5.86，10:00 → 6.36）。密度 k = 0.4，单只生命 ÷ k^0.75 = ×1.99；常规档 `difficulty.standard.enemy_hp` ×1.14。另有 `hp_late`（漂流体 ×3 / 狂奔者 ×2 / 滑动者 ×1.5，4:00→6:00 渐入）和前后期微调 `trim_*`。
- 普通怪伤害只走 `dmg_curve`：**池平均单发**按时间点 0:00 12 → 3:00 19 → 5:00 23 → 7:00 27 → 10:00 32.6（`balance.json dmg_curve.knots`），`norm_full 1` 会把每个阶段的池平均归一到这条线。**换主题后伤害自动对齐，生命不会**——新主题要自己把「池平均基础生命」对齐 §1.3 的表。
- 精英 = 普通公式 × 生命 7 / 伤害 1.3 / 经验 10（`enemy.elite_hp_mult / elite_dmg_mult / elite_xp_mult`），**不吃密度换算**。
- Boss 生命 = 基础 × (1 + t/600) × 中期 2.1 或最终 2.0 × `hp_x_<id>` × 难度（`boss.hp_mid / hp_final`）。

### 1.4 精英词缀与精英小队

- **后期词缀**（`spawner.gd:183 roll_affix`）：普通怪从 7:00（`enemy.affix_start 420`）起按概率带一条，3 分钟内涨到 35%：**甲壳**（非真伤 ×0.75）/ **潮盾**（额外护盾 = 30% 最大生命），各半。词缀名归主题（「潮盾」要换名），机制通用。
- **精英小队 = 紧急作战卡**（`waves.json cross_deck._squad`）：按时间（<4:40 / <8:40 / 之后）从高一阶普通怪里抽 8 / 10 / 12 只，生命 ×2、伤害 ×1.3，全队共用一个词缀，红色描边；全灭给主流派三选一宝箱 + 源石锭 20。

### 1.5 同屏上限与密度

- 同屏敌人上限 120（`enemy.max_alive 300 × density 0.4`，11-16 用户定不分画质），到上限普通刷怪作废，大群可超 60。
- 密度 0.4、单只伤害 ×(1/k)^0.5、单只生命 ×(1/k)^0.75、体型判定 ×1.5（memory `density-decision`）；7–10 分钟同屏普通怪中位约 60。
- 中期 Boss 在场：刷怪 ×0.5、存活上限 ×0.6、本级新种权重 ×0.5、刷出的杂兵伤害 ×0.5；最终 Boss 在场：停刷，只留机制召唤和护卫波（`spawn._mid_boss`、`final._doc`）。
- 同种上限：凿石者 6 / 8 / 12，拟嗣、喷吐者 6，子代 6 / 10（`spawner.gd:120 type_cap`）；高阶 `cap × threat.cap_mult`（2 / 3 / 5）。

**标准**：照抄（这些是全局旋钮，不归主题）。新主题的远程 / 召唤型普通怪必须写 `cap`。

### 2.3 通用硬规则（摘自 docs/38 §1.3 / §1.9 / §1.10、`balance.json boss`）

- **卡点**：中期 50% 两幕；最终 66% + 第二道（或回涨 / 变身）。过卡点无敌 0.8 秒、清掉瞄准队长的预警、0.8 秒内不出新招；最终 Boss 每过一道掉 1 回复 + 1 灯油（新主题换成本主题的资源）。
- **阶段护盾 ≤3 秒**：中间卡点最多撑 3 秒（`gate_hold_max`）；最后一幕停在 3%，最多撑 3 秒，碎时直接倒下（`last_hold_max 3`、`last_auto_kill 1`）。
- **预警**：总时长 ≥0.6 秒；可走躲锁定窗口 ≥（半宽或半径 + 12）÷ 105 + 0.1 秒；连发间隔 ≥0.6 秒；追踪落点半径 ≤45；缺口弧长 ≥80px、扩散 ≤220px/s、缺口提前 ≥0.8 秒画出；全场·必须冲刺两次间隔 ≥2.0 秒，卡点后 1.2 秒内不出；激光蓄力 ×0.65 但 ≥0.6 秒（`laser_tell_k / laser_tell_min`）。
- **不弹提示**：战斗中不弹喊话和机制字（只留骑士撞柱「眩晕」）；最终 Boss 破绽用脚下金环 + 倒计时弧，不写字（`break_text_final 0`）；第一次登场副标题一句教主轴（3 秒，按存档只出一次）。
- **专属色**：只改 Boss 弹芯和预警填充；保留色 Boss 不用：小怪青蓝 194°、预警洋红 340°、主轴目标金 45°、倒计时青 175°、灯火橙 27°。每幕同色系变明暗，色相不跳。
- **伤害保护**：单发 ≤ 队长最大生命 40%（`leader_hit_cap`）、2 秒合计 ≤68%（`leader_2s_cap`）；设计预算：一场 Boss 战承伤 − 回复 ≤ 最大生命 60%（命中率按可走躲 30% / 必须冲刺 40% / 连发每发 30%）。最终 Boss 一发约 12–15%、重招 25–35%（`_final_bullet_x`）。
- **读图预算**：同时最多 1 个大预警 + 1 个目标物；每幕新元素中期 1 个、最终 ≤2 个；Boss 溟痕 ≤12 块等持续地形上限。
- **弹速三档**（最终 Boss）：读图案约 210、普通约 280、快弹约 380，加速弹封顶 520（`spd_all_k_*`、`spd_cap`）；弹体可见半径 9 / 12 / 15–16 三档（`bullet_r_min`）。
- **最终 Boss 弹幕加层**：每颗弹追加 1 层、奇数层转背面（`layer_n_* / layer_omni_*`）。

### 3.4 结局线入口与信物规则（docs/154 §2.3 / §4）

- 入口卡只在通关结局一后出现；路口一放 2 张必出入口卡（三条线在路口一互斥），路口二最多 1 张必出续卡。

- **标准**：结局线数 = 最终 Boss 数 − 1（缺省结局不需要信物）；每条线 1–3 件信物；入口卡全部放在路口一，续卡放在路口二。

## 6. 主题机制槽位

水月四套机制按「玩法定位」抽象成 4 个槽位，新主题逐槽对位（可以留空，留空时核心循环走「无此机制」的缺省）：

|---|---|---|---|---|

| **S2 地形** | 溟痕 | 区域：神经损伤的地面来源（memory `design-pillars`：负面状态只留神经损伤）；100 秒首片，16–24 秒一片，半径 70–110，上限 24 片；灯火高时退散、低时逼近 | 场上常驻 3–24 片 | `update / arena 绘制 / bot_hint` |
| **S3 边界** | 黑潮缩圈 | 计时 + 区域：逐步缩场，最终 Boss 冻结场地半径 520（`boss/arena_r`） | 全程 1 套 | `arena_clamp / arena_dir` |
| **S4 场上目标** | 引航灯标 | 小目标：每 60–75 秒在 250–400 外出现，点亮给灯火 +20 和增益 | 一局约 8 次 | `update / on_kill / bot_hint / hud_bars` |

**标准**：
- 必须有 S3（场地边界，否则世界无限、最终 Boss 冻结无从谈起）。S3 可以只换外观、复用缩圈规则。
- S1 / S2 / S4 至少填 1 个，最多 3 个；新机制先答 memory `design-pillars` 的四问（服务哪条支柱 / 多了什么决定 / 一局几次 / 替代了什么）。
- 机制里给资源的，数值按源石锭 / 经验口径折算，不新建货币。
- 机器人必须会（`core/bot.gd`），否则批跑无效（docs/357 §6.4）。
- 藏品、事件、Boss 卡点奖励、HUD、配乐里所有读 S1 的地方，在无 S1 的主题要有缺省（不显示、不掉落）。

## 9. 难度与节奏目标

- **胜率**（memory `difficulty`）：常规档 无认知 45–55%、18 细胞 65–75%；满点 93–100% 可接受；高压 / 深潮看相对常规的间距。按 ≥3 份 112 局独立均值判，**胜率差 <10 点不下结论**（docs/80）；结论看胜率 + 低血秒 + Boss 用时三样。
- **收紧只用不给奖励的旋钮**（伤害、控制、预警、`hp_x / dmg_x`），不削奖励、不改全局曲线。
- **一局 10 分钟的压力曲线**（水月实测与规则）：

| 段 | 时间 | 压力来源 | 设计意图 |
|---|---|---|---|
| 开局 | 0:00–1:00 | 杂兵、首个途中卡 0:55 | 选人、熟悉；前 3 分钟普通怪生命 / 伤害 ×1.08（`trim_early`） |
| 构筑 | 1:00–3:30 | 首只精英 1:00，精英每 45–55 秒，大群每 85–90 秒，商人 2:00 | 拿第一批藏品，打出构筑方向 |
| 第一个中期 Boss | 3:30 | 60–90 秒，刷怪 ×0.5 | 第一次「读招」 |
| 中段波峰 | 3:45–6:40 | 固定大群 3:45 / 5:00 / 6:15，4:40 换池进高阶；**死亡集中 4–7 分钟（卡门段）** | 构筑检验；伤害曲线 3:00 起按 `relief` 平滑 |
| 第二个中期 Boss | 7:00 | 可能双体，后期词缀 7:00 起 | 第二次检验，路口二选结局续卡 |
| 冲刺段 | 7:00–9:00 | 精英每 32–38 秒，大群每 60–70 秒，8:00 商人后不翻卡 | 割草爽感最强段（构筑成型 = 割得最爽，memory `design-pillars`） |
| 终局预告 | 9:00 | 冻结结局走向 | 一句预告 |
| 最终 Boss | 10:00 起 85–95 秒 | 停刷，弹幕紧张集中在这里 | 全局唯一的弹幕高潮（memory `boss-design`） |

**标准**：新主题保持这条时间轴（时间点和伤害曲线照抄），主题之间的差异放在「压力是什么样子」（机制、怪的读招、Boss 主轴），不放在「什么时候难」。

## 11. 口径备注与待定

1. 招式计数口径：本文「命名招式」= 脚本里有名字、玩家要躲的攻击，含连段新增；docs/165 的「主动攻击」只数基础 + 补充（泡影 7 / 骑士 8 / 伊莎玛拉 7 / 伊祖米克 7），所以两个数字不同。标准里「最少 7」用 docs/165 口径，「推荐 12–20」用本文口径。
2. §1.2 有效生命表没乘 `hp_late`、`trim_*`、`tier_hp`（裂隙后高阶 ×0.42–0.5），只作量级；精确值以 `gallery.gd:570` 的图鉴算法为准。
3. 中期 Boss 用时目标在文档里有两版（docs/38 §1.1 的 25–40 秒、10-31 用户更正的 60–90 秒），本文取后者（`balance.json boss._buff_1101 / _boss_buff_1031`）。
4. 事件普通池：docs/184 §2.5 写「13 件」是 events_v2 新池的数，加上保留的 8 件旧事件，数据里实际 21 件 `pool=common`。
