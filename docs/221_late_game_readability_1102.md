## 1. 方法

- **对局**：seed 13（`tools/late_clutter.py` 用的那一局）、熟练机器人、`--nodeath`。录像用 `--realtime --fixed-fps 30`，跟 Boss 演出走同一时钟。开局给藏品 1（编队上限 +1），机器人自己招第 4 人。
  - A 组：德克萨斯（队长）/ 能天使 / 拉普兰德。羁绊有企鹅物流、宿敌；第 4 人自然招到流明或归溟幽灵鲨。
  - B 组：斯卡蒂（队长）/ 乌尔比安 / 歌蕾蒂娅。羁绊有深海猎人「群猎」；第 4 人招到凯尔希。
  - 编队上限是 4（3 + 藏品 1），召唤物另算。所以「4–6 人满编」按 4 人测。
- **录像窗口**：
  - 7:05–7:35：中期 Boss 第二只，卡门 / 伊比利亚 / 塑路者；
  - 8:50–9:10：后期满屏；
  - 10:05–10:40：最终 Boss 偏执泡影；
  - 9:56–10:12：A 组羁绊连携、精英、最终 Boss 登场、终结技在 3 秒内同时出现，专门补录。
- **分辨率**：电脑 1920×1080；手机横屏 1170×540（`--touch`）；手机竖屏 540×1170（只录了最终 Boss 一段）。
- **计数**：用 autotest 现有的 `_clutter_log` 字段，每 0.5 秒记一份：屏上敌人、友方世界特效 + 干员粒子、屏上敌弹、预警、飘字、拥挤度。
- **像素占比**：同 seed 分层重跑，每秒取 1 帧比较。同 seed 各层的局面逐帧一致：71/71、61/61、41/41 份记录的敌人数和队长屏幕位置都相同。
  - 友方特效占屏：完整画面对比 `--clutterdbg=nofriend`，差异像素占世界区的比例。nofriend 只把透明度置 0，画面随机数照抽，所以是干净的。
  - 敌方层：`nofriend` 对比 `nofriend,nofoe`。不能直接用完整画面对比 `nofoe`：nofoe 会跳过整段绘制调用，画面随机数错位，友方颗粒会挪位，结果被高估约 3–4 个百分点。
  - 「敌方被友方改色」：敌方像素里同时被友方特效改了颜色的比例。
  - 「队长周围」：队长屏幕坐标半径约 46 画布像素内，被友方特效改色的比例。
  - 界面占屏：完整画面对比 `--nohud`，取各帧掩码的中位。
- **事件时间**：在终结技放出、连携亮起、羁绊挑人、升级、横幅几处临时加了 print，单独跑一遍取时间。这些 print 和录像时每秒记一份的探针都**没有提交**，已经还原。

## 3. 清单

### ① 画面乱

**L1 队长被友方特效整团盖住（高）**
- 截图：`01_L1_leader_hidden_phone.png`。手机 10:07，红色锯齿环是友方特效，去掉友方特效后整队清清楚楚。
- 队长周围被友方改色：平均 7–29%，峰值 37–54%。
- 推荐（不降队友）：**被盖时画队长剪影**。
  - 队长本体之上再画一遍队长轮廓，用 1 像素暖白描边 + 低透明填充，只在队长周围友方特效像素多的时候出现。
  - 同时可选：队长脚下常亮一圈细环。docs/139 §11 的 `lead_dir` 方向弧可以复用。
- 代价：低–中。在 `world._draw_fx` 之后、加色层之前加一遍；判断「被盖」用队长附近的友方特效数近似，不读像素。同 seed TRACE 不变。

**L2 敌弹 / 预警被友方特效改色（高）**
- 截图：
  - `02_L2_foe_tinted_9min.png`：青色是敌方层，黄色是友方特效，红色是被友方改色的敌方像素；
  - `03_L2_foe_tinted_final_boss.png`。
- 原因在代码里能看到：
  - 世界画布里，敌弹（`_draw_ebullets_lobs_shocks`）确实画在友方 `_draw_fx` 之后；
  - 但友方**加色层** `g.fx_add` 是 game 节点下另挂的子节点，画在整个世界画布之后，它包括队伍加色特效、柔光和友方帧条（`vfx.draw_add_layer`）；
  - **光学辉光层**是 CanvasLayer 1（`render/optical.gd`），也在世界之上；
  - **Boss 地面预警填充**（`_draw_warns_auras`）画在实体和友方特效之下。
- 推荐（不降队友，对应「敌弹与预警恒在最上层」）：
  - 敌弹、Boss 弹拖尾、预警轮廓（`_draw_tells_outlines`）挪到一个独立的顶层节点，放在 `fx_add` 和光学辉光层之上；
  - 地面预警填充保持在下层，只把轮廓提上去。
  - 不加描边：用户 10-24 说描边丑，见 docs/139 §11.1。
- 代价：中。要改绘制挂载顺序，光学低分辨率层（`VIS_LO`）也要跟着处理。需要量一遍帧时间，同 seed TRACE 不变。

**L3 全队特效预算（中）**
- 现状：
  - 同屏友方特效平均 90–125 个，峰值 165–294（A 组 10:05）。
  - 唯一的控制是拥挤降噪 `render/declutter` 3 档：友方特效超过 50 个开始按拥挤度压透明度，队友另乘到 0.5。实测拥挤度平均只有 0.2–0.4，所以平时只压到约 0.8。
- 协调人的思路里有「队友淡一档」。但用户 10-25 明确说过「队友特效不要降，想其它办法」（docs/139 §10，已撤销过一次）。所以**不推荐**降透明度。
- 例外：docs/220 维什戴尔单人收特效里有「当队友再降一档」（`fx/wd_mate_a` 0.6），那份还在等用户看对照。用户对那一项的态度，可以当作这里的参考。
- 推荐：**按人数分配的生成上限**，只砍装饰件，不碰透明度。照 docs/220 维什戴尔 `wd_pfx_cap` 的做法：
  - 全队装饰粒子上限 `fx/team_pfx_cap`，例如 160；
  - 每名干员按「上限 ÷ 在场人数」分额度，超额时跳过新的纯装饰件（拖尾余烬、命中火花、残光）；
  - 判定、预警、召唤物出入场、状态提示照常画。
  - 平时每人 16–33 个，低于 160 ÷ 4 = 40，所以只在峰值时起作用，是兜底。
- 代价：中。每名干员的装饰生成点都要标记「可跳过」，参照维什戴尔那次要逐人过一遍。建议排在 L1、L2 之后，先看 L2 做完还乱不乱。
- **要用户定**：做不做兜底上限；「队友淡一档」是否仍然不考虑。

已排除：最终 Boss 偏执泡影身上一团白光，看起来像被友方命中光盖住。去掉友方特效后它还在，是 Boss 自己阶段护盾的画法，不在本清单内。

### ③ 羁绊状态局中不可见

**B1 羁绊成立情况与加成没有常驻显示（中）**
- 现状（docs/217 §4）：羁绊只出现在选人页、招募卡标签、图鉴和「出手那一下」的提示里。局中想知道「我现在有几条羁绊、给了什么」，只能等它触发。
- 常驻加成（`link/bond_buff`，如企鹅物流全队攻速 +8%、宿敌对精英伤害 +10%）在局中没有任何地方显示。录像里两组都成立了羁绊，HUD 上一直看不到。
- 推荐方案 A（最省）：
  - 左上队友名单行（「能天使 / 拉普兰德 / 流明」那三行生命条）的名字前加一个 6–8 像素的羁绊色小菱形，标出谁和队长有羁绊；
  - 右下「编队 4 / 4」旁加一个小徽记「羁绊 2」；
  - 电脑悬停、手机在暂停 →「属性」页里展开，每条一行：羁绊名、搭档、常驻加成（文字直接用 `link_bond.buff_text`）、合击名。
- 方案 B：右下编队卡上，有羁绊的两张卡之间画一条细连线。
  - 更直观，但编队卡在手机上已经很挤（P1），而且换队长时连线要重画。
- 推荐 A。
- 代价：低–中。数据现成（`link_bond.formed / of / buff_text`），文案按 docs/76。
