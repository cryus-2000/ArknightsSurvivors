## 1. V1 受伤红边按「最近 1 秒承伤」驱动
- `combat.gd hurt()`：开关开时不再「每次受击拉满 0.6–1.0」，改为把实际扣血记进 1 秒窗口，`承伤 ÷ 最大生命`：
  - 低于 `v1_thr` 3%：只给一个很淡的脉冲（`hurt_vignette` 0.12），全屏薄红 / 红边光（`red_flash`）不出；

- 低血心跳边光（生命 < 30%）、灯火寂灭边光不动——那是「危险」。
- **新发现：后期整帧红像素的大头不是受伤红边。** 开关开 / 关两边红边几乎一样（§8 表），逐像素看是安全区收缩开始后屏幕四周的黑潮 / 安全区外色调（3:00「安全区收缩中」起就有，`optical_col_horde_h` = 1.0 正红）。docs/243 §6 把它算成了受伤红边。V1 只能去掉受伤红边那部分；要把整帧红降下来得改黑潮色（research 稿 S1「horde_h 不再偏到正红」），不在本批范围，列在 §10。

## 5. V3 降噪不压核心
- `world.update_visuals`：开时 `fx_dim`（干员脚本、核心帧条读的那个系数）恒为 1，队友 / 队长的整体透明度系数 `mate_dim` / `lead_dim` 不再压；原降噪系数挪到 `deco_dim`，只给装饰件：
  - `g.fx` 里的 spark / shard / mote / ember / trail；
  - 干员粒子里 `pfx_cappable` 的小件（光点 / 火花 / 碎片 / 光团 / 线 / 火舌 / 不循环帧条）。
- 加色层 `fx_add` 不再按拥挤压到 ×0.4（那一层是干员的核心光）；全屏辉光的拥挤削减（`bloom_cut`）分不出层，开时改为 0（`v3_bloom`），拥挤削减由装饰层自己变淡承担。
- 火花绘制预算、全队装饰粒子上限、粒子上层封顶照旧（都是装饰件）。
- `--clutterdbg=nofriend` 时两个系数都为 0，量测口径不变。

## 7. V5 特效随精英化放大
- 缩放 = 1 + `v5_k` 0.25 × (精英化 + 节点数 ÷ 4 × `v5_lv_w` 0.4)：精零 1.0–1.1、精一 1.25–1.35、精二 1.5–1.6。干员没有逐人等级，「等级档」用逐人的成长节点数。
- 只放大**主形**：
  - 干员出手时生成的 `g.fx` 帧条（`vfx.fx_sprite`，squad 更新时记下是谁放的：`spawn_op`），死亡 / 溶解 / 击杀碎散 / 结晶不放；
  - 干员自画的旋转帧条（`op_api.draw_spr_rot`）和技能帧条（`character._fx_strip`）。
  - 火星 / 碎片 / 光学补粒（`fx_burst`）按原尺寸生成，不放大；判定半径不变。
- 取整：放大后的缩放过 `vfx.int_scale`（fx_int_scale 1 = 取整到低分辨率层整数格，不小于原来取整的值）。
- **加厚**：精一起，主形先用同一帧在上下左右各错 1 格、同色 55% 垫一遍，笔画整体粗 2 格。
- **上限**：主形本来就大的（帧最长边 × 缩放 ≥ 140 世界像素，`v5_cap`）不放大不加厚；放大后超过的截到 140。第一轮没有这条时，逻各斯精二的书写环放大到 ×2 再加厚，把队长整个埋住。
