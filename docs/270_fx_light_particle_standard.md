# 270 特效光感 + 粒子感统一标准（px_plane 体检，11-05）

**结论摘要**
1. 11-05 用户看凯尔希时说「缺少光感和粒子感」，要求已做干员风格统一。本篇给 14 名已按 `fx/px_plane` 做完的干员做了一次实机体检，并把 docs/246 的口径（本色受光、核心用 `_emit`、命中加照地光、少量 Noita 颗粒）写成可量的数。只看，没改任何干员的特效。
2. 体检方法：在 GCP 上逐帧量。同一局图鉴演示（精二、定种子）跑三遍：A 正常，B 关照地光（`fx/recipe_dl=0`），C 关 emit（`fx/px_plane_emit=0`）。A−B 的亮度差就是照地光，A−C 就是发光核心辉光。颗粒和灯的数目、寿命、边长、半径、强度由探针逐帧记录。
3. 标准按四类招式分别给下限和上限（§3）：普攻命中、爆发、持续区域、治疗。表现最好的一组是斯卡蒂、星熊、歌蕾蒂娅、流明 S1、塞雷娅 S1 和逻各斯 S1，标准的数值从这组归纳出来。
4. 低于标准、需要补的有 7 人：浊心斯卡蒂、安洁莉娜、艾雅法拉（S1）、能天使、德克萨斯、凯尔希（普攻）、塞雷娅（普攻）。另有边缘 7 人，多数只是单帧量出来差一点。§5 给每人一句补法。数据是 11-05 第二版（量法修正后），第一版的 S1 数据作废。

### 量法修正（11-05 第二版，`tools/fx_audit.py` 提交见 git log）

第一版有三个问题，已修：
- **S1 没拍进去**：S1 第一次释放在演示第 33–53 帧，而第一版从第 60 帧才开始拍。星熊、逻各斯、浊心斯卡蒂、水月的 S1 截图里没有技能，其余人拍到的是第二次释放。现在改从第 30 帧拍到第 210 帧；技能事件要落在拍摄段里，否则判定表会记一项「技能入镜」不过。
- **技能灯取错了**：第一版 S1 取的是整段所有灯，被普攻小灯拉低。星熊 S1 落地那盏实际是 200 / 0.80，表里记成了 110 / 0.40。现在爆发类和 S1 取技能后 1 秒内最亮的那盏，普攻仍取每次命中的中位数。
- **挑帧偏向颗粒**：第一版的打分以新颗粒数为主，会挑到灯还没亮的那一帧。现在按照地亮度和颗粒数综合打分（见上）。
- **发光晚一帧**（11-05 第三条，推进之王 / 水月 / 浊心斯卡蒂会话查出）：发光层和照地光要晚一帧上屏，而挑出的命中帧常是出手那一帧，量不到这次命中的亮芯。现在命中帧的「照地面积」和「核心辉光」都取命中帧及其后 2 帧里的最大值，2 倍图里的热图也用取到最大值的那一帧；实机图仍是命中帧。
- **技能事件名**：水月 S1 记的是 `mz_burst`（三团大水母），没有 `skill0`。`fx_audit.py` 的 `SKILL_EV` 里可以按干员登记；新干员的 S1 如果改记了自己的事件名，也要在这里登记。

判定改由 `tools/fx_audit_sheet.py` 统一给出（`fx_audit_judge.md`），类别和上下限都写在脚本里（`CLS` / `STD`），与 §3 一致。复测时先 `fx_audit.py both`，再跑 `fx_audit_sheet.py`。

### 量的口径

| 量 | 怎么量 |
|---|---|
| 颗粒/次 | 新颗粒按「爆发簇」归并：有新颗粒或新灯的帧，前后相隔不超过 2 帧的算同一簇，即一次命中或爆点。表里给簇大小的中位数和最大值。计入 `fx_recipe` 颗粒池（Noita 材质）、`fx_grains` 模板颗粒和火星。 |
| 寿命 / 边长 | 新颗粒的平均寿命（秒，不含落地停留）和平均边长（世界像素）。 |
| 形状 | 材质名，即 `fx_recipe.MATS`：ink 水滴 4–6 px、rock 碎石 4–6、tri 三角 6–10、shard 碎晶 2–4、ember 火星 2–4、streak 火星线、twinkle 小星 2、puff 烟团。 |
| 照地灯/次、灯半径 / 强度 | 每簇新挂的灯数（`fx_recipe._light`）。普攻：灯半径、强度取整段每次命中的中位数。爆发类和 S1：取技能事件后 1 秒内最亮的那一盏（先比强度、再比半径），半径和强度都取这一盏（JSON 里 `skill_light_r / skill_light_i`）。 |
| 照地亮度峰值 / 面积 | A−B 的亮度差（0–255）：峰值取整段；面积取命中帧及其后 2 帧里亮度差大于 4 的像素数的最大值（1280×720 画面）。 |
| 发光核心 | 命中帧及其后 2 帧 A−C 辉光面积（亮度差大于 8 的像素）的最大值：≥ 30 记「有」，大于 0 记「弱」，0 记「无」。emit 点/帧取整段的 p90，上限 `EMIT_CAP` = 360。 |

## 3. 量化标准（以后新做和补做都按这个验收）

通用的四条，从 docs/246 来，这里写成数：
1. **本色受光**：色层当普通物体画，不把光晕烤进颜色。
2. **核心用 emit**：只有最亮的热芯像素进发光层。命中帧要量得出辉光，下限见下表；整段 emit p90 不顶到 360 上限（上限 300），超过就有发白、糊成一片的风险。
3. **命中加照地光**：每次命中或爆点挂一盏 0.10–0.15 秒的本人色点光，走 `fx_recipe._light` 或 `_hitlight`。
4. **少量 Noita 颗粒**：有重量、落地、会弹。平均边长 ≥ 3 px，即至少一半是 4 px 以上的大颗，2 px 颗粒只作点缀。寿命 0.7–1.0 秒（治疗、持续类 0.5–1.0 秒）。一招颗粒材质 ≤ 2 种。

| 类 | 颗粒/次 | 边长 | 照地灯 | 灯 半径 / 强度 | 照地亮度峰值 / 命中帧面积 | 核心辉光面积 | emit p90 |
|---|---|---|---|---|---|---|---|
| **普攻命中** | 3–10（中位数），单簇 ≤ 16 | ≥ 3 px | 每次 ≥ 0.9 盏（≤ 2） | 80–160 / 0.35–0.8（每次命中中位数） | ≥ +50 / ≥ 1000 px | ≥ 30 px | 40–300 |
| **爆发**（技能落点、大爆、范围斩） | 技能后 1 秒最大一簇 6–25（建议 ≤ 16） | ≥ 3 px | 每次 ≥ 1 盏（≤ 3） | 140–240 / 0.6–0.9（技能后 1 秒最亮一盏） | ≥ +65 / ≥ 1500 px | ≥ 60 px | 60–300 |
| **持续区域**（光环、领域、持续锁定） | 每跳 1–4，每秒 ≤ 12 | ≥ 3 px | 每跳 ≥ 0.5 盏 | 80–200 / 0.35–0.7 | ≥ +40 / ≥ 800 px | ≥ 20 px | 20–300 |
| **治疗** | 每次 2–6（上浮小星或水滴均可） | ≥ 2 px | 每次 ≥ 0.9 盏 | 80–160 / 0.35–0.7 | ≥ +40 / ≥ 800 px | ≥ 20 px | 20–300 |

- 本次 S1 的归类按技能说明：
  - **爆发**：斯卡蒂、星熊、艾雅法拉、推进之王、水月、安洁莉娜、歌蕾蒂娅、德克萨斯。
  - **治疗**：流明、塞雷娅、凯尔希。
  - **持续**：逻各斯（锁定持续伤害）、浊心斯卡蒂（光环）。
  - **按普攻验收**：能天使（强化弹）。
- **上限的用意**：颗粒超上限会碎；emit 顶到 360 会发白；灯半径超过 240 时一盏灯摊满半屏，反而照不出命中点（浊心斯卡蒂就是这样）。
- **参照组**：斯卡蒂、星熊、歌蕾蒂娅、流明 S1、塞雷娅 S1、逻各斯 S1。数值落在表的中段，可以照它们的写法抄：
  - 斯卡蒂普攻：每次命中约 4 颗 ink，一盏灯半径 90、强度 0.41。
  - 星熊 S1：技能后一簇 14 颗 rock / shard，最亮一盏灯半径 200、强度 0.80。
- 验收：分支做完后按 §1 跑一遍 `fx_audit.py`，再用 `fx_audit_sheet.py` 出表和 `fx_audit_judge.md`。照地面积和核心辉光只看单帧，单独这一项差一点不算失败；看整段量出来的项：颗粒数、颗粒边长、照地灯/次、灯半径 / 强度、emit 量。

## 5. 低于标准的名单与补法（不改代码，供各干员会话补）

- **低于标准**：同一招 ≥ 2 项不过，或整段量出来的核心项（颗粒数、颗粒边长、照地灯/次、emit 量）明显不过。

## 6. 局限

- 「命中那一刻」由程序挑帧。S1 那一局也有普攻混在里面；爆发类的颗粒数取最大一簇，以免把普攻算进去。
- 照地面积只取单帧，所以只作参考，判定以照地灯/次和亮度峰值为主。
- GCP 用软件 OpenGL 渲染，绝对亮度与本机显卡渲染略有不同，但 14 人同条件，横向比较有效。
- 只拍了普攻和 S1。S2、S3、连携没测，补完后可以用同一工具加 `--shot_mode=1/2` 再量。
