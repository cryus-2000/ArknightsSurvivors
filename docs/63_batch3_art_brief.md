### 3.2 动作与出手帧

docs/59 §8 的 JSON 草案里写了一版帧数 / 出手帧；**最终以 Codex 的 manifest 为准**，程序跟着 manifest 改。下表是建议值，已经把草案里低于 docs/24 规格的 fps 调到 12。

|---|---|---|---|
| `skalter` | 手持骨状手杖（用户 10-11 定，按批准参考；手杖每帧都在，但不作攻击动作主体）；站姿端正、稍微后仰 | **抬手低吟**，5 帧 12fps，**出手帧 2**：f0 垂手 → f1 单手抬到胸前 → **f2 手掌向前推开、嘴张开**（声浪从主控脚下扩散，程序画）→ f3–f4 收手。声浪是一圈向外扩的环，所以手势是「向外推开」而不是「指向某处」 | **张臂歌唱**，7 帧 12fps，**出手帧 3**：f0–f1 双手合在胸前蓄力 → f2 仰头 → **f3 双臂完全张开、仰头高唱**（歌域放大，程序画）→ f4–f5 保持 → f6 收回接近 idle f0。三个技能（S1 回复、S2 永久增益、S3 消耗灯火的强歌）都用这一条 |

补充：

- **出手帧之前**的帧要能看出蓄力，**出手帧**本身要和前后帧在剪影上明显不同（第四批流明的教训）。预览图里用星号标出手帧。
- 发射点绑定在手上：能天使的枪口、安洁莉娜的杖头、德克萨斯的剑尖、星熊的盾沿。Claude 接入时会按新图量发射点坐标，所以这些部位在出手帧里要清楚、不被身体挡住。
- 德克萨斯和星熊都是近战，要一眼分开：德克萨斯**快**（身体压低、单剑、动作幅度小但出手快），星熊**重**（站得高、大盾、动作大）。两人都不要和斯卡蒂的大剑横扫撞姿势。
- 浊心斯卡蒂和安洁莉娜都是辅助，都不打近身：浊心斯卡蒂是**向外推开**的手势（声浪是环），安洁莉娜是**指向远处**的杖（重力弹是落点弹）。
- 光环（能天使）、盾（星熊）、剑（德克萨斯）、杖（安洁莉娜）是人物本体，Codex 画；刀光、剑雨、子弹、枪口火焰、歌域、重力场、悬浮光、盾面闪光一律不画。

### 3.3 跑动和待机

- `_run` 6 帧 10fps，和博士同速的小跑。德克萨斯步幅最大、身体前倾；星熊步幅小、盾随步伐上下晃；浊心斯卡蒂裙摆飘动、手不要摆太大；能天使枪端在身前；安洁莉娜杖斜背或斜持，尾巴随跑动摆。
- `_idle` 4 帧 4fps：浊心斯卡蒂轻轻起伏（像在哼歌）；德克萨斯可以有 Pocky 微动；星熊盾随呼吸微动；能天使光环上下浮 1px；安洁莉娜发梢和尾巴轻飘。全部以 f0 为底，只改小范围像素（§1）。
