# 129 · 德克萨斯普攻重设计（10-23，用户「自动冲刺太晕」）

> 起因：用户反馈德克萨斯普攻是「朝最近敌人冲刺穿行」，队长的位置被她一下一下带着走，太晕；并说「剑雨没有敌人的时候就不用放」。
> 协调人任务（10-23）：队长原地两连斩 + 每第 3 刀短剑气；队友保留短突进但收短收慢；删定时自动冲刺；剑雨无敌人不放；冲刺手感由响应动作承担；数值保持强度。
> 分支 `claude/texas-rework`（基于 main ee73410a）。演示录像（队长 / 队友视角各 8 秒，30 fps 实时）在 `build/texas_rework/out/`（本机，不进 git），重录：`python tools/probes/texas_rework_capture.py <out> leader|mate` + `tools/promo_gif.py`。

## 1. 改前改后

| | 改前 | 改后 |
|---|---|---|
| **队长普攻** | 每 1.1 秒朝最近敌人冲刺 140（宽 44，穿透），队长被带着位移；穿过敌人全队技力 +0.6 秒 | **原地**两连斩：每 0.9 秒朝最近敌人挥两刀扇形斩（半径 112，半角 1.0 rad ≈ 115°，各 60% 攻击，第二刀晚 0.2 秒）；每次出手全队技力 +0.5 秒 |
| **短剑气** | 无 | 每第 3 次出手朝 220 内最近敌人甩一道（70%，飞出 170、宽 44、命中第一名敌人即消失）；**220 内没有敌人就不甩**（手动模式沿玩家指向，同样要求范围内有敌人） |
| **队友普攻** | 同队长（冲刺穿行） | 同样原地两连斩 + 短剑气；另有**短突进**：每 2.0 秒一次，≤ 60，只在最近敌人在 100–260 之间时才上前（已经够得着就不动）；穿过 ≥3 名额外技力 |
| **定时自动冲刺**（天赋「战术快递」精一，原兜底） | 队长 2.5 秒没冲刺她自己冲进敌群（S2 缩到 2.0 秒） | **删除**（用户改口，推翻 docs/118 §6.1 的「保留兜底」）；天赋只剩 on_dash_end 回技力；S2 文案去掉「间隔 −20%」 |
| **响应动作「同向疾行」** | 队长冲刺 → 她同向冲刺（她当队长时 ride 跟着队长这次冲刺扫沿途）；精英一才有 | 精英一起**不变**（`response_test` 全过）。**10-23 用户追加：专属冲刺**——她当队长、精零时，自己按冲刺就对路径上的敌人造成伤害（新响应块 `cond is_leader && elite < 1`，来源「冲刺斩」×`dash_mult` 1.0，扫沿途穿透，穿过敌人全队技力 +`hit_sp`），间隔不变（仍是队长冲刺键的冷却）；精一起由「战术快递」接手（同样扫沿途 + 更多技力） |
| **S1 剑雨 / S3 剑雨滂沱**（自动释放） | 技力满就放 | 新字段 `need_enemy`：S1 要 130 内有敌人、S3 要 230 内有敌人才放，否则技力保留满格、有敌人那一帧再放；S2 可靠伙伴（永久增益）不受限 |

补偿：删掉定时冲刺少了「战术快递」每 2.5 秒 +0.8 秒技力（≈ 0.32/秒），精一起双连斩每次出手再 +0.15 秒（≈ 0.17/秒）补回一半多。

## 2. 积木落地

全部数据化，新增 4 个通用参数（docs/61 §21 表补行）：

| 参数 | 位置 | 说明 |
|---|---|---|
| `shape.wave.need_target` | `seg_skadi.hw_wave_start` | `from: self` 时 `aim_r` 内没有敌人就不放出（拉普兰德 / 其他干员也能用） |
| `shape.dash_line.need_target / min_d / aim_r` | `seg_texas.tx_dash_start` | `aim nearest`：`aim_r` 内没敌人、或最近的敌人比 `min_d` 还近就不冲；`aim_r` 缺省 = 冲刺长度 × 1.3（老写法行为不变） |
| `blocks.skills[i].need_enemy` | `character.charge_skills` → `skill_gate_ok`（`data_operator` 覆盖） | 自动释放的前提：`pos` 周围这个半径（× op_range）内要有敌人；不满足时技能不 ready、技力保持满格 |

德克萨斯 json 用法：普攻 = `shape.cone` + `attack.combo`（第 2 斩 / 回马剑）；trait：每次出手回技力、`every_n 3` 短剑气（`wave need_target max_hits 1`）、精一回技力、队友 `tick 2.0 cond !is_leader` 突进（`dash_line aim nearest need_target aim_r 260 min_d 100 r 60`）、`on_dash_end 突进 min_hits 3` 额外技力。短剑气带 `max_hits`，所以升级卡「贯穿」（docs/108 §17）对它生效，编队里有她就能出卡。

## 5. 对局胜率（云端，标准档 · 高手机器人，队长单开德克萨斯，28 seed × 2 份实现 = 56 局）

云端 `tx-rework`（新 = 04607ca76 重设计、旧 = main ee73410a6，各 28 seed × 2 份实现，不含专属冲刺追加）：

| 版本 | 实现 0 | 实现 1 | 均值 | 存活均 / 最短 | 主要伤害来源 |
|---|---|---|---|---|---|
| 旧（冲刺穿行） | 46.4% | 14.3% | **30.4%** | 7:50 / 2:24 | 剑雨滂沱 9%、剑雨 8%、疾行斩 6%、战术快递 6% |
| 新（原地两连斩 + 短剑气） | 39.3% | 46.4% | **42.0%** | 9:31 / 4:56 | 剑雨滂沱 12%、剑雨 10%、Mon3tr 真伤 4%、双连斩 4% |

- **强度没有掉，反而升了 12 点**，平均存活多 1 分半、最短存活从 2:24 到 4:56（站着不动的队长不再被自己冲进怪堆）；两份实现之间差 32（旧）/ 7（新）点，旧版组间差太大，+12 在噪声内（单份 ±6 点、组间标准差约 16），结论是「不低于改前」。
- **但两版都不在 55–70 目标内**：德克萨斯改前在 main 上就只有 30%（队长单开偏弱，不是这次重设计造成的）。要把她拉进 55–70 需要另做一轮数值（候选：双连斩两刀各 60% → 75%、短剑气 70% → 85%，木桩表约 +25%；先不动，等用户 / 协调人定要不要现在拉）。

## 6. 其他干员的自动技能会不会无敌人空放（协调人问，先不改，等用户定是否全员统一）

目前自动技能只看「技力满没满」（`character.charge_skills`），没有任何干员检查场上有没有敌人。按技能性质分：

- **会空放、白白浪费**（瞬发或限时的进攻技能，场上没敌人就打空 / 白烧持续时间）——共 21 个：
  - 瞬发 / 一次性：歌蕾蒂娅 S1、艾丽妮 S2 裂潮、逻各斯 S1 提喻（要锁目标）/ S3 延异视阈、推进之王 S2 跃空锤、斯卡蒂 S1 / S2、艾雅法拉 S2 点燃、乌尔比安 S1、德克萨斯 S1（本次已加门槛）。
  - 限时强化窗口（时间白烧）：能天使 S2 / S3、星熊 S2 / S3、拉普兰德 S2 / S3、水月 S2 / S3、推进之王 S3、斯卡蒂 S3、归溟幽灵鲨 S1 / S2 / S3、艾雅法拉 S3、艾丽妮 S3、歌蕾蒂娅 S2 / S3、安洁莉娜 S3、德克萨斯 S3（本次已加门槛）。
- **不会浪费**：「接下来 N 发 / 下一次」类（安洁莉娜 S1、艾雅法拉 S1、艾丽妮 S1、水月 S1、铃兰 S1、维什戴尔 S1 / S3、推进之王 S1、能天使 S1 装填）——效果留到下一次攻击；永久类（S2 一类）；治疗 / 护盾 / 光域类（凯尔希 S1、流明 S1 / S3、塞雷娅全部、铃兰 S3、斯卡蒂歌域类（`skalter` S1 / S3））——有敌无敌都有价值。
- 统一做法（若用户要全员统一）：把 `need_enemy` 写进上面「会空放」那批技能的 `blocks.skills[i]`（半径取各自技能范围，限时强化窗口取普攻射程），不需要新代码；同 seed TRACE 会变，要跑一次 56 局确认不掉强度（限时窗口不再被空场白烧，通常略升）。

## 7. TRACE 变化（docs/108 §18）

德克萨斯的每一帧都变（普攻形状、位移、技力节奏全换），其他干员同 seed 不变（`need_enemy` 只有德克萨斯写了）。积木等价金样里 texas 一项需要合入后重录。
