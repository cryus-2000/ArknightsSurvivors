# 129 · 德克萨斯普攻重设计（10-23，用户「自动冲刺太晕」）

> 起因：用户反馈德克萨斯普攻是「朝最近敌人冲刺穿行」，队长的位置被她一下一下带着走，太晕；并说「剑雨没有敌人的时候就不用放」。
> 分支 `claude/texas-rework`（基于 main ee73410a）。演示录像（队长 / 队友视角各 8 秒，30 fps 实时）在 `build/texas_rework/out/`（本机，不进 git），重录：`python tools/probes/texas_rework_capture.py <out> leader|mate` + `tools/promo_gif.py`。
> 迭代记录：第一版（原地两连斩 + 每第 3 次短剑气）→ 用户追加「专属冲刺」→ 第二轮钉剑 / 余像改挂短剑气 → **用户 10-23 改口：不要剑气（和人设不符、和拉普兰德重合），改纯近战「疾刃三连」**（本文现行版本，剑气的代码与数据已删）；同时全员自动技能统一加「射程内没有敌人就不放」（§6）。

## 1. 现行设计

| | 改前（main） | 现行 |
|---|---|---|
| **普攻** | 每 1.1 秒朝最近敌人冲刺 140（宽 44，穿透），队长被带着位移；穿过敌人全队技力 +0.6 秒 | **原地两连斩**：每 0.9 秒朝最近敌人挥两刀扇形斩（半径 112，半角 1.0 rad ≈ 115°，各 75%，第二刀晚 0.2 秒）；每次出手全队技力 +0.5 秒 |
| **疾刃三连** | 无 | 每第 3 次出手**改为**原地朝最近敌人 0.25 秒内连斩三下（0 / 0.125 / 0.25 秒），扇形比普攻宽 20°（半角 1.35 rad）、半径同普攻（112）、每下 45%（合计 135%，数值按云端拉回 55–70 再定）；普攻范围内没有敌人（手动空挥）就照常两连斩 |
| **队友** | 同队长（冲刺穿行） | 同样原地两连斩 + 疾刃三连；另有**短突进**：每 2.0 秒一次，≤ 60，只在最近敌人在 100–260 之间时才上前（已经够得着就不动）；穿过 ≥3 名额外技力 |
| **专属冲刺**（用户 10-23 追加） | 她当队长、精零时自己按冲刺没有伤害（只有精一起的响应才扫沿途） | 精零队长自己按冲刺，路径上的敌人受**冲刺斩**伤害（×`dash_mult` 1.0，扫沿途穿透，穿过敌人全队技力 +0.5 秒），间隔不变（队长冲刺键的冷却）；精一起由「战术快递」接手（同样扫沿途 + 更多技力） |
| **定时自动冲刺**（天赋「战术快递」精一，原兜底） | 队长 2.5 秒没冲刺她自己冲进敌群（S2 缩到 2.0 秒） | **删除**（推翻 docs/118 §6.1 的「保留兜底」）；天赋只剩 on_dash_end 回技力，精一起双连斩每次出手再 +0.15 秒补回一半多；S2 文案去掉「间隔 −20%」 |
| **响应动作「同向疾行」** | 队长冲刺 → 她同向冲刺（她当队长时 ride 扫沿途），精英一起 | 精英一起不变（`response_test` 全过） |
| **S1 剑雨 / S3 剑雨滂沱**（自动释放） | 技力满就放 | `need_enemy`：S1 要 130 内有敌人、S3 要 230 内有敌人才放，否则技力保留满格、有敌人那一帧再放；S2 可靠伙伴（永久增益）不受限 |

## 2. 积木落地

全部数据化。新增通用参数（docs/61 §21 表补行）：

| 参数 | 位置 | 说明 |
|---|---|---|
| `trig.every_n.no_combo` | `data_operator._release_body` / `ob_check` | 只配 `replace: true`：这一次出手自己连斩，不再接 `attack.combo`（改调 `hw_combo_end`）。疾刃三连用它避免在三连后又接普攻的第二斩 |
| 条件 `enemy_near` | `ob_core.EXT_CONDS` / `seg_hoshiguma.ext_cond_true` | 普攻范围（形状半径 + 30，同起手找目标半径）内有敌人；疾刃三连的三个块都带它 |
| `verb.emit_path {len, w, src}` | `seg_texas.tx_exec`（EXEC_SEG 段 1） | 把「自身朝最近敌人（没有就朝向 / 手动指向）、长 `len`」的路径当作一次冲刺结束，触发 `src` 匹配的 `trig.on_dash_end`（`tx_emit_path`）；精二余像用它挂在三连上 |
| `shape.dash_line.need_target / min_d / aim_r` | `seg_texas.tx_dash_start` | `aim nearest`：`aim_r`（缺省 冲刺长度 × 1.3）内没敌人、或最近的敌人比 `min_d` 还近就不冲（队友短突进）|
| `blocks.skills[i].need_enemy` | `character.charge_skills` → `skill_gate_ok`（`data_operator` 覆盖） | 自动释放的前提：`pos` 周围这个半径（× op_range）内有敌人，没有就不放、技力保留满格；手动技能不受影响 |

德克萨斯 json：普攻 = `shape.cone` + `attack.combo`（第 2 斩 / 回马剑）；trait：0 每次出手回技力；1 疾刃三连第一下（`every_n 3 replace no_combo cond enemy_near`，cone 半角 1.35 每下 45%，带钉剑 on_hit 与 `emit_path`）；2 / 3 三连第二 / 三下（`every_n 3 delay 0.125 / 0.25 cond enemy_near`）；4 精一每次出手再回技力；5 队友短突进（`tick 2.0 cond !is_leader`）；6 突进多命中回技力；7 S3 剑雨滂沱 tick；8 S3 结束落剑雨；9 专属冲刺穿过敌人回技力。响应块：`is_leader && elite < 1` 的专属冲刺 + `elite >= 1` 的战术快递。

## 6. 全员自动技能「射程内没有敌人就不放」（用户 10-23 同意全员统一）

此前自动技能只看「技力满没满」，没有任何干员检查场上有没有敌人。现统一加 `blocks.skills[i].need_enemy`（半径 × op_range）——**31 个技能**（德克萨斯 2 + 其余 14 人 29）：

| 德克萨斯 | S1 剑雨 130、S3 剑雨滂沱 230 |
| 歌蕾蒂娅 | S1 `s1_range`（300）、S2 / S3 `range`（240） |
| 艾丽妮 | S2 裂潮、S3 判决（各取技能自带 `aim_r`） |
| 逻各斯 | S1 提喻、S3 延异视阈（`range` 310） |
| 推进之王 | S2 跃空锤 150、S3 碎颅击 140 |

| 艾雅法拉 | S2 点燃、S3 火山（`range` 290） |
| 乌尔比安 | S1（`aim_range` 400） |
| 能天使 | S2 扫射、S3 过载（`range` 300） |
| 星熊 | S2 荆棘、S3 力之锯（140） |
| 拉普兰德 | S2 狼魂 150、S3 群狼之噬 200 |
| 水月 | S2 囚徒困境、S3 镜花水月（160） |

**不加**：治疗 / 护盾 / 光域类（凯尔希 S1、流明 S1 / S3、塞雷娅全部、铃兰 S3、斯卡蒂歌域类 `skalter` S1 / S3）、永久类（S2 一类）、「接下来 N 发 / 下一次」类（安洁莉娜 S1、艾雅法拉 S1、艾丽妮 S1、水月 S1、铃兰 S1、维什戴尔 S1 / S3、推进之王 S1、能天使 S1）、星熊 S1 战意（防御窗口）、手动技能（乌尔比安 S3 等，队长按键不受限；当队友时的自动释放也不加）。相对 10-23 清单多了两个：维什戴尔 S2、凯尔希 S3（限时强化窗口，同属「时间白烧」）。

机制：`character.charge_skills` 现在要 `skill_gate_ok(i)`（数据干员读 `need_enemy`）；不满足时技能不 ready、技力不消耗，条一直满着，有敌人那一帧再放。测试：`test_core.test_need_enemy_data`（31 个、不给手动 / 永久、治疗类全不加）、`texas_contract.test_gate`（没敌人不放且技力保留、射程内有敌人放、射程外不放）。**同 seed TRACE 全员可能变**（只在「技力满时场上无敌人」的帧有差别，主要是开局空场与波间），docs/108 §18。

## 7. TRACE 变化

德克萨斯每一帧都变（普攻形状、位移、技力节奏全换）；其余 14 个有 `need_enemy` 的干员只在「技力满且射程内没有敌人」的帧与改前不同。积木等价金样合入后由协调人重录。
