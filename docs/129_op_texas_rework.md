# 129 · 德克萨斯普攻重设计（10-23，用户「自动冲刺太晕」）

> 起因：用户反馈德克萨斯普攻是「朝最近敌人冲刺穿行」，队长的位置被她一下一下带着走，太晕；并说「剑雨没有敌人的时候就不用放」。
> 分支 `claude/texas-rework`（基于 main ee73410a）。演示录像（队长 / 队友视角各 8 秒，30 fps 实时）在 `build/texas_rework/out/`（本机，不进 git），重录：`python tools/probes/texas_rework_capture.py <out> leader|mate` + `tools/promo_gif.py`。

## 1. 现行设计

| | 改前（main） | 现行 |
|---|---|---|
| **普攻** | 每 1.1 秒朝最近敌人冲刺 140（宽 44，穿透），队长被带着位移；穿过敌人全队技力 +0.6 秒 | **原地两连斩**：每 0.9 秒朝最近敌人挥两刀扇形斩（半径 112，半角 1.0 rad ≈ 115°，各 75%，第二刀晚 0.2 秒）；每次出手全队技力 +0.5 秒 |
| **疾刃三连** | 无 | 每第 3 次出手**改为**原地朝最近敌人 0.25 秒内连斩三下（0 / 0.125 / 0.25 秒），扇形比普攻宽 20°（半角 1.35 rad）、半径同普攻（112）、每下 45%（合计 135%，数值按云端拉回 55–70 再定）；普攻范围内没有敌人（手动空挥）就照常两连斩 |
| **队友** | 同队长（冲刺穿行） | 同样原地两连斩 + 疾刃三连；另有**短突进**：每 2.0 秒一次，≤ 60，只在最近敌人在 100–260 之间时才上前（已经够得着就不动）；穿过 ≥3 名额外技力 |
| **专属冲刺**（用户 10-23 追加） | 她当队长、精零时自己按冲刺没有伤害（只有精一起的响应才扫沿途） | 精零队长自己按冲刺，路径上的敌人受**冲刺斩**伤害（×`dash_mult` 1.0，扫沿途穿透，穿过敌人全队技力 +0.5 秒），间隔不变（队长冲刺键的冷却）；精一起由「战术快递」接手（同样扫沿途 + 更多技力） |

| **响应动作「同向疾行」** | 队长冲刺 → 她同向冲刺（她当队长时 ride 扫沿途），精英一起 | 精英一起不变（`response_test` 全过） |

## 2. 积木落地

全部数据化。新增通用参数（docs/61 §21 表补行）：

| 参数 | 位置 | 说明 |
|---|---|---|
| `trig.every_n.no_combo` | `data_operator._release_body` / `ob_check` | 只配 `replace: true`：这一次出手自己连斩，不再接 `attack.combo`（改调 `hw_combo_end`）。疾刃三连用它避免在三连后又接普攻的第二斩 |
| 条件 `enemy_near` | `ob_core.EXT_CONDS` / `seg_hoshiguma.ext_cond_true` | 普攻范围（形状半径 + 30，同起手找目标半径）内有敌人；疾刃三连的三个块都带它 |
| `verb.emit_path {len, w, src}` | `seg_texas.tx_exec`（EXEC_SEG 段 1） | 把「自身朝最近敌人（没有就朝向 / 手动指向）、长 `len`」的路径当作一次冲刺结束，触发 `src` 匹配的 `trig.on_dash_end`（`tx_emit_path`）；精二余像用它挂在三连上 |
| `shape.dash_line.need_target / min_d / aim_r` | `seg_texas.tx_dash_start` | `aim nearest`：`aim_r`（缺省 冲刺长度 × 1.3）内没敌人、或最近的敌人比 `min_d` 还近就不冲（队友短突进）|
| `blocks.skills[i].need_enemy` | `character.charge_skills` → `skill_gate_ok`（`data_operator` 覆盖） | 自动释放的前提：`pos` 周围这个半径（× op_range）内有敌人，没有就不放、技力保留满格；手动技能不受影响 |

德克萨斯 json：普攻 = `shape.cone` + `attack.combo`（第 2 斩 / 回马剑）；trait：0 每次出手回技力；1 疾刃三连第一下（`every_n 3 replace no_combo cond enemy_near`，cone 半角 1.35 每下 45%，带钉剑 on_hit 与 `emit_path`）；2 / 3 三连第二 / 三下（`every_n 3 delay 0.125 / 0.25 cond enemy_near`）；4 精一每次出手再回技力；5 队友短突进（`tick 2.0 cond !is_leader`）；6 突进多命中回技力；7 S3 剑雨滂沱 tick；8 S3 结束落剑雨；9 专属冲刺穿过敌人回技力。响应块：`is_leader && elite < 1` 的专属冲刺 + `elite >= 1` 的战术快递。

## 11. 攻击模式重设计稿（10-24，只出设计、不写代码，等用户挑）

### 11.1 诊断：同样是近战队长，德克萨斯差在哪

数据来源：云端 `tx-old` / `tx-new` / `tx-tri`（德克萨斯，56 / 56 / 168 局）与 `op5-lapp-old` / `op5-lapp-new`（拉普兰德，各 56 局）的整局记录（`final_out` 各来源伤害、`dmg` 队长受伤、`t` 时长、队伍）；`tx-diag`（`tools/probes/melee_diag.py`，前 40 秒的行为采样，见下方说明）。口径：标准档、高手机器人、队长单开 + 自动招募，平均 3 人队。

| 指标 | 德克萨斯 旧（main 冲刺） | 德克萨斯 第一版（两连斩 + 短剑气） | 德克萨斯 疾刃三连 | 拉普兰德 |
|---|---|---|---|---|
| 胜率 | 30% | 43% | 27% | 57% → 68% |
| 她本人每分钟伤害 | 19.8k | 19.5k | 16.7k | 28.0k → 29.5k |
| 其中**技能**占比 | 43% | 68% | **76%** | 26–27% |
| **普攻类**每分钟伤害（双连斩 / 疾行斩 / 双刃 + 双生刃） | 疾行斩 3.0k（连战术快递、余像共 12.9k） | 双连斩 2.3k | 双连斩 2.3k | 双刃 7.1–7.5k + 双生刃 8.4–8.6k = **15.7k** |
| 队长受伤 / 分钟 | 161 | 162 | 174 | **91** |
| 败局里 7 分钟前就死的 | 34 / 39 | 17 / 32 | 73 / 122 | 2 / 24 → 2 / 18 |
| 败局头号死因（该死因败局数，平均死亡时间） | 溟痕 mire 29（6:36） | 创建者接触 11、溟痕 10、追击者 9 | **追击者 52（6:12）**、溟痕 37（9:27）、创建者 25 | 追击者 8（8:04）；整体晚得多 |
| 升到 6 级用时 | 96 秒 | 101 秒 | 104 秒 | 96 秒 |
| 前 3 分钟死亡 | 1 / 56 | 0 / 56 | 0 / 168 | 0 |

结论（按因果顺序）：

1. **不是前期问题。** 6 级用时、前 3 分钟死亡数四组一样；败局集中在 4–9 分钟，那段是追击者、创建者、溟痕一起上来的阶段。
2. **普攻几乎没输出。** 德克萨斯普攻类只有约 2.3k / 分钟，是拉普兰德的 **1/7**；她的伤害 68–76% 靠剑雨 / 剑雨滂沱两个技能，技能冷却期间队长基本是旁观者。拉普兰德相反，普攻占 73%，技能只是加成。两连斩 + 疾刃三连每次出手的伤害（一个扇形里只打到 1–2 只）远小于拉普兰德那一下横扫 + 双生刃（一圈打到一群），所以光调倍率也只能抬 25–30%，抬不到 7 倍。
3. **没有任何减伤 / 控制。** 她被打得比拉普兰德多 80%（161–174 对 91 / 分钟）。拉普兰德有两层：天赋格挡 20% + 精一起每刀封印（被封印的敌人不起新招、不开火）。德克萨斯普攻没有控场，只有剑雨那次眩晕；`tracer`（追击者，快速追人）贴上来没人拦。
4. **第一版好于疾刃三连，看死因就明白**：第一版的短剑气是她唯一的**远程应对**——追击者败局占 16%（9 / 56），疾刃三连去掉剑气后涨到 31%（52 / 168）。两版普攻伤害一样（2.3k），多出来的 2.8k 分钟伤害来自「剑气带出的余像 / 钉剑」触发更勤。**旧版**最差的是溟痕：自动冲刺把队长带进溟痕 29 / 39 局死在 6 分半；原地化之后这类死因降到约 1/3。
5. **机器人永远在走**：前 40 秒采样里所有干员 `move_frac` 都 ≥ 0.985、站定占比 ≈ 0，所以「原地」对机器人只是不位移，它照样边走边挥。这意味着挥击的**起手到出手之间目标会走出范围**：疾刃三连出手时范围内一个敌人都没有的比例 55%、第一版 70%、旧冲刺 20%（冲刺自己追着打，最稳）。别的原地扇形也一样（拉普兰德 44%、斯卡蒂 74%、水月 83%），所以这条是次要因素，主要因素仍是 2、3。**说明**：诊断探针循环遇到「非战斗状态」就提前退出，所以只采到前 40 秒（约 3 级），只作旁证；要采满 5 分钟需修循环后再跑一次云端（约 30 分钟）。

### 11.3 PRTS 取材（已查证：prts.wiki/w/德克萨斯）

- 职业分支：**先锋 · 尖兵**。特性：**能够阻挡两个敌人**；分支信息：**可以攻击自身阻挡的单位，且会优先攻击，即使目标在攻击范围外或为飞行单位**。
- 攻击间隔 **1.05 秒**，阻挡数 2。
- 天赋「战术快递」：编入队伍后额外获得初始部署费用（精一 +1、精二 +2；模组二级起「技能造成的伤害提高 10% / 15%」）。
- 技能：S1「**冲锋号令·γ型**」（自动，立即获得 12 点部署费用）、S2「**剑雨**」（手动，对周围所有敌人造成两次法术伤害，击中后晕眩 2 秒，可对空）。页面写明「此干员无第 3 技能」。
- 档案：战斗风格「可以用**暴风骤雨**来形容」「非常直白」「一切只为消灭对方这个目的服务」；悖论模拟简介：「其灌注源石技艺的剑雨时常能对大范围内敌人的行动造成阻碍」；综合体检「战场机动 / 战术规划 优良」；语音「拔刀。」「斩尽杀绝。」。
- **待你们定的名字问题**：本作 S1「剑雨」（原作是 S2）、S2「可靠伙伴」、S3「剑雨滂沱」——「可靠伙伴」「剑雨滂沱」在德克萨斯这一页查不到（原作她只有两个技能）。按「技能名用原作」应当：S1 改回「冲锋号令·γ型」之类的原作技能、S2 用「剑雨」；S3 属本作自创（可保留，要在设计文档里写明「自创」）。本稿三个方案都不动技能名，只改普攻；名字要不要改回原作单独决定。

### 11.4 三个方案

三个方案共用的出发点：**原作她是「阻挡两个敌人、优先打挡在身前的」站桩剑士，攻击间隔 1.05 秒，战斗风格是暴风骤雨**——所以普攻回到「原地、1.05 秒一刀、打身边的人」，重点补足诊断出的两个洞：普攻没输出（扇形只打到 1–2 只）、没有减伤 / 控制。三个方案都**原地、无位移、无远程弹体**，队友另保留 ≤60 的短突进（已有）。

**方案 A「阻挡」——用原作特性做控制，对应拉普兰德的封印但机制不同**
- 节奏：每 **1.05 秒**一刀「拔刀」，不再两连：一刀 ×1.3 的宽扇形（半径 112，半角 1.2 rad，约 140°）。
- 判定与阻挡：命中的敌人里**离她最近的两名**被「阻挡」——原地定住 0.4 秒（精英减半，Boss 不受），这两名在定住期间不能移动 / 贴身攻击（沿用现有 `st.stun` 的口径）；对应原作特性「阻挡两个敌人 + 优先攻击阻挡自己的」。
- 被包围：每第 4 次出手改为「**骤雨**」——原地 0.6 秒内 360° 连斩 4 下（半径 100，每下 ×0.55，合计 ×2.2，没有敌人时照常拔刀），对应档案「暴风骤雨」；被围时这一下一次清一圈。
- 队长手动：按攻击键一刀，方向 = 玩家指向，指向没敌人也出刀（manual-aim 通用逻辑）；「阻挡」照常取命中里最近两名；骤雨不吃方向（360°）。队友自动：朝最近敌人拔刀，其余同；队友保留 ≤60 短突进。
- 与拉普兰德的区别：她是「横扫 + 封印 + 十字剑气」，减的是敌人**行动**（封印不起招 / 不开火）；德克萨斯减的是敌人**位置**（最近两只被钉住）；她没有剑气，三连改成 360° 全包围。
- 预期：普攻伤害翻 1.5–2 倍（扇形 140° + 骤雨打一圈，普攻类 2.3k → 约 4–5k / 分钟），队长受伤 −25~30%（贴身的两只被定、追击者被钉在身前）→ 约 120–130 / 分钟。**预期胜率 48–60%**（依据：拉普兰德受伤 91 → 胜率 57–68，德克萨斯 161–174 → 27–43，按受伤 / 分钟线性外推到 ~125 约 50 上下；控制能同时抬 kills 与存活，上界取 60）。需新积木：无（`shape.cone` + `st.stun` + `every_n replace`，沿用 `no_combo` / `enemy_near`）。

**方案 B「暴风骤雨」——被围越多越快（把被包围从弱点变成强项）**
- 节奏：每 **1.05 秒**一刀的基准，**身边（110 内）每多一只敌人攻速 +10%，上限 +50%**（5 只以上封顶，最快约 0.7 秒一刀）；一刀是 ×0.9 的 360° 回旋（半径 100，没有朝向，被围也能全打到）。
- 判定：360° 圆，伤害对每名敌人 ×0.9；不带控制，但每刀给她自己 **1.5 秒的叠层减伤**（每名被打到的敌人 +2%，上限 20%）。
- 被包围：这就是设计核心——越围越强，对应「暴风骤雨」；单个敌人时节奏最慢、也最弱，所以队友模式下需要短突进 + 剑雨补伤害。
- 队长手动：按键就转一圈（不吃方向，360°）；攻速倍率照旧按身边敌人数；移动中也能打。队友自动：同。
- 与拉普兰德的区别：她是扇形 + 方向 + 封印，德克萨斯是**全向回旋 + 随人数加速**，没有方向概念，也没有任何弹体。
- 预期：被围时输出翻 2–3 倍，平时与现在持平；受伤 −15~20%（减伤层 + 更快清场）→ 约 135–145。**预期胜率 42–56%**（依据同上，但减伤只有 20% 上限、且平时单体弱，追击者单只贴身时仍有风险；上界取拉普兰德旧版 57% 以下）。需新积木：条件 `enemies_near >= n`（或直接读数量的 `stat buff`），工作量中等。

**方案 C「重斩」——慢而重的全向斩（最简单，纯数据）**
- 节奏：每 **1.05 秒**一刀全向「重斩」：360° 圆，半径 105，**×1.6**，命中击退 70（精英 ×0.3，Boss 不受），无前摇方向；每第 3 次出手同圈再补一下 ×0.8（「复斩」，延迟 0.2 秒）。
- 判定：纯圆、不吃方向；击退把贴身的敌人推到一臂之外，给下一刀留距离，也等于替队长挡一拍。
- 被包围：圆一次全打，击退把围圈撑开；没有控制效果，纯靠清场速度与位移。
- 队长手动：按键转一圈，指向无关（圆）；队友自动同。
- 与拉普兰德的区别：她是扇形 + 封印 + 剑气，德克萨斯是**全向击退重斩**，更接近斯卡蒂的「涌潮悲歌 全方向」思路但没有范围 +、没有剑气。
- 预期：每刀打到的敌人数从 1–2 只升到整圈（普攻类 2.3k → 约 6–8k / 分钟，仍不到拉普兰德的一半），受伤 −10~15%（击退 + 更快清场）→ 约 140–150。**预期胜率 38–52%**（依据：数据最少依赖、不加控制，所以给最宽、最低的区间；价值是**工作量最小**：现有积木 + 数值，半天能出云端数据）。需新积木：无（`shape.circle` + `kb` + `attack.combo`）。

### 11.5 建议

- 首推 **方案 A**：直接对应原作特性（阻挡两个敌人 / 优先攻击阻挡自己的），补上诊断里最大的洞（没有控制、普攻没输出），区间最高，且不需要新代码。
- 方案 B 的叙事最贴「暴风骤雨」，但机制新、区间宽，适合 A 跑完仍不够再叠。
- 方案 C 可作 A 的保底（把 A 的两连 / 宽扇形换成纯圆，其余不变）。
- 不管选哪个，**建议同时决定技能名**（§11.3 末条）；若选 A，S1 / S3 的 need_enemy 保持。
- 进入实现前仍需：①修诊断探针循环、重跑一次满 5 分钟云端采样做基线；②选定方案后云端 56 局 × 3 份复核，目标 55–70。
