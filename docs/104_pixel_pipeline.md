# 104 干员像素素材流程规范（Codex 制作 + 本项目验收）

2026-10-16 定稿（用户「104 先定一下看一下效果」）。起因：Codex 第 2 轮（水月 / 铃兰 f0）与逻各斯待机整条三件工具检查全过、用户肉眼判像素质量不合格。病根是「生成 → 整张缩图 → 自动清点 → 动画平移像素」混在一条脚本流水线里，自动检查过了就当完成。本规范把制作拆成**静态 f0** 与**动画**两条线，把验收拆成**人眼 → 数值 → 游戏内**三层，所有单子只引用本文和 docs/103，不再复制口径。

像素质量基准：逻各斯 `codex/art a3eb677f`（`i_pilot_1015_t4/b_hd_face_smooth_x90@2x.png`）。所有交付先与它并排比干净度。

交付路径（用户 10-28 定）：每批放进 `art/incoming/<批次>/`（批次名 = 内容简称 + 月日，handoff / manifest / 审阅图同目录），收货区根目录不放图；文件命名与目录按 docs/189 §3。接入由本项目复制进 `game/art/`，接入合入后整批归档到 `art/archive/`。

## 2. Codex 侧：静态 f0

1. **读单 + 保持项**：读 docs/103、docs/97 当次单；写一份「保持项」（脸型、头身、瞳色、帽 / 角、武器形状与持握、站姿），后续每次修改对照它，防止修武器顺带改脸。
2. **参照锁定**：PRTS 小人待机帧为第一参照，立绘只补小人看不清处；做局部放大对照图（脸 / 发 / 武器 / 披风四处）。
3. **生成只是候选**：image_gen 出的稿只当参照，不是交付物。不接受「大图好看」跳过小尺寸验收。
4. **按部件在目标网格重排像素**：交付像素在 128 画布上按部件逐块画 / 重排（脸、发与头饰、躯干衣物、臂与武器、披风、腿脚），不得整张算法缩图后直接交付。缩图、归色、描边、去孤点只能作草稿工具，输出先看未清理预览，再逐项人工处理；自动工具负责**发现**问题，不许无条件清掉所有「异常」（高光、细杖会被误删）。
5. **自检三层，任一不过不发**：
   - 技术：`tools/px_lint.py`（孤点 / 单点高光 / 描边 / 色数 / 连通体 / 脚底）、verify-sprites（尺寸 / 帧数 / 透明 / 基线）。
   - 视觉（8 倍放大 + 原尺寸）：轮廓连续、描边 2 像素无断口、色块成面不散点、同一部件同一色阶、高光 / 阴影成组、四处对小人。
   - 干净度：与 a3eb677f 并排，说明达到同等。
6. **本地候选先给用户看**：只发 @2x 预览（原尺寸 + 8 倍）+ 剩余问题；用户一句「过」再 git 提交。提交必带：8 倍放大图、自检表（技术 / 视觉分别记录，不互相代替）、保持项核对、handoff。
7. 未进引擎验证的一律写「未验证」。

## 3. Codex 侧：动画（分层合成，禁止平图挪像素、禁止生成关键帧换脸）

1. 只从**通过的 f0** 出发。
2. **拆层**：头（含发、角 / 帽）、躯干、前臂（持武器）、后臂、披风 / 飘带、腿脚、武器，各为独立透明层，定前后遮挡顺序；补画被遮住的部分。拆层每人一次，所有动作复用。
3. **位移表**：每帧每层一个整像素位移（待机呼吸：头 / 躯干 +1、披风延迟一帧；首尾循环对齐）；需要形变的部件（披风尖、衣摆、袖口）另画 2–3 个替换版，按帧切换。跑 / 攻击 / 技能用同一套层，臂、腿、武器层多画几个姿势。
4. **合成**：脚本按遮挡顺序叠回单帧，只在层交界处补描边；握点、脚底、脸逐帧锁死。
5. **逐帧看**：原尺寸看可读性、8 倍看连接处（颈肩、腰胯、膝、衣摆、武器）、正常速度和慢放各看一遍、末帧回首帧单独看。GIF 生成不等于看过。
6. 自检同 §2 第 5 条，逐帧；附逐帧 PNG + 并排图 + GIF + 位移表。

## 5. 节奏

- **流程验证一次**：新流程先用水月 f0 一张跑通（按部件重排 + 三层自检），证明能出合格像素，再放开。
- **f0 并行**：全员 f0 按簇包同时做，互不等待；验收按包收，过的直接进动画，没过的单独退，不拖整包。
- **人内串行**：每个人 f0 没过不做他的动画；待机过了才做跑 / 攻击 / 技能。
- 用户只在两个节点出现：Codex 本地候选的「过 / 不过」，每个人 f0 的放行。
