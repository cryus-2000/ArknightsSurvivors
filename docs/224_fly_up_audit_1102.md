# 224 「突然向上飞走」排查（11-02）

## 1. 起因

用户 11-02 先后说了两句：

1. 「部署最后的小人退场要不要去掉，突兀的飞上天显得很奇怪」
2. 「再检查一下还有哪里是有突然向上飞走的」

本页排查全游戏里角色、召唤物、敌人、Boss、掉落物、界面元素的「突然往上飞出屏幕 / 快速上移消失」，分两类处理：

- 明显同类的突兀退场：按部署撤回的做法，直接换成就地解散。
- 有设计意义的：保留，列在 §3 请用户定。

## 2. 怎么查的

- 搜代码：
  - 跳出屏幕 / 飞走 / 上飞 / 升起 / 上浮 / 落下；
  - `view_rect(0.0).size.y`、`-pow(`、`Vector2(0, -大值)`；
  - leap / jump / fly / leave / vanish / despawn；
  - g.fx 各 kind；
  - UI 的 slide / tween。
- 录像抽帧核实：部署撤回、骑士离队各录一段改前改后，见 §5。
- 只改画面，不动判定：
  - 部署撤回：同 seed 240 秒的 TRACE，新旧退场逐行一致（308 行）。
  - 骑士离队：用旧版 knight.gd 跑同 seed 120 秒（第 20 秒离队），TRACE 与新版逐行一致（127 行）。

## 4. 开关与测试

- `squad/deploy_exit`：1 = 就地解散（缺省），2 = 部署撤回直接跑回，0 = 旧的向上跳出（对照用）。
- 录片开关：
  - `--grantat=<秒>:<藏品,…>`：到点再给一次藏品，例如 `--grant=222 --grantat=6:221` 看骑士离队。
  - `--onboarddeploy=<距离>`：演示局部署点放远，触发撤回瞬回。
- 回归：squad_v2 / onboard_forced / data_lint 通过；同 seed TRACE 见 §2。
