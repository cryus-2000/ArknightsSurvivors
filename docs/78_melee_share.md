# 78 近战伤害占比与「抢怪」审计（10-12）

用户问（10-12）：「现在乌尔比安这种近战是不是有点弱了，因为伤害都被远程吃掉了？」
本文只读分析，**没有改任何游戏文件**；§6 的改法只是提案。

## 0. 结论先看

- **没有「远程抢怪」效应。** 同一名干员（同角色、同档位）比较，队里远程队友从 0 个变成 1 / 2 个时，近战主控的伤害占比反而 **+6%**（相对值），近战队友胜局每分钟伤害 **+8% / +11%**；远程也一样涨。表面上的「近战占比随远程增多而下降」（主控 37% → 29%）是编队构成造成的：远程队友多的局里塞雷娅、凯尔希这类低输出近战占比更高。逐人看，斯卡蒂、水月、塞雷娅、凯尔希、星熊当主控时，远程队友 0 / 1 / 2 个对应的自身占比只差 ±4 个百分点（§2）。
- **后期也没有被远程挤掉。** 按局在第几分钟结束分组，近战队友的累计占比是 22% → 24% → 28%（3–6 / 6–9 / 9+ 分钟结束），越往后越高；乌尔比安当队友是 26% → 29% → 40%。主控占比随局时变长而下降，近战和远程降得一样多（近 43 → 33，远 54 → 43），原因是队友精英化后分走了伤害，不分近远（§3）。
- **胜率上近战反而更强。** 当前版本（10-10 ～ 10-12）主控胜率：近战标准 76% / Ⅷ 68%，远程标准 60% / Ⅷ 45%（干员等权：73 / 63 对 59 / 44）。编队里近战越多胜率越高：标准档 0 名近战 42% → 3 名近战 86%，Ⅷ 31% → 79%（§4）。
- **乌尔比安的伤害不弱，弱在保命。** 当队友时，他的伤害占比 36%、在队每分钟伤害 4.5 万，在近战里排第四（幽灵鲨 5.5 万 > 斯卡蒂 4.8 万 > 乌尔比安 ≈ 水月），胜局全队每秒伤害 +6%（相对同主控同档基线）。但有他的局，胜率比基线低 **8.9** 个百分点，主控低血秒 +2.7：他贡献伤害，却不帮主控挡伤害。当主控的云端样本在当前版本为 0；本机 2 局（seed 1 死于 4:55，seed 2 胜）他的占比 53–62%，参与击杀 62–68%（§3.2、§4.3、§5）。
- **真正偏弱的近战是艾丽妮**（当队友：占比 25%、每分钟 2.7 万、有她的局胜率 −21 个百分点、全队每秒伤害 −7%）**和当主控的德克萨斯**（43% / 29%，docs/72 已记录）。
- **判断：近战整体不需要因为「抢怪」去补。** 如果要动乌尔比安，应该补保护能力而不是补伤害；§6 给出 3 个改法和云端测法。

## 1. 数据与口径

- 云端结果分支：`ls-*`、`ru-*`、`fsm-*`、`fsm2-*`、`rp-*`、`rs-*`、`rl-*`、`sks-*`、`sk4-*`、`sk5-*`、`bx-base-2`、`bg-x-A`、`b3i-*`，共 51 批，代码 269d066 ～ ceefcc52（10-10 ～ 10-12），全部是 `--maxt=1000`，机器人 expert（标准）/ master（Ⅳ、Ⅷ）。去掉同 seed 同结果的重复局后 **2669 局**，其中 3 人编队 2656 局。乌尔比安、斯卡蒂、艾丽妮的玩法代码 10-10 以后没有改过，数据可比。
- 来源 → 干员：按 `game/data/characters/*.json` 的 `hit_sources` 键（与 `squad.gd` 写进 `g.hit_src[k].op` 的规则相同；一个来源名属于多名干员时取编队里的那一个）。旧名补映射：`火山弹` → 艾雅法拉、`沐雨` → 流明；`骑士`（结局二同伴）和 `HIT_BASE`（援护、藏品、地雷……）记「其他」。未映射来源占比 1.7%–8.4%（主要是骑士）。
- 近战：乌尔比安、斯卡蒂、艾丽妮、塞雷娅、星熊、推进之王、德克萨斯、归溟幽灵鲨、水月、凯尔希（Mon3tr 贴身，按 docs/72 算近战）。远程：维什戴尔、艾雅法拉、铃兰、能天使、安洁莉娜、浊心斯卡蒂、逻各斯、流明。
- 「占比」= 该干员伤害 ÷ 全队总伤害（含其他）。「dpm」= 伤害 ÷ 在队分钟数（队友从 `bot.recruit_t` 入队时刻算），只取胜局（胜局都打满约 11 分钟，排除局长差异）。
- **限制**：BALANCE 记录只有整局按来源的 `out`，没有按时间分段、也没有按干员的击杀（`telemetry.op_kills` / `out_bins` 只进作战记录，不进 BALANCE 行）。所以 §3 的「阶段」用两种替代：按局结束时间分组的累计占比（云端），和本机同 seed 截断（`--maxt=180/360/540`，同 seed 可复现，截断局就是整局的前缀）。「接敌时间」没有任何字段可用，见 §6.3。
- 本机 6 局：`balance_run.py --op ulpianus --bot expert --extra="--maxt=<180|360|540|1000> --tier=0 --runslog=…"`，seed 1 四个截断 + seed 2 两个截断；没有脚本错误；输出在会话临时目录，没有提交。

### 5.2 招式核对（`ulpianus.gd` / `ulpianus.json`）

- 锚击：`melee_hit(c, 0, PI, reach)`，圆心在身前 0.55×reach，**半径 105 的整圆**，命中圈内全部敌人，间隔 1.4 秒。对怪群是有效的（群体估计 7.8 个/次，全员第二）。代价是出手慢：同样贴脸，斯卡蒂 0.7 秒一扫。
- 当队友时走 `melee_spot(LEASH 200)`：追主控 200 内的最近敌人，主控身边出现更近的怪就换目标（「护主」）。所以不会出现「远程把怪打死在外圈、近战够不着」的情况——近战队友本来就主动压上去。
- S1「必须接触」：6 技力，优先钩**最近的精英**，钩至多 2 个（「不容挣脱」后 5 个）拽到面前眩晕再砸。对群是小范围 ×1.7，主要价值是点精英。钩到 Boss 时自己弹过去。
- S3「必须开辟」：落点半径 140 ×3 并眩晕 3 秒，然后**自己顺锁链弹到锚点**（最远 400）。当队友时自动掷向敌群最密处，这会把他带离主控身边；当主控时由玩家选点，机器人就绪即放。
- 天赋「血脉滋养」靠击杀精英叠攻击（每层 +4%，上限 10 / 15）；精二「血脉沸腾」击杀精英后下一击 ×2.5 大爆破。**他的成长挂在精英击杀上**，被远程先打死的精英确实不给他层数——这是全文唯一说得上「抢怪」的地方，但伤害数字（§5.1）显示影响不大。
- 结论：他的伤害手段对怪群有效，S1 / S3 的位移让他在关键时刻离开主控，这和「伤害高、胜率贡献低、主控低血秒 +2.7」一致。

## 6. 判断与改法（提案，未实现）

**判断**：近战没有因为远程抢怪而变弱。近战主控胜率高于远程（标准 +16、Ⅷ +23 个百分点），近战队友的伤害不随远程队友增多而下降。乌尔比安的伤害在近战第一梯队下沿；他弱的是「对主控的保护」，不是「打不到怪」。如果用户觉得他「弱」，更可能是手感：1.4 秒一锤、S3 要自己瞄、成长靠精英击杀。真正该先看的是艾丽妮（伤害和胜率贡献都垫底）和德克萨斯主控（docs/72）。

以下改法按「不改变近 / 远整体平衡」排序。每条都给出云端测法（口径同 docs/72：标准 = `--tier=0 --bot expert`、Ⅷ = `--tier=2 --bot master`、`--maxt=1000`，每组 56 seed）。

### 6.1 乌尔比安「护主钩」（推荐，针对他自己的短板）

- 改法：当队友时，S1 的目标从「最近的精英」改为「离**主控**最近的精英；没有精英时，离主控最近、在主控 120 内的敌人」；钩回的落点仍是他自己面前。S3 当队友时的落点限制在主控 260 内（现在是 400 内最密处），弹射后不离开主控太远。
- 预期：主控低血秒下降，「有乌尔比安时的胜率差」从 −9 往 0 靠；伤害基本不变（S1 本来就是点精英）。
- 测法：没有固定队友的预设，用固定编队 A/B：
  `python tools/balance_run.py --squad wisadel,ulpianus,lumen --seeds 56 --bot expert --extra="--maxt=1000 --tier=0"`（另配 `skalter,ulpianus,suzuran`、`eyjafjalla,ulpianus,kaltsit`），改前改后各一份，看主控胜率、`bot.low_hp_s`、`bot.taken_pm`。

### 6.2 近战对精英 / Boss 加成（如果要补近战伤害手感）

- 改法：已有旋钮 `base.vs_elite`（`melee_hit` / `area_hit` 自动乘，铃兰 / 塞雷娅在用）。给乌尔比安 1.0 → 1.25（他的成长挂在精英上，和定位一致）；艾丽妮 1.0 → 1.3（她已有「对浮空 / 眩晕 +30%」，精英浮空时间短）。只给伤害、不给生存，按用户「标准档不收紧」的口径不影响难度目标。
- 预期：Boss 战时间缩短；整局胜率变化小（§4.3 显示伤害不是胜负主因）。
- 测法：`--bal` 不能改单个干员的 base，需改 JSON 后 `python tools/check.py --ab <ref>`，加上 `b3i` 同口径的乌尔比安 / 艾丽妮主控批：
  `python tools/balance_run.py --op ulpianus --bot expert --seeds 56 --extra="--maxt=1000 --tier=0"`（及 `--tier=2 --bot master`），看胜率与 `bosses` 击破时间。

### 6.3 先补遥测，再谈抢怪（推荐，零玩法影响）

- 改法：BALANCE 行（`telemetry.record()`）加 `op_out`（按干员的来源伤害）、`op_kills`、`out_bins`（10 秒一格，按干员）——这些作战记录里已经在算，只是没写进批跑记录；再给近战干员记一项「出手时射程内无敌人的秒数」（`idle_cd` 分支累加），作为接敌时间的代理。
- 预期：下一轮云端批就能直接算每分钟阶段的占比、按干员击杀、近战空挥率，不用本文的替代口径。字段改名要同步 `tools/balance_run.py` 与 SCHEMA。
- 测法：同 seed 复现不受影响（只记账），`python tools/check.py` 过即可。

不建议：「近战共享击杀计数」（击杀信用目前只影响作战记录显示和乌尔比安天赋，改它对平衡几乎没作用）；全体近战「突进拦截」（近战队友已有 200 前压，近战主控胜率已经高于远程，再加会扩大差距）。
