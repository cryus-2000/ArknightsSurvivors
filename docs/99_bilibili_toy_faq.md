## 一、发布与审核

1. **Toy审核需要多久？** 正常情况下，审核在10分钟内完成。只要Toy本身内容合规，无需担心审核时长。若有异常迟迟未过审，可联系平台工作人员协助排查。
2. **小站发帖需要审核吗？审核多久？** 需要，有一定审核时间，通常较快。若未通过审核，多数是因为内容不合规（如涉及引导至站外注册等）。
3. **发布后Toy不见了或打不开怎么办？** 可能是您使用的访问路径（slug）与历史已有条目重复，建议重新发布并更换一个slug。
4. **一个账号可以发布多个Toy吗？** 可以，目前没有数量限制。
5. **Toy支持哪几种可见状态？** 支持「所有人可见」「链接访问」「密码访问」三种状态，可在管理后台互相转换。
   - 5.1 所有人可见：系统会使用当前上传Toy的账号自动发布一条公开动态；Toy 及相关动态可被搜索、推荐和分享。
   - 5.2 链接访问：用于在开发者可知可控的范围内测试。仅持有链接的人可以访问 Toy 和关联动态，该动态不会在首页、动态、个人主页、搜索等出现。
   - 5.3 密码访问：系统生成访问密码。仅持有密码的人可以访问，该动态将隐藏封面和完整标题。
   - 5.4 三种状态可互转：已发布的 Toy 在更新时选择新的发布方式即可。从链接 / 密码转所有人可见后，关联动态由隐藏变公开；反之动态在所有场景隐藏，仅持链接者可继续访问。
6. **Toy最大支持多大的文件包？** 内测早期作者保留 140MB 特权，新参与内测用户为 50MB，超出部分需单独申请。
7. **发布后还能修改文件吗？** 支持无限次修改文件并更新网页内容，在「发布记录」-「更新」中操作。
8. **能自定义Toy的访问路径吗？** 支持自定义 slug，在「上传发布」-「页面地址」手动输入。
9. **视频和Toy想同时上线，担心Toy卡审核？** 审核流程稳定。可先以「链接可见」发布，过审确认无误后再转公开。建议多次修改攒在一起统一更新，减少审核次数；若仍频繁卡审可联系平台做特殊处理。
10. **发布Toy有门槛吗？** 进入发布页面即可发布，无需事先提交创意。账号尚未获得 Toy 权限的须先通过权限申请。
11. **分类Tag与作品图标可以自定义吗？** 已支持分类 Tag（工具、攻略、游戏等）与自定义图标；系统自动分类可能有偏差，可自行修改。
12. **发布入口在哪里？如何申请内测资格？** PC 端创作中心侧边栏已新增 Toy 入口；未获资格的走「Toy权限唯一申请入口」（原帖链接）。
13. **Toy 能限制未成年人游玩吗？** 可以。类型设置为「游戏」后，未成年人自动无法游玩；未成年开发者测试阶段可先不选「游戏」分类。
14. **新建 Toy 的封面 / 图标上传后看不到？** 封面与图标同样需要审核，审核期间可能不显示。

## 二、视频与Toy联动

1. **发布时可以绑定视频吗？** 可以，仅支持绑定本人发布的视频；在「发布记录」-「管理」-「视频绑定」操作。
2. **多对多？** 一个 Toy 可绑定多个视频，一个视频只能绑定一个 Toy。
3. **绑定视频的作用**：Toy 会出现在视频下方的入口位置。
4. **不绑定能拿视频流量吗？** 绑定是前提；建议同时绑定视频 + 简介 / 评论区挂链接。
5. **与哔哩哔哩Toy官方账号联合投稿**：视频发布后联系运营评估。需 UP 主权益等级 ≥4 级且粉丝数达一千后解锁联合投稿；稿件达 10000+ 播放后评估；投稿必须带 tag `bilibilitoy` 和话题「哔哩哔哩Toy创意挑战」，分区不限。
6. **Toy 内显示 B 站视频**：可使用 bilibili 播放器 iframe（player.bilibili.com）。
7. **竖屏视频有帮助吗？** 有。推荐「一条横屏 + 多条竖屏爽点切片 + 图文」组合；部分 Toy 流量中竖屏短视频来源占 37%–50%。
8. **战绩截图分享到动态？** 目前可将 Toy 入口以二维码形式放入分享内容。
9. **Toy内生成并下载视频？** 目前仅图片类型支持保存到本地。

## 三、SDK功能

1. **SDK支持哪些功能？** 见发布平台顶部【SDK和CLI】：云存档、排行榜；关注检测、三连判断；获取昵称头像；检查包月充电；二维码 / 保存图片 / 网页跳转；摄像头 / 麦克风采集、横竖屏与沉浸模式。
2. **判断三连**：`toy_getuservideoaction`。
3. **昵称头像**：通过 SDK 接口获取，需要时 SDK 自动调用。
4. **排行榜扩展字段**：向运营提交需求说明文档评估。
5. **评论区**：手机端 Toy 页面下方已支持评论互动。
6. **SDK文档**：官方链接（需登录有 Toy 权限的账号）。
7. **横竖屏、沉浸全屏**：JS SDK 容器状态能力——读取 / 监听设备类型、可用尺寸、横竖屏、沉浸状态和安全区；`setContainerMode` 切换；需 B站 App ≥ 9.9.0。
8. **录音权限**：见 SDK 文档录音部分（需权限账号）。
9. **超广角摄像头**：不支持。
10. **用户位置**：API 尚未开放。
11. **本地存储易丢**：重要数据优先云存档；云存档多端同步，手机与电脑不一致先确认测试时已授权登录。
12. **频率限制**：排行榜与云存档对单个 Toy 限流约 50 QPS；用本地缓存 + 定期保存，拉取做「加载中」。
13. **排行榜数值上限**：存在最大数值限制，跨平台 Float32 适配最好；可本地对上传值 / 展示值做偏移；排行榜 SDK 不参与数值展示。
14. **沉浸模式顶栏（胶囊）坐标尺寸**：可获取，由 SDK 提供；交互元素避开安全区。
15. **「充电畅玩」/ 获取作者全部 Toy**：基于充电相关 SDK + 自建索引 Toy。
16. **添加到桌面**：已支持；注意识别用户所处环境（不同端能力有差异）。
17. **上传成绩处「必须关注」**：不推荐在主线强制；可在复活、强化、新武器等环节加关注引导；须保留免交互可见内容。
18. **陀螺仪等传感器**：已在计划中，暂未排期。
19. **排行榜存数字以外的数据**：当前支持 5 个排行榜，可分别存储、合并展示。
20. **移除榜单用户**：会同时移除其所有榜单记录，暂不支持只清单个榜单。

## 四、内容规范与合规（重要！）

1. **版权**：所有素材须版权合规，参考视频 / 图文标准；版权方投诉平台依法处理。
2. **用户自建昵称头像**：不可以。用 SDK 用户信息或系统随机；可提供预置候选昵称。
3. **自由输入框**：须自行接入内容安全审核。
4. **禁止事项举例**（以用户协议为准）：不得放置广告；不得跳转站外；不得侵权；不得允许用户自建昵称 / 头像；自由输入需接审核；不得以锁死基础功能为条件提供附加体验；不得出现第三方平台登录 / 跳转；不得常驻式引导干扰体验。
5. **UGC 安全红线**：用户自定义上传内容（文字 / 图片 / 拍照、聊天室、画板）属安全红线，平台向「权限点审核」收敛，代码层面禁止未授权 UGC；已接审核的文本输入且不允许上传底图的场景仍以平台审核结论为准。
6. **名称、封面、标题、图标**：不涉政、不涉黄、不侵权、不用他人商标。
7. **模拟特定机构 / App 界面**：须在显著位置标识「并非真实 … 界面」。
8. **BGM / 音效**：须版权合规，建议无版权或已授权素材。
9. **跟热点**：可行，不得涉黄涉政、违反社区公约与法规。
10. **引用外部资源**：尚未禁止但权限将逐步收敛，尽量减少依赖；绝对禁止 UGC（含内嵌框架实现的聊天室）。
11. **第三方平台登录**：不可以；Toy 默认自动登录 B 站账号。
12. **引导站外（爱发电等）**：不可以；不得提供第三方收款方式，违规限流或下线；引导充电请引导到作者 B 站个人主页。
13. **b23 短链**：不建议，约一年后失效。
14. **问卷调查**：可以，需自建后端，不得收集敏感信息。
15. **赞助名单**：可以，合规要求与视频感谢充电粉丝一致。
16. **必须保留免交互可见内容**：是；至少 1 个用户可免费获取的内容 / 资料。

## 五、数据与统计

1. **浏览量**：B 站 App 内具备登录态的用户访问才计入。
2. **单款数据**：Toy 详情页顶部。
3. **收录进【哔哩哔哩玩具铺】**：浏览量超 500 后收录，每周一更新。
4. **Toy 广场双端上线**：任意 Toy 详情页右上角广场图标进入；只收录「公开可见」的 Toy。
5. **广场 / 每周必看**：公开发布即收录，无体验量限制；「本周必玩」每周一晚更新；每周必看由运营按当周体验量、互动、质量精选 6–10 个，分「娱乐」「工具」两赛道（工具赛道相对不拥挤）；可参照 Toy 运营白皮书。
6. **留存数据**：数据看板已有「次日留存率」。
7. **「今日推荐」**：系统自动，游玩量高自动上榜。

## 六、推流与推广

1. **推流多久会有**：不固定；视频封面点击率越高自动推流越长；一般提交申请后一天内推流，系统显示「已推」并私信通知。
2. **推流申请表**：按官方表格要求并带指定 tag 和话题；反馈一般 24 小时内。
3. **新游曝光难**：蹭热门标签、持续维护活跃度、经常发视频、拉玩家群；推流效果受首日数据影响。

## 七、技术问题

1. **哪些文件能上传**：只有白名单后缀的文件会被发布，其余（可执行文件、后端脚本）自动过滤；见「Toy发布常见问题」。
2. **数据共享 / 创意工坊**：暂不支持跨用户 KV 存储，已在规划。
3. **联机**：需开发者自建后端，利用云存档减轻压力。
4. **URL 打不开**：检查 URL 完整，不要遗漏 index.html。
5. **构建产物放 ZIP 根目录**：需要，根目录必须有 index.html。
6. **测试环境**：直接用正式环境，「链接可见」或「密码可见」+ 小号测试。
7. **外部资源 / WebGPU**：可引用外部资源；WebGPU 取决于 App WebView 与系统 / GPU，建议 WebGL / WebGL2 兜底，真机容器测试。
8. **预览与正式不一致**：预览生效但格式可能略有差异；带复现信息反馈。
9. **沉浸模式按键被安全区遮挡**：不要在安全区（尤其顶部）放交互元素；顶栏高度 SDK 有返回。
10. **iframe 外部网页**：不能。
11. **推荐技术选型**：ThreeJS、Unity、Canvas 2D 均可；**Godot 对 Web 兼容性一般（3.x 尚可、4.x 变化大且需全量下载），更适合单机**，Web 向推荐前两者。
12. **多机型按键适配**：公认难题，可允许玩家自行调节按键位置。
13. **刷分与反作弊**：管理端可拉黑；官方记录了「上传成绩时自定义轻量 JS 校验」方案并跟进通用能力；纯 B 站排行榜难以彻底反作弊，核心思路是后端运算；可用排行榜 Challenge 机制做弱鉴权 + 后端验签；充值 / 关注等前端校验可能被破解，宜作附加玩法。
14. **Unity 打包黑屏**：常因默认压缩或含 .mp4；关闭压缩、移除视频或 CDN 加载。
15. **Cocos 编译文件被过滤**：`.cconb.bin` 等会被过滤。
16. **后端服务 / 自有 API**：可以；需先开通相应权限，在发布平台查询状态。
17. **跳转与外链判定**：跳自己 B 站主页可以，站外不允许，尺度同个人主页 / 视频简介；wiki.biligame.com 等可蓝链站内域名不算站外。
18. **旧客户端无法横屏**：升级客户端；或做旋转自适应，旧版用户自行旋转。
19. **预发布 / 调试环境**：计划推出「调试版本」（免审、仅作者可见）；现阶段用两个 Toy 区分测试版与正式版。
20. **多 Toy 串联 / 共享进度**：Toy 间跳转串联；「同用户不同 Toy 共享 KV」开发中，跨用户共享 KV 在规划。
21. **代码会被盗用吗**：纯前端易被还原；核心逻辑放自建后端 + 鉴权 + 官方 SDK。

## 八、B站App内体验

1. **找到玩过的 Toy**：平台规划中；开发者可置顶动态、建议粉丝收藏；手机端公开 Toy 在动态里找，非公开去发布页；PC 端投稿中心-图文管理（含加密 / 隐藏动态）。
2. **桌面快捷方式开屏广告**：系统层面行为；iOS 默认浏览器非 Safari 时添加到桌面可能打不开，官方只对 Safari 做了适配。
3. **鸿蒙版**：已支持进入和使用，暂不支持点赞、评论等互动。
4. **国际版 / 海外版**：支持，功能完备程度低于国内主站。
5. **沉浸模式评论栏**：默认隐藏。

## 九、运营与支持

1. **官方工作时间**：不定期查看消息，看到后及时回复。
2. **提问去哪**：Toy 开发者小站发帖。
3. **「建议配合Agent使用」**：把 Toy 开发文档和 SDK 文档配置给 AI 编程助手辅助开发。
4. **权限申请处理**：每周二、周四集中处理。
5. **下架 / 审核不通过查原因**：内测群公告中的审核咨询入口；先自查是否有自由输入、外链或不合规资源。

## 十、收益与商业化

1. **Toy有收益吗**：本身不直接产生收益，流量可辅助关联视频；第三方广告不可行；已知「商单 + 视频」组合变现，取决于账号影响力。
2. **广告联盟 SDK**：暂不支持。
3. **付费功能**：不支持支付；可查包月充电做定制体验（非实时扣款、前端校验可能被破解，建议用于额外玩法或精神奖励）。
4. **其他平台发布过 / 独家**：创作版权属作者，Toy 不要求独家；其他平台已发布内容能否再发以该平台协议为准。
5. **B站小店 / 带货**：开发中，暂未开放。
