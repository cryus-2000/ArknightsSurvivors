# 维什戴尔终结技「更华丽」原型（11-17）

用户 11-17：希望维什戴尔的终结技 Q「太空大扫除」更华丽。本页是诊断 + 两个方向的原型，**等用户挑**，未定稿、未合 main。
分支 `claude/sleepy-austin-c9073a`。开关 `ult/wd_proto`（缺省 0 = V2.2 原样）：1 = 方向 A，2 = 方向 B，3 = A + B。

## 1. 诊断（现版为什么不够华丽）

1. **没有一记「最重的」**：6 排 × 3 发 = 18 团大小相近的红色尖晶爆裂，0.5 秒内平铺落完，节奏是匀速的「哒哒哒」，没有起伏，也没有收尾大爆。冲击帧给在第一排，后面越打越弱。
2. **和普通技能没拉开**：主体帧条就是她普攻 / 技能同一套红色尖晶爆裂，只是数量多；放终结技的那几秒里她的普攻（`op_wisadel_atk / big / quake`）照样在打，画面和声音都混在一起。
3. **没有前摇蓄力**：按下到落地只有 0.15 秒，预兆是细红环 + 细拖线，在满屏怪里几乎看不见（11-04 用户也否过细环）；「架炮—锁定—开炮」这层仪式感缺失。
4. **炮弹没声音（bug）**：11-06「只改颜色」把爆裂帧条换成 `fx_wd_cannon_br`，但 `ult_audio.json` 只给 `fx_wd_cannon` / `fx_wisadel_cannon` 配了 `shell_1–3`，新帧条没规则 → 18 发炮弹全程无声，只剩一声 impact 和余震碎石声。实测 V2.2 录像音效记录里 `shell_*` 为 0 次。
5. **炮击带大半在屏外**：带长约 1000（第一排 -40、末排 +810），横屏视野高约 720，竖屏更短；后两排基本看不到。

## 2. 两个方向（可叠加）

### A「蓄力锁定」（`ult/wd_proto=1`）
- 前摇加 0.32 秒：炮口三层实心热芯由小到大（暗红 → 红 → 橙白）+ 往炮口收的火星 + 一盏灯。
- 一条红色测距光从炮口逐排扫过，每个落点留一个实心红锁定点（菱形芯 + 粗十字，不画细环 / 半透明盘），一直亮到落地。
- 开炮：大炮口焰（原 `fx_cannon_burst_br` ×3.2）+ 一道炮口光刃 + 后坐尘 + 轻震 4 px 0.12 秒 + 新音 `salvo`（原作 `p_atk_blackcannonoverload_h`）。
- 天降弹道改粗（每发一条头亮尾红的光刃斜砸下来），取代细拖线。
- 代价：全部落点晚 0.32 秒（伤害总量 / 比例不变）。

### B「轰炸节奏 + 终爆」（`ult/wd_proto=2`）
- 排间隔由宽到密：0.12 / 0.11 / 0.09 / 0.08，末排前停 0.2 秒（总长仍 ≤ 1.2 秒）。
- 末排落地同时在她正前方 300 处补一记终爆（只画面，判定仍是末排三发）：大爆裂帧条 ×4.4、爆亮冷却（大灯 0.35 秒）、不规整分叉裂网（热红 → 焦黑，按裂地 v3 做法）、尘墙、隆起 + 余震碎石、两团大烟尘、轻震 5 px 0.2 秒、新音 `finale`（原作 `p_imp_blackcannonfull_h` + `p_skill_aeroliteexplo` 降速叠）。
- 冲击帧从第一排挪到终爆这一下（整屏白 + 黑剪影保留）。
- 余烬：弹坑留 3.4 秒（原 1.6），约一半弹坑冒慢火星。

### 两个方向共有
- 修第 4 条 bug：`ult_audio.json` 给 `fx_wd_cannon_br` 补上 `shell_1–3`（与原规则同音量）。这一条不管选哪个方向都建议收。

## 3. 性能与低画质降级

- 低画质（`Cfg.quality == "low"`，手机自动档会落到这里）：不画聚能火星、后坐尘、尘墙、大粒子、余烬；裂网 10 → 5 条。只留帧条、灯、实心锁定点和弹道。
- 帧时对照：`python tools/wd_proto_perf.py`（同种子同局，wd_proto 0 / 3 × 画质 high / low，取每次充满后 2 秒窗口），结果见 §5。
