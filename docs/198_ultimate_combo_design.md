## 0. 结论（供审）

1. **三层，一个按键各管一层**：Q = 队长**终结技**（一局 3–4 次，基础约 150 秒充满）；E = 队友**连携技**（条件满足亮起约 2.5 秒，按 E 出手）；Q 在「终结技满 + 协同满」时升级为**连携终结技**（一局约 1 次，吃掉终结技能量）。
2. **20 人终结技全按用户给的方向写**（§4），每人固定一种形状，范围按同一口径对齐到**屏幕面积 45–55%**（桌面参考视野），威力按「目标当前生命的比例」统一定档：核心区小怪成片倒、精英掉约 40% 最大生命不死、Boss 掉 6–8%（§3）。
3. **连携技每人一个触发条件**，四类各 5 人（§5）；原作关系组合 4 组有出处（企鹅物流、深海猎人、审判庭、德克萨斯 × 拉普兰德），在队时连携升级、并给连携终结技专属版（§6）。
4. 新系统取代 4 套旧东西：响应动作（docs/118）、隐藏连携技（docs/160 / `synergy.json`）、钩与锚联动（`balance.json combo/hook_anchor`）、手动技能体系（乌尔比安 S3 `mode: manual`）。删除清单见 §10.3。
5. 实现分期：第一批 5 人原型（德克萨斯、能天使、浊心斯卡蒂、凯尔希、乌尔比安）→ 量化对齐（§3.4 测试场景）→ 铺开 15 人；连携技在第一批对齐后接入，连携终结技最后接，之后整局重新校准难度（§10）。

## 1. 用户 10-29 已定的规则（照写）

### 1.1 终结技（队长，Q）

- 每名干员**新设计**一招，不复用 S1–S3，**不单独起名**，界面只写「终结技」。
- **频率（10-29 修订，取代「约 60–90 秒满」）**：一局 3–4 次。基础约 150 秒充满，接连携最多缩到约 120 秒；首次约 2:30；最终 Boss 带满条进场约 1 次；连携终结技一局约 1 次（会吃掉终结技能量）；满条不溢出、可以留着。因为次数少，每次都要足够夸张。
- 能量来自输出 / 击杀 / 接上连携（一大截）/ 少量受伤。
- 放出：先顿帧 0.1 秒 + 放慢约 0.5 秒 + 屏边立绘切入（Boss 战也切）+ 原作语音一句。
- **不必全清**：一大片范围内小怪成片倒，精英和 Boss 吃重伤不死，范围外不受影响，刷怪不停。
- 瞬发为主，少数「瞬发 + 短持续」；召唤型可以。每人固定一种形状；瞄准（不瞄 / 指方向 / 选落点）按人定，按下时慢动作便于瞄准。
- 演出要夸张：顿帧、镜头推拉、重震屏、分层特效、敌人被击飞 / 碎裂、余波。
- 精英化第 4 节点的二选一路线改变终结技形态。
- 要符合人设，能力要有原作依据。

### 1.2 连携技（队友，E）

- 终末地式。每名干员一个触发条件（四类：跟队长动作 / 跟敌人状态 / 跟队长危险 / 跟队友连携），满足后头像亮起约 2.5 秒，按 E 出手（手机：一个会亮的按钮），干员冲到目标处出招再回队。
- 各自冷却约 12–20 秒，不新增资源。**不起名**。
- **自动连携不打折**（手动的优势 = 选时机与方向）；漏按无惩罚；多个亮起先放最早亮的，其余排队。
- 每接一次给队长终结技一截能量 + 一格「协同」。
- 原作关系组合（须有出处）在队时连携升级（合击 / 自动接一段），首次触发进图鉴。

### 1.3 连携终结技（全队）

- 协同攒满约 6–8 格且终结技能量满时 Q 升级，一局一两次（10-29 修订后按约 1 次设计，§2.3）。
- 全队同时出招，演出最大（放慢约 0.8 秒），全屏级伤害 + 全队增益。
- 有原作关系组合时给专属版（用势力 / 组合名，须有出处，首次进图鉴），否则通用版（系统名本作自拟）。

### 1.4 设置、机器人、校准

- 设置加「自动连携」「自动终结技」两个开关；机器人要会用。
- 加入后整体重新校准难度：目标 无认知 30–40% / 18 细胞 50–60%，只用不给奖励的旋钮。
- 现有手动技能体系（只有乌尔比安 S3 `mode: manual`）并入终结技。乌尔比安 S3 另换一个适合自动的新技能：**待定，见该方案**（另一会话在出）。

### 1.5 约束

- 手机网页守 30 帧（贴图合批、粒子上限、低画质减层）。
- Boss 战终结技特效压淡一层，不盖住预警与弹幕。
- 设置「减少闪光」。

## 2. 能量、协同与按键

### 2.1 终结技能量（满 100，不溢出）

目标节奏：不接连携 150 秒满；接满连携 120 秒满；首次 2:20–2:40。最终 Boss（10:00）进场时玩家手里有一条满的（9:30 之后能量自然满或之前留着）。

| 来源 | 规则（草案） | 期望占比（150 秒那条） |
|---|---|---|
| 输出 | 全队每造成「当前时刻普通怪基准最大生命 × 1」的伤害 +0.06（按 `enemy_hp_time_mult` 归一，后期不暴涨） | 约 50% |
| 击杀 | 普通怪 +0.1，精英 +3，中期 Boss 每阶段 +5 | 约 40% |
| 受伤 | 每损失 1% 最大生命 +0.15，每 10 秒至多 +1.5 | 约 10% |
| 接上连携 | 每次 +2（按 E 或自动都算）；每 12 秒至多计 1 次 → 最多约 0.17 / 秒，正好把 150 秒压到约 120 秒 | 额外 |
| 擦弹（只在最终 Boss 战，设计总纲 §3 C2） | 每次擦弹 +0.3，每秒至多 +0.6 | 额外，只影响最终 Boss 战第 2 次 |

- 每秒总获取上限 1.0（密集时刻也不会 100 秒内满）。
- 构筑能加快充能，但合计不超过 +15%（藏品 / 卡 / 认知各自的加成在这里封顶），保证一局仍是 3–4 次。
- 满条后不再获取，也不衰减；HUD 满条时有呼吸光（不弹字）。
- 机器人 / 自动终结技也按同一套能量走。

估算一局：2:30 第 1 次 → 约 4:50 第 2 次（多半是连携终结技，§2.3）→ 约 7:20 第 3 次 → 最终 Boss 进场留着的一条（第 4 次）。玩家留着不放会少一次，这是「省着用 / 现在用」的取舍。

### 2.2 协同格

- **7 格**（用户给的 6–8 取中）。每接上一次连携 +1 格。
- **每格最短间隔 40 秒**：40 秒内接多少次连携都只计 1 格。所以协同最快 280 秒满（约 4:40），一局第二次最早 9:20 左右才可能满。
- 放连携终结技后协同清零；放普通终结技不影响协同。
- 结果：一局约 1 次连携终结技（4:40–5:30 前后）；如果玩家把第二次协同留到最终 Boss，可能有第 2 次（见 §11 拍板项 3）。

### 2.3 Q 的升级

- 终结技满 + 协同满：Q 按钮换成连携终结技的样子（金色描边 + 全队头像环），按 Q 放出的就是连携终结技，消耗全部终结技能量与协同。
- 不提供「满了也放普通终结技」的二选键：想放普通的就在协同满之前放。

### 2.4 按键与界面

| 平台 | 终结技 | 连携技 |
|---|---|---|
| 键盘 | Q（按下：顿帧 + 慢动作进入瞄准；松开或慢动作结束时放出） | E（排队里最早亮的那名队友出手；朝向 = 当前移动方向，没有移动输入时朝目标） |
| 手柄 | RB / Ⓐ（沿用现手动技能映射，`pad.gd`） | Ⓨ（现映射里 Ⓨ 是 E） |
| 手机 | 右下大圆键，按住拖动瞄准、松手放出 | 终结技键左上一个小圆键，亮起时显示该队友头像 |

- 现状：`doctor.gd` 里 Q / E / J 都路由到手动技能；本稿把 E 改给连携技，Q 给终结技，J 只在「手动普攻」时是攻击。
- 「指方向」型：慢动作期间用移动方向（键盘）或右摇杆 / 拖动（手机）定方向，松开前不动就朝最近的敌群。
- 「选落点」型：落点光标默认放在「队长前方 260、敌人最密处」，慢动作期间移动光标；落点距离队长不超过 520。
- 慢动作 0.5 秒是游戏时间放慢到 25%（真实时间约 0.5 秒）。按住超过 0.5 秒：保持 25% 慢动作最多再 1 秒，然后自动放出（防止拿它当暂停）。

### 2.5 终结技头像亮起与连携排队

- 连携条件满足 → 该队友头像亮起 2.5 秒（边框从亮到暗的倒计时环），手机连携键同时亮并换成该队友头像。
- 多人同时亮：排队，E 先放最早亮的；后面的在队首出手后接着亮满剩余时间。
- 漏按：亮起结束什么也不发生，冷却不走（下一次条件满足再亮）。
- 自动连携开：亮起 0.6 秒后自动出手（给手动玩家留出抢先手的空间但不压收益）。

## 3. 范围与威力对齐

用户要求：每个人的范围不要差太多。统一用两把尺子：**屏幕面积占比**（范围）和**按目标生命比例定的威力档**（伤害）。

### 3.1 范围口径：屏幕面积占比

- 参考视野：桌面缺省镜头的可见世界范围 **1524 × 857**（`render/view_h_desk` 1080 ÷ 桌面缺省缩放 1.26，16:9）。手机横屏参考 1268 × 585（`render/view_h_phone` 585，19.5:9）。
- 占比 = 终结技伤害区域与「以队长为中心的可见矩形」重叠的面积 ÷ 可见矩形面积。

### 3.3 威力口径：按目标当前生命比例定档

不按「攻击 × 倍率」定伤害，直接按目标生命定，这样 20 人同一档、前期后期同一档、Boss 不被秒：

| 目标 | 一次终结技（含持续段与余波）的总伤害 | 说明 |
|---|---|---|
| 普通小怪（核心区） | 当前时刻普通怪基准最大生命 × 2.0 | 非重型小怪在核心区必倒；重型 / 高护甲小怪（基准生命 2.5 倍以上）约一半倒下 |
| 普通小怪（外缘 15% 宽的衰减带） | × 0.8 | 边缘有漏网的，画面上看得出范围 |
| 精英 | 该精英最大生命的 40% | 有「重伤不死」保底：本次终结技最多打到剩 10% |
| 中期 Boss | 最大生命的 8% | 每阶段至多吃 1 次满额 |
| 最终 Boss | 最大生命的 6% | Boss 战特效压淡一层（§7.4） |
| 召唤物 / 部件 | 按所属本体档 | |

- 构筑影响：总伤害 × (1 + 0.5 × 全队伤害加成)，上限 × 1.3。法伤 / 物伤 / 真伤加成都按这个口径折算，不再各自乘。
- 处决类（逻各斯）：小怪生命低于当前基准 × 2.0 直接处决，和上表同一档；对精英不处决，按 40% 走。
- 控制：小怪击飞 / 眩晕 / 悬浮不设上限；精英控制 ≤ 1.5 秒；Boss 只给打断当前读条以外的 0.3 秒硬直（Boss 免疫的照旧免疫）。
- 持续段（熔岩、领域、巨锯）计入同一预算，不额外加。
- 附带增益（全队攻击、回复、护盾）不算伤害预算，但也统一档：全队增益持续 8 秒，攻击类 +20% 以内，回复类 ≤ 每秒 2% 最大生命。

### 3.4 原型后的量化验收

**同一测试场景**（新测试 `ult_bench`，无头运行，同 seed）：

1. 时间点锁 5:00 的敌人倍率；队长在场景中心；屏内（桌面参考视野）均匀摆 120 只普通小怪（其中 12 只重型）、3 只精英（距队长 200 / 350 / 500，分在默认瞄准方向两侧）、1 只中期 Boss（距 420，只测伤害）；敌人不移动、不攻击。
2. 每人放一次终结技，瞄准按 4 个方向（右、右上 45°、上、敌群最密处）各跑一次，取平均；选落点的落点取默认光标。
3. 记录：屏内小怪倒下比例、重型小怪倒下比例、3 只精英平均掉血比例、Boss 掉血比例、从按下到最后一次伤害的时长、峰值同屏粒子数、手机网页低画质帧时间。

**对齐标准**：

| 指标 | 目标档 | 允许偏差 |
|---|---|---|
| 屏内小怪倒下比例 | 45–55% | 20 人极差 ≤ 12 个百分点 |
| 精英平均掉血 | 40% | ±5 |
| 中期 Boss 掉血 | 8% | ±2 |
| 瞬发型时长 | ≤ 1.2 秒 | — |
| 瞬发 + 短持续型时长 | ≤ 3.5 秒 | — |
| 手机网页低画质 | 放终结技那 2 秒最低 ≥ 30 帧 | — |

偏了先改尺寸（范围），再改伤害系数；范围达标但「看起来小」的，改特效覆盖（特效铺满伤害区，不允许特效比伤害区大 10% 以上）。
第二个场景 `ult_bench_cluster`：同样 120 只但聚成 3 团，检查「选落点 / 指方向」的人在聚怪时的上限不超过 75%（防止某个形状在聚怪时一边倒）。

附注：§3.2 的占比用一段 Python 网格计数（6 像素网格，参考视野内逐格判断是否落在形状里）算出；原型接入后改由 `ult_bench` 在游戏里实测，以实测为准。

- **和现有区别**：S2「生存的渴望」是攻速 + 生命不低于 1，结束后倒下；S3「生存的重压」是加大环斩。终结技是**一把巨锯持续切 3 秒、可移动**，没有「结束后倒下」的代价。
- **人设依据**：原作 S2「生存的渴望」（技能期间生命值不会低于 1）；招聘合同「归溟幽灵鲨，自囚笼里挣脱，从疯狂中苏醒」；干员简介补充「战斗时的她总是疯狂的」。巨锯：用户定（10-29）。

### 4.12 水月

- **瞄准**：指方向。**形状**：身后地面破土一条巨型触手，朝指定方向横扫半圆（半径 640）；自身周围半径 300 钻出小触手。
- **效果**：巨型触手从他身后破土而出，0.5 秒扫过指定方向的半圆；扫完后 6 根小触手从地下钻出，抓住扫过区域里生命最低的漏网敌人并束缚 1.5 秒。
- **数值草案**：横扫 80%；小触手每根 20%，只打漏网（生命最低优先）。
- **附带**：每有一个敌人被横扫打倒，队长回复 0.2% 最大生命（天赋「反移情」的击杀回复口径，每次终结技至多 5%）。
- **路线**：惊跳反射 → 小触手 9 根；病理性依恋 → 被束缚的敌人被拖到水月身边。
- **和现有区别**：S3「镜花水月」是 N 秒全方向伞击 + 触手多打 2 个；终结技是**一条巨型触手的一次横扫**。
- **人设依据**：原作 S3「镜花水月」、语音「你什么时候产生了这些附肢只是幻象的错觉？」（作战中3）；第一天赋「创伤性癔症」（额外攻击生命最少的敌人）。巨型触手：用户定（10-29）。

### 4.13 塞雷娅

### 9.3 终结技语音可用的空闲条目

20 人的作战语音（作战中1–4、行动开始）已全部被 `skill_1–3 / battle / battle_2` 占用（`voice_manifest.json` 的 `source_clip` 对照 charword_table）。空闲且适合战斗的很少，主要是「3星结束行动」，例如：德克萨斯「不堪一击。」、推进之王「对拒绝投降者无需怜悯。」、斯卡蒂「敌人怎么说，怎么想，都与我无关。我只知道他们会怎么倒下。」、能天使「愿我的弹雨能熄灭你们的苦痛。」。所以缺省建议方案 A（§4.21）。
