## 1. 规则

- **按键**：键盘 **Q** 轮流切到编队里的下一名干员（按编队栏从左到右，绕回开头，跳过倒地的人）；**手柄 RB**；**触屏点编队栏头像**直接切到该人。技能键改为只留 **E / J**（键盘）与 Ⓐ / Ⓨ / Ⓧ（手柄，Ⓐ / Ⓨ 现在注入 E）；对局里手柄 RT 仍是冲刺（原先 RT 当 RB 触发冲刺，RB 让给切人）。设置 / 指南 / 选人里的操作说明已同步（Q → E，新增「切换队长」行）。
- **切换方式**：谁都不瞬移。被切到的干员原地成为队长，玩家位置 = 他的位置；原队长原地变回队友，恢复跟随逻辑（编队位互换：新队长占 0 号位、原队长占他原来的位置）。镜头约 0.25 秒缓动过去（`game.swap_off`，从「原来看的位置 − 新队长位置」按 smoothstep 缓动归零，镜头最终位置仍取整，不抖）。
- **冷却 2 秒**（`leader_swap/cd`），HUD 编队栏：冷却中非队长的卡上盖一层从上往下收的暗幕；下一名会被切到的那张卡左上角标键（键盘 Q / 手柄 RB，触屏不标）。切换**不给无敌**。
- **队长生命整局共用**，切人不换血条；队长相关显示（编队卡「队长」标签、升级 / 招募卡「队长 xx」、属性面板、作战记录）都按当前队长即时重算（`g.ch` 同步指向新队长）；手动技能只给当前队长（`is_manual` 本来就看 is_leader）；响应动作（队长冲刺 / 站定）和指挥模式（突击不含队长）自动跟随新队长。**倒地中的队友不能被切成队长。**
- **蓄力 / 瞄准状态**：切换时清掉进行中的手动技能蓄距离（doctor.charge）与蓄力循环音。
- **语音**：切换时播新队长的「出击」语音（指挥语音同一套 `command`，`urgent`，不受冷却节流）。
- **机器人不切换**；不按 Q 时本段不执行任何代码，同 seed 的 TRACE 与 main 逐行相同（`--auto` 快检过、`trace_base.py --here` 两组四人编队 300 秒逐行相同，见 §3）。

## 2. 实现

- `squad.gd`：`swap_leader(o)` / `cycle_leader()` / `next_leader()` / `can_swap_to()`，`swap_cd`；新增 `assign_slots()`（队长恒为 0 号位，其余 1.. 按入队顺序），`remove` / `replace` 改用它（切队长后编队位不再等于数组下标）。
- `game.gd`：`swap_off / swap_t / swap_ease`，`cam_center()` 叠加缓动偏移，`glance_step()` 每渲染帧推进；`_input` 里 Q 切人、E / J 放技能；`doctor.gd` `_skill_key_held` 去掉 Q。
- `touch.gd`：`card_rects`（hud_squad 每帧填），点到编队卡切人；点到队长卡 / 冷却中 / 倒地的卡只吞掉点击。
- `pad.gd`：RB → Q，Ⓐ / Ⓨ → E，RT（对局）→ 冲刺。
- 测试钩子 `--swapat=<秒>,…`：到点各按一次 Q；`--trace` 时切换打印 `SWAP t=… A -> B`。
- 旋钮：`balance.json` `leader_swap/cd`（2.0）。

## 3. 验证

- 同 seed：未按 Q 时 `trace_base.py --here` 两组四人编队 300 秒逐行相同；`check.py --auto` 见提交说明。
- **没有人手验证的**：手柄 RB 实机、触屏点卡实机（逻辑已接、触点命中区取编队卡矩形）。

## 4. 待定 / 已知局限

- 切人时玩家当前的冲刺 / 位移若正在进行，会以新队长的位置继续（没有特殊处理）。
- 编队卡点击切人目前只在触屏开启（`--touch` 或触屏设备）；桌面鼠标点卡不切，需要再说。
- 新队长不重新套用其 json `leader` 段的血量 / 减伤（按「生命整局共用」口径）；回复同理保持开局队长的值。
