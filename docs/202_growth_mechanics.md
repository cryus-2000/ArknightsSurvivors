## 0. 什么算「纯数值」

一个节点的实际效果，如果只是下面这些，就算纯数值，**本轮要换**：

- 倍率 / 半径 / 射程 / 冷却 / 层数 / 持续时间 / 数量 +1；
- 给某个技能 / 状态追加一个百分比。

另一类「同机制多一份」：同一个攻击形状延迟再打一遍（多一刀、多一震、多一拉、多一段）。用户 10-29 定**本轮先不换**，表里单列，保留原样。

算「机制」的：新触发（受击 / 格挡 / 击杀 / 命中 N 个 / 状态满）、新形状或新弹道、新目标规则、引爆 / 标记 / 残留物、和队长 / 灯火 / 队友技力的新交互、攻击形态切换。判断标准是**玩家不看数字也能看出这个节点改变了什么**。

另有两条硬规则（用户 10-29 + 此前清查）：

1. 精零节点（1、2）只能落在普攻、已有的天赋式行为或 S1 上；精一后节点（4、5）可以落在 S1，也可以落在刚解锁的 S2，但**不依赖 S3**（S3 精二才解锁）。
2. 每个节点自带的「+6% 攻击」（`NODE_ATK`，所有普通节点统一给）保持不动；本文说的数值指节点自己的效果。

## 2. 换法的共同规则

### 2.1 每个替换节点属于下列一种，且一名干员的 6 个节点至少覆盖 4 种

| 类 | 例 |
|---|---|
| 新触发（受击 / 格挡 / 击杀 / 命中满 N） | 格挡成功后下一斩变大；击杀处炸开 |
| 新形状 / 新弹道 | 延时重弹、折线飞行、追踪 |
| 新目标规则 | 优先残血、优先被标记者、余震重新索敌 |
| 标记 / 引爆 | 命中留标记，满足条件引爆 |
| 地面残留 | 热砂、法阵、潮痕 |
| 状态连携（自己或队友的状态） | 被束缚者吃下一击重斩；被封印者死亡时扩散封印 |
| 攻击形态切换 | 命中攒能后下一斩变旋锯 |

### 2.2 去掉之后「+X%」去哪了

被换掉的节点原来的数值收益不单独补回。由于节点本身仍给统一的 +6% 攻击，机制节点的强度按下面口径对照：

- 木桩表（docs/79）E2 秒伤，改后与改前同提交对照，差在 ±10% 以内；
- 怪群里新机制可以略高，但不超过 +15%；
- 超出的部分在节点自己的参数里压回，不动别的节点。

### 2.3 唯一性（docs/198 §1）

每个新节点对照该干员的 S1 / S2 / S3 / 终结技 / 连携 / E1 / E2 写一句「和谁区别」，不借用它们的标志元素（终结技的整体形状、连携的触发条件）。

### 2.4 关于「我先查到的数据」

节点数值（半径、次数、百分比）一律写**待试验参数**，由数值会话按 docs/79 / docs/80 定；本稿只定机制。
