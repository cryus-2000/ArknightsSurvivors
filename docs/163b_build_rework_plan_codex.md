> 2026-10-26。七条流派方向已确认，低灯风险不设为独立流派。本次按用户“再重新调整一下方案”修订；**所有新效果与数值仍待审，未修改游戏代码或藏品数据**。
> 改造前事实见 [163A 全量分类](163_relic_inventory.md)；该页与 JSON 继续保留 265 件的原数据快照。本页取代上一版 18 件方案及其重击修补稿。

## 1. 本轮调整原则与范围

干员决定攻击动作、强化周期、技能形态和召唤物身份；藏品围绕现有攻击扩大覆盖、增加可读的弹体，或把控制、弱点、护盾、治疗转成收益。

这次撤回四项上一版设计：

- 通用第三次重击，以及随后将贵族刺剑、老近卫都改成范围件的补丁。
- 凯旋号角为所有干员额外提供周期减速；控制来源继续来自干员和已有控制藏品。
- 相机与合影都累计三次命中的平行计数。
- 召唤物本体 / 副体拆分总伤害，以及为永久召唤、替身额外加攻击频率的例外链。

本轮建议调整 **15 件效果或获取条件**，核对 **5 件范围 / 穿透藏品的判定与显示**。其他藏品保留基础、职业、技能循环、生存与流程价值，另按用途更新构筑关联。件数由缺口决定，不作为交付上限，也不把图鉴标签变化算成新增机制。

| 流派 | 形成玩法的条件 | 主要配套 | 选卡取舍 |
|---|---|---|---|
| 多弹火力 | 银餐叉扩散覆盖，左轮弹巢追加连发 | 射程、穿透、攻速、远程伤害 | 扩散清群与集中补伤；保留原生多弹特色 |
| 近战扩域 | 漆黑的舞鞋扩大覆盖，老近卫奖励一次覆盖多人 | 近卫范围、近战增伤、防护 | 清群收益更高，单体 Boss 仍可选通用增伤 |
| 召唤驻场 | 散轶诗简扩充可复数实体，衍生者终端扩大实体覆盖 | 追击增伤、命中回技力 | 数量与覆盖分工，唯一召唤不复制 |
| 控场引爆 | 队伍已有控制，高闪相机将受控目标变成爆炸中心 | 控制持续时间、技力、受控持续伤害 | 控制频率与覆盖比单纯攻击次数更重要 |
| 弱点收割 | 镶金骨骰使残血敌人暴露双弱点 | 弱点增伤、低血增伤、已有处决 | 前半血正常作战，后半血集中收割 |

| 治疗转伤 | 苍白花冠利用有效治疗，食腐者手杖利用溢出 | 治疗量、回复区域、转伤强化 | 残血与满血有不同收益，医疗角色仍负责治疗 |

“启动 / 强化 / 协同”是构筑用途，和“稀有 / 核心”等稀有度分开。一件启动件不保证所有队伍都能无条件成型：控制需要控制来源，护盾需要护盾，复数召唤需要已解锁对应实体。

|---|---|---|

适用：能天使、艾雅法拉、维什戴尔、铃兰、流明、逻各斯、安洁莉娜对应的普攻弹体 / 咒文 / 落点路径。独立技能弹幕不复制；技能中仍属普攻的攻击可受益。拉普兰德仍按近战伤害分类，不因为出现剑气就算远程。

每枚原生弹体只生成本件规定的追加，追加之间不复制。两件并持时，剔除它们自身增益的基准为 D，原生部分 1.20D、侧弹共 0.15D、延迟弹 0.25D；不计其他加成且全部命中时合计 1.60D。其他加成按现行属性结算，不重复加回旧的 20% / 30%。

只追加伤害及该弹体的碰撞 / 爆炸形状，不重放整个出手函数，不额外消耗技能弹药、不增加技能 / 天赋计数，也不重复挂标、净化、治疗、召唤或触发额外攻击。能天使原生多发照旧，维什戴尔原生余震与殉爆照旧；藏品弹不再产生它们。穿透沿对应普攻路径的既有规则，抛物线炮弹不凭空变成贯穿弹。

延迟弹保留原发射点与方向 / 落点；定目标咒文的原目标失效时，在原目标最后位置周围 120 内选最近合法目标，距离相同按敌人 ID 排序；无目标取消。侧咒文无其他目标则取消，不转移给主目标。各弹命中记录独立。

保留 #57、#148、#149、#152、#154 原有收益与代价。银餐叉和弹巢不是所有远程干员等幅增强；多弹、爆炸、纯辅助路径需分开验证。

## 3. 近战扩域：范围件负责触及，老近卫负责清群收益

| 藏品 | v2 定位与效果 |
|---|---|
| #81 漆黑的舞鞋（保留效果，核对表现） | 近战干员攻击范围 +25%、队长受到伤害 -5%。作为本路线的范围启动件。 |
| #140 折戟-一夫当关（保留效果，核对表现） | 近卫攻击范围 +20%、队长受到伤害 -5%，提供职业强化。 |
| #55 贵族刺剑（保留） | 近战伤害 +22%，仍是稳定通用收益，不再改成第三件范围藏品。 |
| **#56 老近卫军之锋（调整）** | 当前近战伤害 +32%；改为近战伤害 +20%。同一次近战普攻的一个主判定覆盖至少 3 名合法敌人时，该主判定伤害额外 ×1.25。 |

“一个主判定”指一记刀弧、一次盾击或一段刺击的实际目标列表；不同时间的攻击段不累计。先按原有目标筛选及命中上限确定列表，再检查是否至少三人，最后结算这一个主判定。排除补给箱、友方、无敌 / 不可受伤对象；同一目标只算一次，不能用查询范围内但实际上打不到的敌人凑数。

原生强化普攻仍可受益，但不改计数和动作：艾丽妮的第三次裂潮余波照常出现，塞雷娅仍按护服充能替换下一拳，水月仍按原弹药强化。手炮追击、晶柱、地裂、触手、独立技能不附带这一额外倍率。

主判定具备逐弹命中、无法事先确定人数的普攻剑气，只获得近战伤害 +20%，不回头补伤、不把三次穿透算成一次新重击。这一差异需在藏品详情的适用说明中列明，不能宣称所有近战攻击都等价受益。

可见成长主要来自舞鞋 / 职业范围的实际覆盖扩大；老近卫达成多人条件时只强化原命中反馈，不添加第二次攻击或新的重击动画。修正艾丽妮主刺击限幅、塞雷娅固定盾击特效尺寸，核对水月各形态；所有画面尺寸必须跟判定走。

一级对单体是 +20%，对满足条件的主判定在无其他加成时为 1.20 × 1.25 = 1.50。相较原来 +32%，这是明确的清群取舍，不是无条件升级。#63 / #64 继续服务所有物理伤害，职业伤害件 #138 / #143 / #165 保留。

## 4. 召唤驻场：数量与覆盖各管一件

| 调整藏品 | 当前效果 | v2 建议（一级） |
|---|---|---|
| **#129 散轶诗简** | 追击与召唤伤害 +35% | 维什戴尔魂灵数量 +1，魂灵自身的伤害加成改为 +20%；水月触手桩在场上限 +1。触手桩、唯一实体与其余追击保留伤害 +35%。 |
| **#130 衍生者终端-超级改** | 追击与召唤伤害 +25%；追击命中回复 0.2% 技力，每秒最多 1% | 保留原效果；已有驻场实体的显示尺寸与实际攻击覆盖 +15%。不改攻击间隔、不延长寿命、不改变技能结束或本体归队。 |

本版不再造“副体”身份，不拆本体伤害，不复制一整组召唤物。新增数量进入原生召唤机制，额外实体遵循该种类已有的选目标、攻击、挂标与阶段解锁规则。维什戴尔的魂灵并非只有直接伤害，还会挂标与参与精二魂炮，因此不再用“直接伤害总量相等”声称数量改造等价。

| 对象 | 数量 / 覆盖处理 |
|---|---|
| 维什戴尔魂灵 | 原生目标数量从 N 变为 N+1，按原生补齐机制出现；原有魂灵状态不重置。数量加成不随藏品升级继续增加。新增魂灵可以按原技能机制挂标 / 开火，但不会额外触发主炮出手或再生成魂灵。 |
| 水月驻留触手桩 | 仅容量从 N 变为 N+1，仍由原来的触手攻击创建，不能每次触手命中额外复制一根。既有寿命与生成频率保留；不到原容量时，数量提升可能暂时没有实际收益。 |
| Mon3tr、浊心斯卡蒂的海嗣 | 保持唯一；诗简为原 +35% 伤害，终端提供覆盖成长。尺寸变化不扩大受击碰撞箱、不提高生命，不改变技能归属。 |
| 幽灵鲨替身 | 不复制，终端扩大原攻击覆盖，保持出现 / 消失与本体恢复时刻。 |
| 瞬时触手、余震、殉爆 | 保留对应原伤害收益，不伪造成驻场实体；终端不扩大这些非实体效果。 |

“覆盖 +15%”只作用于实体真正的攻击半径 / 宽度；定目标挂标不因变大就免费增加目标数。魂灵的直接范围攻击尚未解锁时，终端对它保留伤害与技力收益，不能承诺尺寸变化一定带来额外命中。

获得 / 升级后刷新现有实体的伤害与范围，不能恢复生命、重置攻击计时、改变剩余寿命。与 #80 海程、#84 几丁质刺刃沿既有追击属性规则叠加；魂灵用 20% 替换自身的 35%，不能同时领取两份。魂灵造成的伤害、主炮产生的余震 / 殉爆和其他追击按实际来源区分，不能直接削减整名维什戴尔的追击收益。触手桩只扩容量，未必马上多出一个，所以保留原伤害，不要求玩家先打满容量才能拿回旧收益。

这组方案接受数量收益与原技能联动，需要单独评估维什戴尔挂标 / 魂炮增益，以及水月容量是否常被用满；不把数量 +1 宣称成固定百分比伤害。全局容量不得挤掉原生实体或因画质改变，具体额度按固定玩法规则实现并做压力测试。#246 无字珊瑚仍为特殊条件收益，不是本流派成型条件。

## 5. 控场引爆：利用原有控制，不另造三击循环

| 调整藏品 | 当前效果 | v2 建议（一级） |
|---|---|---|
| **#98 高闪相机** | 控制持续时间 +80% | 控制持续时间 +40%；干员或召唤物直接命中受控敌人时，在其位置产生半径 90 的法术爆炸，基数 30，乘全队伤害与敌人生命时间倍率；每个目标冷却 2 秒。 |
| **#99 精神治疗录像带** | 控制持续时间 +100% | 保留 +100%；击败受控敌人时，使周围半径 120 的其他合法敌人减速 1 秒，沿用既有减速强度及控制抗性规则。 |

#97 凯旋号角保留控制持续时间 +50%，不额外给全队周期减速。控制来源由干员技能、普攻自带状态及已有藏品提供。相机对没有控制来源的队伍并非万能输出卡；不能因为买了它就自动成为控制队。

受控沿用现有眩晕、束缚、减速判定。直接命中使用这一击开始结算、尚未施加本次附带状态时的目标状态快照；本次新施加的控制由后续直接命中触发相机。快照必须在实际碰撞 / 命中入口取得，不能只在 combat 的伤害入口查询，因为部分干员在调用伤害前已施加状态。只记录给相机使用的旧状态，不重排干员原有状态与伤害顺序；多段攻击按每一段分别取快照。持续伤害、余震、爆炸追击及藏品追加弹不触发相机。

先锁定目标冷却，再将爆炸排入后续结算批；致命命中保留位置。固定伤害基数不取“最后一击伤害”，避免攻击次数、单发倍率和多段技能共同放大。爆炸只做藏品伤害，不重触发相机；录像带只扩散减速。#95 / #96 的受控持续伤害保留二者取较高规则，既不触发相机，也不需要额外叠层。

可见反馈为受控标识、短促爆炸与击杀后减速扩散，不增加三层蓄力圈。控制免疫与 Boss 的既有规则保留，不为流派另造强制眩晕。

## 6. 弱点收割：残血暴露弱点，保留已有处决

| 调整藏品 | 当前效果 | v2 建议（一级） |
|---|---|---|
| **#48 镶金骨骰** | 敌人最大生命 ×0.82 | 敌人最大生命 ×0.90；敌人当前生命不高于最大生命的 50% 时，物理与法术攻击都视为命中弱点。 |

采用当前生命条件，不写入 / 覆盖敌人的原弱点，不加命中计数，不设额外标记持续时间。跨过半血的那次伤害仍按命中前状态结算，从下一次物理 / 法术攻击开始受益；敌人若回复到半血以上就失去这份临时双弱点。Boss 同样可以在半血时暴露弱点，但无敌、阶段门槛与伤害预算照旧，真实伤害不受益。

配套保持原作用：

- #45 残破合影：弱点伤害额外 +25 个百分点，不再承担“三次命中制造弱点”。
- #46 恐鱼干：低于 50% 生命的敌人受到伤害 +18%，放大收割阶段。
- #169 扼喉之手：保留狙击对低于 20% 生命的非 Boss 处决，作为职业分支；认知处决照旧。
- #50《大静谧》：保留敌人最大生命 ×0.8，不新增第二套全职业处决。
- #47 迷迭香之拥：保留全程双弱点，作为后期强化；与骨骰重叠时弱点只算一次，骨骰仍提供生命削减。

这条路线的清楚顺序是“压到半血 → 暴露弱点 → 低血增伤 → 条件允许时原生处决”。并非所有队伍都有最后一步处决，也无需处决才能形成路线。骨骰的生命削减比旧版少，换取全队后半血弱点收益；需验证对精英 / Boss 的影响。

#118 及其他护盾来源不重做。数值吸收盾、临时拾取一层护盾、可再生次数护盾仍分开：只有后者的上限支持这条构筑资格。反击属于独立藏品伤害，不继承上一名干员的攻击描述符，不触发吸血或再次抵挡。

单次抵挡产生一次冲击与一个增伤窗口；再生 / 回复提供循环。没有护盾时，甲胄与城墙仍有生存收益，胸针与护戒则不会提前进入候选。沿现有反击展示，不新增一套角色反击动作。

## 8. 治疗转伤：有效与溢出两条支路

| 调整藏品 | 当前效果 | v2 建议（一级） |
|---|---|---|
| **#70 苍白花冠** | 受到治疗 +30% | 受到治疗 +20%；每 0.5 秒把有效治疗量转成半径 150 的法术伤害，基数为有效治疗的 2 倍，乘现有藏品时间倍率。 |
| **#102 食腐者手杖** | 每 0.5 秒将溢出治疗转伤，半径 150、开局倍率当前为 8 | 保留倍率与间隔，半径改为 180；与花冠共用同一次治疗的有效 / 溢出拆分。 |
| **#71 涌动之餐** | 受到治疗 +30%；侵蚀 / 神经损伤 -30%；全队伤害 +8% | 保留治疗与元素防护；全队伤害 +8% 改为上述治疗转伤伤害 +25%、半径 +35%。 |

医疗依然先完成原治疗，不改技能时机和目标。有效治疗 = 实际补回生命；溢出 = 加成 / 减疗后超过最大生命的部分。同一份治疗只能拆分一次，不能全量同时进入两种转伤。

转伤不产生吸血、额外治疗，也不让它的击杀奖励回复再进入转伤循环；正常独立攻击产生的吸血仍可供给转伤。复活、直接设置生命、最大生命变化不当作治疗；自然回复从自己的入口纳入有效 / 溢出记账。没有敌人仍按时清空累计，不储存场外爆发。

两种半径分别判定，只合并允许合并的绘制，不能为了共用一个圆让小半径伤害打得更远。#159 / #161、#116、#263 分别保留医疗增幅、回复区域和正常吸血。

## 9. 等级、重复获得与来源归属

- 原来 3 级的调整件显式保留 3 级；原来 1 级的仍为 1 级。增量 100% / 70% / 50%，第三级累计 2.2 倍；乘法型属性按现行逐级修正算法，不改写成直接相加。
- 可成长项：伤害 / 范围加成、追加弹伤害系数、#56 多人主判定的额外伤害增量、#98 爆炸基数、#70 转伤系数等。固定项：侧弹数量、补发次数、延迟、三人条件、两秒冷却、半血阈值、每半秒结算。
- #129 每个合资格实体种类仅数量或容量 +1，不随升级再加。魂灵自身伤害增量按 20% / 14% / 10% 累加；触手桩及其他追击的保留增量按 35% / 24.5% / 17.5% 累加。#130 当前只有 1 级，不新增等级。
- 显示“固定机制＋本级增量”；不能把规则藏品仍统一写成“本级 70%”而不说明到底升级什么。
- 远程藏品追加伤害标记独立来源，不能进入技能 / 天赋出手计数及藏品再次追加。原生召唤数量增长仍是干员原生实体，使用其原来源与既有技力预算，不混同于远程追加弹。
- 换队长、切技能、升级、获取藏品不能重置干员原有计数 / 弹药 / 生命。移出编队的实体按现有生命周期退出，藏品不能使其残留。
- 不同画质使用相同玩法实体、目标、时序和命中，低画质只减少拖尾、碎屑、辉光与次要动画。玩法随机使用 seeded RNG；不以绘制负载改变伤害或容量。
