## 1. 要解决的三件事和本方案的对应

| 问题（docs/243 / 248 / 245） | 模组怎么解决 |
|---|---|
| 成长看不见（三档外观一样，精二只多一条普攻质变） | 精二时玩家亲手选一条路；两条路的普攻主形、点缀色、出手节奏都不同（§2.4），同一名干员两局里看起来就不一样 |
| 后期只能靠终结技清屏（docs/248：形状档只把潮位 10 的终结技击杀从 19% 压到 16%） | 清群路线把精二的形状档集中到「一招清一片」上；编队里至少 1–2 人走清群时，后期清怪靠普攻和技能（§5 量这一项） |
| 构筑没深度（升级卡多数是数值） | 三人小队里谁清群、谁攻坚是一次真正的编队决定；藏品 / 升级卡的「扩散」「连锁」只吃清群路线（§2.3），攻坚路线吃精英 / Boss 类卡，两条路各有配套 |

设计支柱（docs/41 / 用户 10-29）：小队代入感，构筑和割草爽感走同一条线。所以模组不是一张数值卡：选了就看得见，打法也跟着变。

## 2. 机制

### 2.1 精二节点弹出二选一

- **数据**：精二节点（`progression` 第 6 项，`type: elite, level: 2`）新增 `modules` 字段：`{模组 id: {name, kind, canon, desc, icon, col}}`，两项。`kind` ∈ `clear`（清群）/ `focus`（攻坚）；`canon` 写原作模组 id（如 `uniequip_002_texas`），本作自创写 `""`。
- **界面**：复用 `progression.open_branch`（docs/119 节点 4 用的那一屏）。外层升级三选一里仍只出一张「德克萨斯 · 精英二」卡；选中后进入「模组 · 德克萨斯 MODULE」屏：两张模组卡 + 「返回」。卡面：
  - 标题：原作模组名（「外勤私人补给包」），类别行写「模组 · 清群」/「模组 · 攻坚」；本作自创的写「模组 · 攻坚（本作自创）」。
  - 正文：先写三技能解锁（两条相同），再写这条路的普攻形态、特性、天赋强化，最后一行写形状 / 攻坚加成（§2.3）。按 docs/76：写对象和数值，不写程度词。
- **状态**：`character.module`（"" = 未选 / 开关关）。不复用 `route`：节点 4 的路线和模组是两次独立选择，一名干员最多 2 × 2 = 4 种组合。
- **要沿用 docs/119 §4.1 的全部事务规则**（代码已有，模组只是第二个调用点）：
  - 返回不消耗升级、不重抽；
  - 赠送推进（典训、博士银印 `relic_fx.gd` 5 处 `advance("")`）排队进选择屏，只能确认不能取消；
  - 换人继承到精二的干员在换人确认流程里选模组（`swap_needs_route` 加一档）；
  - 机器人 / 测试 / 演示走 `bot_module`（同 `bot_route`，读 `--module=texas:focus,…`，否则按策略表 §5.1），不凭界面外随机。
- **精英化时刻**（docs/245 `growth/elite_show`）：横幅第一行改成「德克萨斯 · 精英二 · 外勤私人补给包」，第二行仍是全队效果；定格爆亮的颜色用该路线的点缀色（§2.4）。

### 2.2 模组改什么：普攻、特性、技能

原作模组的结构是「特性追加 + 天赋强化 + 属性」。本作照这个结构拆成三层，每层都写进卡面：

| 层 | 原作 | 本作做法 | 两条路是否相同 |
|---|---|---|---|
| 技能 | 模组不改技能 | 精二照旧解锁三技能；只在原作模组天赋直接写到技能时（如德克萨斯「技能造成的伤害提高 15%」）加一条技能修正 | 解锁相同；修正可以不同 |
| 普攻形态 | 特性追加（「阻挡敌人时攻击力 +8%」「无视 10 点法术抗性」） | **精二普攻质变按路线二选一**：现有的精二形态（docs/91 §0.3）放进意象最接近的那条路，另一条路新做一种质变。这是两条路「看得见不同」的主体 | 不同 |
| 天赋 / 被动 | 天赋强化（「语汇演化」改成打 2 名） | 原作模组天赋有对应机制的，照它改本作天赋的数值或目标数 | 不同 |
| 属性 | 模组三级的攻击 / 生命 / 防御加成 | 并进 docs/245 精二本人那一档（攻击 +12%、攻击速度 +6%）：清群路线照旧；攻坚路线改成攻击 +8% + 受到伤害 -8%（或对应生存项） | 不同 |

- 现有精二形态不删，只是只在一条路上出现，所以已做的代码和画面不浪费。
- 精一形态、节点 4 / 5 的路线不动。
- 原作模组的「部署费用」「再部署时间」「集成战略中」这类本作没有对应概念的条目，改写成最接近的本作机制（技力、复活时间），卡面不写原作原文，§7 表里注明改写。

### 2.3 与 `growth/late_shape` 精二 1.5 档怎么合

docs/248：精一 1 档、精二 1.5 档、Lv14 / Lv20 各 0.5 档，加成按 lane（近战 / 多弹 / 召唤 / 控场）四条共用。

**建议：模组开时，精二那 1.5 档不再按 lane 通用发放，改由模组路线决定内容；精一 1 档和 Lv14 / Lv20 两个 0.5 档不动。**

| 路线 | 精二 1.5 档变成 | 代码 |
|---|---|---|
| 清群 | 和现在完全一样：本人 lane 的 1.5 档（近战范围 +22.5%、每次普攻 1.5 道剑气；多弹每次 1.5 发、范围 +12%、穿透 +1；召唤范围 +27%、召唤伤害 +45%；控场范围 +37.5%、控制时长 +18%）。可吃「扩散」「连锁」卡 | `late_shape.tier()` 不变 |
| 攻坚 | 形状档只算精一 + 等级门槛（满档 2.0 而不是 3.5）；换成 1.5 档「攻坚加成」：对精英 / Boss 伤害 +30%（每档 +20%）、控制时长 +15%、受到伤害 -10%（三项按干员取 1–2 项，见各人）。不吃「扩散」「连锁」，改吃对精英 / Boss 类升级卡 | `late_shape.tier()` 对 `module.kind == focus` 时减去 `w_e2`；另挂来源 `mfocus:<id>` |

取舍：

- **好处**：不另起一套形状数值；清群路线等于今天开着 `late_shape` 的精二，A/B 有现成对照组；攻坚路线的减项和加项落在同一档位上，预算好算。
- **代价 1**：攻坚路线后期范围比清群路线小一截（近战范围差 22.5%）。这是有意的：攻坚干员靠同队清群干员清小怪。风险是三人都选攻坚时后期又只能靠终结技，所以 §5 要专门量「全选攻坚」策略的终结技击杀占比。
- **代价 2**：「扩散 / 连锁」卡的出卡条件要从「编队里有某 lane 干员」改成「编队里有某 lane 的清群干员或未到精二的干员」，否则选了攻坚还会刷出用不上的卡。
- **备选（不推荐）**：模组叠在 1.5 档上面再加。好处是改动小；坏处是精二一下子变得太强（docs/248 已经要靠补偿才回窗口），两条路的差别也被通用档冲淡。

### 2.4 外观：配方特效的精二分两条

配方试点（docs/245_fx_recipe_pilot_1105 §1.4）的 E2 是「主形质变 + 专属点缀色 + 体量 ×1.5」。模组开时 E2 拆成两套：

- `fx_recipes/<id>.json` 的 `tiers.E2` 拆成 `E2a`（清群）/ `E2b`（攻坚），`moves.*.e2` 拆成 `e2a` / `e2b`。没写 `e2b` 的招式回退到 `e2a`，所以只有普攻和受模组影响的招要写两份。
- 规则：
  - 清群路线：主形**变宽变多**（扇面、地裂、锁链、扩散的爆团），点缀色落在外边；
  - 攻坚路线：主形**变重变集中**（更厚的单个主形、命中定帧更长、落点深坑或贴身印记），点缀色落在主体，热芯更亮；
  - 两条路主色都保留本人原作色；只换点缀色，点缀色不用危险红 `#ff2667`、敌弹青 `#33ceff`、结晶淡金（同配方规则）。
- 精英化时刻（docs/245）的脚下光池：清群路线外圈亮边，攻坚路线内圈加一层热芯色，站着不动也能分出是哪条路。
- 配方开关关时（旧帧条画法），两条路仍然不同：普攻质变本身就是不同的弹体 / 判定，旧画法照旧能画出来（各人表里写了不靠配方的画法）。

### 2.5 与精二全队效果（docs/245 `growth/visible_nodes`）共存

- **全队效果不随模组变**。精二全队效果（德克萨斯「全队技力回复 +8%」等）是小队代入感那一条：「她精二了，大家都受益」。模组是她自己的打法，两件事分开，卡面也分两行。
- 本人那一档（攻击 +12%、攻击速度 +6%）按 §2.2 表并进模组属性层，攻坚路线换成一部分生存项。
- 能天使、凯尔希的全队效果本来就是精二形态（天使的祝福、回防）。这两人里，那条形态所在的路线保留它；另一条路线改给 docs/245 的通用全队效果写法（数值另定），保证两条路都有全队效果。

### 2.6 开关与确定性

- `growth/module`（缺省 0）。开 = 试点 4 人的精二出模组屏，其余 16 人照旧精二；全员推广后再去掉白名单。
- 依赖：`growth/module` 开时强制按 `growth/late_shape` 开计算精二档（否则 §2.3 没有可替换的档）；单独开模组、不开形状档时，攻坚加成照发、清群路线不发形状档。
- 玩法随机只用 `g.rng`，画面只用 `g.vrng`；机器人选模组不抽随机数（按 id 和策略表定），开关关时不读任何新键。

## 3. 两条路的设计原则

1. **清群** = 一招打一片：范围、弹数、穿透、连锁、持续场其中一到两项。量的指标是怪群秒伤（docs/79 木桩表的怪群场景）和 5–9 分钟同屏清空秒数。
2. **攻坚** = 打得动硬目标或保住队伍：单体爆发 / 控制 / 生存三选一为主、最多再带一项。量的指标是木桩单体、Boss 用时、队长承伤。
3. **两条都要撑得起后期**：
   - 清群路线：怪群秒伤 ≥ 现精二 +15%，木桩单体不低于现精二 -10%；
   - 攻坚路线：木桩单体 / Boss 秒伤 ≥ 现精二 +25%（或控制 / 生存项换算后同量），怪群秒伤不低于现精二 80%，后期不能完全清不动；
   - 胜率按 §5：同一干员两条路的胜率差 < 10 点。差超过 10 点时先调弱的一条，不削强的那条。
4. **名字和意象来自原作模组**；原作只有一个模组的干员，第二条按原作技能或天赋的意象设计，卡面注明「本作自创」，名字不用原作模组名的格式（不加引号），避免被读成原作有这个模组。
5. **原作现有的精二形态放在意象最接近的那条路**。两个原作模组意象都偏同一边时（如都偏清群），按模组的特性改动定主次：特性加范围 / 目标数的算清群，特性加防御 / 抗性 / 单体倍率的算攻坚。
6. **不用程度词，不写「更强」**：卡面写「对精英与 Boss 伤害 +30%」，不写「大幅强化」（docs/76 §3）。

## 4. 试点 4 人

数值都是草案（docs/79 木桩表验证前不定档）。「现精二」= integ-1105 上的精二普攻形态。原作内容取模组三级，不含潜能加成。

### 4.1 德克萨斯 `texas`（近战 · 先锋）

原作只有一个模组：`uniequip_002_texas`「外勤私人补给包」（SOL-Y）。特性追加「首次部署时部署费用 -4」；天赋「战术快递」强化为「编入队伍后，额外获得 2 点初始部署费用。技能造成的伤害提高 15%」。

| | 清群：外勤私人补给包（原作 SOL-Y） | 攻坚：截击（本作自创） |
|---|---|---|
| 出处 | 原作模组。部署费用 → 本作改写为技力；「技能造成的伤害提高 15%」照搬 | 原作特性「能够阻挡两个敌人」+ 本作精一「钉剑」（被阻挡的敌人插源石剑）。原作没有这个模组 |
| 普攻形态 | 保留现精二「余像」：骤雨前方剑气残像（15% / 跳，减速），消散时沿路落剑（25%，眩晕 0.2 秒）。骤雨间隔 4 → 3 次出手 | 每第 3 次拔刀改为「截击」：冲到 160 内生命最高的敌人（优先精英 / Boss）身前，双剑交叉一刺：拔刀伤害 ×3.0，钉住 1.2 秒（精英减半，Boss 除外）；被钉住的敌人 4 秒内受到全队伤害 +15%。骤雨间隔不变 |
| 特性 / 天赋 | 精二时三个技能立即充满（「首次部署费用 -4」改写）；技能伤害 +15%（剑雨、剑雨滂沱） | 「钉剑」定住时间 0.7 → 1.0 秒；拔刀对被阻挡的敌人伤害 ×1.2 |
| 属性 | 攻击 +12%、攻击速度 +6%（同 docs/245） | 攻击 +8%、受到伤害 -8% |
| 精二档（§2.3） | 近战 1.5 档：范围 +22.5%、剑气 | 攻坚 1.5 档：对精英 / Boss 伤害 +30%；控制时长 +15% |
| 画面一句话 | 骤雨后身前一条剑气残像，残像碎开时一排源石剑从天落下 | 她瞬身到大怪面前，两柄剑交叉钉进去，钉住的怪身上留着两柄剑直到松开 |
| 配方 E2 | `E2a`：余像拉成长条实心剑痕 + 落剑硬边竖刺；点缀色冷白，落在外边 | `E2b`：交叉双刺（两道 `spike` 交成 X）+ 命中定帧 0.06 秒 + 目标脚下深色钉印；点缀色淡金，落在主体 |

## 5. 平衡和验证

### 5.1 机器人怎么选模组

`bot_module` 按策略取，策略由 `--modpolicy=` 指定（只在批跑 / 截图读，`Cfg.dev_args()`）：

| 策略 | 规则 | 用途 |
|---|---|---|
| `clear` | 全员选清群 | 清群路线上限；对照组 = `late_shape` 开、模组关 |
| `focus` | 全员选攻坚 | 攻坚路线是否撑得住后期；终结技依赖是否回升 |
| `fill` | 编队里已精二的清群干员 < 2 名时选清群，否则选攻坚 | 正常玩家的近似选法；胜率窗口以它为准 |
| `fixed` | `--module=texas:focus,…` 逐人指定 | 单人对照 |

不抽随机数，所以同一 (编队, seed) 下的选法可重放。

### 5.2 跑什么

1. **木桩表**（本机可跑，docs/79）：`tools/op_dummy_table.py --ops texas,siege,logos,kaltsit --stages 2`，每人三栏：现精二 / 清群 / 攻坚，单体木桩、怪群两个场景。按 §3 第 3 条判通过。
2. **后期诊断**（云端，docs/248 §2 口径）：20 名队长 × 种子 11 / 23 × 潮位 0 / 10，开关 `growth/late_shape=1` 下比「模组关」和三种策略。看 5–9 分钟终结技占普通怪击杀、同屏清空秒数、清怪比、打掉最终 Boss 比例。试点只有 4 人，诊断里只统计有试点干员精二的局。
3. **胜率**（云端例行任务，docs/36 §7.5.1）：expert，7 编队 × 4 seed × 安慰剂 0 / 1 / 2，每组 84 局；无认知 `--tier=0 --tide=0`，18 细胞 `--tide=0 --meta=18`。编队里固定放 1–2 名试点干员。
   - 窗口：无认知 45–55%、18 细胞 65–75%（memory 难度口径 10-31）；≥ 3 份实现的均值。
   - 按 (编队, seed, 安慰剂) 配对，给「负转胜 / 胜转负」和符号检验 p。
   - **两组胜率差 < 10 个点不下「变强 / 变弱」结论**；`clear` 和 `focus` 之间同样适用，差 < 10 点只说「没看出差别」。
   - 出窗时按 docs/245 / 248 的补偿口径（只在开关开时生效的怪物生命 / Boss 系数），不削模组本身。
4. **TRACE**：开关关时同种子 TRACE 与基准逐行一致；开关开、配方开 / 关两局 TRACE 一致（配方只改画面）。
5. **截图 / 录像**：每名试点干员同一时刻两条路并排（3:00 精二后 / 8:00），给用户看「一眼能不能分出来」。按 memory：只发 mp4、`--realtime` 30 帧、原色原速。

### 5.3 判断标准

| 看什么 | 通过 |
|---|---|
| 两条路都撑得起后期 | 木桩表满足 §3 第 3 条；`focus` 策略的胜率不比「模组关」低 10 点以上 |
| 不靠终结技清屏 | `fill` 策略下潮位 10 的终结技击杀占比 ≤ docs/248 开形状档时的 16%，目标 ≤ 12% |
| 没有一条明显更强 | 同一干员 `clear` vs `focus` 胜率差 < 10 点；超过时调弱的一条 |
| 看得见 | 用户看并排录像能分出两条路（人眼判断，不用指标代替） |

### 6.3 风险

1. **组合爆炸**：节点 4 路线 × 模组 = 每人 4 种，20 人 80 种。批跑覆盖不了全部组合，只能按策略量平均；单个组合过强要靠真人局发现（memory「真人局后分析」）。缓解：试点期把 4 种组合都在木桩表里列出来。
2. **全选攻坚时后期清不动**：§2.3 代价 1。如果 `focus` 策略的终结技击杀占比明显回升，可以让攻坚路线保留 0.5 档通用形状（而不是 0）。
3. **原作意象偏一边**：有的干员两个模组都偏同一方向（如艾雅法拉两个都是输出），硬分会显得牵强；§7 表里这类标了「意象偏弱」，推广时要用户逐个过目。
4. **撞名**：推进之王（万兽之王）、凯尔希（不毁重构）、铃兰（画地为牢）三人的原作模组天赋名已被本作节点 4 路线占用；卡面只写模组名，天赋名不出现，避免同一局里两张卡同名。
