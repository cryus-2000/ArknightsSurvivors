# 49g · 引航灯标「圈内安全」方案（Boss与怪物 代 玩法系统，2026-10-01，方案稿，未改代码）

> 背景：
> - Ⅷ 高手 / 熟练机器人的灯标点燃率在 40–43%（灯标 A–E 对照，e3217e2）。离开光圈的原因 90% 以上是 danger，三种灯标旋钮都推不动（docs/41 第 88 行、docs/49f）。
> - 普通玩家中期死因 38% 是引痕者接触 / 前刺（docs/38 §8.12）。
> - 本稿先查清「danger」到底是什么，再比较圈内安全的几种做法。机制与旋钮见 `run/beacon.gd`，机器人站定与离圈判定见 `core/bot.gd` 的 `_stand_ok` / `_bdbg`。

## 0. 先量：「danger」离圈到底是被什么逼出来的

**做法**：给熟练机器人加临时探针（不提交），在每次 danger 离圈前一帧拆开它的位置打分 `here`：
- 敌人贴近项；
- 站在预警里（−25）；
- 站在溟痕里（−18）；
- 子弹 / 弹幕项。

同时记下预警和子弹的出手者、60 内的杂兵种类、是否冲刺离开、血量。

**样本**：Ⅷ（--tier=2）熟练机器人，7 个开局干员 × seed 1–3 共 16 局，--maxt=1000，当前 main。

| 项 | 结果 |
|---|---|
| 灯标出现 / 点燃 | 137 / 29 = **21%**（本地 16 局，样本小，低于云端 28 局的 40–43%，只作结构参考） |
| 离圈次数 | 65 次，其中 danger 60、switch 4、pushed 1 |
| danger 的**主因**（打分里扣得最多的一项） | **预警 52%**、**子弹 / 弹幕 40%**、敌人贴近 8%、溟痕 0% |
| 预警出手者（第二批 8 局记了出手者，n = 28 次预警离圈） | **杂兵 24 次（86%）**、Boss 4 次 |
| 预警来源前几位 | 凿石者贯射 11、浮海飘航者齐射 11、收割者扇形斩 4、巢涌者齐射 3、引痕者前刺 3；Boss 合计 4（伊莎玛拉直线 2、骑士冲锋 / 冰线 2） |
| 离圈时 90 内的子弹出手者 | 杂兵 20、Boss 3 |
| 其他 | 离圈时 Boss 在场 60%（但逼走机器人的是杂兵的出手）；冲刺离开 15%；血量 < 40% 只有 5% |

**结论**：
1. 「danger」主要不是怪贴身，而是**站在杂兵的远程预警和子弹里**。凿石者、飘航者、巢涌者三种远程杂兵占了预警的一大半。
2. 引痕者前刺只占约 5%：它是普通玩家**死因**的大头，但不是机器人**离圈**的大头。
3. Boss 在场时，逼人离圈的仍然主要是杂兵。

## 1. 候选机制逐条评估

**口径**：
- 「对 danger 压多少」按上表的主因份额估，是机器人离圈的上限估计；
- 「对高手是否白给」看熟练玩家能不能拿它刷收益；
- 「机器人会不会多点灯」看它是否改变机器人打分里的项。机器人只看距离、血量、危险打分，不看伤害数字。

### a 点灯读条期间，圈内敌人移速 −40% 且不冲刺
- **对 danger**：只直接作用于「敌人贴近」那 8%，以及近战杂兵的出招预警（收割者扇形斩、引痕者前刺、子代咬，约占预警的 25%）。估计压掉 **10–20%**。远程杂兵的预警和子弹不受影响。
- **机器人会不会多点灯**：会一点（敌人贴近项变小），幅度小。
- **对高手**：不白给。读条只有 2.5 秒（低灯火 3.75 秒），减速范围只在光圈。
- **Boss 在场**：只对杂兵生效，Boss 不减速（Boss 冲锋本来就是要躲的预警）。

### b 圈内弹幕 / 接触伤害 −30%
- **对 danger**：**0%**。机器人的打分里没有伤害，子弹照样算危险、照样躲。
- **机器人会不会多点灯**：不会。云端 A/B 会显示点燃率不变，只有承伤略降。
- **对高手**：轻度白给（站圈时少掉血）；对真人是「圈里扛得住」的心理安全，但看不见、读不出来。
- **Boss 在场**：若对 Boss 伤害也减，等于 Boss 战里多一个减伤区，和「Boss 只加强」的口径冲突。只能做成只减杂兵伤害。

### c 点灯期间圈内引痕者前刺预警加长
- **对 danger**：引痕者前刺只占预警的约 5%。而且机器人把整段预警都当危险，预警变长反而更久不站，**可能变差**。估计 **0 到 −5%**。
- **对真人**：前刺更好躲，对普通玩家的中期死因有一点帮助，但只在点灯那几秒。
- **Boss 在场**：不涉及。
- **判断**：对点燃率没用；如果要处理引痕者死因，应该放到引痕者本身（全局前摇），不是灯标。

### d 点亮瞬间圈内敌人击退
- **对 danger**：**0%**。发生在点燃之后，不影响读条期间离不离圈。
- **对高手**：点燃后的一次清场，奖励性质，轻度白给。
- **判断**：可以作为点燃的爽感反馈，和点燃率无关。

### e（数据指向的新候选）点灯读条期间：光圈内杂兵子弹消散 + 杂兵不对圈内主控发起新的远程出招
- **做法**：主控站在**未点燃**灯标的光圈（r 70）里、进度在涨时：
  - ① 非 Boss 敌方子弹进入光圈即消散，画一点光屑；
  - ② 远程杂兵（凿石者、浮海飘航者、巢涌者、喷吐者这类远程 / 带预警齐射的）不对此时的主控发起新的远程出招，冷却照走，主控一出圈就恢复；已经在读的预警照常结算。
- **对 danger**：直接作用于「杂兵预警」（预警主因 52% × 86%）和「杂兵子弹」（40% × 约 87%），合计约占 danger 主因的 **80%**。扣掉混合原因和离圈前一帧以外的累积，估计压掉 **50–70%**。
- **机器人会不会多点灯**：会，而且是主效果。预警和子弹项是机器人站不住的主因；不改机器人代码，打分里这两项自然消失。
- **对高手**：不白给。
  - 只在未点燃灯标的读条期间（每座 2.5–3.75 秒）、只在半径 70 内；
  - 一局约 8–9 座，总共最多约 30 秒；点燃后效果立刻结束，不能蹲在圈里。
  - 和灯标「局部安全区」的定位一致（beacon.gd 头注）。
- **Boss 在场**：**只对杂兵生效**。Boss 的预警、子弹、冲锋照常，Boss 战的压力不变，符合「Boss 只加强」。
- **画面 / 可读性**：光圈边缘画一圈「护佑」的暖光，子弹撞上光圈时碎成光点，玩家一眼看得出「圈里是安全的」。

## 2. 推荐

**主推 e，a 作为可选叠加，b / c / d 不做**（d 可以另作点燃反馈，和本议题无关）。

| 旋钮（balance.json beacon 段） | 含义 | 缺省 |
|---|---|---|
| `beacon/safe_bullet` | 1 = 读条期间进入光圈的非 Boss 子弹消散 | **0（关）** |
| `beacon/safe_ranged` | 1 = 读条期间远程杂兵不对圈内主控发起新的远程出招（冷却照走） | **0（关）** |
| `beacon/safe_slow` | 读条期间光圈内杂兵移速倍率减少量（如 0.4 = −40%）并禁止冲刺；0 = 关 | **0（关）** |

- 「读条期间」= 主控在未点燃灯标的 r 内、且该灯标进度在涨（与 beacon.gd 现有判定同一处）。
- 只影响 `boss == false` 的敌人和子弹。
- 可加难度修正键 `difficulty/<档>/beacon_safe`（按档开关，标准档可以不开），缺省 −1 跟全局。

**代码量估计**：
- 子弹消散：enemies.gd 子弹更新处加一次距离判定；
- 远程出招暂停：enemy_ai.gd 远程出招入口加一行条件；
- 减速：enemies.gd 移动处一行。
- 合计约 1–2 小时，另加 prot_test 3 条。

## 3. 云端 A/B 设计

- **局型**：Ⅷ（--tier=2）熟练机器人，starts 7 干员 × 4 seed = **28 局 / 组**，--maxt=1000，同 seed 配对。
- **组**：
  - **A**：现行为；
  - **B**：`safe_bullet=1`；
  - **C**：`safe_bullet=1, safe_ranged=1`（主推）；
  - **D**：C + `safe_slow=0.4`。
  - 共 4 组 × 28 = 112 局。
- **指标**：
  1. 点燃率（主指标），目标从 40–43% 抬到 ≥ 55%；
  2. 离圈原因分布，用本稿的离圈探针（`--bdbg` 加分项拆解），看 danger 是否从 90% 降下来、剩下的是谁；
  3. 胜率与同 seed 翻转（防止安全区让 Ⅷ 胜率越过 10–20% 目标上沿）；
  4. 承伤 / 分、溟痕存量（点燃变多后溟痕应下降）。
- **附加对照**：标准档高手 28 局 × A / C，看是否把高手胜率推出 55–70%（白给检查）。
- **判定**：
  - C 对 A 点燃率显著上升，且 Ⅷ 胜率不越过目标上沿 → 开 C；
  - D 只在 C 不够时再看；
  - B 单独用预计不够，只用来拆分 ① 和 ② 各自的贡献。
