## 4. 给 Codex 的反馈（下一轮返修，不挡合入）

1. **德克萨斯：补企鹅物流徽记**（用户 10-11 定保留）。现在四组动作里都看不到。请在左胸或外套袖口画一块白底小徽记：1x 下 2×3px 左右、@2x 下 4×6px，白底 + 1px 深色内点，四组动作每帧都在（跑动和前冲时跟着躯干走）。不要和手套的白块挨在一起，否则会糊成一块。
2. **能天使：出手帧枪口不要上扬**。`op_exusiai_attack` f1 和 `op_exusiai_skill` f3–f5，现在枪身整把抬起约 35°（@2x 枪口从 (+30,−33) 跳到 (+31,−50)）。请改成枪保持基本水平（枪口高度和瞄准帧差 ≤ 2px@1x / 4px@2x），后坐表现为枪和肩膀整体往后缩 1–2px、枪托顶肩、头微后仰；skill f4–f5 的连射抖动也保持在这个幅度内。出手帧剪影仍要和前后帧不同（靠后缩和肩膀压低）。
3. **星熊：站姿可以再高一点（可选）**。现在待机 / 跑动外框高 31–33px，是五人里最矮的，和工单「星熊重、站得高」相反。如果改：待机身体直起来到 35–36px（含角），盾仍护在身前；攻击 / 技能里的半蹲保留。改不改都不影响接入，接入时发射点会重量。

另有两处可不改：能天使待机光环不浮动（工单写的上下 1px）；安洁莉娜 skill f3 没有离地 1px。
