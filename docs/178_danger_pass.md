**结论**

1. 常规 · 无成长：新 26.8% vs 旧 39.3%，方向更难（−12.5 点），McNemar p = 0.27 不显著；落在目标 30–40% 下沿以下 3 点，但 95% 区间 17–40% 覆盖目标区。未触发 §3 的「< 25% 回调」条件，**没有跑回调轮**。
2. 常规 · 18 细胞：新 53.6%，在 50–60% 目标内；比旧高 10.7 点（p = 0.31，噪声级，方向与无成长相反，不解读为变易）。成长的收益在新值下更明显（无成长 → 18 细胞 +27 点，旧值只 +4 点），符合「危险感靠成长化解」的意图。
3. 高压两档：新旧都 5–9%，差在 ±4 点内，看不出方向；高压本身仍极难（高手 ≤ 9%）。
4. **危险感指标没有按预期上升**：生命 < 35% 秒四档新值都略低于旧值（6.6 vs 7.6、4.1 vs 4.6、5.9 vs 6.7、7.8 vs 9.7），与本机 6 + 6 抽样（2.3 → 6）方向相反；< 20% 秒约 1–2 秒 / 局。国王套低血触发极少（56 局里 1–6 局出现过，均 < 0.6 秒 / 局），门槛 0.3 下这件藏品基本不生效。即：本轮让队长更容易死（5–8 分钟死亡增多），但没有拉长「低血还活着」的时间——放宽的 2 秒上限 + 增伤更像把濒死变成直接死。

**建议旋钮值**

- 难度：维持本分支缺省（`enemy/dmg_gain_late` 1.10、`boss/leader_2s_cap` 0.68），无成长 26.8% 与 18 细胞 53.6% 都在目标附近；单份 56 局 ±12 点，下一轮按 docs/36 §7.5.1 补 placebo 1、2 两份再判无成长是否真低于 30%。若补跑后三份均值 < 28%，按 §3 先把 `enemy/dmg_gain_late` 1.10 → 1.05。
- 危险感：要让低血时间真正变长，靠的不是更高伤害，而是低血时的缓冲。可选：`relic/king_low` 0.3 → 0.4（让国王套实际能触发），或把满血保护保底 `boss/fullhp_guard_left` 5% → 8%；需再一轮云端对照验证，本轮未测。
