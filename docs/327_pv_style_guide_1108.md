## 1. 一句话结论

鹰角 PV 的「味道」来自四件事，我们的粗剪四件都缺：
1. **暗**：画面平均亮度 0.12–0.22（满分 1），六到七成像素在 0.15 以下；亮只在高潮和白闪里出现，每次不超过 1–2 秒。看起来亮的片（D、E 后段、F）是**去饱和的灰白高调 + 一个强调色**，不是彩色铺满。
2. **一个强调色**：平均饱和度只有 0.05–0.09。每支片只有一个强调色（B 猩红、C 灰蓝、D 冰蓝 + 一点红、F 灰 + 苹果红、A 暗红），其余全是灰阶。
3. **慢—快—停—慢—爆的结构**，切点落在拍上；字很少，标题最后才出。
4. **字体克制**：故事段只用细衬线（宋 / 明朝体）和极小的宽字距英文；粗黑体只出现在「活动信息」那种说明卡上。

景别和运镜（逐帧看下来的共性）：
- **开场一定是暗场里的一点光**：B 8.5–12 s 舞台顶光照着小标志；C 6.5–9 s 天空里的小标志；E 4–7 s 黑底上的周年标志；F 4.5 s 黑底联合标志。标志只占画宽 12–22%。
- **大远景 / 剪影建立 → 中景 → 特写 / 微距收**：B 的走廊（38–56 s）全是暗大远景慢推；F 用逆光剪影和长焦特写（手、苹果、火）；A 和 B 大量**微距物件**（王冠、卡片、棋子、羽毛）。
- **运镜只有慢推、慢移、漂浮**，没有手持晃动；快段才有快速横摇和推轨，且一镜一个方向。
- **焦点只有一个**：每镜画面里只有一个亮区 / 一个主体（顶光、逆光轮廓、一团火），四周压暗。这正是用户说的「焦点散」的反面。
- **3D 物件当道具**：B 和 D 都把游戏里的符号（卡牌、藏品、棋盘、徽记）做成有厚度的实物，在暗场里打一盏光，镜头贴着掠过（同 pv-cut 拉的回声行动 PV）。

| 类型 | 用在哪 | 时长 | 本作对应 |
|---|---|---|---|

### 2.3 节奏和鼓点

- **结构**：标志静音 4–9 s → 安静的前奏（暗、慢、少字）→ 爬升 → **急停**（黑场 / 一点光 / 只剩单音）→ 慢段或直接高潮 → 高潮（全片最亮最快）→ 标题 → 余韵（E、F 尾段都留 5–30 s 慢镜，最后黑底小标志）。
- 响度：E 前奏 −33 dB、爬升 −20 dB、满编 −12 dB；112 s 处降到 −30 dB 喘口气，172–179 s 渐弱到 −51 dB 后急停再起。D 同构：静音 4.5 s → −25 → −17 → −12 → 渐弱。
- **切点对拍**：C 快剪段一半落在拍点 ±0.04 s，其余在半拍（pv-cut 已量）；D 快段 60 刀里 31 刀落在起音 ±0.08 s（14 刀 ±0.04 s），D 的音乐起音很密（约 0.2 s 一个），所以它对的是**重拍和小节**，快段内部跟半拍。规律：**场景切换、白闪、急停、标题都踩小节线或重拍；快剪内部按 1 / 2 拍**。
- **标题最后出**：B 在 112 / 117 s，C 在 100 / 112 s，D 在 61 / 63 s。片中不反复出标题。

### 4.4 文字用量

- 全片文字按出现顺序：开头标志（若用）→ 干员名字条（每人一次）→ 三位追加干员的角落标名 → 标题卡 / 结尾卡。**片中不重复出标题**。

## 10. 画面美术（构图、材质、光、色）

- **构图**：主体放三分线或偏心，**留 50–70% 暗的负空间**（B 30.0、C 74.0）；巨物对小物的比例反差（C 31.5 巨大洞口里一块小礁石）；框中框（C 31.5、B 41.0）；微距贴近（C 38.0 鳍、B 13.0 手饰）。
- **材质**：鹰角 3D 段几乎全是**半透明 / 自发光 / 折射**材质：水母和鳍（透射 + 次表面）、冰晶触须（细、边缘亮）、高潮的玻璃 / 水体雕塑（C 92、96，折射 + 高光），没有塑料感的漫反射。本作对应：水母、发光触须、晶簇用透射 + 自发光；招募卡做成实物（有厚度、清漆高光、青色细边）。
- **光**：一盏主光（顶光体积光或逆光）+ 主体边光；不打平光，不用环境光把暗部抬平——暗部的「不死黑」来自雾和背景色，不是来自补光。
- **色**：单色调（C 整段蓝，色相 200–220）+ **一个极小的暖色点缀**（C 39.5 水母触须上的一点橙、C 48.5 一点黄，面积 < 1%）。暖点让冷色更冷。本作：青蓝为主，**灯火的暖橙 #FFB45A 作点缀，单镜面积 < 1–2%**；这条补充 §3「强调色只有水月青」——青是强调色，暖橙只作点缀，不作大面积。
- **动**：物体慢漂、慢转（每秒 0.5–3°），粒子按远近分速；没有匀速直线平移。

## 11. 字体风格（气质）

- **衬线讲故事，黑体讲信息**：名字、标题、旁白引语用 Noto Serif SC；行动语、说明、标名用 Noto Sans SC。同屏 ≤ 2 个字族、≤ 3 个字号级。
- **字号要悬殊，不要中间档**：主 : 次 ≈ 3 : 1 到 4.5 : 1（C 大字卡 4.5 : 1；C 结尾卡 MIZUKI 100 px : 中文 46 px : 副英文 36 px）。本作标题 132 : 副标题 48 : 英文 30。
- **大字细、小字粗**：大字用 400–600，小字用 500–700，保证小字在手机上可读、大字不笨重。
- **字距**：中文标题 0.1–0.3 em；英文小字全大写 0.3–0.5 em；字幕 / 说明 0–0.06 em。
- **颜色**：不用纯白（#ECF1F4），次级降到 60–70% 亮度；**不渐变、不外发光、不描边、不硬投影**，只用柔阴影（模糊 4 px）。
- **对齐和网格**：统一 5% 安全区（左右 96 px、上下 54 px）；英文微标签和中文左缘对齐；行距 1.3–1.5。
- **装饰只用细东西**：标题组里的 1 px 细线和小菱形、结尾卡角落的编号行；不用框、不堆图标、不用刻度、不用底板和色块标签（§16）。
- **动效**：硬切出现，或 6–12 帧淡入 + 4 px 模糊到清 / 位移 ≤ 20 px；不弹跳、不逐字打字（终端字除外）。

| 运动 | 漂浮旋转每秒 0.5–3°；推进先慢后更慢 | 基本符合 | — |

## 15. 对 pv-cut 现有样帧的意见（11-08 15:10 那批）

1. **开头水母**：好的地方是暗、半透明、有遮幅。问题：只有一层（水母 + 纯黑）；伞缘一圈等距光点太规整、像图标。改：加背景雾和一束顶光（L0、L1），近处 3–5 颗虚化海雪（L3），伞缘光点疏密不均，触须末端放一点暖橙。
2. **干员出场**：像素水月平贴在空中，没有光和影，和 3D 场景不融；圆光斑同大小、硬边，最像屏保。改：干员给青色边光 + 脚下接触光 / 倒影；光斑改成三档大小、焦外虚化；名字条避开丝线（文字不压在线上）。
3. **结尾卡**：标题版式按规范了；但背后丝线穿过标题、左下卡片卡面密字正对镜头，抢标题。改：标题区后面只留雾和一束光，丝线移到画外或压暗虚化；卡片转一个角度、只露边和一点卡面。
4. **发光丝线镜**：几十根等粗等亮的线都在焦内，没有主次。改：2–3 根主线清晰，其余远处虚化变暗；线的粗细和亮度都分档；加雾。

## 16. 纯色几何：在画面里，不在贴纸上（11-08 晚追加，同日改写；干员出场以 §17 为准）

> 用户 11-08（经 pv-cut 转述，大意）：舟游设计最统一、最标准化，很重要的一点是**大量使用纯色或接近纯色的几何图形，单个元素尽量不复杂**；现在的样帧「还是不太有设计感」。随后 pv-cut 按此出了「大块纯色面板 + 色块标签」版式，用户判**太丑，PV 里不会有这种大块方块**。
> 所以本节的意思是：纯色几何体现在**画面本身的构成**里——整片的黑、整片的灰白、一个单色、简单剪影、光的形状——而**不是**贴在画面上的 UI 零件。pv-cut 复看塔露拉前瞻 PV 印证了这一点：人物出场是居中一束光、四周暗的大留白（约 20 s），文字只有底部居中的小号中英字幕。

### 16.1 不做

- 纯色面板、侧栏、信息栏、色块标签（职业色块、底条）、条码、大号编号底纹、画框角标、HUD 刻度装饰。
- §4.3 里原来的名字条竖条 / 英文底纹 / 行动语青底条已一并删掉（N1–N3、C1 已改）。

### 16.2 做：画面由几块大面积纯色构成

| 手法 | 鹰角例 | 本作做法 |
|---|---|---|
| 整片暗 + 一个亮形 | F 120–124 黑场一束顶光照一个人；B 30.0 一束光照一件物 | 黑海底 + 一束青白顶光锥 + 光里的一个像素干员；光锥边缘清楚，是一个三角 / 梯形 |
| 整片灰白 + 一个暗形 | F 17–24 灰白天空里的剪影；D 13.5 白底上的小黑点 | 高潮前后可用一次：白闪后的灰白画面里一个干员剪影 |
| 单一颜色铺满 | B 22–24 整片红幕；F 165–185 整片火 | Boss 段：整片深红；终结技：整片青白 |
| 简单剪影 | F 28–31 逆光人影；B 41.0 栏杆剪影 | 海嗣、灯塔、礁石用纯黑剪影，不画细节 |
| 光的几何 | C 74.0 光柱；B 10.5 顶光圆 | 光锥、光柱、地面光圈（椭圆）、水平线 |

规则：
- **一镜 ≤ 3 块大色面**（例如：黑背景 / 光锥 / 主体），每块颜色接近纯色（色块内亮度起伏 ≤ 0.1），边界清楚。
- **主体居中或在三分线，四周留白 ≥ 60%**。
- 颜色仍按 §3：深海黑、灰白、水月青，Boss 段单一红；灯火暖橙只作点。
- 像素素材全片统一一个放大倍数（例如 1 游戏像素 = 8 屏幕像素），最近邻缩放，不能有粗细两种像素格。

### 16.3 文字（跟着这条收紧）

- 出场名字、旁白都在**底部居中**的同一位置，小号（N1–N3、S1）；一镜只出一组。
- 结尾卡 T1–T4 + C1 + D1 保留，但不加面板和色块；背景是画面本身（主视觉或一束光）。
- 字体：方正雅宋（用户提到鹰角用它做人文化设计）是方正的商业字体，视频里用要买商用授权，同人 / 免费作品也一样；免费替代仍是思源宋体（Noto Serif SC）。类 engraving 西文可选 Cinzel / Cormorant（SIL OFL 1.1），要从 Google Fonts 下载，**下载前问用户**；没下载前用 Montserrat / Noto Serif SC 拉丁。

| 官方 | 本作替代 |

| 实机放技能（在名字卡之后） | 实机录像里这名干员放技能（按 §9.3 叠海雪 + 暗角） |

节奏（battle2 一小节 1.644 s；用户 11-08 定，pv-cut ded67f7b9 已按此做）：一位干员 = **名字卡 1 小节 → 实机技能 0.5–1 小节**（先出场、后技能），名字卡内部**先镜头运动、人物一点点出来，再出字**：

| 名字卡内 | 帧（60 fps） | 画面 |
|---|---|---|
| 贴近 | 0 起 | 镜头贴在人物附近（约 1.6 倍），人物是剪影，无字 |
| 拉开 + 亮起 | 0–48（0.8 s） | 镜头缓出拉开到全景；人物从剪影亮到原色；**人物站在对准她的光束和脚下光圈里**（光束底边中心 = 人物脚下中心） |

### 17.3 对 §16 的修正

§16 说的「纯色几何在画面里、不贴面板」仍然成立；但「一束光 + 底部一行小字」只适合叙事 / 急停镜（N3），**不适合干员出场主镜**。出场主镜按本节：画面要满、字要大、小字簇和小几何（2×2 小方格、下划线、编号）可以有，大块纯色底板仍然不要。
