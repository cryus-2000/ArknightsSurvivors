## 2. 本作改编

定位：**特种 · 拉拽控制 + 深海猎人续航核心**。全队第一个「把远处敌人拖到身前」的干员：远程怪、吐酸怪拉过来给近战队友砍；编队里每多一名深海猎人（斯卡蒂 / 浊心斯卡蒂 / 乌尔比安 / 归溟幽灵鲨），队长的回复与减伤多一档。与乌尔比安区分：乌尔比安是近战锚击、精二才有一次「掷锚拖回一线」；歌蕾蒂娅**每一下**都是掷钩拖回，单体、远距、落地范围小。

### 2.1 普攻「钩索」

- 名义普攻是 `shape.circle center front`（不会出手），`trait` 用 `trig.every_n {n 1, replace}` 把**每一下**换成 `shape.hookshot`（docs/61 §18.1，乌尔比安精二掷锚的积木）：钩索掷向射程 `range` 240 内离她最远、且 70 以外的敌人（没有就最近的），飞 ≤ 0.24 秒，落地半径 90 内攻击 ×1.0（`src 钩索`）；锁链绷直 0.12 秒后把钩索到她之间一线宽 40 的敌人（至多 `hook_n` 1 名，Boss 除外；`drag_only: ranged` 只拖远程怪的版本 10-22 第 4 轮试过，单开无改善，改回 all）0.22 秒拖回身前 150 处（拉到接触范围外：她当队长时怪不会直接被拉进身上，10-22 首轮 16% 胜率的教训），到位再受 60%（`src 拖拽`）。间隔 `cd` 1.1 秒，钩索在外面时不出手（`lock`）。
- 索敌 `attack.range` 240（数值表「射程」行读 `base.range`）。
- **队长身份（10-22 协调人定 ②，分支 claude/gladiia-leader-hook）**：`leader_pin_stun` 0.7——她当队长时钩住**不拖**：本该被拖回的那些敌人原地眩晕 0.7 秒（精英减半，Boss 不受），「拖拽」到位伤害在原地结算，钩与锚联动落在钩中点；队友身份照常拖回喂近战。原因：五轮调数单开都停在 37–54%，拉怪向自己与队长生存天然冲突（§5）。
- 帧条契约：占位期借乌尔比安 `attack` 槽（8 帧、出手 0.29 秒）；正式帧条到了按 docs/108 §9 写 `attack_timing {duration 0.5, fire_time 0.29, active_ratio 0.9, windup_ratio 0.45}`。

### 2.2 天赋「阿戈尔的波涛」（精一）

她在队时队长每秒回复 **0.6%** 最大生命（**入队即生效**，10-22 第 4 轮从天赋挪到特性）；精一起编队里每名其他深海猎人再 +0.3%/秒、队长受到的伤害 −5%（至多 3 人：满编深海猎人 = 1.5%/秒 + 15% 减伤）。
实现：`trait` 一块 `aura.heal {scope always}`；`talent` 三块 `cond faction:深海猎人 >= 1 / 2 / 3` 各加 `aura.heal` + `verb.dr`（星熊段的队长减伤积木）。原作「海怪伤害降低」在本作全是海怪，直接作通用减伤；原作天赋二「弱肉强食」（对轻型敌人攻击 130%）本作没有「敌人重量 / 非精英加伤」积木，先不做（§3 新积木清单）。

### 2.4 精英化（docs/91 §0.2 口径）

- **精一 · 普攻「锚定」**：钩索把敌人拖到身前后，身前 180 内的敌人眩晕 0.6 秒（精英减半，Boss 除外）。`progression.elite1 = every_n {n 1, delay 0.45}` → `verb.displace {kb 0, on_hit st.stun}`（延迟 = 锚飞行 + 绷直 0.12 + 拖回 0.22）。不加伤，给近战队友一个安稳的输出窗口；画面：到位处蓝色小光点。
- **精二 · 普攻质变「冲撞」**：钩索把敌人拖回到位时，身前半径 80（中心在身前 1.9 × 80 = 152，即拖回落点）掀起一圈冲击：攻击 80%、击退 160（10-22 试过 260：云端复核 50% → 43.8%，无改善，改回）。**队长身份**改为以钩中点（`center: last_hit`，circle 新增的中心）为圆心、掷钩后 0.3 秒结算，两块 `every_n` 按 `cond is_leader / !is_leader` 分开。`progression.elite2 = every_n {n 1, delay 0.5}` → `shape.circle center front`。动词「拖回撞击」：被拖回的敌人撞进身前的人堆，与乌尔比安「抛出 + 回拉」（一次拖一线）和星熊「往返」不同。单体 +80% 每下看起来多，但钩索间隔 1.1 秒、基础只有 1.0 + 0.6，精二后每下 1.0 + 0.6 + 0.8 = 2.4：按 docs/91 「相对现有精二 ±10%」，木桩表（§5）超出就把 `ram_mult` 下调。

### 2.6 响应动作（docs/118，设计，本阶段不实现）

触发源选**冲刺**（协调人建议「队长冲刺时把落点敌人拉向自己」，论证成立）：

- **「回收」**：队长冲刺结束时，她朝冲刺**落点**掷钩，把落点半径 110 内至多 3 名敌人（精英减半，Boss 除外）拖回自己身前，**到位后眩晕 0.5 秒**（精英减半，Boss 除外；不加伤）；由队长冲刺触发，不另计冷却（满足 docs/118 §1.4：她不位移，被拖的是敌人）。
- 论证：冲刺是「脱离 / 切入」，落点处的敌人正是玩家想摆脱或想集中打的那一撮；把它们从落点拉回她（也就是队伍）身前，既清开落点又喂给近战队友。乌尔比安的冲刺响应是「拉到自己身前 + 下一锚 ×1.3」（加伤），这条改成「拖回后眩晕」（控制），两人同队时一个负责打、一个负责定住，不抢同一种收益（协调人 10-22 定）。
- 积木：`blocks.response = {trig: on_leader_dash, at: dash_end, do: [shape.hookshot {target: leader_dash_end, max_n 3, back_mult 0, on_arrive: [st.stun 0.5]}]}`；需要 `trig.on_leader_dash` 从德克萨斯段挪到共用段（docs/118 §3.1）+ `shape.hookshot` 加 `target: leader_dash_end` 与 `on_arrive`（新参数）。

### 2.7 专属联动「钩与锚」（歌蕾蒂娅 × 乌尔比安，10-22 用户提议、协调人派单；已实装）

- **效果**：歌蕾蒂娅的钩索把敌人拖回到位时，乌尔比安在落点 260（× 射程倍率）内就立刻朝落点补一次锚击：半径同锚击（105）、攻击 ×1.0、击退同锚击，每 2 秒至多一次，**不占他的普攻冷却**；这一击的击杀照常算他的（天赋「血脉的哺养」的精英 / Boss 击杀叠层）。只在两人同队时出现；她当队长或队友都行。反向（他掷锚拖回的敌人她优先瞄）本次没做：钩索只认「最远」目标，要先加 `pick` 参数（§3）。
- **可见**：招募卡 / 换人卡说明行加「联动：与乌尔比安「钩与锚」」（换人卡写「新增 / 失去联动」），走切片 B 的只读接口 `build_affinity`（`combo_partners / combo_line`），数据来自两人 JSON 顶层 `combo {with, name, knob, desc}`，不写干员名硬判。战斗里是乌尔比安多出的一下锚击（同锚击画面）落在她的拖回点上。
- **实现**（docs/61 §21）：新触发器 `trig.on_mate_hook {op, cd, range, knob, do}`（精英化段 `EL_TAGS`，`data_operator.on_mate_hook`）；`shape.hookshot` 拖回到位（`_hw5_hook_arrive`，有人被拖回时）广播 `notify_mate_hook(落点, 被拖回的敌人)`；乌尔比安 `trait` 加一块 `on_mate_hook {op gladiia, cd $combo_cd 2, range $combo_range 260, knob combo/hook_anchor}` → `shape.circle center target r $reach mult $combo_mult src 钩与锚`。开关 `balance.json combo/hook_anchor`（缺省 1；0 时两人同队与无联动同 seed 逐行相同，其他编队不经过这条路径）。确定性：只读 `g.t` 与两人位置，不取随机数。
- **机器人小样**：见 §5 末「钩与锚」对照。

## 3. 积木落地

**全部用现有积木**（纯数据干员，0 个 `custom`）：`shape.hookshot / circle`、`verb.displace / field / shield / dr / mode / buff_self`、`aura.heal`、`trig.every_n / passive / on_skill_end`、`st.stun / slow`。`validate_operator` / `test_core` 干员契约通过。

**需要新积木 / 新参数的清单（本阶段没做）**：

| 需求 | 现状 | 用处 |
|---|---|---|
| `shape.hookshot` 进 `ATTACK_SHAPES`（直接当普攻形状，带 `cond` 变体） | 只能放技能 / 触发器 do，现在用「名义 circle + every_n n:1 replace」绕 | 去掉名义普攻；路线「怒海」三份参数可以收成一份 |
| `shape.hookshot` 的 `on_hit` / `then`（拖回到位时的状态与追加效果） | 没有 | 「锚定」眩晕、「冲撞」现在靠 `every_n delay` 对齐时刻，锚飞行时间随距离变（0.1–0.24 秒）会错开 |
| `shape.hookshot` 选目标 `pick: nearest / densest`、`target: leader_dash_end` | 只有「最远」 | S1 想拉精英、响应动作拉冲刺落点 |
| `verb.displace to: self`（拉向自己） | docs/91 §20 列了，未实现 | S3 结束「拖拽至面前」、响应动作 |
| 对非精英 / 轻型敌人加伤（`mod.cond_dmg`） | 📝 未实现 | 天赋二「弱肉强食」 |
| `trig.on_leader_dash` 共用段 | 只在德克萨斯段 | 响应动作「回收」 |

**已知妥协**：钩索只认「最远」目标，S2 的「每次拖两个」改为「掷钩时把身边敌人拉近」；S3 不绑定远处目标，落在最近一次钩中处；两钩同时在外上限 2（`HW_HOOK_MAX`），S1 与普攻叠加时第三条链不会出。
