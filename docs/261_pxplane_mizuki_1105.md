## 1. 意象与配色

- 深海、水母、触手、幻象（镜花水月）。原作参照：普攻命中是蓝色尖刺星芒一闪后鼓开青色水母伞（attack_01_hit）；S1 是深紫水面 + 青色光 + 触手（skill_01_start）；S2 起手是触手往中心收 + 冰蓝尖晶炸开 + 暗色碎屑（skill_02_start）；S3 命中是圆形里一朵四瓣纹（skill_03_hit）。
- 色：本人深蓝紫 8 阶（house.js `OP.mizuki` 加一阶淡紫白 `#cfd6ff`）；水母荧光青 `#6fe8ff` / `#c4f7ff`；精二点缀荧光紫 `#b98cff`。不用危险红。
- 半透明淡出不用 Bayer 抖动（2 倍下成网点），用噪声成团消散；持续地面区域（水镜）只画断续的边 + 2 格深色内边 + 贴边真半透明淡渐变（α ≤ 0.12）。

同一招元素：主形（伞面 / 旋斩 / 大水母）、水母绽开或触手、贴地件，至多 3 种；照地光不算。

**分档口径（11-05 用户看 GIF 后改）**：用户「E0 普攻不加触手，差额更大」「加吸盘亮点看不出什么差距」——每升一档多一个新元素或形状变化，不靠换色 / 加细节：E0 伞面 + 水母 → E1 触手出现 → E2 荧光紫 + 深蓝之籽 + 双触手 / 对缠。原 E1 的伞沿细须、青色伞沿已删（伞面 E0 = E1）。

**同屏上限**（不碎、不整屏发白）：同一名干员触手至多 8 根、同一只身上 0.35 秒内不叠第二根；缠绕至多 10 只（同一只续时间不叠）；命中水母至多 5 朵；伞面只留上一刀 + 这一刀。接管时唤醒的整屏闪（`g.flash` 0.12）和技能起手的整屏闪（0.25）、金环 / 放射线不生成。

**跟人**（docs/246 §10）：伞面 / 旋斩、S2 起手那圈触手、S3 起手大水母挂在人身上（`fo`）；缠绕跟被缠的那只（`ef`，敌人死了就收）；裂隙、冲击环、水镜月影、细水纹留在原地；S3 持续水镜每帧画在脚下。
