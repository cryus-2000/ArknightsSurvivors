# 160 · 跑动拖尾的干员代表色（10-26）

> 用户 10-26：「每个人跑步后面跟随的粒子特效可以换成他们自己的代表色」。状态：已实现（分支 `claude/run-trail-colors`），待用户看对比图。

## 1. 哪个粒子

跑起来时队长身后拖着的那串小火星 = 光学观感的「灯火余烬」（`render/optical_particles.gd` `embers`，GPU 粒子，`local_coords = false`，所以跑动时被甩在身后）。原来一律是灯火色（暖橙），现在改成**当前队长**的两个代表色。

- 数量 / 尺寸 / 寿命一律不变（`render/ember_n` 缺省 16，低档仍按 `k_amount` 缩，性能预算不变）。
- 每颗出生时在「主色 → 辅色」的渐变上随机取一个色（`ParticleProcessMaterial.color_initial_ramp`）；渐变只在队长换人（按 Q 切队长 / 开局）时重建一次，每帧只比较一个字符串。
- 队友身上没有这类粒子（只有队长带余烬），所以「队友」体现在：**换队长后拖尾立刻换成新队长的颜色**。冲刺没有独立拖尾粒子（只有落地环 / 无敌闪），无须另改。
- 灯火低时的红色余烬（`vfx.gd` 的 lamp_dim）是灯火状态提示，保持灯火色不动。
- 旋钮：`render/trail_col`（缺省 1；0 = 回到灯火色，录帧对照用）。

## 2. 数据

写在 `data/characters/<id>.json` 顶层：`"trail_col": {"main": [r, g, b], "alt": [r, g, b]}`（0–1）；没写退回 `col`。`character.gd` `trail_cols()` 读它，**亮度 < 0.55 的向白提亮到 0.55**（深色系在深海地面上看得见；表里的色已按此取亮，提亮只是兜底）。
