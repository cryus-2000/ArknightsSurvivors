## 2. 本作改编

### 2.0 共通

- **结局线卡**：同水月（docs/154 / 184）。路口一必出一张结局线入口卡；持某条线的信物时，后面的路口必出这条线的后续卡；卡背色边 = 结局色（`endings.gd` `LINE_ENDS`）。
- **9:00「走过萨米的臂膀」**（本作拟，对应原作第Ⅴ层倒数第 2 个节点）：
  - 开了结局线的局，9:00 固定弹一次命运所指，替换水月的 9:00 纯文字终局预告。
  - 选项：【前进】一直可选；【戴上头盔】需要【树痕之盔】。
  - 持【维度流质】的局改弹「重构」（§2.3）。
  - 选完再显示该结局的终局预告（`omen`）。
- **判定**：沿用 `endings.gd` `judge()`（信物 + flag + forbids，取优先级最高），最终 Boss 登场即冻结。萨米的 `endings` 已有 winter / abyss / eternal 条目，现在 requires 是占位 flag，改成下面各节的条件。
- **资源折算**：原作的希望 / 抗干扰指数，样例里还没有，按 docs/390 的口径折算：希望换源石锭；抗干扰指数在全量做之前改用坍缩值。

### 2.1 结局二 · 直至冬夜降临（Boss 「木裂」埃克提尔尼尔）

**主方案（贴原作，要密文板面板）**

1. **入口**：路口一的结局线卡 = 失与得「低地市集」（途中路口一 1:20 也可以按权重出）。
   - 【帮助拿着密文板的萨米人】：坍缩值 +4，得【空无】【伤痕】两块无色密文板，只在两块都没有时出现。原作原样。
2. **宣告**：在密文板面板（docs/394 §5，空无 / 伤痕两行已经写好）把两块组合宣告，坍缩值照常 −1。下一个路口里有一张卡变成命运所指「木裂前兆」，这张卡必出。
   - 时限：路口二发牌之前（原作「第Ⅴ层倒数第 3 个节点之前」）。过了时限，两块板留着也没用。
3. **木裂前兆**：
   - 【搜索营地】→【树痕之盔】。原作效果「希望 +3」，本作拟改成「回复 30% 生命」。
   - 另一个选项：搜刮物资离开，给少量源石锭（本作拟）。
4. **9:00「走过萨米的臂膀」**：【戴上头盔】→ 结局二；选【前进】仍走结局一（原作同）。
5. **条件**：`requires {relic: 树痕之盔, flag: sami_helm_on}`，`forbids` 无。

**备选（不等密文板面板）**：【空无】【伤痕】合成一件结局线藏品「空无·伤痕」，拿到后下一个路口自动出「木裂前兆」，省掉宣告这一步，其余同主方案。密文板全量上线后再换回主方案。

### 2.2 结局三 · 自深处的一瞥（Boss 无垠回荡克雷松）

**主方案**

1. **入口**：路口一的结局线卡 = 先行一步「探寻前路」。
   - 【征求凛视的意见】→【路网】。
   - 效果改编（本作拟）：之后每次大群刷怪量 +15%，精英小队 +2 人。对应原作「作战出现额外敌人」，最终 Boss 战不加。
2. **凛视的路线**：
   - 持【路网】时，下一个路口必出一张紧急作战卡「凛视画出的路线」，卡背是结局三的颜色。
   - **这个路口不翻它，【路网】就变灰，本局失去结局三**（原作「没走这条路就永久失去」）。
3. **悲观者囚笼**：清完这支精英小队弹事件「悲观者囚笼」。
   - 【捧起祭坛上的花】→【无垠赠礼】，坍缩值 +3（原作）。
   - 【还是算了】→ 坍缩值 −3（事件一览里这个选项的效果）。
4. **条件**：`requires {relic: 无垠赠礼}`，`forbids [维度流质]`。
5. **Boss 场地**：10:00 起换「远见之构」冻结场地，同终始的 `boss_map` 做法（docs/393 §8 第 6 条），不做整局换图。

**备选**：持【路网】且坍缩等级到 5 级时，凛视出现，直接弹「悲观者囚笼」，不刷精英小队。这样跟坍缩值主轴绑得更紧，代价是不翻卡也能进，原作「必须走那条路」的取舍感变弱。

### 2.3 结局四 · 终始（Boss 哈兰杜汗 + 路加萨尔古斯）

**主方案**

1. **视界邀约**：
   - 商店卡（诡意行商）有 70% 概率上架【视界邀约】，售价 5 源石锭（原作 1 源石锭，「大概率」）。概率与价格都是本作拟。
   - 第一次进局的路口一结局线卡也可以直接是「诡意行商·视界邀约」，免得一直刷不到。
2. **变化**：持【视界邀约】时，下一个路口必出不期而遇「变化」。
   - 【出示视界邀约】→ 特殊战斗「黄沙幻境」。本作拟：30 秒沙尘场地，刷两王的「影子」小怪（`twin.gd` 的 shadow），活过或清完都算赢。
   - 赢了得【维度流质】，【视界邀约】消耗掉。
3. **9:00「重构」**：持【维度流质】的局，9:00 改弹「重构」，三段连选，每段都另有【依靠安玛的遗赠】（失去【安玛的爱】）：

   | 阶段 | 选项（括号里是本作折算） |
   |---|---|
   | 一 | 坍缩之种（负面藏品） / 过载探测（坍缩值 +3，代替抗干扰指数） |
   | 二 | 空间碎片（负面藏品） / 50 源石锭 / 失去【树痕之盔】 |
   | 三 | 深度灼痕（负面藏品） / 最大生命 −10%（代替 20 希望） / 失去【无垠赠礼】 |

   - 原作「进入永恒之尘时坍缩值不增加」→ 本作：9:00 以后坍缩值不再涨。
4. **条件**：`requires {relic: 维度流质, flag: sami_rebuilt}`。重构三段都付完才置 flag；中途付不起的选项灰掉，至少保留一个负面藏品选项，保证付得起。
5. **Boss 场地**：已定 10:00 起换「永恒之尘」（`boss_map: eternal_dust`）。

**备选**：不做「变化」和「黄沙幻境」，把它们并成一张紧急作战卡「黄沙幻境」，持【视界邀约】时在下一个路口必出，清完得【维度流质】。少一个事件、一种特殊战斗，代价是少了「出示邀约」那一下的剧情感。

### 2.4 几条线的关系

- 优先级照原作：终始 > 一瞥 > 冬夜 > 越过群山。同一局可以同时追几条线，高的覆盖低的。原作也能叠，例如持赠礼又持流质会走终始。
- **结局线卡的时间点**：入口都在路口一，后续卡都在路口二（路口二最多 3 张卡）。三条线同时追时：
  - 路口二最多被「木裂前兆」「凛视的路线」「变化」三张必出卡占满，没有填充卡。
  - 这是玩家自己贪的结果，符合原作「信物链互相挤节点」的味道，所以不另设限制。

## 3. 玩家怎么知道这些结局（参照水月）

水月现在的做法：
- 图鉴结局页锁着时显示「触发：…」一句（`gallery.hint`）。
- 结局线卡卡背带结局色，路口一必出入口卡。
- 拿到信物时横幅「探索的走向改变了：结局 X」，9:00 弹终局预告。
- 结算页显示「已达成 n / 4」。

萨米照搬这几样，另加两处：

1. **图鉴提示**（草稿，按 docs/76 再润色）：
   - 结局二：在失与得里接过特别的密文板，把它们宣告出来，找到「树痕」的头盔。
   - 结局三：听凛视的意见，并走完她画出的路。
   - 结局四：向诡意行商买下一张邀约，在「变化」中出示它。
2. **远见**（原作机制，docs/394 已用于预告范式 / 密文板）：持结局线信物时，HUD 远见行改成显示下一步，例如「凛视在下一个路口画出了一条路线」「密文板指向下一个路口」，玩家不用记步骤。本作拟。
3. **9:00 命运所指**：「走过萨米的臂膀」本身就是提示。持头盔时【戴上头盔】高亮；没头盔时这个选项灰着写「需要树痕之盔」，第一次通关后的玩家会看到这条路存在。

## 4. 和局外成长、首通奖励的关系

- **进度按主题分开**（docs/390 第 4 条，用户 11-19「原作也是各个作品单独成长」）：萨米的 `endings_cleared` 存在萨米自己的主题存档里（`theme_save.gd`），跟水月互不影响。
- **首达奖励**：沿用现有口径，结局首达评分 +40，不乘系数（`meta.gd`），再加图鉴解锁、结局勋章（`medals.gd`）、结算「已达成 n / 4」。不额外给局内强度。
- **解锁顺序**：两种口径，见 §6 第 1 条。
  - **原作链**：结局二要先通结局一，结局三要先通结局二，结局四通任一结局后开。
  - **水月口径**：通结局一后三条线一起开。

## 5. 胜率批跑：机器人怎么走

- `endings.gd` 的 `bot_route()` 现在按 seed 在水月四条路线里轮换。萨米改成 `["winter", "abyss", "eternal", "none"][seed % 4]`，`--route=` 可以固定一条。`bot_choice()` 加萨米事件的映射：
  - 低地市集选密文板；木裂前兆选搜营；臂膀按路线选头盔或前进。
  - 探寻前路选凛视；路口二必翻「凛视的路线」；囚笼选捧花。
  - 商店买邀约；「变化」选出示；重构每段挑负面藏品以外最便宜的一项。
- 密文板宣告（主方案）：机器人拿到空无 / 伤痕就立刻宣告。
- 批跑缺省开结局线（同水月 `lines_on`：测试 / 批跑缺省开），所以 112 局约 3/4 会走结局二到四。
- **对胜率的影响**：
  - docs/392 §13.3 的 54.8% 只含结局一，结局线做完要重测。
  - 三条线都带代价：结局二坍缩 +4，结局三刷怪 +15% 外加坍缩 +3，结局四要付重构代价。
  - 预计无认知总胜率下降 3–6 个百分点，结局三最难。
  - 汇报改成按结局分开列胜率；目标沿用 docs/392：混合路线总胜率无认知 45–55%、18 细胞 65–75%。
- 单结局冒烟仍用 `--forceending=winter / abyss / eternal`（已有）。
