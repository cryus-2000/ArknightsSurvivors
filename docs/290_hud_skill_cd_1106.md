## 技能细格

一个技能占一段，从左到右依次是 S1 / S2 / S3。

| 状态 | 画法 |
|---|---|
| 没解锁 | 空框（白，30% 不透明） |
| 充能中 | 暗底，灰色（`GREY`）从左往右填，填满就是充能完成 |
| 生效中 | 白色，从满往左退，表示剩余时长。队友在该段下方写剩余秒数，队长写在细格行右边 |
| 永久型已生效 | 整段白，不写秒数 |
| 就绪（充满待放） | 亮青（`UI.CYAN`）。自动技能一般一充满就放；德克萨斯这类要等敌人进范围才放的技能会停在这一档 |

这几档都守指挥台的造型规矩：常态只用黑白灰，青色只表示「能用」，不用洋红和金色，也不画底板，每段只垫 1 像素黑边，防止糊进地面。

尺寸（s = 1.25 桌面 / 1.0 触屏，单位是界面像素）：

- 段高 `max(2, 2.4 s)`，桌面 3 像素；段间距 `max(2, 2 s)`。
- 队友细格和头像同宽（34 s），画在血量线下方 2 s 处，不抬高整台。
- 队长细格宽 30 s，和等级牌垂直居中，画在等级牌右边 4 s 处。
- 秒数用拉丁数字字体：队友 `max(7, 6.5 s)`，队长 `max(7, 7 s)`。

## 悬停提示（桌面）

鼠标停在队长头像（含等级牌）或某个队友头像上，整台正上方会浮出一块小牌：

- 一招一行，左边写技能名，右边写状态。
- 状态有：就绪（青）、生效中 N 秒（白）、充能中 约 N 秒（灰）、永久生效、精英一 / 精英二解锁。
- 「约 N 秒」按当前自然充能速度估算：技力倍率 × 干员技力回复 × 灯火档。命中回技力的招会比估的快，所以写「约」。
- 看提示时整台保持全亮。触屏不出这个提示。

Tab 属性面板（桌面三栏版）编队栏的每个头像下，也画同一行细格；鼠标移上去出同一块提示。队长三招的说明仍在攻击栏下半（`skill_rows_data`）。手机五页版没改。

## 放不下就滚轮（11-06 用户定，作为缺省做法）

用户 11-06 的原话：「技能那一栏放不下，可以改成滚轮的」「默认所有放不下的全部加上滚轮」。

**规矩：** 菜单和面板里的列表放不下，一律按行滚动（滚轮），不截断成「…」，也不把多出来的收成「+N」。右沿画一道 2 像素的细滚动条（暗轨 + 白滑块）。鼠标停在哪块，就滚哪块。局内 HUD（状态行等）打的时候不方便滚，照旧收「+N」，全部内容在 Tab 里看。

**Tab 属性面板（桌面三栏版，`stats_panel.gd`）：**

- 技能栏：每招说明按全文算行高，从当前行往下放得下几行就画几行。原来是把说明压成一行「…」，天赋行还会掉出面板。
- 编队栏的成长和藏品：合成一列按行滚。小标题算一行，每排图标算一行。原来藏品多了，前面的会收成「+N」格。
- 通用实现：`_scroll(区域名, 矩形, 每行高度)` 返回起始行并画滚动条；`wheel(dy)` 由 `game.gd` 在 STATS 状态下转来；每次打开面板调 `reset_scroll()` 回到顶上。
- 截图参数：`--tabscroll=N`，把这两块各滚 N 行。

**原来就能滚的：** 事件选项（`choice_panel`）、寻访指定干员列表（`headhunt`）、作战记录（`run_stats`）、对局记录（`run_log`）。

**还没做：** 手机五页版属性面板，要靠拖动来滚。
