# 290 指挥台技能冷却（11-06 示意，待用户定）

用户 11-06：「现在界面看不到各个干员的技能和cd了，这个怎么改」。用户选了 A + B，要先看示意图。
指挥台（docs/222 §18，`game/scripts/screens/hud_v3.gd`）开着时，右下角的编队卡和技能格不画。三个技能现在都自动释放，冷却只是给玩家看的信息。

本页只说明示意版。两个开关缺省都是 0，所以游戏缺省画面和同种子 TRACE 都不变。

## 开关

| 键 | 值 | 效果 |
|---|---|---|
| `ui/console_skills` | 0（缺省） | 不画技能细格 |
| | 1 | 布局一：队长细格放在终结技环下方，环整体上抬一行（桌面约 7 像素） |
| | 2 | 布局二：队长细格放在等级牌右边，整台不抬高 |
| `ui/console_peek` | 0（缺省） / 1 | 方案 B：临时展开旧的编队卡 |
| `ui/console_dash_trace` | 0（缺省） / 1 | 冲刺格充能沿图标轮廓走一圈（见下「冲刺格充能」） |

截图用的调试参数：`--slot4` 开局解锁第 4 位编队；`--consolepeek` 让编队卡一直展开。出图脚本是 `tools/probes/hud_skill_cd_1106.py`，在 GCP 上跑。

## A：头像下 3 段技能细格

一个技能占一段，从左到右依次是 S1 / S2 / S3。

| 状态 | 画法 |
|---|---|
| 没解锁 | 空框（白，30% 不透明） |
| 充能中 | 暗底，灰色（`GREY`）从左往右填，填满就是充能完成 |
| 生效中 | 白色，从满往左退，表示剩余时长。队友在该段下方写剩余秒数，队长写在细格行右边 |
| 永久型已生效 | 整段白，不写秒数 |
| 就绪（充满待放） | 亮青（`UI.CYAN`）。自动技能一般一充满就放；德克萨斯这类要等敌人进范围才放的技能会停在这一档 |

这几档都守指挥台的造型规矩：常态只用黑白灰，青色只表示「能用」，不用洋红和金色，也不画底板，每段只垫 1 像素黑边防止糊进地面。

尺寸（s = 1.25 桌面 / 1.0 触屏，单位是界面像素）：

- 段高 `max(2, 2.4 s)`，桌面 3 像素；段间距 `max(2, 2 s)`。
- 队友细格和头像同宽（34 s），画在血量线下方 2 s 处，不抬高整台。
- 队长布局一：细格宽 0.9 × 头像直径（45 s），画在环和「Q 终结技 64%」之间，环上抬 6 s。
- 队长布局二：细格宽 30 s，和等级牌垂直居中，画在等级牌右边 4 s 处。
- 秒数用拉丁数字字体：队友 `max(7, 6.5 s)`，队长 `max(7, 7 s)`。

## B：临时展开旧编队卡

旧编队卡就是 `hud_squad.gd` 的部署卡加技能格。打开方式：

- 键盘按住 Alt，手柄按住 Ⓨ，松开就收回。
  - 没用 Tab：Tab 和 C 在局内已经是属性面板（`game.gd`），手柄 SELECT 也注入 Tab。
  - Ⓨ 在终结技模式下没有动作（原连携键，11-05 收回）。
- 触屏点队友头像区，展开 5 秒；再点一次收回。参照手机编队卡收起（docs/221 P1）的做法。

展开的卡组靠屏幕右下。如果和指挥台右翼横向重叠，就抬到整台上沿之上；不重叠就贴底。指挥台开着时，展开一律是整卡，不走手机收起版。

## 冲刺格充能

用户 11-06：「冲刺的加载沿着图标加载而不是笔直往上」。

- 原来：正在充能的那一格，从下往上竖直回填一截青色。
- 现在（`ui/console_dash_trace = 1`）：一道青色亮边（90% 不透明，线宽 `max(1, 1.2 s)`）沿冲刺图标（箭头形）的轮廓走，走满一圈就是充好。凹进去的尾槽也跟着走。
- 起点和方向同终结技刻度环：从图标上沿中点出发，顺时针走。

已充好的格是实心青色，没充的格是 15% 白，这两档不变。
