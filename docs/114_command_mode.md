# 114 指挥模式（第 1 步原型）

状态：原型（10-21），分支 `claude/command-mode`，未合 main。第 2 步目标优先、第 3 步接局外成长（docs/109）和正式按键，另做。

## 1. 用户已定

- 一个键循环切换，不用长按：**随行**（缺省，现状）→ **突击** → **归队** → 自动回随行。归队途中再按 = 突击。
- 归队要先集合（10-21 用户看录屏后定）：全员快速回到队长身边后站定约 0.4 秒（`command/gather`），像集合完毕，再回随行；不要冲回来就接着走。
- 突击：队友自己找怪打，不回队长身边；离队长最远约 1.5 屏（实现取 1.5 个半屏宽 = 960 世界像素，见 §3），超出就往回收。
- 医疗、辅助默认不突击：干员 json `command.roam: false`（安洁莉娜、凯尔希、流明、浊心斯卡蒂、铃兰已写），个别干员可改 json 破例。
- 屏幕外的队友在屏幕边缘画方向标记。
- 突击耐力（10-21 用户定，不做队友血条）：全队共用一条，显示在指挥键旁。突击时按时间消耗，满耐力约 15 秒（10-21 看视频后改 25 秒）；**耗尽自动归队**（走集合停顿那套）并进冷却，回到约 30% 才能再突击；不突击时慢慢回满，空到满约 30 秒（同比例改 50 秒；回得比扣得慢，防反复刷）。只按时间扣——「被怪碰到额外扣」用户否了（玩家控制不了 AI 队友）。耐力不足时按键不切，队长头顶飘「耐力不足」。
- 设计理由：玩家是博士，指挥是核心身份；操作必须极轻（注意力在走位上，网页和手机也要能用）。

## 2. 操作

| 输入 | 键位 | 说明 |
|---|---|---|
| 键盘 | **F** | Tab / C 已是属性面板，Q / E / J 技能，Space / Shift / K 冲刺，V 倍速；F 在局内空闲（只在商店里是刷新） |
| 手柄 | **LB**（LT 同） | 局内上下文原来没用左肩键；RB = 冲刺 |
| 触屏 | 「指挥」键 | 暂停键左侧同一行（桌面 `(vs.x-118, 186)`，手机 `y=160`）；离冲刺 / 技能 / 攻击键与编队区都远，不挡摇杆；可在「设置 → 触屏按键布局」里挪 / 缩放（键名 `cmd`） |

HUD：非触屏时编队区（源石锭框）上方右对齐一行「指挥 · 随行」+ 按键牌（手柄显示 LB），颜色随模式：随行青、突击金、归队绿。触屏时模式名写在「指挥」键圈里。屏外队友：屏幕边缘一个小头像（10-21 用户定）——用编队卡同一份待机帧条（`o.portrait()`，图鉴 / 选人也是这份），按第 0 帧最上面的不透明像素裁出约 26 美术像素见方的头部（`hud_banners._head_src`，每人扫一次缓存），画成 30 像素；外圈 = 职业色（`Character.CLASS_COL`，同图鉴 / 选人），外侧细线 = 当前模式色，箭头职业色指向队友；贴在避开顶栏 / 底部提示的框边上，压在 HUD 之上。缺贴图时退回职业首字。

## 3. 实现

- 状态：`squad.stance`（0 随行 / 1 突击 / 2 归队），`squad.cycle_stance()` / `set_stance()`；切换记进 `squad.stance_log`，`--trace` 时打印 `CMD t=… stance=…`（不进 TRACE 行）。
- 站位：`character.follow()` 里，突击时用 `roam_target()` 代替 `follow_target()`（编队位 / 近战前压）：以干员自己为中心 `command/search` 内最近的敌人（离队长 ≤ `command/leash`），站到它朝自己一侧 `cmd_reach()` 处；有滞回（目标死 / 出圈才换，近 50 以上才换更近的）；没怪回编队位；落点夹在 leash 圈里。`cmd_reach()`：近战取 `blocks.follow.gap`，普攻带 range 的远程取 range × `command/range_k`。
- 速度：随行原样（lerp，不限速，> 700 瞬移归位）；突击限速 队长移速 × `command/roam_speed`；归队 lerp 加快 + 限速 × `command/recall_speed`，全员离随行站位 < `command/recall_done` 或满 `command/recall_max` 秒后进入集合：全员原地站定 `command/gather` 秒（`squad.gather_t`），再自动回随行。突击 / 归队时瞬移阈值放宽到 leash × 1.6。
- 耐力：`squad.stamina`（0–1）/ `squad.exhausted`，`squad._tick_stamina()` 每帧：突击扣 dt / `stamina_secs`，到 0 → `exhausted` + `set_stance(归队)`；其余回 dt / `regen_secs`，回到 `min_start` 解除冷却。`cycle_stance()` 发起突击前查 `can_roam()`。HUD：桌面在「指挥 · 随行」下方一条 180×7 的条（10-21 由 120×4 加宽）（突击金、冷却灰、其余青，白刻度 = `min_start`）；触屏在指挥键外圈一道弧。
- 找怪只经 op_api `nearest_enemies`，不抽随机数。
- 开关：`data/balance.json` 的 `command.on`（缺省 1）；0 = 不画按钮 / 标签，按键无效（对照用 `--bal=command/on=0`）。
- 机器人：缺省随行（`command/bot_roam` = 0）；`--bal=command/bot_roam=1` 突击常开：开局突击，耐力耗尽归队后一回到 `min_start` 就再突击（首段 15 秒，之后约 4.5 秒突击 / 9 秒回复循环）。测试钩子 `--cmdat=秒,秒,…` 到点按一次指挥键（录片用）。

| 旋钮 command/… | 缺省 | 含义 |
|---|---|---|
| on | 1 | 总开关 |
| leash | 960 | 突击离队长最远（世界像素） |
| search | 520 | 找怪半径（以干员为中心） |
| roam_speed | 1.3 | 突击限速（× 队长移速 150） |
| recall_speed | 4.0 | 归队限速 |
| recall_done | 28 | 归队归位判定距离 |
| recall_max | 3.0 | 归队最长秒数 |
| gather | 0.4 | 归队到位后站定秒数 |
| stamina_secs | 25 | 突击耐力满 → 空秒数 |
| regen_secs | 50 | 不突击时空 → 满秒数 |
| min_start | 0.3 | 低于它不能发起突击（耗尽后的冷却线） |
| range_k | 0.6 | 远程站位 = 射程 × 它 |
| bot_roam | 0 | 机器人局突击常开（受耐力限制） |

## 4. 已知局限（原型）

- 一部分干员的普攻 / 技能以**队长**为中心或只打队长身边的怪（斯卡蒂大剑「在队长身边横扫」、浊心斯卡蒂声浪、推进之王「冲到队长身边的敌人面前」、塞雷娅阻挡圈等），突击后这部分输出不跟着走——第 2 步要逐个定「突击时以谁为中心」。
- 敌人只追队长，突击的队友不吸引仇恨；队长身边少了近战，承伤会变（见 §6 数据）。

## 5. 命名

10-21 用户定：随行 → **随行**、突击 → **突击**、归队 → **归队**（代码标识符仍是 GUARD / ROAM / RECALL、stance 0 / 1 / 2）。
按键 / 标签名用户未定，先保留「指挥」；候选：指挥、战术、号令。
（按 docs/76 §2：「部署、撤离」是原作词，但原作指放上 / 撤下场，不借用。）

## 6. 观感与数据

### 6.1 对比视频

`tools/command_rec.py --start 55 --secs 48 --cmdat 62,85,90,98` 录：机器人（expert）队长持续走位，水月 + 推进之王 + 维什戴尔，seed 3，30 fps、1280×720。时间线：55–62 秒随行 → 62 秒按键突击 → **77 秒耐力耗尽自动归队**（跑回 + 0.4 秒集合，79.2 秒回随行）→ 85 秒按键被拒（耐力 27% < 30%，飘「耐力不足」）→ 90 秒按键突击 → 96.6 秒再次耗尽自动归队 → 98 秒按键被拒 → 随行到 103 秒。突击段可看到屏外头像标记，编队区上方耐力条随时间减少。
输出：`E:/ArknightsSurvivors/build/command_rec/command_mode.mp4`（10-21 第三版：耐力 + 归队集合 + 屏外头像；不进 git，帧在同目录 `command_mode_frames/`）。触屏截图（1560×720，`--touch`）：`build/command_rec/touch/`。

第一版观感（用户看过）：突击后推进之王、维什戴尔各自追最近的怪，常跑到屏外；归队是一股脑冲回、没有集合停顿；屏外标记只有职业字，认人难 → 第二版加集合站定、改头像。

### 6.2 机器人小样（耐力 15 / 30 秒时测；改 25 / 50 秒后未重跑）：突击常开（受耐力限制）vs 随行

`balance_run.py --preset squads --seeds 3`（normal 机器人、标准档、6 编队 × 3 seed），突击常开 = `--extra=--bal=command/bot_roam=1`（耐力够就突击，耗尽归队、回到 30% 再突击；实际约首段 15 秒、之后 4.5 秒突击 / 9 秒回复循环，突击时间占比约三成）。基于 main 52e989f9。随行列 / 突击列；输出 / 秒 = 全队总输出 ÷ 存活秒；承伤 / 分 = 队长受到的伤害。

读法（每组只有 3 局，胜率差 < 10 点不下结论）：
- 加耐力后总体 **输出 +8%、队长承伤 +22%、存活 +21 秒、胜 3/18 vs 1/18**。无耐力的首版（突击一直开）是输出 +14%、承伤 +23%：耐力把输出收益压了约一半，承伤没怎么降——突击时近战离队，队长身边空了，回来后承伤才恢复。
- 水月 + 凯尔希 + 推进之王这组随行这次 1 胜、输出高（同 seed 下随行局本身跑得好），差值主要是单局波动；纯远程（维什戴尔 + 艾雅法拉 + 铃兰）仍是突击更差。
- 机器人是「一能突击就突击」，不挑时机；玩家会挑怪多时开、危险时归队，实际收益应好于这组数。要定数值请用同种子配对 + 更多 seed（云端例行任务）。
