# 25 · 编队干员特效设计（Claude，2026-09-25）

> 分工（AGENTS.md）：人物形象归 Codex，攻击 / 命中 / 技能特效归 Claude。本文是首批 7 名干员 + Mon3tr 的特效设计与实现记录。
> 原则：**每个干员的特效取自她在《明日方舟》里的技能表现**（配色、形状、节奏），再按本作像素风与"3–4 人同屏可读"的要求收敛；所有特效程序绘制，不占 Codex 的帧条。
>
> 2026-10-14 制作人定：「所有特效程序绘制，不占 Codex 的帧条」已过时，以 docs/06（10-11 更新）与 docs/98 §6 为准：重点技能特效可由 Claude 写特效单派给 Codex 重绘（`_back` / `_front` / `_orbit` 分层），Codex 版优先于同名程序版，程序版作为没有 Codex 版时的缺省；其余 fx_* / proj_* / 图标仍归 Claude。

## 0. 实现方式

- 每个干员脚本持有自己的粒子表 `pfx`（`character.gd` 的 `fx()` / `fx_sparks()`），`squad.gd` 每帧 `_tick_pfx()`，地面层在 `draw_entities_floor` 后、身上层在 `_draw_skill_over` 后绘制。
- 通用粒子 kind：`ring`（扩散环）、`spark`、`glow`、`shard`、`line`、`flame`、`mote`、`crack`（地裂）。干员专属 kind 在各自 `_draw_pfx()` 里画（表中标 ★）。
- 近战命中走 `melee_hit()` → `_hit_fx(e, origin)` 钩子；子弹可带 `src`（伤害来源）、`fx_col`（爆炸 / 拖尾颜色）、`hidden`（不画默认弹体，干员自己画）。
- 干员主色：`character.gd CLASS_COL` 按职业给默认，JSON `"col": [r, g, b]` 可覆盖；HUD 环、卡面、默认粒子都用它。

## 2. 收敛规则

- 同屏最多 4 名干员：地面层特效（光域、阻挡圈、熔岩）用低 alpha（≤ 0.3）填充 + 细边，避免叠成一片。
- 亮度 > 1 的颜色只用于核心闪光（≤ 0.2 秒），让辉光只抓住"出手瞬间"。
- 每次普攻的粒子数 ≤ 12，技能 ≤ 60；粒子寿命 ≤ 0.6 秒（地面残留物除外：熔岩 3 秒、晶柱 1.5 秒）。
- 命中反馈仍由 `_damage()` 的敌人闪白 / 挤压承担，干员特效只负责"是谁打的、打的是哪种伤害"。

## 5. 可见成长与三档特效（2026-09-26，用户确认）

### 5.1 规则

1. **截图可辨**：同一干员在「精零 N1 N2 后 / 精一 N4 N5 后 / 精二」三个阶段，不看 UI 也能分辨。用 `--compareshot=<id>` 出三联图自查。
2. **成长节点只做看得见的变化**：N1 / N2 让普攻的核心元素变多或变形；N4 / N5 强化一个已有技能（次数、发数、段数、可见的形态）；精一 = 解锁 S2 + 天赋；精二 = 解锁 S3 + **普攻质变**。持续时间、充能这类看不见的改动不单独占节点。
   **选下当场就要看得到**（2026-09-26 用户反馈后补）：节点只能强化此时已解锁的技能（N4 / N5 只能强化 S1 / S2，S3 精二才有）。想让它连带强化 S3，写成「……；精二后「S3」同样如此」。精英化解锁的技能立即充满，选下就放。`tests/test_core.gd` 检查说明里有没有引用未解锁的技能，`python tools/check.py` 检查每个节点选下当场有没有变化。
3. **不重复**：N1 / N2 与精二质变不得复刻任何技能或天赋；N4 / N5 不加新机制。
4. **不 OOC**：每条变化都要有原作依据（docs/31：技能、天赋、档案）。
5. **不放大、不震屏**：主控只多一圈脚下标记；爽感来自元素变多、变形。
6. **数值守恒**：数量变多就下调单发，整体输出按 docs/27 预算。
7. **上限**：每名干员同时存在的弹体 / 召唤物 ≤ 12，地面残留 ≤ 6。
8. **第三方素材可以用在正式特效里**（用户确认），按 art/third_party/README 的许可署名。

> 2026-10-14 制作人定：第 2 条「精一 = 解锁 S2 + 天赋」已过时，以 docs/91 §0.5、§22 第 1 条为准：精一另给一项普攻机制（写进精英一节点，加了普攻机制后不再另给攻击）；精二质变按 docs/91 逐人表，替换 §5.2 表里「精二质变」一列，不叠加。普通节点统一攻击 +6% 仍有效（`character.gd NODE_ATK`）。

选色依据：
- **不碰敌方色**：洋红是敌方危险主色（`world.ENEMY_TELL #ff4db8`、`ui.RED #ff3d8b`、敌弹外圈的亮洋红描边、精英登场），紫是新星弹 / 囊海爬行者 / 束缚，暗橄榄是酸团，浅黄是神经弹；绿是治疗（医疗无人机、伊莎玛拉治疗）。所以 S3 没用最初设想的「亮粉 / 洋红」，改成**过热白**（整条弹体发白、只在尾巴留能天使的深红），读作「枪管过载」，也最亮。
- **色盲也分得开**：普攻红与 S1 冰青落在蓝–黄轴两侧（红绿色盲照样分得清）；红 → 琥珀橙 → 过热白 明度依次 0.49 → 0.62 → 0.78 拉开；倾泻的金与普攻红明度接近，但倾泻是 8 发扇形 + 大号弹体 + 金色枪口，形状与节奏就分得开。
- **暗海床上看得清**：海床底色约 `#17262a`，各模式都有白芯弹头，主色明度都远高于底色；冰青比拾取的经验结晶（静止、偏青绿）更亮、而且在飞。
- **倾泻**：沿用原来的金色强力弹 + 金枪口焰（和「弹匣满」时枪口的金光、状态条「弹匣 n/上限」同色），只补了金色命中火花；不复用普攻红，免得倾泻混在普攻里。
- S1 与 S2 / S3 同时生效时，S1 的余弹逐发换成冰青（补丁逐发合并，枪口焰跟第一发）；S2 与 S3 重叠时后一个技能的颜色生效。跳弹继承母弹的弹体与命中火花。
