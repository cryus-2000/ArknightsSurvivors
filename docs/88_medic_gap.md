# 88 有医疗 / 无医疗编队的差距：诊断与方案（2026-10-13）

协调人 10-13 派单：入队回复台阶（`squad/regen_per_member` 0.9，docs/83）之后，带医疗的固定队仍明显更稳。本文先拆「医疗队到底靠哪几项活下来」，再给 3 个改法，数值交协调人定。
口径照 docs/80（区间、配对、胜率 + 低血秒 + Boss 用时）。本轮**不改平衡数值、不改玩法逻辑**，只加了遥测和测试旋钮（§5）。

> **2026-10-14 已定档（28e28118，10-13，云端 mgc）**：§6 方案 A 与方案 B 的几项已进数据，现值以数据为准——灯火暗淡 `lamp/dark_taken` 1.15 → **1.05**、`lamp/dark_enemy` 1.2 → **1.1**（`enemy/spawn_dark_mult` 仍 1.15）；受击灯火 `lamp/hit_base` 3 → **2**；凯尔希庇护 `guard_red` 0.2 → **0.1**（`shell_red` 仍 0.35）；流明沐雨 `s1_heal` 5.1% → **3.5%**、`s1_lamp` 8 → **4**，灯塔 `s3_lamp` 2 → **1**（`talent_lamp` 仍 2）。§0、§4、§5 的测量和 §4 / §6 里写成「现状」的 ×1.15 / ×1.2、hit_base 3、庇护 20%、沐雨 5.1% / +8 都是定档前的旧值；方案 C 没有做。

## 0. 结论先说

1. **医疗队并没有少挨打**。同一时段承伤每秒 % 最大生命：流明队最高（标准 6–9 分 2.15，艾雅法拉队 1.92，斯卡蒂队 1.28），凯尔希队 1.46。差别全在「挨打那一阵回得上来」和「灯火」。
2. **致死的是 30 秒的压力窗**（30 秒内承伤 ≥ 90% 最大生命）。四组每局都会遇到 1–3 个，窗内承伤相同（120–160%），但窗内治疗：无医疗 90–98（自身 46–58 + 浊心斯卡蒂 23–32），医疗 116–140（医疗干员 56–72）。
   每个压力窗的致死率：无医疗 12–45%，医疗 0–11%；活下来的窗后生命中位：无医疗 48–72%，医疗 84–99%。
3. **流明的最大隐性贡献是灯火**。Ⅷ 6–9 分钟灯火 < 30（「暗淡」）的时间：艾雅法拉队 55–71%、斯卡蒂队 39–44%、凯尔希队 49–50%，**流明队 0–1%**。
   暗淡时敌人接触伤害 ×1.2 × 主控受伤 ×1.15（≈ ×1.38）、敌人移速 ×1.2、刷怪 ×1.15；灯火归零（寂灭）还每秒掉 3 点生命，这部分**不进承伤来源统计**：
   Ⅷ 每局寂灭掉血 艾雅法拉队均 54% 最大生命、斯卡蒂队 29%、凯尔希队 99%，流明队 0。Ⅷ 进压力窗时灯火 < 30 的致死率 22–36%，≥ 30 的 0–11%。
4. **凯尔希的减伤和治疗一样大**。「庇护」（治疗溢出时 20% 减伤 5 秒，满血附近几乎常驻）+「结构加固」护壳（35%，3 秒）在 6 分钟以后每秒挡掉 0.5–0.9% 最大生命，和她的有效治疗（0.6–1.3%）同一量级。
5. **流明的治疗里「沐雨」（S1）占一半，常驻治疗只占 20–25%**；而且所有医疗治疗「给出的量」是「实际回进去的量」的 2–5 倍（满血时大多溢出）。所以 mdm20 砍常驻 20% 不起作用：砍掉的部分本来就被富余容量吸收。
6. 消融（本机 Ⅷ 熟练，seed 1–12，同 seed）：流明队 12/12 → 去掉 S1 治疗 11/12 → 去掉全部治疗 9/12 → 再去掉灯塔 6/12；只去掉流明的三项灯火来源（治疗保留）9/12；凯尔希队 11/12 → 去掉庇护 10/12 → 去掉全部治疗（护壳仍在）7/12；无医疗 斯卡蒂队 4/12、艾雅法拉队 2/12；**无医疗两队去掉暗淡惩罚后 9/12、5/12**（合计 6/24 → 14/24）。
   **各项能互相顶替**：去掉流明的治疗后，浊心斯卡蒂的有效治疗从 0.45 涨到 0.85–0.92%/s。单砍一项治疗很难拉开，要动「容量」或「灯火」这种结构性的东西。
7. 无医疗队的死法在入队台阶之后变了：标准下不再是 docs/82 的「两段式消耗」，而是**单个压力窗**（死前 30–60 秒生命中位 86–96%）；Ⅷ 下是**灯火熄灭 + 压力窗**：艾雅法拉队 22 个输局里 18 个死时灯火 < 30（12 个为 0）。
8. 凯尔希当队长 Ⅷ：云端自然组队 3/8（ssdb）、2/8（ssdc，台阶 0.6），本机 7/12；合计 12/28 = 43%，仍低于 50%，需要云端 32 局复查（§6 ④）。

| 流明队 只去掉灯火来源（`s1_lamp / s3_lamp / talent_lamp = 0`，治疗保留） | 9/12 | 3/49 | 139：医疗 74、自身 39、浊心 18 | 96 |
| 凯尔希队 | 11/12 | 1/29 | 140：医疗 72、自身 46 | 96 |
| 凯尔希队 去掉庇护（`guard_red=0`） | 10/12 | 2/37 | 151（窗内承伤 164） | 84 |
| 凯尔希队 去掉全部治疗（`heal_pct / s1_heal = 0`，护壳仍在） | 7/12 | 3/20 | 90：自身 55、浊心 24 | 44 |
| 无医疗 斯卡蒂队 去掉暗淡惩罚（`lamp/dark_taken=1 dark_enemy=1 spawn_dark_mult=1`） | 9/12 | 3/21（14%） | 94（窗内承伤 144 → 115） | 80 |
| 无医疗 艾雅法拉队 同上 | 5/12 | 7/28（25%） | 104 | 63 |

- 每格 12 局，Wilson 区间约 ±25 点，只作方向。本机无医疗两组 6/24 = 25%、医疗两组 23/24，比云端（39% / 82%）差距更大。
- 去掉流明治疗后浊心斯卡蒂补位（窗内 21 → 41）：**回复来源之间互相顶替**，单砍一项的效果会被其余吸收，这和 mdm20 的结果一致。
- 去掉流明的治疗和灯塔后（6/12）仍比斯卡蒂队（4/12）好，剩下的是灯火（§4）和净化。

## 6. 方案（数值交协调人定；每个都能先用 --bal 在云端扫）

目标：固定队「有医疗 − 无医疗」两档都缩到 15 点以内；自然组队两档 50–70%（现在标准 76.8% 已经超了，Ⅷ 55.4%）；凯尔希 / 流明当队长 Ⅷ ≥ 50%。

### 方案 A：灯火暗淡惩罚减轻 + 受击灯火损失放缓（推荐主修，针对流明的隐性优势）

- 改什么：`lamp/dark_taken` 1.15 → 1.05、`lamp/dark_enemy` 1.2 → 1.1（本分支新加的旋钮，缺省值不变）；`lamp/hit_base` 3 → 2（已有旋钮）。可选：`enemy/spawn_dark_mult` 1.15 → 1.05。
- 依据：Ⅷ 无医疗与凯尔希队 6–9 分有 39–55% 的时间在暗淡，暗淡中接触伤害 ×1.38、移速 ×1.2；暗淡进压力窗致死率 22–36%，不暗淡 0–11%。流明队几乎从不暗淡，所以这项改动**只帮非流明编队**，不需要「检测有没有医疗」的开关。
- 预计：无医疗队 Ⅷ 明显上升（本机把暗淡三项惩罚全关时，无医疗两队 Ⅷ 6/24 → 14/24、+33 点，斯卡蒂队压力窗承伤 144 → 115、致死 30% → 14%；方案 A 只减一半左右，按比例估 +10–20 点）；凯尔希队同样受益（她 Ⅷ 暗淡 50%、寂灭 54 秒），**凯尔希当队长 Ⅷ 也会上来**；流明队不变。标准影响较小（暗淡时间 15–31%）。
- 风险：灯火是「探索资源」的核心表现，暗淡太温和会让灯火系统失去存在感；docs/76 文案里写了暗淡的效果（指南「生命与灯火」），数值改了要同步。整体变易：自然组队标准会再涨，需要配合方案 B 或全局收紧（例如 `enemy/dmg_div`）。

### 方案 B：削医疗的「富余容量」而不是常驻治疗（针对真正起作用的那几项）

- 流明：`opbase/lumen/s1_heal` 0.051 → 0.035（沐雨占她有效治疗一半，给出量是实际的 4–7 倍）；`s1_lamp` 8 → 4、`s3_lamp` 2 → 1（灯火来源减半，配合方案 A 让流明的灯火优势变成「少暗淡」而不是「永不暗淡」）。
- 凯尔希：`opbase/kaltsit/guard_red` 0.2 → 0.1（庇护近乎常驻，去掉它压力窗承伤 +35%）；`shell_red` 0.35 → 0.25。常驻治疗不动（10-12 刚削过一半）。
- 预计：医疗固定队下降、无医疗不变，差距直接缩；自然组队里医疗占六成，**标准自然组队会从 76.8% 往 70% 回落**（这是好事）。但消融显示单项影响很小（流明去掉沐雨治疗 12 → 11/12，凯尔希去掉庇护 11 → 10/12），要缩 25–40 点必须多项同时动，而且 Ⅷ 自然组队（55%）会跌破 50%。
- 对医疗当队长：凯尔希队长 Ⅷ 现在约 43%（§0 第 8 条），再削庇护会更低，**必须和方案 A 一起做**，或只削「当队友」时的数值（需要代码：凯尔希当队长时庇护不变）。流明当队长前期问题 docs/82 §3.3 已处理，沐雨削弱对她当队长影响中等（她自己吃到）。
- 风险：用户要求「医疗仍是好选择」；削到感受不到「有奶妈很稳」就过头。建议幅度不超过上面这组，先云端扫。

### 方案 C：给所有编队一个「挨打时才生效」的回复（把医疗的按需特性给到无医疗队）

- 规则（需要写代码，带旋钮）：队长最近 `sustain/hurt_window` 5 秒内受到的伤害 ≥ `sustain/hurt_th` 15% 最大生命时，入队回复台阶 × `sustain/hurt_mult` 2，持续 5 秒。卡面 / 指南写成「编队应急回复：队长 5 秒内损失 15% 以上生命时，入队带来的生命回复翻倍」。`hurt_mult` 1 = 关。
- 依据：压力窗里无医疗队自身回复 46–58 点 / 30 秒已满额，比医疗队少 31–41 点；满编时入队台阶 1.8 / 秒，翻倍再加 1.8 / 秒 ≈ 最大生命 200 时 +0.9%/s ≈ 每窗 +27 点，能补上大约 70–85% 的缺口。医疗队平时生命 93–99%，压力窗里也很少掉 15%，多出来的回复大多溢出。
- 预计：无医疗队两档上升，医疗队小幅上升（溢出为主），塞雷娅 / 水月开局也会小幅上升。差距缩，但**整体变易**，自然组队标准会更超 70%，需要同时用 `enemy/dmg_div` 等全局旋钮收一点，或和方案 B 合用。
- 风险：新机制；和 docs/83 刚定的「入队台阶」叠在一起，玩家理解成本略高；对「残血拉扯」打法有正反馈，需要看低血秒有没有异常变长。

### 推荐组合

先做 **A（灯火）+ B 的凯尔希庇护那一项**：A 直接打掉 Ⅷ 无医疗与凯尔希队的头号死因，同时把凯尔希当队长拉上来；B 的庇护减半抵掉凯尔希当队友时 A 给的那部分好处。流明的数值留到 A 落地后看差距再定。
C 作为备选：如果 A 落地后标准档差距仍 > 15 点（标准暗淡时间少，A 帮得有限），再加 C。
