# 161 紧急作战改「精英小队」

> 2026-10-26，协调人转用户：「两只精英会不会太简单了？奖励也不够，设置成一下子多一些高阶普通怪，然后身上可以带一些红光之类的标识」。分支 `claude/elite-squad`。

## 1. 改了什么

| | 改前 | 改后 |
|---|---|---|
| 来的敌人 | 2 只精英（精英池随机） | 一支小队：按阶段 8 / 10 / 12 只高一阶的普通怪 |
| 阶段怪池 | — | 4:40 前：凿石者 / 喷吐者 / 飘航者 / 引痕者；4:40–8:40：引痕者 / 收割者 / 奠基者 / 巢涌者 / 喷吐者；之后：引痕者 / 收割者 / 奠基者 / 巢涌者 / 子代 |
| 强度 | 精英原数值 | 生命 ×2、伤害 ×1.3（在普通刷怪的密度换算之上）；全队共用一个词缀：甲壳（受到伤害 ×0.75）或潮盾（30% 最大生命的护盾） |
| 出场 | 画面边缘各自随机 | 同一侧扇形（±25°）一起出现；入场冲锋 ×2.2（离队长 180 外，进圈恢复原速），奠基者 / 巢涌者不冲要走二十多秒 |
| 标识 | 头顶 ▼ | 红色描边（复用精英描边那条路径，危险红）+ 脚下红色底光（地面层两层椭圆，不闪），手机上也看得清 |
| 同屏上限 | — | 计入同屏上限（手机自动档第 2 级 65）；放不下的成员推迟，有空位再从原出生方向刷出 |
| 全灭奖励 | 1 个宝箱 + 10 源石锭 | 1 个宝箱（这次藏品三选一按稀有 / 核心加权，同「得偿所愿」）+ 20 源石锭 |
| 文案 | 「精英小队来袭！全部击败可获得额外宝箱」 | 横幅「紧急作战：精英小队来袭 · 潮盾 —— 全部击败获得宝箱与源石锭」；全灭「精英小队已全灭 —— 拾取宝箱」；节点卡「一支精英小队从边缘压上来。全部击败，得宝箱与源石锭。」 |

数值都在 `waves.json` 的 `cross_deck`：`squad_t`、`squad_n`、`squad_pool`、`squad_hp`、`squad_dmg`、`squad_rush`、`squad_ingots`。词缀沿用后期词条（`enemy/affix_armor`、`affix_shield`）。

画法缓存：小队标记 `e.squad` 在刷出时写定、之后不变，描边开关在缓存计算时读到，不用改签名。脚下红光只遍历紧急作战名单（最多十几只），不逐只发粒子。

## 3. 手机帧时（iPhone 仿真）

`tools/perf_web.py run --mobile --dpr 3`（844×390 横屏、3 倍像素、触屏），中档画质，`--mobilecap`，seed 13 浊心斯卡蒂单人开局，快进到 4:52 后按真实步长；两局同 seed，一局 5:00 刷小队，一局不刷（`build/_perfweb/a6a1ef9b9/out_squad2.txt` / `out_nosquad2.txt`）。

| 时段 | 刷小队 P50 / P95 / 最大 | 对照 P50 / P95 / 最大 |
|---|---|---|
| 刷出前 4:54–5:00 | 28.2 / 37.9 / 56.4 ms | 28.3 / 38.5 / 57.1 ms |
| 刷出那 2 秒 | 27.9 / 41.3 / 53.8 ms | 28.7 / 37.1 / 54.4 ms |
| 小队压上来 5:02–5:12 | 30.5 / 47.7 / 64.6 ms | 28.1 / 38.1 / 89.8 ms |
| 5:12–5:22 | 33.8 / 43.5 / 87.5 ms | 29.8 / 39.7 / 69.9 ms |

刷出那一刻没有尖峰（刷新本身不贵）；小队压上来后中位多 2–4 ms、P95 多 5–10 ms，来自十只重型怪的招式、预警和命中特效。仍在手机 30 帧档（33 ms）附近。

## 4. 测试

- `enemy_attack_variety_test`：中段 10 只、来自中段怪池、全队同一词缀、生命 × squad_hp；同屏上限 4 时先放 4 只、推迟 6 只，有空位后补齐；全灭后掉 1 个宝箱、稀有加权打开、源石锭 +20。
- `--only enemy_attack_variety / core / prot` 通过。
- 没做云端胜率复测：紧急作战只在首通结局一后的节点卡里出现，机器人批跑基本走不到；需要时用 `--squadat` 单独测。
