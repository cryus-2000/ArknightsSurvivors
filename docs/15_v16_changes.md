## 1. 伤害类型

每个伤害来源都带两维标签：**距离**（近战 / 远程）× **类型**（物理 / 法术 / 真实）。表在 `game.gd DMG_TYPE`：

| 来源 | 距离 | 类型 |
|---|---|---|
| 伞击、囚徒困境双斩、镜像 | 近战 | 物理 |
| 唤醒·创伤扩散冲击 | 近战 | 法术 |
| 触手追击、触手桩、触须阵、巨触 | 近战 | 法术 |
| 水刃 | 远程 | 物理 |
| 潮汐弹 | 远程 | 法术 |
| 无人机子弹 / 导弹 | 远程 | 物理 |
| 无人机激光 | 远程 | 法术 |
| 狙击援护（含流血） | 远程 | 物理 |
| 术师 / 辅助援护 | 远程 | 法术 |
| 藏品持续伤害 | 远程 | 法术 |
| 地雷 | 远程 | 物理 |
| 处决、扣挠之手（当前生命 %） | — | 真实 |

规则：真实伤害不吃任何倍率、防御、灯火加成；物理 / 法术各有独立倍率（`melee_mult / ranged_mult / phys_mult / arts_mult`）。

**受到伤害**同样分型：接触、冲撞、横扫、突刺、跳砸、震荡 = 近战物理；海嗣弹幕、酸液、水柱、光束、泡影 = 远程法术；凿石者碎石、圣徒枪击 = 远程物理；溟痕 / 黑潮 / 侵蚀 / 神经损伤 = 真实。
- 硬化 / 护甲只减**物理**；新属性 **法术抗性**（`arts_res`，上限 70%）只减法术；真实无视两者。
- 闪避分 **物理闪避 / 法术闪避** 两项加成（在基础闪避之上，总上限 60%）。
- Tab 面板显示：物理减伤 / 法抗、闪避 物 / 法、近战 / 远程倍率、物理 / 法术倍率。

## 4. 藏品等级

- 纯属性型藏品（effects 全是 `stat`，且非升华 / 遭诅）可叠到 **3 级**，每级效果 100% / 70% / 50%。
- 已拥有的可升级藏品仍会出现在三选一与商店（权重减半），卡名显示「Lv.1 → 2」；藏品栏图标下方画等级点。
- 触发 / 规则 / 一次性类只有 1 级。

## 5. 其他

- 水刃默认**不穿透**：命中第一个敌人后碎裂（伤害基数 0.62 → 0.8）；新路线卡「潮刃·贯」：穿透 2 名 / Lv.2 无限穿透。深渊巨斩始终穿透。
- 巨触吞噬改为**横扫**：破土 0.45s → 绕中心扫一整圈（1.65s，半径 185）→ 沉回；扫到的敌人受重击、晕眩 0.9s、被甩开。伤害基数 40+2.5L → 28+1.8L。
- 商店每次商人**只能刷新一次**；提示文字随之变化。
- 开局指南每局都播（Esc 跳过，暂停菜单 G 可重看）；技能解锁 / 精英化演出改为**每局**首次完整播放（之前是每台机器只播一次，导致看不到）。
- `--nodeath`（配合 `--balance`）：bot 不死，用于跑完 10 分钟查后期报错；自测 bot 现在会躲预警、溟痕和弹幕。

## 7. 弱点制（v1.6.1 追加）

敌人**没有防御与法抗**，任何伤害 100% 生效；一部分敌人带弱点标签，对应类型伤害 **+50%**（金色大字"弱点"），打错类型不吃亏。

| 弱点 | 敌人 |
|---|---|
| 法术弱点 | 沉海撕裂者、巨骸漂流体、囊海爬行者、塑路者、接潮蔑死体、固海凿石者（架起期间） |
| 物理弱点 | 潜海裂魔、溟海喷吐者、掠海漂移体、投嗣育母、接潮主教、接潮斥亡体、偏执泡影（二阶段） |
| 无 | 骨海漂流体、底海滑动者、注亡拟嗣、子代、圣徒二人、偏执泡影一阶段 |

敌人头上画一个小菱形（金 = 物理弱点，紫 = 法术弱点），精英与 Boss 额外标字。藏品：45 残破合影 → 弱点伤害额外 +25%；47 迷迭香之拥（升华）→ 所有敌人视为带弱点。

配合弱点，敌人数值上调：带标签的普通怪生命 +30% 左右，Boss 生命 +15–25%，全局生命曲线 8 分钟内 ×5.0（原 ×4.4）。威胁等级新增修正：Ⅲ 起直接刷进化体（3% → Ⅵ 22%），Ⅳ 起敌速 +3% → +12%，大群间隔 120s → 80s。潜海裂魔潜行时不再减伤。
