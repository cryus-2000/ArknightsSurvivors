# 282 · 羁绊不只是数值：盘点与玩法差异方案（设计稿，11-06）

状态：**被 docs/294 取代**（用户 11-06 嫌不够有趣、割草里看不清，改 HoloCure 式羁绊技）。以下为原稿。

状态：**设计稿，待用户审，不改代码**。来源：用户 11-06「希望羁绊之类的不只是数值上的区别」。基线 main 319b5de4b。
约束：设计支柱（memory design-pillars）——小队代入感是本作特色；构筑要和割草爽感走同一条线；弹幕紧张留给最终 Boss。

## 0. 结论摘要

1. 现在的羁绊 = **一条被动数值加成 + 一个专属合击**。被动加成 8 条全是「一个属性 ±6–15%」，量级「约一张普通升级卡」（`link_bond.gd` 的 `BUFF` 表）。合击虽然是专属动画，但触发条件只有一种：队长放技能 + 全队 60 秒冷却，一局最多亮约 10 次（60 秒一次，10 分钟）。玩家平时感受到的羁绊就是左下角一个数字和一次偶发的演出。
2. 用户说得对：**羁绊在大部分时间里等于一个小数值**。建议把「常驻数值」换成「常驻行为规则」（两人同在编队时，他们的普攻 / 技能多了一条互相作用的规则），合击保留为高光。
3. 每种羁绊下面给 2–3 个方案，A 方案是我的推荐。全部方案都**只用游戏里已有的积木**（标记、拉拽、冲刺、掉落物、形状判定），不新增系统。
4. 推荐落地顺序：先做 3 条**目标明确、画面最易读**的（急件箱、交叉斩、灯下宣判），用一轮 A/B 看割草手感；其余 5 条按结果再排。
5. 所有行为改动会改变 TRACE，要走 docs/80 的配对 A/B（胜率差 < 10 点不下结论）。纯画面部分另算。

## 1. 现状盘点

### 1.1 羁绊（`run/link_bond.gd`，`skill_link.BONDS`，开关 `link/bond`）

| # | 羁绊 | 成员 | 常驻数值（`BUFF`） | 专属合击 | 玩法上的区别 |
|---|---|---|---|---|---|

| b2 | 宿敌 | 德克萨斯 × 拉普兰德 | 对精英伤害 +10% | 旧怨交锋（交叉剑气 + 沉默） | 无 |
| b3 | 潮下授课 | 乌尔比安 × 斯卡蒂 | 全队技力回复 +8% | 锚钉 + 重砸 | 无 |
| b4 | 引潮夺命 | 歌蕾蒂娅 × 归溟幽灵鲨 | 控制持续 +15% | 拖拽 + 横斩 | 无 |
| b5 | 漩涡钉锚 | 歌蕾蒂娅 × 乌尔比安 | 敌人移速 −5% | 漩涡 + 砸锚 | 无 |
| b6 | 双鳍 | 斯卡蒂 × 归溟幽灵鲨 | 移动速度 +6% | 双冲交错 + 水痕 | 无 |

触发：队长放技能 → v2 连携（`link/v2_gap` 60 秒）→ 有羁绊的队友优先接。「羁绊成立」只在编队变化时闪一次横幅，之后只在属性面板和作战记录里出现。

### 1.2 与羁绊并列的数值型编队系统

| 系统 | 做什么 | 是否数值 |
|---|---|---|
| 入队人数台阶（docs/83） | 编队每多一人，最大生命 / 回复上台阶 | 纯数值 |
| 协同卡（升级卡类别「协同」） | 队友相关的小加成 | 多数数值 |
| 连携 v2（docs/209） | 队长放技能 → 一名队友进场出招，60 秒一次 | 有动作，触发稀疏 |
| 连携技 `synergy`（docs/160） | 5 对 + 1 群，12–14 秒冷却的小合击，已有「冲刺 / 连射 / 拖拽」动作 | 有动作，已是玩法差异（本稿不动） |
| 终结技 / 连携终结技（docs/199） | 队长 Q；队友连携终结技 | 画面强，次数少 |

→ 羁绊（b1–b8）是其中**数值味最重、又最“专属”**的一档，最值得改。

## 2. 设计原则（本稿自己定的，供审）

1. **规则优先于数值**：每条羁绊的常驻效果写成一句「当 X 时，Y 会 Z」，而不是「+N%」。
2. **看得见**：规则生效时有一个小而固定的画面语言（两人色的细线 / 标记 / 地面符号），不靠文字提示（用户 10-26 定过「不弹提示」类的口径，羁绊的编队轻提示已有，见 docs/217 §4）。
3. **不改割草节奏**：不增加操作、不要求玩家盯着看；规则只让「站位 / 选目标 / 技能顺序」更有意义。
4. **互为镜像**：两人羁绊对称，谁当队长都成立（沿用 docs/217 的做法）。
5. **保留小数值**：被动加成不必全删。建议改成「规则 + 很小的数值（≈原来的一半）」，或只在规则**不可能触发**的情景下兜底。是否保留由用户定（§4 问题 1）。
6. **成本**：只挂在已有钩子上——`link_bond.refresh`（编队变化）、`ob_core.exec_shape` 命中事件、`Character.syn_mv`、敌人标记表；不新增每帧全表扫描。

## 3. 逐条方案

每条：**A（推荐）/ B / C**；括号里写“行为 · 触发 · 画面”。

### b1 企鹅物流（德克萨斯 × 能天使）

- **A「急件箱」**：德克萨斯击杀精英或重甲怪时，原地落下一只“急件箱”（像素小木箱，企鹅物流的橙黄角标，最多 1 只在场）。队内任何人踩到：能天使立刻换满弹匣并下一轮子弹变金弹（穿透），德克萨斯下一次冲刺无冷却。行为：多了一个**拾取目标**和**站位选择**；触发：击杀；画面：地面箱子 + 箱盖弹开的 4 帧。
- **B「代装」**：能天使的子弹命中被德克萨斯剑气标记的敌人时，子弹弹射 1 次到最近敌人。行为：弹道；触发：命中；画面：金色折线弹道。
- **C「同班」**：两人距离 < 160 像素时，互相共享“站桩”收益（德克萨斯每次近战命中让能天使下一发必暴击）。行为：站位；画面：两人之间一根细橙线。

### b2 宿敌（德克萨斯 × 拉普兰德）

- **A「交叉标记」**：同一敌人被两人都命中后（2 秒内），头顶出现红黑交叉标记；0.8 秒后该敌人位置落一道十字斩。行为：**配合命中产生延迟爆发**；触发：命中；画面：交叉标记 + 十字斩。
- **B「抢怪」**：另一人的自动索敌优先选“队长正在打的目标”（原本各打各的）；表现为两人同时扑向一个敌人。行为：目标选择；画面：两道冲刺轨迹交汇。
- **C「较劲」**：每 10 秒，击杀数落后的一方获得一次“追赶”：下一次冲刺 / 技能范围 +25%。行为：竞争；画面：落后一方脚下的红色小箭头。（数值感最强，不推荐）

### b3 潮下授课（乌尔比安 × 斯卡蒂）

- **A「钉后处决」**：被乌尔比安的锚钉住的敌人，对斯卡蒂的伤害承受变成“处决线”——生命 < 25% 的非精英直接被斩（Boss 与精英改为破绽）。行为：处决阈值；画面：被钉敌人脚下一圈蓝色刻度，斩杀时水刃十字。
- **B「引线」**：斯卡蒂的水刃穿过乌尔比安的锚链线时，分裂成两道。行为：弹道；画面：锚链线被水刃“点亮”。

### b4 引潮夺命（歌蕾蒂娅 × 归溟幽灵鲨）

- **A「潮线」**：幽灵鲨每次击杀小怪，在地面留一小段水痕；歌蕾蒂娅的钩索拉人时，沿水痕拉得更远（射程 +40%）并拖行经过水痕的敌人。行为：**地面状态 + 技能射程**；画面：水痕像素带（沿用双鳍水痕）。
- **B「回收」**：被歌蕾蒂娅拖拽后的敌人，幽灵鲨的下一次斩击自动转向它。行为：目标选择。

### b5 漩涡钉锚（歌蕾蒂娅 × 乌尔比安）

- **A「聚团落锚」**：歌蕾蒂娅的漩涡 / 歌域把敌人聚成团后，乌尔比安的下一次砸地自动瞄准团中心（原本瞄最近）。行为：目标选择；画面：团中心一个短暂的锚形准星。
- **B「水龙卷」**：锚砸进漩涡眼时，漩涡持续 2 秒并跟着队长移动。行为：状态区域跟随。

### b6 双鳍（斯卡蒂 × 归溟幽灵鲨）

- **A「并游」**：队长冲刺时，另一人同步冲刺（沿平行线），两人各留一道水痕，水痕交点爆开一个小十字。行为：**操作联动**（冲刺是玩家已有操作）；画面：两条水痕 + 交点。
- **B「回流」**：两人冲刺轨迹相交时，交点留一块 2 秒“回流区”，区内友方移速 +20%。（有数值，但绑在位置上）

### b7 灯下审决（艾丽妮 × 流明）

- **A「宣判」**：被流明光弹照亮的敌人，艾丽妮对其的第一次攻击变成“宣判”：附带崩解——死亡时炸成自身颜色的像素波，波及周围小怪（延续终结技“崩解”语言，docs/275）。行为：**击杀连锁**；画面：被照亮敌人头顶小圆光，死时像素波。
- **B「光道」**：艾丽妮的刺击路径留下光道 3 秒，流明的弹在光道内穿透 +1。行为：弹道。

### b8 群猎（深海猎人 ≥ 3）

- **A「猎物」**：队内猎人共享一个“猎物”：每 6 秒从场上精英 / Boss 里选一个标记（头顶深蓝准星），所有猎人对其攻击优先；猎物死亡时给每名猎人一次“狩猎”层数（下一次技能附带冲刺）。行为：目标优先 + 击杀奖励；画面：准星 + 层数小点。
- **B「猎场」**：浊心斯卡蒂的歌声区变成“猎场”，区内猎人的普攻附带水刃。行为：区域规则。

## 4. 推荐与排序

| 优先 | 条目 | 理由 | 成本 | 风险 |
|---|---|---|---|---|
| 1 | b2-A 交叉标记 | 两人**都**要打到同一个敌人，才有额外爆发；有延迟，画面一眼懂 | 中（标记表 + 一个延迟判定） | 低：爆发可被现有“按目标生命预算”的 `_dmg` 封顶 |
| 2 | b1-A 急件箱 | 直接复用拾取物体系（磁铁 / 补给箱），玩家有“去踩”的动机，割草时顺手 | 中（新掉落类 + 贴图） | 中：拾取物上限 / 磁铁式掉落已有规则可抄 |
| 3 | b7-A 宣判 | 把终结技崩解语言带进平时，割草爽感直接加分 | 中高（连锁判定要封顶） | 中：连锁 + 精英 / Boss 要写例外 |
| 4 | b6-A 并游 | 绑玩家已有的冲刺操作，最有“小队代入感” | 中（`syn_mv` 已有位移推队友） | 低 |
| 5 | b3-A、b4-A、b5-A、b8-A | 好但依赖更多状态；等前四条的 A/B 结果 | 中高 | 中 |

**不推荐**：b2-C「较劲」、b6-B「回流」（都又回到了数值）。

## 5. 要用户定的问题

1. 常驻数值：**全删**（只留规则）、**减半保留**，还是**只对做不了规则的羁绊保留**？我的倾向：减半保留，规则做出来的那几条再逐步删。
2. 规则触发是否要有**文字**？docs/160 当年是“完全不提示”，docs/217 又加了编队轻提示。我的倾向：沿用 217——编队和属性面板写一句规则，局内不弹字。
3. 是否同意**第一轮只做前 3 条**并跑配对 A/B，再决定其余 5 条？
4. b8「猎物」会让群猎队明显更强（共享目标优先 + 层数奖励）；要不要把“深海猎人”做成**强度低一档**以免成为唯一最优（docs/160 §4 的约束）？
