## 1 为什么只有企鹅物流有新意

企鹅物流 = **一个具体物件（车）+ 一件具体的事（碾过去丢炸弹）+ 来自两人身份（快递公司）**，与两人平时的技能毫无关系。其余 7 条第三版都是「两人技能叠加」，等于平时放技能。

别的游戏的合击（出处见 §4）里，俯视、2 秒、怪群中读得清的只有几类：

| 类型 | 例子 | 俯视 2 秒 |
|---|---|---|
| A 共乘 / 驾驶物件、沿车道冲过 | P5R「Drive Hard」巴士；吸血鬼幸存者「Take Us Away」火车 | 最清楚（固定车道、从屏幕边进来） |
| B 一人把另一人 / 物件扔出去 | FF7 重生「Overfang」；KH3「Goofy Bombardier」 | 清楚（抛物线 + 落地冲击） |
| C 物件在两人之间来回 | 马力欧 & 路易吉「Green Shell」「Bomb Derby」 | 清楚（往返扫过怪群） |
| D 两人关系象征物 / 梗 | P5R 花束变双枪；HoloCure 合作武器（燃烧土豆、酒瓶变雪花） | 物件够大就可读 |
| E/F 场景再现、击掌定格、台词特写 | P5R 多数 Showtime | 不可读（要镜头 / 过场），最多 0.3 秒收尾点缀 |
| H 两人属性叠加 | 超时空之轮「Fire Whirl」 | 就是被否的「技能叠加」 |

**结论**：每条要有一个从两人原作关系来的物件 + 事件，优先 A / B / C 型；范围用带状 / 车道（不清屏）；画法仍用转平面帧条 + Noita 颗粒，但形体新做，不借两人现成技能件。

## 3 待用户决定 / 风险

- **宿敌**：碎杯（新、原作味更足）还是双狼（更直白）。
- **深海猎人同质化**：五条里已分成 刀弧复刻 / 串刺 / 竞速 / 斩首 / 复唱 五种事件，海兽巨物（鲸、鲨口、沉船）一律不用。
- **灯下审决**：光束会不会被看成流明 S3 的灯塔——不画塔、光从画面外来，用户看过再定。
- **需要新素材**：高脚杯 + 玻璃碎片、长槊、巨剑剪影、狼影（若选备选）；锚与车已有。按 pixfx / 转平面口径出。
- **原作文本**：本页钩子只用于设计；写进玩家可见文字（招式描述）前，按 docs/76 在 PRTS 原页再核一次原文（调研是转述抓取）。

## 4 原作考据要点与易误用说法（调研 11-07）

- 流明语音「照亮黑夜的提灯」说的是一位男性审判官（像达里奥），**不能**当「流明提灯照艾丽妮」的出处。
- docs/296 写流明「与重建灯塔联系的行动有关」不准：档案写的是父母是灯塔工程师；重启伊比利亚之眼的出处是剧情角色一览（乔迪）。
- 流明是卡门的学徒，不是艾丽妮的；艾丽妮已辞去审判官、现为审判庭信使。说「上下级 / 师生」没有出处。
- 歌蕾蒂娅的武器剧情里是「长槊」；「深海猎人队长」「第一队」PRTS 档案没出现。
- 拉普兰德档案没有「失语」一词（天赋「精神摧毁」：特殊能力失效）；「狼首」「背鳍」「海沟」「推演箭头」都是本作意象。
- docs/294 引的后勤技能名（恩怨、默契、手段应当有效、潮汐守望、集群狩猎）这次没核。
- 没查到：德克萨斯与拉普兰德在叙拉古直接交手的剧情场面；艾丽妮与流明同场对话；斯卡蒂档案 / 语音提乌尔比安；猎人小队徽记与统一口号。
