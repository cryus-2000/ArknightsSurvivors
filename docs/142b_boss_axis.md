# 142b · Boss 改版方案 B：每只一个主轴 + 合并 A 的新弹幕（10-25，待用户审；已按自动攻击核过）

> 用户 10-25 看过方案 A（docs/142：每幕换招式形状 + 特效）后：「感觉还是有点同质化，都是躲弹幕和冲击，能不能从根本上改」；问过同类游戏的做法后：「再做一套方案给我」。
> 本稿是**另一套方案**，不是 docs/142 的补丁：A 改「Boss 怎么打你」，B 改「玩家这场要做什么」。两套可以二选一，也可以 B 为主、A 的转场演出与特效套当包装（§6）。
> 只出稿、不改代码。基线 origin/main 7fbe5f23。原作机制 10-24 经 PRTS 复核（docs/142 附录 A），原作没有的标「本作拟」。同类游戏做法见 docs/49d。

## 0. 一句话

**每只 Boss 给玩家一件「这场必须做的事」**（主轴），只躲招、只输出也能打，但慢两三倍；做了这件事才打得快。每一幕换的是这件事的**规则**，不是招式的数字。8 场 Boss 战 = 8 个不同的动词：

| Boss | 动词 | 类别（docs/49d §9） | 原作依据 |
|---|---|---|---|
| 最后的骑士 | **斗牛**：引他冲锋撞冰枪桩 | 场地道具 | 受伤反冻来源；冲锋形态不可阻挡 |
| 塑路者 | **截路**：跑过他铺的路线上的路标，把路截断 | 场地规则 | 分形沿自身路径行动；「为大群探索生路」 |
| 圣徒伊比利亚 | **打断**：躲过一炮，趁装填冲进去打断 | 时机 | 弹药 1；装弹被打断晕眩 |
| 圣徒卡门 | **封锁线**：三枪火线把场地切成跑道，在跑道里绕到她身边 | 安全线 / 限制空间 | 弹药 3；远程射击；描述：坚守职责（转述） |
| “偏执泡影” | **打落**：冲刺穿过她，把她从悬浮打落；三幕改成冲刺打散光环 | 时机 | 近地悬浮，受异常失去悬浮并晕眩；光环压攻速 |
| 伊莎玛拉 | **破网**：先杀被歌声连着的海嗣，拆她的护盾 | 目标（清场） | 治疗敌方单位；「它为大群发声」 |
| 伊祖米克 | **拦截**：在子代走到她身边前截杀 | 目标（追击）+ 时间 | 学习：吸收子代叠强化 |
| 接潮组 | **同步**：两具血量拉平，8 秒内一起打进假死 | 双目标 | 两具一体，同处假死才死 |

和方案 A 的区别：A 里每只 Boss 都是「4 种预警形状 + 换色换纹样」，玩家的应对始终是「看形状、走开」；B 里每只 Boss 要你**去一个地方、先打一样东西、等一个时机**，躲招只剩 2–3 招，而且都服务主轴（例如骑士的冲锋既是威胁也是你要引的东西）。

示意图（程序画的形状 + 现有帧条，不是游戏截图）：`tools/probes/boss_axis_sheets.py` 生成，输出 `build/boss_axis_sheets/<boss>.png`（knight_boss、path、iberia、carmen、paranoia、ishar、izumik、tide_pair 共 8 张），每栏一条规则。白点 = 队长，灰点 = 队友，金圈 + 心形 = 要去打的目标，青色环 = 限时。

## 1. 通用规则（10 只共用）

0. **自动攻击前提**（用户 10-25 提醒）：玩家**选不了目标、也停不了手**，射程内一直在打。玩家能操作的只有：
   - **移动**（站哪、离谁多近）——主轴的主力；
   - **冲刺**（有冷却）——打落、打断、穿身；
   - 指挥圆盘（突击 / 归队、清杂优先 / Boss 优先，docs/114 §13）——只管队友，**只当加分项**：任何主轴都不能要求必须用圆盘（机器人从不改优先级）。

   所以每条主轴都写成「把队长带到哪里」「什么时候冲刺」，不写「先打 X」「别打 Y」。**玩家一直在跑**（用户 10-25：「玩家必然会跑动」）：主轴也不能要求站定不动——不写「站满 N 秒」「躲在某处等」，只写「跑过哪里」「在哪个范围里跑」。自动索敌现状（`op_api.gd:24-55`）：射程内有 Boss 就把 Boss 排第一（`ai/boss_focus`）；只有最近的敌人本身就是部件（`e.part`，泡影的茧、塑路者的核）时不被抢走；队长 60 内有小怪贴脸时先打小怪。**要新加一条**：主轴里要先打的东西（连线海嗣、泪、茧、子代、分形）标成「主轴目标」，射程内有主轴目标就先打最近的主轴目标、再轮到 Boss 优先（改 `nearest_enemies`，队长和队友都适用；圆盘的清杂 / Boss 优先照旧覆盖队友）。这样玩家的事只是把它们带进射程——它们都放在离 Boss 有距离的地方，不去就打不到。

1. **窗口，不锁血**：主轴做成了，给伤害窗口（受伤 ×1.5–2.0）或拆掉减伤（×0.4–0.6 → ×1.0）；没做成只是慢，不出现「打不动」。目标：会主轴的玩家用时 ≈ 现在，完全不理主轴的玩家用时 ×2–3。原则同 docs/49d §10「不专罚某类构筑」：每个主轴都至少有一条不靠特定干员的路（冲刺、走位、站位人人都有）。
   例外只有接潮组：两具同处假死才死是原作规则，现状已是这样。
2. **一种读法一种样式**（采纳 docs/49d §11 通用建议 1），全游戏只用这五种，新主轴不发明样式：
   - 白芯深描边 = 会伤人、走开躲；
   - 白色双描边 + 冲刺图标 = 现在冲刺有用（打落、打断、穿桩）；
   - **金色描边 + 心跳** = 要去打的目标（连线海嗣、子代、泪、路标）；
   - **青色倒计时环** = 限时（破绽剩余、同步窗口、子代到达）；
   - 低亮度纹理 = 场地（路线、光环、冰面、灯光），只减速或无伤。
3. **第一次见要教**：每只 Boss 第一次登场（按存档记），副标题亮一句该做什么，例如「引它冲锋撞上冰枪桩」，3 秒；之后不再出。文字按 docs/76。
4. **转场换规则**：过卡点时横幅写这一幕的新规则（一句话，如「破网：先打碎泪」），而不是只写幕名；配一次单发、不闪的演出（方案 A §2.5 的转场演出可直接用）。
5. **最终战小怪 = Boss 自己的机制小怪**：用 Boss 自己的小怪取代现在的少量补怪（`final/trickle_*`）和护卫波（`final/escort_*`）。小怪本身就是主轴的一部分（连线海嗣、子代、原作「释放当前波次」），照常掉经验。没有机制小怪的 Boss（泡影）按 Halls of Torment 的做法清场单挑。守住 Death Must Die 的教训：**机制小怪不会跑到玩家够不着的地方**（都在场地圈内、不出屏）。中期 Boss 照常刷怪，不变。
6. **躲招精简**：每只保留 2–3 招，都要和主轴有关；其余删掉。
7. **测试机器人必须会主轴**：`core/bot.gd` 每只 Boss 加一段主轴行为（§3 各节「机器人」一行），不会主轴的机器人测出来的用时和胜率没有意义。机器人做完、能稳定完成主轴之后，才跑云端 A/B。

## 3. 每只 Boss

格式：主轴规则 → 每幕怎么换规则 → 保留的躲招 → 小怪 → 读法 → 机器人。数值都是起点，实现后由数值会话按实测调。

### 3.1 最后的骑士 · 斗牛（结局二）

**原作**：受到伤害时给伤害来源附加寒冷（2 秒，低于 50% 时 4 秒）；攻击冻结目标攻击力 175%；首次倒地「释放当前波次」，30 秒重生，进入冲锋形态（移速 −50%、不可阻挡）。

**主轴**：骑士正面受伤 ×0.4（重甲）。场上有冰枪桩，引他冲锋撞上去：长枪脱手，**破绽 5 秒、受伤 ×2.0**。另外是原作的反冻，按自动攻击改成两条：① 打他的干员挂寒冷，攻速 −30%（不是破绽期就一直挂着，相当于平时输出打折，破绽期解除）；② 队长离他 140 以内时寒冷条上涨，满了冻结 1 秒、他下一击 ×1.75（原作 175%）。所以近战编队不能一直贴着：等冲锋 → 侧身让他撞桩 → 破绽期贴上去打满（寒冷条不涨）→ 退开。

| 幕 | 规则 |
|---|---|
| 一 · 骑士（100–66） | 登场就有 3 根桩（现状 66% 才有）；冲锋锁定后直线冲刺，桩在你和他之间就会撞上 |
| 二 · 冰原（66–33） | **桩会碎**：每根只能撞一次；他的冲锋路径留冰面，站冰面涨寒冷；新桩只能靠他「掷枪」补——掷枪是威胁也是资源（落点立新桩） |
| 三 · 掷枪（33–0） | 掷枪改 2 连；寒冷条满的冻结 1 → 1.5 秒；寒冷条上涨距离 140 → 180 |
| 重生 · 冲锋形态 | **桩不再管用**（原作不可阻挡：撞碎桩继续冲）；改成时机题：冲锋三连后喘气 2.5 秒（现状），喘气期受伤 ×2.0；重生时原作「释放当前波次」：刷一波 16 只普通海嗣 |

- **躲招**：冲锋（就是要引的东西）、长枪连刺（贴太近的惩罚）、掷枪（二幕起）。删掉冰线 + 追击、寒冷圆（寒冷改成反冻条）。
- **小怪**：一到三幕清场单挑；重生时刷一波（原作）。
- **读法**：冲锋锁定 = 直线；桩 = 金色描边（「要用的东西」）；寒冷条在队长血条下方，他脚下画出 140 的低亮度寒气圈（进圈就涨），满前描一次边框（单发）；破绽 = 青色倒计时环套在骑士身上。
- **机器人**：选一根桩，站到「桩在自己和骑士连线上、离桩 60–100」的位置；冲锋锁定后侧移；破绽期贴近；平时留在寒气圈外，寒冷条 > 70% 就拉开。

### 3.2 塑路者 · 截路（中期）

**原作**：塑路者分形沿自身路径行动；描述「为大群探索生路」「其分形会遍历错误的进化路线」。

**主轴**：塑路者每 10 秒从脚下向场边铺一条「生路」（地面发光折线，3–4 段，低亮度纹理），分形沿路线往外走，走到尽头 = 探到生路：塑路者叠一层强化（伤害 +10%，最多 3 层）。**路线上每段有一个发光路标，队长跑过去碰到路标就截断那一段**（不用停）：截断点以外的分形原地停住、变成金色目标（主轴目标，自动攻击先打）；击杀分形也行。路线全部截断的那一刻，塑路者「迷路」：硬直 3 秒、受伤 ×1.5。

| 幕 | 规则 |
|---|---|
| 一 · 探路（100–50） | 一次一条路，分形外出 |
| 二 · 订正（50–0） | **方向反过来**：分形改成沿路线**往回走**，走回他身上 = 回 3% 生命（「订正」）；被截断的路会在 2 秒后绕开你改道重铺一段；一次两条路 |

- **躲招**：冲撞（直线）、震地（圆，惩罚贴脸）。删掉分形塑路扇形、订正刃环、猎核（截路取代猎核的「要去打的东西」）。
- **小怪**：中期，照常刷怪；分形是他自己的。
- **读法**：路线 = 低亮度发光折线；路标 = 路线上的金色小菱形；截断点 = 金色断口；分形 = 金色描边；迷路 = 青色倒计时环。
- **机器人**：按「最近的未断路标」依次跑过去；路线都断了就贴近输出。

### 3.3 圣徒伊比利亚 · 打断（中期，7:00）

**原作**：手炮（200% 物理，弹药 1）；装弹 2 秒回 1 点，被晕眩 / 冻结等打断则晕眩 10 秒；弹药空时切近战模式。

**主轴**：节奏就是「一炮 → 装填」。手炮是全场最重的一发（单发上限照主控保护截断），锁定后贯穿直线。**躲过之后他必须装填 2.2 秒**（头顶读条 + 弹药格），装填中冲刺穿过他的身体（现状已有），或者站在射程里让自动攻击累计打掉 5% 生命（近战编队要冲进去才打得到）= 打断：**晕眩 5 秒、受伤 ×1.5**。没打断，装填完是手炮三连。

| 幕 | 规则 |
|---|---|
| 一 · 圣徒（100–50） | 如上；打断两种方式都算 |
| 二 · 延生（50–0） | 装填 2.2 → 1.4 秒；**只有冲刺穿身算打断**（累计伤害不再算）；原作近战模式：装填时你在他身边 90 内，他先抡一下（扇形，0.6 秒预警），冲进去要先躲这一下或从背后冲 |

- **躲招**：手炮（直线）、轰击（圆，压你靠近的路线）、近战抡击（二幕）。删掉散射、清膛。
- **读法**：手炮 = 直线；装填 = 头顶弹药格 + 读条，读条期间他身上出白色双描边 + 冲刺图标；晕眩 = 青色环。
- **机器人**：手炮锁定后侧移；装填开始就朝他冲刺穿身；晕眩期贴近输出。

### 3.4 圣徒卡门 · 封锁线（中期）

**原作**：弹药 3；远程射击；装弹 2 秒回 1 点，被打断晕眩；描述大意是失去神智后仍坚守职责（PRTS 摘要转述，不是原文）。

**主轴**（10-25 改：原「掩体」方案要玩家停在景物后面等，和「玩家一直在跑」相反，删）：卡门守着这块地方。她连开 3 枪，每枪是一条锁定后贯穿全场的直线，**打完不消失，留下一条火线（封锁线）持续 6 秒**，碰到掉血 + 减速。**每条火线上留一处缺口（约 80，白圈标出，同缺口环的读法），三条线的缺口错开**：三枪下来场地被切成几条跑道，玩家边跑边 S 形穿过缺口，绕到她身边。3 枪后她装填 3 秒（原作 2 秒 1 发，本作压成一次）：火线开始消退，她站定、受伤 ×1.5——这是压上去打的窗口；近战编队要在火线之间穿过去才够得着。和伊比利亚的区别：伊比利亚是**时机题**（躲一炮、冲刺打断），卡门是**空间题**（三条线切出来的地形里找路）。

| 幕 | 规则 |
|---|---|
| 一 · 圣徒（100–50） | 三条线大致平行（同一方向扫射三枪，间距 120–180），跑道是一条条长条 |
| 二 · 守誓（50–0） | **交叉成格**：三枪分两个方向（2 + 1），火线交叉把场地切成格子，每条仍留一处缺口；**最后一枪锁定的是你所在的那条跑道**，要在锁定的 1 秒里穿缺口换到隔壁格子；装填时她「退避跳」到场地另一边（窗口还在，但要多跑一段） |

- **躲招**：狙击（直线，打完变封锁线）、炮身横扫（贴脸惩罚）。删掉狙击三连。
- **读法**：狙击锁定 = 直线预警；封锁线 = 低亮度火线（危险色细描边，不闪），消退时由两端向中间褪去；弹药 3 格在头顶；装填 = 白色双描边。
- **机器人**：火线落下后按缺口规划一条通到卡门的折线，沿着跑；锁定线压到自己所在跑道时穿最近的缺口换格；装填开始就冲过去。

### 3.5 “偏执泡影” · 打落（结局一）

**原作**：近地悬浮，免疫失衡，受到部分异常效果后失去近地悬浮（并晕眩 0.5 秒）；范围内我方攻速 −60（二形态 −80）；第二形态 5 目标；重生 20 秒回满。

**主轴**：泡影是「冲刺」的 Boss——三幕都靠冲刺穿身，只是每幕冲刺的用处不同。悬浮时受伤 ×0.5，自动攻击照打、只是打折。**冲刺穿过她的身体**（本作把「冲刺穿身」算作原作的「异常效果」）→ 坠地 4 秒，坠地期间受伤 ×1.8（控制类技能命中也算，但不能只靠它，没有控制干员的编队一样能打）。难点在靠近：她的光环压攻速（现状 −10%，本稿不改），凝视逼你横移，冲刺有冷却。

| 幕 | 规则 |
|---|---|
| 一 · 凝望（100–66） | 如上 |
| 二 · 狂望（66–33） | **叠影**：分出 2 个幻影一起漂；**只有真身在地上有影子**（HoloCure 的影子语言）。按自动攻击：幻影也会挨打（自动索敌打射程内最近的那只），挨 3 下就散、6 秒后重新分出——所以**站得离真身最近**，输出才全给真身，这是站位题；冲刺穿过幻影 = 幻影炸开（小伤害 + 减速 1 秒）、冲刺进冷却——认错的代价是丢一次冲刺。幻影不吃主轴目标的优先（不能让自动攻击替玩家认真身） |
| 三 · 失声（33–0） | 原作第二形态：**落地，不再悬浮**，冲刺的用处换成**打散光环**：落地后光环加重（原作攻速 −60 → −80，本作 −10% → −35%，r300），整个光环内的干员都在挨这个减益——近战编队必须进光环才打得到，远程站在光环外又够不着；**冲刺穿身 = 光环散掉 5 秒**（这 5 秒正常输出），之后重新张开。节奏：等冲刺好 → 冲进去穿身 → 5 秒里打满 → 躲呼号 |
| 茧 | 现状保留（8 秒内打碎茧壳；打碎复活 40% 并有 5 秒破绽） |

- **躲招**：凝视（直线）、叠影落点（圆）、呼号（三幕扇形）。删掉泡影环。
- **小怪**：清场单挑（Halls of Torment 做法）：登场时现有杂兵 3 秒内由远到近消散（`final/clear_mobs_s` 现成旋钮）；不刷补怪、不刷护卫波。
- **读法**：悬浮时她身下有一圈白色双描边 + 冲刺图标（冲刺冷却好时亮）；真身影子 = 地上实心椭圆，幻影没有；坠地 = 青色环；三幕光环 = 低亮度紫纹，散掉时纹理由内向外褪去（渐隐，不闪），青色环显示剩余秒数。
- **机器人**：冲刺好了、离她 < 冲刺距离时朝她冲；二幕站得离有影子的那只最近、冲刺也朝它；三幕冲刺好了就冲进去穿身，光环散掉的 5 秒贴着打。

### 3.6 伊莎玛拉 · 破网（结局三）

**原作**：初始形态普通攻击改为治疗（最多 3 个敌方单位）；描述「她不再歌唱，它为大群发声」；濒死强化（首次低于 50% 攻击 +50%，立即召唤 2 个伊莎玛拉之泪）；变身后同时攻击 3 个目标、真实伤害。

**主轴**：她的歌把海嗣连成网：每只被连着的海嗣（头顶音符、金色描边）给她 −10% 受伤，最多 6 只（−60%）。连线海嗣**标成主轴目标**（自动攻击先打），而且被歌声拉到她周围 220–320 的一圈上站定，**离她有距离**：队长站在她身边时射程够不着，要绕着她去一只只拆。她每 6 秒「召唤合唱」，从场地边缘叫来 3 只补进圈里。清怪强、射程长的构筑拆得快（docs/49d §10 的「第二条路」）。

| 幕 | 规则 |
|---|---|
| 一 · 大群（变身后 100–66） | 如上 |
| 二 · 濒死强化（66–33） | 原作召 2 个泪：**泪 = 歌眼**，泪在场时网上限 6 → 10，断掉的线 3 秒后自动接上——**先打碎泪，再清网**（规则从「清怪」变成「先拆核心」） |
| 三 · 回声（33–0） | 被杀的连线海嗣死后留一个音圈，1.0 秒后爆开（圆，小伤害）——近战编队贴上去拆开始有代价，射程长的站远拆更安全；原作三目标：她的扫射分锁队长与两名队友 |

- **躲招**：三线扫射（直线）、撕咬（扇形，贴脸惩罚）、回声音圈（三幕）。删掉三点落击、大群之歌。
- **小怪**：她自己的合唱海嗣 + 场上原有的海嗣都可被连；关掉补怪与护卫波。
- **读法**：连线 = 青色细线（低亮度）；被连的海嗣 = 金色描边 + 音符；她身上的减伤以「护盾环」显示，每断一根线护盾环少一格；泪 = 金色描边 + 心跳。
- **机器人**：沿 220–320 那一圈走，依次靠近被连海嗣（自动攻击会先打主轴目标）；二幕先去泪那里；网空了贴近她。

### 3.7 伊祖米克 · 拦截（结局四）

**原作**：学习：召唤子代；吸收子代计数，5 次得 1 层强化（攻击 +40%，最多 4 层）并回 15% 生命；分享：对场上所有我方单位溅射；震撼：生命首次低于 75% / 50% / 25% 强制触发。

**主轴**：子代分批从场边走向她（每批 4–6 只，走约 10 秒），**HUD 边缘箭头标出这一批从哪边来**；走到她身边就被吸收：计数 5 = 强化 1 层（伤害 +15%，最多 4 层）并回 5% 生命（原作回 15%，按时长收）。子代标成主轴目标；玩家要迎上去，让它们在半路就进射程。和伊莎玛拉的区别：伊莎玛拉是在她身边清场，伊祖米克是**去场边追截**、和时间赛跑。

| 幕 | 规则 |
|---|---|
| 一 · 阐释（100–66） | 一次一个方向；75% 强制震撼一次（原作阈值） |
| 二 · 学习（66–33） | 一次**两个方向**；走到她身边的子代不立刻被吸收，而是在她脚下结茧 4 秒（DRG 的茧，青色倒计时环，主轴目标——在她身边时自动攻击也先打茧，不打她）——最后一次机会，但要贴近她；50% 震撼 |
| 三 · 分享（33–0） | 不再来子代，主轴改成灯柱：每 12 秒一次全场「分享」，**站在灯柱光圈里不受伤**（用户 10-24 定），预告 2–4.5 秒 + 蓄力 1.6 秒（用户 10-24 要缓冲）；**每次分享后，有人躲过的那根灯柱熄灭**——灯柱越来越少，最后一根熄灭前要打完；25% 震撼 |

- **躲招**：潮汐坠落（圆）、分享扇形（贴脸惩罚）、全场分享（三幕，灯柱免伤）。删掉解读旋涡。
- **小怪**：子代就是她的机制小怪；关掉补怪与护卫波。
- **读法**：子代 = 金色描边，头顶细线连向她；HUD 边缘方向箭头；身上的强化层数用 1–4 圈亮点；灯柱光圈 = 低亮度暖光。
- **机器人**：朝这一批子代的来向迎上去截杀；子代清完回中间输出；三幕看到预告就去最近的亮灯柱。

### 3.8 接潮组 · 同步（中期，7:00）

**原作**：两具一体；生命归零先假死（每秒回 5%，斥亡体 10%）；两具同处假死，或一具假死时另一具到达终点，才真正死亡。

**主轴**：现状的「8 秒内把另一具也打进假死」保留，再加原作没有、取材深岩银河：幸存者无畏舰双子的**血量差护盾**：两具血量差超过 25% 时，血少的那具受伤 ×0.4。所以要**平衡输出**：自动索敌先打射程内最近的 Boss，玩家靠站位决定打谁——站到血多那具旁边，让另一具在射程外。两具缺省保持 ≥ 360 的距离（比大多数干员射程远），保证站位分得开。

| 幕 | 规则 |
|---|---|
| 一（各自为战） | 如上 |
| 二 · 统一（任一具过 50%） | **换位**（「统一」）：每 10 秒两具之间亮起连线，1 秒后瞬间互换位置——你身边那具换成了另一具，要重新判断站哪边；血量差门槛 25% → 15%；假死窗口 8 → 6 秒 |

- **躲招**：主教潮汐柱（直线）、蔑死体跃击（圆）或斥亡体连斩（直线突刺）。删掉交错潮环、统一连线、扇浪、裂潮、飞刃、旋刃。
- **小怪**：中期，照常刷怪。
- **读法**：两具血条并排显示在 HUD 上方，中间一个「差值」刻度，超阈值时血少那具身上出护盾环；假死 = 青色倒计时环（现状）。
- **机器人**：站到血多那具身边、另一具在射程外；差值在门槛内时按血多的那具走；换位预警出现后重新选边。

## 4. 难度与用时

口径照旧：无局外成长常规胜率 45–60（docs/109、111）；收紧只用不给奖励的旋钮；胜率差 <10 点不下结论。

| 组 | 预期 | 风险 |
|---|---|---|
| 会主轴的玩家 | 用时 ≈ 现在（最终 Boss 血量 −15% 抵掉主轴的学习成本） | 第一次见要几次才学会：靠第一次登场的提示（§1.3） |
| 不理主轴的玩家 | 用时 ×2–3，承伤上升，胜率下降 | 有意如此，但不能锁死：每只最多慢 3 倍（窗口倍率按这个反推） |
| 机器人 | 只有学会主轴后才能代表玩家 | 机器人没做好就测，数据会偏难 |

验证：机器人主轴行为做完后，云端例行任务 `--preset starts` 7 开局 × 16 seed = 112 对，每只强制出场，改前 vs 改后，看用时、胜率、主轴完成率（机器人每场做成几次）。

## 8. 合并版：B 的主轴 + A 的新弹幕（10-25，现行推荐）

用户 10-25：「能不能和之前设计的新的弹幕给结合起来」。§6 原来只借 A 的转场演出和配色、不做 A 的换形弹幕；**本节取代 §6 的建议**：A 每幕的新弹幕形状（docs/142 §3A）保留，并且每一招都给主轴派一个用处。

### 8.1 怎么结合

1. **弹幕服务主轴**：每招弹幕必须属于下面三种用处之一，写在表里；三种都不沾的招删掉。
   - **拦路**：挡在玩家去做主轴的路上（去桩、去路线、去连线海嗣、冲进去穿身），要穿过它才做得成；
   - **惩罚**：主轴没做成时才出、或者做不成时更凶（例如装填没被打断 → 清膛 + 三连）；
   - **定拍**：给窗口定节奏（例如卡门三枪之后才装填，三枪本身就是计时器）。
2. **窗口期停火**：破绽、晕眩、坠地、光环散掉这些窗口里，Boss 不起新招（已经在飞的弹照常结算），窗口给的是「放心输出」。
3. **读图上限**：同一时刻屏上最多 1 个有名字的招（现有招式令牌）+ 1 个主轴元素（路线 / 连线 / 寒气圈等，低亮度）；每幕可用的躲招 3 招，比方案 A 的 4 招少一招，给主轴腾读图空间。
4. **每幕三件套照 A**：特效套（配色、预警纹样、本体颗粒、地面）和转场演出按 docs/142 §2.5 / §3A；转场横幅写 B 的新规则（§1.4）。
5. **自动攻击前提照 §1.0**：所有弹幕的躲法都只靠移动和冲刺。

### 8.3 工作量与顺序

- 比单做 B 多的：A 的换形弹幕（预警纹样、泪滴 / 鳞片弹、螺旋臂、折线冲锋等，docs/142 §5）和 8.2 里新加的几处联动（泡影幻影空弹、卡门封锁线、塑路者冲撞沿路线、订正刃环落在断口）。
- 顺序不变（§5）：先做骑士 + 伊比利亚两只样板，合并版一起做进去，给你上手试；方向对了再推其余六只。
