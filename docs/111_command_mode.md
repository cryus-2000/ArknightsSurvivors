# 111 指挥模式（第 1 步原型）

状态：原型（10-21），分支 `claude/command-mode`，未合 main。第 2 步目标优先、第 3 步接局外成长（docs/109）和正式按键，另做。

## 1. 用户已定

- 一个键循环切换，不用长按：**护卫**（缺省，现状）→ **出击** → **召回** → 自动回护卫。召回途中再按 = 出击。
- 出击：队友自己找怪打，不回队长身边；离队长最远约 1.5 屏（实现取 1.5 个半屏宽 = 960 世界像素，见 §3），超出就往回收。
- 医疗、辅助默认不出击：干员 json `command.roam: false`（安洁莉娜、凯尔希、流明、浊心斯卡蒂、铃兰已写），个别干员可改 json 破例。
- 屏幕外的队友在屏幕边缘画方向标记。
- 设计理由：玩家是博士，指挥是核心身份；操作必须极轻（注意力在走位上，网页和手机也要能用）。

## 2. 操作

| 输入 | 键位 | 说明 |
|---|---|---|
| 键盘 | **F** | Tab / C 已是属性面板，Q / E / J 技能，Space / Shift / K 冲刺，V 倍速；F 在局内空闲（只在商店里是刷新） |
| 手柄 | **LB**（LT 同） | 局内上下文原来没用左肩键；RB = 冲刺 |
| 触屏 | 「指挥」键 | 暂停键左侧同一行（桌面 `(vs.x-118, 186)`，手机 `y=160`）；离冲刺 / 技能 / 攻击键与编队区都远，不挡摇杆；可在「设置 → 触屏按键布局」里挪 / 缩放（键名 `cmd`） |

HUD：非触屏时编队区（源石锭框）上方右对齐一行「指挥 · 护卫」+ 按键牌（手柄显示 LB），颜色随模式：护卫青、出击金、召回绿。触屏时模式名写在「指挥」键圈里。屏外队友：屏幕边缘一个小圈（干员色描边 + 职业首字，同编队卡左上角；外圈细线 = 当前模式色）+ 指向箭头；贴在避开顶栏 / 底部提示的框边上，压在 HUD 之上。（试过头像上半身：圈里只有约 14 像素高，认不出，改职业字。）

## 3. 实现

- 状态：`squad.stance`（0 护卫 / 1 出击 / 2 召回），`squad.cycle_stance()` / `set_stance()`；切换记进 `squad.stance_log`，`--trace` 时打印 `CMD t=… stance=…`（不进 TRACE 行）。
- 站位：`character.follow()` 里，出击时用 `roam_target()` 代替 `follow_target()`（编队位 / 近战前压）：以干员自己为中心 `command/search` 内最近的敌人（离队长 ≤ `command/leash`），站到它朝自己一侧 `cmd_reach()` 处；有滞回（目标死 / 出圈才换，近 50 以上才换更近的）；没怪回编队位；落点夹在 leash 圈里。`cmd_reach()`：近战取 `blocks.follow.gap`，普攻带 range 的远程取 range × `command/range_k`。
- 速度：护卫原样（lerp，不限速，> 700 瞬移归位）；出击限速 队长移速 × `command/roam_speed`；召回 lerp 加快 + 限速 × `command/recall_speed`，全员离护卫站位 < `command/recall_done` 或满 `command/recall_max` 秒自动回护卫。出击 / 召回时瞬移阈值放宽到 leash × 1.6。
- 找怪只经 op_api `nearest_enemies`，不抽随机数。
- 开关：`data/balance.json` 的 `command.on`（缺省 1）；0 = 不画按钮 / 标签，按键无效（对照用 `--bal=command/on=0`）。
- 机器人：缺省护卫（`command/bot_roam` = 0）；`--bal=command/bot_roam=1` 开局常开出击。测试钩子 `--cmdat=秒,秒,…` 到点按一次指挥键（录片用）。

| 旋钮 command/… | 缺省 | 含义 |
|---|---|---|
| on | 1 | 总开关 |
| leash | 960 | 出击离队长最远（世界像素） |
| search | 520 | 找怪半径（以干员为中心） |
| roam_speed | 1.3 | 出击限速（× 队长移速 150） |
| recall_speed | 4.0 | 召回限速 |
| recall_done | 28 | 召回归位判定距离 |
| recall_max | 3.0 | 召回最长秒数 |
| range_k | 0.6 | 远程站位 = 射程 × 它 |
| bot_roam | 0 | 机器人局常开出击 |

## 4. 已知局限（原型）

- 一部分干员的普攻 / 技能以**队长**为中心或只打队长身边的怪（斯卡蒂大剑「在队长身边横扫」、浊心斯卡蒂声浪、推进之王「冲到队长身边的敌人面前」、塞雷娅阻挡圈等），出击后这部分输出不跟着走——第 2 步要逐个定「出击时以谁为中心」。
- 敌人只追队长，出击的队友不吸引仇恨；队长身边少了近战，承伤会变（见 §6 数据）。

### 6.2 机器人小样：出击常开 vs 护卫

`balance_run.py --preset squads --seeds 3`（normal 机器人、标准档、6 编队 × 3 seed），出击常开 = `--extra=--bal=command/bot_roam=1`。护卫列 / 出击列；输出 / 秒 = 全队总输出 ÷ 存活秒；承伤 / 分 = 队长受到的伤害。

读法（每组只有 3 局，胜率差 < 10 点不下结论，docs/36 / balance-method）：
- 总体出击 **输出 +14%、队长承伤 +23%、存活 +16 秒、胜 2/18 vs 0/18**；近战编队（水月 / 推进之王、斯卡蒂 / 推进之王）输出 +50% 以上，纯远程（维什戴尔 + 艾雅法拉 + 铃兰）输出 -24%（铃兰不出击，两名远程散开后火力不集中）。
- 承伤普遍上升：近战离队后队长身边没人挡，符合「出击 = 拿安全换输出」的设计取向。
- 输出 / 秒受存活时间影响（后期输出高），这组数只看方向。要定数值请用同种子配对 + 更多 seed（云端例行任务）。
