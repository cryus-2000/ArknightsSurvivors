# 283 · 中期 Boss 不够显眼：诊断与改法（设计稿，11-06）

状态：**诊断 + 设计稿，待用户审，不改代码**。来源：用户 11-06「中期 Boss 不够显眼」。基线 main 319b5de4b。
边界：**不加 Boss 弹幕提示**（用户定：图案弹幕不做符卡、不弹提示；弹幕紧张感主要留给最终 Boss，见 memory boss-design / design-pillars）。本稿只解决“一眼认出这是 Boss”，不动招式难度。

## 0. 结论摘要

1. 中期 Boss = 3:30（塑路者，或圣徒卡门）与 7:00（圣徒伊比利亚 / 圣徒卡门 / 接潮组（主教 + 执政官或不死者）/ 塑路者），数据见 `waves.json` 的 `boss_times` [210, 420, 600]、`mid_first`、`mid_pool`。
2. **最强的一条证据：这几只 Boss 的画布高度和精英一样**。实测（`game/art/enemies/*@2x.png`，@2x 像素，取第一帧身体包围盒高）：

| 单位 | 类别 | 帧画布高 | 身体包围盒高 | 碰撞半径 r |
|---|---|---|---|---|
| 圣徒卡门 | 中 Boss | 128 | 80 | 22 |
| 圣徒伊比利亚 | 中 Boss | 128 | 82 | 22 |
| 主教 | 中 Boss | 128 | 78 | 22 |
| 执政官 / 不死者 | 中 Boss | 128 | 96 | 24 / 20 |
| 塑路者 | 中 Boss | 192 | 126 | 34 |
| 母巢（mother） | **精英** | 128 | 92 | 18 |
| 骑士（knight） | **精英** | 192 | 144 | 18 |
| 偏执泡影 / 伊祖米克 | 最终 Boss | 256 | 170 / 174 | 40 |

→ 圣徒卡门、伊比利亚、主教的身体比精英“母巢”**还矮**（78–82 对 92），塑路者比精英“骑士”矮（126 对 144）。血量 1400–3800、碰撞半径 20–34 是 Boss 级，但**画面上没有大一圈**。
3. 其余几条（登场演出、血条、音效）**已经有**，问题不在“没有”而在“和同屏其他东西抢不过”：见 §1。
4. 推荐改法：**① 体型 + 常驻 Boss 标识（本体层）**，**② 登场后 10 秒内的“压场”处理**，**③ 颜色隔离**，都是纯画面（TRACE 不变）。不加预警、不动招式。

## 2. 改法（推荐 A，可叠加）

### A 体型 + 常驻脚下环（本体层，推荐）

- **A1 放大**：中 Boss 的 `draw_scale` 提到约 1.35（圣徒 / 主教 / 执政官 / 不死者）、1.2（塑路者）。碰撞半径**不变**（只画；`draw_scale` 已是 enemies.json 字段，塑路者 / 最终 Boss 都在用）。放大后身体包围盒约 105–130，与精英拉开一档、低于最终 Boss。
- **A2 常驻脚下环**：Boss 活着期间脚下有一圈**像素断续环**（直径≈碰撞半径×2.6，Boss 强调色，慢速旋转，亮度低于登场聚光圈）；Noita 口径：环是少量发光像素点 + 地面一圈很淡的光，不是实线圆。精英无此环。
- 成本：两个旋钮 + 一处脚下绘制（`world._draw_enemy_full` 里 Boss 分支，登场聚光圈同一位置）。

### B 登场后 10 秒“压场”（时间层，可选）

- 登场后 10 秒内：Boss 周围 200 像素内的**小怪画面亮度降 15%**（只画，不改判定），Boss 本体亮度 +10%；10 秒后渐回。
- 不同于暗角演出：它在**游戏继续**时生效，不挡画面。成本低（画面系数），但需要验证不和“光学观感”（docs/130）互相干扰。

### C 颜色隔离（色彩层）

- 塑路者 / 卡门的强调色（环、名片、血条）改用**更饱和的一档**，Boss 本体贴图不动（贴图色按 PRTS 立绘，docs/87 §4.3 / canon-art-consistency）。只改 `bcol`（环 / 血条 / 名片 / 招式色），本体配色不碰。

### D 不推荐

- 加 Boss 头顶箭头 / 文字：和“不弹提示”冲突，也和精英白标记语言混。
- 登场后再弹一次名片：打断割草。
- 提高登场音量：低疑点且已按外放口径拉过电平。

## 6. 实机截图核实（11-06，GCP，main 319b5de4b 的游戏代码）

截图：`Claude outputs/design_1106/boss_{carmen,bishop}_*.png`（1280×720，镜头不放大；`tools/design_shots_1106.py`，同 seed 3，机器人「集火」姿态，水月 + 4 名队友；卡门在 6:45、主教在 3:15 的时钟下）。

**结论：部分推翻。**

| 原判断 | 截图所见 | 结论 |
|---|---|---|
| Boss 被「怪群」淹没 | 3:15 / 6:45 同屏**几乎没有其他怪**（密度缺省 0.4，Boss 战前后小怪很少），血条在顶部、清楚 | **推翻**：不是被敌群淹没 |
| Boss 体型和精英一样，不够大 | Boss 约 40–50 像素高，和旁边的干员立绘同量级，战场上没有「一只大东西」 | **成立** |
| 登场演出后没有常驻标识 | 本局是「集火」状态，Boss 身上有粉色锁定框 + `LOCK / BOSS` 字样，很显眼；**但这只在集火后才有**，玩家不下令就没有 | **成立，并找到更便宜的改法**（见下） |
| 颜色偏淡（塑路者 / 卡门） | 卡门本体是白灰色，位于队伍的蓝白剑气环、金色晶簇里，**被己方特效盖住**，比颜色本身更要紧 | **改判**：主要矛盾是**被己方的技能特效盖住**，不是颜色 |

### 修订后的改法优先级

1. **（新，最便宜）Boss 常驻锁定框**：集火时已有的粉色 `LOCK / BOSS` 框改成 Boss 在屏时**一直显示**（亮度低于集火时），玩家不用下令也能一眼找到。纯画面。
2. **体型 A1 / 脚下环 A2** 仍然成立（截图里 Boss 和队友一样大，脚下没有标识）。
3. **「压场」B 取消**：场上没有怪群可压。
4. **己方特效避让（新，待议）**：Boss 周围 120 像素内，队友的**大面积半透明剑气环 / 晶簇**降 25% 不透明度（只画，不改判定）。副作用是会削弱爽感，**不推荐首轮做**，列出供用户定。
5. 颜色 C 降级：先做 1、2，再看。

### 局限

只截了 2 只中期 Boss（卡门、主教）；机器人局的站位比真人更集中，Boss 总在队伍中央，真人局可能更分散。塑路者、伊比利亚没截。
