# 138 材质颗粒验收（Codex codex/particle-materials @ 7289a73dc，10-24）

粒子化会话（分支 `claude/particles-8d10a8`）验收 Codex 的「材质颗粒」未验收草稿：共享材质颗粒池、艾雅法拉火球 / 熔岩 / 点燃爆燃、拉普兰德剑气转碎片。模板规范见 docs/136，Codex 交接说明 `art/incoming/codex_material_grains_1024.md`。

## 1. 结论

- **可以合**（关时与 main 逐行相同，开时也逐行相同）。合入的是本分支（含修复），不要直接合 7289a73dc。
- **原先缺省关**：桌面帧时代价小（§4），但观感还没定：艾雅三项用户已给阶段性方向认可，拉普兰德后半段偏暗、用户要的「明显差异」不够（§3）。用户看 gif 后再决定哪几项缺省开。
- **10-24 用户定**：火 / 水 / 艾雅先缺省开，拉普兰德等第 2 轮。已拆开关（balance.json `fx`）：`material_grains` = 1（火命中、水花、艾雅火球 / 熔岩 / 点燃）；`material_lappland` = 0；`material_fluid` = 0（海嗣体液命中 `fx_corrode_hit`，用户这次没点名，先关）。缺省 / 三道全开与全关同 seed 均逐行相同（181 行）；快检 126 项只剩金样过期。

### 7.1 哪些不粒子化（10-24 用户「不是所有都需要改成粒子特效」，本会话判断同意）

- **粒子化的标准**：特效本体是「材质」（火、水花、体液），散成颗粒仍读得出、而且更像那种东西。现接入：火命中、水花、蓝水花、艾雅火球 / 熔岩 / 点燃（缺省开），海嗣体液命中（缺省关），到此为止。**爆炸 / 炮击不算**：靠爆心与放射尖刺的冲击感认，粒子化后变弱还更费帧（维什戴尔炮击，用户 10-24 看后定）。
- **不粒子化**：靠**形状**认的特效——刀光 / 突刺、环、符文、圣光菱形、光束，以及几乎所有干员技能帧条。`--fxcensus` 也数了干员数据特效（`ob_fx`，`@ob` 一次性 / `@obL` 循环与扩散件）：一次性的是安洁莉娜牵引、拉普兰德剑气、歌蕾蒂娅牵引 / 滑行、Mon3tr 爪 / 震地环、星熊鬼斩、归溟内卷涟漪、能天使祝福闪等，全是形状型，不接。归溟血锯已证明锯环散成点就认不出。
- **太小的命中火花**（12–16 px）不值得：采样不到 8 颗时代码自动退回原帧条。
- 之后只在新增「材质型」特效时按本模板接；拉普兰德剑气用户定先用原版（10-24）。

## 10. 特效缩放取整到整数格（交接手册 §6 第 8 条「172 张强制读 1 倍版 + 84 处非整数缩放」，10-24 用户定）

**查到的实质**（原统计的出处没进仓库，本节重新量）：
- 「172 张」≈ `fx_` / `proj_` 里同时有 1 倍原图和 @2x 的 171 张。main 的仓库清理（`52677a2c`，docs/131 §1.3-1）已把这 171 张 1 倍原图删掉，游戏一律读 @2x；需要时可从 git 历史找回。
- 光学观感的世界层是 640×360（1 格 = 2 世界像素），帧条在里面按最近邻采样：@2x 和缩放倍数不是整数的帧条，像素被不均匀地抽掉或一宽一窄，圆环粗细不均、细节丢失。
- `--fxcensus` 另记每次特效的缩放（`SC|名|每贴图像素世界像素`）。7 局（同 §7 盘点口径，不含死亡帧条）共 15351 次特效播放，按「1 个美术像素在低分辨率层占几格」分：本来就是整数格 3257 次（21%）；≥ 0.75 格、非整数，本次取整 9608 次（63%）；< 0.75 格、不动 2486 次（16%）。

**做法**（`vfx.int_scale`，开关 `render/fx_int_scale` 缺省 1）：只在光学低分辨率层开着时生效。美术像素 ≥ 0.75 格的取整到最近整数格（至少 1 格），像素宽度均匀；< 0.75 格的不动。接在 `world.gd` 的 `sprite` / `gsprite` 绘制和 `ob_fx.fx_draw`（一次性 / 循环帧条）；**按半径拟合（fit）的条目、扩散件、区域常驻件不取整**——取整最多差三成，会把范围画错。大小变化：多数 ±10–33%（如墨圈 1.2 → 1 格、刀光 1.5 → 2 格）。纯画面。子弹（`proj_`）这次没统计，绘制路径分散，另做。

2. **德克萨斯刀光重复**：拔刀 / 回马剑每刀叠了两套——数据里的 `blade` 帧条 `fx_slash_heavy_steel`（json 没写 `tint`，走了缺省冷蓝 `(0.72, 0.86, 1.05)`，就是那道蓝色大月牙）+ 通用近战刀光（她的橙色本色）。删掉 texas.json 拔刀 / 回马剑的两条 `blade`，留橙色那套。
3. **斯卡蒂旧特效 Noita 化**：`--fxcensus` 单人 150 秒：蓝水花 216（已是水材质）、`fx_slash_heavy_deep` 136（S1 迅捷打击 / 跃浪击的刀光帧条，形状型，保留，本来就带水珠 motes）、`fx_skadi_surge_release` 14、`fx_skadi_surge_hit` 1；数据里还有 `fx_skadi_surge`、`fx_skadi_leap_splash`。「旧」在后四条：后半段是棋盘格抖动点阵消散。做法 = 帧条后半段换颗粒（`fx_grains.MAT_HANDOFF` + `ob_fx._mat_handoff`）：一次性帧条播到交接比例（浪刃 0.5、浪击 0.4、涌潮环 0.67、跃浪水花 0.4）时，从当时那一帧的可见像素迸出水材质颗粒（带重力下落、冷却），帧条 0.08 秒淡出；形状由前半段交代。颗粒走共用预算六成，预算满 / 低画质 / 材质关时帧条照原样播完。同帧对照 `--materialmovie --obnames=…`。

4. **水月 S1 黄圈**（10-24 用户「水月一技能造成的这些黄色的圆形可以去掉」）：唤醒命中处的金色十字光团（`impact`）与创伤扩散的金色实心圆 + 粗环（`burst`）不画；伤害 / 击退 / 火星 / 触手照旧（r70 金环原本就被 `render/hit_rings` 关着）。

## 12. 激光改版原型（10-24 协调人转用户「现在的激光表现方式你觉得是不是可以更改一下？」）

**盘点**：画法分四套，都是满长度瞬间出现、颜色 > 1（不受亮度上限和特效照明管，只靠全屏辉光糊开）：
- `beam`（world.gd）：治疗 / 连线——医疗无人机、流明治疗、凯尔希治疗 / 连 Mon3tr、伊莎玛拉泪滴治疗；两层线（外层 ×2 色 α0.35 宽 3w + 2.5 倍白芯）。
- `bbeam`：Boss 粗光束——偏执泡影凝视 ×3、伊莎玛拉三线扫射、执政官腐蚀吐息、Boss 招式直线；三层线宽度按 sin(40t) 抖动 + 6 个脉动圆，满屏刺眼、闪。
- `tracer`：狙击 / 穿刺弹道——圣徒手炮 / 狙击 / 齐射、7 种杂兵穿刺、Boss 直线（伊比利亚 / 卡门 / 骑士）。
- 干员 `line`（character.gd）：艾琳枪线、维什戴尔炮线、流明折射等细线，宽 1–2，问题小，本轮不动。流明灯塔光柱是帧条，另算。

**原型**（`render/laser_draw.gd`，开关 `fx/laser_style`：0 = 原样（缺省）/ 1 = A / 2 = B，接管上面前三种）：两版都是 0.06 秒从起点伸到终点、颜色压回 ≤ 1、不画常驻光晕、不抖宽度。
- **A 像素光束**：宽度先张开（前 15% 寿命）再收到 1/4；三层硬边（外层本色 → 中层亮色 → 2 px 白芯）；伸到头时沿线迸少量火花（每 24 px 一颗），末端两帧小菱形命中闪。
- **B 颗粒光束**：只留 2 px 细芯，光束本体在伸到头时沿线生成颗粒（每 2.5 px 一颗）顺着方向飘散。实测颗粒光束太弱，Boss 光束几乎看不出来，危险信号不够。
- 对照：`--materialmovie --lasermovie --bal=fx/laser_style=N`（三种光束同屏）。本会话判断推荐 A；用户挑定后再缺省开并量帧时。
