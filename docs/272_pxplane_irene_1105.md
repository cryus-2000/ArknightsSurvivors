## 1. 意象与配色（原作参照 `Claude outputs/irene_ref/`，tools/ref_fx/rebuild_prefab.py 从本机客户端解出，不进 git）

**11-05 用户看第一版 GIF：「艾莉妮的主基调是不是应该是白色+亮紫色？」** 查证后改成白 + 亮紫为主，深蓝潮水作辅色，金色只留在手提灯上。第一版用的是任务单写的「金白光刃配深蓝潮水」。

查证依据：
- **原作特效**：普攻、S1–S3 的 prefab 粒子起始色绝大多数是纯白（例如 S3 起手 `start_02` 有 11 个白、`start_01` 有 6 个白），回放出来几乎都是白色。带颜色的只有渐变关键色：命中类（`attack_hit_01`、`skill_01/02/03_hit_01`）里有紫 (0.24, 0, 1.0)、粉紫 (0.87, 0.33, 0.52)、蓝 (0, 0.34–0.54, 1.0)，S3 起手 `start_02` 有一串玫粉 (1.0, 0.46–0.62, 0.42–0.74)。按回放关键帧统计：前五个特效的高饱和像素都是 0，只有 S3 起手这张有 2571 个，色相集中在 330°（品红偏紫）。
- **本作立绘像素**（`op_irene_idle@2x.png`，按 docs/87 §4.3 与 PRTS 立绘对过色）：除黑白灰外，唯一的高饱和色相是 340°（品红 / 紫红）。
- **本作已有设定**：`irene.json` 的代表色 `col` 是 (0.95, 0.6, 0.8)，即粉紫。
- 结论：原作特效以白为主，点缀的是紫 / 粉紫；服装点缀色也落在紫红一带。主基调定为白 + 亮紫（色相约 270–285°，比服装的 340° 更偏紫，按用户的「亮紫」取），不用金。

| 用途 | 色阶 |
|---|---|
| 光刃（刺剑、裂潮月牙、余波新月、判决光环 / 光矛、手炮火光、提灯光圈 / 光尘、剑气细刺） | 白 → 亮紫 7 阶 `#1a0c28 #3a1a58 #6a32a0 #9d58e0 #cf98ff #f0e2ff #ffffff`：芯白，紧挨着淡薰衣草，外缘亮紫 |
| 潮水（辅色：刺击潮痕、裂潮水花、起风水旋、贯穿水珠、剑气拖尾、水珠颗粒） | 深海蓝 → 白沫 7 阶 `#050b1a … #90c4ea #e6f6ff`；水花上半改成以白沫为主 |
| 手提灯（点缀） | 金 7 阶，只用在灯本身 |
| 手炮烟 | 暗灰 4 阶 |
| 照地光 / 受击闪 | 亮紫 `#c890ff` / `#d8b0ff` |

不用红色。原游戏的粉色刺光（look.col）在接管时不画。

## 8. 主色改白 + 粉、去蓝（11-07）

用户原话：「艾莉妮的主色调应该是白+粉为主，一技能的蓝色去掉」。

**定稿色（取代 §1 的白 + 亮紫）**：粉色取自 PRTS Spine 立绘。`build/prts_ref/irene` 攻击帧的服装点缀色是 `#d090a0` / `#c88898`，色相约 345°；本作 `op_irene_idle@2x` 的 `#ca8b9b` 同色相，按 docs/87 §4.3 一致。特效色阶在同一色相上提亮度：

| 用途 | 色阶（暗 → 亮） |
|---|---|
| 主色 LT（光刃、星芒、月牙、光环、光矛、手炮火光、终结技斩击 / 冲击环 / 粒子） | `#1e0c16 #4a1c32 #8a3a5a #c8668a #eaa0b8 #fbe0ea #ffffff`：芯白，两侧和余韵是粉 |
| 辅色（原深海蓝潮水 TIDE → 粉雾：S1 水旋、S2 水花碎沫、余波水珠、粒子、终结技浅色粒子） | `#140a10 #2a1620 #46283a #6e4458 #a8788c #e0bfca #fff2f5` |
| 照地光 / 受击闪 | `#eaa0b8` / `#f4c0d0`；起风水旋灯 (1.0, 0.72, 0.84)；终结技收尾灯 (1.25, 0.88, 1.0)、盖章慢暗灯 (1.0, 0.62, 0.78) |
| 不变 | 手提灯本体（金，判决 / 连携里的灯具）、手炮烟（暗灰）、终结技地面尘 / 碎石（暖灰）、审判纹章（白）、怪物崩解（取怪物自身色） |

**改了哪些（去蓝 / 去紫）**：
- 普攻：光锥 / 星光、出手星芒、贯穿十字、命中星爆，紫 → 粉。
- S1 起风：水旋原为深蓝水流 + 白紫风线，改成粉雾 + 白粉；刺击线两侧潮痕和蓄光也去蓝；水旋照地光由蓝改粉。
- S2 裂潮：月牙紫 → 粉；水花 / 碎沫 / 水纹 / 内侧潮刃由蓝改粉雾。
- 裂潮余波：细新月 + 水珠，蓝 → 粉雾。
- S3 判决：光环 / 光矛紫 → 粉，根部水沫蓝 → 粉雾。
- 手炮、严律刺印、卷风 / 裂潮·三度、剑气细刺（late_shape）：紫 → 粉；剑气细刺的水珠拖尾蓝 → 粉雾。
