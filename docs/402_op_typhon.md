## 2. 本作改编

定位：**狙击 · 主输出（直接 DPS 预算 100%，偏单体）**。卖点一句话：**全队最远的一箭，专射最难缠的那一个；技能一开，每个新目标的第一箭都是重击加停顿。**

### 2.0 与现有狙击 / 远程输出的区分

| 干员 | 普攻 | 强项 | 提丰的不同 |
|---|---|---|---|
| 能天使 | 0.35 秒一发速射、多弹 | 持续弹幕、贴身清杂 | 提丰 1.8 秒一箭、单发重、穿透一线；清精英快，贴脸杂兵慢 |
| 维什戴尔 | 1.4 秒一发落点炮击 | 范围爆炸、随从开火 | 提丰没有爆炸范围，靠「直线穿透 + 控」覆盖；按「最重」选目标，而不是按最密 |
| 艾雅法拉 | 火山弹落点 | 法伤范围 | 物理、单线 |
| 流明（精二光柱） | 直线光柱 | 治疗位 | 提丰的穿透是普攻常态，不是精二 |

### 2.1 普攻「猎矢」（本作自拟）

- 选目标（**特性**，招募即有）：440 内按 **Boss → 精英 → 重型（`enemies.json heavy: true`）→ 当前生命最多** 排序取第一个；同档取近者。和现有 `elite_prio / focus_boss` 不同的是第三、四档（重型、生命最多），需要一个新的选目标档 `target: heaviest`（§3）。
- 形状：一支重箭（`shape.projectile`，速度 900，近似瞬达），穿透一线至多 3 名敌人（主目标之后每穿一名 ×0.7），击退 60（精英 ×0.3、Boss 不受）。1.8 秒一箭（÷ 攻速），不前压，站队长侧后（随行间距同能天使）。
- 帧条契约：原作 Attack_Begin 0.17 秒 + Loop 第 0.033 秒出手，**出手在 0.2 秒**，整轮 2.4 秒。`attack_timing` 用 0.9 秒一轮、出手 0.2 秒（docs/108 §2，剩下的时间播 Loop 后段的收弓 + Idle）。跑动用 `move_attack`（@1x，Spine 直转时从 Attack 轨拼上半身 + 步态脚本，同令）。
- 手动普攻（队长按住 A 方向）：朝方向射，穿透规则不变（docs/61 手动普攻口径）。

### 2.2 天赋「重如沼泥」（精一，原作天赋二）

- **她自己的任意技能生效期间**（S1 10 秒、S2 生效中、S3 箭雨中），对每名敌人**第一次**造成伤害时：伤害 ×`mire_mult` 1.6，并使其停顿 `mire_pause` 1.5 秒（精英 ×0.5、Boss 除外；原作 3 秒，本作敌人多、停顿再长就把整片怪锁死，砍半；同 `op_api` 的控制递减口径）。
- 每名敌人只吃一次（敌人字典记 `ty_mire` 标记，敌人死了自然清掉）；技能结束不清标记（原作「技能期间」每次开技能重新算，本作一局敌人流水大，记一次就够，也省得 S1 每轮重刷）。
- 为什么放精一：原作是天赋二（精二解锁）。本作「天赋」槽只有一个、精一解锁；原作天赋一「锐如兽牙」改作精一普攻机制（§2.4），这样两个原作天赋都用上，名字都不改。
- 和 S2 的配合（原作就有）：**S2 第二次起永久 → 天赋永久生效** → 进场的每个新敌人第一箭都是 ×1.6 + 停顿。这是她中后期割草的那条线（memory design-pillars：构筑 = 割草爽感）。

### 2.3 三技能（全自动，手动只有终结技 Q）

| 技能 | 技力 / 时长 | 效果 | 积木 |
|---|---|---|---|
| S1「迅捷打击·γ型」 | 8 / 10 秒 | 攻击 ×`s1_atk` 1.3、攻速 ×`s1_aspd` 1.35（原作 +45% / +45%，本作 S1 是常态技能、在场率约 55%，取低一档） | `buff_self op_atk` + `buff_self op_aspd`（现有） |
| S2「冰原秩序」 | 14 / 首次 15 秒，**第二次起永久** | 攻击 ×`s2_atk` 1.2；每次普攻射两支箭（第二支按同一排序取下一个目标，没有就射同一个，×`s2_twin` 0.8）；每支 `s2_stun_p` 30% 概率眩晕 `s2_stun` 0.8 秒（精英减半，Boss 除外） | `buff_self` + `attack_patch.shots 2`（能天使段已有）+ `st.stun chance`；**外壳新参数** `dur_first` / `permanent_after: 2`（§3） |
| S3「“永恒狩猎”」 | 24 / 10 轮弹药 | 起手标记 440 内最重的目标；普攻改为每 `s3_cd` 1.3 秒一轮箭雨：5 支箭随机落在标记周围 `s3_r` 100 内的敌人身上（敌人不够 5 个时多出来的都落在标记上），每支 ×`s3_mult` 1.1、眩晕 `s3_stun` 0.4 秒（精英减半，Boss 除外）；标记目标倒下，标记移到它 200 内下一个最重的；10 轮打完结束 | `verb.ty_hunt`（新，§3）：标记 + 改普攻 + 弹药计数；可复用能天使 S3 的「改普攻 + 弹药」外壳 |

- 技能时序一句话：S1 打常态、S2 从第二次起常开（两支箭 + 天赋常驻）、S3 是对精英 / Boss 群的爆发窗口。
- S2 永久后技力去哪：S2 不再转技力，S1 / S3 照常转。原作就这样，不另补。
- Boss 口径（docs/351）：选目标本来就是 Boss 第一；眩晕、停顿对 Boss 无效但伤害照算；S3 标记 Boss 时，箭雨落在 Boss 周围的杂兵身上，Boss 自己也吃多出来的那几支。

### 2.4 精英化（docs/91 §0.2）

- **精一 · 普攻「锐如兽牙」**（原作天赋一名，可查证）：
  - 她每射一箭叠 1 层（不管射谁），至多 5 层，4 秒没射清零（原作精一 3 秒 / 精二 8 秒，本作取中；她 1.8 秒一箭，3 秒太紧）。
  - 每层：无视敌人减伤 10%（敌人 `def` 系数与「坚甲」词缀，满层 50%，同原作精二上限）+ 对精英 / Boss 伤害 +3%（满层 +15%）。本作敌人大多没有减伤，「无视防御」只在坚岩冠兽、着铠术师、坚甲精英身上看得出来，所以补一条对精英 / Boss 的加成，让木桩上也看得见。
  - 画面新元素：箭头随层数变亮（1–4 层），**满层时箭身转黑、拖一道黑影**（权限记录「武器的黑色外观」）。
  - 预算：对杂兵 0、对精英 / Boss 平均约 +12%（爬层要 4 箭），按输出位全局 ≤ +8% 算在上限内（精英 / Boss 占她伤害约一半）。
  - 和能天使精一「穿甲连射」的区分：能天使要**连续打同一名敌人**、按每发加伤；提丰是**连续射击就叠**、换目标不掉层，加成只对精英 / Boss 和有减伤的敌人生效。
- **精二 · 普攻质变「钉影」**（本作自拟；取材 SIE-Y 模组故事「两支长矢钉在影子上」）：
  - 每第 `pin_every` 3 箭命中首个目标时，在它脚下影子里插一支黑箭（`pin_dur` 4 秒），目标定身 `pin_root` 1.2 秒（精英 ×0.5；Boss 不定身，改为减速 30% 2 秒）。
  - 黑箭立着的期间，她**每次**打中这名敌人，伤害的 `pin_echo` 40% 以涟漪扩散到黑箭 `pin_r` 90 内的其他敌人（每名每次一下，不连锁，不吃天赋第一击）。同时至多 3 支黑箭，多了最早的一支消失。
  - 动词：**钉住单体 + 伤害涟漪到周围**——docs/91 §0.4 表里没有（最近的是逻各斯「连锁」：那是跳向下一个；安洁莉娜「落点变成持续场」：那是区域本身伤害；提丰的场不伤人，只把她打在钉住目标身上的伤害分出去）。
  - 一眼认出：精二前只有一支支飞出去的箭；精二后敌群里立着黑箭，她每射中那名敌人，黑箭处就荡开一圈波纹（档案资料一「箭矢让周遭空间发生微小的波动」）。
  - 预算：单体木桩 +0（只有一个目标时涟漪没有对象，定身对木桩无意义）；怪群 +25–35%（按黑箭周围敌人数）。

## 9. 需要用户拍板的点

1. **S2「第二次起永久」照原作做吗？** 这是提丰原作招牌，永久后天赋「重如沼泥」也常驻；代价是她中后期 S2 不再转、强度高度依赖这一条。备选：每次固定 20 秒、不永久。建议照原作。
2. **精二质变「钉影」**（插黑箭 + 定身 + 打中被钉目标时伤害涟漪到周围）行不行？备选：「越远越痛」（取 SIE-Y：目标越远伤害越高 + 远处命中留空间裂纹），更简单但画面弱。
3. **萨米撑持坍缩体要不要在数据里标 `heavy: true`**（让她的特性自动先点撑持体）？这是改萨米主题敌人数据，归 Boss与怪物会话；不标的话她只会在撑持体是精英时优先它。
4. **天赋放「重如沼泥」、精一普攻放「锐如兽牙」**（两个原作天赋都用上）这样分配行吗？备选：天赋放锐如兽牙、重如沼泥并进 S2 / S3 的技能说明里。
5. 精二给全队的一条效果：①被钉影的敌人受到全队伤害 +8%；②她锁定的目标队友打它 +8%。建议①。
