## 换算规则

| 原作概念 | 本作 |
|---|---|
| 目标生命 | 水月最大生命 |
| 希望 | 源石锭（×3） |
| 可同时部署人数 | 援护干员上限（藏品加上限总共最多 +2） |
| 特种干员 / 伏击客 | 水月本人 |
| 近战单位攻击 | 伞击 |
| 远程单位攻击 | 援护干员 |
| 物理伤害 | 伞击、狙击 |
| 法术伤害 | 触手、术师、触须阵 |
| 元素损伤 | 侵蚀、神经损伤 |
| 攻击速度 +N | 挥伞速度 +N% |
| 防御力 +X% | 受到伤害 -X/2% |
| 庇护 | 受到伤害 -X% |
| 目标生命为 1 时 | 生命低于 30% 时 |
| 进阶干员 | 成长三选一 / 援护干员升级 |
| 钥匙 | 补给箱必出藏品 |
| 每次战斗 | 每 60 秒 / 每个 Boss |
| 遭诅古物 | 负面藏品 |
