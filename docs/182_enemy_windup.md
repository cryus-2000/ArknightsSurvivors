# 179 普通怪蓄力加速（claude/enemy-windup，10-28）

用户 10-28：「收割者这种小怪的蓄力也可以加速」。非精英、非 Boss 的普通怪，蓄力 / 预警 / 引信统一 × `enemy/windup_mult`（0.7），但不短于 `enemy/windup_min`（0.4 秒，手机上看得清；本来就更短的不拉长）；预警圈 / 线 / 扇形的显示与判定读同一个时长，伤害不改。1 = 关。

| 怪物 | 招式 | 改前 → 改后（秒） |
|---|---|---|
| 钵海收割者 | 镰肢劈砍（扇形预警；醒来第一下 +0.2 不变，一起缩） | 0.8 → 0.56（首下 1.0 → 0.7） |
| 深溟引痕者 | 尾刺直线前刺 | 0.55 → 0.40（触下限） |
| 深溟奠基者 | 踏地震荡（圆形预警） | 0.9 → 0.63 |
| 深溟巢涌者 | 触须爆发（圆形预警） | 0.7 → 0.49 |
| 底海滑动者 | 冲刺蓄力 `dash_wind` | 0.5 → 0.40 |
| 壳海狂奔者 | 自爆引信 `blast_fuse` | 0.9 → 0.63 |
| 普通怪额外招（swipe / pierce / pulse / volley，如凿石者贯射、浮海飘航者） | 起手预警 | 0.75 / 0.85 → 0.53 / 0.60 |

不动：精英（囊海爬行者、掠海漂移体、投嗣育母、箱形恐鱼、最后的骑士）、所有 Boss。画面：滑动者蓄力的前倾 / 自爆鼓胀的进度条改读这一次实际蓄力时长（`dash_w0` / `blast_w0`），不再按 JSON 常数算。
录像：`python tools/windup_rec.py 330 14`（改前 = `--bal=enemy/windup_mult=1`，同 seed 20 fps 原速，窗口经 godot_runner 屏外、静音）。小手感改动，不单独跑种子对照，随下一轮批跑带上。
