# 171 最后的骑士 · 分阶段方案 v2（10-28）

> 用户 10-28：「每个 boss 不同阶段是不是得做出点不同的风格来？」「招式和弹幕都可以有一些变化」；对照原作后定：「弹幕可以保留，是特色；剩下的按照你说的来」。
> 目标（用户 10-28，骑士属其他结局 Boss）：单场无认知 50–60%、18 细胞 65–75%，用时中位 90–120 秒，可输出 ≥ 35%。
> 「已做」= 分支 `claude/knight-fx-polish` 已有；「新」= 待做。

## 原作依据（PRTS「最后的骑士」）

- 卡西米尔家喻户晓的童话原型；骑士 + 坐骑罗辛南特。
- 领袖，近战物理，攻击间隔 3.5 秒：慢而重。
- 受到伤害时对来源施加寒冷 2 秒，生命低于 50% 延长到 4 秒；攻击被冻结的目标时攻击力 175%。
- 首次被击倒后释放当前波次，30 秒重生、回 25% 生命，获得 2 秒无敌，进入冲锋形态：移速 −50%，无法被阻挡。

**本作取舍**：
- 冰系弹幕是本作特色，保留，但每阶段形态不同。
- 阶段分界对齐原作：三幕起点从 33% 改到 50%（原作寒冷增强点）。
- 寒冷 / 冻结贯穿全程，重生后也在（原作反冻没有形态限制）。
- 重生外观回到冰白，靠冲锋形态的动作和招式区分。
- 招式名为本作自创（原作此敌人无招式名）。

## 一幕 · 霜甲（100–66%）

- **主色 / 场地**：霜白 + 浅青。原地面，五根冰柱（已做）。
- **主题**：引冲锋撞柱。
- **招式**（均已做）：
  - 冲锋：撞柱眩晕 2.5 秒；
  - 冰线 → 寒冷追击；
  - 长枪连刺；
  - 断潮劈击；
  - 踏冰裂阵；
  - 侧踏挑枪；
  - 贴身回旋 / 脱身跳。
- **弹幕**：冰屑扇，少、慢（150）。劈击收尾 5 片，冲锋停下 3 片。
- **节奏**：连段间隔 0.22 秒。
- **破绽**：撞柱眩晕 2.5 秒，受伤 ×2；收招破绽 2.4 秒，离得远再补最多 1.2 秒。

## 二幕 · 冰棱带（66–50%）

- **主色 / 场地**：青绿偏冷。边缘霜带往里爬；冲锋留冰面 3 秒（已做）。
- **主题**：冰面封路 + 掷枪。
- **招式**：
  - 掷枪（已做）。
  - **新 · 冰棱阵列**（掷枪变体）：长枪落地后沿投掷路径每约 60 像素立一根冰棱，1 秒后同时炸开，向两侧各射 1 发细长冰棱弹。
  - **新 · 冰面碎屑**：冲锋冰面消失时碎成一排冰屑，向两侧慢飞，每条冰面 ≤ 6 片。
  - 冰线移出二幕。
- **弹幕**：冰棱弹，细长、180，成对横射，形成「线」。
- **节奏**：连段间隔 0.18 秒（已做）。
- **破绽**：撞柱照旧；**新** 掷枪后硬直 1.0 秒。

## 三幕 · 寒潮（50% → 首次击倒）

- **主色 / 场地**：深蓝 + 雪白，飘雪，霜带加宽（已做）。
- **主题**：原作寒冷增强。
- **原作机制**：
  - **新** 寒冷条涨速 ×1.5，冻伤时长 ×2（对应原作 2 → 4 秒）；
  - **新** 冻伤期间骑士优先出「冻结重击」：近身单发重劈，对冻伤中的队长 ×1.75（原作 175%），预警 0.8 秒、范围小，躲开即可。
- **招式**：
  - 掷枪两连；冲锋折返（已做）。
  - **新 · 寒潮回卷**（三幕标志招，弹幕保留）：插枪站定 4 秒，两臂螺旋雪片弹，弹速 110。离它 90 像素以内是风眼、安全，鼓励近战顶上去。
  - 断潮劈击 → **变体 · 雪幕劈**：收尾 8 片雪片，分两层速度（120 / 170）。
- **弹幕**：雪片，小、慢、量多，旋转排布。同屏 ≤ 60 片。
- **节奏**：连段间隔 0.15 秒（已做）；回卷冷却 14 秒。
- **破绽**：回卷结束 3 秒；撞柱照旧。

## 重生 · 冲锋形态（10:00 后场地中心重生）

- **主色 / 场地**：冰白，回到原色（「黑冰」取消）。重生点放射状裂冰保留，作为重生位置提示。残柱碎尽、不再布柱（已做）。
- **主题**：原作冲锋形态：慢走（×0.5）、无法被阻挡、靠冲锋追人。
- **招式表**（只留冲锋形态专属，一阶段的三个招移出轮换）：
  - 冲锋三连 + 喘气（已做）→ **新 · 裂地冲锋**：每段冲锋停下时向前扇形裂出 3 道地缝，0.6 秒预警后依次喷冰刺（地面判定）；
  - 长枪回旋（已做）→ **变体**：环外缘留 8 枚冰锥，延迟 0.4 秒外射，缺口方向不放；
  - 冰枪封径、冻潮夹击（已做）；
  - **新** 寒冷 / 冻伤重新生效：现状重生后寒冷条只降不涨，按原作改回，用三幕的增强值。
- **弹幕**：冰锥，少（每次 ≤ 8）、快（220）、重。
- **节奏**：三连之间 0.10 秒（已做）。
- **破绽**：三连后喘气 2.5 秒（已做）；**新** 回旋后 2.0 秒。

## 重生 v3 · 冲锋形态重做（待审，10-28）

> 用户 10-28：「重生之后的攻击方式也再重新设计一下」。

**现状问题**：
- 4 招里冲锋三连占大头，冰枪封径和冻潮夹击只是辅助区域招。
- 实战里几乎一直在「冲 → 喘 → 冲」，没有第二个节奏。
- 一幕靠撞柱给破绽，重生柱子碎尽后，这类「引它撞」的玩法就没了。

**主题不变**（原作依据见上）：平时慢走（×0.5）、无法被阻挡、靠冲锋追人。重做后**每个大招一种节奏、一种破绽**，轮换不连续重复。
