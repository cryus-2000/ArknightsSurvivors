# 171 最后的骑士 · 分阶段方案（10-28）

> 用户 10-28：「每个 boss 不同阶段是不是得做出点不同的风格来？」「四个最终 boss 的修改方案出来了吗？我觉得招式和弹幕都可以有一些变化」。
> 目标（用户 10-28，骑士属其他结局 Boss）：单场无认知 50–60%、18 细胞 65–75%，用时中位 90–120 秒，可输出 ≥ 35%。
> 「已做」= 分支 `claude/knight-fx-polish` 93fcf5433 已有；「新」= 待做，本页审过再动手。

每一阶段只认一个主题：一幕斗牛撞柱，二幕冰面封路，三幕风雪弹幕，重生黑冰冲锋。招式和弹幕不跨阶段复用原样。

---

## 一幕 · 霜甲（100–66%）

- **主色 / 场地**：霜白 + 浅青。原地面，五根冰柱（已做）。
- **主题**：斗牛。引它冲锋撞柱是主要输出手段。
- **招式**
  - 冲锋：撞柱眩晕 2.5 秒。（已做）
  - 冰线 → 寒冷追击：沿冰线冲。（已做）
  - 长枪连刺：三刺，各自追踪。（已做）
  - 断潮劈击：弧斩。（已做）
  - 贴身挨打 1.5 秒放长枪回旋；累计 3.5 秒脱身跳。（已做）
- **冰系弹幕**：冰屑扇，慢速 150、少量。劈击收尾 5 片，冲锋停下 3 片。弹幕只当点缀，主压力是近身招。
- **节奏**：稳。连段间隔 0.22 秒，招式之间留空。
- **破绽**：撞柱眩晕 2.5 秒，受伤 ×2；收招破绽 2.4 秒（离得远再补最多 1.2 秒）。

## 二幕 · 冰棱带（66–33%）

- **主色 / 场地**：青绿偏冷。场地边缘结霜带，往里爬（已做）。冲锋留下冰面 3 秒，站上去涨寒冷条（已做）。
- **主题**：封路。冰面和冰棱把场地切成几块，逼玩家绕行。
- **招式**
  - 掷枪：二幕起放。（已做）
  - **新 · 冰棱阵列**（掷枪变体）：长枪落地后，沿投掷路径每隔约 60 像素立起一根冰棱，1 秒后同时炸开，向路径两侧各射 1 发细长冰棱弹。整条线像一堵会喷射的墙，两端和炸开后的空档可走。
  - **新 · 冰面冲锋**（冲锋变体）：冲锋留下的冰面在 3 秒消失时碎成一排冰屑，向两侧慢慢飞散，一条冰面最多 6 片。
  - 冲锋、连刺照旧；冰线移出二幕，交给一幕和三幕。
- **冰系弹幕**：冰棱弹，细长方向弹，速度 180，成对横向射出，形成「线」而不是「扇」。和一幕的冰屑扇形态不同。
- **节奏**：中。连段间隔 0.18 秒（已做）；掷枪冷却 8 秒。
- **破绽**：撞柱照旧；**新** 掷枪后硬直 1.0 秒，原地喘一下，冰棱炸开前近战能贴上去打。

## 三幕 · 寒潮（33% → 归零重生）

- **主色 / 场地**：深蓝 + 雪白。全屏斜落飘雪，霜带加宽（已做）；寒气圈 180（已做）。
- **主题**：风雪弹幕，这是骑士唯一的「弹幕阶段」。
- **招式**
  - 掷枪两连；冲锋后折返再冲一次。（已做）
  - **新 · 寒潮回卷**（三幕标志招）：插枪站定 4 秒，以自身为中心放两臂螺旋雪片弹。旋转慢、弹速 110，每臂每 0.12 秒 1 发。离它 90 像素以内是风眼，弹幕从这里外起射，贴身反而安全，鼓励近战顶上去。结束后接 3 秒破绽。
  - 断潮劈击 → **变体 · 雪幕劈**：弧斩收尾的 5 片冰屑换成 8 片雪片，分两层速度（120 / 170），落成一条前后错开的弧带。
  - 连刺、冰线照旧，频率下调，让位给回卷。
- **冰系弹幕**：雪片，小、慢、量多，旋转排布。和二幕的直线冰棱、一幕的冰屑扇都不同。同屏上限 60 片，计入敌弹 < 20 指标时按时间平均。
- **节奏**：快。连段间隔 0.15 秒（已做）；回卷冷却 14 秒，全阶段至少放一次。
- **破绽**：回卷结束 3 秒；撞柱照旧（冰柱仍在）。

## 重生 · 冲锋形态（10:00 后在场地中心重生）

- **主色 / 场地**：黑冰，钢蓝暗色 + 白裂纹。重生点一大片放射状裂冰（已做）。残柱全部碎掉，不再布柱，霜带转暗（已做）。
- **主题**：黑冰冲锋。慢走快冲，冲锋才是威胁。
- **招式**
  - 冲锋三连 + 喘气（已做）；长枪回旋（已做）；冰枪封径、冻潮夹击（已做）。
  - **新 · 黑冰裂地**（冲锋变体）：每段冲锋停下时，脚下向前方扇形裂出 3 道地缝。0.6 秒预警后地缝依次喷出黑冰刺（地面直线判定，不是弹）。三连冲完，场上留下一片交错的裂缝网，持续 2 秒后消失。
  - 长枪回旋 → **变体 · 黑冰回旋**：冲击环外缘留下一圈 8 枚黑冰锥，延迟 0.4 秒向外射出，环的缺口方向不放。
- **冰系弹幕**：黑冰锥，暗钢蓝带白芯，少（每次 ≤ 8）、快（220）、重。和三幕的雪片相反。
- **节奏**：冲锋三连之间 0.10 秒（已做）；走路速度 ×0.5（已做）。
- **破绽**：三连后喘气 2.5 秒（已做）；**新** 黑冰回旋后 2.0 秒。

## 落地顺序与验收

1. 二幕：冰棱阵列 + 冰面碎屑 + 掷枪后硬直。
2. 三幕：寒潮回卷 + 雪幕劈。
3. 重生：黑冰裂地 + 黑冰回旋。
4. 每批做完：录一段该阶段 mp4，跑骑士单项回归，推分支。三批做完请测试台（docs/170）复测，按上面的目标判。偏离目标只调旋钮：新招伤害系数、回卷时长、裂地数量。

**数值约束**：
- 新弹幕单发 = e.dmg × 0.35 × 冰类系数（同冰屑），受保护规则截；
- 新招都带完整预警（主色），红 / 洋红只用于危险边缘；
- 低画质只降颗粒、不降判定。
