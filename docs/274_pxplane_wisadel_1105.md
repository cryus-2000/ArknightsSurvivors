## 4. 实现

- `game/scripts/render/fx_pxplane_wd.gd`：维什戴尔一节（单独文件）。事件 → 件表；运行时逐格画炮弹 / 额外弹、落点准星、四角括号、残影标记、引线；炮弹进 2.5D 排序（按地面投影 y）。
- `fx_pxplane.gd`：`IDS` / `METAS` 加维什戴尔（键前缀 `wd_`），`ev / draw_floor / draw_over / sort_items / draw_sorted` 各一行转到 `_wd()`；`owns_id` 对维什戴尔只在 `fx/px_plane = 1` 时为真。
- 只画钩子（`_FXR.ev`，没接管时第一行返回）：`seg_wisadel` 出膛（`_h4_fire` / 魂炮 / S2 阶段炮）、爆炸画面（`_h4_boom_visual` 接管时只发事件，**顿帧与音效照旧**）、合并小火团（`_h4_dup_puff`）、残影生成、续燃吸附；S1 强化炮在炮弹字典里记画面专用键 `pxk`（玩法不读），爆炸前后在 `wd.pxk` 暂存；`vis_growth` 额外弹命中、接管时不画通用弹体；`late_shape` 扩散 / 连锁；`skill_link` l_wisadel 残影 / 殉爆（接管时不画原来的椭圆 / 环 / 岩块）。原来的 `_wfx` 粒子接管时本就不画（`character.draw_pfx`），`_wspr` 帧条（Codex 炮击帧条、魂炮炮口烟）只在爆炸画面函数里，已整段跳过。
- 帧条：`game/art/fx/pxp/pxp_wd_*.png`（90 张，约 0.6 MB）+ `game/data/pxp_wisadel.json`；重新生成 `python tools/pxplane_bake_wisadel.py`（图形在 `tools/pxplane_wisadel_art.py`），之后 Godot `--import` 一次（GCP 上自动）。颜色组 `data/fx_pxplane/wisadel.json`。
- 送审 GIF：`python tools/pxplane_gif_wisadel.py [--only atk,s1,...]`。
