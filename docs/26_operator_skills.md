# 26 · 干员三技能表（契约 v2.1，2026-09-25）

> 用户决定：水月不再是主心骨，而是 8 名可选开局干员之一，所以回到"一个角色三个技能"。
> 规则（docs/23 §4.2 v2.1）：每名干员 **普攻 + 3 个自动技能 + 1 个天赋**；S1 招募即有、S2 精英化一解锁、S3 精英化二解锁；三个技能同时充能、生效中的不充能，同时就绪时先放 S3 > S2 > S1。
> **v2.2（2026-09-25，用户决定）**：干员可以有**至多 1 个手动技能**（技能 JSON `"mode": "manual"`）：照常充能，但充满后不自动释放，等玩家按 Space / J（手柄 Ⓐ / Ⓧ），入口仍是 `doctor.try_manual_skill()`。目前只有**归溟幽灵鲨 S2「求生之渴」**，定位为保命技能（10 秒内博士不会倒下）。HUD 在该技能图标上方标出按键，就绪时外圈呼吸发光；未就绪时按键会提示「充能中 / 生效中 / 暂时离场」。批跑机器人在博士生命 < `balance.json bot.manual_hp`（30%）时替玩家按下；图鉴演示与精英化演出充满即放。
> 定位分层：S1 短充能循环用，S2 中等，S3 是精二的大招。数值只做了粗调，统一平衡放 P5。
> **永久型技能**（JSON `permanent: true`，2026-09-25 用户建议）：像「暖光」这种临时增益不再反复开关——精一解锁后充能一次释放，之后**永久改变攻击方式**，环显示「·永久」并不再充能。首批用在铃兰 S2、凯尔希 S2。

## 数据格式

```json
"attack": {"name": "…", "desc": "…"},
"skills": [
  {"name": "S1", "en": "…", "sp": 10, "desc": "…"},
  {"name": "S2", "en": "…", "sp": 16, "desc": "…", "dur": 6.0},
  {"name": "S3", "en": "…", "sp": 26, "desc": "…", "icon": "skill_s3"}
],
"talent": {"name": "…", "desc": "…"}
```

- `Character.validate_operator()`：attack + 恰好 3 个 skills（都 auto）；`skill_unlocked(i) = elite >= i`。
- 充能：`character.gd charge_skills(dt)` 三个技能并行充能（`sp[i]`），`skill_active_left(i) > 0` 的技能不充；返回就绪的最高序号，干员 `start_skill(aim, i)` / `spend_sp(i)` 后在 `_release_skill()` 按 `cur_skill` 分派。
- 精英化节点 `advance()` 后自动排队解锁演出（`_elite_show`：新技能 + 精一天赋）。
- HUD 右下编队栏（2026-09-25 改版）：每名干员一列，底部头像（环 = 已解锁最高技能充能），上方三枚小技能图标（环 = 各自充能 / 生效倒计时，未解锁灰显，永久型打勾，海嗣化紫点，悬停显示技能名与解锁阶段）；开局干员在最左。Tab 攻击栏 = 开局干员三技能 + 天赋。
- 排异反应（结局四）通用化：随机一个已解锁技能海嗣化（技能强度 +40%、充能 +30%、博士最大生命 -10），HUD 环上紫点、Tab 标「排异」。
- 下线：`skill_lv`、技能进阶卡、`data.gd` 的 SKILLS / SKILL_ADV / SKILL_P / GROWTH / EVO、水月的潮刃 / 群触路线与路线成长卡、水刃 / 触手桩 / 巨触 / 触须阵、`--evo=` 等测试参数。相关藏品属性（`mizuki_umbrella_*`、`mizuki_tentacle_*`）保留。

### 流明（2026-09-25 定稿，第二批唯一已定技能的干员）

定位：**不治血条，治环境**。凯尔希 = 回血 + Mon3tr 输出，塞雷娅 = 回血 + 护卫，铃兰 = 跟随博士的减速 / 易伤光域；流明是唯一操作灯火、驱散全部负面状态（侵蚀、神经损伤、溟痕、黑潮圈外）的干员。治疗量故意低于凯尔希（0.67%/秒 对 1%/秒）。灯塔固定不动，带来"守塔 10 秒"的走位决策。与深蓝 / 低灯火流派天然对冲，这是有意的 Build 分歧。

接入点（`lumen.gd` + `data/characters/lumen.json`，参照凯尔希 / 铃兰）：

- 现成挂点：`g._heal()`、`g.nerve = 0.0`（凯尔希 S1 先例）、`g.corrode_pool`、`g.lamp` / `g.lamp_cap`、数值键 `light_decay` → `lamp_decay`（S2 永久型走一句 `stats.add`）、`_lamp_sp()` 已在充盈时给全队 +30%（天赋的额外部分在自身 `charge_skills` 覆写里做）、灯塔道具走 `extra_bodies()` / `draw_auras()` / `draw_fx_add()`、光爆走 `g._hit()` + `g._damage()` + 敌人眩晕字段。
- `game.gd` 要动的三处：① `_lamp_r()` 与光源视觉半径加一个乘数（S2）；② `_damage` 的灯光 +25% 判定加 `e.lit` 字段与每帧衰减（参照 `aura_weak`）；③ `_update_status` 的溟痕与缩圈结算加"圣域"检查——建议做成干员侧挂点 `sanctuary() -> {pos, r}`，由 game.gd 询问编队，供以后复用（同 `dmg_taken_mult()` 模式）。顺手把三处内联加灯火收拢成 `_lamp_add()`。
- 原作对应（行医 Therapist）：普攻 ← 特性"大范围治疗"；S1 净化之光 ← In Downpour, Grace（蓄力版驱散负面）；S3 指引灯塔 ← This Lantern Undying（提灯）；天赋余晖 ← An Everyman's Wish / Quick Fix（被治疗者获得状态抵抗、友军受负面时自动治疗）。本作技能名保留自拟。

### 第二批其余四人（2026-09-25 定稿，用户已确认）

原作资料来自 arknights.wiki.gg。四人都保留原作的核心机制，再翻译成"博士唯一受击、干员不死"的规则。
