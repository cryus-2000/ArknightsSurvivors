# 72 干员初始数值审计（10-12）

用户问（10-12）：「现在干员的初始数值填写的有没有问题，是否合理和平衡」。本文只读审计，**没有改任何游戏文件**；下面的数字建议都只是建议。

底：origin/main 41e6c9c0。数据来源：`game/data/characters/*.json`（`base` / `leader`）、`doctor.json`、`balance.json operators`、`screens/initial_stats.gd`；
云端结果分支 `cloud-results/*`（见 §3 口径）；本机 6 局 headless（§2.2）。

## 0. 结论先看

- **录入错误 / 与规则不符（建议修）**
  1. 星熊 `leader.armor 3.5`：docs/23 规定减伤 = 原作防御 / 150、**上限 3**。她是全员唯一超上限的，加上 25% 格挡，有效生命（按职业系数折算后）比原作生命更高的斯卡蒂还高。
  2. 安洁莉娜 `leader.max_hp 100`：原作生命 / 防御 / 法抗（1484 / 134 / 20%）和铃兰（1480 / 128 / 25%）几乎一样，铃兰 105、浊心斯卡蒂 105、逻各斯 105，只有她 100。有效生命 107，和能天使并列全员最低，看起来是填错了。
  3. 能天使 `leader.max_hp 105`、法抗 0：按 docs/23「减伤 / 法抗越高，生命越低」，她没有法抗，生命应该比同档有 20% 法抗的远程高；现在有效生命 107，全员最低。
  4. 局内属性面板 / 博士卡把护甲按整数显示：`stats_panel.gd:118 / :368` 用 `int(g.armor)`，`doctor.gd:357` 是 `"减伤 %d → %d"`。流明 0.5 显示成 **0**，凯尔希 / 维什戴尔 1.5 显示成 1，水月 / 艾丽妮 / 推进之王 2.5 显示成 2，星熊 3.5 显示成 3；「硬化」卡显示「2 → 4」，实际是 2.5 → 4.5。选人编队页（`title.gd:2541`）用 `snappedf(…, 0.5)`，是对的。
  5. 有几个 JSON 参数代码里没读，改了不生效：水月 `swing_arc` / `tentacle_mult` / `awaken_swings`（代码写死 75°×2、`stat_defs` 0.6、唤醒计数另算）；逻各斯 `requiem_bonus`（`combat.gd:972` 写死 ×1.15）、`glyph_max`（`logos.gd` 常量 `RESIDUE_MAX 6`）。现在的值和写死的值一致，所以**眼下不影响数值**，只是旋钮是假的。
- **选人页显示容易误读（initial_stats.gd，不是数值错）**：浊心斯卡蒂显示「攻击 4」，但声浪一次最多打 16 个，本机实测开局 2 分钟她当队友（精零）每秒 34 伤害，比同局精零的艾雅法拉 / 维什戴尔高；艾丽妮（每次 2 刺）、铃兰（每次 2 发）、水月（附带触手）、维什戴尔（附带余震）只显示单段伤害，看起来比实际弱一半左右。凯尔希显示的是 Mon3tr 的攻击、间隔和范围（有标注），德克萨斯的「攻击范围 140」其实是冲刺距离，能天使「间隔 0.35 秒」是对的。
- **平衡（是判断，不是错误）**：已有数据的 12 名主控中，**德克萨斯偏弱**（标准 42% / Ⅷ 28%，n=56），每分钟承伤 150 多，是全员最高，问题出在打法（冲刺把主控带进怪堆），不是基础数值低；**能天使 Ⅷ 偏弱**（39%）；**安洁莉娜 Ⅷ 偏弱**（46%）。**偏强**：水月 / 塞雷娅标准 94–100%、斯卡蒂 Ⅷ 88%（n=16，标准误约 ±12）。其余在 50–70 区间内或贴着区间。
  非开局池的 6 名（艾丽妮、乌尔比安、推进之王、幽灵鲨、逻各斯、流明）**没有近期当主控的云端数据**（最后一次是 9/29 普通机器人的 solo），没法下胜率结论，见 §5 的补测命令。

### 4.3 平衡判断（按职业定位和 50–70 目标）

- **德克萨斯偏弱，但不是基础数值低**：单体 23.6、EHP 125 都在中游；她的承伤 / 分 156，是其他主控的 1.5 倍，存活 8:23 / 7:28 全员最短。原因推测是普攻 / 天赋冲刺把主控带进怪堆。先动打法类旋钮（冲刺期间短暂无敌，或主控时不自动冲向敌群）比加生命更对症；只动数值的话，`leader.regen` 1.3 → 1.6（与斯卡蒂同档）、`max_hp` 118 → 122。
- **能天使 Ⅷ 偏弱（39%）**：输出不低（单体 38、占比 44%），死得早（9:26）；与 #3 一起把生命补到 110 是同方向的。docs/61 §14.3 已记录「加伤害不加胜率」。
- **安洁莉娜 Ⅷ 46%**：标准 67% 正常；#2 把生命补到 105 大概能补回几个点，不需要动输出。
- **星熊**：胜率 69 / 60 在区间内，承伤 / 分 53 是全员最低（格挡 + 3.5 减伤）。#1 修回 3.0 后预计仍在区间内；修了以后应补一轮 b3i-hsg-lead 复测。
- **浊心斯卡蒂**：53 / 51 贴下沿，按辅助定位可以接受；她当主控时的占比（39%）比「辅助」的直觉高，是领唱 + 群体声浪带来的。
- **偏强（开局 7 人）**：水月标准 94%、塞雷娅标准 100% / Ⅷ 81%、斯卡蒂 Ⅷ 88%。n=16 的噪声大，但早些时候 n=24 / 52 的批方向一致（水月标准 96%、斯卡蒂 Ⅷ 78%）。这三人主要靠打法（水月法抗 30% + 大扇形；塞雷娅减伤 3 + 治疗；斯卡蒂单体 57 + 回复 1.6）而不是哪一个数填错。按用户「标准档不收紧、收紧只用不给奖励的旋钮」的口径，先不动；如果要收，最小的一刀是斯卡蒂 `leader.regen` 1.6 → 1.4（与推进之王同档）。
- **远程三人 Ⅷ 在当前口径刚好 50%**（维什戴尔 / 艾雅法拉 / 铃兰），10-11 早些时候的批（停刷前，且隔了几次其他改动）是 23–38%。较新的批已经回到下沿，但 n=16 只够看方向，先不动，等下一轮 starts 批确认。
