# Boss 招式与密集弹幕（2026-09-27）

## 已实现

10 类 Boss 各增加两种招式，保留原招式及阶段机制；塑路者强化版沿用同一骨架和招式。伊莎玛拉人形继续治疗海嗣、不可索敌，伊祖米克学习阶段保持原逻辑。

| Boss | 新招式 |
|---|---|
| 圣徒卡门 | 交错速射、压制散射 |
| 圣徒伊比利亚 | 裁决齐射、双翼弹幕 |
| 塑路者 | 甲刃重劈、碎壳刃波 |
| 接潮主教 | 交错潮环、追潮落柱 |
| 接潮蔑死体 | 双爪交斩、裂潮刃波 |
| 接潮斥亡体 | 交错连斩、掠海飞刃 |
| 偏执泡影 | 偏执涡流、泡影弹幕 |
| 最后的骑士 | 寒锋刃雨、长枪回旋 |
| 伊莎玛拉（敌对形态） | 腐潮旋流、棘鳍刃潮 |
| 伊祖米克（解读阶段） | 解读旋涡、潮汐坠落 |

中期扇射每排 7–13 发、最多三排；最终环弹基数 32–36 发、三波错位，二阶段非刃弹每排再加 4 发。环弹跳过约 44 度扇区，实际约 30–35 发/波，黄线标明缺口方向；弹速 300–460 世界像素/秒。所有弹幕使用原有真实受击与 Boss 保护，不用装饰粒子冒充弹幕。

新招式在旧招式的空闲窗口释放，预警至少 0.9 秒，波间隔 0.6 秒，整段后休整 1 秒。近战范围外切换刃波；圣徒弹药消耗与可打断装填继续生效。死亡、假死、眩晕、破绽或中立状态不会结算新招式。新弹幕发射时检查单 Boss 活弹 120、全场活弹 240 阈值，避免新招式无限叠加。

## 分层与素材

配置在 enemies.json 的 patterns；enemies/boss_patterns.gd 负责调度与发弹，boss_ai.gd 仍是公共预警和伤害入口。render/vfx.gd、world.gd 负责特效库复用与缺口标记。使用 fx_slash_arc_rose、fx_slash_heavy_steel、fx_water_splash，敌方刀光保留洋红危险识别，不受友方降噪影响。没有新增或改写原始图片。

## 验证

boss_variety_test 使用实际 BossAI 驱动 10 类 Boss，检查两种新增招式都能释放；覆盖三波环弹、真实密度、缺口、速度、弹量阈值、死亡/假死/破绽取消及远距离刃波。伊莎玛拉原四招回归仍验证其完整轮转，允许新招式穿插。图形预览保存在本机 build/ea_boss_dense_ring.png 与 ea_boss_blade_volley.png。
