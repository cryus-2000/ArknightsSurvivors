# 212 Boss 体检（11-01）：击杀用时、按招式承伤、骑士弧斩命中率

用户 11-01 想看「最新的 Boss 试炼用时和造成的伤害，需不需要调整」。本文只给数据与建议，**不改数值**，调不调由协调人和用户定。

## 0. 方法

- **代码**：integ-1101 86e8c1bc2 + 骑士分支 claude/boss-knight-1101 + 演练记录 claude/boss-trial-log-1101。体检专用开关在 claude/boss-diag-1101 d1ea6283d，**不合入**：`--diagtrial` 起一局演练，`--diagbot` 让机器人打，结束时打印 `run.trial`。
- **跑法**：Boss 演练（成品分队 6 组 × 种子 1–3）、机器人 expert、观察模式（不会倒下）、上限 300 秒。每组 Boss 18 局，共 162 局。云端结果在 `cloud-results/bdiag2-1101`。
  - 演练里没有杂兵分火，用时比正常局短。
  - 中期 Boss 另看正常局：gv6 两档，每档 168 局，同一个机器人。
- **数据**：`docs/212_data/trial_diag.txt`（一局一行，`run.trial` 格式）；汇总脚本 `agg_trial.py` → `agg_trial_out.txt`。
- **口径**：
  - 「承伤 %/分」= 承伤占最大生命 % ÷ 战斗分钟，同 docs/201 §8.3。
  - 「命中 / 出手」= 打中队长的次数 ÷ 有伤害预警的段数。冲刺无敌时不算命中。
  - 「几乎打不中」的招，多数是因为机器人按预警走位躲得很准，不等于真人也打不中。

## 4. 建议（待定，先不改）

1. **中期 Boss 偏短**：四组正常局 41–69 秒，演练 28–44 秒，都在 60–90 之下，伊比利亚最短。建议
   - 先把 `hp_mid` 1.3 提到约 1.7（中位用时 ×1.3 → 正常局约 55–90 秒）；
   - 或者只给塑路者 / 伊比利亚 / 卡门单独加血（主教双 Boss 已在区间下沿）。

   血量不给奖励、不影响掉落。要配一轮云端胜率配对（中期 Boss 主要压 3–7 分钟段）。
2. **骑士弧斩成了骑士最大的伤害来源**（40%，每下 25% 最大生命）。对不冲刺的玩家偏狠，对会冲刺的玩家正好。可选
   - 第二道伤害 ×0.7，或者冲刺躲过第一道后第二道不再追踪，二选一；
   - 用户这次没对弧斩提意见，建议先观察真人记录，现在有试炼记录了。
3. **中期 Boss 的有名招式对机器人 0 命中**：塑路者冲撞 / 震地、卡门狙击、伊比利亚手炮。伤害全靠接触和敌弹，这些招只是走位提示，威胁感偏弱。若要提升，优先缩短塑路者冲撞和卡门狙击的锁定时间，原则同骑士弧斩：缩前摇或加预判，不加伤害。
4. **伊莎玛拉承伤 76% → 126%/分**：10-31 之后涨得最多，主要来自歌声围拢 / 歌声涟漪的多段命中。150 秒内胜 13 / 18，在可接受范围，暂不动。真人如果嫌太痛，先看歌声涟漪的段数。
5. **最终 Boss 的长尾**在斯卡蒂 m0 / 凯尔希 m0（输出偏低），属于干员平衡，交数值会话处理，不改 Boss 血量。
