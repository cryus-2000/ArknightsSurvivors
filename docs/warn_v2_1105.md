# 普通怪预警收细（任务单 11-05）

基于 `origin/claude/integ-1105` 的 `e80a39eb2`。独立分支 `codex/warn-v2`；默认 `render/warn_v2=0`，未认可前不启用。

开启后，普通怪的圆、直线和扇形预警统一为灰紫色：常态一美术像素轮廓，最后 0.3 秒两美术像素轮廓并短闪、渐亮。内部固定 0.045 透明度，不叠增长内圈、光环、结算整面白闪。直线保留末端方向尖角。前刺也进入同一颜色路径，不再沿用红色填充或光学危险红。

精英、Boss、精英小队（squad / cross_elite）、必须冲刺、缺口环、无伤害生成预告保持原路径。原本静默的普通怪 shot / extra_volley 保持静默，不重新加预警。打不到队长的预警沿用原 dim 系数。只读 owner、形状和计时，不写预警、伤害或随机数。

## 实现与验证

- `render/minion_warn.gd`：归属、最后 0.3 秒信号及几何绘制；从 telegraph_draw 填充和 world 轮廓两个入口接入。
- `render/warn_v2` 缺省 0；fill 数值强制限制在 0–0.15。普通怪灰紫 RGB=(0.66,0.62,0.78)，避免危险红、敌弹青及结晶暖金。
- `tests/warn_v2_contract.gd`：开关关闭、精英/Boss/特殊躲法排除、最后时窗边界，短本地自检通过；无 SCRIPT ERROR/Parse Error。退出 ObjectDB/resource 提示另保留，不宣称全部日志无提示。
- `tools/warn_v2_capture.py`：正常 seed 11，逻各斯/德克萨斯/铃兰，8:00 起等待第一条屏内有效普通怪预警；冻结同一局，实际切 Bal 配置 0/1。截图记录精确时间与在场预警，未伪造或补画预警。走共享 godot_runner，静音离屏，不写存档。
- `tools/warn_v2_metrics.py`：按 docs/221，敌方掩码=no friend 与 no friend+no foe 的差；被改色=敌方掩码与完整图对 no friend 差异的交集，阈值 0.06，ROI=(180,150)–(1100,560)。这是单帧回归，不代替多局可读性评价；墙钟 shader 的差异仍可能带来噪声。

截图与数值在本地 `build/warn_v2/`；交付拷贝由主任务汇总到 Claude outputs。正式 `check.py --auto --jobs 3` 和同种子开关 TRACE 由主任务的云端会话统一执行；本地未跑批量或 TRACE，未将代码静态不写 rng 冒充实测等价。
