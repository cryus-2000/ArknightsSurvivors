# 普通怪预警：固定红边与内部计时扫线（11-05 修订 5）

分支 `codex/warn-v2`，基线 `e80a39eb2`。默认 `render/warn_v2=0`，关闭精确走旧绘制路径。按 CLAUDE_REVIEW 小改，旧 revision_3/4 保留但不作为本轮证据。

## 产品变化

范围始终由完整固定外边界表示，计时独立在内部显示：line 横截线由发起点向末端推进；cone 半径线从扇形一侧扫至另一侧；circle 仅一个内部细圈随时间向固定外边界推进。**移动线仅表示倒计时，不是新的判定范围**。无填色、无白预警，仍用沉朱红和珊瑚红，末0.3秒红边加粗到4世界像素。扇形外沿常态恢复2世界像素，与其他轮廓相同，不再常驻粗边。

`dim`（当前不会打到主控的普通预警）只画一条2世界像素（1美术像素）淡红线，alpha=.4，无暗衬、计时、方向标和临击强调。主要危险仍用窄暗衬。内部填充恒0，已无非零填色参数，任意多个重叠均不会累计内部底色；不宣称实现了非零透明度全局遮罩封顶。轮廓和扫线相交仍可能互相遮挡。

精英/Boss/小队/must_dash/缺口环/无伤害预告保持旧路径；quiet shot等保持静默，done先被旧入口过滤。读取原计时，不改玩法、伤害或RNG。外部late_read冲突交协调人处理。

## 验证

短契约包含开关、精英及小队排除、末段时窗、零填充、三种内部计时几何，以及dim恰好一次alpha<=.45的2px绘制（没有暗衬或计时）。已通过；最初新增断言把Godot orthogonal向量方向写反，修正测试预期后通过，无产品修补掩盖。

动态生产draw夹具 `game/tests/warn_v2_shapes.tscn -- --warn-motion --warn-shot-dir=<绝对路径>`：30fps、90帧；上单个、下错时重叠、右精英原样，明暗块检查对比。这是受控夹具，不是自然实战。`tools/warn_v2_capture.py --perf` 则在实际seed11局8:00后等待有效普通预警，冻结同局，拍摄开关0/1；之后关闭vsync、解除fps限制、每轮20帧预热+90帧采样，0/1交替8轮。重绘同场景，记录wall frame ms，包含驱动和系统调度，不是整局模拟性能或GPU独立耗时。该场景仅3条屏内普通预警，不能代表几十条警告的最坏负载。单次测量不能夸大噪声级净差。
