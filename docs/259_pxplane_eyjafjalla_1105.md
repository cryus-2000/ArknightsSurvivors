## 3. 实现

- `game/scripts/render/fx_pxplane.gd` 末段「艾雅法拉」：`_ev_ey`（事件 → 一次性件）、`_ey_floor`（贴地层 + 熔岩池 / 熔池 / 熔蚀 / 影子 / 热边）、`_ey_sort_items`（弹体、熔岩泡、灼烧火苗，读玩法状态，只读）、`_ey_draw_rt`、`_ey_draw_raw`。`IDS` / `METAS` 加艾雅法拉（帧条键前缀 `ey_`）。`_step` 加「跟着施放者本人走」（`fop`）。
- 钩子（都只画）：`seg_eyjafjalla` 出手 `ey_fire`、法术弹爆点 `ey_boom`（atk / s1 / s2，三重咏唱在 `_hw5_lob_land` 发 tri）、抛射熔岩落地 `ey_splash`、火山落点 `ey_s3`、二重咏唱起手（cast instant 不走 data_operator 的技能事件，在 `hw_instant` 补发 `skill`）；二重咏唱强化弹在子弹字典里记画面专用键 `pxs`（玩法不读，只在接管时写）；`vis_growth` 额外弹命中 `ey_xhit`、接管时不画通用弹体；`late_shape` 连锁 `ey_chain`；`skill_link` 熔岩 `ey_link` / `ey_link_hit` / `ey_link_burn`（接管时岩块、影子、冲击环、溅落斑、颗粒都不生成，伤害与顿帧照旧）；`combo.gd` 出手 `ey_link`、落点 `ey_combo`、熔岩持续画面接管时不画。
- `magma_projectile.gd` 的 `material_on`：接管时返回 false，原材质颗粒、熔岩帧条、落点帧条都不生成（这些全只用 `g.vrng`，玩法随机数不动）。
- 帧条：`game/art/fx/pxp/pxp_ey_*.png`（118 件，约 2 MB）+ `game/data/pxp_eyjafjalla.json`；效果源 `tools/pixelfx_fx/fire/ak-eyjafjalla-pp.js`（用库里的 `Particles` / `Bits` / `fire/fireball`；半透明一律按固定噪声成团消散，在本文件里把画布的 Bayer 网点换掉）；重新生成 `python tools/pxplane_bake_eyja.py`（需要本机 pixelfx 库 `build/pixelfx`，缺的 `.png.import` 按模板补）。颜色组 `data/fx_pxplane/eyjafjalla.json`。
- 出图：`tools/pxplane_shots.py --op eyjafjalla`（技能招对齐到技能事件之后第一次爆点事件；连携三栏按 `PXPLOG ey ey_link` 对齐）；原作一栏本机拼：`python tools/pxplane_refcol.py --op eyjafjalla --ref "Claude outputs/eyjafjalla_ref" --cmp <GCP 下载目录> --out <交付目录>`。
