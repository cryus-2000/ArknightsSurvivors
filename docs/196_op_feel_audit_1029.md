## 1. 方法

- 探针 `game/scripts/run/feel_probe.gd`（`--feelprobe` 才建，普通局记录不变）：只看队长。
  - **贴身**：身边有敌人（距离 < 敌人半径 + 22）的时间占比；**被围**：90 内 ≥ 4 只。**贴身时承伤占**：总承伤里发生在贴身时的比例。
  - **自身走不动**：机器人想走、不是被控制、实际位移 < 移速 30% 的时间占想走时间的比例（自身动作 / 技能锁步）。
  - **被带位移**：没冲刺却位移 > 1.6 倍移速的秒数（技能 / 普攻把队长带着走）。
  - **技能冒险**：队长发动技能后 2 秒承伤 ≥ 发动前 2 秒 ×2 且 ≥ 5% 最大生命的比例。
- 批跑：20 人各单人开局（`--op`，其后机器人自己招人），高手机器人，`--tier=0 --tide=0`，seed 1–6，本机 120 局。原始数据 `build/feel_audit/`（不进 git）。
- 前摇 / 全长读 `sprites.attack.attack_timing`；顿帧 = json `hit_feel`（heavy / melee；空 = 普攻命中无顿帧，docs/141）。
- **口径提醒**：每人 6 局，胜率差 < 10 点不下结论（docs balance-method）；排查只看「同一机器人下谁明显偏离」。整体胜率偏低（20 人里最高 2 / 6）：integ-1029 头比 10-28 的 eysu 批跑（维什戴尔 62%）难不少，归今晚合包后的统一校准，不在本表下结论。
- 最终 Boss 输出：6 局里打到最终 Boss 的只有少数几局（胜局），样本不够，本轮不出结论。

## 3. 最差几名：原因与建议（待定，未改）

### 3.1 推进之王：存活最短（168 秒，6 局 5 局死在第一个 Boss 之前）

- 数据：被带位移 0.91 秒/分（其余人 0.15–0.21，乌尔比安 0.37），技能冒险 23%（最高），自身走不动 1.4%（最高），2:00 时每 30 秒承伤 101（并列最高）。
- 原因（读数据 + json）：锤击射程 92 要贴脸；「跃空锤」+ 分支「再跃」（机器人选 `leap`）落地后「再跃向下一群敌人」——队长被带着跳进下一群怪；「碎颅击」攻速 −25% 让站桩更久。
- 建议（二选一，先报）：① 她当队长时「再跃」改成往回跳（落点取离怪群远的一侧）或不位移只出地裂；② 当队长时锤击命中给轻击退 / 小概率眩晕（同艾雅法拉 / 铃兰的开局自保口径）。

### 3.2 歌蕾蒂娅：贴身 9.5%（全员最高，中位 2.7% 的 3.5 倍），贴身时承伤占 65%（最高），存活 222 秒

- 原因：普攻每 1.1 秒把 240 内最远的敌人钩来，一线上至多 2 名敌人拖到「身前 110」，到位眩晕 0.9 秒；她当队长时 = 每秒把两只怪拖到自己脸上，眩晕结束就贴身咬。与乌尔比安之前的问题同型（10-28 修法：拉回打断 + 眩晕 + 沉默）。
- 建议：① 当队长时落点 `hook_front` 110 → 170–180（拖到身前但留出一步）；② 或套乌尔比安的 `pull_cc`（打断预警招 + 到位后沉默 1 秒）；自爆 / 精英不拖到身前、只拖半程。

### 3.3 流明：6 局 3 局死在 2:00 前，存活 230 秒

- 原因：普攻是治疗 + 每秒一发小光弹（22 攻、溅射 60%），当队长时自己清怪最慢（2:00 击杀 167，全员倒数第二）；死因以近身撞为主（`contact_tracer` 4 局）。和艾雅法拉 / 铃兰同一类「后排当队长没有自保」。
- 建议：按艾雅法拉 / 铃兰的口径给开局自保（光弹命中小减速或「沐雨」附带推开），不改治疗量；或干脆不进开局池（她现在本来就不是开局干员，只在换队长时出现——那就只记录不改）。

### 3.4 浊心斯卡蒂（282 秒）、艾雅法拉（249）、铃兰（318）

- 浊心：攻击 4 的声浪 + 领唱 25.5%，当队长时输出偏低；不在开局池，同流明，建议只记录。
- 艾雅法拉 / 铃兰：今天已做 C+E，偏差留给统一校准（10-29 协调人定），本轮不再动。

### 3.5 维什戴尔：自身走不动 0.9%（第二高）

- 炮击前摇 0.21 + 全长 0.95（全员最长），走射时有停顿；占比小，胜局并列最高，**不建议改**。
