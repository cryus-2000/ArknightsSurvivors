# 170 · 伊祖米克：分幕连携、专属弹幕与拦截通道（2026-10-27）

分支 `claude/boss-izumik-4931b3`（起点 `codex/boss-fx-rework` 72f41c3c7），未合入 main。用户 10-27 要求每只 Boss 分别改特效、招式间连携、招式数量，并要有「打 Boss 的感觉」；协调人转达更正：东方 Project 只是例子，**不照搬符卡制度**（不做符卡名横幅、不按符卡清屏）。本文按这个口径：弹幕有图案、有规律可学、可读、有节奏，Boss 存在感强，用海嗣 / 伊祖米克自己的语言表现，阶段沿用现有三幕。

连携组与新弹幕全部是**本作改编**，不是原作技能。原作依据只有：学习（召唤子代）、吸收子代计数强化并回血、分享（对我方全体溅射）、震撼（75 / 50 / 25% 强制）。组名只在文档、测试、录像标题里出现，不上游戏界面。

## 1. 结构

阐释阶段（phase 2）出招全部由 `izumik.gd` 的连携控制器接管：

- 每幕两组连携，轮流出；每组 = **起手蓄势**（1 秒短停，本体脚下一圈群青颗粒外扩 + 亮环，不闪白、不出字）→ **2–4 段** → **收招破绽**（一幕 1.6 / 二幕 2.0 / 三幕 2.2 秒，沿用破绽受伤加成）。
- 段间至少 0.3 秒收势；下一段要等本段有伤预警全部结算、弹幕发射结束；组末若还有移动水墙，等它走完再进破绽（破绽会取消在场移动攻击）。
- 打断：外部眩晕 / 韧性破绽 / 30 秒保护上限 → 清掉未出的段，不额外给收招；转幕（过卡点）→ 清队列，1.5 秒后进下一幕的组；已出的弹与预警照常结算（不清屏）。
- 震撼按原作阈值插在组与组之间。
- 原共用轮转（`final_attacks.try_attack`）与数据招式轮转（`boss_patterns.try_attack`）对伊祖米克置 INF，只经连携点名；`boss/izumik_cards = 0` 退回旧行为，供云端 A/B。
- 学习期（无敌 20 秒）与子代批次、结茧、灯柱规则不变。

## 3. 新弹幕（5 种，原 7 招 → 12 种主动攻击）

弹体进 `g.ebullets`（命中、地形、绘制走原管线：暗描边 + 发光核心 + 专属群青），本体每帧按 `izu_*` 字段改速度。同时在场上限 150 颗；伤害倍率 0.45–0.55 × e.dmg，低于原数据招式的 0.51 环弹均值以上不加。

| 弹幕 | 图案与规律 | 设定 / 主轴关系 |
|---|---|---|
| 潮汐相位流 | 五条摆动水流（相邻反相，正弦摆幅约 ±21°），每 0.22 秒一发、持续 3 秒，r6 细弹 125px/s | 海流；**这一批子代的来向正好落在两条流之间**，去截杀的路是开的 |
| 子代共鸣 | 每只走在路上的子代（最多 4）先亮 0.8 秒共鸣环，再三连发 3 颗小扇瞄你；子代被打死这一路立刻停 | 子代 / 分享；越早截杀越少弹 |
| 螺旋弹臂 | 两条慢转螺旋臂（0.7 rad/s，每组换向），3.6 秒；吸收 3 层起变三条臂 | 学习期设计稿「2 条慢转螺旋弹臂」；回去打茧从臂间走 |
| 习得弹 | 两圈弹散开到 150 / 230 处停住 0.5 秒（每颗外圈收缩的光点标记），再各自转向停住那一刻的你、加速到 150 | 学习；**吸收层数越多弹越多**（12 + 2 × 层，上限 20），拦截失败的代价看得见 |
| 回流弹 | 两圈 18 颗外放，1.1 秒后反向卷回（±1.5 rad/s，持续 1.5 秒），两圈交叉成格子 | 海流回流；三幕**点亮的灯柱光圈会吞掉伊祖米克的弹**，灯柱既是庇护也是弹幕里的空洞 |

## 4. 特效

- 迁徙潮预警改成暗红低填充的水墙带 + 像素波峰勾边（浪尖随时间起伏），行进通道只画稀疏泡沫点，去掉原来的矩形框、行进四边形与箭头（`render/izumik_attack_draw.gd`）。
- 全场震撼 / 分享·全场（光学观感）：不再铺通用的整屏斜线，改为暗红低填充 + 从本体外扩的三道断续浪纹弧（暗底亮芯，越到结算越连贯），点亮的灯柱暖光圈压在上面，安全区一眼可辨。
- 起手蓄势、灯柱吞弹、本体倒下清弹都走现有 Boss 颗粒池（`boss_beam.grains`，低画质不画，只用 g.vrng）。
- 其他预警（潮汐坠落圆、深渊涌流环、触腕扇）沿用 167/168 的暗红低填充 + 材质边。

## 9. 10-27 第三轮：输出窗口、专属非弹幕招、伤害旋钮

协调人转达用户：「每个 Boss 都要注意给干员输出的机会和时间」；伊祖米克要有一招非弹幕的专属攻击；弹幕单发伤害下调做成旋钮。激光的蓄力 / 消散要求对伊祖米克不适用（她没有光束类招式）。

- **海流牵引**（本作改编，非弹幕，取材海流）：在你脚下锁一个漩涡，2.6 秒内半径 320 的海流把你往中心拖（最高 70px/s，0.6 秒渐强，越外圈越弱；低于步行速度，顶着流走得出去，冲刺中不拖），结束时中心 r80 涌起一次（e.dmg × `boss/izumik_current_mult` 1.0）。读法：地面向心流线 + 外圈流转虚环 + 中心暗红低填充圈；结算为水柱涌起后塌落。破绽 / 眩晕取消。并入连段：迁徙潮汐（替潮汐坠落）、习得变形（替子代共鸣）、深蓝回流（替深渊涌流）。
- **输出窗口**：收招破绽 2.6 / 3.0 / 3.2 秒（原 2.2 / 2.6 / 2.8）；破绽后再空 1.6 秒才起下一组；组末在场弹散到 8 颗以下才进破绽（破绽窗口不叠弹幕）；新弹幕寿命 4.5–5 秒（原 6–7），不拖进下一段；灯下三叶改为以分享扇收尾。
- **伤害**：新弹幕单发 × `boss/izumik_bullet_mult`（缺省 0.8）；解读旋涡单发 mult 0.507 → 0.406，每波 32 → 26。触腕、潮汐坠落、涌流、分享等非弹幕伤害不变。
- **量测**（`izumik_card_test` 三幕各 70 秒正式 AI、105px/s 绕行、无子代批次；低压 = 以本体为中心一屏内敌弹 < 20 且无未结算有伤预警、无移动水墙）：

| 一 | 47% | 36 | 2.6 秒 × 4 |
