# 333 · 无敌包四个最终 Boss 连测（11-11）

用户原话：「自动测试能不能四个连着测？这样也好测试重新开一局的情况，然后用负载中最高的几个干员测。然后性能报告要记录全面」。
基线：toy-god-test fa34e7f17（auto=1 + 统计合并 + speed 修复）。代码：`core/god_suite.gd`（新）、`settings.gd`、`run/auto_play.gd`、`core/perf_report.gd`、`title.gd`。

## 1. 用法

| 网址 / 命令行 | 作用 |
|---|---|
| `?boss=all` 或 `?suite=1` | 四局连测：等于 auto=1 + loop=1，一局一个最终 Boss，偏执泡影 → 伊莎玛拉 → 伊祖米克 → 最后的骑士，轮完停在汇总页 |
| 再加 `&squad=队长,队友,…` | 四局都用这一队（不给就按 §2 每局换一套） |
| 再加 `&speed=N` | 照旧局内倍速 |
| 桌面调试 `-- --god --testsuite --perfreport [--testspeed=4]` | 同上；`--testsuite=new` 先清掉旧进度；汇总写 `user://god_suite_report.txt` 并以 `PF SUITE|` 打进日志 |

- 进度存 localStorage `sy_suite`（桌面 `user://god_suite.json`）。手机网页局间整页重载（run_reload），重载后接着下一个 Boss——走的就是真人「再来一局」的路径。
- 每局开局先记「进行中」；页面被杀（闪退）后下次打开，发现那局没结算，就把它记成「未结算（闪退 / 页面被关）」并附上闪退报告（crash_box 上次那份），标题页弹出进度面板（30 秒后照常接着下一个 Boss，面板可随时复制）。
- 局内 25 分钟还没击破最终 Boss：记「超时未击破」，重开下一局（防一局卡死整轮）。
- 轮完：结算页停 8 秒后弹汇总面板（复制全部 / 保存文件 / 重新连测 / 关闭）；之后再打开同一网址也停在汇总页、不再出发。要再测一轮点「重新连测」。上一轮记录留在 `sy_suite_prev`。
- 只在 test_god 包生效；正式包 `Cfg.test_suite()` 恒为 false。

## 3. 每局报告内容

每局结算（含超时退出）把完整性能报告存进 `sy_suite`，并加两项新读数（`perf_report.gd`，正常性能报告也带）：

- **最终 Boss 战段**：Boss 登场到击破之间的帧时 P50 / P95 / P99、最差 1 秒帧率、内存峰值、WASM 峰值、开始时间与时长。
- **本局 WASM 最大**：每 5 秒采样的 WASM 堆容量最大值（原来只有内存峰值那一刻的读数）。

原有项照旧：设备、画质、帧时、7 分钟后、内存峰值与构成、掉帧档、护栏、最慢 5 秒、贴图上传峰值与本局最大单张、按人读入量、局间重载轨迹。
闪退那局：附 crash_box 闪退报告全文（内存曲线、高频曲线、事件日志、WASM 增长）。

汇总页：第一段每局一行（Boss · 编队 · 局长 · 结果 · 帧时 P50 / P95 · 最差 1 秒 · 内存峰值 · WASM · Boss 战段），后面接四局全文。

## 4. 桌面验证（11-11，4 倍速，测量交给手机，跑完两局即停）

- 第 1 局 偏执泡影（凯尔希 / 维什戴尔 / 乌尔比安）：击破，局长 11:32；Boss 战段 10:00 起 89 秒，数据正常记入。
- 第 2 局 伊莎玛拉（维什戴尔 / 浊心斯卡蒂 / 艾丽妮）：同进程自动重开、编队与 Boss 正确换成第二套，击破，局长 10:51。
- 第 3 局 伊祖米克（乌尔比安 / 归溟幽灵鲨 / 水月）：正确开局后按用户意见停测。零脚本报错。
- 重开那一帧引擎报 2 条 `!is_inside_tree`（结算页同帧还在读视口）→ 重开改成帧末执行（`call_deferred`），没再复跑。
- 桌面帧时没有参考价值（4 倍速每帧负载翻倍，这台机器重编队后期只有 0.2–0.65 倍实时）。网页 localStorage、整页重载接续、闪退补记、汇总面板只在手机上能验；面板 JS 已过 `node --check`。
- 调试版 `--suitetimeout=<秒>` 可以把超时改短，用来测超时 / 重开路径。

结论：B站 App 内（iOS WebView）内存算过：WASM 四局都是 286 不涨（11-08 同环境开局 513）、护栏未触发。后续修正（分支 claude/god-suite-fixes，docs/319 §24）：
- 伊莎玛拉 / 骑士 / 伊祖米克二阶段运行时预混（两首同驻 → 一首）；
- 最终阶段敌人帧条每 5 秒最多放一种（684 ms 那一秒只有「释放帧条」）；
- 「本页开局前打开过：图鉴 1 次」误报：标题页一建图鉴就记了，改为真正打开才记；
- 「本局干员特效读入」里编队外的乌尔比安 0.2 MiB 不是串读：地裂 / 碎石 / 尘墙帧条叫 fx_ul_*，星熊、斯卡蒂终结技、升级特效都在用，改算公共。
还差：后期帧率（7 分钟后 P50 47–57 ms，四局都进掉帧档 350–400 秒，×2 倍速偏重但离 ≥30 帧仍远）。
