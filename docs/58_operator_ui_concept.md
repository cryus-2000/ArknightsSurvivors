## 1. 从原作借什么、不借什么

| 原作干员界面的做法 | 本作怎么用 | 不照搬的 |
| --- | --- | --- |
| 左 / 下方一排竖卡名册：左上职业图标、右上星级、底部名字条，选中卡抬起亮边 | 选择页改成**底部横向名册**（13 名放不下就横向滚），图鉴页保持 4 列网格；星级换成**精英阶段菱形**（本作没有稀有度） | 不做稀有度、潜能、信赖 |
| 半身立绘压在界面后面，名字大字 + 英文压缩斜体 + 职业 / 标签 | 待机帧 4–5 倍最近邻放大当「立绘」，底部渐隐，职业色外晕；名字 44 号 + `UI.en` + `UI.chip` | 不画原作的立绘、徽记 |
| 右侧信息页签：属性 / 技能 / 模组 / 档案 | 选择页三页签 **属性 / 技能 / 编队**；图鉴页四页签 **档案 / 技能 / 成长 / 藏品契合**（模组 → 成长节点；战绩页 10-11 用户说不急，已去掉） | 不做模组、语音、皮肤 |
| 技能行：图标 + 名字 + SP 环 + 技能等级 | 图标（已有 32×32）+ 名字 / 英文 + **充能 SP 环** + 解锁阶段（招募 / 精英一 / 精英二）+ **手动 Q / 自动** 标签（主控才手动，队友一律自动） | 不做技能专精 |
| 左侧职业筛选栏 | 两页都有竖向职业轨（全部 + 7 职业，当前职业高亮为职业色） | — |
| 右下大按钮「开始行动」 | 右下斜切青底「出击 ›」，副标「ENTER / 手柄 A · 下一步选择难度」 | — |
| 切角面板、暗底白细线、每页一个强调色 | 面板沿用 `UI.panel`（炭灰半透明 + 顶部高光 + 1px 细边 + 左上强调段），加**右上切角**；强调色 = 当前干员的职业色（`Character.CLASS_COL`） | docs/37 §1 写「不画切角」是针对旧 v1.2 像素角括；这里的切角是原作式单角斜切，要不要开放由用户定 |

颜色全部是 `ui.gd` 现有常量（CYAN / GOLD / RED / VIOLET / PURPLE / GREEN / STEEL / TEXT / SUB），`UI.PURPLE` 仍只用于干员标签片，不改。

## 7. 美术方向对比

> 2026-10-11 用户：「战绩不急着做，能不能多出几个美术版本对比？」同一内容与骨架（顶栏 / 职业轨 / 立绘 / 名字块 / 信息页签 / 编队条 / 名册 / 出击），只换美术语言，便于公平对比。
> `python tools/concept_operator_ui.py --variant=all` 生成到 `build/concept/operator_ui/variants/`：
> `contact_sheet.png`（选择 A–D + 图鉴 B / C，2×3）、`contact_sheet_codex.png`（图鉴 A / B / C / E）、各张 `concept_select_<X>.png` / `concept_codex_<X>.png`。
> 单出一个方向：`--variant=B`。对比图都不带编号标注；带标注的 A 版仍是 §2 / §3 那三张。

| 方向 | 长相 | 借自哪里 | 相对 A 的风险 / 成本 | 会破哪条 docs/37 规则 |
| --- | --- | --- | --- | --- |
| **A 现版** | 炭灰半透明面板、右上单切角、左上职业色角段、职业色斜切页签、青色斜切「出击」 | 原作干员页的切角 + 本作方案 A 的配色 | 基准（约 29–35 h） | §1「不画切角」（单角斜切） |
| **B 水月 / 集成战略** | 无切角圆角面板，紫色细边 + 内衬细线 + 顶角金菱形；深海青 → 深紫斜向渐变底，下方浪纹、两侧触须剪影、灯火光点；圆角标签片、胶囊职业轨；节点标签条式标题（紫底压缩英文 + 中文）；青底圆角「出击」外套金细框 | 本作局内（docs/37 方案 A：标签条、小标签头、`UI.VIOLET` 当前、`UI.GOLD` 灯火）+ 原作集成战略的紫金饰线 | 最低：组件几乎都已在 `ui.gd`（strip / chip / tab / panel）；背景用 shader 或一张预渲染图（+2 h）；比 A 少做切角（−1 h） | 基本不破；金菱形饰角接近 §1「像素角括」的禁区，要用户确认这种细饰线算不算 |
| **C 罗德岛终端** | 浅灰底 + 细网格、白面板黑字黑细线、选中黄底 + 左黄条；立绘背后职业色大斜带 + 黑细带 + 超大描边英文名；黄黑警示条（标题、出击）；英文微型标签（OPERATOR DATA // SKILL、01 / 02 页签号）；名册卡黑名字条、顶部职业色条 | 最像原作干员 / 编队界面（浅色终端、斜色带、微型英文） | 中：全套浅色要另做一组颜色常量（`ui.gd` 加 light 主题，所有面板 / 文字颜色走主题）约 +6 h；和局内暗色 HUD 割裂，标题页 → 选人 → 局内会有一次明暗跳变；像素立绘在浅底上描边要重调 | §1「像原作的局内界面：炭灰半透明平面板」整体换成浅色；§2 语义色里 `UI.TEXT` / `UI.SUB` 在浅底上要反转 |
| **D 极简像素** | 640×360 画布画后 ×2：粗像素九宫格边框（黑描边、缺角、亮内边、顶高光）、界面 ≤16 色（取自 `ui.gd`：BG 三档、STEEL、SUB、TEXT、CYAN / CYAN_DIM、GOLD、RED、VIOLET、PURPLE、GREEN、TAB_HP、TAB_LAMP；精灵与技能图标不计）；点阵标题（不抗锯齿 + 1px 硬影）；Bayer 抖动背景；SP 用 8 格像素条；**名册改两行 7 列网格**（13 名一屏放下，不用横滚） | 像素游戏常见的复古菜单；网格名册对应现在的 4 列网格 | 中：九宫格可用 `StyleBoxTexture`（一张 12×12 贴图）+2 h；点阵中文在 9–10 号会糊，只能用于 ≥11 号的标题；整套界面风格与局内 HUD（方案 A 平面板）不一致，局内要不要跟着改是个更大的决定 | §1 整体（方案 A 的平面板 / 细线）、§1「不画像素角括」（旧 v1.2 像素风已退役，D 等于部分回退） |
| **E 深海档案**（仅图鉴） | 旧纸底 + 噪点 + 水渍圈、纸卡面板带投影与横格线；干员照片是拍立得（白边、胶带、斜放、红色「已归档」印章）；衬线字标题（`fonts/serif.ttf`，缺字自动退回 UI 字体）；页签做成文件夹标签；档案小表下划线填空式 | 原作干员档案 / 医疗报告的「资料」气质 + 本作事件画面 C 版式的墨色纸感 | 中：图鉴是独立页面，换风格不影响局内；纸底 / 照片框需要 3–4 张贴图（+4 h）；只适合图鉴，不适合选人（选人要快、要和出击衔接） | §1 平面板（图鉴里局部换成纸本）；与事件画面的 C 版式（docs/37 §4）同源，可以说是把 C 版式推广到图鉴 |

**骨架差异**：A / B / C 名册是底部横滚一行（10 张 + 「还有 3 名」）；D 是两行网格（13 张 + 1 空位一屏放下）。图鉴各方向都是 4 列网格。
**图鉴战绩页**：各方向都已去掉；藏品契合页放大为两行 10 枚图标。
