> 2026-10-11 用户问：「干员的图鉴和选择界面能不能学习一下明日方舟里面的设计？给我出一个概念图。」
> 本页是概念图的图例与实现估算，**不是定稿**；图片不入库，用 `python tools/concept_operator_ui.py` 重新生成到 `build/concept/operator_ui/`：
> `concept_op_select.png`（选择，1280×720）、`concept_op_codex.png`（图鉴，1280×720）、`concept_op_select_phone.png`（手机触屏，740×360）。
> 现状截图同目录 `current/shot_oppick.png`、`current/shot_gallery_ui.png`（`--opshot` / `--galleryshot=0,0,0,1.2`）。
> 概念图只用本项目像素资产（待机帧、技能图标、成长图标、藏品图标）+ `game/fonts/ui.ttf`；不用原作任何图片、Logo，职业图标是白线几何示意。

## 1. 从原作借什么、不借什么

| 原作干员界面的做法 | 本作怎么用 | 不照搬的 |
| --- | --- | --- |
| 左 / 下方一排竖卡名册：左上职业图标、右上星级、底部名字条，选中卡抬起亮边 | 选择页改成**底部横向名册**（13 名放不下就横向滚），图鉴页保持 4 列网格；星级换成**精英阶段菱形**（本作没有稀有度） | 不做稀有度、潜能、信赖 |
| 半身立绘压在界面后面，名字大字 + 英文压缩斜体 + 职业 / 标签 | 待机帧 4–5 倍最近邻放大当「立绘」，底部渐隐，职业色外晕；名字 44 号 + `UI.en` + `UI.chip` | 不画原作的立绘、徽记 |
| 右侧信息页签：属性 / 技能 / 模组 / 档案 | 选择页三页签 **属性 / 技能 / 编队**；图鉴页五页签 **档案 / 技能 / 成长 / 藏品契合 / 战绩**（模组 → 成长节点，语音 → 战绩） | 不做模组、语音、皮肤 |
| 技能行：图标 + 名字 + SP 环 + 技能等级 | 图标（已有 32×32）+ 名字 / 英文 + **充能 SP 环** + 解锁阶段（招募 / 精英一 / 精英二）+ **手动 Q / 自动** 标签（主控才手动，队友一律自动） | 不做技能专精 |
| 左侧职业筛选栏 | 两页都有竖向职业轨（全部 + 7 职业，当前职业高亮为职业色） | — |
| 右下大按钮「开始行动」 | 右下斜切青底「出击 ›」，副标「ENTER / 手柄 A · 下一步选择难度」 | — |
| 切角面板、暗底白细线、每页一个强调色 | 面板沿用 `UI.panel`（炭灰半透明 + 顶部高光 + 1px 细边 + 左上强调段），加**右上切角**；强调色 = 当前干员的职业色（`Character.CLASS_COL`） | docs/37 §1 写「不画切角」是针对旧 v1.2 像素角括；这里的切角是原作式单角斜切，要不要开放由用户定 |

颜色全部是 `ui.gd` 现有常量（CYAN / GOLD / RED / VIOLET / PURPLE / GREEN / STEEL / TEXT / SUB），`UI.PURPLE` 仍只用于干员标签片，不改。

## 5. 实现估算

| 块 | 文件 | 工时 | 备注 |
| --- | --- | --- | --- |
| 切角面板 + 页签 + 大按钮 | `scripts/ui.gd`（`panel` 加 `cut_corner` 参数、新增 `tab_bar` / `big_button`） | 3 h | 要先问用户是否放开 docs/37 §1「不画切角」 |
| 职业线性图标 | `scripts/ui.gd icon()` 加 8 个几何图标（或 `tools/make_skill_icons.py` 再出 8 张 16×16） | 2 h | 概念图里是几何示意 |
| 选择页重排 | `scripts/title.gd _draw_op_pick` 全部重写（约 230 行）+ `_op_follow` 改横向、`op_rects` 命中、键盘 / 手柄 / 触屏输入 | 8–10 h | 立绘层用待机帧放大，与现 `od.tex` 同源 |
| 技能卡 + SP 环 + 手动 / 自动 | 同上，复用 `hud_squad.gd` 技能格的环绘制 | 2 h | — |
| 图鉴干员页重排 | `scripts/gallery.gd _build / _draw`（干员分支）：网格卡换样、信息页签 3 → 5、成长时间线 | 6–8 h | 其他页签（敌人 / 藏品 / 结局）不动 |
| 藏品契合页 | `scripts/run/affects.gd` 加「按干员反查藏品」+ gallery 一页 | 3 h | 口径已有 |
| 战绩页 | `settings.gd` 存档加 `op_stats{出击, 通关, best_t, max_diff}`，结算时写入 | 3 h | 存档版本号 +1 |
| 触屏版式 + 验收 | 两页的 `touch_device()` 分支 + `--opshot --touch` / `--galleryshot --touch` 截图 | 4 h | 按 docs/37 §4 手机版式 |
| 快检 / 截图自测更新 | `tools/check.py` 现有 `--opshot` / `--galleryshot` 用例看一遍、补 `--opsel` 滚动用例 | 1 h | — |

合计约 **32–38 h**；分两步交付：先选择页（1–4 行，约 15 h），再图鉴（其余）。
不改游戏数值、不改存档格式（战绩页除外，可后做）。
