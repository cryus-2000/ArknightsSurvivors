## 1. 从原作借什么、不借什么

| 原作干员界面的做法 | 本作怎么用 | 不照搬的 |
| --- | --- | --- |
| 左 / 下方一排竖卡名册：左上职业图标、右上星级、底部名字条，选中卡抬起亮边 | 选择页改成**底部横向名册**（13 名放不下就横向滚），图鉴页保持 4 列网格；星级换成**精英阶段菱形**（本作没有稀有度） | 不做稀有度、潜能、信赖 |
| 半身立绘压在界面后面，名字大字 + 英文压缩斜体 + 职业 / 标签 | 待机帧 4–5 倍最近邻放大当「立绘」，底部渐隐，职业色外晕；名字 44 号 + `UI.en` + `UI.chip` | 不画原作的立绘、徽记 |
| 右侧信息页签：属性 / 技能 / 模组 / 档案 | 选择页三页签 **属性 / 技能 / 编队**；图鉴页四页签 **档案 / 技能 / 成长 / 藏品契合**（模组 → 成长节点；战绩页 10-11 用户说不急，已去掉） | 不做模组、语音、皮肤 |
| 技能行：图标 + 名字 + SP 环 + 技能等级 | 图标（已有 32×32）+ 名字 / 英文 + **充能 SP 环** + 解锁阶段（招募 / 精英一 / 精英二）+ **手动 Q / 自动** 标签（主控才手动，队友一律自动） | 不做技能专精 |
| 左侧职业筛选栏 | 两页都有竖向职业轨（全部 + 7 职业，当前职业高亮为职业色） | — |
| 右下大按钮「开始行动」 | 右下斜切青底「出击 ›」，副标「ENTER / 手柄 A · 下一步选择难度」 | — |
| 切角面板、暗底白细线、每页一个强调色 | 面板沿用 `UI.panel`（炭灰半透明 + 顶部高光 + 1px 细边 + 左上强调段），加**右上切角**；强调色 = 当前干员的职业色（`Character.CLASS_COL`） | docs/37 §1 写「不画切角」是针对旧 v1.2 像素角括；这里的切角是原作式单角斜切，要不要开放由用户定 |

颜色全部是 `ui.gd` 现有常量（CYAN / GOLD / RED / VIOLET / PURPLE / GREEN / STEEL / TEXT / SUB），`UI.PURPLE` 仍只用于干员标签片，不改。

## 7. 美术方向对比

> 2026-10-11 用户：「战绩不急着做，能不能多出几个美术版本对比？」同一内容与骨架（顶栏 / 职业轨 / 立绘 / 名字块 / 信息页签 / 编队条 / 名册 / 出击），只换美术语言，便于公平对比。
> `python tools/concept_operator_ui.py --variant=all` 生成到 `build/concept/operator_ui/variants/`：
> `contact_sheet.png`（选择 A–D + 图鉴 B / C，2×3）、`contact_sheet_codex.png`（图鉴 A / B / C / E）、各张 `concept_select_<X>.png` / `concept_codex_<X>.png`。
> 单出一个方向：`--variant=B`。对比图都不带编号标注；带标注的 A 版仍是 §2 / §3 那三张。

| 方向 | 长相 | 借自哪里 | 相对 A 的风险 / 成本 | 会破哪条 docs/37 规则 |
| --- | --- | --- | --- | --- |
| **A 现版** | 炭灰半透明面板、右上单切角、左上职业色角段、职业色斜切页签、青色斜切「出击」 | 原作干员页的切角 + 本作方案 A 的配色 | 基准（约 29–35 h） | §1「不画切角」（单角斜切） |
| **B 水月 / 集成战略** | 无切角圆角面板，紫色细边 + 内衬细线 + 顶角金菱形；深海青 → 深紫斜向渐变底，下方浪纹、两侧触须剪影、灯火光点；圆角标签片、胶囊职业轨；节点标签条式标题（紫底压缩英文 + 中文）；青底圆角「出击」外套金细框 | 本作局内（docs/37 方案 A：标签条、小标签头、`UI.VIOLET` 当前、`UI.GOLD` 灯火）+ 原作集成战略的紫金饰线 | 最低：组件几乎都已在 `ui.gd`（strip / chip / tab / panel）；背景用 shader 或一张预渲染图（+2 h）；比 A 少做切角（−1 h） | 基本不破；金菱形饰角接近 §1「像素角括」的禁区，要用户确认这种细饰线算不算 |
| **C 罗德岛终端** | 浅灰底 + 细网格、白面板黑字黑细线、选中黄底 + 左黄条；立绘背后职业色大斜带 + 黑细带 + 超大描边英文名；黄黑警示条（标题、出击）；英文微型标签（OPERATOR DATA // SKILL、01 / 02 页签号）；名册卡黑名字条、顶部职业色条 | 最像原作干员 / 编队界面（浅色终端、斜色带、微型英文） | 中：全套浅色要另做一组颜色常量（`ui.gd` 加 light 主题，所有面板 / 文字颜色走主题）约 +6 h；和局内暗色 HUD 割裂，标题页 → 选人 → 局内会有一次明暗跳变；像素立绘在浅底上描边要重调 | §1「像原作的局内界面：炭灰半透明平面板」整体换成浅色；§2 语义色里 `UI.TEXT` / `UI.SUB` 在浅底上要反转 |
| **D 极简像素** | 640×360 画布画后 ×2：粗像素九宫格边框（黑描边、缺角、亮内边、顶高光）、界面 ≤16 色（取自 `ui.gd`：BG 三档、STEEL、SUB、TEXT、CYAN / CYAN_DIM、GOLD、RED、VIOLET、PURPLE、GREEN、TAB_HP、TAB_LAMP；精灵与技能图标不计）；点阵标题（不抗锯齿 + 1px 硬影）；Bayer 抖动背景；SP 用 8 格像素条；**名册改两行 7 列网格**（13 名一屏放下，不用横滚） | 像素游戏常见的复古菜单；网格名册对应现在的 4 列网格 | 中：九宫格可用 `StyleBoxTexture`（一张 12×12 贴图）+2 h；点阵中文在 9–10 号会糊，只能用于 ≥11 号的标题；整套界面风格与局内 HUD（方案 A 平面板）不一致，局内要不要跟着改是个更大的决定 | §1 整体（方案 A 的平面板 / 细线）、§1「不画像素角括」（旧 v1.2 像素风已退役，D 等于部分回退） |
| **E 深海档案**（仅图鉴） | 旧纸底 + 噪点 + 水渍圈、纸卡面板带投影与横格线；干员照片是拍立得（白边、胶带、斜放、红色「已归档」印章）；衬线字标题（`fonts/serif.ttf`，缺字自动退回 UI 字体）；页签做成文件夹标签；档案小表下划线填空式 | 原作干员档案 / 医疗报告的「资料」气质 + 本作事件画面 C 版式的墨色纸感 | 中：图鉴是独立页面，换风格不影响局内；纸底 / 照片框需要 3–4 张贴图（+4 h）；只适合图鉴，不适合选人（选人要快、要和出击衔接） | §1 平面板（图鉴里局部换成纸本）；与事件画面的 C 版式（docs/37 §4）同源，可以说是把 C 版式推广到图鉴 |

**骨架差异**：A / B / C 名册是底部横滚一行（10 张 + 「还有 3 名」）；D 是两行网格（13 张 + 1 空位一屏放下）。图鉴各方向都是 4 列网格。
**图鉴战绩页**：各方向都已去掉；藏品契合页放大为两行 10 枚图标。

## 8. C 方向提炼

> 2026-10-11 用户：「我还挺喜欢 C 的风格，在 C 的风格上进一步提炼原本的 UI 设计风格、动效，然后再做几版本方案。」
> 生成：`python tools/concept_operator_ui.py --cvariants`（静图）/ `--anim [--animvariant=C4]`（GIF）→ `build/concept/operator_ui/c_variants/`（不入库）。
> 下面是凭对原作干员列表 / 干员详情 / 编队 / 集成战略画面的印象归纳的规则，再换算到本作 1280×720 像素画面。不用原作素材。

| 原作的做法 | 本作规则（1280×720） |
| --- | --- |
| **栅格与边距**：大块留白，信息贴边排；左栏筛选、中央立绘、右栏数据，底部一排卡 | 外边距 24；顶栏 0–48；舞台 48–548；名册带 548–720；右栏数据面板 x 936–1256（C4 分区斜边 890–930）；左职业框轨 x 24–60，步距 44 |
| **字体层级**：巨型描边英文名压在立绘后；中文名大而粗；英文名小字宽字距；到处是小号代码（`No.04 // GUARD`、`01`、`SP`） | 描边英文 150 px（描边 2 px，墨色 15–20 % 透明度）；中文名 48 px（描边加粗 1 px）；英文名 14 px、字距 5；页标题 18–20 px；正文 12–15；说明 11；**微型代码 7–9 px**（`UI.en` 不斜体、字距 2，即 `code()`）。最小字号触屏 +2（沿用 `tb`） |
| **细线**：1 px 分隔线、面板 1 px 黑框，选中加粗 | 分隔 / 普通框 1 px；选中框、主分隔（顶栏底、名册带顶）2 px；强调条 3–4 px |
| **斜向色带 / 平行四边形**：立绘后的职业色斜带 + 一道黑细带；按钮、页签、编队格都是平行四边形 | 斜带倾角约 66°（顶 x 比底 x 右移 210）；主带宽 240、黑细带 16、远处淡带 16（墨色 14 %）；平行四边形斜移：页签 8–10、标签 6、编队格 10、出击 18 |
| **职业 / 稀有度色**：职业色只用在小面积（卡顶条、斜带），稀有度用星 | 职业色（`Character.CLASS_COL`）只用在：卡顶 4 px 条、立绘斜带、未选卡无其他职业色；精英阶段用菱形（选中卡显示）；**`UI.PURPLE` 不改，只做干员标签片左色条**；`UI.VIOLET` 只做「主控」小牌 |
| **大数字**：属性、SP、费用都用大号数字，标签小 | 技能页属性 22 px、属性页 30 px、SP 22 px；标签 = 微型英文代码 + 9 px 中文；数字右对齐，竖线分隔 |
| **黄黑警示条**：主操作、警告用 | 只用在三处：顶栏标题块右侧 24 px、出击按钮左段、转场带前缘；条宽 8、45° |

## 9. 动效

> 预览：`c_variants/anim_a_switch_operator_C4.gif`（换干员）、`anim_b_skill_tab_C4.gif`（开技能页）、`anim_c_confirm_transition_C4.gif`（出击 → 难度），640×360、30 fps。
> 实现总则：全部是**界面层**动画，用 `create_tween()` 或 `_process` 里累计时间再在 `_draw` 插值；**不碰 `g.rng`**（只用固定曲线，不随机）；设置里加「减少动态效果」（`Cfg.reduce_motion`）：开启后所有位移 / 缩放 / 扫入直接到终态，只保留 ≤ 120 ms 的透明度渐变，警示条不滚动。

| 动效 | 时长 | 缓动 | 触发 | Godot 实现 |
| --- | --- | --- | --- | --- |
| 面板正文滑入 | 260 ms，位移 60 → 0 px + 透明度 0 → 1 | ease-out cubic（`Tween.TRANS_CUBIC, EASE_OUT`） | 换干员后 120 ms | 面板正文画进单独 `Control`，tween `position:x` 与 `modulate:a` |
| 斜色带扫入 | 380 ms，新色带从左 −900 px 扫到位，旧色带留在下面被盖住 | ease-in-out cubic | 换干员立即 | `_draw` 里 `band_t` 插值画两个多边形；颜色取 `CLASS_COL` |
| 立绘缩放进入 + 视差 | 300 ms，缩放 0.92 → 1、右移 24 → 0、透明度 0 → 1；平时随鼠标 / 右摇杆 ±6 px 视差 | ease-out cubic | 换干员后 60 ms | 立绘 `TextureRect` 用 `scale` / `position` tween；缩放用最近邻（`texture_filter = NEAREST`），保证像素不糊 |
| 英文名打字机 | 420 ms 逐字出现（中文名同时淡入 260 ms） | 线性 | 换干员后 80 ms | `visible_ratio`（`Label`）或 `_draw` 里截字符串 |
| 名册卡抬起 / 高亮线 | 选中 220 ms 抬 10 px（ease-out back，轻微过冲），离开 160 ms 落回；悬停 120 ms 抬 4 px，底部强调条从左展开 | 选中 back、其余 cubic | 悬停 / 选中 | 每张卡一个 `lift` 浮点，`_process` 里 `move_toward` 或 tween；画时 y −= lift |
| 数字跳动 | 400–450 ms 从 0 计到终值（间隔类从 2× 降到终值） | ease-out cubic | 面板正文出现时 | `tween_method` 驱动显示值，只影响显示 |
| 出击按钮警示条滚动 | 常驻，60 px / 秒；按下时 160 ms 下沉 4 px + 白闪 | 线性 / sine | 常驻 / 按下 | 警示条用 `TextureRect` + shader `UV.x += TIME*k`，或 `_draw` 里相位偏移；减少动态时停住 |
| 页签下划线滑动 | 200 ms 滑到新页签；旧正文 100 ms 淡出，新正文三行错开 60 ms、各 250 ms 从右 40 px 滑入 | ease-out cubic | 点页签 / LB RB | 下划线 `position:x` tween；行用 `tween.set_parallel().tween_interval(i*0.06)` |
| 出击 → 难度转场 | 按下后 140 ms 开始，600 ms 斜切黑带（前缘 26 px 黄条）从左扫过；过半换底页，再扫出 | ease-in-out cubic | 出击 | 复用 `screens/scene_transition.gd` 加一种「斜切」模式（`ColorRect` + 多边形 shader），难度页在黑带全覆盖的那一帧切换 |

性能：都是 `_draw` 少量多边形 + 一张立绘，不涉及世界层；标题页本来就在 `_process` 重绘。估算 6–8 h（含减少动态开关与手柄 / 触屏触发）。

### 11.1 哪屏用哪种语言

| 画面 | 语言 | 理由 |
| --- | --- | --- |
| **干员选择** | **B+**：B（水月 / 集成战略：无切角圆角面板、紫色细边 + 金菱形饰角、深海青紫渐变 + 浪纹触须、圆角标签、青色出击）+ 从 C 只借两样：① 立绘后的**职业色斜带**（透明度 35 %，右缘金细线、左缘紫细线）；② **巨型描边英文名 + 微型代码**（`No.04 // 近卫 // 近战`、`OPERATOR DATA // SKILL`、`ROSTER 13 / 13`） | 选人之后直接进暗色局内 HUD，应该说局内的话；不用黄黑警示条、不用平行四边形 |

**网格取舍**（`contact_sheet_final.png` 第 2 行，`grid_*.png`）：原 C4 舞台 + 面板都有网格，确实碍眼；面板 1 px、4 % 的淡网格在 1280×720 下几乎看不见、缩到手机更看不见，只增加噪点。**采用全部去掉**；面板靠白底 + 1 px 墨色框 + 平行四边形页签分区已经够清楚。

**两种语言怎么保持亲缘**（从标题页进入任一屏都不突兀，见总览第 3–4 行）：
1. **同一条职业色斜带**：位置、倾角（约 66°）、宽度两屏完全相同；B+ 里柔（35 % + 金紫细线），C4' 里实（80 % + 黑细带）。换干员时两屏都是「新色带从左扫入盖住旧色带」。
2. **同一套英文名排版**：150 px 描边英文名压在立绘后、14 px 宽字距英文名、7–9 px 微型代码（`code()` / `b_code()` 同一函数口径）、48 / 44 px 中文名。
3. **同一张名册卡**：顶部 4 px 职业色条、左上职业框、右上精英菱形、底部名字条、选中抬起 10 px + 底部强调条；B+ 只换圆角与紫金描边（强调条青色），C4' 是直角黑框（强调条黄色）。
4. **同一套立绘处理**：待机帧整数倍最近邻放大、底部渐隐、缩放进入 + 右移归位。
5. 转场各说各的话但节奏相同（都是 600–700 ms、ease-in-out、过半换页）：选人用**深海浪幕**，图鉴用**斜切黑带（黄前缘）**。
