## 3. 实现

- `game/scripts/render/fx_pxplane_sa.gd`：塞雷娅一节（单独文件，少撞 fx_pxplane.gd）。事件 → 件表；运行时逐格画注射器 / 碎晶片、阻挡圈、墙脚线、钙化斑；晶柱 / 晶簇由 `seg_saria.h4_draw_extra` 转来（参与 2.5D 排序）；剑气晶刺读 `o.vg.qi`，进度记在剑气字典的画面专用键 `_pxs`。
- `fx_pxplane.gd`：`IDS` / `METAS` 加塞雷娅（键前缀 `sa_`），`ev / draw_floor / draw_over / sort_items / draw_sorted` 各一行转到 `_sa()`；`owns_id` 对塞雷娅只在 `fx/px_plane = 1` 时为真。
- 只画钩子（`_FXR.ev`，没接管时第一行返回）：`seg_saria` 盾击 / 满格环冲 / 晶柱碎 / 钙晶撞敌 / 弹体命中 / 晶簇爆开 / 碎晶 / 钙晶击碎 / 治疗 / 持续回复每跳 / 晶柱槽碰碎 / 钙质化起手；`skill_link` l_saria 起手一行，接管时不画原来的护盾块和地面斑。碎晶·崩落走 `ob_core.exec_shape` 已有的 `shape` 钩子。
- 帧条：`game/art/fx/pxp/pxp_sa_*.png`（155 张，约 140 KB）+ `game/data/pxp_saria.json`；重新生成 `python tools/pxplane_bake_saria.py`（图形在 `tools/pxplane_saria_art.py`），之后 Godot `--import` 一次（GCP 上自动）。
- 送审 GIF：`python tools/pxplane_gif_saria.py [--only atk,s1,...]`。
