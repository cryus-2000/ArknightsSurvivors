# 48 · 怪物特效审查（2026-09-27，测试与验收，只读）

> 用户问：怪物的特效表现需不需要升级。这次逐个审查了 17 种普通敌人（含 V8 六只）、5 种精英、8 只 Boss：攻击、受击、死亡、技能预警、弹幕，并盘点了 `art/third_party` 里可以直接套用的素材。代码版本 main 6c7a017。
> **结论：需要升级，但大头不在「画新特效」，而在三件事：**
> 1. 预警画的范围和实际判定不一致，有的预警太短；
> 2. 敌方特效被后期降噪调淡，并和友方特效撞色；
> 3. 已经交付的素材一直没接入代码。
>
> 共 98 条：P0 9 条、P1 45 条、P2 44 条。

- 完整报告与证据：`Claude outputs/monster_vfx_0927/`（enemies / elites / bosses 三份 .md 加截图）。本文只列总览和需要用户挑选的部分。
- 优先级：P0 = 影响可玩性或读图（会被没看见的东西打死），P1 = 明显难看或容易误判，P2 = 锦上添花。
- 归属：「Boss与怪物」= 机制与弹幕逻辑；「界面与美术」= 特效绘制、素材接入；「Codex」= 需要新画素材。

## 3. P1 要点（按归属）

**界面与美术**
- 精英几乎只靠金色描边来辨认：脚下光晕 alpha 0.12，看不出来；血条被光照压成暗褐色；关掉「怪物轮廓光」之后精英就没有任何标识了。建议把精英的标识移到不受光照的叠加层，换成洋红或橙红，而且不受轮廓光开关影响。
- 招式名飘字只停 0.65 秒、颜色偏暗，深色主题下看不见。建议改成白字加描边，停 1 秒以上。
- Boss 登场在屏幕外，没有屏外箭头（商人和祭坛都有），换幕只有横幅，死亡特效和精英同一套、而且比本体还小。
- 伊莎玛拉转化后外形不变（素材已交付）；泪没有危险圈，外形像掉落物。伊比利亚 / 卡门的装填和打断，身上没有表现；接潮组的假死没有倒计时环。
- 引痕者的狂暴外观只在待机帧生效；巢涌者光环放大 4.6 倍后颗粒很粗，画在实体层会盖住其他东西。
- 普通敌人的击杀溶解、经验结晶、敌人描边都是青色，后期连成一片。

**Boss与怪物**
- 滑动者、撕裂者、骑士精英的冲刺预警线写死 230，实际只有 80–135；骑士精英蓄力的前 0.1 秒，线还往身后画。
- 收割者的扇形斩预警只有 0.45 秒。
- 近战怪不播攻击帧条（素材已有）。
- 泡影一阶段的预警比本体还小，被本体挡住；骑士长枪连刺的刀光朝向当时主控的位置，主控躲开了也像被打中。
- 最终 Boss 死亡当帧就进结算，没有终结演出（B1 的 `S.FINISH`）。
- 掠海漂移体三连发没有前摇，子弹和普通怪完全一样。

## 6. 取证方法与局限

- **普通敌人**：图鉴和平衡模式都不能指定刷哪种怪，所以用仓库外的脚本（`-s` 挂载，不改仓库）固定主控、在主控身边刷指定的敌人，然后逐帧连拍；另外跑了两组约 200 只混编的大群场景。
- **Boss**：`--bosstest` 连拍。碎裂、换幕、假死、死亡在原版 bosstest 里拍不到，因为有单次受伤上限 4%，所以在 scratchpad 的一份游戏副本里加钩子，直接设置 Boss 的位置和血量。
- **精英**：`--bosstest=<精英>` 会把它当成 Boss 处理；测试机器人会远离敌人，所以精英的爆裂和骑士冲刺都没在 bosstest 里触发。囊海爬行者的爆裂只在实战里拍到了；敌对骑士精英的冲刺没有截图，只能按代码判断。
- 截图偶尔被升级、商人面板挡住。这类测试专用的现象没有算作问题。
- 很多 Boss 条目和 docs/38 的 B1–B6 计划重合，`bosses.md` 里每条都标了对应的计划项。唯一建议不等计划、先单独修的是伊祖米克冲击波。
