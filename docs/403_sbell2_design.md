### 2.1 「阵」在割草里怎么成立：两个方案

原作阵法术师的核心是**两种状态**：平时不攻击、硬（守阵）；技能开启时群体法伤（开阵）。圣聆初雪再加一条：**地上的积雪**（天赋一，精零就有）。割草里所有人都在一直打，「平时不打」要靠别的东西撑起手感。

#### 方案 A「雪阵」（推荐）：积雪铺在世界地格上 + 技能开阵

- **积雪地格**：场地按 40 × 40 的格子划分（世界坐标，不跟人走）。初雪身边半径 `snow_r` 150 内的格子每 `snow_cd` 秒积一层雪（精零 3.0 / 精一 2.4 / 精二 1.8 秒，原作 10 / 7.5 / 5.5 秒按割草节奏压到约 1/3），每格至多 5 层。
- **队伍走过就留下一路雪**：格子是世界的，队伍走开雪还在。追着队伍的敌人一路踩雪，正好对上割草「边走边打」的走位。
- **踏雪**（原作原样）：敌人踏上有雪的格子立即受到攻击 × `snow_hit` 的法伤（精零 0.25 / 精一 0.5 / 精二 0.75），并在雪上按层数减速（每层 −10%，精二 −12%，至多 5 层；`st.slow_soft` 同口径，不写减速状态）；首个离开该格的敌人带走那格雪。积雪生成到有敌人站着的格子上也算踏上（否则站桩的敌人永远不触发）。
- **守阵**（平时）：不攻击。她当队长时护甲 / 法抗大幅提升（§4 面板）；当队友时只铺雪。
- **开阵**（技能生效期间）：每 2.0 秒（÷ 攻速）以自身为心半径 140 群体法伤。S1 是瞬发吹雪，S2 / S3 是限时开阵。
- 好处：**「阵」是看得见、摸得着的地形**——白蓝雪格一路铺开、层数越厚越亮，敌人踩上去碎一格。走位（往哪拉怪）直接决定她打多少，这是现有 25 人里没有的玩法。
- 代价：要一个新的地格系统（`seg_sbell2.gd`，§3），格子数和逐敌检查要控性能（§3 已给上限）。

#### 方案 B「铃阵」：随身阵圈 + 冻伤层数

- 不做地格。初雪身边一圈半径 130 的阵圈跟着她走（同浊心斯卡蒂歌域的 `zone`）。圈内敌人每 `snow_cd` 秒叠 1 层「积雪」（记在敌人身上），每层减速，满 5 层冻结 1 秒后清零。
- 普攻：每 2.0 秒阵圈内群体法伤，圈内敌人越多伤害越高（借原作模组「千分之一的心」：至多 +15%）；守阵 / 开阵只改伤害倍率（平时 ×0.4、技能 ×1.9）。
- 好处：全用现有积木就能拼（`zone` + `st.slow_soft` + `verb.mark`），零新系统，性能没风险。
- 代价：和浊心斯卡蒂的歌域、铃兰的减速圈重了；「平时不攻击」变成「平时打得轻」，阵法的味道没了；积雪不留在地上，原作天赋一最好认的那一点丢掉了。

#### 对比

| | A 雪阵（地格） | B 铃阵（随身圈） |
|---|---|---|
| 原作还原 | 守 / 开两态 + 地上积雪，三条都在 | 只剩「范围法伤 + 减速」 |
| 和现有干员区分 | 唯一一个改变地形、靠走位铺场的干员 | 与浊心斯卡蒂、铃兰重叠 |
| 玩家读不读得懂 | 雪铺在地上、踩一格碎一格，一眼懂 | 敌人身上叠层，要看小图标 |
| 割草爽感 | 拉着一大串敌人绕圈踩雪，雪格成片碎裂 | 和普通光环差不多 |
| 实现 | 新地格段（约 1 个积木段 + 地面绘制） | 零新积木 |
| 性能 | 有上限设计（≤ 240 格、0.1 秒一检、只查附近敌人） | 无风险 |
| 萨米主题 | 白雪地格和萨米冻土地面要靠颜色分开（§6.2） | 无此问题 |

**推荐 A**。下文 §2.2 起按 A 写；B 只作退路（用户若嫌新系统太重就换 B，数值表照样能用）。

### 2.2 特性「无垠的雪景」与守阵 / 开阵

- **特性**（招募即有；原作特性 + 天赋一，天赋一在原作精零就有，是她的身份，所以提到特性层）：积雪规则见 §2.1 A；不攻击；队长面板守阵加成（不在技能期间：护甲 +`guard_armor` 1.5、法抗 +`guard_res` 0.15，对应原作防御 +200%、法抗 +20）。
- **开阵攻击**（技能生效期间才有，也就是她的「普攻」）：`shape.circle center: self`，半径 `open_r` 140 × op_range，每 `cd` 2.0 秒（÷ 攻速），倍率按技能（S2 ×`s2_open` 1.9、S3 ×`s3_open` 1.3），法术伤害，无击退。原作「群体法术伤害」= 范围内全部。
- Boss 口径：踏雪伤害对 Boss 照算，减速对 Boss 无效（同 `st.slow_soft` 缺省）；冻结 = `st.stun`（精英减半、Boss 不受）；寒冷 = `st.slow`。

### 2.3 天赋「圣山的祝福」（精一）

- **寒冷反击**：队长受到伤害时，队长周围 `bless_r` 90 内的敌人寒冷 `bless_cold` 1.5 秒（`st.slow`；每 1 秒至多一次，免得被弹幕刷满）。原作「受到伤害时使敌人寒冷」——原作是她自己挨打，本作只有队长挨打，所以改成护队长。
- **一局一次「圣山」**：队长受到致命伤害时不倒下 → 回复 `bless_heal` 100% 生命（原作「回复所有生命值」）→ 队长冰封 `bless_self` 2 秒（无敌、不能移动 / 冲刺，原作「自身冻结 4 秒」）→ 周围 `bless_freeze_r` 240 内敌人冻结 `bless_freeze` 5 秒（原作 8 秒；精英减半、Boss 除外），并在这片地格积满 5 层雪。
  - **这是一次免死，强度很大**（§7 拍板点 2）：备选「回复 50%」「只在她当队长时生效」。
- 实现：受击挂钩（`trig.on_leader_hit`，若无则新增，§3）。

## 3. 积木落地

**用到的现有积木**：`shape.circle (center: self)`、`shape.cone (dir: densest)`、`st.slow`、`st.stun`、`st.slow_soft`、`verb.displace (dir: ring)`、`verb.field`、`verb.mode`、`verb.buff_self`、`trig.tick / every_n / delay / passive / skill_active`。

**本人段 `blocks/seg_sbell2.gd`（新，审过再写）**：

| 积木 | 做什么 | 为什么现有积木不够 |
|---|---|---|
| `verb.sb_snow`（常驻，trait） | 积雪地格表：按 `snow_cd` 给身边格子 +1 层；0.1 秒一检附近敌人，处理踏上 / 离开（伤害、减速、带走雪）；守阵 / 开阵状态；风雪边界外不生成 | 没有世界地格状态；`verb.field` 是圆形区域、不记层数、不会被敌人「踩掉」 |
| `verb.sb_lay` | 在一组格子上 +n 层（S1 雪道、节点 1 冲刺路线、铃落、终结技、连携、免死） | 同上 |
| `verb.sb_mode` | S2 / S3 期间打开溢出、雪上持续伤、离雪寒冷、冻结点、积雪加速 | 规则挂在地格上，积木表达不了 |
| `verb.sb_wave` | 精二霜涛：沿雪格扩散的环，只打站在雪上的敌人 | 没有「只对某种地格上的敌人」的形状 |
| `verb.sb_bless` | 天赋免死：一局一次、致命伤害时回复 + 冰封 + 冻结 | 需要「致命伤害」挂钩（见下） |

**需要的通用挂钩 / 扩展**：

| 需求 | 现状 | 用处 |
|---|---|---|
| 队长受击挂钩 `trig.on_leader_hit`（带伤害值、是否致命，可拦截致命伤害） | 只有藏品层的受击回调（需确认）；干员积木层没有 | 天赋寒冷反击、免死、连携触发 |

| 开阵：平时不攻击、技能期间才有普攻 | `blocks.attack` 缺省总在打；可用 `cond: skill_active` 或 `verb.swap_attack` 拼 | 守阵 / 开阵两态 |
| 风雪边界半径读口 | 萨米主题 `mech_tide_zone` 复用（docs/391 §7.3） | 圈外不铺雪 |

**性能上限**（docs/91 §0.5 第 5 条）：同时有雪的格子 ≤ 240（超出先清最旧的）；逐敌检查 0.1 秒一次、只查有雪格子附近（空间格）的敌人；地面画法每格一个贴图矩形（`world.tb_*` 合批），层数用亮度 + 1–5 个亮点表示，不逐格画圆。
