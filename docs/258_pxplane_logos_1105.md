## 3. 实现

- `game/scripts/render/fx_pxplane.gd` 末段「逻各斯」：事件转成一次性件；状态件直接读玩法状态，包括 `o.hw` 的 bolts、lock、links、fan、pools 和 `o.vg.bul`（只读）。`IDS` 加了 logos，`METAS` 加了 `pxp_logos.json`（键前缀 `lg_`），`ITEM_MAX` 从 72 提到 120。
- **跟着施放者走**：协调人 11-05 转达了用户实机发现的问题，斯卡蒂 / 星熊的斩击不跟人走。逻各斯这边，件上挂 `fop` 字段（施放者）后，`_step` 每拍（15 fps）把件移到施放者当前的脚底，朝向也跟着翻转。用在出手笔光、字环、殁亡起手字环和延异视阈起手上。提喻咒文行、咒域、连缀每帧都按当前状态画，本来就跟着走；彗星、命中、处决、落地件留在原地。斯卡蒂会话的框架层修复出了提交以后要再合一次。
- 钩子（都只画）：逻各斯原有的配方钩子 `fire / hit / exec / lock_tick / fan_tick`（docs/245）直接转过来。新增的钩子：`vis_growth.gd` 额外弹命中 `lg_xhit`（接管时不画通用弹体）；`late_shape.gd` 连锁 `lg_chain`；`skill_link.gd` l_logos `lg_link`（接管时不生成碎石块、不画字环贴图 / 占位）；`combo.gd` 出手 `lg_cshot`、落点 `lg_combo`（接管时不画通用曳光和圆环）。
- **法术弹道（只画面）**：「言」的画面位置用 `_lg_arc(a, b, s, lift, side)` 计算，即直线加侧向 `lift·sin(πs) + 0.3·lift·sin(2πs)`，两端分别落在出手点和目标上。墨尾沿这条线往回取点（`_lg_arc_path`）。进度 s 读自玩法弹体：有 `visual` 的弹用 `visual.u`，没有的用「到目标的剩余距离 / 总距离」，并记在画面专用键 `_pxs0` / `_pxu`（玩法不读）。判定、命中时刻和玩法弹位都不动。
- **咒域渐变**：整盘渐变按半径 R（美术像素）只生成一次贴图并缓存，扇形用带 UV 的多边形从贴图里取那一块。张满后 1 贴图像素 = 1 美术像素；张开那 0.33 秒按比例取。
- `fx_recipe.recipe()`：缓存按开关区分（`px:` 前缀）。逻各斯转平面关、`fx/recipe` 开时，仍然走 docs/245 的配方，两个试验互不影响。
- 帧条：`game/art/fx/pxp/pxp_lg_*.png`（37 件）和 `game/data/pxp_logos.json`。平面版效果源是 `tools/pixelfx_fx/arcane/ak-logos-pp.js`；旧做法对照烤的是旧放开版原文件 `tools/pixelfx_fx/logos_ul_ref/`（取自 `claude/pixelfx-ul-logos`）。重新生成用 `python tools/pxplane_bake_logos.py`，需要本机 pixelfx 库 `build/pixelfx`。新 PNG 的 `.import` 本分支没有生成（本机不开 Godot），合入后由 Godot `--import` 一次补上；GCP 每次开机都会自己导入。
- 颜色组 `game/data/fx_pxplane/logos.json`：只给颗粒、照地光、受击反应用。
- 看图：`python tools/pxplane_shots.py demo|rec|trace|linkcmp --op logos`。新加的选项：`--bals`（逗号分隔的旋钮）、`--leader`（同 `--lead`）、`--name`；OPS 里的 `ev` 可以按某个事件对齐（S2 按 `exec`）。原作一栏由 `tools/pxplane_refcol.py` 在本机拼（只用 PIL）。
- 本分支合入了 `claude/pxplane-lumen` 和 `claude/integ-1105`。`fx_pxplane.gd` 有 8 处冲突，三人的配置都保留：`METAS` 改成字典加前缀，`ev / draw_floor / draw_sorted / _step` 两边分流都留着；`optical.gd` 照地光取流明那一版（分账开时并进候选）；`pxplane_shots.py` 以星熊版为底，补回流明的 OPS、`--bals` 和 START。

## 4. 已知不足 / 偏离

- **彗星位置每帧走**，只取整到像素格，没有按 15 fps 跳格。原因和流明光弹一样：按拍跳会一卡一卡。
- **咒域渐变**张开的 0.33 秒里按比例缩放取样，这段时间贴图像素不在美术像素格上；张满以后是对齐的。
- **咒域按框架口径压扁**（贴地层 0.72），但玩法判定是屏幕上的正圆扇形，所以画出的边在竖直方向比判定范围窄。斯卡蒂、星熊、流明的贴地圈也都这样。要改需要统一定，本稿没有单独改。
- 被减速的敌弹标记（原画法的减速墨滴）接管时不画；「消除弹幕 ×n」飘字照旧。
