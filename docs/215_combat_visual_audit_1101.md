## 3. 查过、判断不是问题

- **终结技冲击帧整屏白 + 黑剪影**（D4，用户 11-01 定）：有意模仿中村丰风格，保留。
  - 放终结技那一刻的一帧整屏近白（实测 25–46%）+ 干员色黑剪影，不算发白、遮挡、占位图形，后续巡检 / 预审一律不报。
  - vreview 的近白探针（> 12% 提示）和「发白」检查项遇到这一帧，按误报处理。
  - 只有在终结技以外出现整屏白，或一段内连续多帧白，才算问题。

- **普通敌人冲锋预警**：粉白长条 +「‹‹‹」箭头，预审报占位图。是小怪冲锋的标准预警，保留。
- **伊莎玛拉连向屏幕上方的绿线**：连向网鸣海嗣的连线，设计内。
- **白色钙晶簇**：塞雷娅的钙质化晶体，设计内。
- **生命垂危**：整屏红色暗角，正常。
- **层级**：特效压 HUD、地面层压单位、文字压在地面特效下——都没看到。唯一压 HUD 的是 D1 的余光。
- **残留**：没看到定格不消失的特效。骑士死亡冰砖残留已在 10 月修过，这次没复现。

## 4. 没覆盖到

- **倒下演出**：批跑模式状态一离开 PLAY 就停录，只拍到「生命垂危」。正式局的倒下 / 失败演出要开窗口真人局或 `--bossdeath` 类入口另录。
- **帧率尖峰时的画面撕裂**：截图 / 录帧拿到的是每帧完整画面，看不出撕裂。需要真机开垂直同步对照，归帧率会话。
- **网页版、触屏**：只跑了桌面版。
- **demo 里没出的招**：伊莎玛拉一阶段本来不出招，招式都在二阶段。下面几招没在 `--bossmoves` 里出，但在别的阶段或录像里看到了，没发现问题：
  - archon 裂潮；
  - immortal 掠海飞刃；
  - 偏执泡影呼号；
  - 骑士掷枪 / 长枪回旋：骑士预览录像里出现过。
