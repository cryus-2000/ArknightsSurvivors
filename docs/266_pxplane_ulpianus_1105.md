## 1. 颜色与原作参照

- 主色用 OP.ulpianus 审定的 7 阶深海靛蓝（组长 C 11-04 定），外加一阶压底：`#070a1e` … `#4463c8` `#7b93e6` `#c0cbf6` `#ffffff`。白只出现在命中那一拍的爆闪和水舌顶。
- 锁链用 OP.ulpianus_dust 的冷灰 6 阶。
- 精二的暗涡用 OP.ulpianus_blood 的暗段，只取最暗的几阶（暗紫红），不出亮红；红色仍然只留给危险。
- 原作参照：用 `tools/ref_fx/arkab.py` 从本机客户端 `ulpia.ab` 提取了 35 个 prefab、147 张贴图，再用 `sim.py` 回放出 16 张序列图，都放在 `Claude outputs/ulpianus_ref/`。从参照里取了两样：
  - 命中那一下是蓝白尖刺爆闪（`attack_hit`、`skill_02/03_hit`）；
  - 命中后有水泡往上飘，这是原作的标志。
  两样都改画成像素版：第 0–1 拍出尖刺爆闪，之后是 3×3 的小环水泡，飘起来、晃，最后破掉。

- **同一招最多 3 种元素**：主形（水冠 / 水束 / 链圈 / 冲击波）、贴地件（锚印 / 涟漪 / 水沟，算一件）、水滴颗粒。照地光不算元素。
- **画面范围 ≤ 判定 × 1.1**：
  - 水冠的水舌根在 0.5R，往外斜；落回的水珠水平速度压到 10–26 美术像素/秒，所以整体不出判定圈；
  - 涟漪正好推到判定半径；
  - 收链拖痕只画在 reach × 1.43 以内（就是玩法的拉拽范围）；
  - 链圈画在锚击半径上；回卷涟漪画在连携拉拽半径 180 上。
- **跟人走**：S2 链圈和起手水束带 `fo`，跟着他走。锁链和锚每帧从玩法状态（`o.hw.anchor` / `hooks` / `leash`）读手和锚头的位置。水冠、锚印、涟漪、水沟、通路都是落地的，留在原地。
- **不叠糊**：同一名干员同屏最多两记锚击水冠（最新的一记加正在收的一记），更早的立刻收掉。

## 3. 实现

- `game/scripts/render/fx_pxplane_ul.gd`（新文件，静态函数）：事件 → 件表、地面层、上层（锁链和锚）、排序项（后期冲击波）和运行时件（锁链、V 字水沟、冲锋尾迹、暗流通路、水泡、冲击波），都按美术像素逐格画、15 fps 节拍。同批五人都在改 `fx_pxplane.gd`，所以单独成文件，`fx_pxplane.gd` 只加了分流：`IDS`、`METAS` 的 `ul_`、`ev`、`draw_floor`、`draw_over`、`sort_items`、`draw_sorted`。
- **帧条**：`game/art/fx/pxp/pxp_ul_*.png`，67 张，共约 0.39 MB，另有 `game/data/pxp_ulpianus.json`。生成脚本是 `tools/pxplane_bake_ulpianus.py`。**这一版不经 pixelfx 库**，直接用 Python 逐美术像素生成，口径一样：1 帧条像素 = 1 美术像素、15 fps、贴地层压扁、色层不含光晕、最亮的像素出 emit 点表。`.png.import` 按现有格式生成，GCP 上会再 `--import` 一次。
- 颜色组在 `game/data/fx_pxplane/ulpianus.json`，只给颗粒、照地光和受击反应用。
- **钩子（都只画，不碰玩法和玩法随机数）**：
  - `seg_ulpianus`：在咬地、拽回开始、S1 重砸、冲锋开始、落地、通路、余震、钩索落地 / 拖回 / 到位这些地方各加一行 `_FXR.ev`。
  - 重砸和落地另外收集命中列表，交给 `_MI.hit`（打击感包）。它们原来不经过 `exec_shape`，所以之前没接上打击感包。
  - `hw_draw_mute` 加了参数 `leashes`：接管时拴链由转平面来画，沉默图标照旧画。
- **其他文件**：
  - `ulpianus_charge_fx.gd`：接管时 `grains()` 返回 null，S3 的旧冲锋颗粒不出。它只用画面随机数 vrng。
  - `skill_link.gd` `l_ulpianus`：接管时改发 `ul_link` / `ul_link_pin` 事件，不再画旧的锚、链和裂网。
  - `melee_impact.gd`：`IDS` 加了乌尔比安（闪色是本人的浅靛色）。撼地、定点爆破、锁链回旋这几种附带冲击不再顿一次帧。重击 = S1 重砸和 S3 落地（带 skill 标签）。
  - `data_operator.gd`：接管时仍画精二血脉红纹的轮廓光，脚下血脉环在 `floor_layer` 里照画。这两样是本体状态，不属于攻击特效。
- **旧做法对照（`fx/px_plane = 2`）**：乌尔比安没有旧 pixelfx 帧条可贴，2 时只画锁链和锚。三栏图的「旧做法」一栏留空，改成「原作 / 当前 / 转平面」。
- **音效**：没有新增。
