**悬浮的敌人读得清**（用户要点，只改画面）：脚下两道往上提的短竖线；地上影子随高度缩小变淡（离地感）；悬停期间按 15 fps 节拍上下浮动 1 美术像素。`world.gd` 画悬浮敌人时读 `fx_pxplane.air_look`，只对安洁莉娜悬浮表里的敌人生效，其余返回 (1, 0) = 原样。

**每招不同招牌**：普攻 = 内爆（碎片吸入）、S1 = 下钉光刃、S2 = 缠绕绸带、S3 = 三叉光刃 + 托起碎石、连携 = 三碎片绕圈收拢。全程「只往里收」，不画往外扩的环（坍缩爆开那一下除外）。

同一招元素：普攻 = 弹体 / 落点星芒 / 贴地件（碎片吸入 + 暗凹，精一停顿弧同属贴地件）；S3 = 光刃 / 碎石 / 场边；颗粒（黑三角碎块、紫小星、碎晶）与照地光不算元素。

**范围**：碎片起点 ≤ 拉拢半径 × 0.92，停顿弧 ≤ 落点半径 × 0.95，绸带起点 ≤ 场半径 × 0.97，场边 = 场半径 × 0.97，井旋臂 ≤ 井半径 × 0.95。范围加成（op_range、area）变大时按 1.0 / 1.15 / 1.3 三档尺寸挑不超过判定 × 1.1 的最大一档。

## 2. 同屏封顶

- 落点画面每拍至多 3 处；双重引力回响每拍 2；扩散每拍 2；沉落锁每拍 3。
- 绸带隔一个场拍（0.5 秒）出一次，且只在场内有敌人时。
- 悬浮竖线每人只画前 12 只（反重力场一次托起几十只；影子缩放与浮动照常）。
- 照地光：落点一盏（≤ 0.12 秒），S1 / 连携 / 反重力起手 / 致密爆开各一盏，走 fx_recipe 灯光预算。

## 3. 实现

- `game/scripts/render/fx_pxplane_ang.gd`：安洁莉娜一节单独成文件（第四批五人并行，少撞 `fx_pxplane.gd`）；`fx_pxplane.gd` 只加了 `IDS` / `METAS` 一项、`owns_id` 一条（没有「旧做法原样贴」对照：2 = 不接管）、ev / draw_floor / sort_items / draw_sorted 各一处分流、静态 `air_look`。
- 帧条：`tools/pxplane_bake_angelina.py` 只用 Python（PIL）烤，图形定义在 `tools/pxplane_ang_art.py`（与游戏同一份 PNG）；`game/art/fx/pxp/pxp_an_*.png` 100 张共约 160 KB + `.import` + `game/data/pxp_angelina.json`。全部 15 fps，1 帧条像素 = 1 美术像素，只按 `g.PX` 整数放大，不旋转。
- 运行时逐格画：弹尾、弹药珠、连携碎片尾迹、透镜点线（算法与 `pxplane_ang_art.py` 对应，改一边要改另一边）。弹体位置每帧走（同能天使，弹速 380 / 秒按拍跳格会一卡一卡），只取整到美术像素格。
- 状态件直接读玩法状态（只读）：`o.shots`（重力弹）、`o.fields`（失重井，按井的年龄选帧）、`o.air_list`（悬浮）、`o._state` 里 look = ring / lift 的场、`o.ammo[0]`（弹药珠）。
- 跟人 / 跟场：杖头星芒、身后光刃带 `fo` 跟她；环带、场边、绸带跟场心（队长；图鉴演示跟她自己）；落点、井、碎石、连携落定留原地。
- 钩子（都只画）：`seg_angelina.point_aoe_land` 发 `ang_land`；`field_tick` 末尾发 `ang_field`（多一个场内敌人计数 `nin`，只给画面）；`dense_collapse` / `dense_tick` 发 `ang_dense`；`sink_tick` 发 `ang_sink`；`late_shape` 扩散发 `ang_splash`；`skill_link` `l_angelina` 接管时发 `ang_link` / `ang_link_land`、不画旧碎片与环；`data_operator._draw_fields` / `_draw_shots` 接管时直接返回；`world.gd` 悬浮影子与浮动读 `air_look`。
- 原 pfx（拉拢环、停顿帧条、失重井帧条、悬浮脚下帧条、技能起手环）接管时由 `character.draw_pfx` 统一跳过绘制。
- 颜色组 `game/data/fx_pxplane/angelina.json`（颗粒 / 照地光 / 受击反应压暗紫）。

## 5. 自查（docs/246 规矩）

- 贴地层压扁（暗凹、碎片、断弧、井、环带、场边、绸带都按 0.72）、立起层竖直并按脚底 y 排序（落点星芒在身体高度，排序往前补 24，压在落点附近的敌人上；光刃排在她身后）。
- 1 特效像素 = 1 美术像素，整数放大、位置对齐 2 世界像素格；15 fps 全局节拍。
- 本色受光（帧条当普通物体画），亮芯 emit 进发光层；命中照地光走预算；Noita 颗粒少量（黑三角碎块、紫小星、碎晶）。
- 分档按技能解锁：普攻 / S1 三档、S2 精一 / 精二、S3 只有精二；每升一档多一个新元素（停顿断弧 → 失重井；绸带 2 条 → 3 条 + 奇点）。
- 持续区域只画边（环带、场边都是很暗的稀疏点线），不平涂；不整屏发白；没用危险红（发箍红压暗只在精二奇点描边一小段）；没有文字。
