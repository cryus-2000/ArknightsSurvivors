# 77 · 作战记录（局终统计界面）

> 2026-10-12 用户：「最后可以加一个统一界面，各个干员伤害统计之类的，你看着进行指标设计和UI设计」。
> 同日第二次：「UI什么的可以简洁一点，数据统计展示的也可以简洁一点」「可以记录一下」（v2）。
> 同日第三次：「这个是不是太精简了，学习一下类似于雨中冒险这种是怎么做统计的」（本页 v3）。
> **结构参考**：《雨中冒险 2》（Risk of Rain 2）的结算界面「Run Report」：左边是角色和击倒者，中间是拾取的物品格，右边是一列「标签 — 数值」统计。只借结构，不用它的素材、配色和文字；外观仍是本作局外 T5s（docs/37 §8）。
> 实现：数据 `scripts/run/run_stats.gd`，界面 `scripts/screens/run_stats_screen.gd`，计数 `scripts/run/telemetry.gd`。文字按 docs/76 写。
> 截图（不入库）：主仓库 `build/run_stats/v3/`；v1 概念图 `tools/concept_run_stats.py` → `build/run_stats/concept_*.png`（三栏之前的方案，只作历史参考）。

## 1. 入口与操作

- 胜利 / 结局结算和失败结算有三个按钮：「再次探索 R」「作战记录 Tab」「回到标题 T」。不自动弹出。Boss 演练结算没有这个按钮。
- 总览：方向键在「藏品格」和「编队条」之间走（藏品格按行列；最下一行再 ↓ 进编队条，编队条 ↑ 回藏品格；不循环）。悬停 / 选中藏品时下方显示名字、等级、稀有度、效果。编队条上 Enter / Ⓐ / 点击进干员详情。PgUp / PgDn（LB / RB）/ 滚轮滚动右栏数据。Esc / Ⓑ / Tab / 「返回结算」回到结算。
- 详情：← → / LB RB / 右上「‹ ›」换干员；Esc / Ⓑ / Enter / 「返回总览」回总览。
- 手机：总览分三页「概况 / 藏品 / 数据」，页签在标题行右边（点按或 Tab 切换）。

## 2. 显示什么

### 2.1 左栏：这一局与主控

| 项 | 内容 |
| --- | --- |
| 标题行 | 「作战记录」+ 结果：胜利写结局名 +「探索完成」（青），失败写「探索终止」（洋红） |
| 难度、探索时间 | 档名；时间用像素字大写 |
| 主控 | 待机帧（3 倍）、名字、英文名、Lv. 与精英阶段 |
| 击倒者（失败） | 最后一次掉血的来源：敌人画第一帧，环境（侵蚀、黑潮、溟痕、神经损伤、寂灭）画洋红菱形；名字 +「倒下于 mm:ss」 |
| 击破最终 Boss（胜利） | 结局对应的最终 Boss 第一帧 + 名字 +「击破于 mm:ss」 |

### 2.2 中栏：藏品与编队

| 项 | 内容 |
| --- | --- |
| 藏品格 | 按拾取顺序；每格左上一小段分类色；等级 > 1 时左下画等级点；遭诅藏品右上洋红角标，升华藏品右上紫角标；放不下时自动缩小格子 |
| 选中藏品 | 名字、Lv. 当前 / 上限（可升级的才写）· 稀有度 · 分类、效果说明（最多 3 行，按当前等级的数值） |
| 编队条 | 全队伤害 · 每秒；全队占比分段条；每名干员一张小卡：待机帧、名字、入队（被替换的写离队）、全队占比、伤害。最后一张是「藏品与支援」（援护、藏品、地雷、骑士等没有干员归属的伤害） |

### 2.3 右栏：数据（雨中冒险式统计表）

| 标签 | 口径 |
| --- | --- |
| 探索时间 | 局内时间（演练从开练算） |
| 击杀 / 精英击杀 | `g.kills` / `g.elites_killed` |
| Boss 击破 | 击破的 Boss 数（撤场的不算） |
| 造成伤害（旁注每秒） | 全队有效伤害（按敌人剩余生命封顶，同 `dmg_out`） |
| 最高单次伤害（旁注来源与干员） | 一次命中算出的伤害（不封顶） |
| 受到伤害 | 主控掉血合计（`dmg_log` + 灯火熄灭的持续掉血） |
| 生命回复 | 回复合计（各干员治疗、吸血、击杀回复、自身回复、藏品、拾取……） |
| 获得经验（旁注 Lv.） | `pickups.xp_total` |
| 获得源石锭（旁注花费） | `rfx.gain_ingots` 的合计（含熔铸后进熔铸池的）；花费 = 商店购买 + 刷新 |
| 打开补给箱 | 补给箱被打开次数 |
| 海嗣祭坛 | 打开的祭坛数（有才显示） |
| 点亮引航灯标 | 点燃数 |
| 灯火通明 | 灯火 ≥ 70 的时间占比 |
| 冲刺 | 冲刺次数 |
| 技能发动 | 全编队技能发动次数合计 |
| 藏品 | 件数 |
| 源石锭熔铸 | 触发了才显示：全队伤害 +x% |

行高 25，标签左、数值右、行间一道 1 像素细线。放不下时可以滚动（右上角显示「1-18 / 19」）。手机分两列。

### 2.4 干员详情（v2 的简化详情）

- 身份卡：造成伤害、全队占比、每秒、击杀、技能、治疗主控（有才显示）、最高单次（只在打出全局最高一击的干员上显示）。
- 伤害来源：前 5 条（名字、数值、该干员内的占比、条），其余并成「其他」。
- 主控另有「生存」：受到伤害、生命回复（前 3 个来源）、灯火通明占比、源石锭熔铸。

### 2.5 口径

- 全队占比 = 该行伤害 ÷ 全队伤害，最大余数法取整，合计正好 100。
- 每秒 = 该行伤害 ÷ 在队时长（入队到局终或离队）。
- 击杀 = 参与击杀：敌人死前 3 秒内命中过它的干员各记一次。一个敌人可以记给几名干员，各行相加可以大于总击杀。
- 治疗主控按治疗记录里和干员同名的来源算。

## 3. 界面

- 风格：局外 T5s。全屏压暗 + 一块藏青抖动底；主控块、击倒者块、藏品说明、藏品格、干员小卡、按钮带阶梯切角，标题和统计表直接排在底上。数字用 5×7 像素字（加了逗号和撇号），中文 ui.ttf。选中的藏品格 / 干员卡是 S4 近白反白 + 细青边。只用冷色和干员颜色；失败、遭诅用洋红，升华用紫，回复用绿。
- 桌面 1280×720：左栏 300 宽，右栏 356 宽，中间自适应（藏品格 48 一格，编队条 188 高）。1920×1080 按 canvas_items 拉伸，UI 逻辑仍是 1280×720，像素按屏幕取整。
- 手机（UI 逻辑约 1044×481）：一格 = 1.4 逻辑像素；三页：概况（左栏 + 编队条）、藏品（格 + 说明）、数据（两列统计表）；页签 88×36，触点外扩；「返回」按钮 44 高；不画按键提示。
- 动效（docs/62 §3.24）：主动作「藏品依次弹出」——每格从 0.6 倍弹到 1 倍（T2，`out_back(1.4)`），格间隔 ≤ 35 ms，整组 ≤ 0.6 秒。次要：统计数值计数到终值（T3，逐行错开 20 ms）、全队占比条按干员分段落位（T2，错开 70 ms）、干员卡占比计数。确认键 / 点击先跳到终态；减少动态效果直接终态，只留 T1 淡入；待机帧停在第一帧。

## 4. 计数与记录

`telemetry.gd` 新增（只累加，不读写 `g.rng`，同 seed 复现不受影响）：

| 字段 | 写入处 |
| --- | --- |
| `op_out {干员: {来源: 伤害}}`、`out_bins`（10 秒一格）、`best_hit` | `combat.damage` 记 `dmg_out` 的同一处（`on_dmg`） |
| `op_kills`（参与击杀） | `on_dmg` 在敌人身上记 `_hb {干员: 最近命中时刻}`（纯记账字段）；`kill(e)` 之前 `on_kill_credit` 按 3 秒窗口记给各干员 |
| `op_casts` | `character.spend_sp` |
| `joins`（入队 / 离队） | `squad.add` / `squad.remove` |
| `chests` / `altars` | `combat.kill` 的补给箱、海嗣祭坛分支 |
| `ingots_got` / `ingots_spent` | `rfx.gain_ingots` / `shop.buy`、`shop.refresh` |
| `dodges` / `blocks` / `dashes` / `lamp_s` | 闪避、护盾抵挡、冲刺、灯火四档秒数 |

击倒者用原有的 `telemetry.last_src`。

**runs.jsonl**：本地记录每局多一段 `run.op_stats`，每名干员一项：`id`、`join` / `left`（秒，-1 = 没离队）、`dmg`、`share`、`dps`、`kills`（参与击杀）、`casts`、`heal`（治疗主控）、`top`（主要来源）。只在 `save_local` 里加，沿用原规则：调试版与对内包写，对外包不写，测试运行不写。BALANCE 行（`record()`）不变，SCHEMA 不升。

## 5. 验收

- 快检 `run_stats`（`tests/run_stats_test`，`--balance --op=mizuki --squad=skadi`，106 条）：
  - 假记录（`RunStats.fake_raw()`）：各行之和 = 全队伤害；整数占比合计 100；每行来源之和 = 该行伤害；「前 5 + 其他」守恒；离队干员的在队时长；承伤合并；统计表与模型一致（造成伤害 = 全队伤害、技能发动 = 各干员合计、藏品 / Boss 击破 / 补给箱 / 熔铸 / 祭坛 / 灯标、受到伤害 = 主控承伤）；胜利时最终 Boss。
  - 真实短局（45 秒）：按干员拆的输出 = `dmg_out` = 时间线合计；参与击杀；`op_summary()` 占比合计 1；统计表击杀 / 藏品数 / 经验 / 时间；藏品列表 = `g.relics`。
  - 界面：结算有「作战记录」→ 打开；编队卡数 = 行数；← → 不循环；藏品格 ↔ 编队条方向键往返；Enter / Esc / 点卡 / 点返回；1280×720 与 1044×481（三页逐页）命中区不出屏、卡片不重叠。
- 实机截图：`--statsshot=<秒>[,dead]`（autotest 钩子：结算 → 总览动效中 → 总览 →（手机：藏品页、数据页）→ 主控详情 → 第二名干员详情，存 `--shotdir`）。
