- 弹壳（Noita 颗粒，黄铜 → 暗铜，落地弹一下）：每拍至多 1 颗（倾泻 2 颗）。

## 3. 实现

- `game/scripts/render/fx_pxplane_exu.gd`：能天使一节单独成文件（四人并行，少撞 `fx_pxplane.gd`）；`fx_pxplane.gd` 只加了 `IDS` / `METAS` 一项和 ev / draw_floor / sort_items / draw_sorted 各一处分流。

- 运行时逐格画：弹体、连锁细线、连携曳光、扫射枪口发红（算法与 `pxplane_exu_art.py` 的 `bullet()` / `tracer_line()` 对应，改一边要改另一边）。**偏离 docs/246 的一处（同流明）**：弹体 520 像素 / 秒，按 15 fps 跳格一次跳 35 像素会一卡一卡，所以位置每帧走、只取整到美术像素格。
- 挂在人身上的件（枪口焰、过热烟、S3 起手光环）带 `fo` 跟她走；S3 持续光环、队友头顶光环每帧按当前位置生成；命中火花、贴地环留原地。
- 钩子（都只画）：`seg_exusiai` 开火 `exu_fire`、命中 `exu_hit`、过热 `exu_heat`，接管时 `exu_draw` 不画旧弹体；`vis_growth` 额外弹命中 `exu_xhit`（接管时不画通用弹）；`late_shape` 连锁 `exu_chain`、溅射 `exu_splash`；`ob_elite` 祝福星芒 `exu_bless`；`ob_fx.fx_hold_strips` 接管时跳过 `fx_exusiai_halo`；`skill_link` `l_exusiai` 接管时发 `exu_link`、不画 LFA 曳光（`in_band` 提前到画面前，结果不变）。
