## 2. 同屏封顶（纯射手、高射速）

- 弹体：每人只画最新 16 颗（额外弹 6 颗），更早的照常结算、只是不画。
- 枪口焰：每人同时 1 个，新的一轮顶掉旧的（4 连射 / 扫射不叠）。
- 命中火花：每拍（1/15 秒）至多 3 团（技能弹 4、叠满金 X 5），同时在画至多 8 团；额外弹 / 连锁每拍各 ≤ 3，溅射环 ≤ 2，弹片环 ≤ 2。
- 照地光：开火一盏、命中一盏，各每拍至多 1 盏，走 fx_recipe 灯光预算。
- 弹壳（Noita 颗粒，黄铜 → 暗铜，落地弹一下）：每拍至多 1 颗（倾泻 2 颗）。

## 3. 实现

- `game/scripts/render/fx_pxplane_exu.gd`：能天使一节单独成文件（四人并行，少撞 `fx_pxplane.gd`）；`fx_pxplane.gd` 只加了 `IDS` / `METAS` 一项和 ev / draw_floor / sort_items / draw_sorted 各一处分流。
- 帧条：`tools/pxplane_bake_exusiai.py` 只用 Python（PIL）烤，图形定义在 `tools/pxplane_exu_art.py`（与游戏同一份 PNG）；`game/art/fx/pxp/pxp_ex_*.png` 78 张共约 22 KB + `.import` + `game/data/pxp_exusiai.json`。枪口焰按 5 个平面角预生成 + 水平翻转；命中、环、光环不分方向。
- 运行时逐格画：弹体、连锁细线、连携曳光、扫射枪口发红（算法与 `pxplane_exu_art.py` 的 `bullet()` / `tracer_line()` 对应，改一边要改另一边）。**偏离 docs/246 的一处（同流明）**：弹体 520 像素 / 秒，按 15 fps 跳格一次跳 35 像素会一卡一卡，所以位置每帧走、只取整到美术像素格。
- 挂在人身上的件（枪口焰、过热烟、S3 起手光环）带 `fo` 跟她走；S3 持续光环、队友头顶光环每帧按当前位置生成；命中火花、贴地环留原地。
- 钩子（都只画）：`seg_exusiai` 开火 `exu_fire`、命中 `exu_hit`、过热 `exu_heat`，接管时 `exu_draw` 不画旧弹体；`vis_growth` 额外弹命中 `exu_xhit`（接管时不画通用弹）；`late_shape` 连锁 `exu_chain`、溅射 `exu_splash`；`ob_elite` 祝福星芒 `exu_bless`；`ob_fx.fx_hold_strips` 接管时跳过 `fx_exusiai_halo`；`skill_link` `l_exusiai` 接管时发 `exu_link`、不画 LFA 曳光（`in_band` 提前到画面前，结果不变）。
- 没有「旧做法原样贴」对照：`fx/px_plane = 2` 时能天使不接管（= 当前游戏），三栏图只有「当前游戏 / 转平面」两栏 + 原作参照。
- 颜色组 `game/data/fx_pxplane/exusiai.json`（颗粒 / 照地光 / 受击反应）。
- 原作参照：`Claude outputs/pixelfx_ul_exusiai_saria/exusiai_ref_check.png`（原作 renwu_05 光环、angel_02 S3 光环 + 光刺、trail_32 白色细长尖梭弹体）；只在本机。

## 7. 第二轮（11-05 用户看 GIF：「继续改进一下会话里说的缺点，同时也加强一下枪械感」）

- **倾泻不再像梳子**：8 发同一帧出膛（玩法不动），画面上按序号前后错开 0 / 3 / 6 / 9 美术像素（只画）。
- **GIF 模拟光照**：整体压暗到 0.8，枪口照地（1 拍）、命中照地（2 拍）各一盏暖色径向提亮；游戏里枪口照地光同步加亮（半径 70+、强度 0.5+）。
- **枪口火**：改成 2 拍的硬星形短闪——3×3 白芯 + 前向长芒（根部 3 宽收尖）+ 侧芒 + 后向短芒；连射时十字（侧芒垂直）/ 斜星（侧芒斜前 45°）两种交替；S3 八芒；倾泻五道扇形硬芒；每 3 轮带一缕枪口烟（`smoke_up`，5 拍上飘）。
- **抛壳**：每轮一枚黄铜弹壳往后上方抛出、落地弹一下停住（游戏里走配方颗粒 shard，每拍至多 1 枚、全队颗粒池封顶）。
- **弹道**：更细、尾迹短——2 格白热弹头（弹头 2 像素宽）+ 很快变暗的 1 像素尾（速射 7–9 格）。
- **命中**：不再是一团光，改成按弹道方向的硬质金属火花溅射（橙白，多数往回溅、两道往前穿）+ 2–3 块深色碎屑飞起落下；模式色只留在 3×3 芯上；同一只身上 2 拍内只留一团（过载 4 连射不叠白）。**精二质变**加一道沿弹道往前的白金穿甲亮线（2 拍）。命中帧条按 5 个平面角预生成 + 翻转。
- **后坐**：开火那一拍干员本体往后挪 1 美术像素（`character.draw_body` 读 `fx_pxplane.recoil`，只画，判定不动）。
- 音效维持 §4 收紧后的档位（枪声间隔 0.05 秒、命中 0.2 秒 −6.5 dB）。
- 帧条 186 张约 49 KB（枪口火两种变体 × 5 方向、命中 × 5 方向）。
