# 网页版全屏与 Esc（11-06）

用户原话：「itch全屏之后一按esc就会退出全屏，修复一下」。

## 限制

浏览器全屏时，Esc 被浏览器用来退出全屏，网页拦不住。

能拦住 Esc 的只有 Keyboard Lock：`navigator.keyboard.lock(['Escape'])`。它的条件是：

- 顶层页面；
- 页面自己请求的全屏；
- 只有 Chrome / Edge 支持。

锁住后，短按 Esc 会照常交给页面（等于暂停），长按才退出全屏。这是浏览器自带的行为。

itch 把游戏放在 iframe 里，锁不住，所以要兜底。

## 做法

代码在 `game/scripts/web_fs.gd`，只在网页版桌面生效。手机 / 触屏、Windows 包、无头测试都不装，也不碰对局逻辑。

1. **能锁就锁。** 页面自己进全屏、而且是顶层页面时调 Keyboard Lock，失败就静默降级。
2. **退出全屏就暂停。** 局内只要退出全屏，多半就是按了 Esc，直接打开暂停菜单。判断依据：
   - `fullscreenchange`；
   - 加上 iframe 尺寸等于屏幕尺寸。itch 的全屏按钮是把外层页面全屏，iframe 里收不到 `fullscreenchange`，只能看尺寸。
3. **「返回全屏」按钮。** 暂停菜单下方显示，只在这次暂停是由退出全屏引起时出现：
   - 点击或按 F 重新请求全屏；
   - 点击和按键都算用户手势，所以浏览器允许；
   - 重新进的是 iframe 自己的全屏。
4. **P 键。** 网页版桌面上，P 和 Esc 一样暂停 / 继续，全屏时按它不会退出全屏。暂停菜单下方写了一行：「全屏时 Esc 会退出全屏，可按 P 暂停 / 继续」。

## 本地模拟 itch

```
python tools/serve_web.py --dir <网页包目录>
```

然后打开 `http://127.0.0.1:8794/__itch.html`。这个页面是 16:9 的 iframe（宽不超过 1280），带 `allow="fullscreen"`；iframe 下方的按钮像 itch 那样把外层容器全屏。

## 实测

见文末，按浏览器逐条记录。

### 11-06 本地测试（Claude 应用内置浏览器，Chromium 内核，itch 式 iframe）

测试页是 `/__itch.html`。测试时浏览器面板是隐藏的，渲染节拍靠 rAF 替身。

**已确认的：**

- **退出全屏，对局内。** 局内退出全屏后立刻打开暂停菜单。菜单下方有一行「全屏时 Esc 会退出全屏，可按 P 暂停 / 继续」，下面是「返回全屏」按钮（F）。
- **退出全屏，局外状态。** 在开场动画或选卡这类非对局状态里退出全屏，会等回到对局时再补一次暂停。
- **itch 外层全屏的尺寸判断。**
  - iframe 变成屏幕大小时记为全屏；
  - 缩回去时记一次退出。
- **P 和 Esc。** P 暂停和继续都正常。Esc 仍然照常暂停，这时不显示「返回全屏」。
- **「返回全屏」按钮。** 点击会调用重新请求全屏。

**没能确认的：** 真正进入和退出全屏。隐藏的面板会拒绝全屏请求，外层按钮也一样被拒。所以下面这些没有实测，都按浏览器文档推断：

- Chrome / Edge / Firefox 真按 Esc 的表现；
- 顶层页面里 Keyboard Lock 的效果。

**各浏览器预期：**

- **Chrome / Edge，itch iframe 内：** 锁不住 Esc。按 Esc 会退出全屏，然后游戏自动暂停，玩家点「返回全屏」或按 F 回去。
- **Chrome / Edge，顶层页面自己全屏**（直接打开游戏页，用设置里的全屏）：可以锁住 Esc。短按 = 暂停，长按约 2 秒才退出全屏。
- **Firefox / Safari：** 不支持 Keyboard Lock，表现同第一条。

**不受影响的：** 手机 / 触屏、Windows 包、无头测试都不装这套。
