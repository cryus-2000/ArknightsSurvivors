## 2. 本作方案

- **纯荣誉**：不给藏品、生机细胞、寻访凭证、任何数值。陈列页和获得提示是唯一的「奖励」。
- **与已有系统不重叠**：不替代图鉴（图鉴记「见过什么」）；蚀刻章记「做过什么」。
- **三星 + 镀层**：★ 一次就能拿 / ★★ 要打几局 / ★★★ 要专门去挑战。镀层 = 同一枚章的更高条件，**只给少数**（本批 8 枚），镀层不改变拥有状态。
- **隐藏章**：未获得显示「？」，只写分组，**不写条件**；获得后展示条件与文案（原作未查到隐藏章的未获得显示方式，这里是本作自定）。
- **不计入的局**：同 `Roster.on_run_end`：演练（Boss 试炼）、练习、图鉴演示、非 PLAY 模式、任何带 `--` 参数的测试局；对内包同对外（对内包存档独立）。
- **判定时点**：一次探索结束（`game.gd` 进入 WIN / DEAD，与寻访凭证 / 生机细胞同一处）一次性判定整局数据；少数累计量在发生时就累加、局终统一判。

## 4. 存档与统计

**存档**（`settings.cfg` 新段 `[medals]`，随云存档）：

| 字段 | 内容 | 云存档合并 |
|---|---|---|
| `medals` | `{id: {"t": 获得时间(Unix 秒), "plated": 镀层时间或 0}}` | 并集；`t` 取较小，`plated` 取非 0 中较小 |
| `medal_stats` | 累计量：`runs`、`pick_draws`、`crates_total`、`meta_save_n`、`run_days`（最近连续天数 + 最后一天） | 数值取较大；连续天数取较大、最后一天取较新 |
| `op_wins` | `{干员 id: 通关次数}` | 逐键取较大 |

- 云存档新键走 `core/cloud_pack.gd` 的 OPTIONAL_KEYS（缺省不影响旧存档，参照 `meta` / `dbest` 的做法）。
- **判定入口**：新文件 `core/medals.gd`（规则）+ `data/medals.json`（章表：id / 组 / 星 / 条件类型与阈值 / 镀层条件 / 隐藏 / 文案）；`game.gd` 局终在 `Roster.on_run_end` 同处调 `Medals.on_run_end(g, won, raw)`，`raw` 就是 `run_stats` 里那份一局原始数据（已含 kills / elites / downs / dodges / blocks / beacons / bosses / ops）。
- 局内累加的新统计（`g` 上新增几个计数，写进 `run_stats` 原始数据）：本局招募数、本局行商花费、`meta_save_n`（免死 / 复活触发）、通关时生命比例；`crates_total` 用 `data.crates` 局终累加。
- **测试**：`tests/medals_test.gd` 单测（章表完整、每章判定函数用假 `g` 造数据、镀层不丢拥有、云合并）；`check.py` 加场景 `medals`。`--medals=<id,…>` 预置已得章（只在内存，截图用）。

## 5. 界面

- **陈列页放在图鉴**：图鉴新增第 8 个页签「蚀刻章」（原型：[reference/medals_sketch.svg](reference/medals_sketch.svg) 草图 A）。不新增标题磁贴——图鉴已是「记录类」入口，章的定位和它一致；局外主界面不加东西。
- **版式**：左栏 5 个分组 + 筛选（★ / ★★ / ★★★、有镀层、未获得）；中间是章盒网格（圆章，已得亮青、镀层金边、未得虚线灰、隐藏显示「？」）；右栏是选中章的详情（条件、镀层条件与是否达成、文案、获得时间）。与图鉴其他页同一套切页动效，减少动态效果时直接出。
- **自定义套组（原作「编辑」）本批不做**：36 枚用不着挑；以后章多了再加。
- **获得提示**（原作未查到，本作自定，草图 B）：
  1. 局内：右下角小条「蚀刻章 · 名称」，2.5 秒淡出，**排队、不打断操作**、不压 Boss 预警和技能提示；触屏也在右下，避开按键区。
  2. 结算页底栏新增一行「本次获得」：列出本局拿到的章（含镀层），点开直接跳到陈列页；一局没拿到就不显示这一行。
  3. 镀层：同样的小条，描边换金色，文案「蚀刻章 · 名称（镀层）」。
- 配色沿用图鉴青黑色系；金色只给镀层。
