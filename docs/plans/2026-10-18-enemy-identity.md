# 怪物原作机制补齐（用户已确认检查清单）

基于 main 6b697796，分支 codex/enemy-mechanics；保留原创攻击与全部现有动画。先编写真实战斗回归，确认旧实现失败，再补数据、结算、状态与显示，最后运行 check.py --auto --jobs 3 和同 seed 复现。这里只交付工作分支，不发布。

## 设计和验收
- 凿石者：架起 20 秒内物理承伤乘 0.55，法术弱点照旧；结束恢复。不把通用 def 改成物理防御。
- 引痕者：半血硬化物理承伤乘 0.65，保留加速、前刺、铺痕；法术/真实伤害不受硬化影响。阈值转换优先于额外招式。
- 巢涌者：眩晕/寒冷时长减半；免疫铃兰式停顿，不免疫普通减速和浮空；当前以 stun 实现的招式仍按项目眩晕分类。补光环法伤（每秒 0.2 倍攻击，0.5 秒一次），重叠只取攻击最强者；离开范围/死亡/封印立即停止，流明光域内不生效。保留神经光环与原创触须攻击。
- 箱形恐鱼：眩晕与寒冷免疫；本项目封印对应沉默，免疫封印；普通减速和浮空仍有效。不是宝箱海怪，不补尖叫。
- 冰冻目前没有独立敌方状态；骑士给敌人的寒冷减速走 cold 分类，未来新增冻结仍需显式接入。
- 囊海爬行者：验证跨多个 15% 阈值按现有预警与间隔逐次消化、死亡取消待发爆发；不改成瞬间连爆。

## 修改范围
数据 enemies.json；combat.gd 物理减伤；enemies.gd 控制分类和光环结算；enemy_ai.gd 半血转换；op_api 与必要的控制来源调用；gallery.gd 与 world.gd 状态显示。复用已有光环和绘制方式，不重画动作。
数值是本游戏试调值，不直接移植原作防御数。状态参数写数据。新增 enemy_identity_test 场景纳入 check.py，检查伤害类型、状态生效/失效、控制例外、光环重叠与离场、爆发阈值。
