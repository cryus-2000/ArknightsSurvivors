# 35 · 藏品流派重做方案

> 2026-09-26 方案稿（另一会话起草）；同日由本会话接手落地（提交 280f1bb），表中数值已改成落地后的实际值，落地时的取舍见文末「落地记录」。以本文件为准。

## 目标与原则

藏品流派从「水月单人时代」改成「编队怎么打」：玩家看编队里有谁，就知道该往哪条流派凑。现在已实装 86 件，只有 47 件有流派，触手流 7 件里 4 件离开水月就是废卡。

- 每条流派都要能被至少 4 名干员吃到，不绑定单个干员。
- 每条流派都有 基础 → 稀有 → 核心 → 升华 的梯度，现在稀有档全游戏只有 3 件，要补到每条流派 1–2 件。
- 优先启用官方藏品：总表 262 件里还有 176 件未实装，其中不少原来标「本作没有先锋 / 近卫 / 重装」，编队制下已经可以用了。
- 说明写效果，不写机制名：玩家看卡就知道对谁生效、生效多少。
- 只改藏品层（`relics.json` / `relic_effects.json` / `relic_fx.gd`），不动干员数值和敌人曲线。
- 受击、回复、减伤的对象是**主控干员**（博士已不再是主控）。

改成 8 条流派加一组通用：近战、远程按职业分，追击、控制、收割按打法分，新增「编队协同」吃编队构成，生存类单独成「守护·续航」。件数为本方案落地后的已实装数。

## 新增流派 H：守护·续航

## 实现要点与验证

大部分是数据改动，引擎只需要三处小扩展：属性按职业生效、「追击」标签集合、按编队过滤候选藏品。

1. **数据**：`relics.json` 的 `lanes` 换成 A–H，逐件改 `lanes`；新增 `requires_class`（职业门槛）；`relic_effects.json` 补 40 项效果和说明（上表 29 项 + H 新增 11 项）。
2. **按职业生效**：`relic_fx._apply_stat` 透传 `scope`，属性块已经支持 `class:<职业>` 作用域；在 `character.scopes()` 里加 `range:近战 / 远程`，攻击范围类藏品写 `op_range`。
3. **追击**：新增属性 `followup_dmg`，在伤害结算时对带 `follow_up / aftershock / detonation / entity` 标签的伤害生效；去掉 `mizuki_tentacle_mult` 与 `src_is: tentacle` 两个水月专用写法。
4. **候选池**：`can_offer` 增加「编队里有该职业」判断；编队上限类藏品走 `squad.extra_slot`，已解锁就不再出现。

### 引擎

- 属性作用域：`relic_effects.json` 的 stat 效果可带 `scope`（`class:<职业>` / `range:近战` / `range:远程`），`character.scopes()` 新增 `range:` 作用域（近卫 / 重装 / 先锋 / 特种算近战）。
