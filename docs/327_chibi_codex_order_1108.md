# 327 干员 Q 版像素小人美术单（Codex，11-08）

用户 11-08 定：20 名干员每人一张 Q 版半身像素小人，交给 Codex 逐人手绘。Claude 先用格子图试过一版，用户判不合格（问题见 §5），这一版只当反例。

流程按 docs/104（静态 f0 那条线：按部件逐格画、三层自检、本地候选先给用户看）。本单只写范围和这次的特殊要求。

## 1. 用在哪里

- **分享战绩卡的专属相框**（docs/313）：相框左下角并排放本局小队最多三人，队长在最左、压在最前。参考 `build/chibi_ref/frame_usage_example.png`。
- 游戏里按一格放大 5 倍显示，并自动外加一圈一格宽的相框描边色轮廓。**交付图里不要画外轮廓**。
- 以后可能还会用在选人界面和图鉴上，所以每人都要能单独认出来。

## 2. 规格

| 项 | 要求 |
|---|---|
| 画法 | 照用户给的参考小人：`build/chibi_ref/style_chibi_crop.png`（局部放大）和 `style_frame_full.jpg`（整张）。只学画法，不抄人物、配色和相框 |
| 构图 | 半身像，只画到腰。头大身小，头约占 2/3 高 |
| 尺寸 | 约 16–20 格宽、17–19 格高。双马尾、帽檐、角、耳朵可以伸到头外，但整张不超过 22 × 20 |
| 一格 | **交付 1 格 = 1 像素**（不要放大），PNG，透明背景 |
| 描边 | 不用纯黑外描边，最深的发色或衣服色就是轮廓（同参考图） |
| 朝向 | **所有人都往右看**，3/4 侧脸，透视要统一：脸、刘海、鬓发、肩膀都朝同一个方向转 |
| 眼睛 | **露几只眼按原作立绘**（§3 表里的「露眼」一列是 Claude 的初判，Codex 照立绘逐人核对，以立绘为准）。露出的眼睛要大、要一样大，在游戏里放大 5 倍后必须看得清 |
| 脸 | 脸不要宽。Claude 版推进之王的脸太宽，是反例 |
| 发型 | 发型、刘海、发色分层按各人立绘还原。**不要把大家都画成齐刘海**；碎刘海、侧分、呆毛、挑染都要保留 |
| 性别感 | 男性干员（流明、乌尔比安、逻各斯、水月）要画得像男性：眉眼、脸型、肩宽都要有区别，不要画成女生 |
| 配色 | 取 PRTS 立绘：`build/prts_ref/<id>/`（standing_1 / idle 帧）、取色表 `build/prts_ref/_colors/<id>.png`（有的就按它）。docs/87 §4.3：色调、瞳色、衣服细节和立绘一致 |

## 4. 交付与验收

- **交付路径**：`art/incoming/chibi_1108/op_<id>_chibi.png`（20 张），同目录放 8 倍放大总览图（20 人一张）、handoff、自检表（docs/104 §2 第 5 条）。
- **顺序**：先交三人试点，用户过了再做剩下 17 人。试点是德克萨斯、斯卡蒂、乌尔比安，各代表一类：普通、宽檐帽、男性加面罩。
- **用户看**：8 倍总览加原尺寸；并且放进游戏、在相框里按实际大小看。
- **接入（Claude）**：拷到 `game/art/operators/<id>/op_<id>_chibi.png`，Godot 导入后截分享卡。截图命令：autotest `--settleshot=win --shareopen --sharesave --shareframe=ri|deep`，配 `--op=<队长> --squad=<两名队友>`。代码不用改：`share_card.chibi()` 读这张图，按一格 5 倍放大、加相框描边色轮廓。
- `tools/chibi/chibi_grids.py` 是 Claude 版的格子图，Codex 版接入后作废、可以删掉。

## 5. Claude 版的问题（反例：`build/chibi_ref/claude_v1_rejected.png`）

用户 11-08 依次指出的问题：

1. 套模板，干员的特色和发型没了。后来改成逐人画。
2. 眼睛太小，缩到相框里就看不见了。
3. 每个人都只露一只眼；改成双眼以后，两只眼又不一样大。
4. 刘海全被统一改成了齐刘海。
5. 眼睛挤在脸右边，左边空出一块；居中以后又成了正脸，透视不对。
6. 推进之王的脸太宽。
7. 斯卡蒂的帽子怪。
8. 乌尔比安像女生。
9. 铃兰两只耳朵分得太开。
