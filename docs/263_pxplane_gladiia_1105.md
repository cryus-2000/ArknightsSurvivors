**同屏封顶**：钩索同时至多 `HW_HOOK_MAX` 条（玩法本身）；到位拍水 / 锚印每次至多 3 只；扩散涟漪每拍（1/15 秒）至多 2 团；倒钩颗粒每拍至多 2 次；龙卷同一时刻一处（S3 `cap: 1`）。

**不碎**：水刺只在出手前 0.4 秒；冲击环、湿痕、拖痕、锚印都按固定噪声成团消散（不抖动、不留细环）；不做竖直水柱，竖直方向只有水刺和水花冠的水滴。

**同一招元素 ≤ 3**：主形（水刺 / 水花冠 / 水环 / 龙卷 / 涟漪）、贴地件（冲击环 / 湿痕 / 拖痕 / 锚印 / 暗沟）、颗粒（水滴）；链与钩头算钩索本体，照地光不算元素。

**原作对应**：普攻命中的深蓝水刺 + 白芯取自原作 `glady_attack_01_hit`；S2 起手倾斜大水环取自 `glady_skill_02_start`；S3 漩涡水墙按用户认可的龙卷版（`gl_v4b_s3_tornado.png`、`gl_v5_ult_tornado.png`）；S1 原作是一道长白水线（`glady_skill_01_line`），本作在钩线上留一道贴地的「被分开的水」（暗沟 + 两侧白沫），第一版两侧立起的水墙原作没有、用户嫌像墙，已去掉。连携「聚拢」是本作原创。参照图只在本机 `Claude outputs/gladiia_ref/`，不进 git。
