# 243 后期攻击不显眼 / 依赖终结技清屏 诊断（11-05）

**结论摘要**
1. 看不见的主因是「小、碎、不长大」，不是不够亮：后期我方攻击只占战场区 1–8%，碎成几百到两千多块、中位 2–4 像素；3:00 → 9:30 占屏面积基本不变。亮度均值排第 2–6（10 层里），比结晶、受击闪白、敌方预警的高光低一截，又被拥挤降噪压到 ×0.65–0.89、被敌方预警层盖住 18–87%。
2. 红不是战场里的红：战场中央红像素只占 0.4–1.7%，整帧却有 10–30%——几乎全是**受伤红边**（每次受击拉满，后期每分钟挨打数百次，等于常亮），外加预警缺省色是红、敌方弹幕描洋红边。小队没有边光 / 脚底光，后期被预警框和结晶盖过。
3. 「依赖终结技」是结构性的：小怪生命按时间涨到 3 分钟的 2.4 倍，普攻 / 技能的形状和数量几乎不随成长变（升级卡里改形状的只有「贯穿」，「协同·广」不进卡池）；终结技对小怪的伤害按同一条生命曲线定档、半径约 550 覆盖全屏，所以永远清得动。后期（5–8 分钟）终结技占普通怪伤害 17–30%、击杀 14–24%；高潮位下非终结技清怪比中位 0.64–0.92（< 1 = 清不过来），同屏清空要 12–15 秒。
4. 终结技不滚雪球：每局 5–7 次、间隔稳定 91–107 秒，充能 72% 来自伤害、18% 来自击杀；它从不击杀精英（留 10% 血），但每次削中期 Boss 22–41% 血量。
5. 召唤物 / 放置物「出力不出镜」：带地雷组 + 轰隆隆时「地雷」占全队伤害 14.5%，Mon3tr 在凯尔希局占 27–39%，但地雷本体是半径 9 的暗褐圆、画在敌人之下，截图里找不到。

基准：`claude/integ-1105` db27f6745，特效新版开关（`fx/px_unleashed` 等）全部缺省关。本稿只诊断、给方案，不改玩法和画面；只加了只读遥测（§1.1）。

## 1. 方法

### 1.1 只读遥测 `--diagbins`
- `game/scripts/run/diag_bins.gd`，telemetry.gd 挂 4 处钩子；只有命令行带 `--diagbins` 才启用，不读写随机数、不改玩法，BALANCE 记录多 `diag` / `diag_x` 两个字段。
- 每 30 秒一桶：伤害 / 击杀按来源类别（普攻 core、技能 S1–S3、天赋、分支、终结技、连携、藏品、召唤物、支援），对普通怪的伤害单列；每秒采样同屏（1280×720 ÷ 战斗缩放）敌人数与怪群总血量、新刷怪生命总量；终结技充能来源累计。
- S1–S3 按「命中时该干员最近一次起手的技能序号」归类，持续性技能区域跨技能时有误差。
- `diag_x`（批跑第 42 局起才有，即潮位 10 的 36 局）：每种预警的次数 / 时长 / 面积 / 颜色；每只精英从出现到死亡的秒数、致死来源、终结技伤害占其最大生命；每只 Boss 被终结技打掉的血量比例。

### 1.2 批跑
- 20 名干员各当一次队长（单人开局、机器人自然招募），种子 11 / 23，潮位 0（缺省）与 10（深潮），机器人 normal，`--nodeath` 打到终局：80 局，脚本 `tools/late_game_diag.py`。
- **打不到 17 分钟**：最终 Boss 10:00 登场，打掉或到 780 秒（`bal_maxt`）就结算，一局 10:40–13:00。下文「后期」= 5–9 分钟，10 分钟起是最终 Boss 战。
- 召唤物专项：凯尔希 + 水月 + 塞雷娅，开局给 210 支援地雷组 + 211 支援轰隆隆，同上 2 种子 × 2 潮位 = 4 局。
- 原始数据在本机 `build/late_diag/raw*.jsonl`（3.6 MB，未入库）；汇总表、图在 `docs/assets/late_game_diag/`：`tide_minute.csv`（潮位 × 分钟）、`per_op.csv`（按队长）、`per_run_minute.csv`（逐局逐分钟）、`share_by_minute.png`、`clear_ratio.png`、`ult_kill_by_op.png`。

### 1.3 截图与分层量测
- 云端 xvfb + `--rendering-driver opengl3` 能画世界层；1280×720，`--fixed-fps 60` 非实时（约 0.0659 局内秒 / 帧），同种子 11。脚本 `tools/late_game_diag_shots.py`。
- 时间点改为 3:00 / 8:00 / 9:30 / 10:40（13、17 分钟不存在）。干员：德克萨斯（近战刀光）、能天使（远程弹）、艾雅法拉（法术爆炸 / 熔池）、浊心斯卡蒂（召唤海嗣）；另加凯尔希召唤专项，和协调人转来的用户截图同队的逻各斯 + 德克萨斯 + 铃兰（9:46）。
- 分层：同一局再用 `--clutterdbg=nofriend / noenemy / nofoe / noamb / nogem / nonum / nomire / noaura / noground` 与 `--lookdbg=noflash` 各跑一遍（该层全透明、代码照跑，画面随机数照抽），与完整画面逐像素比，差异 > 0.06 的像素 = 该层掩码。量的是战场区 (180,150)–(1100,560)，避开 HUD。`nofoe` 会跳过整段绘制，个别帧画面随机数错位，敌方层面积偏高约 3 个百分点（同 docs/221 §1）。
- 截图：`shot_<干员>_<秒>.png`；掩码描边图 `mask_*.png`（青 = 我方特效，品红 = 敌人，橙 = 敌方弹幕 / 预警）；色彩预算 `budget_logos_*.png`、红像素图 `budget_red_logos_*.png`、小队特写 `squad_crop_logos_586.png`；数值 `visual_metrics*.json`、`budget_logos.json`。

## 2. 打得动：为什么后期靠终结技清屏

（技能 = S1 + S2 + S3；天赋 / 分支 / 连携合计 5–8%，表里略。第 9 分钟终结技低是机器人从 570 秒起攒终结技留给最终 Boss（`ult/bot_hold_from`）。图：`share_by_minute.png`。）

- 普攻占比从 70% 一路掉到 36–47%，技能稳定在 15–24%：**技能没有接替普攻**，缺口由终结技和藏品补。
- 「几分钟起跟不上」：清怪比 = 非终结技对普通怪的伤害 ÷ 同一分钟新刷怪的生命（`clear_ratio.png`）。
  - 潮位 0：第 4 分钟起中位在 0.70–1.11 之间来回，40–100% 的局 / 分钟 < 1，就是「刚好跟得上，一波大群就落后」；
  - 潮位 10：第 4–8 分钟中位 0.64–0.92，60–95% 的局 / 分钟 < 1——**从第 4 分钟起持续清不过来**，只能靠终结技周期性清场；
  - 不靠终结技清掉同屏怪群要多久（同屏怪群总血 ÷ 非终结技秒伤）：潮位 0 稳定在 7–10 秒；潮位 10 从 3 分钟 7 秒涨到 8 分钟 15 秒。
- 同屏敌人：潮位 0 后期均 16–24、峰值 33–52；潮位 10 均 22–33、峰值 47–69。

### 2.3 根因
1. **小怪生命线性涨，我方攻击形状不涨。** 普通怪生命倍率（时间 × 难度）3:00 = 2.85、10:00 = 6.87。我方后期加成几乎都是数值（攻击 / 攻速 / 技能强度）：升级卡里改变攻击形状的只有「贯穿」（远程穿 2，最多 2 张）；「协同·广」（全队范围 +8%）`pool: false` 不进卡池；「近战·扩域」+12% 只给近战扩域干员；可见成长藏品（docs/163：多射 / 补射 / 剑气 / 范围）要掉落才有。怪变多变厚，单体 / 小范围攻击清不完。
2. **终结技按怪的生命曲线定档。** `ult.gd budget()`：小怪预算 = `ult/ref_hp`(20) × 时间倍率 × 难度 × `ult/minion`(2)，再乘各人 `dmgk`；半径 526–708（约整屏）。它天生跟得上刷怪曲线，普攻 / 技能没有这层保底。
3. **机器人放终结技的条件**：屏内 ≥ 40 只（`ult/bot_n`）或精英近身或生命 < 30%。人类玩家会更早按，依赖感更重。

### 2.4 终结技频率与充能（协调人追加问题 3）
- 每局 5–7 次（均 5.9）；相邻两次间隔中位：0–2 分钟 107 秒、2–4 分钟 104、4–6 分钟 94、6–8 分钟 91、8 分钟后 96。**没有滚雪球**：后期击杀多，但每秒充能有上限 `ult/e_sec_cap`（1.2 / 秒），击杀充能反而从 3 分钟的 17 / 分钟掉到 9 分钟的 7.5 / 分钟。
- 充能来源（80 局合计）：伤害 72%、击杀 18%、受伤 8%、连携 1%。按分钟（潮位 10 的 36 局）：伤害 22 → 53 / 分钟（5 分钟起封顶）、击杀 15 → 8、受伤 4–6。
- 满能量后闲置中位 19 秒 / 局。
- **精英**（415 只，潮位 10）：终结技致死 0%——设计如此（`ult/elite_floor` 0.1，终结技最多打到剩 10%）；20–28% 的精英吃到过终结技，平均被它削掉最大生命的 11–15%；精英从出现到死亡中位 20 秒（最终 Boss 段 10 秒）。「精英小队出现后被终结技清掉」不成立，终结技清的是精英周围的小怪。
- **Boss 被终结技打掉的血量**：卡门 24%、主教 36%、执政官 38%、不朽 34%、伊比利亚 41%、塑路者 22%；最终 Boss 偏执泡影 5.5%、伊祖米克 / 骑士约 8%。中期 Boss 每场约 1–2 次终结技 = 三分之一血量，是终结技「好用」的另一半来源。

- **不长大**：3:00 → 9:30 我方特效占屏 1–5% 来回，不随等级 / 精英化变大；敌人与敌方层从 1–4% 涨到 4–11%（最终 Boss 段敌方层 24%）。
- **碎**：一帧几百到两千多个连通块，中位 2–4 像素、P90 5–32 像素——「一招一个实心主形」不存在，是一片碎线碎点。
- **亮度够、对比度够，只是没有面积**：我方特效平均亮度 0.32–0.55，普遍高于敌人本体（0.18–0.44）和地面（0.09–0.31），对周围 6 像素环带的局部对比 +0.15 ~ +0.33（敌人只有 0 ~ +0.16）。
- **被压**：拥挤降噪 `render/declutter=3` 在后期把友方特效透明度压到 ×0.65–0.89（满拥挤时下限 ×0.25、加色层 ×0.4、辉光 ×0.6、队友 ×0.5、队长 ×0.8、击杀火花 ×0.35）；全队粒子上限 `render/pfx_cap` 30。
- **被盖**：docs/226 把敌弹和预警挪到友方特效之上（`render/foe_top`），后期我方特效像素有 18–55% 落在敌方层下面，最终 Boss 段 76–87%。
- **敌人受击闪白不是主因**：闪白像素只占战场区 0.05–0.75%；已有「同帧 6 只以上按比例压淡」与降噪 `flash_a` 0.45。但它是画面里**最亮的东西**（见 §6 排名第 1），整只敌人刷白的剪影在截图里最抢眼。

### 3.2 我方特效亮度被谁封顶（协调人追加问题 1）

| 环节 | 现值 | 作用对象 | 对我方特效的实际影响 |
|---|---|---|---|
| look 预设 `render/look` = 5 | actor_cap 1.12 / knee 0.9 | 干员 / 敌人本体受光 | 不压特效；压的是**小队本体**，干员不能比环境亮太多 |
| 同上 | shoulder 0.8、toe 1.15、bloom_th 0.92、god 0.6 | 全屏色调 | 高光 0.8 以上软压，特效最亮那截被压平 |
| 光学 `render/optical_fx_cap` | 1.4 | 特效绘制色通道 | 原来 ×2–2.8 的过曝色截到 1.4 |
| `render/optical_glow_budget` | 0.06 | 全屏平均发光度 | 后期攻击多时按比例压辉光与亮部——**攻击越多、每一下越暗** |
| `render/optical_steps`（防油腻） | 3 | 辉光 / 光池分阶 | 辉光变硬边 3 阶，光晕面积小 |
| `render/optical_local_light` / `local_budget` / `local_bursts` | 1.6 / 0.5 / 4 次每 0.5 秒 | 队长 120 半径内 | 近身新爆发超过 4 次就压暗——近战干员后期正好总在这里 |
| `render/optical_dl_max` | 12 盏 | 特效照地 | 后期同时命中远超 12 处，大多数命中不照地 |

色彩预算里我方特效 P95 亮度 0.78–0.87，低于结晶（0.79–0.99）、受击闪白（0.78–0.97）、敌方预警（0.78–0.95）。平均亮度排第 2–6 / 10（§6）。**结论：没有单独一道闸把我方压到很后面，而是几道「总量预算」叠在一起，后期攻击数量一多，每一下分到的亮度和光都变少；敌方 / 结晶没有这类预算。**
