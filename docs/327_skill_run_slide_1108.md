# 技能期间滑步（11-08）

用户 11-08 反馈：维什戴尔一边移动一边放二技能时没有跑步动作，看上去在滑步。

## 1 维什戴尔 S2：原因与修法

S2 是技能帧条序列 `sprites.skills.s2`，循环里有三段：

- 普攻变体 `s2_attack`
- 跑动段 `s2_run`
- 后半段换成 `s2_over_attack` / `s2_over_run`

移动时，原逻辑会在出手帧播完后让位给跑动段，这一步本身没问题。

**根因：`character.gd` 的 `follow()` 里有一个局部变量 `var sq = g.get("squad")`（编队），遮住了成员变量 `sq`（技能帧条序列）。**

- 推进跑步相位的那句是 `sq.has("run")`，读到的成了编队的 `has(干员 id)`，结果永远为假。
- 所以 `run_ph` 一直不涨，`s2_run` 定格在同一帧（GCP 逐帧日志：`kind=s2_run fr=5`，`run_ph` 一直是 5.81）。
- 画面上就是：身体切到跑步姿势，腿却不动，人在滑。
- 所有技能跑动段都受影响：安洁莉娜、艾雅法拉、歌蕾蒂娅、逻各斯、流明、塞雷娅、德克萨斯的 S3，歌蕾蒂娅 S2，维什戴尔 S2 / S3。

还有第二处问题：`set_attack_phase` 切到第二阶段时只换 `loop` / `attack` / `end`，没换 `run`。所以 S2 后半段一直跑前半段的 `s2_run`，`s2_over_run` 从来没用上。

修法：

- 局部变量改名为 `sqd`。
- 阶段里写了 `run` 的，一并换上。
- 只改画面；同 seed TRACE 跨提交对照见交付汇报。

**剩下的滑步：** 每发炮的前摇（第 0–3 帧，约 0.35 秒）仍播站姿 `s2_attack`。这是按 docs/140 的口径，出手帧播完才让位跑步。S3 有跑动版开炮 `move_skill_s3_attack`，S2 没有，要补就需要新帧条（见 §2）。

## 2 Codex 单：维什戴尔 S2 跑动开炮（两条）

用途：S2 期间移动时，引擎 `_move_swap` 会把普攻变体整条换成 `move_` 版：上半身同一开炮动作，腿换成跑步步态。

- 只换贴图，帧号、脚底、炮口点都沿用原条。
- 所以帧数、出手帧、帧格、脚底必须和原条逐项一致。

| 交付 | 对应原条 | 帧数 | 出手帧（零基） | fps | 画布 / 脚底 | 上半身 | 腿 |
|---|---|---|---|---|---|---|---|
| `op_wisadel_move_s2_attack@1x.png` / `@2x.png` | `s2_attack` | 8 | 3 | 8.42 | 96 画布，foot 48.25, 75.86 | 与 `s2_attack` 逐帧同姿（炮口位置不能变，炮口点按原条每帧的 muzzles 读） | 跑步步态，相位同 `s2_run` |
| `op_wisadel_move_s2_over_attack@1x.png` / `@2x.png` | `s2_over_attack` | 8 | 3 | 8.42 | 同上 | 与 `s2_over_attack` 逐帧同姿 | 跑步步态，相位同 `s2_over_run` |

验收：

1. 叠在原条上，逐帧比对上半身和炮口：不能偏 1 个美术像素以上。
2. 腿交替要在 1 倍尺寸下看得出（S3 跑动第二版的教训：步幅太小，1 倍下和蹲射分不出）。
3. 色板、瞳色、衣服细节与原条一致（docs/87 §4.3）。

参照：S3 的同类条 `op_wisadel_move_skill_s3_attack` 已在包里，由 `tools/op_1x/make_wisadel_s3_run.py` 从原作 Spine 逐部件出。S2 也可以走同一条脚本路线：在 `make_wisadel_s2_run.py` 里加 `move_` 两条，参数照 S3 的 `MOVE_ATK_EXTRA`。由协调人决定交 Codex 画还是走脚本。

引擎侧不用改：交付后在 `wisadel.json` 的 `sprites` 里加两个槽，`frames` / `fps` / `fire` / `foot` 抄原条，`_move_swap` 会自动接上。

## 3 其他干员技能期间滑步扫描（先不改）

做法：

- 图鉴演示 E2，各招式轮流施放。
- 用 `--shot_walk=1` 强制主控在放技能期间也上下来回走，`--shot_log=1` 逐帧记录动画状态。
- 统计走动中（mv > 40）播放非跑步帧条、又没有换移动版贴图的帧数。
- 每招约 16 秒，480 帧。

脚本：`tools/gcp/render_jobs/skill_run_scan.sh`。

- 修前结果：`cloud-results/render-skillrun1`。
- 修后结果：`cloud-results/render-skillrun3`，修后重扫另加了「跑步帧定格」检测。

清单见 §3.1（修后重扫填入）。
