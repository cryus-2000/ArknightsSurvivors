## 要求（逐人）
- **通用**：6 帧循环，「着地 → 下沉 → 过渡」两遍，两腿明显交替、后脚蹬地脚跟抬起；上半身随步伐上下 1–2px（@2x 2–4px），头发 / 衣摆 / 尾巴 / 武器尖端比身体晚一帧摆 1–2px；脸、衣纹逐帧同一组像素只平移（不要整张重绘闪烁）；着地脚在三帧里往后移 2–4px（1x）。
- **艾雅法拉**：小步快跑，身体近直立（前倾 ≤ 15°），法杖斜持随手臂摆，长发与外套下摆滞后摆动；两只鞋前后交替露出。
- **斯卡蒂**：保留前倾冲刺感但收到 ≤ 25°；大剑贴身斜持随步伐上下，长发与帽檐滞后；两腿要真正交替（现在腿几乎不动）。
- **博士**：正常步行跑，两脚交替离地（现在两脚一直贴地）；兜帽外套下摆摆动；前倾 5–10°。
- **艾丽妮**：腿部可保留，补上身：上身随步伐起伏、披风 / 发梢滞后摆，剑随手臂摆 1–2px。
- **维什戴尔**：改成前倾 5–15°（现在后仰），大炮 / 武器随身体起伏；脚底不要漂移。
