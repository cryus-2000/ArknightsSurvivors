## 0. 一句话

博士下的不是「跟着 / 冲出去」两档开关，而是**三种战术姿态**——随行是护卫阵型（安全区）、突击是按职业分工的出击（有代价）、部署是明日方舟式落位阻挡（有代价）；队友在三种姿态下**接队长招式的方式不同**（连携），队长的终结技在慢动作里亲手选方向（瞄准 UI 和指挥用同一套 PRTS 范围格语言）。

## 1. 战术姿态（`command/v2`）

### 1.1 三种姿态

| 姿态 | 怎么进 | 队友怎么站 / 怎么打 | 代价 |
|---|---|---|---|
| **随行**（护卫阵型） | 缺省；圆盘「随行」（队友离得远时等于原来的「归队」：闪回 + 集合） | 按职业站位：重装站在队长和怪群之间，近战在前侧两翼，远程在后排，医疗 / 辅助贴身；远程从自己的位置索敌（不变） | 无：队长身边是安全区，队友不受伤、慢慢回血 |
| **突击**（职业分工） | 圆盘「突击」 | 狙击猎精英 / 飞行怪；术师打怪群最密处；先锋沿队长前进方向冲锋开路；近卫清队长身边；重装护住队长前方（原规则）。以队长为中心的技能改成以施放者为中心 | 会吃敌弹、精英 / Boss 的预警招式和近战接触；作战时限照旧 |
| **部署**（落位） | 圆盘「部署」点一个位置（原「移动 / 驻扎」升级） | 走到点上站定；重装 / 近卫 / 先锋 / 特种有**阻挡数**，挡住的近战敌人停下来改打她；远程地面显示攻击范围格；医疗跟去、站在阻挡者身后治疗 | 同突击 |

- 共同规则：队友生命低于 `command/retreat_hp`（30%）**自动撤回**队长身边（单人，不影响其他人），回到 60%（`retreat_back`）再归位；撤回途中算随行（不受伤、回血）。
- 医疗干员（`cls == 医疗`）在任何姿态下都给队友回血：每秒给 `medic_r`（320）内生命最低的一名队友回 `medic_heal`（6%）生命上限。
- 集火（圆盘「集火」）保留：点精英 / Boss，全队打它；规则同 docs/196 §15。
- 「肃清」从圆盘移除（和部署重复）；机器人内部仍可下「肃清」（`bot_point` 被包围时）。

### 1.2 随行 = 护卫阵型（`command/escort`）

- 威胁方向：队长 `escort_r`（420）内最近 12 只敌人的质心方向，按 `escort_turn`（3 弧度 / 秒）平滑转向；没有敌人时朝队长朝向。
- 站位（f = 威胁方向，s = 侧向；同职业多人按编队序左右错开）：

| 职业 | 站位 |
|---|---|
| 重装 | f × 72（挡在队长和怪群之间） |
| 近卫 / 先锋 / 特种 | f × 44 ± s × 70（前侧两翼） |
| 狙击 / 术师 | −f × 78 ± s × 62（后排） |
| 医疗 / 辅助 | −f × 40 ± s × 30（贴身） |

- 近战的前压（`blocks.follow`，`melee_spot`）照旧优先，没有前压目标时才回阵位；随行限速、到位停顿不变。

### 1.3 突击 = 职业分工（`command/roles`）

`roam_target` 的候选得分按职业修正（不抽随机数）：

| 职业 | 偏好 | 做法 |
|---|---|---|
| 狙击 | 精英 / 飞行怪 / Boss 部件 | 得分 −`role_snipe`（600） |
| 术师 | 怪群最密处 | 得分 −`role_dense`（45）× 周围 90 内敌人数（封顶 8） |
| 先锋 | 队长前进方向前方 | 得分 −`role_lead`（320）× max(0, 朝向点积) |
| 近卫 / 特种 | 队长身边 | 得分 = 离队长距离（不按断后点） |
| 重装 | 队长身边的威胁 | 原规则（得分 + 离队长距离） |

- 有分工时不再用清杂优先的密度重排（分工本身就是更细的优先级）；集火 / Boss 优先的锁定、紧急护主照旧。
- **以施放者为中心**（`command/self_center`）：积木里 `center / at = leader` 的范围（斯卡蒂潮汐、浊心斯卡蒂声浪、星熊、安洁莉娜、歌蕾蒂娅、铃兰等 15 处）在该队友**突击 / 部署**时改以她自己为中心（`op_api.lead_pos()`）；随行时仍以队长为中心。

### 1.4 部署 = 落位阻挡（`command/block`）

- 阻挡数（`block_<职业>`）：重装 3、近卫 2、先锋 2、特种 1、狙击 / 术师 1、医疗 / 辅助 0。精英占 2 格，Boss / 部件 / 宝箱 / 远程怪不吃阻挡。
- 每帧：部署中、站到位（离驻扎点 < 40）、没倒地的阻挡者，把身边接触距离内（自身 18 + 敌人半径 + 8）的近战敌人登记为「被挡住」，直到挡满；被挡住的敌人原地停步（`set_aggro` 到自己的位置），改打阻挡者（接触伤害照 §1.5 算）；`block_pull`（140）内还没满时，把最近的近战敌人引过来（`set_aggro` 到阻挡者）。阻挡者倒地 / 撤回 / 离开部署时全部释放。
- 远程部署：地面画攻击范围格（`command_pick._tiles` 同款 48 格，PRTS 配色），半径 = 当前普攻射程；阻挡者脚下画阻挡数小方块（挡住几个亮几个）。
- 医疗部署：站到阻挡者身后（驻扎点朝队长一侧 60）。

### 1.5 代价（`command/expose`）

- 随行 / 归队 / 撤回中：免伤（原规则）。
- 突击 / 部署中（`roaming_op`）：除原来的近战接触外，还会吃
  - 敌弹：子弹碰到队友（弹半径 + 16）就消失，伤害 × `op_bullet_k`（1.0）；
  - 预警招式：精英 / Boss 的预警结算时，站在判定区里的队友吃 `w.dmg` × `op_warn_k`（1.0）。
- 倒地规则不变（25 秒、队长在旁 4 倍速）。

### 1.6 圆盘（v2 合并为 4 项）

| 位置 | 项 | 说明（圆盘里的字） |
|---|---|---|
| 左上 | 随行 | 护卫阵型，队长身边安全 |
| 右上 | 突击 | 按职业分工出击，会受伤 |
| 右下 | 部署 | 点一个位置落位，重装 / 近卫阻挡敌人 |
| 左下 | 集火 | 点精英或 Boss：全队集火 |

键盘 F / 手柄 LB / 触屏「指挥」键打开，操作同 docs/114 §13.1；部署 / 集火进入选点（docs/196）。

## 2. 连携重设计（`link/v2`）

### 2.1 现状与问题（docs/210）

- E 连携技 + 技能连携：伤害占比 0.2–0.5%，对胜率没有可测的作用；真人 78 次窗口一次没按。
- 18 细胞档关掉技能连携反而 +6（1.3σ）。代码排查见 §2.5。

### 2.2 新规则

- **全自动**：去掉 E 键、手机 E 键与亮起倒计时；`Combo`（E 连携技 A–D 四类）不再亮起。
- **只由队长触发**：队长放技能 / 终结技时，按**当前姿态**挑一名队友接一招互补的（技能连携的 20 人接法照用）：

| 触发 | 姿态 | 挑谁（按接法类别排序，同类轮换） | 区域 |
|---|---|---|---|
| 队长放技能 | 随行 | 掩护 > 附加 > 冲阵 > 追击 > 聚拢 | 队长身边 260 内最密一团；聚拢类的拉拢中心放在离队长 ≥ 220 的外侧（不把怪拖到队长脚下） |
| 队长放技能 | 突击 | 追击 > 冲阵 > 附加 > 聚拢 > 掩护 | 接手队友自己身边 300 内最密一团 |
| 队长放技能 | 部署 | 聚拢 > 附加 > 追击 > 冲阵 > 掩护 | 部署点 260 内最密一团（把怪拖进阻挡线） |
| 队长终结技放完 | 任意 | 追击 / 冲阵 / 附加优先 | 终结技落点 / 方向上最密一团（收割） |

- **少而重**：技能触发全队共用间隔 `link/v2_gap`（60 秒）；终结技触发不占间隔。目标每局 8–12 次。伤害 × `link/v2_mult`、范围 × `link/v2_area`，目标输出占比 3–5%（§2.4 实测）。
- **演出**：保留接手光柱 + 短特效 + 音效；不慢放、不压暗、不停顿、不加冲击帧（用户口径）；队友头顶飘接法名。
- **连携终结技**：保留，节奏改为每次连携 +1 协同格（`ult/cell_gap` 间隔照旧），格数 `ult/cells` 不变；一局约 1–2 次。连携终结技本身规则不变。

### 2.5 「关掉技能连携 +6」的代码排查

- 出手路径（`ult._fire_head` → `skill_link.fire / step`）**不打断**接手队友自己的普攻和技能：`play_vis_anim` 只换画面，`attack_t / sp` 不动，也不吃她的技力；冲刺类只改位置（`syn_mv`），期间她照常出手。伤害本身只占 0.2–0.5%，不是原因。
- 能改变战局的只有**控制与位移**。减压的：掩护类（星熊 / 塞雷娅护盾、嘲讽，凯尔希推开 + 回血）、逻各斯消弹、流明灯火、浊心斯卡蒂 / 艾丽妮增伤。**加压的只有聚拢类**：歌蕾蒂娅钩索把区域外 6 只拖进来、安洁莉娜把外圈 180 内的敌人吸向中心、乌尔比安的锚把 180 内小怪拖向主目标——而技能区域取的是「**队长身边 260 内最密的一团**」，等于把被风筝拉开的怪又堆回队长脚下。18 细胞档队长输出够、主要靠走位拉扯，这条最可能是 +6 的来源；无成长档反而 −1.2，两档都在 1.3σ 内，也可能只是噪声。
- v2 的处理：随行时聚拢类的拉拢中心推到离队长 ≥ 220（`link/v2_gather_out`）的外侧；部署时拉向部署点（阻挡线）；突击时以接手队友自己为中心。§4 的云端配对同时量。

## 3. 终结技慢动作瞄准（`ult/aim`）

- 按下 Q（手柄 RB、手机终结技键）后进入慢动作 `ult/aim_slow`（0.3 倍），最长 `ult/aim_max`（1.5 真实秒）；超必杀暂停照旧先播。
- 选方向 / 落点：电脑跟鼠标；手机从终结技键按下处**拖动**（拖的方向 = 方向，拖的距离 = 落点远近）；手柄右摇杆（不推时用左摇杆）。
- 范围预览：落点类 = 落点处的 PRTS 范围格（`command_pick._tiles` 同款）+ 取景角标；方向类 = 朝向的带状范围格；自身周围类不需要选，**跳过选择**、只闪一下范围就放。
- 释放：松开 Q / 手指；轻点 Q（< 0.2 秒）则保持瞄准，再按一次 Q 或点左键释放；到 1.5 秒自动释放。
- 慢动作期间无敌（沿用 `ult/play_invuln`）。机器人和批跑不走这条（旧的自动瞄准），同 seed 不变。
- 0 = 旧行为（移动键挪落点、0.25 倍 0.5 秒 + 按住最多 1 秒）。
