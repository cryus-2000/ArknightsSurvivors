# 205 终结技语音挑选与专属音效

10-30 用户看了带声音的终结技录像（`tools/ult_rec.py --sfx`）：「需要专属音效，语音我觉得得挑选一下。」本篇是两件事的方案和试听记录。设计见 docs/198 §4，原型见 docs/199。

## 1. 现状

- **语音**：按 Q 进入瞄准时（`run/ult.gd` `_begin`）播 `Sfx.voice(op, "skill_3", urgent)`，实际从该干员的技能池（作战中 1–4，四句洗牌）里随机挑一句，所以终结技和普通技能说的是同一组话。
- **音效**：起手只有就绪音；第一下伤害（`impact`）只有配乐压低；慢放结束那一刻播通用的 `boom`。没有专属音效。

## 2. 语音：每人候选与推荐

**来源**：台词逐字取自 ArknightsGameData `charword_table.json`（与 PRTS 同源的解包数据，docs/76 §4 / docs/198 §9 同一做法），音频取自 Ark-Voice 长音轨（主仓库 `build/arkvoice/`，固定提交见 game/audio/voice/README.md），整句不拼不改。时长是原作切片长度。

**现在在哪**：`技能` = 已在技能池（作战中 1–4）；`入队 / 突击 / 闲聊` = 已在对应池；`未用` = 游戏里还没有这句，要新切。作战中4（CN_028）同时在技能池和闲聊池。

**挑选口径**：短（终结技整段 1–4 秒）、像全力出手、贴这一招；尽量不用技能池里的句子。20 人的「作战中 1–4」「行动开始」「部署」「选中」等战斗条目都已经在某个池里，没用过又适合战斗的主要是「3星结束行动」「完成高难行动」「非3星结束行动」，这几条多是收尾口吻，能用的不多（docs/198 §9.3）。

### 2.1 要用户定的

1. 每人用哪一句（上表 ★ 或改选其他候选，也可以点名表外的原作条目）。
2. **选中的句子要不要从原来的池里拿掉，只在终结技说**（推荐拿掉：终结技那句才有分量；原池少一句，技能池剩 3 句、闲聊剩 2 句的会更常重复，可从未用条目补）。
3. **10-31 用户定顺序「先一下提示音效，然后放语音和对应音效」**：按 Q → 只响定格提示音 sf（超必杀暂停 0.35 秒；正在说的别人的语音同时淡出、排队清空、期间谁都不开口，`Sfx.voice_hush`）→ 暂停结束（立绘切入那一刻）开口说固定句 + 蓄力 charge → 招式各段音效。没有超必杀暂停时（连携终结技 / 开关关）立刻开口。下面是原来的说法：**10-30 用户「放终结技时把别的干员的语音停掉」，已做（4a0ce4fe3）**：开口即淡出正在说的任何一句（含队友技能语音）、清掉排队；招式进行中和那句说完后 0.5 秒内，别的干员一律不开口。

## 3. 专属音效

### 3.1 接法（只动框架，不动招式）

| 槽 | 什么时候响 | 在哪里调 | 播放音量（缺省） |
|---|---|---|---|
| `charge` 蓄力 | 按 Q 进入瞄准（和语音同一刻） | `run/ult.gd` `_begin` | −6 dB |
| `cast` 出手 | 松开 Q / 瞄准时间到，招式开始 | `_cast` | −4 dB |
| `impact` 冲击 | 这一次终结技第一下掉血（就是原来配乐压低的那一刻） | `impact` | 0 dB |
| `hit` 连击 | 冲击之后每次命中，按 `hit_gap` 真实秒节流（冲击 0.06 秒内不叠） | `hit` → `_hit_sfx` | −9 dB |
| `boom` | 慢放结束那一声，保留原来的通用 `boom`（+2 dB、音高 0.8），表里可逐人改 | `fx_tick` | — |

- 映射表 `game/data/ult_audio.json`：`default` + 每人覆盖（`voice` 固定句、`vol`、`hit_gap`、`boom`）。文件名固定 `audio/sfx/ult_<干员>_<槽>.wav`，缺文件静默。
- 语音：`Sfx.voice(op, "ult", urgent, line)` 指定那一句；`ult` 优先级 5、无单句冷却。`voice` 留空时仍播技能池（现状），所以表没填完也不会变哑。
- 持续型招式（浊心斯卡蒂光束 3.8 秒、归溟幽灵鲨巨锯 3.1 秒、歌蕾蒂娅漩涡 1.4 秒、流明光柱 2.4 秒）把整段持续声做进 `cast`，不另开循环播放器。
- 凯尔希（d61028742 新时序：出手到冲击 0.9 秒）：`cast` = 跃起 0.3 秒 + 落地一下 + 0.6 秒蓄压，尾巴接冲击。

### 3.2 候选（`game/tools/gen_sfx_ult_1030.py`，输出主仓库 `build/ult_sfx/<A|B|C>/`）

- **A 厚重写实**：程序合成的物理质感（刀刃、炮弹、碎石、水浪、低频下沉），音高感弱。
- **B 能量感**：同样的结构，多了和弦 / 钟声 / 电弧层，更亮、更「技能」。
- **C 现有音色加工**：拿该干员现有的 `op_<干员>_*` 技能、命中音（及 `cue_beam_*`、`ulp_*` 等）降调、倒放、叠低频重做，和平时技能声同一家族。其中部分原文件剪自 CC0 录音（能天使枪声 DarkShroom / Invisible_inks、德克萨斯刀划与星熊格挡 Kenney、乌尔比安锁链 klakmart），来源已登记在 docs/113 §8 和 `data/credits.json`，本批没有下载新的网上素材。
- 响度：每个文件峰值 −1 dBFS，最响 100 ms RMS 按槽对齐（charge −14 / cast −12 / impact −9 / hit −15 dBFS）；冲击加播放音量后约 −10 dB，和语音（约 −8 至 −10 dB）同档，低频为主、不压 1–4 kHz 人声段。

## 4. 终结技音效模板（10-30 用户「先学习一下别的游戏放终结技的时候音效是怎么做的」）

### 4.1 别的游戏怎么做（通行做法，按公开演示 / 开发分享归纳，非逐条考证）
- **格斗游戏超必杀**（街霸、拳皇、MUGEN 一系）：按下即全屏定格 + 一声短促高亮的「锵 / 叮」（定格音），同时喊招式名；定格期间配乐不停但被压住。之后每一段打击各有自己的命中声，连段越往后越重，最后一击单独一个大音（低频 + 碎裂 + 长尾），收招后有一拍安静。
- **原神 / 星穹铁道大招**：起手语音先行（大招台词优先级最高、打断其它语音）；特写镜头期间是专属「蓄力 / 展开」音；真正出手时一声定音，多段伤害每段一个短命中声，靠**音高微变 + 多个样本轮换**避免「机关枪式」重复；最后一段放大招专属的高潮音。大招期间配乐与环境声压低（侧链 / 闪避），结束后约 0.5–1 秒缓回。
- **吸血鬼幸存者 / Hades 一类**：同屏命中极多，靠**节流**（同一种声音几十毫秒内只播一次）和**同时发声上限**防糊；Hades 的大招（Call）是起手吼 + 一声厚重主音 + 每次命中的轻「点」声，命中声远比主音轻（低 10 dB 上下）。
- **共通的几条**：①起手要有「定格」的一下，耳朵先知道「大招来了」；②画面上每个看得见的打击单元都要有声音，一一对应，数得清；③重复的单元每声略不同（样本轮换 + ±3% 音高 + 轻微音量起伏），并按节奏间隔而不是同时堆；④高潮只有一下，低频 boom（60–120 Hz）+ 高频碎裂（3–8 kHz）+ 混响长尾，比前面所有声音都响；⑤语音 > 高潮音 > 段落音 > 命中声 > 配乐；⑥结束后留一拍安静再恢复配乐。

### 4.2 我们的模板（每个终结技都按这几层配）
| 层 | 触发（跟画面走） | 时长 | 响度（100 ms RMS） |
|---|---|---|---|
| 定格 sf | 按 Q 超必杀暂停那一下（sf_sound） | 0.4–0.6 s | -10 dBFS |
| 蓄力 charge | 进入瞄准 | ≤1 s | -13 |
| 出手 cast | 放出那一刻（短，交代动作：隐去 / 上膛 / 跃起） | 0.1–0.5 s | -13 |
| 单元 fx | **画面上每个可见打击单元出现那一刻**（ult.gd `_fx_tag`：图形 kind / 帧条名 → 槽；数组轮换 = 每声不同；gap 节流，同帧冒出的合成一声；at = 帧条里打中那一帧） | 0.1–0.4 s | -16 ～ -12 |
| 段落 seg | 招式某一段第一下伤害（§3.5 的 on），给没有专属画面单元的段 | 0.3–1 s | -11 |
