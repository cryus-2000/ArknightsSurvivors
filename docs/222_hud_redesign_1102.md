## 2. 三个方向

三个方向共同的规则：
- docs/37 水月风格不变：炭灰平面板 + 顶部高光线 + 1px 细边 + 左上一小段强调色；数值上方小标签头；标签片；青 = 可选 / 当前模式，紫 = 队长，金 = 灯火 / 羁绊，绿 = 源石锭。`UI.PURPLE` 不改。
- B′ 徽记样式不改，只挪位置。
- 顶部中央战斗顶栏和 Boss 条不动。
- 手机右侧按键列位置不动（`touch_layout`）。
- 胶囊形状（指挥模式、倍速）借选人页 B+ 的 `UI.pill`。
- 编队卡沿用选人页名册卡的结构：头像窗 + 左上职业块 + 底部名字带。

### A · 四角收拢（推荐）

`A_desktop.png` / `A_phone.png`。改动最小，每个角只放一类信息：

- **左上 = 队长**：B′ 徽记 + 生命值 / 灯火**上下叠**（以前左右并排），宽度从约 380 收到 260；下面状态标签。**队友不再列在这里**。
- **右上 = 局况**：藏品收成一条（「藏品 15」+ 最近 4 件 + ▸，悬停或 Tab 展开整栏）；右边暂停、倍速成对，倍速写在方块里（1× / 2×），不是 1× 时青色描边亮起。
- **右下 = 编队面板**，一个面板装下三样：
  - 标题栏：「指挥 · 随行 F」胶囊（青）+ 下面一条作战时限细条，右边「编队 4/4 · 羁绊 2」；
  - 卡：4 张 86 高（原来 96 + 技能格行 38），三枚技能缩成卡右上角 15 像素的小图标；
  - 卡底：队友生命细条，羁绊菱形在名字旁；队长卡紫框 + 「队长」签。
  - 源石锭小块贴在面板左边。
- **头顶条**：只在队友受伤或倒地时出（现有 `hpbar_style 2` 的规则）。
- **手机**：同样结构，编队卡用收起的 52 高版（docs/221 P1），技能用三颗色点。

代价：
- 中。改的是 `hud_bars.draw_top_left`（叠排）、`hud_relics`（收起条）、`hud_squad`（面板标题栏、技能进卡角、卡高）、`hud_allyhp`（队友生命进卡底，样式 4 退役）。
- `touch_layout.SQUAD_TOP_UP` 要按新高度重算。
- 好处：玩家的位置记忆不变（队长左上、编队右下），只是每块更整齐。

### B · 底部指挥台

`B_desktop.png` / `B_phone.png`。把「人」全部收进底部中央一台，像动作游戏的底栏：

- **指挥台**，底部中央，600 宽：
  - 中间：B′ 徽记；
  - 左边：生命值 / 灯火两条长条；
  - 右边：三名队友小卡（头像 + 名字 + 三枚技能 + 生命细条 + 羁绊菱形）；
  - 上沿：一排胶囊「指挥 · 突击 · 集火 F」「倍速 1× V」「编队 4/4 · 羁绊 2」+ 作战时限。
- **左上**只剩状态标签；**右上**是藏品收起条 + 暂停 + 源石锭；瞄准 / 冲刺按键牌挪到台子左边。
- 好处：视线从队长往下就到，生命和终结技离画面中心最近。
- 问题：
  - 底部中央本来是冲刺提示和开局提示的位置，要一起挪；
  - 手机上台子压住拇指下方的战场，左下摇杆区也离得近；
  - 改动最大，玩家位置记忆全变。

代价：大（左上 / 右下 / 底部中央全部重排，触屏布局要重做一轮）。

### C · 终端侧栏

`C_desktop.png` / `C_phone.png`。左侧一列「档案」，最像 PRTS 终端和选人页：

- **左侧档案列**，236 宽，从上到下：
  - 队长卡：B′ 徽记 + 名字 + LEADER + 生命 / 灯火，左上紫色强调；
  - 三行队友档案：职业色条 + 头像 + 名字 + 三枚技能 + 生命条 + 羁绊菱形；
  - 指令行：「突击 · 集火 F」「1× V」胶囊 + 作战时限；
  - 状态标签。
- **右上**是一块局况卡：源石锭 / 羁绊 / 藏品数 + 最近 5 件藏品；下面是暂停。**右下**空出来给战场，声呐挪到右下。
- 好处：信息全在一列，从上往下读；右下大片战场露出来。
- 问题：
  - 左侧一列较重（约 300×420 像素），左边的弹幕会被挡；
  - 手机上左上一大块，摇杆在左下，问题不大，但列太高时会压到左侧战场；
  - 队友档案行和编队卡是两套画法，编队卡在局内就退役了。

代价：中–大。

### 三个方向的取舍

| | A 四角收拢 | B 底部指挥台 | C 终端侧栏 |
|---|---|---|---|
| 队长生命 / 灯火 | 左上，上下叠 | 底部中央，长条 | 左列顶部 |
| 队友生命 | 编队卡底 + 受伤时头顶条 | 台上小卡 + 受伤时头顶条 | 左列档案行 + 受伤时头顶条 |
| 指挥模式 / 倍速 | 编队面板标题栏 / 右上与暂停成对 | 台上沿胶囊 | 左列指令行 |
| 技能 | 编队卡右上角小图标 | 台上小卡 | 档案行右侧 |
| 战场露出 | 右下省约 38 高 | 左上、右下都空 | 右下全空 |
| 位置记忆 | 不变 | 全变 | 半变（队友从右下挪到左列） |
| 手机 | 好（右下面板压低） | 一般（底部中央压战场） | 一般（左上列较高） |
| 代价 | 中 | 大 | 中–大 |

**我的判断**：选 A。乱的根源是同一份信息出现几次（队友生命三份）、右下三行和右上藏品栏各自为政，A 用最小的位置变动把这些收掉。如果用户想要更强的「终端」感，可以在 A 的基础上，把编队面板的卡换成 C 的档案行样式（横排 4 行 → 竖排），作为 A+C 的折中。

## 3. 开局指南卡（统一样式）

`guide_card_style.png`（2 倍）。现在的指南卡（docs/219，强制版 c347bd6ab 沿用）是金色描边的暗面板，和 HUD 的炭灰平面板不是一套。统一后：

- 面板同 HUD：炭灰平面 + 顶部高光 + 1px 细边，左侧 3px **青**条（不再用金边，金留给灯火 / 羁绊）。
- 标题行用 docs/37 的**节点标签条**：左段青底压缩英文 `TUTORIAL`，右段暗底中文步骤名。
- 右上步骤点用小菱形：做过的青色、当前的白芯青边、没到的暗色，代替「TUTORIAL 2 / 6」文字。
- 左边实时演示框保留：暗底 + 1px 细边，演示内容不变。
- 右边一句话 + 青菱形起头的「做完条件」行。
- 强制版不出「跳过」；「玩过」线的快速版在右上放一个描边按钮「跳过」（`UI.button outline`）。

位置跟着方向走：
- A：左上状态标签下方，即左侧事件槽的位置，和连携提示同一列，演出排队照常；
- B：指挥台正上方；
- C：左侧档案列下面。

指南卡的问题框（玩过 / 没玩过）也换成同一套面板与节点标签条，版式不变。

## 4. 用户要定的

1. 选哪个方向：A / B / C，或 A+C 折中。
2. 队友头顶血条：只在受伤 / 倒地时出（推荐），还是常驻？
3. 倍速：放右上和暂停成对（A），还是并进指挥模式那一组（B / C）？
4. 指南卡：同意去掉金边、换成青条 + 节点标签条 + 菱形步骤点吗？

### 5.1 参考与借鉴

- **ignoredone.space**（用户给的设计味参考，`ref/ignoredone_1–3`；站点首页、「明日方舟美术资源系统」页）。借了四点：
  1. **尺寸对比**：巨大的粗体字配极小的字距拉开的小标签，层级靠尺寸差，不靠颜色多。用在 ③ 的大号数字和 ① 的等宽小标签。
  2. **一种强调色 + 大量中性底**：页面只有一种饱和色，其余全是中性。三套处理各自只用一种主强调色：① 青，② 青 + `UI.PURPLE`，③ 青色板；金只留给灯火。
  3. **条形律动纹理**：首页黄色块上的竖条（像均衡器）。① 的分段刻度条、③ 的斜纹都是这个思路，用重复的短条表现数值。
  4. **胶囊导航**：圆角胶囊标签。② 的状态标签和指挥牌用它。
- **本作启动页方向 3「声呐终端」**（`ref/ours_boot_v3_sonar_terminal.png`）：发丝线、`TELEMETRY` 这类等宽小标题、点线引导的读数行（`编译 · 界面 7 / 19 ……OK`）、罗盘刻度。① 直接沿用这套语言。
- **本作图鉴 C4′**（`ref/ours_codex_c4.png`）：斜向色带、超大幽灵英文名、平行四边形页签、职业符号片。③ 借它的斜带与职业色块，但不用警示黄（docs/37：黄只在图鉴）。
- **明日方舟原作局内 HUD 与集成战略界面**：PRTS 上集成战略页（`集成战略`、`水月与深蓝之树`）只有文字和规则表，找不到可用的局内界面截图，这次没截。原作口径仍按 docs/37 §1 已归纳的那几条：炭灰平面板、数值上方小标签头、节点标签条、白色线性图标。三套处理里 ① 最贴近原作。

### 5.3 我的判断

- **① PRTS 终端最稳**：
  - 和启动页方向 3、原作的「终端读数」最一致；
  - 发丝线、小字都不抢战场，后期画面乱时也不添乱；
  - 实现成本最低：都是线和小块，`UI` 现有画法加一套切角框和分段条即可。
- **② 水月深海最有本作特色**：液面槽很好认，「生命像水位」也和主题贴合。但半透明玻璃叠在后期满屏特效上会被染色（docs/221 L2 同一个问题），要压低透明度；液面晃动和涟漪每帧都要重画，HUD 缓存层要为它破例。
- **③ 强图形最有「设计感」、辨识度最高**，但色块面积大、饱和度高，后期满屏时会和特效抢眼；大号数字在手机上占地方。
- 推荐 **① 为底，借 ② 的液面槽只用在生命 / 灯火两条上**：终端的线和读数，加上本作的水。如果用户想要更强的冲击感，就选 ③，并把色块饱和度压一档。
