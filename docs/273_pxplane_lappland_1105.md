## 3. 实现

- `game/scripts/render/fx_pxplane_lp.gd`：拉普兰德一节（单独文件）。事件 → 件表；运行时逐格画剑气细针 / 狼首弹拖尾与晶片 / 命中斩痕 / 四角星 / 封招符印 / 观察刻痕 / 连携斩痕 / 传染虚线。
- `fx_pxplane.gd`：`IDS` / `METAS` 加拉普兰德（键前缀 `lp_`），`ev / draw_floor / draw_over / sort_items / draw_sorted` 各一行转到 `_lp()`；`owns_id` 只在 `fx/px_plane = 1` 时为真；`lp_marks()` 给 ob_summon 用。
- 只画钩子（没接管时第一行返回）：
  - `ob_core.exec_shape` 已有的 `shape` 钩子：双刃 / 狼之舞 / 断喝 / 噤声十字斩；
  - `data_operator` 技能事件（日晷 / 狼魂 / 噤声起手）；`data_operator._negate_fx` 一行 `ll_block`（日晷格挡；其他接管的干员不认这个事件）；
  - `seg_skadi._hw_waves` 命中处一行 `ll_whit`（只对带 `ll` 的剑气）；
  - `seg_lappland`：反斩待命 `ll_arm`、回敬 `ll_riposte`、传染 `ll_spread`；
  - `ob_summon.sm_draw_over`：接管时封印画符印、观察层数画刻痕、叠满的灰白冲击波不画（十字斩代替）；
  - `skill_link` l_lappland：接管时发一次 `ll_link`，不画原来的月牙刃块 / 斩痕。
- `melee_impact`（`fx/melee_impact`，缺省关）加拉普兰德：本人色淡紫，狼之舞 / 断喝 / 噤声算重击。
- 帧条：`game/art/fx/pxp/pxp_lp_*.png`（156 张，约 175 KB）+ `game/data/pxp_lappland.json`；重新生成 `python tools/pxplane_bake_lappland.py`（图形 `tools/pxplane_lappland_art.py`），之后 Godot `--import` 一次（GCP 上自动）。
- 送审 GIF：`python tools/pxplane_gif_lappland.py [--only atk,s1,...]`。
