## 1. 伊祖米克：队友跑出去截子代

**反馈**：后期除非三近战，子代会被队长走位时的普攻顺手清掉，队友跑出去追没必要，观感也怪。

**现状**：`character.gd::_izu_intercept`（10-28 用户定 B）——学习期（Boss 无敌）里，队长 `command/intercept_r` = 1200（约两屏）内的喂食子代，非队长队友不论随行 / 突击都改去截，按编队位分配。机器人局同样生效。

**方案（2 句）**：截击半径从 1200 收到 320，只截已经游到队伍身边的子代；远处的子代交给队长走位和全队普攻（射程内照常打，只是不再为它离队跑）。开关 `command/intercept` 保留，不改任何招式。

**改动**：`game/data/balance.json` `command/intercept_r` 1200 → 320（说明同步）。

**验证**：Boss 单场测试台（docs/177），伊祖米克，同一批快照（wisadel / skadi / kaltsit 开局，18 细胞，seed 1，10:00 登场）新旧各 3 场，旧 = `--bal=command/intercept_r=1200`：

| 版本 | 局数 | 胜率 | 胜局用时中位 | 承伤（队长掉血 / 最大生命） |
|---|---|---|---|---|
| 旧 1200 | 3 | 3/3 | 55 秒 | 46%（51 / 23 / 64） |
| 新 320 | 3 | 3/3 | 56 秒 | 70%（119 / 41 / 49） |

- 通关不受影响，用时持平。承伤 +24 点主要来自凯尔希那一局（51 → 119%，含回复所以超过 100%），另两局一升一降；3 局样本、单局波动 ±30 点，不下结论。§3 的云端批跑（结局四路线）里顺带看伊祖米克段的阵亡数。
- 快照还原 fp 3/3 两边一样（测试台已知现象，不影响对照）。

## 2. 事件「引火之木」：付费选项被完全压制

**反馈**：选项 1「立即招募一名干员」婉拒后照样给成长三选一；选项 2「源石锭 −5，成长三选一」成了白花钱。

**原因**：11-05 入队邀请改二选一（docs/252）时，事件来源的婉拒统一改给「一次成长三选一」；编队已满时选项 1 也改给成长三选一。引火之木（`waves.json` `tinder`，普通不期而遇）的选项 1 免费，于是在任何情况下都 ≥ 选项 2。

**改法**：引火之木的选项 1 婉拒 / 编队已满时改为**回复 20% 最大生命**，不再给成长三选一；接受入队不变。选项 2 不动。这样两项各有用处：要人 / 要血选 1，要成长付 5 源石锭选 2。
- 数据：招募 op 可带 `decline`（婉拒 / 满员时执行的事件 op）+ `decline_txt`（卡面 / 横幅文案）；没写 `decline` 的来源照旧（铜印、银印、深蓝之心「办公室」、安全屋「重整编制」）。
- 代码：`endings.gd::_recruit(x)` 读 `decline`，经 `progression.offer_recruit(src, cid, dec)` 带进排队的邀请；`_offer_decline` / `offer_full` 有 `dec` 时执行它的 op 而不加成长次数；婉拒卡说明改为「改为回复 20% 最大生命」。
- 文案：选项说明「立即招募一名干员；婉拒或编队已满时回复 20% 最大生命」；英 / 日 / 韩补了对应行（`events.csv` 改原键行 + 原文键行，`run.csv` 加 4 行）。
- 平衡：机器人缺省接受入队，批跑与改前逐行相同；只有真人婉拒和满员两种情况从「成长三选一」变成「回复 20%」，是削弱（少一次成长），幅度很小。

**同类漏洞排查**（凡是「婉拒 / 满员 → 成长三选一」的来源）：

| 来源 | 婉拒 / 满员给什么 | 同一画面有没有「付费买成长」 | 判定 |
|---|---|---|---|
| 引火之木 选项 1 | 成长三选一 → **改为回复 20%** | 有（选项 2 付 5 买成长） | 已修 |
| 深蓝之心「搜寻办公室」 | 成长三选一 | 无（同屏其他房间也都是付 8：藏品 / 回血）；本身要付 8 | 不算漏洞 |
| 安全屋「重整编制」 | 成长三选一（满员时卡面写明） | 无（另两项是补给 / 灯火，都免费） | 不算漏洞 |
| 人事部铜印 / 博士银印 | 成长三选一 / 全队推进 + 成长三选一 | 无（藏品本身的效果） | 设计如此 |
| 强制招募画面「婉拒」 | 这次升级改为普通三选一 | 无（不额外给次数） | 不算漏洞 |
| 挑人招募（recruit_pick 事件） | 没有婉拒按钮 | — | 无 |
