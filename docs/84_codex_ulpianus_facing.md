## 3. 游戏里的临时修正（Claude，10-13）

`game/data/characters/ulpianus.json` 与 `siege.json` 的 `sprites.idle` 加了 `"mirror": true`（推进之王的 command 条首尾帧朝左、中间朝右，整条镜像会把中间帧翻反，暂不加标记，号令动作首尾仍会短暂朝左，等返修）：

- 战斗绘制（`character.gd` 的 `anim_state` / `draw_body_at`、随行召唤物 `op_blocks.gd`、乌尔比安 / 归溟幽灵鲨自己的 `anim_state`；推进之王跃空翻转用的也是同一个翻转标志）把带标记的帧条当作已翻转处理，翻转标志取反；脚底锚点 foot 仍按源图量，`foot_dx` 随翻转自动换算（x → 帧宽 − x），站定 / 起跑脚底不跳。
- 界面贴图（选人 `title.gd`、图鉴 `gallery.gd`、编队像 / 作战记录 / 开场 `choice_panel.op_idle`、HUD 头像 `Character.portrait`、标题陪伴干员 `title_bg.gd`）用 `A.mirror_strip` 生成的逐帧镜像副本；标题陪伴干员的脚底锚点按 宽 − x 换算。

**返修合入后**：协调人删掉对应干员 json 里的 `"mirror": true`，同时把 `sprites.idle.foot` 改成新图量得的值。`mirror` 机制本身保留，以后有画反的帧条可同样临时处理。
