# 306 Boss 弹幕东方化：样板、对比与进游戏（11-07；§8 已做进游戏，render/danmaku_v2 缺省开）

用户原话：「boss当时我说的是要东方感，所以是园的弹幕」「之前的试点不要了，但是最终boss的美术我都挺满意的」「先给我看看对比，让我抉择一下」；
后改重点：「我觉得boss的弹幕主要是要做中期Boss的，因为之前我朋友反馈说中期Boss不是很明显」。

本文只是样板和对比，没改游戏。用户选定方案后再做进游戏（§5）。

## 1. 范围（已定）

- 只重画 **弹体**，以及发射、消弹、命中三下瞬间特效。Boss 本体、动作、地面预警、11-06 的中期 Boss 放大（render/mid_boss_scale 1.35）和常驻 BOSS 角标都不动。
- 塑路者「订正」刃片子弹试点（分支 `claude/boss-fx-1107`）作废，不合。
- 遵守 memory「Boss 设计口径」：图案弹幕不做符卡，各 Boss 用专属弹幕色，不弹文字提示，最终 Boss 承担弹幕紧张。
- **重点是中期 Boss**：Boss 弹和普通怪弹要一眼分得开。普通怪弹（洋红描边通用弹、各怪专属弹体帧条）不改，作为对照。

## 2. 弹型（种类少，配成一套）

| 弹型 | 美术像素 | 层次（由内到外） | 用在 |
|---|---|---|---|
| 小圆弹 | 直径 9 | 白芯 → 浅环 → 彩环 → 1 格暗边 | 判定 r ≤ 6（泡影双旋、伊莎玛拉碎片、塑路者小弹） |
| 中圆弹 | 直径 13 | 同上，彩环外沿多 1 格深色调 | r 7–9（主教潮环、圣徒弹、泡影中弹） |
| 大圆弹 | 直径 19 | 同上 | r ≥ 10（伊莎玛拉大泪、伊比利亚重弹） |
| 米弹 | 9 × 5（× 判定 r / 8） | 椭圆，白芯沿长轴 | 有朝向的刃 / 冰屑（骑士冰屑雪片、斥亡体旋刃 = 1.5 倍大米弹） |
| 针弹 | 11 × 3 | 一条白芯 + 两侧彩色 + 暗边 | 细长冰棱、狙击类（骑士冰棱弹、卡门曳光弹列，进游戏时用） |

- 画面半径比判定大一圈（判定 r6 → 画面 9 世界像素，和现在的「r + 3 暗圈」一样大），东方口径：看着大，判定小。
- 白芯 + 暗边：深色、浅色地面都看得清（样板表深 / 浅各一张）。
- 米弹、针弹按 16 个方向直接在像素格上重新栅格化，不旋转贴图，斜着飞也不糊。
- 叠弹时分两遍画：先画所有弹体，再补画白芯，叠在一起时白芯始终在最上层（游戏里本来就分遍合批）。

## 3. 两个方案

| | A 纯东方 | B 东方 + pixelfx |
|---|---|---|
| 弹体 | 白芯彩环暗边，极简，每颗 1 张小图 | A 的弹体 + 外沿 1–2 格像素光晕（加色，第二格棋盘抖动）+ 反向 3 点渐隐拖尾 + 中、大弹芯上 1 格高光闪烁 |
| 瞬间特效 | 发射十字星芒；消弹 4 片碎光；命中断环 | 同 A，再加 Noita 式粒子光：发射多一圈 8 点外飞，消弹多 6 颗飘散星点，命中断环变成整圈 + 一圈白点 |
| 观感 | 干净，满屏时最好读 | 更华丽，有「活」的感觉；满屏 200+ 颗时光晕会连成片，浅色地面上光晕偏白 |
| 每颗绘制 | 影子 + 1 个贴图矩形（现在约 4–5 次 tb 调用） | A + 1 个光晕贴图 + 3 个拖尾点 |
| 帧率 | 比现在省（每颗调用从 4–5 次减到 2 次，全是贴图矩形，能合批；memory「Godot 绘制合批实测」：圆 / 环不能合批） | 比 A 多约 4 个贴图矩形 / 颗；偏执泡影峰值 243 颗 ≈ 多 1000 个矩形，合批后桌面估 0.1–0.3 ms，手机网页估 0.5 ms 左右（实做后用同局轮换开 / 关量） |
| 包体 | 0（运行时用代码生成小图集，不烤帧条） | 0 |

两个方案的发射、消弹、命中都是逐格画的小帧（每帧约 0.05 秒，共 4 帧），见样板表下半部分。

### 4.1 对比图怎么做的（可复现）

1. 实机：GCP（tools/gcp_render.py custom，9 台并行，`render-danmaku-all`），`--autotest --seed=1 --op=mizuki --bossmoves=<Boss> --bossonly=<招> --extraspawn=floater,stone,skimmer,floater --flashrec=151.0,140,1920 --ebdump`。
   每个 Boss 跑两遍：原样一遍；`--ebhide`（不画 Boss 弹）一遍当底图。同种子两遍每帧 Boss 弹数完全一致（9/9 核对过）。
2. 新样子 = 底图 + 按 `eb_*.json`（该帧每颗 Boss 弹的位置、速度、判定半径、种类）用 `tools/concept_danmaku.py` 重画。弹数、速度、扩散角都是游戏里那一帧的真值。
3. 探针（`--ebdump / --ebhide / --extraspawn`、录帧期间 bossmoves 不退）只在临时提交里，没进本分支；补丁存在 `tools/probes/danmaku_ebdump.patch`，要重拍时 `git apply` 到临时分支再跑。

## 5. 选定后怎么做进游戏（待用户选）

1. 新建 `render/boss_bullet_draw.gd`：按 §2 的层表在运行时生成每个 Boss × 弹型（米弹 / 针弹 16 向）的小 ImageTexture 图集（9 Boss × 约 40 格，几十 KB 显存，包体 0），world._draw_ebullets_lobs_shocks 里 Boss 弹改走这里，一律贴图矩形合批。
2. 弹型映射按 §2（判定 r → 圆弹档；boss_blade → 米弹；冰棱 / 曳光 → 针弹）；判定半径不变，同 seed TRACE 不变。
3. 瞬间特效：发射 / 消弹 / 命中三个事件接 bullet_fx 现有的 spawn / die 观察点，B 方案的粒子走 Boss 颗粒预算（BossBeam.take）。
4. 开关 `render/boss_bullet_v2`（0 = 现状），先中期 Boss，再最终 Boss；用户看实机录像后再定缺省。
5. 「Boss 来了」的存在感：出场第一轮弹的发射闪光放大一档（不加文字提示）。

## 6. 第二版（11-07 用户：「骑士的不要修改，剩下的可以改，但是我觉得现在设计的不够好看，还是要好看的」）

第一版 A / B 两个方案都作废，换成第二版（`tools/danmaku_v2.py`，图在 `Claude outputs/boss_danmaku_1107/v2/`）。**最后的骑士保持现状**，不进新画法。

- **画法提升**：
  - 每颗弹按解析形状 4×4 超采样，再落回美术像素格。
  - 亮度用 5 阶色带（白 → 淡 → 亮 → 主 → 深），只在色带交界处做 2×2 有序抖动。
  - 外沿 1 格暗边，暗边外 1–2 格柔光晕（加色，3 档透明度），左上角镜面高光。
  - 仍是 1 特效像素 = 1 美术像素。
- **专属弹形**：小弹统一用精修圆弹，保持成套；中、大弹按 Boss 身份换弹形：

| Boss | 弹形 | 色带主色 |
|---|---|---|
| 塑路者 | 菱晶弹（四个切面明暗不同 + 白棱；小弹也是菱晶） | 冷银蓝 #96B2E6 |
| 接潮主教 | 水泡环（亮环，中间透出地面） | 靛蓝 #5C70FA |
| 接潮斥亡体 | 刀弹（刃面一亮一暗、尖白、尾部护手；旋刃 r12 用大号） | 淡紫蓝 #A8A0FF |
| 圣徒伊比利亚 | 火球（圆头 + 波浪火舌） | 火色带 白 → 淡黄 → 橙 → 深红 |
| 圣徒卡门 | 星弹（五角星自转；面积比圆小，所以放大一档） | 金色带 |
| 伊莎玛拉 | 泪滴（头朝前、尾巴收尖） | 青绿 #40F0A0 |
| 偏执泡影 | 泡弹（半透明泡身 + 亮边 + 弧形高光；小弹也是泡） | 紫 #B260FF |

- **瞬间特效**：
  - 发射：四芒星 + 斜芒 + 6 粒外飞火星。
  - 消弹：先胀白，再碎成 6 片旋转亮片，末尾成星点。
  - 命中：压扁白闪 → 破环 + 八向短芒。
  - 每种 5 帧，逐格画。
- **帧率**：
  - 每颗弹 = 1 个光晕贴图矩形 + 1 个弹体贴图矩形（白芯那一遍只在叠弹时需要，可以并进弹体那张图里）。
  - 图集在运行时生成，种类为 Boss × 弹形 × 16 向（星弹、火球另加 10 个相位），全部是贴图矩形，可以合批。
  - 比现在每颗 4–5 次圆 / 环调用省；包体 0。
- **已知限制**：
  - 浅色地面上，加色光晕和消弹碎光偏淡。进游戏时，浅色地图上的光晕改成「主色正常混合」。
  - 主教「交错潮环」截到的那一帧里，刚生成的整圈弹叠在 Boss 身上（现在的游戏里也一样），新画法照实画了，所以那一团偏密。

### 6.1 第三轮（11-07 用户：「卡门星弹、伊比利亚火球。都太丑了，在原本的基础上修改」「斥忘体的刀剑子弹也很丑，以及为什么没有一组米克的」）

图在 `Claude outputs/boss_danmaku_1107/v3/`。这三个 Boss 改回「原样精修」：外形和配色照现在游戏里的，只换成第二版的画法。

- **圣徒卡门**：奶白圆炮弹 + 棕边（原样），加白芯渐变、高光、柔光，后方 1 格宽的金色曳光尾渐隐，替掉原来的洋红拖尾。
- **圣徒伊比利亚**：橙色圆炮弹 + 暗红边（原样），热芯偏前，加余烬色曳光尾。
- **接潮斥亡体**：白 → 淡紫的月牙刃（原样，高约 18 美术像素）。凸面刃口描白、凹面描深紫，后方 4 点碎光闪烁；不描整圈暗边，叠刃时不会糊成暗团。
- **伊祖米克**（之前漏了）：GCP 补拍二阶段「螺旋弹臂」同帧（150 颗）。原样是淡天蓝扁平圆弹，现在精修成白芯 + 天蓝渐变 + 高光 + 柔光的光玉。

  - 曳光尾和碎光不长光晕。
- 其余（塑路者菱晶、主教水泡环、伊莎玛拉泪滴、泡影泡弹）沿用第二版；最后的骑士不改。

## 7. 第四轮：Noita 粒子 + pixelfx 动画（11-07 用户：「这个版本没有我要的 notia 粒子感和 fx 的感觉」）

静态图看不出「活」，这一轮直接做进游戏，用实机录像对比（§8）。`tools/danmaku_fx.py` 是进游戏前的 Python 示意版（同一套粒子规则），后来改用实机录像，示意版只留作参考。

- **pixelfx 逐格感**：
  - 圆形弹的芯两帧交替脉动（半径 +0.4 格）；
  - 月牙后方碎光 3 相位闪烁；
  - 发射 / 消弹 / 命中是 5 帧逐格闪光（每帧 0.05 秒）：四芒星 + 6 粒外飞火星、先胀白再碎成 6 片旋转亮片、压扁白闪 → 破环。
- **Noita 式粒子**：每颗 1 美术像素，HDR 色，交给光学辉光处理。
  - 沿途掉光：每颗弹每帧 0.6–2 颗，按年龄走色带，随机闪烁。
  - 各 Boss 一种环境粒子：塑路者菱晶闪点、主教浪花沫、斥亡体碎光、伊比利亚余烬上飘、卡门金色闪点、伊祖米克生物荧光呼吸、伊莎玛拉水滴下落溅开、泡影小泡上浮摆动。
  - 发射火星、消弹碎屑：有重力，落到地面停住再熄灭。
  - 地面光：弹脚下两档椭圆柔光，弹幕越密地面越亮。
- **上限**：同屏粒子 ≤ 700（手机网页 ≤ 350，发射率也减半）；超了不发新粒子。同一处 0.1 秒内只放一个发射闪光，一圈齐射不会叠成白团。

## 8. 进游戏（11-07 夜，协调人转用户整夜授权：「按最新一版做进游戏」）

- **开关**：`render/danmaku_v2`，缺省 1；0 = 旧画法，旧代码全部保留。另有 `render/danmaku_v2_hdr`（缺省 1.2，光学观感下弹体提亮，抵消光照暗角）。
- **范围**：
  - 塑路者、接潮主教、接潮斥亡体、圣徒伊比利亚、圣徒卡门、伊祖米克、伊莎玛拉、偏执泡影（一阶段）。
  - 不动：最后的骑士；接潮蔑死体没有弹幕；泡影二阶段的海嗣滴（`own_draw`）仍由 `paranoia_combo_draw` 画。
  - 中期 Boss 分级弹的显形期（点环收缩 = 预警）仍走 `mid_card_draw`，出发后才换新画法。
- **代码**：
  - `game/scripts/render/boss_bullet_draw.gd`（新）：运行时用代码逐格生成弹体图集，每个 Boss 一张贴图，行式装箱。
    - Boss 在场就开始预生成，每帧 3 格（手机网页 1 格）；缺格时当帧补。
    - 弹体一律 `draw_texture_rect_region` 同一贴图，一批画完。粒子、地面光走 `world.tb_*` 合批。
    - 自带 `RandomNumberGenerator`，不碰玩法随机数；不引用自动加载（手机判断用 `g.mobile_cap()`）。
  - `world.gd`：三遍敌弹绘制跳过 `bbv2.mine(b)` 的弹。
  - `bullet_fx.gd`：旧拖尾跳过新画法的弹；出现 / 消失走 `set_spawn_hook` / `set_hook`，交给本模块。
  - `autotest.gd`：开发参数 `--danmakuab=N`，同局每 N 帧轮换新旧画法，用来量帧时。
- **验证**：
  - 同种子 TRACE：开窗口（绘制代码会跑），mizuki 种子 3、skadi 种子 5 各 260 秒（含 3:30 第一只中期 Boss），开 / 关两组逐行一致，261 = 261 行（GCP `render-danmaku-trace2`）。
  - 帧时：本机，偏执泡影「偏执双旋」，同屏 238 颗，`--danmakuab=30` 同局轮换、`--prof`，两局。
