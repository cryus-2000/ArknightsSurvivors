# 103 · 像素人物体型模板（界面与美术，2026-10-15）

> 用户 10-15：「总结不同体型的人的像素风格的不同，先定好模板，别每次重画。」G 批整组重画被退回（「小羊眼距太宽、逻各斯脸太尖」，旧版画风更好）。本页把 main 现版 18 名干员 + 博士的待机 f0 量出来，按体型分簇，给出每簇的模板卡。**Codex 新画、返修都必须引用本页**（docs/87 §4.3）。

## 1. 量法

- 工具：`python tools/body_metrics.py`，输出终端表与 `build/body_metrics/report.md`（`--json` 另存）。样本是 `sprites.idle` 的 f0，在 @2x 上量，**全部换算成 1x 像素报**。
- 自动量：站立高、头宽、肩宽、腿长、脚底 x。
- 人工标：眼和下巴在 1x 下只有 1–2 像素，自动识别不可靠（白发角色会把头发当成皮肤），所以在 @2x ×11 网格图上读数，写在脚本的 `ANNOT` 表里（`build/body_metrics/face2x_*.png`，±0.5 像素 1x）。
- 抽查：水月、逻各斯、凯尔希、塞雷娅四人和整身网格图（`build/body_metrics/grid_*.png`）对过。塞雷娅的下巴第一次读错（脸小，被盾的白色挡住），已改。
- 定义：
  - 站立高 = 脚底行 − 最高不透明行 + 1，帽 / 耳 / 角都算。
  - **头高 = 下巴 − 发顶 / 额头，不含帽 / 角 / 耳 / 光环**（10-15 协调人定口径）。发顶在整身网格上人工读（脚本 `HAIR_TOP`）。帽子盖住头顶的四人（斯卡蒂、浊心斯卡蒂、水月、乌尔比安）按「眼心 − 8.75」推算，8.75 是其余 13 人眼心到发顶的中位；乌尔比安面罩遮眼，按「下巴 − 12」推算。
  - 头饰高 = 发顶 − 最高不透明行，单列。
  - 头身比 = 头高 / 站立高。
  - 眼高 = 眼心在头高里的位置（0 = 发顶，1 = 下巴）。
  - 眼到下巴 = 下巴 − 眼心。这是脸下半的长度，不受帽子、角、耳影响，**比头身比更能区分脸型**。
  - 头宽 = 眼高那一行主体段的宽（含两侧头发）。
  - 下巴宽 = 下巴往上 1 像素处的脸宽。
  - 肩宽 = 下巴往下 1–4 像素的最大行宽。
  - 腿长占比 = 两腿分开的最高行到脚底 / 站立高。裙子和长外套会盖住腿，这一项只作参考。

## 4. 各卡的脸部构成规则（来自 §2 实测）

- **成女**：眼睛低（眼高 ≥ 0.76），脸下半短（眼到下巴 ≤ 3）；下巴略收，深海猎人一系尖；刘海压到眼上沿。
- **少**：眼高 0.69–0.74，眼到下巴 3.25–4.0（斯卡蒂例外，按现版）；圆下巴、下巴宽约 5；少年肩窄（≈ 14），少女胯宽。
- **幼**：在少的基础上眼更高（≈ 0.6）、额头大、圆脸。
- **成男**：眼距窄（3–3.5），脸长（眼到下巴 4–4.5），平底 / 方下巴；**不能收成 2 像素的尖下巴**（G 批逻各斯被退的原因）。

## 5. 规则（Codex 新画 / 返修必须引用）

1. **新角色**：先定卡（按原作设定，写在需求单里），**先只交一张待机 f0（1x + @2x）**，附 `tools/body_metrics.py` 量得值和模板卡对照；用户看过说「没问题」才画其余动作（「先 f0 审图」硬流程，同 docs/97 G 批退修单的分阶段交付）。脸下半指标要在卡的区间内，超出范围写理由（例如原作就是长脸）。
2. **返修**：一律在 main 现版帧上改颜色层与饰件，不重画头脸（docs/87 §4.3）。交付附改前 / 改后逐像素 diff，眼距、下巴、头宽、头身比与现版差 ≤ 1 像素。
3. **整组重画**：只有协调人单子写明「重画造型」才允许，并且同样先交待机 f0 按模板卡核量。
4. **量测工具**：Codex 不跑游戏，但可以跑 `python tools/body_metrics.py`（只读 PNG）。新角色要在脚本的 `ANNOT` 里补一行人工标注（眼 x / y、下巴 y、下巴宽 / 形），随交付提交。
5. 模板卡数值随新样本更新：每有一名新角色合入，重跑脚本，簇内中位与范围按实测改本页。

## 6. PRTS 小人比例实测（10-15，界面与美术；同日补维什戴尔 / 乌尔比安 / 逻各斯，18 人全齐）

原作 Spine 小人（PRTS 待机 f0）按 §1 同一套口径量了全部 18 人，用来判断模板卡里哪些是原作规律、哪些是本作像素版自己的习惯。**只是定模板的数据**：干员美术仍暂停（用户要大改），不派 Codex，现有角色不据此返修（§3.1），§2–§5 的卡值等用户看完再定改不改。

- 素材：主仓库 `build/prts_ref/<id>/idle_f00.png`（1000×1000、朝右，不入库）。
- 分卡同 §3：维什戴尔归成女；逻各斯、乌尔比安、流明归成男（用户确认逻各斯是成男）。
- 量法：纯剪影自动量会被头发、帽子、武器、披风带偏，所以**全部人工读**。读数写在 `tools/prts_metrics.py` 的 `ANNOT`，脚本只汇总和出图。读数在 10 像素网格放大图上取，误差约 ±5 原图像素，换成比例约 ±0.02–0.03。
  - 发顶不含帽 / 耳 / 角。帽子盖住头顶的五人（水月、斯卡蒂、浊心斯卡蒂、归溟幽灵鲨、乌尔比安）按其余 13 人的眼高中位 0.742 推算。乌尔比安面罩遮住下半脸，下巴取面罩下沿。
  - 头宽是眼睛那一行的宽，含两侧头发，不含双马尾、耳、角和背后的武器 / 翼。肩宽含肩上的外套 / 披风。
  - 裙子或长外套盖住腿的（铃兰、塞雷娅、归溟幽灵鲨、逻各斯、乌尔比安），裆位取下摆，腿长偏小。
- 新增口径：
  - 头身数 =（脚底 − 发顶）/ 头高，即原作说的「几头身」，不含头饰。
  - 腰位 =（腰 − 发顶）/（脚底 − 发顶）。
  - 腿长占比 =（脚底 − 裆）/（脚底 − 发顶）。
  - 眼距 / 头高：头宽受头发影响大，比较眼距时以这一项为准。
- 对照拼图：`art/reference/prts_body_ratios.png`（标线：顶 / 发顶 / 眼 / 下巴 / 肩 / 腰 / 裆 / 脚，黄圈是瞳心，带 * 的发顶是推算值）。
- 重出数据和拼图：`python tools/prts_metrics.py --ref <主仓库>/build/prts_ref`。

### 6.3 看出来的规律

1. **原作小人是一套共用的头，四簇在脸部比例上分不开。**眼高 0.71–0.79、眼到下巴 0.21–0.29 头高，成女、少、幼（铃兰）、成男（流明、逻各斯、乌尔比安）都落在同一段里。能天使 0.85 / 0.15 是侧脸低头造成的，不算。原作的体型差别主要靠发型、服装、配色和眼睛画法（这次没量）。
