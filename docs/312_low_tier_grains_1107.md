# 312 · 低档加一点点粒子（11-07，帧率会话，分支 claude/lowfx-grains-1107）

> 协调人转用户 11-07「最低的特效版本加一点点粒子」——指画质「低」档（不是精零特效档）。从 claude/integ-1105 447b694bf 拉。只改画面，帧时守住（手机网页 ≤ +1 ms）。

## 0. 结论

- 低档所有 CPU 颗粒（命中火星、技能、Boss 特效）保留比例 `render/low_grains` 0.4 → **0.55**（docs/50 §36 那条）。
- 子弹颗粒（bullet_fx 命中 / 消失迸散）低档原来整层关，现在按新旋钮 `render/low_bullet_grains` **0.6** 份额打开（累加器均匀抽、不抽随机数；进颗粒层后再乘 low_grains，合计约中档的 1/3）。
- 光学 GPU 粒子（optical_particles）低档仍关（太贵）。
- 帧时：手机网页低档净差 **−0.6 / −0.1 ms**（8:00–10:00 / 10:00 后），桌面低档 **+0.2 ms**（三段平均）。同 seed 低档 TRACE 逐行一致。

- **桌面帧时**（`perf_stack.py run night3 … --quality=low --more="--optab=60 --optmask=2147483648"`，同局每 60 帧轮换新 / 旧，8:00–11:00）：

| 桶 | 新 | 旧 | 新 − 旧 |

- **手机网页帧时**（`perf_web.py --mobile --dpr 3`，iPhone 横屏 844×390 仿真，同场景同轮换，`--realtime --rtfrom=480`）：
