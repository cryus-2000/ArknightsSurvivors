# 76 游戏内语言风格规范（约束，必须遵守）

2026-10-12 用户定：「需要按照报告改，而且最关键的是我们需要统一整个游戏的语言风格，这个需要写在约束里面。要有明日方舟的味道。五人档案根据 prts 里面的资料去查，不要自己编。」

**适用范围**：玩家能看到的所有文字。包括 `game/` 下的 `.gd` 字符串，`data/*.json` 里的 name / desc / adapt / lore / hint / text / epilogue / banner，以及图鉴、横幅、指南、设置、商店页文案。Claude 和 Codex 写新文字、改旧文字，都按本文执行。docs/75 是本文的审计来源；两者冲突时，以本文为准。

不在范围内：`_doc`、代码注释、报错信息，以及 `relics.json` 的 `original` 字段（它是原作原文，照抄，不改用词）。

## 1. 总基调：罗德岛的口吻

明日方舟的文字有三个特点：**简短、克制、信息密**。界面像罗德岛的作战终端，档案像人事部的记录，效果说明像技术手册。照这个来写：

- **短句，陈述句。** 一句只说一件事，能删的字就删。
- **不抒情，不升华。** 不写感悟，不喊口号，不替角色说心里话。情绪交给画面和语音。
- **数字说话。** 能写数字就不写形容词，能写条件就不写「有时」。
- **第二人称用「你」**，指博士 / 玩家。全游戏不出现「您」。

### 1.1 各类文字的写法

| 文字类型 | 语域 | 要点 | 例 |
|---|---|---|---|
| 界面、指南、横幅、提示 | 罗德岛作战终端 | 先说发生了什么，再说要做什么。可以用行动用语（见 §2）。横幅格式固定为「事件 —— 指示」 | 「海嗣祭坛「抉择 · 其一」出现了 —— 靠近祭坛进行抉择」 |
| 技能 / 天赋 / 成长节点 / 藏品效果 | 技术手册 | 「对象 + 数值 + 条件 + 例外」。阈值写成数字，例外写「Boss 除外」 | 「队长一次受到超过 10% 最大生命的伤害时，周围敌人眩晕 3 秒（Boss 除外）」 |
| 图鉴「本作定位」一句话 | 简报 | 用一句话说清楚这名干员怎么打、靠什么。可以不写数字，但不能写对仗句和口号 | 「持续治疗队长，Mon3tr 在身边撕碎靠近的敌人」 |
| 干员档案（lore.json 干员条目） | 罗德岛人事档案 | 见 §4。首句用招聘合同原文；正文只写 PRTS 档案里有的事实；第三人称；不写本作机制 | — |
| 敌人 / Boss 档案 | 现场观察记录 | 写它是什么、长什么样、做什么，最后一句停在一个具体画面上。机制写在图鉴的机制说明行（gallery.gd），不写进档案 | 「它像岸上的走兽一样奔跑，扑到猎物身边就炸开。」 |
| 结局、祭坛事件 | 行动记录 | 写谁在哪里做了什么，一两句就够。不加收尾感悟，不把结局名再念一遍，不替 Boss 写心理 | 「潮水退了。回岸的船上少了一个人。」 |
| 难度、模式副标题 | 参数说明 | 写这一档比上一档多了什么 | 「敌人生命与攻击 +20%，受击损失的灯火 +30%，灯油掉落减少。」 |
| 商人台词 | 角色口语 | 短，有角色感，不说教。shop_screen.gd 现有 4 句可以作参照 | — |

## 2. 明日方舟用语（优先使用）

界面和指南里，优先用原作的行动用语，不用泛化的游戏腔：

| 用 | 不用 | 说明 |
|---|---|---|
| 行动目标 | 任务目标、你的使命 | 开场与指南 |
| 探索、一次探索 | 冒险、旅程、一局（正文里） | 一局游戏 = 一次探索（集成战略的说法）。「本局 / 每局 / 下局」只允许出现在 4 字以内的短标签里（如「本局构成」「下局生效」） |
| 干员、编队、加入编队、招募 | 角色、队伍成员、加入你的旅程 | |
| 精英一 / 精英二（正文），精一 / 精二（徽标） | 一阶、进阶（指精英化时） | |
| 技力、技力回复 | 技能能量、充能速度 | 见 §5 |
| 部署、撤离、威胁等级 | 召唤、逃跑、危险度 | |
| 抉择 | 做出你的选择 | 海嗣祭坛事件的动作；按钮 / 标题可以写「选择一项」 |
| 博士 | 指挥官、玩家（文中） | |

## 3. 禁用写法（看到就改）

| 编号 | 写法 | 典型例子 | 改成什么 |
|---|---|---|---|
| X1 | 对仗 / 排比公式 | 「灯越亮…，越…」「A 时是…，B 时是…」「永远…永远…」「更快更凶更多」 | 写阈值和数字：「灯火 ≥ 70 时……；< 30 时……」 |
| X2 | 口号、标语 | 「大海不再留情」「灯火未熄，便还能走下去」 | 说明这一项的具体内容；没有信息就删掉 |

| X4 | 「不是…而是…」以及其他设问铺垫 | 「她不替你包扎，她让你……」「你的抉择，会……」 | 直接陈述 |

| X6 | 堆叠成语、四字格连用 | 「生生不息、前赴后继、势不可挡」 | 一个具体动词 |

## 4. 原作角色档案（硬性规定）

1. **引言**：所有干员统一用 PRTS 干员页「招聘合同」里的**干员简介**（用途句，如「企鹅物流职员能天使，将用铳枪为小队扫平前路。」），一字不改，标点也不改。不用「干员简介补充」（描述句）当引言；描述句如果是档案事实，可以转述进正文。查不到就不写引言。（2026-10-12 第二轮用户定）
2. **正文**：只写可核实来源里有的事实。来源包括 PRTS 的「基础档案 / 客观履历 / 档案资料 / 晋升记录」，也包括其他可核实来源：游戏内档案、剧情和集成战略文本，官网与官方 B 站 / 微博，官方设定集，维护良好的 wiki（Fandom、bwiki），游戏数据镜像（如 Kengxxiao/ArknightsGameData 的 handbook_info_table / roguelike 表）。优先用官方一手文本；每条事实都要能对应到附录 A 里的一个 URL，用自己的话转述。不大段照抄原文，不加推测，不加评价。
3. **查不到的事实，宁可不写。** 例如德克萨斯的「科西嘉家族继承人」、能天使的「苹果派」、浊心斯卡蒂的「溟海之心」，PRTS 页面上都没有，已经删掉。
4. **档案栏位**（性别 / 出身地 / 种族 / 所属）按 PRTS 基础档案和势力字段填写。PRTS 写「未公开」的就填「未公开」。
5. **不替角色说话**：正文不出现「她说过……」，也不写角色内心。
6. **记录来源**：新增或改写原作角色、原作剧情时，要把来源 URL（PRTS 或其他可核实来源）加进本文附录 A。2026-10-12 用户定：来源不限于 PRTS，别的能证实的来源也可以，但不能编。

## 6. 数值写法

- **随时间成长**：要写出起点和增长速度，格式为「伤害 X，每分钟 +Y（10:00 约 Z）」。藏品的时间缩放和敌人生命同一条曲线（combat.gd `enemy_hp_time_mult`）：倍率 = 1 + 秒数 / 110，8:00 后改为每 120 秒 +1（`balance.json` enemy 段 `hp_div` / `hp_knee` / `hp_late_div`，10-13 由 130 改为 110）。所以 0:00 是 ×1，8:00 约 ×5.36，10:00 约 ×6.36；每分钟增量 = 起点 × 60 / 110。藏品说明里这类数字**写成占位**，读取时按 balance.json 现值填（`relic_db.fill_desc`，与干员文字 docs/61 §1.4 同一套 `{$键}` 写法；可用 `pm` = 每分钟增加的倍数、`m10` = 10:00 倍数，以及 `mine_dmg` / `wrath_dmg` / `dust_dmg` / `scavenge_mult`），例：`伤害 {$mine_dmg}，每分钟 +{$mine_dmg*$pm:0}（10:00 约 {$mine_dmg*$m10:0}）`。曲线改了文字自动跟着变，不要再手写算好的数。「每分钟 +Y」写的是 8:00 之前的增速，8:00 之后略快。另外还要乘全队伤害加成。
- **距离**：技能说明里的半径、射程，和属性面板的「照亮范围」是同一个单位（灯火 100 时照亮范围是 360）。指南「成长路线」页写了这一条。
- **百分比**：写明基数（最大生命 / 当前生命 / 技力 / 基础伤害）。
- **持续时间**：写「X 秒内」或「持续 X 秒」，不写「一段时间」。

## 7. 性别中立

主语可能是任意一名干员时（藏品、通用说明、招募效果），写「该干员」「干员」，不用「她」「他」。

## 8. 写完自查（提交前逐条过）

1. 有没有「您」、宣传词（X12）？
2. 有没有「越…越…」、对仗、排比（X1）？
3. 有没有口号或空洞形容词，能不能换成数字（X2、X3）？
4. 叙事段尾是不是感悟句或抽象名词（X5）？
5. 叙事里有没有破折号（X7）？
6. 档案里有没有机制、数值、「本作中」（X9、X10）？
7. 原作角色的引言是不是 PRTS 招聘合同原文？正文每一句能不能在 PRTS 页面上找到出处（§4）？
8. 术语是不是 §5 表里的叫法？要改用词时，用 `grep -rn` 全游戏搜一遍旧叫法。
9. 指代不确定的干员时，有没有用「她 / 他」（§7）？
10. 数字和条件是不是和代码一致？改文字不改数值；文字和代码对不上时，以代码为准修文字。
