# 247 终结技重新定位 A/B（11-05）

**结论**
1. 推荐组合：`ult/rework` = 1（降频 + 精英 / Boss 单次上限 + 清一圈留余烬三项全开，缺省值见 §1），**并且同时开 late-power-ab 的 `growth/late_shape` = 1**。这一组胜率 m0 52.4% / m18 71.4%，两档都在窗口内（45–55 / 65–75），和基线（56.0 / 75.0）的差都不到 10 个点，不下「变难 / 变易」的结论。
2. 只开本开关：m0 47.6% 仍在窗口，m18 61.9% 低于 65，比基线低 13 个点（配对 9 赢 / 20 输，p = 0.06）。不建议单独上线，原因是中期 Boss 打不完（击破率 68% → 51%）。
3. 频率达标：真人口径（expert、会死）一局终结技 5.1–5.5 → 3.1–3.3 次；打到终局的诊断局 5.9 → 3.9 次，间隔中位 97 → 165 秒，首次充满 122 → 161 秒。降频旋钮单独就贡献了几乎全部次数变化。
4. 定位达标：精英单次最多被打掉 91% → 56%，中期 Boss 单次中位 29% → 18%（最大 20%）；终结技占 5–9 分钟普通怪击杀 16.3% → 7.5–8.0%，潮位 10 从 19.0% 降到 9.1–10.4%。非终结技清怪比反而略升（配对 +0.07，80 局里 56–58 局变好），终结技不再是唯一清屏手段。
5. 未跑：「清一圈 + 留余烬」单独组、「late-power 单独」组没有数据；「精英 / Boss 上限单独」只跑了 56 / 80 局。云端额度用完，协调人 11-05 叫停，见 §5。

基准：`claude/ult-rebalance-ab`（late-game-diag + 合入 late-power-ab 329f277ee + 本稿 2babf3f01），所有组跑在同一份代码上，只用 `--bal=` 切开关。

### 3.4 读法
- **次数和间隔全靠降频**：只降频就从 5.9 次降到 3.8 次，另两项不改次数。
- **对普通怪的定位靠「清一圈」**：只降频时终结技击杀占比 12.1%，三项全开 8.0%；两者之差（约 4 个点）来自圈外留余烬（上限只管精英 / Boss，对普通怪击杀几乎没有影响，见 §3.3）。「清一圈」单独组没跑，这是推算。
- **精英的压力回来了一点，但没有完全回来**：精英单次最多 56%，不再一发打到剩 10%；但精英存活中位只从 16 秒变成 15–17 秒——本来大部分精英是被普攻 / 技能打死的，吃到终结技的只有 14–24%。
- **中期 Boss 是只削终结技的主要代价**：每只 Boss 吃的终结技次数 1.2 → 0.6，单次 29% → 18%，击破率 68% → 51%（只降频时 48%）。加上 late-power 后击破率回到 66%，最终 Boss 击破 45% → 60%。
- **清怪比没有变差**：终结技清得少，普攻 / 技能拿到的击杀多，配对比较 70% 以上的局清怪比上升；同屏清空秒数 10.2 → 9.8（加 late-power 8.9）。
- **只上限的中期 Boss 战时长变短（100 → 84 秒）是幸存者偏差**：击破率掉了 8 个点，留下来算时长的是打得快的那些局。

## 6. 推荐与下一步

- **推荐旋钮组合**：`ult/rework` = 1，子项全开，缺省值（`rw_soft` 10、`rw_sec_cap` 0.9、`rw_elite` 0.5、`rw_boss` 0.18、`rw_ring_r` 300、`rw_ember` 0.6），**和 `growth/late_shape` = 1 一起上**。只上本开关会让 18 细胞档出窗口。
- 上线前：补跑「清一圈」单独组和第二组种子，确认 18 细胞档不是贴着 65 的运气；late-power-ab 的说明对账 3 条要先修。
- 若想精英压力更明显：`rw_elite` 降到 0.4（单次 40%），或让机器人遇到精英不再立即放（`ult/bot_n` 判定里的 elite_core），后者只影响机器人局。
- 真人局：机器人按满能量 + 条件就放；真人通常放得更早更频繁，本稿的降频对真人的影响会比机器人局更明显，建议用户实机试一局（`--bal=ult/rework=1 --bal=growth/late_shape=1`，只在 debug 构建有效）。
