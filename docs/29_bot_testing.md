# 29 · 分档机器人测试（AFK / 手残 / 普通 / 高手）

> 2026-09-25。在 docs/27 的平衡框架上加一层「玩家水平」维度：同一版本、同一开局，用四档机器人跑，
> 看难度曲线对不同水平的玩家是否合理。docs/27 §10 要的「真人对照」先用这四档近似。

## 1. 四档机器人

代码：`game/scripts/core/bot.gd`（game.gd 只在 `--balance` 下创建它；`_bot_move` / `_bot_pick` 原样保留作 normal 档）。

| 档 | 参数 | 走位 | 选卡 | 代表谁 |
|---|---|---|---|---|
| AFK 挂机 | `--bot=afk` | 完全不动，只靠干员自动攻击 | 随机 | 下限：什么都不做能活多久 |
| Bad 手残 | `--bot=bad` | 随机方向走 0.8–2.2 秒再换；每 0.5 秒看一次危险，30% 概率、延迟 0.4 秒才躲 0.5 秒；缩圈时慢半拍往回走 | 随机 | 第一次玩、不看屏幕的玩家 |
| Normal 普通 | `--bot=normal`（缺省） | 原有机器人：躲预警 / 溟痕 / 弹幕、远离远程怪射程、低血后撤、捡东西 | `balance.json bot` 权重 | 会玩的一般玩家；与 docs/27 的历史基线可直接对比 |
| Expert 高手 | `--bot=expert` | 每帧对 16 个方向 × 2 个步长打分找空地；弹幕按 0.15 / 0.3 / 0.45 秒后的位置预判；带动量绕圈风筝；近战编队贴近到 50（远程编队保持 100）；灯火低优先灯油；Boss 保持 200–320 | 打分：精英化 > 补齐编队（缺治疗 / 保护优先、档位高优先）> 技能 > 全队被动（受伤时偏生存）> 藏品按稀有度 | 熟练玩家 + 合理 Build |

机器人的随机数走自己的 `RandomNumberGenerator`（按 `--seed` 派生），不消耗全局随机流。

## 2. 指标

`BALANCE` 输出里新增 `bot` 段（`bot.gd report()`），批跑器 `tools/balance_run.py` 汇总成两张表。

| 指标 | 含义 | 看什么 |
|---|---|---|
| 胜率 / 平均存活 / 最短存活 | 同 docs/27 | 总体难度 |
| 3:30 / 5:00 存活率 | 活过第一个 Boss / 中期 | 「任何开局都能站住」 |
| 首次招募、首次精一 / 精二 | 秒 | 成型节奏（目标精一 1:00–1:40、精二 6:00–7:00） |
| 中期 Boss 击杀数 / 平均用时 | Boss 出现到倒下 | Boss 是否是「考试」而不是「墙」 |
| 受击 / 分、承伤 / 分 | 从 dmg_log 增量统计 | 走位质量 vs 压力 |
| 低血（< 35%）秒、熄灯秒、熄灯掉血 | 熄灯每秒 3 点不进 dmg_log，单独记 | 死亡螺旋 |
| 静止%、移动距离 / 分 | | 验证机器人行为符合设定 |
| 主要死因 | 最后一次掉血的来源 | 注意：侵蚀（corrode）常是补刀，看承伤构成更准 |
| 曲线 | 每 30 秒：生命%、灯火、等级、击杀、编队人数、承伤、场上敌人数 | 画压力曲线 |

## 3. 难度目标（本版提议，可改 `balance_run.py BOT_TARGETS`）

| 档 | 胜率 | 平均存活 | 3:30 存活 | 理由 |
|---|---|---|---|---|
| AFK | 0% | 1:30–5:00 | — | 挂机必死，但不该死在第一分钟；活过 5:00 说明太简单 |
| Bad | 0–10% | 3:00–8:00 | — | 新手能看到第一个 Boss，偶尔撑到中后期 |
| Normal | 30–55% | 7:00–13:00 | ≥ 90% | 一般玩家三到五成通关 |
| Expert | 70–95% | 9:00–13:00 | 100% | 高手大多通关但不是必胜；与 docs/27「成型队伍 60–75%」衔接 |

## 4. 用法

```bash
python tools/balance_run.py --preset starts --bots afk,bad,normal,expert --seeds 4 --tag bots   # 标准矩阵：7 个开局 × 4 档 × 4 seed
python tools/balance_run.py --op wisadel --bot expert --seeds 5                                   # 单档
python tools/balance_run.py --preset squads --bot expert --seeds 3                                # 预设编队 × 高手
```

`starts` 预设 = 单人开局、自然招募（真实流程），每个职业一名：维什戴尔 / 艾雅法拉 / 斯卡蒂 / 水月 / 塞雷娅 / 凯尔希 / 铃兰。
报告最上面是「按机器人汇总」表，每档给出 达标 / 偏难 / 偏易。云端 2 核跑完 112 局约 22 分钟。

## 5. 基线（2026-09-25，`build/balance/bots_baseline_0925_2022`，难度 0，112 局）

| 档 | 胜率 | 平均存活 | 3:30 存活 | 终局等级 | 判定 |
|---|---|---|---|---|---|
| AFK | 0% | 1:04 | 0% | 3.2 | 偏难 |
| Bad | 0% | 1:22 | 0% | 3.9 | 偏难 |
| Normal | 0% | 5:32 | 100% | 16.0 | 偏难 |
| Expert | 17% | 7:40 | 100% | 23.3 | 偏难 |

承伤构成（全部局汇总）：

| 档 | 接触 | 弹幕 | 侵蚀 | 其它 |
|---|---|---|---|---|
| AFK | 89% | 1% | 7% | |
| Bad | 85% | 4% | 8% | |
| Normal | 45% | 20% | 9% | 电击 4%、缩圈 4%、熄灯 3% |
| Expert | 24% | 43% | 6% | 溟痕 9%、电击 4% |

### 结论

1. **四档都偏难，但层次是对的**：AFK < Bad < Normal < Expert，存活 1:04 → 1:22 → 5:32 → 7:40，说明机器人分档有效、测试可信。问题是整条曲线整体右移不够。
2. **开局 90 秒对不躲的玩家是死刑**：AFK 与 Bad 平均 1:00–1:30 死，89% 是接触伤害；第 60 秒场上约 45–50 只、第 90 秒约 70–85 只，生命从 93% → 69% → 40%。与开局干员无关（7 个开局都在 0:48–2:03）。对应 `waves.json` 第一段 `elite: 45`（45 秒就出精英，pocket / mimic 是这一段的主要杀手）与刷怪率。
3. **普通玩家卡在 4–7 分钟**：2:30 前生命一直 ≈ 98%，3:30 全员活着（生命 83%），之后第一个 Boss（3:30）+ 场上 165→210 只把他们压垮；0% 通关。艾雅法拉 / 凯尔希开局 5:00 存活只有 25% / 0%，是最弱的开局。
4. **高手死于弹幕**：高手把接触伤害压到 24%，但弹幕占 43%、溟痕 9%；受击频率约为普通的 0.8 倍，仍大多在 5–9 分钟被磨死。维什戴尔 / 水月开局 50% 通关、艾雅法拉 25%，斯卡蒂 / 塞雷娅 / 凯尔希 / 铃兰 0%。
5. **成型节奏偏慢**：高手首次精二 3:13–4:46（目标 6:00–7:00，偏早），普通玩家很多局到死都没精二；普通玩家首次招募 1:16–1:39 正常。

### 建议（按 docs/27 §2 分层，每次只动一层）

| 优先 | 层 | 改什么 | 预期影响 |
|---|---|---|---|
| 1 | 敌人压力（`waves.json` 第一段） | 首只精英 45 → 90 秒；或 pocket / mimic 前 2 分钟接触伤害 ×0.7 | AFK / Bad 活到 1:30–3:00，普通 / 高手几乎不变 |
| 2 | 敌人压力（`balance.json enemy`） | 中期（3:30–7:00）刷怪率或 `spawn_div` 放缓 10–15% | 普通玩家 5:30 → 7:00+，开始有通关 |
| 3 | 敌方弹幕 | 远程怪弹幕伤害或射速 −15%（只动远程怪） | 高手胜率上升，接触型玩家基本不变 |
| 4 | 干员层 | 艾雅法拉 / 凯尔希单人开局补清群（参照 docs/27 铃兰溅射的做法） | 最弱开局追上中位 |

改一项跑一次 `starts × 4 档 × 4 seed`，对照上表；同 seed 仍不能完全复现（docs/27 §7），结论看均值。

## 6. 局限

- 高手机器人是「规则打分」不是最优解：不会主动放技能（技能自动释放）、不会规划商店、不会利用地形卡位；它是真人高手的**下限**。
- 机器人没有反应延迟之外的疲劳 / 注意力模型；真人的「普通」可能比 normal 档略差。
- 伤害来源的「主要死因」是最后一击，侵蚀常作为补刀出现；判断杀手看承伤构成。

## 7. 调参记录

- **2026-09-26 r4–r6（敌人层）**，全部在数据里：
  - `balance.json enemy`：`first_elite` 45 → 90（首只精英出现时间，原为 game.gd 里写死的 45）；`spawn_div` 30 → 35（刷怪增长放缓约 15%）；新增 `bullet_dmg_mult` 0.85（敌方弹幕与抛射物伤害）。
  - `waves.json`：新增 `mid_first: [0, 1]`，3:30 的第一个中期 Boss 只从塑路者 / 圣徒伊比利亚里抽；卡门与两组接潮双 Boss 留到 7:00。依据：基线里普通机器人对双 Boss 击杀 1/20、对卡门 0/9，Boss 出现后约 1.5 分钟死亡，3:30 是「墙」不是「考试」。
  - `enemies.json`：接潮主教 2300 → 1700、蔑死体 2600 → 1900、斥亡体 1800 → 1400（双 Boss 总血量约等于一个单 Boss 的 1.1 倍）。
  - 结果（`r4_enemy` / `r5b_boss` / `r6_bullet`，每档 28 局）：AFK 1:04 → 1:24，手残 1:22 → 1:49，普通 5:32 → 5:40–6:17（首次出现胜局），高手胜率 17% → 21–28%、存活 7:40 → 8:25–8:45。第一个 Boss 击杀率：普通对塑路者 13/16、伊比利亚 5/12，平均 51 秒。
  - 仍全部「偏难」。普通机器人的死因里缩圈占比上升（黑潮 8–16%），部分是它躲缩圈的逻辑不足（`_bot_move` 缩圈权重 3.0 常被敌人推力盖过），不全是数值问题。高手的主要死因仍是弹幕（约 50%）。
  - 同 seed 不能完全复现，每档 28 局的平均存活误差约 ±40 秒；小于这个幅度的变化不当结论。
- **斯卡蒂**：S1「潮涌斩」补登记 `hit_sources`（之前伤害被统计成未知来源）。
- **干员层（未落地）**：`--preset opcmp`（被测干员 + 推进之王 + 流明，开局满编，高手机器人）显示维什戴尔直接伤害约为主输出均值的 120%，艾丽妮 / 乌尔比安约 75%、幽灵鲨约 63%。试改后复测被随机误差淹没（「每分钟伤害」会被存活时间干扰），下一步用 `--extra=--nodeath` 跑满 10 分钟再比，结论出来前不改干员数值。
- 批跑器：新增 `opcmp` 预设与「开局干员 伤害占比 / 每分钟」列；局内出现 `SCRIPT ERROR` 会在报告顶部警告（r5 曾因一处 float/int 比较失败导致第一个 Boss 整段没刷出来，结果作废）。
