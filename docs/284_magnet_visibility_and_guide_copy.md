## 1. 磁铁：现状

### 1.1 掉落与规则（`run/combat.gd`、`run/pickups.gd`、`balance.json` 的 `pickup/*`）

- 来源：精英 / 大型击杀（`pickup/elite_magnet_share` 0.5，另一半是回复药剂）、小怪击杀 0.375%（`magnet_kill_chance`）、补给箱 10%（`crate/magnet_p`）；**场上同时最多 2 个**（`pickup/magnet_cap`）。
- 效果：拾取后全场经验、灯油、源石锭被吸过来；屏幕一圈 420 像素的粉红环 + 飘字「磁铁：吸取全场掉落」。
- 所以磁铁**很少见**（一局几个）而**很值钱**（后期一次吸回全场经验），但玩家常常没看到它。

### 1.2 画法（`render/world.gd` 约 1120–1142 行，`_pq_sprite`）

| 层 | 现状 |
|---|---|
| 本体 | `art/world/pickups/pickup_magnet.png`，**14×14 美术像素**（世界里 28×28），上下浮动 ±2 像素（`sin(t*3.5)`） |
| 颜色 | `item_col("magnet")` = (1.0, 0.5, 0.55) 粉红 |
| 光环 | 非宝箱的特殊掉落：一圈半径 11±2 的细环（alpha 0.5）+ 半径 16 的淡填充（alpha 0.12） |
| 落地提示 | 掉落后头 0.9 秒一道 140 像素高、10 像素宽的白色光柱，然后消失 |
| 屏外提示 | **没有**。商人 / Boss / 灯标 / 鸭爵有屏外指针（`hud_banners._edge`），磁铁没有 |
| 存在时间 | 代码里未见过期逻辑（出屏回收 `recall` 只针对经验结晶） |

### 1.3 为什么看不见（判断，需截图确认）

1. 28 像素的小贴图 + 粉红色，在后期满屏受击白闪、紫黑溟痕和粉红 / 红色敌人特效里**颜色撞车**（磁铁粉红 ≈ 终结技 / 敌方危险色系）。
2. 光环太细太淡（0.5 / 0.12 alpha），白光柱只有 0.9 秒，错过就没有任何持续提示。
3. 没有屏外指针；磁铁掉在屏外（击杀点在边缘、吸附后位置）就丢了。
4. 磁铁没有“动”的语言：只有 ±2 像素浮动，经验结晶、灯油反而在流动。

## 2. 磁铁：两个画法（Noita 像素观感）

Noita 口径（memory look-direction-1023 / fx-style-pixelfx-noita）：实心主形 + 少量发光像素 + 粒子化光，不画实线圆、不用半透明盘；程序生成，少帧。磁铁场上 ≤ 2 个，所以每个可以画得很讲究，成本可忽略。

### 画法 A「磁场铁屑」（推荐）

- **本体**：贴图放大到 ≈ 20×20 美术像素（保持 24 色以内），马蹄形，**红 / 钢蓝两极**（磁铁的通用符号；全游戏其他掉落都是单色：经验青、药剂绿、箱子金，所以双色立刻分得出）。两极各一点 `emit` 发光像素（沿用 `gem_*_emit` 做法，光学观感下同位置排发光层）。
- **磁场**：地上 3–4 小簇**灰蓝铁屑像素**（1×1 / 1×2 美术像素），朝磁铁缓慢聚拢、到了又被弹开，循环；每簇 3–5 个点，总共 ≤ 16 个点。
- **脉冲**：每 1.2 秒一道由像素点组成的断续环从磁铁向外扩 90 像素然后消失（红 / 蓝各半），不是实线圆。
- **落地**：保留 0.9 秒光柱，改成**双色细光柱**并拖一小段铁屑向上飘。
- **屏外指针**：加入 `hud_banners._edge`，用同一套箭头 + 小磁铁图标，颜色红 / 蓝；只在磁铁离开屏幕时出现。
- 成本：贴图 1 张（20×20 + emit）、粒子点程序生成（`g.vrng`）、脉冲环用合批点。

### 画法 B「冷光柱」

- 本体保持 14×14 但换成**冷白 + 品红**（避开粉红 / 红），加 2 帧闪烁（各 0.35 秒）。
- 一根**常驻**竖向像素光柱（高 ≈ 70 像素，宽 3 像素，白 → 青逐像素渐变），顶端有 3–4 个像素火星缓慢上飘；柱子低亮度，不盖怪物。
- 屏外指针同 A。
- 成本更低（不要新贴图，只改 `bcol`），但“磁”的语义弱，光柱和商人 / 灯标的竖柱语言可能混。

### 推荐

**A + 屏外指针**。理由：双色马蹄 + 铁屑聚拢让“这是磁铁”一眼就明白，不靠颜色单独区分，也不和已有的竖光柱（落地 / 灯标）混。B 作为低成本备选。

### 与玩法的关系

- 只改画面和屏外指针，**不改掉落 / 拾取 / 上限**，同 seed TRACE 不变（只读 `g.vrng`）。
- 屏外指针只是 HUD 画，不改判定。
- 不加“出屏回收”：磁铁上限本来就是 2，丢了也是设计；要不要加另议。

### 验证

GCP 出图（docs/256）：后期 8:00 同 seed，放 1 个磁铁在玩家右侧 200 像素，现状 / A / B 三张全屏 + 三张 3 倍放大；再出一张磁铁在屏外的指针截图。用户选定后再接。
