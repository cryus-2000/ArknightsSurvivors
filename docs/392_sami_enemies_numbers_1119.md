## 4. 国度撑持体（坍缩体的撑持状态）

用户 11-19 定的瓦解规则（docs/390 §13.6–13.7）：国度只靠击杀撑持它的坍缩体瓦解，外加在国度里或边缘击杀敌人让裂纹长。撑持体是**普通坍缩体加一层状态**，不是新敌种：

| 项 | 值 | 理由 |
|---|---|---|
| 来源 | 国度刷出时，从躯壳 / 构造体 / 施法者里按当前阶段池权重抽 2–4 只（只数见 docs/391 §6.3） | 跟当前阶段的怪长得一样，玩家不用新学认怪 |
| 生命 | **×2.5** | 不加的话，撑持体会被路过的割草顺手清掉，国度「打着打着自己就碎了」，瓦解就不是一个目标；×2.5 让一只撑持体要专门打 1–2 秒 |
| 移速 | ×0.8，拴在国度中心 160 内 | 连线不能拉太长，否则读不出是谁在撑 |
| 经验 | ×2 | 专门去打要有回报 |
| 伤害 | 不变 | 只加肉、不加痛，避免「撑持体 = 小精英」 |
| 标记 | 头顶小冰晶菱形 + 到国度中心的地面墨纹连线 | docs/390 §13.6 |
| 词缀 / 精英小队 | 撑持体不带词缀、不进精英小队 | 避免叠加成肉墙 |
