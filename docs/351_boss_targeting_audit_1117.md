# 351 选敌排查：干员不打 Boss（11-17）

起因：11-17 玩家反馈「安洁莉娜不打 Boss」，abc544d32 已修（普攻 / S1 落点只找最密处）。本篇把 20 人全查一遍，口径与安洁莉娜相同。

## 1. 统一口径

`op_api.nearest_enemies` 是全队的统一选敌：部件优先 → 中期 Boss 锁定 → Boss 优先档把可受击 Boss 排第一 → 护主（队长身边有小怪贴脸时不强制）。
凡是按「最密处 / 最远 / 人头最多方向」挑落点的，先问它：排第一的是可受击 Boss / 部件就选 Boss，否则照旧。
新增两个入口（`op_api.gd`）：

- `focus_boss(max_dist, origin)`：统一选敌排第一的是可受击 Boss / 部件就返回它，否则 `{}`。
- `boss_or_densest(radius, origin)`：有 `focus_boss` 就落在 Boss 身上，否则敌群最密处。

清杂优先档、护主、射程内没有 Boss 时行为不变。

## 4. 偏低但有意保留（不是选目标问题）

按 `BPROBESRC` 拆到伤害来源看，下列偏低来自范围 / 位置设计，Boss 在圈里时照打：

- **浊心斯卡蒂**（约 24%）：声浪 / 潮汐和声 / 余音都以**队长为圆心**、半径 aura 内最多 wave_n 个（Boss / 精英优先）。Boss 在圈里时它本来就排第一；占比低是因为队长常不贴 Boss，且一圈打多名敌人、Boss 只占一份。保留（原作定位：以自身为中心的范围增益 / 输出）。
- **流明**（约 34%）：医疗位，伤害主要是终结技光圈（以队长为心）和「散射」（成长藏品银餐叉：额外弹**有意**射向另一名敌人，docs/163）；光弹 / 灯塔光柱 / 发光单元单体部分 62–73% 打 Boss，正常。
- **星熊**：举盾反击打的是攻击队长的敌人（小怪居多），设计如此；力之锯 / 般若回旋 69–71%。
- 范围技：乌尔比安「撼地」、维什戴尔「余震 / 殉爆」、安洁莉娜「失重井」、斯卡蒂 / 星熊的「剑气」（藏品锈蚀刀片）等，打一片、Boss 只占一份。
- 连携技（`combo.gd`）里明确只打非 Boss 精英 / 残血杂兵的几种（拉普兰德、逻各斯、歌蕾蒂娅），是清杂分工，保留。

## 5. 查过、看了数据决定先不改

普攻都能打到 Boss（满足「普攻不能完全不碰 Boss」），只是某个技能 / 节点偏向别的目标：

- 艾丽妮 S3 判决：12 次追击只从浮空表里抽，Boss 不能被挑起所以不在池里（「手炮轰击」35% 打 Boss）；总体 50%，不偏低。若要改：Boss 在判决范围内时并进抽取池。
- 德克萨斯 S3 次元斩：每轮每个目标只斩一次、按离上一刀最近排序；「次元斩」49%，正常。
- 拉普兰德点「追猎」节点后，远程剑气 aim=low_hp（满血 Boss 排不上）；近战普攻照打 Boss，总体 55%。节点本意是追残血。
- 水月触手追击按绝对血量升序挑；「触手」40%，与总体一致。
- 能天使护航 / 对空优先节点、维什戴尔 S2 第二段 random、礼尚往来第二发：节点 / 招式本意分散火力。
- 乌尔比安 S1（reel，pick=elite）：拉精英，Boss 拉不动会退成扑击，保留精英 / Boss 同档。
- 终结技缺省落点 `ult._densest` 里 Boss 算 3 只怪：半径 460–615，Boss 多半在圈内，不改。
