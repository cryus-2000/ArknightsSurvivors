# 194 普通怪伤害曲线平滑化（claude/dmg-curve，10-29）

用户 10-29：① 后期普通怪一下最高 30（10:00 及以后封顶）；② 前期加成改成 0–3 分钟的一条平滑曲线；③ 整条曲线单调平滑、没有凹凸点和断崖，后期不再「一下子暴毙」。
口径（参考图 `Claude outputs/enemy_dmg_curve_1029.png`）：标准档「当时刷怪池平均」的一下伤害 = 池平均基础伤害 × 时间倍率 × 密度 1.58（(1/0.4)^0.5）× 受伤 0.9（`dodge_comp_taken`）− 平均护甲 1.9。

## 改了什么

`spawner.new_enemy` 原来叠了 `dmg_div/knee`、`dmg_early(+until)`、`dmg_late_cap(+start/div)`、`dmg_gain_early/late/from`、`_trim_apply` 里的 `trim_early_dmg` 多段，换池（档位刷怪池变化）时池平均基础伤害还会跳，所以 1:15 / 2:50 / 4:40 / 6:40 / 8:40 各一个台阶、3–4 分钟有凹、5:00 断崖。现在收成**一条**按时间的目标曲线（`run/dmg_curve.gd`，`balance.json` 新段 `dmg_curve`）：

- `knots` = [[0, 12], [180, 19], [300, 23], [420, 27], [600, 30]]（秒，池平均一下伤害），单调三次插值（Fritsch–Carlson，一阶连续），末点之后封顶 30；
- 时间倍率 m(t) = (T(t) + ref_armor) / (池平均基础伤害 × 密度系数 × ref_taken)，**按每个威胁档刷怪池的平均基础伤害归一**（池里重复出现的按次数加权），所以「池平均一下」严格沿 T(t) 走，换池也不跳；个体差异保留（狂奔者 12 照样比骨海漂流体 5 疼）；
- 精英 ×1.3（`elite_dmg_mult`）、大群 ×0.7（`horde_dmg`）、敌弹系数、Boss、`tier_dmg`（高阶怪接触伤害打折，图上口径本来就不含）、难度档的 `enemy_dmg` 倍率全部不动；
- 旧旋钮（`dmg_div/knee/early/early_until/late_*/gain_*`、`trim_early_dmg`）在 `dmg_curve/on = 1` 时不再起作用，JSON 里旧值保留；`on = 0` 回到旧写法（对照用）。`dmg_late_cap` 的难度档值（潮位 9 的 0.5 等）在 10 分钟内本来就碰不到上限（斜率 1/900 秒，10:45 才到 0.25），没有实际意义，不再生效；
- 图鉴的怪物伤害（开局的数）改读曲线 0 秒的倍率。
