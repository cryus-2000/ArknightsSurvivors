# 171 圣徒伊比利亚 / 圣徒卡门：出招组、连携与分级弹幕（10-27）

状态：已实现，待用户看录像；分支 `claude/boss-saints`（从 `codex/boss-fx-rework` 72f41c3c7 开出），未合入 main。

用户 10-27：每只 Boss 分开做特效、招式间的攻击连携、招式数量；要有「打 Boss 的感觉」——弹幕有图案、有规律可学、可读、有压迫感和节奏、Boss 存在感强。东方只是例子，**不照搬符卡制度**（不做符卡名横幅、不按符卡切幕清屏）；阶段沿用现有幕制（50% 卡点）。追加：「boss 的攻击方式要有自己的特色」。

两只共用 `enemies/bosses/saint.gd`，但出招组各自独立设计：

| | 伊比利亚（炮火橙） | 卡门（象牙白） |
|---|---|---|
| 身份 | 单发重炮：一发打完必须装填 | 三发连射：直线火力切场地 |
| 弹体 | 大弹（r11–12，热白发光核心 + 暗橙外描边）→ 落地 / 到点炸成碎弹（r5，无核心） | 细弹（r5，白芯 + 暗金褐外描边），排成平行或交叉的直线弹列 |
| 主轴 | 打断：躲过一炮，装填时冲刺穿身（一幕累计 5% 也算） | 封锁线：三枪各留带缺口的火线，装填时压上去 |
| 图案 | 「点 → 炸开」：炮线上一串残弹、弹坑碎片环、三发重炮弹 | 「线 → 跑道」：平行弹列空一条道、两组 ±45° 交叉弹列空一格 |

## 1. 出招组

每幕 2 组，每次补满弹药（装填完毕 / 打断起身）换下一组，两组交替。每组是一串 ≤4 段的连携，最后一定打空弹药 → 装填 = 收招破绽（主轴窗口）。段间至少收势 0.35 秒（卡门狙击之间 1.3 秒）。组名只用于文档与录像标题，玩家看到的是血条副标题里的招式名。名字均为本作改编：原作只有「手炮」「弹药」「装填」（PRTS，docs/49c §6）。

| Boss | 幕 | 组 | 连携 | 追加弹幕 |
|---|---|---|---|---|
| 伊比利亚 | 一 | 手炮 · 炮线 | 手炮 → 装填 | 炮线上距本体 150–630 留 5 发残弹（静止，×0.4），0.55 秒后各炸 6 片、相邻错开半格，往两侧慢扩散 |
| | 一 | 轰击 · 弹坑 | 轰击 → 装填 | 落点炸 12 片，朝伊比利亚留 ±0.5 弧度缺口 = 冲向他的路 |
| | 二 | 延生 · 重炮弹 | 散射（近身才放）→ 重炮弹 → 装填（三连曲射、抡击照旧） | 重炮弹：0.6 秒枪口预警后 3 发大弹扇形 ±0.34，230 减速到 45，1.15 秒各炸 8 片 |
| | 二 | 延生 · 三角弹坑 | 轰击（不耗弹）→ 手炮（带炮线残弹）→ 装填 | 装填时三连曲射三个落点各炸 8 片，朝他留 ±0.7 缺口，三角内部不加弹 |
| 卡门 | 一 | 狙击 · 封锁线 | 狙击 ×3 → 装填 | 原封锁线 |
| | 一 | 狙击 · 曳光弹列 | 曳光弹列 → 狙击 ×2 → 装填 | 7 列平行弹（间距 56，每列 4 发，300px/s），空一列（随机偏离你 1–2 列）；0.7 秒枪口预警 + 出弹点红闪 |
| | 二 | 守誓 · 交叉封锁 | 狙击 ×3（第三枪垂直锁你所在跑道）→ 装填 | 原交叉封锁线 |
| | 二 | 守誓 · 交叉弹列 | 环射 → 交叉弹列 → 狙击 ×2 → 装填 | 两组各 5 列（间距 64、270px/s），沿瞄准方向 ±45° 从你身后 380 处扫过，各空一列，两空道相交处 = 安全格；0.6 秒预警 |

招式数：伊比利亚 7（手炮、轰击、三连曲射、抡击、散射、清膛、重炮弹）；卡门 6（狙击、炮身横扫、环射、炮身砸击、曳光弹列、交叉弹列），每幕至少 2 组。

## 2. 生命周期

- 出招组队列保存在敌人字典（`cq` / `cq_next` / `card_ph` / `card_i`），玩法随机只用 `g.rng_enemy`，同 seed 可复现；画面颗粒只用 `g.vrng`。
- 破绽、晕眩、过卡点无敌清队列；一组超过 18 秒强制结束。转幕（过卡点）换到新幕第一组。
- 打断装填 = 主轴奖励：清掉她 / 他在飞的弹体和未出膛的弹（化成淡金白颗粒），追加弹幕监听表清空。
- `patterns` 的自动轮转（散射 / 环射）停用，只由出招组点名。
- 远程段超时（`saint_ranged_max`）在连携出招时清零，仍保留给「站着不打」的兜底。
- 原近战追击、退避跳、炮身横扫 / 砸击、二幕清膛 + 三连等规则不变。

## 3. 读法与特效

- 预警：新弹幕起手是枪口小圈（不画矩形）+ 出弹点红色闪点，红只给预警；弹体用专属色。
- 弹体分级：大弹 `core_r` 热白核心（`render/world.gd` 通用字段，其他 Boss 也可用）、同色系暗外描边（`enemies.json bcol_outline`，卡门新增 `bcol_core` / `bcol_outline`）。
- 炸点：专属色一圈颗粒迸散（`bfx`，走 Boss 颗粒预算，docs/136）。

## 6. 输出窗口（10-27 用户「每个 Boss 都要注意给干员输出的机会和时间」）

探针：`saint_card_preview --card-check --card-measure`，自然流程每幕 60 秒（出招组照常轮换），玩家无敌、绕 Boss 130 处一直跑；「打断」= 每次装填读条 0.4 秒时调用正式 `saint_interrupt`（模拟冲刺穿身）。
低压 = Boss 在 ≤180 内、她 / 他的同屏敌弹 < 20、没有未结算的伤害预警；窗口 = 装填或破绽。

| Boss | 幕 | 不打断：低压 / 窗口 / 窗口内弹密 | 打断：低压 / 窗口 | 火线挡住连线 |
|---|---|---|---|---|
| 伊比利亚 | 一 | 52% / 2.2 秒 / 3% | 80% / 5.4 秒 | — |
| 伊比利亚 | 二 | 41% / 1.8 秒 / 1% | 56% / 5.4 秒 | — |
| 卡门 | 一 | 68% / 3.0 秒 / 0% | 68% / 5.4 秒 | 13% |
| 卡门 | 二 | 51% / 3.0 秒 / 0% | 61% / 5.4 秒 | 9–11% |

调整前伊比利亚不打断时为 38% / 30%，装填窗口里同屏碎弹 ≥20 的占比 29% / 38%。调整（不改单发伤害）：

- 炮线残弹 5 → 4 发（距本体 170–590），各炸 6 → 5 片，碎片寿命 2.4 → 1.4、速度 90 → 120（装填开始前散完）。
- 三角弹坑每点 8 → 6 片、寿命 1.4；弹坑 12 片寿命 1.8。重炮弹每发 8 → 6 片、寿命 1.4。
- 二幕装填 1.4 → 1.8 秒（`boss/iberia_reload_p2` 缺省值；docs/142b §3.3 原 1.4）。
- 装填完毕的「三连」打完多收势 0.6 秒，才接下一组。

卡门不用改：装填 3 秒、窗口内没有密弹；火线挡住「你到她」连线的时间 ≤13%，每条火线都有缺口。探针玩家固定在 130 处绕圈，不代表全部编队和走位，整场难度还要云端同 seed 对照。

## 7. 光束蓄力 / 消散、伤害旋钮（10-27 用户）

用户：激光、光束、火线都要有「蓄力」和「消散」的感觉；弹幕变密了，单发伤害整体下调。

- **蓄力**（`render/saint_draw.gd charge`）：手炮、三连、狙击的预警带 `saint_beam`，不再画斜纹矩形与轮廓。光束从 1 像素长到预警宽度 ×1.2，亮度随进度上升，锁定后加白芯；两侧危险色细边标出判定宽度；枪口外 34–60 处的颗粒向枪口收拢（mote_in，走 Boss 颗粒预算）。
- **开火**：Kanpelle 光束短闪，不变（0.25 秒）。
- **消散**（`saint_draw.fades`）：开火 0.12 秒后接上，0.32 秒内光束变细、断成 18 像素碎段逐段熄灭，第一帧沿线迸出颗粒。
- **卡门火线**（`boss_beam._fire_lines`）：生成 0.25 秒由细变粗（线宽 2 → 4）；最后 0.4 秒变细并断成碎段，余烬颗粒往上飘。判定不变。
- **伤害旋钮** `boss/saint_dmg_mult`（缺省 0.8）：出场第一帧乘到 e.dmg 上。所有招式、弹体、火线、接触伤害一起缩；云端测完再定。

公共文件钩子：`telegraph_draw.draw_fills` 和 `world.draw_warn_outlines` 遇到 `saint_beam` 时交给 saint_draw；`boss_beam.draw_ground` 对两位圣徒调用 `fades`。其他 Boss 想用同一套，可以给自己的直线预警加 `saint_beam`，或者复制这两个函数。

## 8. 单场时长与伊比利亚装填窗口（10-27 协调人，测试台 docs/170）

测试台（云端 96 局 / 只）：单场中位卡门 30 秒、伊比利亚 24 秒，招式没放全就结束；伊比利亚破绽输出 3%（装填读条不算破绽，打断又很少发生）。目标：单场 45–75 秒（4 招放一到两轮 + 2–3 次破绽），伊比利亚破绽输出 ≥25%，胜率保持 ≥90%。

| 旋钮 | 缺省 | 作用 |
|---|---|---|
| `boss/iberia_hp_k` / `boss/carmen_hp_k` | 2.9 / 2.4 | 出场第一帧乘生命（在 hp_mid、hp_x_ 之后；伤害预算补充速度同乘） |
| `boss/iberia_reload` / `boss/iberia_reload_p2` | 3.0 / 2.6（原 2.2 / 1.8） | 装填读条 |
| `boss/iberia_reload_r` / `boss/iberia_reload_walk` | 160 / 1.8 秒 | 装填前离主控 > 160 先追最多 1.8 秒再原地装填 = 近战够得到 |
| `boss/iberia_reload_taken` / `boss/carmen_reload_taken` | 1.8 / 1.5 | 装填读条中受伤倍率（`taken_mult`，测试台记为破绽输出）；打断后的大破绽仍 ×1.4 |
| `boss/carmen_dmg_mult` | 0.9 | 卡门单发伤害（伊比利亚仍 `saint_dmg_mult` 0.8）：×0.8 时承伤只剩 15% |

一幕伤害打断阈值仍是 5% 最大生命：读条更长、受伤加成，打断更容易打出来。探针（§6 同口径）：伊比利亚不打断低压 57% / 44%、窗口 3.0 / 2.6 秒、窗口内弹密 1–2%；卡门不变。时长与破绽输出交 boss-bench 云端复测。

本机测试台（cherry-pick 4121e81ee + e82cdaffd，云端 saints 快照 3 开局 × 2 档 × seed 1–6，每只 36 局）：

| Boss | 胜率（0 / 18 认知） | 用时中位 | 承伤 | 破绽输出 | 破绽时间 |
|---|---|---|---|---|---|
| 卡门 | 94% / 100%（超时 3%） | 52 秒 | 22% | 36% | 27% |
| 伊比利亚 | 100% / 94% | 54 秒 | 51% | 32% | 20% |

## 9. 持续压力（10-28 用户批「加不停顿的新招」）

测试台复测（29f8d8854）：两只用时进区间，但卡门承伤 24%、胜率 94–98% 偏软；单纯加单发伤害（k4：卡门 0.9 → 1.1）承伤不动——机器人躲得开单次招式。改为两只各加一种「出招之间也在压场」的机制，装填 / 破绽 / 起身前一律停下（`_calm`），输出窗口不受影响：

| Boss | 机制 | 读法 | 旋钮 |
|---|---|---|---|
| 卡门「收束」 | 狙击留下的火线 0.6 秒后朝落枪时主控那一侧平移，跑道越来越窄，要从缺口穿过去；装填时停下并按原规则消退 | 线：火线本身在动 | `carmen_fire_drift` 36 / `_p2` 46 像素/秒；`carmen_fire_mult` 0.35 → 0.5；`carmen_dmg_mult` 0.9 → 1.15 |
| 伊比利亚「余烬」 | 每 1.4 秒（二幕 1.0）往主控前进方向（提前 0.7 秒）抛一团余烬，0.6 秒落地预警后烧 3.2 秒，r44，站在里面每 0.5 秒受伤 + 减速；最多 6 团；装填 / 破绽时 0.6 秒内熄掉，打断装填时清空 | 点：危险色细圈收拢 + 飞来的火点 → 暗橙烧地 + 闪烁外沿 + 余烬上飘（`saint_draw.embers`） | `iberia_ember_cd` / `_cd_p2` / `_lead` / `_arm` / `_life` / `_r` / `_max`；`iberia_ember_mult` 0.21 |

本机测试台（bench-base-1028 + 本分支 saint.gd / saint_draw.gd，新录快照 3 开局 × 2 档 × seed 1–6，每只 36 局）：

| Boss | 胜率（0 / 18 认知） | 用时中位 | 承伤 | 破绽输出 |
|---|---|---|---|---|
| 卡门 | 94% / 100%（失败都是超时） | 54 秒 | 44% | 39% |
| 伊比利亚 | 72% / 100% | 64 秒 | 134% | 40% |

卡门仍偏软但已有威胁（承伤 24 → 44%）；伊比利亚无认知偏难一点。18 局一档误差约 ±10 点，以云端全量为准。录像 `build/boss_saints/v4/{iberia,carmen}_cards.mp4`。
