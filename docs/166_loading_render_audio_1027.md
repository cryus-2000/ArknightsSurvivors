# 启动加载、渲染回收与激光混音（2026-10-27）

基线：`2b95168f2`，分支 `codex/final-boss-complete`。延续 docs/165 的完整 Boss 改造。本轮不改变伤害、攻击节奏、预警时长或游戏随机流。

## 启动加载

- 网页从下载到资源预热始终使用同一 HTML 加载页。Godot 启动页只回传真实进度，不再绘制第二层启动界面；菜单就绪后明确通知关闭，百分比不倒退。
- 引擎默认状态元素移除不再提前关闭加载页；引擎报错仍让错误信息露出。
- 网页带测试参数跳过预热时，静态协程等待新场景就绪及首帧，再关闭 HTML 遮罩，避免原启动节点销毁后失去回调。
- 桌面引擎初始化使用纯背景，移除先出现的静态加载图，保留有真实资源进度的动态启动页。开始一局时的场景加载仍单独保留。

## 渲染与内存

- 拉普兰德等后处理的友方保色遮罩连续停用 2 秒后，从普通及光学材质解绑纹理并释放视口；重新激活时按需恢复。短暂关闭复用原视口，弱引用不保留已离场材质。
- 1280×720 实际渲染测量：基础纹理内存 12,315,683 字节；启用遮罩 19,688,483；旧实现关闭后仍为 19,688,483，新实现回到基础值，回收 **7,372,800 字节（7.03 MiB）显存**。这是纹理内存，不是进程总内存或音频内存。
- Boss 地面圆环缓存投影单位圆坐标，保留原浮点舍入、40 个四边形及顶点顺序。10,000 次绘制微基准中位耗时由 241,730 µs 降至 173,478 µs，降低 **28.2%**；该数值只代表这一绘制函数，不能换算成整局帧率提升。
- 遮罩移动后像素变化、释放后双材质解绑、重建后像素一致、圆环全部顶点精确一致均有回归覆盖。桌面标题单次前后探测的稳态 P95 为 26.88/25.59 ms，样本不足以声称整局改善。未做手机真机内存或帧率验收。

## 激光音效

- 替换公共 `cue_beam_start` / `cue_beam_hit`：高频锯齿与嘶声改为较低频的圆润蓄能、空气脉冲与下沉尾音；单声道 44.1 kHz、0.9/0.8 秒及触发时刻保持。
- 两音源峰值由 -1.01 降至 -9.90 dBFS；4 kHz 以上能量占比分别从 9.47%/24.14% 降至不足 0.001%。混音后的最响 100 ms RMS 分别由 -16.07/-11.84 降至 -23.60/-23.38 dBFS。
- 起手与命中各最多一个播放实例，彼此不抢占。Boss 提示优先级保持。影响使用公共光束提示的直射、吐息、追踪冰线、潮链等招式；专属身份音和 BGM 不改。
- `gen_sfx_cues.py` 保留可再生成实现；频谱/响度检查和真实播放器并发回归覆盖该改动。能天使前轮音效及音乐文件哈希保持。
