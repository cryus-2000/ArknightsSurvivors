## 1. 原作：主题概况

- **剧情前提**（主题开场白，`topics.rogue_3.lineText`）：物资和人员都已备齐，探险者从萨米南疆的城市出发北上，穿过萨米和冰原，去揭开未知。解锁条件：通关主线 3-8。主题已完结（还能玩，部分内容已下线）。
- **初始状态**（PRTS「开始探索」）：目标生命 8、希望 6、源石锭 8、可携带干员 6、抗干扰指数 3、密文板 0。另有消耗性的**护盾值**，挡目标生命损失；目标生命有上限，提升上限会同时加同量的目标生命。
- **区域**：5 个常规层 + 2 个隐藏层（PRTS「区域」，名字和描述跟 `details.rogue_3.zones` 一致）：

| 层 | 名称 | 区域描述（概括） | 节点长度 | 层末 |
|---|---|---|---|---|
| Ⅰ | 初霜湖泽 | 新雪落在水面，风吹着船 | 4 | 2 个诡意行商 |
| Ⅱ | 密静林地 | 角兽伏在密林里，黑色树影渗进雪地 | 4 | 2 个得偿所愿 |
| Ⅲ | 昧明冻土 | 林木稀疏，**黑色苔原上析出点点虹光**，路线图一片空白 | 5 | **险路恶敌**（中期 Boss，3 选 1） |
| Ⅳ | 积冰岩骸 | 萨米抬起山脉，冷酷的战士筑起高墙 | 5 | 3 个得偿所愿 |
| Ⅴ | 无瑕花园 | 越过群山，生命无声；坚冰封住生灵，长出花簇般的冰晶 | 6 | 命运所指（走过萨米的臂膀）→ **险路恶敌**（结局一 / 二的最终 Boss） |
| Ⅵ（隐藏） | 远见之构 | 冰原尽头矗立着无法回避的命运 | 4 | 险路恶敌（结局三） |
| ¬ΔS（隐藏） | 永恒之尘 | 无始无终的时间，亘古的沙尘 | 5（单线） | 险路恶敌（结局四） |

  每层的失败结局都叫「风雪蔽目」（Trapped in the White Walls），失败文案各层不同。
- **节点类型**（`nodeTypeData`）：作战、紧急作战、险路恶敌、安全的角落、不期而遇、兴致盎然、迷雾重重、得偿所愿、失与得、先行一步、诡意行商、树篱之途、命运所指。本主题新增的是**失与得**（用代价换资源，结局二要从这里拿密文板）、**先行一步**（结局三要从这里拿【路网】）、**树篱之途**（进入隐藏的「深埋迷境」）。
- **主题机制**（PRTS 原名；「抗干扰指数与节点勘察」「坍缩值、坍缩等级、坍缩范式」「密文板」「远见」「宝箱」五节）：
  - **抗干扰指数** 0–6，初始 3，决定能看清前面几步节点：0 时之后所有节点都只剩「模糊的预感」（只分得出战斗 / 非战斗），6 时全域信息实时更新（`modules.rogue_3.vision`）。它也可以当资源花掉（事件代价）。
  - **坍缩值**：初始 0。遭遇某些事件、战斗中目标生命受损（每场 +1）、深入冰原（第二层起每层 +3）时增加。每满一档坍缩等级升 1 级，并新增或加深一条负面的**坍缩范式**；最多同时 4 条，坍缩等级最高 8（`maxChaosSlot 4`、`maxChaosLevel 8`）。升级所需值：挑战自然·0 每 4 点一级；·1 起后段缩到 3、2 点（12→15→18→21→23→25）。坍缩值降下来时随机弱化或去掉一条范式。等级越高画面的扭曲波纹越明显。
  - **坍缩范式** 10 种，每种有加深版（`modules.rogue_3.chaos.chaosDatas`）：

| 范式 → 加深版 | 效果（原文） |
|---|---|
| 去量化 → 去量深化 | 在非战斗节点付出希望、源石锭或增长坍缩值时，25% 概率多付 1 点 → 50% 概率多付 2 点 |
| **实质性坍缩 → 蔓延性坍缩** | 战场中出现 4 处【国度】，【国度】上的我方单位攻击速度 −50 → 8 处，−75 |
| 非线性移动 → 非线性行动 | 所有【坍缩体】生命 +15%、移速 +15% → 生命、移速 +20%，攻速 +20 |
| 情绪实体 → 恐怖实体 | 敌人出场时 5% 概率生命 +100% → 10% |
| 泛社会悖论 → 泛文明悖论 | 诡意行商售价 +25% → +50%，稀有商品 +100% |
| 气压异常 → 气压失序 | 部署费用自然回复 −20% → −40% |
| 触发性损伤 → 触发性危殆 | 我方单位部署时损失 30% 生命 → 60% |
| 趋同性消耗 → 趋同性缺失 | 抗干扰指数降低时目标生命上限 −1 → −2 |
| 目空一些 → 睁眼瞎 | 目标生命和敌人生命不再可见 → 另加敌人生命 +10% |
| 图像损坏 → 一抹黑 | 战场上我方单位的形象不再可见 → 另加部署费用 +1 |

  - **密文板**：共 43 块（`totemBuffDatas`），分**布局**（艾塔布局，指定节点）和**本因**（法玛谋篇，给效果）两类，各分红 / 绿 / 蓝三色（PRTS 写作族群 / 自然 / 灵魂），另有全色 2 块、无色 2 块（结局二专用的【空无】【伤痕】）。单块没有效果；一块布局 + 一块本因组成一次**密文宣告**：改变指定节点或给经过 / 战斗时的增益，**坍缩值 −1**，两块都消耗。同色组合触发**柯瓦狄协语**（增强版，例如红色本因「我方在此处战斗时攻击速度 +50」的协语版再加「场上出现斗志昂扬无人机」，「最大生命 +50%」的协语版加「场上出现友方盾卫」）。挑战自然·3 起还有附加的**凯宁嘉修辞**（延续 / 自足 / 循环 / 广阔）。
  - **远见**：进入新一层时，独眼巨人按坍缩等级给远见：等级低于 3 时预告一块密文板，≥3 时预告下一个将触发或加深的坍缩范式，满 8 级不再给。
  - **宝箱**：作战地图上随机出现，**击破**后给额外源石锭：宝箱 2、尖刺宝箱 4（受击反伤）、**巨壳藤蔓** 10（拟态成宝箱，挨打会跑）。合计后按「**无主的财富**」跟通关奖励分开结算——名字和傀影的「无主的财富」一样，但规则不同（傀影是敌人抢宝箱，萨米是玩家打宝箱）。
- **难度**：「挑战自然」0–15，没有简单档（PRTS「扩展难度」）。

出处：PRTS 主题页「本主题下的独特机制」「开始探索」「区域」「事件节点」各节；`roguelike_topic_table.json`。

## 7. 改编：主题机制（两个方案）

前提：水月的四个槽位是 S1 计量（灯火）、S2 地形（溟痕）、S3 边界（黑潮）、S4 场上目标（灯标）（docs/359 §6）。萨米的 **S3 边界照搬缩圈规则，只换外观成「风雪」**（每层失败结局都叫「风雪蔽目」）。

### 方案 A：坍缩值 + 坍缩范式（推荐样例先做）

- **S1 坍缩值**（替代灯火的位置，反过来是「越涨越糟」）：
  - 涨：队长受击（按伤害占比，像灯火掉的公式，原作「目标生命受损 +1」）；进入下一个威胁阶段 +3（原作「每深入一层 +3」，水月 6 个阶段刚好对上层数）；事件代价「坍缩值 +N」原样搬。
  - 降：击杀坍缩体精英、安全的角落、事件 / 藏品（本作拟），以及方案 B 的宣告（原作 −1）。
  - 每 4 点升 1 级，**每级从池里抽一条坍缩范式挂上或加深，最多 4 条**（原作规则）；坍缩值降回去时随机弱化一条。HUD：顶部一条计量 + 黑烟环显示等级；等级高时加全屏扭曲波纹（原作效果，shader 低成本）。
- **S2 国度**（取自范式「实质性坍缩」和中期 Boss「邪魔的利刃」）：场上出现若干块【国度】地块，**站在里面的我方攻速 −50%**（原作数值；加深版 8 块 / −75%）。只降攻速、不叠负面状态，不违背「负面状态只留神经损伤」。玩法上跟溟痕一样，都是「别站在这里」的地形。
- **范式改编表**（本作拟，原作效果对照 §1）：

| 原作范式 | 本作 | 说明 |
|---|---|---|
| 实质性坍缩 | 4 / 8 块国度 | 主力，见上 |
| 非线性移动 | 坍缩体敌人生命、移速 +15% / +20% | 原样 |
| 情绪实体 | 刷出的普通怪 5% / 10% 生命 ×2 | 原样 |
| 泛社会悖论 | 商人售价 +25% / +50% | 原样 |
| 气压异常 | 全队技力回复 −20% / −40% | 部署费用改成技力（傀影同口径） |
| 触发性损伤 | 换人入队时新队员掉 30% / 60% 生命 | 部署改成入队 |
| 目空一些 | 敌人血条隐藏 / 再加敌人生命 +10% | 原样，Boss 血条不隐藏（本作拟） |
| 去量化 / 趋同性消耗 | 改到事件代价上：付坍缩值 / 源石锭时概率多付 | 原样（只在事件里生效） |
| 图像损坏 | **舍弃** | 队员不可见会直接让割草没法读图 |

- **优点**：①直接用原作机制和数值，事件里「坍缩值 +N」的代价原样能用，事件对位最省事；②S1 + S2 两个槽位都填上，刚好复用 docs/364 的挂钩（`on_player_hit` 涨值、`on_spawn_tick` 刷国度、`on_status_tick` 国度减攻速、`on_player_tick` 范式检查），等于是第二次验证 ThemeMechanic 接口；③机器人好写：躲国度 = 溟痕的同一套 `bot_land_bad`；④压力随时间上升的曲线跟水月的灯火变暗是同一个节奏，不改「什么时候难」（docs/359 §9）。
- **缺点**：①纯负面，没有灯火「满灯 +40% 伤害」那样的正反馈，要靠降坍缩的手段和范式之间的取舍兜住，否则手感是「越打越憋屈」；②「范式」需要一页说明和 HUD 图标，读图有新负担；③跟水月灯火里「受击 → 掉资源」的骨架很像，差异化主要靠范式和国度。
- **缓解**（本作拟）：坍缩等级 ≥4 时击杀坍缩体额外给经验（「坍缩越深越肥」）；远见改成「HUD 预告下一条范式」（原作：坍缩等级 ≥3 时预告），让玩家有机会主动压坍缩。

### 方案 B：密文板宣告（推荐放全量）

- 精英、宝箱、事件掉**布局**和**本因**两类密文板（原作分类）。路口翻卡（docs/359 §3.2，每局 5 次）时多一个「宣告」按钮：选 1 块布局 + 1 块本因。
  - **布局**指定生效对象，改成时间 / 事件对象（本作拟）：「下一场精英小队」「下一个路口的第 N 张卡」「下一场中期 Boss」「接下来 60 秒」。
  - **本因**给效果，原作条目大多能直接用：攻速 +50、最大生命 +50%、回复生命、源石锭 +8、卡变诡意行商 / 紧急作战 / 安全的角落、招募必出高星（改成三选一必出流派件）。
  - **同色 = 柯瓦狄协语**：原作协语里的「场上出现斗志昂扬无人机 / 友方盾卫」「一名精英干员临时加入编队」在割草里正好做成**临时友军**，对得上「小队代入感」这根支柱。
  - 每次宣告坍缩值 −1（原作），所以跟方案 A 是联动的。
- **优点**：①萨米最有辨识度的系统；②构筑多一层规划决策，协语的临时友军很合支柱；③可以复用路口卡的 UI（`choice_panel`）。
- **缺点**：①大部分发生在战斗外，割草的核心是战斗中，收益要验证；②43 块 × 普通 / 协语两份文案，加上四语、图标，工作量大；③原作「布局」的整个前提是节点地图，本作没有，改成时间对象后原作味会淡；④机器人要会选组合，批跑验证成本高。

### 次要（两个方案都可以带）

- **宝箱**（原作三种）：宝箱 / 尖刺宝箱 / 巨壳藤蔓（挨打会跑的拟态精英，原作 10 源石锭）。做成 S4 场上目标，几乎不用新规则；巨壳藤蔓还能顺便当「稀有敌人」槽位（水月的鸭爵位）。
- **抗干扰指数 → 路口卡可见度**（本作拟）：指数 0–6 决定路口 3 张卡里翻开几张，其余显示「凶戾的预感」（战斗类）/「诡秘的预感」（非战斗类，原作文案）。只改卡面，规则不变，成本低，萨米味很重。
- **边界「风雪」**：缩圈规则不动，外观换成白色风墙 + 雪粒。

**推荐**：样例做 **A（坍缩值 + 国度）+ 风雪边界 + 宝箱**；B 和抗干扰指数放全量阶段。

## 8. 改编：样例 Boss 候选

通用口径照旧：图案弹幕、不做符卡、不弹提示、Boss 专属色、基础 4 招覆盖 4 种预警样式、主轴给受伤窗口不锁血（docs/95 §0.2、142b §1、359 §2.3）。

**配色风险（三只都要注意）**：萨米的自然色是冰蓝，但**小怪青蓝 194°、倒计时青 175° 是保留色**，Boss 弹芯不能用冰蓝。另外雪地很亮，按 docs/359 的观感 L4（去白灰）地面要压暗，否则弹幕读不清。建议地面用原作「昧明冻土」那种黑苔原 + 深灰蓝雪（§9）。

### 8.1 「萨米的意志」（越过群山，推荐）

- **主轴「借银凇」**（取自关卡装置积雪银凇，本作拟）：场上长出 4–6 棵积雪银凇（可破坏的大型障碍，挡移动也挡 Boss 弹）。冰凌从列顶往下落，**被银凇挡住，银凇南侧那一段是安全的**；一棵银凇挡下 3 次冰凌就碎，碎时 Boss 受伤 ×1.6，持续 5 秒。也就是「躲到树后面」本身就是推进进度。机器人：冰凌预警出现时走到最近银凇的南侧。
- **专属色**：苔原虹光紫（色相约 285°，白芯，三档明暗）。取自「黑色的苔原析出星星点点的虹光」；离预警洋红 340° 有 55°，离小怪青蓝 91°。
- **招式**（目标 12 招，docs/359 推荐区间）：

| 幕 | 招 | 预警 | 做法 | 依据 |
|---|---|---|---|---|
| 一 | **冰凌** | ② 直线 | 以队长所在的 x 为一列，从上往下每 0.2 秒落一个冰凌 | 原作普攻原名、原节奏 |
| 一 | 冰凌连落 | ② | 三列依次落下，间隔 0.6 秒 | 本作拟 |
| 一 | 震地 | ① 落点圈 | 以自身为心的大圈 | 本作拟 |
| 一 | 雪崩 | ③ 扇形 | 朝队长的扇形碎冰 | 本作拟 |
| 二（≤66%） | **自然涌动** | ① + 机制 | 冻住一名**队友**（不冻队长）3 秒并持续掉血；队长冲刺穿过它解冻（复用圣徒的穿身判定） | 原作原名；晕眩改到队友身上 |
| 二 | 冰凌双列 | ② | 两列同时落 | 原作「生命 <50% 多选 1 列」 |
| 二 | 风雪环 | ④ 缺口环 | 雪粒缺口环 | 本作拟 |
| 二 | 冰屑散射 | 图案 | 银凇碎裂时向外射一圈冰屑（对称环） | 本作拟 |
| 三（≤33%） | 暴风雪 | 场边收拢 | 场边风雪往里收，留出几条安全缝 | 原作深寒造像「自然涌动变为暴风雪」 |
| 三 | 冰凌交叉 | ② | 横竖各一道 | 本作拟 |
| 三 | 群山回响 | ④ | 两层反向旋转的缺口环 | 本作拟 |
| 末段 | **叹息** | ④ | 最后 3% 的收尾：一圈全场缺口环，躲过就倒下 | 原作技能原名；不扣血、不自毁 |

- **舍弃**：生命 <50% 时受到伤害 −60%（等于锁血，违反 142b，跟傀影剧作家同理）；600 秒「叹息」扣 30 目标生命（§3.3）。
- **优点**：缺省结局，不要信物链，样例只需 1 个结局；原作招式本身就是可读的直线弹幕；「借银凇」跟现有主轴（截路 / 封锁线 / 打断 / 同步 / 打落 / 斗牛 / 破网 / 拦截）都不重复，是新的「掩体」读法；固定不动的巨型 Boss 跟水月四只都不一样。
- **缺点**：原作「自缚」不动，弹幕全靠场地补；银凇要做成新的场上实体（障碍 + 可破坏 + 挡弹），是新代码；巨型 Boss 帧条尺寸要按最终档的上限（≤320 宽）画。

### 8.2 「木裂」埃克提尔尼尔（直至冬夜降临）

- **主轴「熬过泯灭」**：原作「自我泯灭」触发在 70% / 40% / 10%，正好对上本作的三道卡点；每次 3 秒疾冲（不可阻挡、受到伤害 −80%），跟本作「阶段护盾 ≤3 秒」的规则一致。冲完有 2 秒破绽，受伤 ×1.5。寒冷改成脚下冰面减速区，不做成状态。
- **优点**：人形英雄，剧情分量最重（萨米人心中共同的英雄）；机制跟卡点系统一一对得上；Spine 直转美术最省事。
- **缺点**：原作要走密文板链（空无 + 伤痕 → 木裂前兆 → 树痕之盔）才能见到，当样例缺省结局就偏离原作；近身追击型跟水月「最后的骑士」（冲锋骑士）定位太像。

### 8.3 无垠回荡克雷松（自深处的一瞥）

- **主轴「稳定设施」**：本体无敌（原作），场上的空间稳定设施（金色主轴目标）启动后无敌失效 6 秒、受伤 ×1.5。闪现到下一个点时留下 2 块【苗圃】（攻速 −50%、持续掉血，原作数值），跟国度是同一套地形；首次打空后 5 秒重生、攻击力 +50%，正好是「1 段形态变化」。
- **优点**：原作自带主轴（设施），苗圃跟方案 A 的国度能复用同一套地形代码。
- **缺点**：要走路网 → 悲观者囚笼 → 无垠赠礼这条链，还要换第Ⅵ层地图「远见之构」；「本体无敌 + 去打目标」跟傀影喉舌、水月接潮组思路接近；造型抽象（「如思维般混沌的本能」），像素化难度最高。

不推荐双王（终始）做样例：两只 Boss 加专属地图「永恒之尘」，一个样例里放不下。

**推荐 8.1「萨米的意志」+ 结局「越过群山」。**

### 8.4 中期 Boss（样例要不要带由用户定）

傀影样例没带中期 Boss（3:30 / 7:00 换成精英小队，docs/360 §0）。萨米建议**带一只「邪魔的利刃」**：

### 11.2 每个主题单独一个 B站 Toy 的影响

- **好处**
  - 包体：Toy 上限 50 MB，水月单主题包已经 49.78 MB（docs/357 §5），两个主题本来就不可能放进同一个包——一主题一作品是唯一可行的路。
  - 选主题入口在 Toy 包里可以省掉：打包时固定主题（`export_web --theme=sami`），11.1 的第一个卡点在 Toy 上变成构建参数。
  - 萨米可以独立宣传、独立审核，不影响水月作品的评分和数据。
- **对萨米样例的影响**
  - 要先做 `export_web --theme` + `check_release` 校验「包里只有一个主题清单」（docs/357 §5 列的阶段 2 工作，约 3–4 会话日）。这只挡**发布**，不挡样例开发。
  - **包体预算**：萨米包 ≈ 共享部分（代码、干员、特效、音效、语音）+ 萨米独有部分。水月配乐约 20.7 MiB（memory `web-package-budget`），萨米配乐按 §10 的 7 个文件、同规格应该更小，有余量；但共享部分只要再涨，两个作品都会跟着涨，要按「共享部分 + 最大主题」守 50 MB。
  - **存档与局外成长**：网页存档按网站源隔离（docs/89 §1），两个 Toy 作品大概率是两个源，云存档是否按作品隔离**未查证**。docs/366 定的是认知塑造等局外成长「跨主题共享」——分成两个作品后这个共享很可能做不到，等于萨米从零开始。要用户定：接受各作品各自成长，还是要做跨作品同步（需要查 Toy SDK 能不能做）。
  - **发版成本翻倍**：每次发版要出两个 Toy 包、两次上传和审核；发版提速（memory `ship-speedup-todo`，45→20 分钟）的优先级会更高。排行榜、PV / 视频绑定也是各作品各一份。
  - itch / 桌面版不受 Toy 上限限制，可以一个包带两个主题，那里仍然需要正式的选主题界面（不急）。

### 13.2 改编方案

| 方案 | 做法（本作拟，标原作依据） | 手感 | 风险 | 机器人 |
|---|---|---|---|---|
| **P1 冲碎国度** | 队长冲刺穿过一块国度就把它打碎：坍缩值 −1（每阶段最多 −3），掉一把「坍缩结晶」经验（≈ 3 只杂兵）。跟中期 Boss 利刃的主轴「冲碎国度」是同一个动作 | 主动、清楚：看到国度就想冲过去，冲刺多了一层用途 | 冲刺本来是保命技，玩家可能为了碎国度把冲刺用空；坍缩会被压得太低，要靠每阶段上限兜住 | 冲刺可用、周围没有近身威胁时，沿一条能串起 ≥1 块国度的直线冲（复用利刃那套判定） |

### 13.3 两条提案（用户还在考虑，未定）

**① 坍缩越深越肥**：即 P4。原作依据是「乌萨斯断刃」（每级范式经验 +10%）和「演员的首饰盒」（坍缩涨了给源石锭）——**原作是放在藏品上的，不是基础规则**。两种做法：
- A. 只放藏品（贴原作）：坍缩基础上仍是惩罚，想吃收益要靠拿藏品构筑。
- B. 基础小量 + 藏品放大（本作拟）：每级 +4% 经验 / +2% 源石锭，藏品再叠。坍缩从一开始就有两面。

**② 密文板随时组合**：原作就是在节点地图上随时宣告（不在战斗里）。改编（本作拟）：
- 加一个按钮（键鼠一个键、手柄一个键、触屏 HUD 一个图标）：按下后暂停，弹出组合面板，选 1 块布局 + 1 块本因宣告；同色触发柯瓦狄协语；**宣告后坍缩值 −1**（原作）。
- 布局改成时机：「立刻 60 秒」「下一场精英」「下一个 Boss」「下一个路口」（替代原作的「指定节点」）。
- 好处：保留原作「随时宣告」的手感，跟 P1 / P4 一起，让坍缩值有一个**可规划**的降法；暂停面板跟升级三选一同类，不新增读图负担。
- 风险：暂停太频繁会打断割草节奏（建议 Boss 战中可用、但宣告后 1 秒无敌不给，免得当成暂停躲弹）；面板要做触屏版；机器人要一条宣告规则（例：持有可组合的一对就在下一个精英前宣告「下一场精英」类）。

### 13.4 推荐

（P1 已被 §13.6 用户定的「击杀坍缩体瓦解国度」取代）**P1 冲碎国度 + P5 原作藏品 + P4 只放藏品（①选 A）**，P3 深埋迷境放全量，P2 不做成基础规则（原作里它就是藏品「范式中和仪」，归 P5）。
- 理由：P1 给每块国度一个正面用途，而且跟利刃的主轴是同一个动作，玩家在 3:30 学会就能一直用；P5 的四件原作藏品直接把「国度克敌、坍缩越深越肥」做成构筑路线，最贴原作；基础规则不加「越深越肥」，坍缩值还是一个要压住的压力，避免高手故意养坍缩。

### 13.6 用户 11-19 定：击杀坍缩体瓦解国度

用户觉得「冲刺一碰就碎」太粗糙，原话：「击杀坍缩体来瓦解我觉得可以，雨中冒险也有类似的做法，但是坍缩体可以不止一只。」**取代 §13.4 推荐里的 P1。** 规则（数值本作拟，交数值会话）：

- **撑持体**：每块国度由若干只坍缩体撑着，随国度一起刷出、在国度周围 160 内游走。数量随坍缩等级和阶段增加：前 3 阶段且坍缩 ≤2 级时 2 只；第 4–5 阶段或 3–5 级时 3 只；第 6 阶段或 ≥6 级时 4 只（两项取大）。
- **可读的联系**：撑持体头上有标记（小冰晶菱形，不用主轴金，避免跟 Boss 主轴目标混），它和国度中心之间有一条地面墨纹 / 冰纹连线；撑持体死一只，对应连线就断一条。
- **瓦解**：撑持体全部打死后，国度从中心裂开碎掉：**坍缩值 −1**（每阶段最多 −3），掉一把经验（约 3 只杂兵）。
- **辅助进度（裂纹）**：在国度里或边缘 60 内每击杀一只敌人，裂纹往外长一截（+8%）；队长**冲刺穿过只砸出裂纹**（+15%，同一块 1.5 秒内只算一次），不会一碰就碎。裂纹长满 100% 时国度也会碎（剩下的撑持体失去标记，照常存活），奖励相同。
- **碎裂表现**：不规则分叉的裂网从中心长出、冰片崩飞、短暂爆亮后冷却、留下一圈碎冰；不要规则放射状、不要同心圈（memory `impact-fx-power`）。
- **机器人**：优先打带标记的撑持体（`bot_goal` 指向最近国度的最近撑持体，周围没有近身威胁时）；在国度里击杀也算进度，所以不必刻意躲出国度再打。
- 原作依据：原作没有「击杀坍缩体瓦解国度」，这是本作拟；坍缩体、国度、坍缩值 −1 的名字和量级取自原作（§1、§13.1）。

仍待定（用户还没回）：§13.5 第 1 条里「国度是否也压制敌人（P2）」、第 2 条「坍缩越深越肥放不放基础规则」、第 3 条「密文板随时组合放全量还是进样例」。
