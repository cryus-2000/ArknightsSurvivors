## 1. 集成战略总览（详见 49a §1–2）

数据里共 6 期（rogue_1–6）：傀影与猩红孤钻、**水月与深蓝之树**（本作母题）、探索者的银凇止境、萨卡兹的无终奇语、岁的界园志异、沉沦者的黑流树海（2026-07）。

**共通核心循环**：选分队 → 招募干员（花希望）→ 在节点地图上前进（作战 / 紧急作战 / 险路恶敌 / 不期而遇 / 诡意行商 / 安全屋……）→ 作战得源石锭、藏品 → 层末 Boss → 按持有的信物走向不同结局。每期在这个骨架上加一两个招牌系统：

| 主题 | 招牌系统 |
|---|---|
| 傀影 | 剧目（一次性临时增益，高难有「猩红剧目」） |
| **水月** | **灯火**、进层掷骰（启示 / 排异反应）、战斗骰子、护盾与钥匙 |
| 银凇 | 密文板（三色组合）、坍缩值（负面范式）、抗干扰指数（视野） |
| 萨卡兹 | 思绪（遗愿 / 灵感 / 构想）与负荷、年代、节点升级 |
| 界园 | 通宝（投钱与镀色）、烛火、岁时 |
| 黑流树海 | 网格地图与行动力、天气、零件（数据为主，待核） |

**共通系统**：源石锭（商店货币）、希望（招募费用）、目标生命值（漏怪扣）、藏品分类、招募券 / 进阶券（精英化）、事件、结局与隐藏结局、逐级叠加的难度分级。

## 2. 水月与深蓝之树要点（详见 49a §3）

- **层与 Boss**：3 层三选一（圣徒卡门 / 伊比利亚、接潮组、塑路者，紧急版为加强版）→ 5 层「偏执泡影」（结局一）或「最后的骑士」（结局二）→ 更深层「伊莎玛拉，腐化之心」（结局三）/「伊祖米克，生态泉源」（结局四）。
- **灯火**：100 通明 / 50–99 摇曳 / 1–49 暗淡 / 0 寂灭。原作灯火**按战斗结算**掉（漏怪、残血），每进一层掷骰：只有满灯火才可能得「启示」（7 国全队增益），不满就有「排异反应」风险，寂灭时必定排异。
- **排异反应**：干员身上的负面变异，有 4 个基础、「+」版（负面加补偿）、组合版和终点「进化」；有道具可以抑制。
- **结局**：一「平凡即是喜乐」、二「静谧时代」、三「息潮的代价」、四「如星空般深蓝」。结局二靠「狂徒妄念 → 海潮的气息 → 猎潮的骑士同行 → 骑士仍在」一条事件链。
- **难度**：「浪静风平」（有静音小队护航的简单档）+「波涛迭起」0–18 逐级叠条件。
- **局外**：深蓝之树（生态谱系、认知塑造）。

## 3. 本体战斗机制要点（详见 49b）

- **职业**：8 职业 71 分支。本作最常参照的是医疗 7 个分支（医师、群愈师、疗养师、咒愈师、链愈师、行医……）和辅助、护盾类。
- **技力**：自动回复、攻击回复、受击回复三种；技能分自动、手动、被动。
- **异常状态**：寒冷 → 冻结、晕眩、束缚、沉默、睡眠、浮空、停顿、麻痹、脆弱 / 法术脆弱、庇护、护盾 / 屏障、闪避、真实伤害、禁疗等，49b §2 列了定义、叠加规则、抵抗。「抵抗」的官方定义是晕眩、寒冷、冻结等持续时间减半。
- **元素损伤**：神经、侵蚀、灼燃、凋亡、狂躁。累积到阈值（干员 1000；敌人普通 / 精英 1000、领袖 2000）触发爆发，敌我两侧效果不同，见 49b §2.4。
- **敌人**：普通 / 精英 / 领袖三级；飞行、隐匿、潜地、自爆、屏障、复活、召唤、重量等机制关键词，海嗣 18 种见 49b §3.3。

## 5. 原作 → 本作：已有 / 可借鉴 / 我们的特色（汇总）

各子文件末尾有完整对照表：49a §5 共 14 行，49b §4 共三张表，49c §8 按 Boss 列。这里挑出最重要的。

### 5.1 本作已经做出的特色（保持）

- **灯火是实时的**：受击就掉，灯光照到的敌人受伤 +25%。原作灯火按关卡结算，本作让玩家在战斗中直接看到后果。
- **排异改的是技能行为**：技能海嗣化后有得有失，不只削数值，适合动作游戏。
- **只有主控受击**：治疗全部集中在一个人身上，队友不受击；Boss 在场时主控「永不硬控」，控制改成减速。
- **结局由局内祭坛事件决定**：固定时间窗口，玩家可以规划；骑士是同伴，活到终局才反目。
- **照亮 / 灯光显形**：可以作为隐匿敌人、控制流派的本作独有解法。

### 5.2 最值得借鉴的（按成本从低到高，供各会话排期）

### 5.3 留给本作自己发挥的空间

- 10 分钟、实时、大群：原作的「按关卡结算」系统（灯火、启示、希望）都可以改成**实时、可看见后果**的版本，这是本作和原作拉开差距的主要方向。
- 大群里的元素爆发可以连锁（原作没有）；照亮与灯火把「光」做成贯穿战斗、资源、叙事的一根线。
- 局外成长刻意不做纯数值（「永久攻击 +100%」），更接近原作深蓝之树「解锁新事件、新规则」的思路。

## 8. 类幸存者游戏的 Boss 设计（详见 49d，2026-09-29 追加）

在「自动攻击、只管走位」的框架里，Boss 逼玩家换操作的手段只有几种：**必须冲刺的大招、限时目标（部件 / 茧 / 另一具身体）、区域封锁、锁定方向的冲撞、拖久了越来越难**。各家好的做法都是：预警样式少而统一、大招配固定声音、奖励即时。

| 做法 | 出处 | 结论 | 原因 |
|---|---|---|---|
| 「血量到卡点或本幕满 N 秒，先到先换幕」 | Brotato | 值得借鉴 | 不加血，让慢构筑也打到后半段招式，符合用户「拖久了越来越难」的方向；做成默认关闭的参数 |
| 部件 / 茧可以靠击杀周围小怪间接削 | DRG: Survivor | 值得借鉴 | 给清怪强、单体弱的构筑第二条路（塑路者核心、泡影茧） |
| 冲撞在起手时锁定方向，并把锁定时刻画出来 | 20MTD（反例：看不出何时锁定） | 值得借鉴 | 伊比利亚三连线、卡门剑冲刺、骑士冲锋在锁定瞬间从虚线变实线 |
| 一招一个视觉语言；大招喊招 / 固定音效 | HoloCure、Death Must Die | 值得借鉴 | 预警收成五种样式；「必须冲刺 / 破绽开始 / 限时目标」三类配固定音 |
| 击杀快慢分档，战斗中看得到档位倒计时 | DRG: Survivor | 借鉴一半 | 只借「看得见档位」，不借「慢了没宝箱」（docs/38 §1.16） |
| 支线道具削弱 Boss | Halls of Torment | 借鉴思路 | 做成事件或高灯火的「战前准备」，不能变成必选 |
| 领主出场清场单挑、封场围栏 | Halls of Torment、Death Must Die | 不适合 | 本作中期 Boss 照常刷怪、不封场（用户 9/27、docs/38 §1.7） |
| 死神式时间墙秒杀、Boss 血量随玩家等级涨 | Vampire Survivors | 不适合 | 违反主控保护；等级缩放会罚升级快的人 |
| 按击杀数召唤 Boss | Soulstone | 不适合 | 本作结局和事件按时间表走 |
| Boss 奖励给整件新道具 | 20MTD、VS | 不适合 | docs/38 R30：Boss 奖励不再加藏品候选 |

**对本作 Boss 的加强建议**（49d §11 逐只列了 2–3 条，都是建议，不改 docs/38 §8 已定机制）：

| Boss | 最值得做的一条 |
|---|---|
| 塑路者 | 猎核也能靠击杀核心周围的小怪间接削；限时目标统一用青色倒计时环 |
| 圣徒伊比利亚 | 三连瞄准线逐条锁定、锁定时变实线；装填读条配升调音效 |
| 圣徒卡门 | 枪 → 剑换形态用轻量信号，不用换幕信号，免得误读成进了下一幕 |
| 接潮组 | 一具假死时，从主控脚下画箭头指向另一具；连接线亮度和倒计时同步 |
| 偏执泡影 | 茧也能靠清怪削；凝视光束按 1 / 2 / 3 标序号 |
| 伊莎玛拉 | 泪给本体充能的进度条看得见（只加显示） |
| 伊祖米克 | 全场地波配倒数音，灯柱光圈同步呼吸；拦截子代掉 1 点灯火 |
| 最后的骑士 | 冲锋长度先长后短；锁定时同时亮「破」字端盖 |

**通用**：7:00 两只中期 Boss 共存时只共用一个招式令牌，避免两个大预警同时出（Death Must Die 的玩家反馈）。
