# 305 · 性能与帧率夜检（11-07 夜，帧率会话，分支 claude/perf-night-1107）

> 协调人转用户：「把性能和帧率继续检查一下」。对照 docs/287（11-06 夜基线）。今天合进来的东西（Codex 内存释放、打击感推全员、安洁莉娜黑洞透镜、后期减负 A 版、红雾、艾丽妮星光、歌蕾蒂娅小水爆……）有没有让帧时 / 内存变差；网页 / 手机找 iPhone「顶不住」的原因，找到就修。

## 0. 三行结论

1. **桌面帧时没变差**：今天的 main 对 11-06 优化后的 main（9391d662f），同场景两轮交替（安静时段），3 人局 8:00–11:00 与 late 场景都在噪声内；后期减负 A 版同局轮换开 / 关差 ±0.5 ms。
2. **找到并修了一个真问题**：暂停 / 三选一 / 属性面板开着时主控脚下扬尘每秒照出 10 颗、只增不减——面板挂多久堆多久（网页实测 15 分钟 7600 个特效、帧时 25 → 90 ms）。另修 10:00 最终 Boss 换曲时两首配乐同驻的内存尖峰（护栏读数 452 → 527 MB，超 520 线）。
3. **手机网页内存峰值约 450 MB**（3 人局，显存 330 + 音频 123），与 docs/287 修后 440 同量级；显存 10 分钟内从 170 缓涨到 330（新帧条 / 敌人种类），没有看到持续泄漏。网页帧时 8:00–10:00 约 45–52 ms，离 30 帧目标仍远，大头仍是世界绘制（排序实体、贴地层）。

### 1.1 网页测量脚本坏了（已修，f56e9f50f 等）

11-06 起网页测量一直跑不起来（游戏一行不输出、停在启动页「开始游戏」）。三处原因：
1. 网页上 `get_cmdline_user_args` 只认 `--` 之后的参数——测量脚本现在自动在游戏参数前补 `--`；
2. 11-06 起发行包排除 autotest / bot（be9da95f8、f7b624eea）——测量副本里把 autotest 守卫去掉、导出预设里放回这几个脚本；
3. autotest 预载 `ak_mock.gd`，缺了它 autotest 整个解析失败，机器人在三选一面板前不动（这正是下面 §3.1 那个问题被暴露出来的场景）——一并放回。

## 3. 修了的问题

### 3.1 暂停 / 选卡时特效只增不减（52f7e9563）

- 现象：网页那局机器人卡在三选一面板（§1.1 第 3 条），浮层日志显示局内时间停在 0:19、特效数每 10 秒 +92，15 分钟到 7677 个，帧时 P50 25 → 90 ms。
- 桌面复现（`--powerseq`：暂停 20 秒、选卡 20 秒）：暂停 / 选卡期间 `spark` 每秒 +9.3，全是 `world.feet_dust` 的灰蓝扬尘。
- 原因：`update_player_feel` 按真实时间走（为了受击低通等表现在暂停时也衰减），面板打开时 `g.moving` 停在 true，跑步扬尘每 0.2 秒照出 2 颗；特效寿命只在模拟里扣，暂停时不扣。**真人玩家开着暂停菜单 / 选卡 / 属性面板时同样会堆**（选卡一般十几秒，堆一两百个；挂着暂停去做别的事，就是几千个，手机上发烫掉帧）。老问题，不是今天合进来的。
- 修：扬尘只在 `S.PLAY` 出。修后暂停 / 选卡各 20 秒特效稳定 2–4 个。
- 校验：扬尘用全局 `randf`，不碰玩法随机数；TRACE seed 11（61 行）/ 23（26 行）修前修后逐行一致。

### 3.2 最终 Boss 换曲两首配乐同驻（07e0f0aa9）

- 网页 3 人局 10:00：护栏读数 t=600 是 452 MB（显存 329 + 音频 123），t=601 跳到 **527 MB**（超 520 线 → 清缓存），t=630 回到 401。差的 75 MB 正好是最终 Boss 曲（406 秒、24 kHz 双声道）注册进来、而 battle3 还没放。
- 原因：Boss 曲在 boss_in 后 0.75 秒进，旧曲 1.5 / 秒淡出约 0.67 秒到 0，但释放要再等 `FREE_AFTER` 3 秒。
- 修：手机网页、换进 boss / final 时旧曲淡完即释放（`web/mobile_music_swap`，缺省 1，0 = 旧写法）。只改资源释放时机，声音不变。
- 验收：同场景（night3 540–640 秒）修后一局：t=600 309 + 123 = 432 MB，换曲后 t=630 315 + 84 = 399 MB，**护栏不再触发**（修前同场景 10:01 触发清缓存）。只跑了一局（换曲时刻护栏采样有间隔，单局可能漏看），帧时 8:00–10:00 52.2 ms，同修前。
