# 11 · 藏品图标设计规范与接入约定

> 2026-09-24。给美术方（GPT / Codex）。藏品全部来自原作「水月与深蓝之树」的 262 件收藏品（`docs/08`、`docs/reference/mizuki_collectibles_adaptation.json`），图标按**名称与含义原创绘制**。
> 交付方式不变：PNG 放 `art/incoming/`，附 manifest 和联系表，提交后告知提交号。

## 1. 图标出现在哪里

| 位置 | 显示尺寸 | 倍率 | 说明 |
|---|---|---|---|
| HUD 右上藏品栏 | 32×32 | ×1 | 一排最多 9 个，最常看到，**轮廓必须一眼能认** |
| 升级 / 藏品三选一卡片 | 64×64 | ×2 | 卡片中央，下方是名称和效果 |
| 商店卡片 | 64×64 | ×2 | 同上（开发方会把现在的 40 改成 64） |
| 图鉴详情 | 96×96 | ×3 | 大图展示 |
| 属性面板 / 提示框 | 32×32 | ×1 | — |

全部用整数倍最近邻放大，所以**只画一张 32×32**。

## 2. 画布与画法

| 项目 | 要求 |
|---|---|
| 画布 | **32×32**，透明背景 |
| 主体范围 | 居中，控制在 **28×28** 以内（四周留 2px，给程序画的稀有度边框） |
| 描边 | 1px 外轮廓 **#080E18**，与角色、敌人一致 |
| 透明度 | 只允许 0 / 255 两种 alpha，不要半透明、不要抗锯齿 |
| 颜色 | 每个图标 ≤ 16 色；整体用深海调色（下表），每个图标可有 1–2 个自己的点缀色 |
| 光照 | 统一左上方来光；暗部偏蓝紫，不要纯黑 |
| 构图 | 一个物件为主，45° 斜放或正面；不要场景、不要文字、不要数字 |
| 背景与边框 | **不要画**。底板、稀有度边框、发光都由程序按稀有度绘制 |
| 风格 | 与游戏现有像素美术一致（参考 `art/incoming/` 里的敌人、掉落物、援护） |

**深海基础色**（可自由取用，不强制只用这些）：

| 用途 | 颜色 |
|---|---|
| 轮廓 | #080E18 |
| 深暗部 | #16233A |
| 中间调冷色 | #2E4C6E、#3F7A94 |
| 冰蓝高光 | #9FE3F0、#E6FAFF |
| 灯火暖色 | #FFC46B、#FF8A3D |
| 海嗣紫 | #8A5CD6、#C9A6FF |
| 金属 | #7F8A99、#C7CFD9 |
| 血 / 腐化 | #B3263E、#E0506A |

## 3. 原创性（必须遵守）

- 按藏品的**名字和含义**设计物件造型。`docs/reference/icons/` 里的原作图标**可以作为参考**（2026-09-25 放开），用来确认这件藏品的物件、构图和配色；成品按本文的 32×32 像素规格制作。
- 不画任何官方角色的脸或形象；「国王」「教母」「主教」等人物相关藏品只画物件（枪、冠、信物、手稿）。
- 书籍类藏品（《……》）画成书、卷轴或手稿，封面不写字，用图案区分。

## 4. 稀有度（程序画边框，美术只需让画面气质匹配）

| 稀有度 | 边框颜色 | 画面气质 |
|---|---|---|
| 基础 | 灰蓝 #8FA6B8 | 朴素、日常、旧物 |
| 稀有 | 青 #53EBE0 | 精致一些，有少量高光 |
| 核心 | 金 #FFC46B | 有明显的发光点或特殊材质 |
| 升华 | 紫白 #C9A6FF，带呼吸光 | 最华丽，可有光晕内的小符号 |
| 遭诅古物 | 深红 #E0506A | 裂纹、腐化、海嗣侵蚀，颜色发灰发紫 |
| 结局 | 白 #E8F6FF | 神秘、深蓝、极简 |

## 5. 命名与交付

- 文件名：**`relic_<编号>.png`**，编号就是藏品表里的原作编号，不补零。例：`relic_54.png`（皇帝的恩宠）、`relic_118.png`（药枚）。
- 每批附 `relic_icons_manifest.json`：

```json
[{"file": "relic_54.png", "id": 54, "name": "皇帝的恩宠", "size": [32, 32], "colors": 12, "sha256": "..."}]
```

- 另附一张联系表 `relic_icons_preview.png`：所有图标 ×2 排列，每个下面写编号，方便检查。
- 交付前自检：尺寸正好 32×32；alpha 只有 0/255；四周 2px 内无像素；缩到 ×1 仍能分辨。
