## 2. 三个独立维度

1. **实际机制**：上表唯一主类与逐件子类；混合效果不被主类隐藏。
2. **反馈渠道**：数值、节奏、空间、实体、触发结果、流程。这里判断机制通过什么渠道被感知，不声称玩家已能清楚辨认；没有做逐件运行录像。
3. **获取与适用**：最终稀有度、单件等级、source、商店许可、前置、职业要求及当前编队；这些决定改造能否在前中期被拿到和用到。

现有数据的 17 个 effect_category 保留在 JSON 底表，不直接改图鉴分类或抽取逻辑；本次只提出语义更清楚的审阅分组。
