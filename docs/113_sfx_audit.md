# 113 干员音效盘点与调整（10-21）

用户实测反馈：「枪击音效、锁链音效等各种音效都需要优化」。本篇把 18 名干员普攻 / 命中 / 重击 / 三个技能实际播放的文件列成表，标出问题，记录这次已直接调的旋钮，以及要替换的音色方案和候选文件。音色约定见 docs/28，打击感层级见 docs/53。

## 1. 测法

- **文件与音量**：`Sfx.op()` 在 `--sfxstat` 下记下每个请求名（`op_<干员>_<类别>`）实际落到哪个文件、最终播放音量、音高倍率和音高随机（`sfx.sfx_op`，autotest 每 30 秒打印 `SFXOP`）。借用（OP_ALT）和缺文件退回（OP_FALLBACK）都按实际文件记。
- **触发频率**：每名干员单人上场（`--balance --seed=1 --op=<id> --prog=12 --maxt=300 --nodeath --norecruit`，无头、`--audio-driver Dummy`），5 分钟局内时间的请求数 ÷ 300；30 秒峰值取最密的一个 30 秒窗口。`--prog=12` 把成长节点推满，三个技能都已解锁，但机器人每局只走一条技能路线，有的技能「本局未触发」，只列文件。
- **文件响度**：`audio/sfx/*.wav` 的峰值、最响 100 ms 的 RMS（dBFS）、时长、频谱重心、4 kHz 以上与 250 Hz 以下的能量占比。
- **有效响度** = 文件 100 ms RMS + 播放音量（不含音高与总线）；**混音权重** = 有效响度 + 10·log10(每秒次数)，同一份时间里这个动作给混音贡献多少能量，用来比「谁最吵」。普通干员普攻在 −24 到 −30 之间。
