# 19 · 四结局总体方案（设计稿，未实现）

> 2026-09-24。整合 docs/18（结局二·最后的骑士，另一会话稿）并补齐其余三个结局。承载方式统一用 docs/18 提出的**事件箱**（特殊补给箱 → 2–3 选项卡片面板），不用商人，避免"碰到商人时灯火不够"的问题。
> 与原作 Boss 的对应关系是按现有素材排的（伊祖米克、伊莎玛拉的 Boss 机制早已实现，最后的骑士 V9 美术已齐），**顺序请按原作核对后再定名**。

## 0. 总原则

1. **结局 = 一个有代价的决定 + 一个改变后半程的规则**，不是随机掉落。每个结局的触发物都在固定时间窗口必定能遇到，玩家可以规划。
2. 四个结局互斥；**后做的决定覆盖先做的**（原作同）。Tab 面板和右上角常驻显示"当前结局"，9:00 横幅预告最终 Boss。
3. 代价只用**灯火 / 数值 / 规则**表达，不用持续掉血：本作没有关卡间恢复，掉血型代价会直接暴毙。灯火扣除一律**最低降到 10**，不清零。
4. 解锁顺序照原作：结局二～四的触发事件只在**通关过结局一**后出现；存档记录已达成结局，图鉴显示四格。
5. 数据驱动：`waves.json.endings` 写触发条件（藏品 ID / 计数）与 Boss；`relic_effects.json` 里用 `on_gain: set_ending` 一类动作；代码不认结局名。

## 3. 结局二「最后的骑士」

完全按 docs/18：狂徒妄念 → 海潮的气息 (222) → 骑士作为同伴 → 骑士仍在 → 骑士骨血 (225) → 10:00 骑士走入黑潮中心重生为 Boss；骑士道中阵亡 → 退行的罗辛南特 (223)，结局回退默认。

补两条与其他结局的衔接：
- 骑士在场时若又选了深蓝之心，**骑士立刻离队**（横幅"骑士无法接受海嗣的气息"），得到 223，结局改为深蓝。用这个替代"后覆盖先"的生硬切换。
- 抉择事件对骑士结局无影响，两条线可并存到 10:00，最终以骑士为准（骑士存活）。

## 4. 结局三「抉择」（决心 / 观望 / 犹疑）

原作：三个"选择"类收藏品各来自一次事件，组合决定走向。本作三次事件箱各弹一次免费三选一，三件都是真藏品：

| 选项 | 藏品 | 即时效果 | 长期代价 |
|---|---|---|---|
| 决心 | 238 | 最大生命 +30%，物理减伤 +2 | 之后每次精英来袭多 1 只 |
| 观望 | 239 | 藏品三选一变四选一（本次事件后持续到局末） | 无 |
| 犹疑 | 240 | 藏品出现权重 +30%（稀有 / 核心更常见） | 拾取范围 −20% |

**触发规则**：三次抉择中**至少两次「决心」** → 结局三。观望 / 犹疑不推动结局，只是给玩家"这一次我不想赌"的退路，同时保证三次事件箱都有价值。

**后半程变化**（决心 ≥ 2 时）：8:40 起海嗣的弱点标记全部取消（"它们学会了"），换来黑潮不再收缩最后一轮。这是这条线的核心张力：你选择了硬碰硬。

**最终 Boss**：伊莎玛拉·腐化之心（泪 + 转化两阶段，已实现）。

## 5. 结局四「深蓝」（深蓝之心 / 深蓝回忆）

**获得**：6:00–6:40 事件箱「深蓝的低语」：**倾听**（得 221 深蓝之心）/ **离开**（普通藏品三选一）。

**深蓝之心 (221) 的代价**：灯火 −50（**最低降到 10**），并触发一次**排异反应**。

**排异反应（最小版）**：从已获得的技能进阶里随机选一个，替换成"海嗣化"版本——是改变，不是纯削弱，也不掉血：

| 原进阶 | 海嗣化版本 |
|---|---|
| S1 创伤扩散 | 冲击范围 +50%、伤害 +30%，但唤醒所需挥伞次数 +2 |
| S1 深层唤醒 | 触手 4 → 6 条，但唤醒不再强化本体那一击（只强化触手） |
| S2 双重困境 | 反向斩变成全方向触手环，但囚徒困境持续 −3 秒 |
| S2 无解困境 | 束缚改为侵蚀（受控敌人每秒受法术伤害），但束缚不再传播 |
| S3 镜像 | 镜像变成独立行动的海嗣分身（会吸引仇恨、自己挑目标），但最大生命 −20 |
| S3 深海 | 幻境半径 ×1.5，但幻境内水月也减速 15% |
| 没有任何进阶可换 | 兜底：触手追击目标 +2，但灯火照亮加成（光中敌人 +25%）对触手无效 |

海嗣化的进阶卡片变成紫色并标"排异"，Tab 面板能看到换成了什么。

**后半程变化**：直刷进化体比例翻倍；灯火上限降为 70（可选，看试玩）；商店多一栏遭诅古物。

**深蓝回忆 (242)**：8:50–9:10 事件箱，只在已持有深蓝之心时出现：**再次倾听**（灯火再 −50 最低 10，第二次排异，最终 Boss 受到伤害 +40%）/ **离开**。这是这条线的"骨血"对应物。

**最终 Boss**：伊祖米克·生态泉源（学习 → 解读两阶段，已实现）。

### 测试开关

- `--allend`：无视通关进度，所有事件箱都出。
- `--eventtest=<id>`：开局 30 帧在身边刷该事件箱。
- `--grant=221,222`：开局直接给藏品（测排异 / 骑士）。
- `--evpick=1` 或 `--evpick=madness:0,knight_stay:0,default:1`：平衡机器人在事件面板的选项。
- `--bosstest=knight_boss`。
- 平衡跑（`--balance --nodeath`）四条线均能到最终 Boss；骑士线、抉择线已跑到胜利。
