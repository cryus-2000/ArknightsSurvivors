基线：integ-1029 + ult-proto（ult/on=1、combo/skill_link=1）。机器人 expert，`--preset starts`（7 开局 × 4 种子），云端每组 168 局、3 份独立实现（`--placebos 0/1/2`）。
目标：无局外成长 30–40%、18 细胞（`--meta=18`）50–60%；只动不给奖励的旋钮；不动用户定的早期伤害与最终 Boss 血量。

## 结论

- 无成长局的 0–4 分钟死亡占四分之一，伤害来源约七成是深溟引痕者的接触与前刺；艾雅法拉 / 铃兰 / 凯尔希三个开局最脆。
- tracer ×0.7 把无成长拉到 43.5%，线性插值取 0.85 对应约 35%；18 细胞基本不受影响（51%）。
- 中期 Boss 血量对胜率没有可见影响，击杀用时（机器人）本来只有 44–52 秒，维持 `hp_mid` 1.3。
- 最终缺省的确认批跑见下表。

## 10-31 新目标校准（无成长 45–55 / 18 细胞 65–75）：未全部达标，留给用户定

基线代码：`claude/diff-1031`（护盾削弱 `shield/block_invuln` 0 + 回层 15 秒 + `mid_cut` 0.22 + Boss 弹判定 `4939ab62d` + 终结技上调 `9904aa2ed` + integ 曲线夹单调 `87e1a87c7`）。机器人 expert，`--preset starts`，云端每组 168 局、3 份独立实现。

| 点（`dmg_curve/scale` / `enemy/dmg_x_tracer`） | 无成长 | 18 细胞 |
|---|---|---|
| fa 1.0 / 0.85（不放松） | 50.6% | 61.3% |
| fb 0.85 / 0.75 | 61.3% | 70.2% |
| fc 0.7 / 0.65 | 67.9% | 77.4% |
| **缺省 0.94 / 0.81（caedfd7bc，两个种子段 61/65 + 73/77 合计 336 局）** | **49.7%**（48.8 / 50.6） | **58.9%**（61.3 / 56.5） |

缺省点的死亡分布（0–4 / 4–7 / 7–10 / 终局）：无成长 15 / 72 / 24 / 58；18 细胞 11 / 58 / 19 / 50。打到最终 Boss 后的胜率：无成长 74%（167/225），18 细胞 80%（198/248）；偏执 77% / 79%，骑士 67% / 88%。

**结论**：
- 无成长 49.7% 在 45–55 内；18 细胞 58.9% 低于 65（判定线 63），差 4~6 点，不通过。
- 两档之间的差只有 9–11 点（fa 10.7、fb 8.9、fc 9.5），而目标窗口要求至少差 10，所以只能贴边；放松伤害对两档几乎同幅（约 +10 点 / 档），拉不开差距。
- 原因：终局战死亡（约 50~58 局，与档位无关）和 4–7 分钟的死亡共同卡住——无成长的 4–7 分钟死亡本来就多，放松伤害主要救这一段，两档都受益。
- 若把 18 细胞推进 65（取 fb 附近），无成长会到 ~61，超窗口 6 点。
- 可选方向（待用户定）：① 放宽窗口（例如无成长 45–60、18 细胞 60–75，或重新定义两档差）；② 按档单独加差异化旋钮，如认知成长对最终 Boss 的加成，或最终 Boss 对无成长档的额外强度（只动一档，不给奖励类以外的值）。
- 缺省暂放 0.94 / 0.81（提交 `caedfd7bc`），两档都比放松前高；若采用方向 ① 放宽窗口则缺省不必再动。
