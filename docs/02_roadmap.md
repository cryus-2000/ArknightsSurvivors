# 02 · 开发路线

| 阶段 | 内容 | 完成标准 |
|---|---|---|
| 0. 策划 | 定下 01_brainstorm 里的待定项 | 核心循环、结构、美术方案都已确定 |
| 1. 灰盒原型 | 色块角色；移动、自动攻击、刷怪、经验、三选一升级、死亡重开 | 能玩 5 分钟，同屏 300 个敌人不卡 |
| 2. 水月机制 | 灯火、藏品、招募僚机、敌人进化 | 手感和构筑能体现出"水月味" |
| 3. 肉鸽层 | 节点地图、商店、不期而遇、Boss | 完整打通一局 |
| 4. 美术替换 | 像素素材接入、动画、特效、音效 | 看起来像一个游戏 |
| 5. 打磨 | 平衡、局外成长、存档、设置 | 可以发给朋友试玩 |

## 你需要准备的
- 在电脑上安装 Godot 4（官网 godotengine.org，下载 Standard 版解压即可）
- 每个阶段结束后试玩并给反馈
