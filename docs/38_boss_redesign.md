# 38 · Boss 重做调研与方案（2026-09-26，草案，待用户确认）

> 用户反馈：现在的 Boss 存在感太弱，露头就被秒。本文件是三路调研的汇总：
> ① 代码现状审计（数据、公式、招式、机器人实测击杀用时、现有美术）；
> ② 原作「水月与深蓝之树」这 10 个 Boss 的机制（PRTS / arknights.wiki.gg）；
> ③ 同类幸存者游戏怎样让 Boss 立得住（Vampire Survivors、Brotato、Halls of Torment、HoloCure、DRG: Survivor、Hades 等）。
> 结论先行：**问题不在单个 Boss，而在整套 Boss 框架没有"最短战斗时长"的保护**。先补通用框架，再逐个补招式。

---

## 0. 为什么露头就被秒

机器人实测（`build/balance/` 下 204 局，全部难度 0；中期 Boss 按出场到击杀计时，最终 Boss 按胜利时刻 − 600 秒）：

| Boss | 出场 | 实测击杀用时（中位 / 最短） | 实际血量（难度 0） |
|---|---|---|---|
| 塑路者 | 3:30 | 高手 23s | 4320 |
| 伊比利亚 | 3:30 / 7:00 | 高手 86s（装填打断机制拖长了） | 4320 / 5440 |
| 卡门 | 7:00 | 高手 42s | 4760 |
| 接潮双体 | 7:00 | 高手 34–49s | 合计约 5300–6100 |
| **最后的骑士**（最终） | 10:00 | **中位 9s，最短 2s** | 10400 + 二阶段回 50% |
| **偏执泡影**（最终） | 10:00 | 中位 25s，最短 3s | 14800 |
| **伊莎玛拉**（最终） | 10:00 | 中位 25s，最短 4s | 18000 |
| 伊祖米克（最终） | 10:00 | 中位 41s（含无敌学习阶段） | 10400（35% 血量出场） |

报告里还有：高手维什戴尔打中期 Boss 平均 **11 秒**。

原因（按影响排序）：
1. **血量涨得太慢**：Boss 血量 = 基础 × (1 + t/600)，10 分钟才 ×2；同期普通怪 ×5，玩家输出成长更快。最终 Boss 血量只是中期 Boss 的 2–3 倍。
2. **没有任何"最短时长"保护**：没有伤害上限、没有护甲、没有阶段卡点，只有骑士复活那 1.5 秒无敌。
3. **增伤乘区叠满**：弱点 +50% × 灯光内 +25% × 终局藏品 +80% / +40%，可以一起乘。
4. **招式太少、太好读**：伊莎玛拉没有任何带预警的招式，伊祖米克只有一个冲击波；大多数 Boss 靠普通射击。
5. **没有"Boss 战"的场面**：从屏幕边缘刷出，小怪照常刷，没有封场、没有登场演出，除骑士外都没有攻击帧。

## 1. 通用框架（所有 Boss 共用，先做这一块）

同类游戏的经验：**存在感 = 仪式感 + 一段不能被跳过的时间 + 2–4 个看得懂的招式 + 死亡奖励**。只堆血会变成"海绵"（Halls of Torment 的教训），强力构筑照样秒。

### 1.1 目标战斗时长

| 类型 | 目标时长 | 最短不低于 | 说明 |
|---|---|---|---|
| 中期 Boss（3:30 / 7:00） | 25–40s | 12s | 强力构筑可以比基准快 30–50%，但不能 2 秒结束 |
| 最终 Boss（10:00） | 60–90s | 40s | 三阶段，每阶段 20–30 秒 |

### 1.2 血量：跟上玩家输出

- 时间曲线改为和普通怪同斜率：**基础 × (1 + t/150)**（3:30 ×2.4、7:00 ×3.8、10:00 ×5），`balance.json enemy.boss_hp_time_div` 600 → 150。
- 基础血量按"目标时长 × 该时刻期望全队 DPS"反推，用机器人数据校准（高手终局有效 DPS 约 1.7k/s → 最终 Boss 目标约 1.7k × 75s ≈ 13 万量级需要框架配合，见 1.3–1.4，不靠单纯堆血）。
- 数值由 balance 会话按 docs/27 流程落地，这里只定目标。

### 1.3 阶段卡点（防秒杀的核心）

- 中期 Boss 在 **50%** 处、最终 Boss 在 **66% / 33%** 处设卡点：一次伤害最多把血打到卡点为止，然后 **1.2 秒无敌转阶段**。
- 转阶段演出：本体闪白 → 一圈冲击环扩散 → 横幅出现阶段名，同时换一套或加强招式。
- 这是同类游戏里最有效、玩家最不容易察觉的"最短时长"手段。

### 1.4 软伤害上限

- 每只 Boss 有每秒伤害上限 = 最大血量 ÷ 最短时长（如中期 Boss ÷12、最终 Boss ÷40）。超出部分打 **×0.25** 折扣，不是归零。
- 伤害数字照常显示，超出上限的数字颜色变灰，玩家看得懂"打到上限了"。
- 附带收紧增伤乘区：弱点、灯光、终局藏品对 Boss 的合计增伤封顶 **×2.0**。

### 1.5 韧性条（统一控制处理）

现在控制对 Boss 的处理很散：击退、浮空、封印、推进之王眩晕对 Boss 直接跳过，乌尔比安眩晕 ×0.5 / ×0.27，水月 S3 眩晕却全额生效。统一成：

- Boss **免疫击退和浮空**，减速上限 35%。
- 眩晕、冻结、束缚、浮空不直接生效，改为积累 **韧性条**（血条下方一条黄条）。条满 → **破韧**：Boss 倒地 3 秒、承受 +30% 伤害，之后韧性条清空，重新积累需要的量 ×1.5。
- 好处：控制型干员（推进之王、艾丽妮、乌尔比安、塞雷娅）对 Boss 也有明确作用和爽点，而不是"对 Boss 无效"。
- 伊比利亚 / 卡门"装填被打断 → 长晕"并入这套：装填时韧性条需求减半。

### 1.6 Boss 战场面

- Boss 登场期间普通刷怪降到 **40%**，并换成该 Boss 的随从（分形、子嗣、潮汐小怪等）。
- **最终 Boss** 登场时，在博士周围 r520 画一圈发光符文环：离开环 → 减速 30% + 灯火流失加快（不是实墙）。中期 Boss 不封场。
- Boss 从距博士约 400 处的地面浮出（登场前 1.5 秒地面出现扩大的阴影），不再从屏幕边缘刷进来。

### 1.7 演出（全部不震屏）

- **登场**：画面四角压暗 → 地面阴影 → Boss 浮出 → 名片（名字 + 称号 + 原作一句台词，1.8 秒，可按键跳过）→ 专属配乐（已有 boss / final 曲）。
- **血条**：顶部长血条带延迟白条、阶段卡点刻度、韧性条；已有的机制副标题保留。
- **受击**：闪白 1 帧 + 形变 5% + 大伤害时 40ms 顿帧，替代震屏。
- **死亡**：0.4 秒慢动作 → 身上连续 4–6 个小爆点 → 一圈奖励喷出（经验、钱币、藏品）→ 横幅。

### 1.8 招式框架（boss_ai.gd 扩展）

所有招式统一"预警 → 生效"两段，预警 0.6–1.2 秒，预警期 Boss 停步：

| 招式模板 | 预警画法（程序绘制） | 躲法 |
|---|---|---|
| 直线冲锋 / 光束 | 地面矩形，先细后粗，满了生效 | 横向走开 |
| 落点圆 | 空心圆由外向内填满 | 走出圆 |
| 弹幕环 / 螺旋 | Boss 身上蓄光，环上留 1–2 个缺口 | 找缺口 |
| 扩散冲击环 | 地面细环预示最终半径 | 冲刺（无敌）穿过，或站远 |
| 追踪落点 | 跟着博士的圆，最后 0.3 秒锁定 | 锁定后横移 |
| 召唤 / 地形 | 地面裂缝 / 溟痕先浮现 | 远离，地形持续 ≤ 6 秒 |

节奏规则：招式间隔 2–4 秒，同一招不连放两次；每进一个阶段，缩短间隔或给招式加一种变体（1 圈 → 2 圈）。中期 Boss 3 招，最终 Boss 每阶段 2 招、总共 5–6 招。

## 2. 逐个 Boss 设计

格式：**原作招牌 → 现状 → 改动**。数值只给相对量，最终由平衡流程定。

### 2.1 塑路者（中期，3:30）
- **原作**：每受到 10 次伤害、每攻击 2 次，就分出一个"分形"，越打越多；本体离场分形全灭。**多段、零碎的攻击反而刷怪**。
- **现状**：75 / 50 / 25% 各分 4 只分形；震地、冲撞。
- **改动**：
  - 分形改成**按受到的命中次数**生成（每 25 次一只，场上上限 8），直接反制高频小伤害队伍；分形 20 秒自灭，本体死亡时全灭。
  - 新招 **「塑路」**：朝博士方向留下一条 6 秒的暗色路痕，路痕上的分形移速 ×2、博士踩上减速。
  - 50% 卡点：**「合流」**，所有分形冲回本体，每只回 3% 血，路上撞到博士造成伤害。
  - 保留震地、冲撞。

### 2.2 圣徒卡门 / 圣徒伊比利亚（中期）
- **原作**：同一人（伊比利亚是强化版）。手铳 3 发（伊比利亚 1 发，一枪秒杀近战），打空换剑；原地装填时被眩晕 / 冻结 / 浮空打断 → **自身晕眩 10 秒**。
- **现状**：已有弹药、装填、打断晕眩 6 秒；卡门狙击 + 退避跳，伊比利亚散弹 + 裁决。
- **改动**：
  - 装填变成明显的读条：头顶弹药格 + 装填圈，装填中韧性条需求减半，打断 = 破韧 + 晕眩 6 秒。这是本 Boss 的"攻略点"，做得越显眼越好。
  - 卡门新招 **「终审三连」**：三条交错的直线预警依次开火。
  - 伊比利亚改为原作的**单发重炮**：**「审判之枪」**，全屏红色瞄准线锁定博士 1.6 秒（最后 0.3 秒锁死），伤害 ×3.5；需要横移或冲刺躲开。
  - 弹药打空后的剑击改成主动招 **「圣徒之剑」**：短距冲刺 + 扇形斩。

### 2.3 接潮主教 + 蔑死体 / 斥亡体（中期）
- **原作**：一个意识分成两具身体。一方倒下进入假死（无敌、每秒回复，回满复活）；**两边同时假死才算真正击杀**。侵蚀累积后永久降防。
- **现状**：机制已还原（假死、回血、同时倒下才死）。
- **改动**：
  - 可读性：两具身体之间一道**连结光带**；假死的一方头顶显示复活倒计时圈，玩家一眼看懂"要同时打倒"。
  - 主教新招 **「潮汐圣咏」**：以自身为中心依次扩散 3 道带缺口的波环。
  - 50% 卡点 **「分离与统一」**：两具身体瞬间互换位置，连结光带变成伤害线，1.5 秒内横扫经过的区域。

### 2.4 偏执泡影（最终，结局一）
- **原作**：低空悬浮，同时打 3 个目标并附带侵蚀；攻击范围内我方**攻速 -60**；被击倒 20 秒后满血复活进入二阶段（5 个目标，攻速 -80）。
- **现状**：泡影环、凝视光束、泡影爆裂；**任何一次控制就触发二阶段**。
- **改动**：
  - **「认知负担」光环**：Boss 周身 r220 的泡泡光环，范围内干员攻速 -35%（二阶段 -50%）。逼玩家拉开距离、换站位，是原作最有代表性的机制。
  - 阶段改为原作形式：血量打到 0 → 缩成一个**泡影茧** 8 秒（无敌、周围不断吐小泡），然后以 60% 血量复活进二阶段。去掉"一控就二阶段"。
  - 新招 **「泡影囚笼」**：一个泡泡罩住博士 2 秒并减速，冲刺可以戳破。
  - 保留泡影环、凝视光束、泡影爆裂，按阶段分配。

### 2.5 伊莎玛拉，腐化之心（最终，结局三）
- **原作**：普攻是**治疗**友军；定期召唤"泪"为本体充能，**在泪上部署干员可以阻止充能**；充满后变身为真伤输出形态，两种形态血量分开算。
- **现状**：有泪、充能、变身、50% 狂暴、给小怪回血；**没有任何带预警的招式**。
- **改动**：
  - **踩泪封印**：博士站在泪上 1.5 秒即可击碎它（取代现在"站上去掉真伤"）。这是这场战斗的核心互动：输出 Boss 还是去拆泪。
  - 新招 **「大群之歌」**：声波环从本体向外扩散（每波带 2 个缺口），初始形态每 8 秒一次。
  - 新招 **「腐化潮汐」**：地面依次浮现 3 条溟痕带，1 秒后涌起。
  - 变身形态：真伤三连弹保留，新增 **「终焉咏叹」**：扇形光束从一侧扫到另一侧。
  - 阶段：66% 卡点召泪 ×2，33% 卡点强制变身。

### 2.6 伊祖米克，生态泉源（最终，结局四）
- **原作**：学习形态无敌，不断召唤子嗣，子嗣被吸收就变强；阐释形态每 30 秒**全屏震荡**（长晕 + 持续法伤），血量 75 / 50 / 25% 时各立即触发一次。
- **现状**：学习阶段已有；二阶段只有每 7 秒一次冲击波。
- **改动**：
  - 学习阶段加**拦截引导**：子嗣走向本体的路径用地面虚线标出，拦下一只 = 本体少回一截血。
  - **「全屏震荡」**：本体蓄力 2 秒，一道覆盖全屏的冲击环扩散过来。**用冲刺（无敌帧）穿过**即可无伤，被命中 → 眩晕 1.5 秒 + 持续伤害。在 66 / 33% 卡点各触发一次，之后每 25 秒一次。不照搬原作的 16 秒长晕。
  - 新招 **「生态回响」**：子嗣死亡处留下一圈 3 秒的孢子区。
  - 保留二阶段的周期冲击波，但降为 12 秒一次，给全屏震荡让位。

### 2.7 最后的骑士（最终，结局二）——现在最短命，最优先
- **原作**：DEF 4000（极高）；谁打它，谁就被施加"寒冷"，再被打一次就"冻结"，攻击冻结目标伤害 ×1.75；第一次倒下后原地 30 秒重生、回 25% 血，进入不可阻挡的冲锋形态。
- **现状**：冲锋、长枪连刺、寒冰领域、二阶段复活回 50% 血；实测中位 9 秒打完。
- **改动**：
  - **「寒冷反噬」**：干员每命中骑士 1 次积 1 层寒冷，满 8 层 → 该干员冻结 1.5 秒（停止攻击）。高频攻击的干员会被反复冻住，直接克制"满输出速推"。
  - **厚甲**：每次命中固定减伤（平减），对大量低伤害的连击特别有效；破韧期间甲失效。
  - 二阶段改为原作的 **冲锋形态**：连续穿场冲锋 3 次（每次预警线），冲过的路径留下 4 秒的冰痕（减速）；不再普攻。
  - 保留长枪连刺、寒冰领域，分配到一阶段。

## 3. 美术需求

### 3.1 Codex（怪物本体，交到 codex/art）

现状：只有最后的骑士有攻击 / 蓄力 / 死亡帧条；其他 Boss 出招时靠程序把待机图拉伸变形。`art/incoming/bosses/` 下 15 张首轮待机图从未接入，游戏用的是 `e_*`。

规格沿用 `e_*` 现有单帧尺寸（见下表），4 帧横条，脚底对齐本体；新增动作优先级从高到低：

| 优先级 | Boss（tex，单帧） | 需要的帧条 |
|---|---|---|
| P1 | 最后的骑士（e_knight，96×80） | `_charge_form`（二阶段冲锋形态奔跑 4 帧）、`_frozen_hit`（被破韧倒地 2 帧） |
| P1 | 伊莎玛拉（e_ishar，80×80） | `_attack`（歌唱 / 声波起手 4 帧）、`_transform`（变身 6 帧）、**变身形态**一套 `e_ishar_t` idle 2 + move 4、`_death` 4 |
| P1 | 偏执泡影（e_paranoia，72×72） | `_attack`（凝视 / 吐泡 4 帧）、`_cocoon`（泡影茧 2 帧循环）、`_death` 4 |
| P2 | 伊祖米克（e_izumik，72×72） | `_learn`（学习形态、半透明被护住 2 帧）、`_attack`（全屏震荡蓄力 4 帧）、`_death` 4 |
| P2 | 圣徒卡门 / 伊比利亚（e_carmen / e_iberia，40×48） | `_attack`（举铳开火 4 帧）、`_reload`（装填 4 帧循环）、`_slash`（剑斩 4 帧）、`_stun`（被打断跪地 2 帧）、`_death` 4 |
| P2 | 塑路者（e_path，56×56） | `_attack`（震地 4 帧）、`_charge`（冲撞蓄力 4 帧）、`_death` 4；分形 e_fractal 加 `_death` 2 帧 |
| P3 | 接潮主教 / 蔑死体 / 斥亡体（40–44 宽） | 各一条 `_attack` 4 帧、`_death` 4 帧（feign 已有） |

外观参考（原作设定，交付前请对照立绘 / PRTS 模型图）：卡门 / 伊比利亚是黑色长外套、宽檐帽的白须老者，一手手铳一手长剑；蔑死体是色彩斑斓、形似螳螂虾的海嗣；偏执泡影是吞食海嗣细胞后失控的阿戈尔少女、泡状半透明；伊莎玛拉是苍白巨大的人形海嗣；最后的骑士是持长枪的旧式重甲骑士。

### 3.2 Claude（特效 / UI，程序绘制为主）

- 招式预警：矩形、圆、缺口环、追踪圈、扩散冲击环——全部程序绘制，不需要贴图。
- Boss 登场地面阴影、名片底框、韧性条、阶段刻度、符文封场环。
- 新特效：分形路痕、泡影光环 / 泡影囚笼、泪的封印进度、声波环、全屏震荡、冰痕、连结光带、死亡连爆。可按需要少量做 `fx_boss_*` 帧条。

## 4. 实施顺序

| 阶段 | 内容 | 预计效果 |
|---|---|---|
| **B1 框架** | 1.2 血量曲线、1.3 阶段卡点、1.4 软上限、1.7 演出（名片 / 血条 / 受击 / 死亡） | 基本解决"露头就被秒" |
| **B2 招式** | 1.8 招式模板；最后的骑士、偏执泡影、伊莎玛拉三个最终 Boss 的新招 | 最终 Boss 变成真正的一场战斗 |
| **B3 战场** | 1.5 韧性条（统一各干员对 Boss 的控制处理）、1.6 刷怪减量 + 符文封场、伊祖米克 | 控制型干员对 Boss 有用；Boss 战有场面 |
| **B4 中期** | 塑路者、卡门 / 伊比利亚、接潮组的新招 | 中期 Boss 也有记忆点 |
| **美术** | 3.1 表 P1 → P2 → P3 交给 Codex；到货前用程序姿态变形顶替 | — |

每个阶段结束用机器人批跑核对击杀用时是否落在 1.1 的目标区间。
