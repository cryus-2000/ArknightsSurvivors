# 38 · Boss 重做调研与方案（2026-09-26，v2 草案，待用户确认）

> 用户反馈：现在的 Boss 存在感太弱，露头就被秒。本文件是三路调研的汇总：
> ① 代码现状审计（数据、公式、招式、机器人实测击杀用时、现有美术）；
> ② 原作「水月与深蓝之树」这 10 个 Boss 的机制（PRTS / arknights.wiki.gg）；
> ③ 同类幸存者游戏怎样让 Boss 立得住（Vampire Survivors、Brotato、Halls of Torment、HoloCure、DRG: Survivor、Hades 等）。
> 结论先行：**问题不在单个 Boss，而在整套 Boss 框架没有"最短战斗时长"的保护**。先补通用框架，再逐个补招式。
> v2.1：按 v0.7 主控规则修正（主控 = 玩家操控、唯一受击的开局干员，博士是挂件），新增 1.11 控制保护规则：硬控只打编队干员，不硬控主控。
> v2（用户：战斗设计可以更丰富）：加入 1.9 丰富原则、1.10 机制类型库，逐个 Boss 改为三幕式，用上灯火、溟痕、黑潮圈、石柱、冲刺、干员离场、大群事件等本作系统。

## 0. 为什么露头就被秒

机器人实测（`build/balance/` 下 204 局，全部难度 0；中期 Boss 按出场到击杀计时，最终 Boss 按胜利时刻 − 600 秒）：

| Boss | 出场 | 实测击杀用时（中位 / 最短） | 实际血量（难度 0） |
|---|---|---|---|
| 塑路者 | 3:30 | 高手 23s | 4320 |
| 伊比利亚 | 3:30 / 7:00 | 高手 86s（装填打断机制拖长了） | 4320 / 5440 |
| 卡门 | 7:00 | 高手 42s | 4760 |
| 接潮双体 | 7:00 | 高手 34–49s | 合计约 5300–6100 |
| **最后的骑士**（最终） | 10:00 | **中位 9s，最短 2s** | 10400 + 二阶段回 50% |
| **偏执泡影**（最终） | 10:00 | 中位 25s，最短 3s | 14800 |
| **伊莎玛拉**（最终） | 10:00 | 中位 25s，最短 4s | 18000 |
| 伊祖米克（最终） | 10:00 | 中位 41s（含无敌学习阶段） | 10400（35% 血量出场） |

报告里还有：高手维什戴尔打中期 Boss 平均 **11 秒**。

原因（按影响排序）：
1. **血量涨得太慢**：Boss 血量 = 基础 × (1 + t/600)，10 分钟才 ×2；同期普通怪 ×5，玩家输出成长更快。最终 Boss 血量只是中期 Boss 的 2–3 倍。
2. **没有任何"最短时长"保护**：没有伤害上限、没有护甲、没有阶段卡点，只有骑士复活那 1.5 秒无敌。
3. **增伤乘区叠满**：弱点 +50% × 灯光内 +25% × 终局藏品 +80% / +40%，可以一起乘。
4. **招式太少、太好读**：伊莎玛拉没有任何带预警的招式，伊祖米克只有一个冲击波；大多数 Boss 靠普通射击。
5. **没有"Boss 战"的场面**：从屏幕边缘刷出，小怪照常刷，没有封场、没有登场演出，除骑士外都没有攻击帧。

## 1. 通用框架（所有 Boss 共用，先做这一块）

同类游戏的经验：**存在感 = 仪式感 + 一段不能被跳过的时间 + 2–4 个看得懂的招式 + 死亡奖励**。只堆血会变成"海绵"（Halls of Torment 的教训），强力构筑照样秒。

### 1.1 目标战斗时长

| 类型 | 目标时长 | 最短不低于 | 说明 |
|---|---|---|---|
| 中期 Boss（3:30 / 7:00） | 25–40s | 12s | 强力构筑可以比基准快 30–50%，但不能 2 秒结束 |
| 最终 Boss（10:00） | 60–90s | 40s | 三阶段，每阶段 20–30 秒 |

### 1.2 血量：跟上玩家输出

- 时间曲线改为和普通怪同斜率：**基础 × (1 + t/150)**（3:30 ×2.4、7:00 ×3.8、10:00 ×5），`balance.json enemy.boss_hp_time_div` 600 → 150。
- 基础血量按"目标时长 × 该时刻期望全队 DPS"反推，用机器人数据校准（高手终局有效 DPS 约 1.7k/s → 最终 Boss 目标约 1.7k × 75s ≈ 13 万量级需要框架配合，见 1.3–1.4，不靠单纯堆血）。
- 数值由 balance 会话按 docs/27 流程落地，这里只定目标。

### 1.3 阶段卡点（防秒杀的核心）

- 中期 Boss 在 **50%** 处、最终 Boss 在 **66% / 33%** 处设卡点：一次伤害最多把血打到卡点为止，然后 **1.2 秒无敌转阶段**。
- 转阶段演出：本体闪白 → 一圈冲击环扩散 → 横幅出现阶段名，同时换一套或加强招式。
- 这是同类游戏里最有效、玩家最不容易察觉的"最短时长"手段。

### 1.4 软伤害上限

- 每只 Boss 有每秒伤害上限 = 最大血量 ÷ 最短时长（如中期 Boss ÷12、最终 Boss ÷40）。超出部分打 **×0.25** 折扣，不是归零。
- 伤害数字照常显示，超出上限的数字颜色变灰，玩家看得懂"打到上限了"。
- 附带收紧增伤乘区：弱点、灯光、终局藏品对 Boss 的合计增伤封顶 **×2.0**。

### 1.5 韧性条（统一控制处理）

现在控制对 Boss 的处理很散：击退、浮空、封印、推进之王眩晕对 Boss 直接跳过，乌尔比安眩晕 ×0.5 / ×0.27，水月 S3 眩晕却全额生效。统一成：

- Boss **免疫击退和浮空**，减速上限 35%。
- 眩晕、冻结、束缚、浮空不直接生效，改为积累 **韧性条**（血条下方一条黄条）。条满 → **破韧**：Boss 倒地 3 秒、承受 +30% 伤害，之后韧性条清空，重新积累需要的量 ×1.5。
- 好处：控制型干员（推进之王、艾丽妮、乌尔比安、塞雷娅）对 Boss 也有明确作用和爽点，而不是"对 Boss 无效"。
- 伊比利亚 / 卡门"装填被打断 → 长晕"并入这套：装填时韧性条需求减半。

### 1.6 Boss 战场面

- Boss 登场期间普通刷怪降到 **40%**，并换成该 Boss 的随从（分形、子嗣、潮汐小怪等）。
- **最终 Boss** 登场时，在主控周围 r520 画一圈发光符文环：离开环 → 减速 30% + 灯火流失加快（不是实墙）。中期 Boss 不封场。
- Boss 从距主控约 400 处的地面浮出（登场前 1.5 秒地面出现扩大的阴影），不再从屏幕边缘刷进来。

### 1.7 演出（全部不震屏）

- **登场**：画面四角压暗 → 地面阴影 → Boss 浮出 → 名片（名字 + 称号 + 原作一句台词，1.8 秒，可按键跳过）→ 专属配乐（已有 boss / final 曲）。
- **血条**：顶部长血条带延迟白条、阶段卡点刻度、韧性条；已有的机制副标题保留。
- **受击**：闪白 1 帧 + 形变 5% + 大伤害时 40ms 顿帧，替代震屏。
- **死亡**：0.4 秒慢动作 → 身上连续 4–6 个小爆点 → 一圈奖励喷出（经验、钱币、藏品）→ 横幅。

### 1.8 招式框架（boss_ai.gd 扩展）

所有招式统一"预警 → 生效"两段，预警 0.6–1.2 秒，预警期 Boss 停步：

| 招式模板 | 预警画法（程序绘制） | 躲法 |
|---|---|---|
| 直线冲锋 / 光束 | 地面矩形，先细后粗，满了生效 | 横向走开 |
| 落点圆 | 空心圆由外向内填满 | 走出圆 |
| 弹幕环 / 螺旋 | Boss 身上蓄光，环上留 1–2 个缺口 | 找缺口 |
| 扩散冲击环 | 地面细环预示最终半径 | 冲刺（无敌）穿过，或站远 |
| 追踪落点 | 跟着主控的圆，最后 0.3 秒锁定 | 锁定后横移 |
| 召唤 / 地形 | 地面裂缝 / 溟痕先浮现 | 远离，地形持续 ≤ 6 秒 |

节奏规则：招式间隔 2–4 秒，同一招不连放两次；每进一个阶段，缩短间隔或给招式加一种变体（1 圈 → 2 圈）。

### 1.9 让战斗"丰富"的五条原则（v2 新增）

只加躲避类招式，玩家从头到尾只在做一件事：走位。一场丰富的 Boss 战，玩家在不同时刻要做**不同的事**、下**不同的决定**。

**① 每个 Boss 至少用上三种玩家动作**

| 玩家动作 | 本作已有的系统 | Boss 里怎么用 |
|---|---|---|
| 走位 | 移动 | 躲预警（基本盘） |
| 冲刺穿越 | 冲刺 0.18 秒无敌 | 穿过全屏冲击环、戳破泡泡、撞碎冰墙 |
| 站位 / 占点 | 主控本体 | 踩泪封印、守灯柱、站进安全圈 |
| 选目标 | 主控走位带着编队走（编队跟随、自动索敌） | 先拆部件 / 随从，还是硬打本体 |
| 手动技能 | 幽灵鲨 S2 等手动技能 | 留着在 Boss 的大招窗口开 |
| 灯火管理 | 灯火（昏暗 < 30 / 充盈 ≥ 70） | Boss 吞灯、场上出现灯油 / 灯柱 |
| 利用地形 | 石柱、墙有碰撞 | 引冲锋撞柱、躲在柱后挡弹幕 |

**② Boss 要"碰"到编队，而不只是打主控**

主控（玩家操控的开局干员）是唯一会掉血的，编队干员不会死（v0.7，docs/23）。这让 Boss 只能打主控，编队在 Boss 战里没有存在感。给 Boss 加"针对编队干员"的招式，让编队也卷进战斗。**硬控只打编队干员，不打主控**（保护规则见 1.11）：

- **冻结 / 囚禁编队干员**：被困的干员停止攻击，主控走过去（或冲刺穿过）把他解救出来；不管也会在 2 秒后自动解除。可选：博士（挂件）会慢慢走过去解救，玩家不必亲自跑，只是更慢。
- **拉走干员**：把一名干员拖离编队，干员要跑回来才恢复输出。
- **压制技力**：歌声、光环让干员技力流失或攻速下降，逼玩家拉开距离。
- **反噬**：打得越猛的干员越容易被反制（骑士的寒冷），逼玩家换思路，而不是一味堆输出。

**③ 每个阶段换一个"主题"，而不只是加快**

三幕式：**开场**（教会玩家这个 Boss 怎么打）→ **中盘**（加一个目标或场地变化）→ **高潮**（全力输出窗口 + 最危险的招）。每幕至少有一个新元素：新招、新目标、场地变化三选一。

**④ 破绽窗口：奖励会看招的玩家**

每个 Boss 都有 1–2 个"破绽"：大招收招后硬直、读条被打断、冲锋撞柱、部件被拆。破绽期间 Boss 受伤 +30–50%，并有明显提示（身上出现裂纹光、头顶"破绽!"字样）。这样强力构筑依然能打得快，但快的前提是看懂机制，而不只是数值碾压。

**⑤ 终结与奖励**

- **最后一击**：Boss 血量归零时进入 0.6 秒慢动作，由输出最高的干员打出终结一击（播放该干员的技能动作 + 一句语音）。
- **战斗评价**：按用时、受伤、破绽次数给出评级（优秀 / 良好 / 普通），评级越高，掉落的藏品候选越多（3 选 1 → 4 选 1），给"打得漂亮"一个实在的回报。

### 1.10 通用机制类型库

下面这些机制会在各个 Boss 里重复使用、组合，实现时做成通用模块：

| 类型 | 机制 | 例子 |
|---|---|---|
| 躲避 | 预警招式（见 1.8） | 冲锋线、落点圆、缺口环 |
| 目标 | 场上出现可破坏物，拆掉才有进展 | 泪、分形核心、泡影茧外壳 |
| 占点 | 主控站进某区域维持若干秒 | 踩泪封印、点亮灯柱 |
| 救援 | 编队干员被困，主控去解救 | 泡泡囚笼、冰封 |
| 资源 | Boss 夺走或压低某种资源 | 吞噬灯火、技力流失、侵蚀 |
| 地形 | 战场形状在战斗中变化 | 涨潮、冰墙、溟痕蔓延、黑潮圈收缩 |
| 反制 | 打断读条 / 引招撞墙换破绽 | 装填打断、冲锋撞柱 |
| 时限 | 倒计时内完成，否则 Boss 发动大招 | 伊祖米克学习、伊莎玛拉变身 |

### 1.11 控制保护规则（防止"被秒"）

v0.7 起主控是玩家操控、唯一掉血的角色，攻击也从她身上打出。控制编队干员只损失一份输出；控制主控则等于让玩家不能走位、不能输出，Boss 招式一接上就是秒杀。所以：

| 规则 | 内容 |
|---|---|
| 硬控只打编队 | 冻结、囚禁、狙击离场、魅惑这类硬控**只作用于编队干员**，主控永远不会被硬控 |
| 主控只吃软控 | 打在主控身上的效果只能是减速、减攻速、持续伤害，且都有上限（减速 ≤ 50%、减攻速 ≤ 15%） |
| 同时最多一人 | 编队里任意时刻最多 1 名干员处于被控 / 离场状态，编队不会整体哑火 |
| 时长短、可解救 | 编队干员被控最长 2 秒（离场 4 秒），结束后 4 秒内不会再被同类控制；主控靠近 1 秒或冲刺穿过即可立刻解救 |
| 能躲就能完全躲 | 所有大招都能用冲刺（无敌帧）或站进安全区完全躲掉，没有"必中" |
| 不给围殴机会 | Boss 战期间小怪刷新降到 40%（见 1.6） |

实装后机器人批跑多统计一项「Boss 战期间主控死亡率」；某个机制让死亡率明显上升，就先调这个机制。

## 2. 逐个 Boss 设计（v2：三幕式）

格式：**一句话定位 → 原作招牌 → 三幕流程（场地 / 招式 / 机制 / 破绽）→ 用到的系统 → 高光时刻**。数值只给相对量。

### 2.1 塑路者（中期，3:30）——"越打越多"
- **原作**：每受 10 次伤害、每攻击 2 次就分出一个分形，分形继承本体血量百分比、会自我复制；本体离场分形全灭。
- **第一幕：分裂**
  - 招式：震地（跟随圆）、冲撞（直线）。
  - 机制：**按受到的命中次数分裂**（每 25 次一只，上限 8）。分形是本体的暗色残影，移速快、血少，20 秒后自灭。
  - 教会玩家：高频小伤害会刷出一堆分形。
- **第二幕：塑路**（50% 卡点）
  - 场地：Boss 身后开始留下**溟痕路痕**（复用溟痕地形），路痕持续 8 秒、会慢慢扩散；分形在路痕上移速 ×2。
  - 新招 **「塑路冲刺」**：沿着已有路痕连冲 2 段，折线预警。
  - 机制：**分形核心**——场上最老的一只分形变成发光的"核心分形"，击碎它，其余分形全部崩解，本体硬直 3 秒（破绽）。
- **第三幕：合流**（25% 以下）
  - 所有分形冲回本体，沿途撞到主控造成伤害；每只回本体 3% 血。拦截越多，本体回得越少。
  - 合流完成后本体体型变大、冲撞变为 3 连。
- **用到的系统**：溟痕地形、自动索敌（逼玩家带着编队去打核心分形）。
- **高光时刻**：一炮打爆核心分形，满场分形同时碎成烟。

### 2.2 圣徒卡门 / 圣徒伊比利亚（中期）——"老猎人的枪"
- **原作**：同一人，伊比利亚是强化版。手铳有弹药，打空换剑；原地装填时被控制打断，自身晕眩 10 秒。
- **第一幕：狙击**
  - 招式：卡门 **「终审」**（单条长瞄准线，锁主控）；伊比利亚 **「审判之枪」**（全屏红色瞄准线，1.6 秒锁定，一发重伤）。
  - 机制：**狙击干员**——每隔一段时间，瞄准线改为锁定一名干员，命中后该干员"暂时离场" 4 秒（复用幽灵鲨的离场机制；只狙编队干员，瞄准主控时就是一发可躲的重伤害）。主控挡在瞄准线上可以替干员吃这一枪（伤害减半）。
  - 地形：场上出现 2–3 根**石柱**，躲在柱后可以挡子弹。
- **第二幕：装填**（弹药打空）
  - 机制：**装填读条**——头顶弹药格 + 装填圈，读条 4 秒。装填中韧性条需求减半，打出控制即可打断 → **长破绽 6 秒，受伤 +50%**。这是这场战斗的核心攻略点。
  - 没打断：装填完成后立刻 **「连发」**，三条瞄准线依次开火。
- **第三幕：剑**（50% 以下）
  - 招式：**「圣徒之剑」**，贴身冲刺 + 扇形斩；**「猎人步法」**，被靠近就后跳拉开并留下一个延时爆炸的弹壳。
  - 弹药上限 -1，装填更频繁，破绽也更多。
- **用到的系统**：石柱地形、干员离场、控制 / 韧性条。
- **高光时刻**：推进之王一锤砸断装填，老猎人跪地，全队集火。

### 2.3 接潮主教 + 蔑死体 / 斥亡体（中期）——"分离与统一"
- **原作**：一个意识分成人类和海嗣两具身体；一方倒下就进入假死，回满复活；两边同时假死才算击杀。侵蚀累积后永久降防。
- **第一幕：两具身体**
  - 招式：主教 **「潮汐圣咏」**（三道带缺口的扩散波环）；蔑死体横扫、跃击 / 斥亡体三连斩。
  - 机制：两具身体间有一道**连结光带**，站在光带上的干员被侵蚀。玩家要把两具身体分开打，又要在复活窗口内同时打倒。
- **第二幕：假死**（任一方首次倒下）
  - 假死的一方头顶显示复活倒计时圈（8 秒）；另一方进入狂暴：主教召潮、蔑死体攻速加快。
  - 机制：**倒计时赛跑**——必须在 8 秒内打倒另一方。没做到，假死的一方满血复活，但复活次数有上限（3 次后不再复活，给打不过的玩家留退路）。
- **第三幕：统一**（两方都低于 30%）
  - 两具身体互相靠拢，连结光带变成**旋转的伤害线**，以两者中点为轴扫场；两者距离越近，转速越快。
  - 玩家选择：拉开两者（用走位把近战那只引走）降低危险，或者趁它们靠拢时范围技能一次打倒两个。
- **用到的系统**：侵蚀、范围技能（艾雅法拉、维什戴尔）的价值。
- **高光时刻**：两具身体同时倒下，光带断裂。

### 2.4 偏执泡影（最终，结局一）——"变成最厌恶的样子"
- **原作**：低空悬浮、不能阻挡；同时打多个目标并附侵蚀；攻击范围内我方攻速大幅降低；被击倒 20 秒后满血复活进入二阶段。
- **第一幕：认知负担**
  - 场地：**黑潮圈**开始缓慢收缩（复用黑潮圈），战斗空间越来越小。
  - 招式：泡影环（减速弹）、**「多重凝视」**（同时锁定主控和 2 名编队干员的三道光束；打在编队干员身上是减攻速，打在主控身上是伤害）。
  - 机制：**认知负担光环**——Boss 周身 r220，范围内干员攻速 -35%。玩家要一边拉开距离，一边让远程干员在光环外输出。
- **第二幕：泡影囚笼**（66% 卡点）
  - 新招 **「泡影囚笼」**：一名编队干员被泡泡困住，停止攻击；主控冲刺穿过泡泡就能戳破，不管也会在 2 秒后自己破掉。每 12 秒一次，同时只困 1 人，不会罩在主控身上。
  - 场地：地上的泡泡落地后变成溟痕，逐渐铺满外圈。
- **第三幕：蜕变**（首次血量归零）
  - Boss 缩成**泡影茧** 10 秒：茧外有一层可破坏的外壳（外壳血量 = 最大血量 10%），茧周围不断吐出小泡。
  - 外壳被打破 → 进入二阶段时只剩 40% 血；没打破 → 60% 血。**把输出窗口交给玩家选择**。
  - 二阶段：光环扩大、攻速削减 -50%，泡影爆裂 4 圈，凝视光束变 5 道。
- **用到的系统**：黑潮圈、溟痕、冲刺、编队站位。
- **高光时刻**：冲刺连破两个泡泡，放出的干员一起开大。

### 2.5 伊莎玛拉，腐化之心（最终，结局三）——"替大群发声"
- **原作**：普攻不伤人，而是治疗友军；召唤"泪"为本体充能，在泪上部署干员可以阻止充能；充满后变身为真伤形态，两种形态血量分开算。
- **第一幕：泪**
  - 招式：**「大群之歌」**（声波环，每波两个缺口）；普攻治疗附近海嗣。
  - 机制：**踩泪封印**——泪出现后开始给本体充能，主控站在泪上 1.5 秒即可击碎。玩家要在"输出本体"和"去拆泪"之间做取舍。
  - 资源：歌声经过时，干员技力流失 10%。
- **第二幕：大群**（66% 卡点）
  - 事件：**大群涌来**（复用大群事件，规模减半），海嗣从四面扑来，伊莎玛拉持续治疗它们。
  - 新招 **「腐化潮汐」**：地面依次浮现 3 条溟痕带，1 秒后涌起。
  - 机制：**吞噬灯火**——每个未击碎的泪每秒吸走 1 点灯火；灯火进入"昏暗"时，伊莎玛拉的歌声范围变大。
- **第三幕：变身**（泪充满或 33% 卡点强制）
  - 变身过程 2 秒无敌，清空所有泪；变身形态血量独立（最大血量的一半），真伤三连弹 + **「终焉咏叹」**（扇形光束从一侧扫到另一侧）。
  - 打倒变身形态 → 本体回到初始形态、2% 血，**3 秒长破绽**，全队可以一波带走。
- **用到的系统**：大群事件、灯火、溟痕、技力。
- **高光时刻**：打倒变身形态后，伊莎玛拉跪在海面上，最后一波集火。

### 2.6 伊祖米克，生态泉源（最终，结局四）——"人之光辉"
- **原作**：学习形态无敌，定期召唤子嗣，子嗣被吸收就变强；阐释形态每 30 秒全屏震荡（长晕 + 持续伤害），血量 75 / 50 / 25% 时各立即触发一次。
- **第一幕：学习**（无敌）
  - 机制：**拦截子嗣**——子嗣走向本体的路线用地面虚线标出，拦下一只 = 本体少回一截血、少一层强化。这一幕是防守战：玩家要带着编队在本体周围巡防。
  - 场地：战场逐渐变暗，灯火半径缩小；场上刷出 3 根**灯柱**，主控站在灯柱旁 2 秒可以点亮它，被点亮的灯柱周围子嗣移速减半。
- **第二幕：阐释**（学习结束）
  - 招式：远程法术普攻、**「生态回响」**（子嗣死亡处留 3 秒孢子区）、周期冲击波。
  - 机制：**全屏震荡**——本体蓄力 2 秒，一道覆盖全屏的冲击环扩散过来；**冲刺穿过**即可无伤，或者站在已点亮的灯柱光圈里也能免疫。被命中 → 减速 50% 2 秒 + 持续伤害（**不眩晕主控**，见 1.11）。
  - 在 66% / 33% 卡点各立即触发一次，之后每 25 秒一次。
- **第三幕：泉源**（33% 以下）
  - 本体扎根不动，身边长出 4 条**根须**（可破坏部件），根须每 3 秒向外射出一道扫射线；每拆掉一条根须，本体受伤 +15%。
- **用到的系统**：灯火、灯柱（新道具）、冲刺、编队巡防。
- **高光时刻**：最后一次全屏震荡，主控在光圈里站定，编队在震荡波里爆发。

### 2.7 最后的骑士（最终，结局二）——"堂吉诃德"
- **原作**：防御极高；谁打它谁就被施加寒冷，再被打就冻结，攻击冻结目标伤害 ×1.75；第一次倒下后原地 30 秒重生，进入不可阻挡的冲锋形态。
- **第一幕：寒冷**
  - 招式：长枪连刺（三段扇形）、寒冰领域（减速圈）。
  - 机制：**寒冷反噬**——编队干员每命中骑士 1 次积 1 层寒冷，满 8 层冻结 1.5 秒（同时最多 1 人被冻）。高频攻击的干员会被反复冻住，逼玩家换打法。**主控不会被冻结**：主控打骑士只叠寒冷，每层攻速和移速各 -3%（上限 -15%），停手 3 秒后消退。
  - **厚甲**：每次命中固定减伤，低伤害的连击几乎打不动；破韧期间甲失效。
- **第二幕：冰原**（66% 卡点）
  - 场地：骑士把长枪插进地面，场上升起 4–6 道**冰墙**（有碰撞，挡子弹也挡路），把战场切成几块。冰墙被冲刺撞到就碎。
  - 新招 **「骑枪冲锋」**：长直线冲锋；**冲锋撞上冰墙或石柱 → 骑士眩晕 3 秒（破绽）**。玩家要学会把冲锋引向墙。
- **第三幕：重生与冲锋**（首次倒下）
  - 原地重生 5 秒（缩短原作的 30 秒），回 30% 血，进入**冲锋形态**：不再普攻，连续穿场冲锋 3 次一组，每次预警线；冲过的路径留下 4 秒冰痕（减速）。
  - 每组冲锋之间有 2 秒喘气（破绽）。
- **用到的系统**：石柱 / 冰墙碰撞、冲刺、韧性条（破韧 = 甲失效）、编队（寒冷反噬）。
- **高光时刻**：骑士一头撞碎在冰墙上，长枪脱手，全队追击。

## 3. 美术需求

### 3.1 Codex（怪物本体与可破坏部件，交到 codex/art）

现状：只有最后的骑士有攻击 / 蓄力 / 死亡帧条；其他 Boss 出招时靠程序把待机图拉伸变形。`art/incoming/bosses/` 下 15 张首轮待机图从未接入，游戏用的是 `e_*`。

规格沿用 `e_*` 现有单帧尺寸，横条排列，脚底对齐本体。优先级从高到低：

| 优先级 | Boss（tex，单帧） | 需要的帧条 |
|---|---|---|
| P1 | 最后的骑士（e_knight，96×80） | `_plant`（长枪插地、升起冰墙 4 帧）、`_stun`（撞墙眩晕、长枪脱手 2 帧循环）、`_charge_form`（冲锋形态奔跑 4 帧） |
| P1 | 伊莎玛拉（e_ishar，80×80） | `_attack`（歌唱起手 4 帧）、`_transform`（变身 6 帧）、变身形态一套 `e_ishar_t`（idle 2 + move 4 + attack 4）、`_kneel`（跪倒破绽 2 帧）、`_death` 4 |
| P1 | 偏执泡影（e_paranoia，72×72） | `_attack`（多重凝视 4 帧）、`_cocoon`（泡影茧 2 帧循环 + 外壳破裂 4 帧）、`_death` 4 |
| P2 | 伊祖米克（e_izumik，72×72） | `_learn`（学习形态、被光膜护住 2 帧）、`_attack`（全屏震荡蓄力 4 帧）、`_root`（扎根 4 帧）、**根须部件** `e_izumik_root`（约 24×48，idle 2 + 射击 2 + 断裂 3）、`_death` 4 |
| P2 | 圣徒卡门 / 伊比利亚（e_carmen / e_iberia，40×48） | `_attack`（举铳开火 4 帧）、`_reload`（装填 4 帧循环）、`_slash`（剑斩 4 帧）、`_stun`（装填被打断跪地 2 帧）、`_death` 4 |
| P2 | 塑路者（e_path，56×56） | `_attack`（震地 4 帧）、`_charge`（冲撞蓄力 4 帧）、`_death` 4；分形 e_fractal 加 `_death` 2 帧 |
| P3 | 接潮主教 / 蔑死体 / 斥亡体（40–44 宽） | 各一条 `_attack` 4 帧、`_death` 4 帧（feign 已有） |

外观参考（原作设定，交付前请对照立绘 / PRTS 模型图）：卡门 / 伊比利亚是黑色长外套、宽檐帽的白须老者，一手手铳一手长剑；蔑死体是色彩斑斓、形似螳螂虾的海嗣；偏执泡影是吞食海嗣细胞后失控的阿戈尔少女、泡状半透明；伊莎玛拉是苍白巨大的人形海嗣；伊祖米克是水月与深蓝之树的融合体；最后的骑士是持长枪的旧式重甲骑士。

### 3.2 Claude（特效 / 道具 / UI，程序绘制为主）

- **招式预警**：矩形、圆、缺口环、追踪圈、扩散冲击环、折线冲锋、瞄准线——全部程序绘制。
- **新道具**（`prop_*`，归 Claude）：灯柱（未点亮 / 点亮 2 态）、冰墙（完整 / 破碎 3 帧）。石柱复用现有 `prop_pillar`。
- **机制特效**：核心分形发光、溟痕路痕扩散、连结光带与旋转伤害线、认知负担光环、泡影囚笼（困住干员的泡泡 + 戳破）、泪的封印进度圈、声波环、吞噬灯火的光流、全屏震荡、孢子区、冰痕、寒冷层数（干员头上的雪花格）、破绽标记（裂纹光 + "破绽!"）。
- **UI**：登场地面阴影、名片底框、韧性条、阶段刻度、战斗评价卡、终结一击的慢动作滤镜。

## 4. 实施顺序

| 阶段 | 内容 | 预计效果 |
|---|---|---|
| **B1 框架** | 1.2 血量曲线、1.3 阶段卡点、1.4 软上限、1.7 演出、1.9⑤ 终结一击与评价 | 基本解决"露头就被秒"，Boss 有仪式感 |
| **B2 模块** | 1.8 招式模板 + 1.10 机制模块（可破坏部件、占点、救援、资源、地形、反制、时限）+ 1.5 韧性条 | 后面每个 Boss 都是组合这些模块 |
| **B3 最终 Boss** | 最后的骑士 → 偏执泡影 → 伊莎玛拉 → 伊祖米克（按实测最短命排序） | 最终战变成三幕式的真正战斗 |
| **B4 中期 Boss** | 塑路者、卡门 / 伊比利亚、接潮组 | 中期也有记忆点 |
| **美术** | 3.1 表 P1 → P2 → P3 交给 Codex；到货前用程序姿态变形顶替 | — |

每个阶段结束用机器人批跑核对击杀用时是否落在 1.1 的目标区间；机器人要补会用冲刺、会踩泪 / 点灯柱的行为，否则测出的时长会偏长。

## 5. 待用户确认

1. 目标时长：中期 25–40 秒、最终 60–90 秒，可以吗？
2. **Boss 针对编队干员**（冻结、囚禁、狙击离场、技力流失，按 1.11 只控编队、不硬控主控）这个方向可以吗？编队干员会短暂停止输出，主控要去救。
3. 最终 Boss 要不要**封场**（黑潮圈收缩 / 符文环），还是保持开放地图？
4. **韧性条**替代现在各干员对 Boss 的"控制无效 / 减半"，可以吗？会改到多名干员的代码。
5. 新道具**灯柱、冰墙**、新机制**踩泪、点灯**会让主控在 Boss 战里需要主动走到某处，这个节奏可以吗？
6. **战斗评价**影响藏品候选数量（3 选 1 → 4 选 1），会不会太影响平衡？
