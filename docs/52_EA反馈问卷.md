## 完整版

## 1. 难度
1. 三档（波涛迭起 / ·Ⅳ / ·Ⅷ）你各玩了几局？通关了哪几档？
2. 哪一档玩起来刚好「难但想再来一局」？哪一档太简单或太难？
3. 最让你难受的一次死法是什么？（被 Boss 打死 / 被怪围住 / 黑潮缩圈 / 神经损伤眩晕 / 没看清是什么）
4. 开局前 3 分钟会不会无聊？「围猎」（约 1:30 的包围圈）是紧张还是烦？

## 2. Boss
5. 哪只 Boss 最有意思？哪只最烦？为什么？
6. 有没有哪场 Boss 战觉得拖得太久？大概打了几分钟、当时手上有几件藏品？
7. 每只 Boss 的破解方法（打碎核心、打断装填、打破茧、点亮灯柱、引骑士撞冰枪桩……）你看懂了吗？哪一个没看懂？
8. Boss 的预警（虚线在追、实线已锁定）看得清吗？有没有「根本没看到就被打中」？

## 3. 操作
9. 你用的是自动普攻还是手动普攻？为什么选它？
10. 用过乌尔比安的三技能选落点吗？顺手吗？
11. 用的是键鼠、手柄还是手机？有没有按不到、按错的键？

## 4. 画面与性能
12. 用的是什么电脑 / 手机（大概型号或配置）？网页版还是 Windows 版？
13. 画质选的高还是低？后期怪多时卡不卡？
14. 怪多的时候，能不能分清自己、敌人、弹幕和掉落？

## 5. 溟痕与引航灯标
15. 溟痕（紫黑色地面）会不会太多、太烦？神经损伤满了眩晕，你知道是怎么来的吗？
16. 引航灯标你会主动去点吗？点了之后觉得值不值？

## 6. 最后
17. 如果只能改一件事，你最想改什么？
18. 有没有哪句说明看不懂，或者和实际效果对不上？

## 怎么发给我
- **截图最有用**：死掉或通关时的**结算页**（有用时、等级、击杀、结局和难度），再加一张你觉得卡住或看不懂的画面。
- 顺手写上：开局干员、难度、打到几分几秒、手上大概几件藏品。
- **对内测试版**：再附上对局记录文件 `%APPDATA%\ArknightsSurvivors_Internal\runs\runs.jsonl`（设置 → 游戏 → 对局记录「打开记录文件夹」一键定位；只有对局摘要，不含个人信息，不会自动上传）。
