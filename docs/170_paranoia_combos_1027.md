# 170 · 偏执泡影连携攻势与弹幕图案（2026-10-27）

状态：已实现，回归通过，实机录像待用户看。分支 `claude/boss-paranoia`（从 `codex/boss-fx-rework` 72f41c3c7 开出），未合入 main。

用户 10-27：每只 Boss 分会话改特效、招式连携、招式数量，要有「打 Boss 的感觉」。协调人更正：东方 Project 只是例子，**不做符卡制度**（没有符卡名横幅、没有按卡切换清屏），要的是弹幕有图案、有规律可学、可读、有节奏和压迫感，阶段沿用现有幕制。本文所有连段与弹幕名都是本作改编，不是原作技能。

## 1. 结构

- 每幕两组有限连段，轮流出：一组 ≤4 段，每段按当时队长位置重新瞄准，段间收势 0.25 秒（悬浮幕）/ 0.15 秒（落地后）。
- 一组结束进入「收招」：悬浮幕 1.6 秒、落地后 2.0 秒，不出招不走动；悬浮幕正好冲刺穿身打落（主轴 docs/142b §3.5）。收招不加受伤倍率，避免和坠地 ×1.8 叠成过高的爆发。
- 打断：坠地、三幕打散光环、被控 / 破绽、转幕、结茧都清掉没放完的弹幕段、队列、未结算的有伤预警和移动泡；已在飞的弹照旧。下一组从轮换的下一位起手。
- 换幕时她先聚光 1 秒（收拢双环 + 颗粒），不出招。
- 一幕悬浮离得远时，连段之间先「泡影漂近」（机制，不占连段）。
- 连段接管后，`final_attacks` 与 `boss_patterns` 的独立轮换不再自己出招（`final_next` / `pattern_next` 置 INF），它们的招只作为连段的段出现。
- 开关：`boss/paranoia_combos`（缺省 1）。0 = 回到原独立轮换，方便云端 A/B。

## 3. 新增弹幕（7 种，合计主动攻击 7 → 14，加幻象冲撞共 15）

用户 10-27「boss 的攻击方式要有自己的特色」：泡影的弹不做通用光球，统一用她自己的三样东西。**泡**：所有弹在公共的亮芯 + 暗描边外面套一层淡紫泡膜和左上高光，到期 / 命中 / 被消时破成几颗淡紫颗粒；**眼**：千目注视在你身边睁眼、轮流开枪（凝视的延伸，被注视的压迫）；**幻影与迟疑**：幻影放空心泡（认真身）、花瓣泡停住鼓起再追你（偏执的犹豫）。其余图案（错位缺口环、正反旋、缝隙墙）也都是泡。

全部 `paranoia_combos.gd`，进公共 `g.ebullets`（判定、机器人躲避、干员消弹走同一管线）。起手前 0.55 秒聚光颗粒（`mote_in`）。

| 弹幕 | 图案与规律 | 怎么躲 |
|---|---|---|
| 千目注视 | 7 只眼在你身边 280 处睁开（缺的那一格在她那侧），0.8 秒后顺时针轮流朝你当时的位置开枪，两圈共 14 枪 | 一直走动，枪都落在身后；缺口那格就是冲向她的路 |
| 环流狙击 | 3 轮 5 向扇（间隔 0.24），每轮重新瞄准你当时位置 | 一直横移，中间那发打空 |
| 镜影齐射 | 真身与每个幻影各放 3 轮 3 向自机狙；只有真身的是实心弹，幻影放的是空心泡（不判定） | 看谁放实心弹认真身（docs/142b 当时没做的「幻影放空弹」） |
| 偏执双旋 | 8 轮 12 发环，正反交替转，交织成菱形格 | 菱形格的空当随时间放大，走斜线 |
| 无声波环 | 2 道 18 发泡环，缺口约 1.2 弧度，第一道缺口朝你、第二道错开 0.95；以 80 慢慢鼓出，0.45 秒后每秒 +260 加速到 280（用户 10-27「打出去以后加速」） | 慢的那段看清缺口、站进去，连穿两道错位缺口 |
| 侵蚀帘幕 | 2 排横向弹墙向前推进，留 120 宽的缝；第一道缝在你当前横向位置，第二道向较宽一侧错开 170 | 先站在缝里，再横移 170 |
| 群愿回响 | 2 朵五瓣花，按花瓣速度散开，1 秒后全部停住 0.5 秒（弹芯闪），再各自对准你当时的位置射出 | 停住时离开原地 |

弹体分三级：小 r6（×0.34 e.dmg）、中 r9（×0.42）、大 r12（×0.5），侵蚀 0.15。专属色：`enemies.json` paranoia 加 `bcol_core`（淡紫弹芯，不用白，避免满屏白点）与 `bcol_outline`（深紫外描边），沿用公共 Boss 弹绘制的「芯 + 暗描边」，外面再套判定半径 +6 的泡膜（2 像素膜 + 白高光，1 倍画面可见）。同屏上限 200 发。红 / 洋红仍只给危险预警。

## 3i. 幻象冲撞动态（10-28 用户「冲锋只是平移」）

预告期幻象渐显并上下浮动；最后 0.35 秒后退 26 像素蓄势、沿冲刺方向压扁并抖动；起冲时身后一圈泡沫迸开（swing 音）；冲刺中本体沿方向拉长 1.3、垂直抖动，身后 4 个渐淡缩小的残影，两侧泡沫尾流。判定不变。

## 3e. 用户 10-27 第三轮：光束蓄力 / 消散、独有的非弹幕招、伤害旋钮

- **凝视蓄力与消散**：预警期中线从 1 像素长到半宽的 0.6、亮度递增，发射点颗粒向内收；结算瞬间沿线短闪（bfx_flash）；光束 0.2 秒张开、保持到结算后 0.8 秒；结束 0.2 秒变细收拢，同时整条线碎成颗粒散开（mote_burst）。判定只到保持段结束。
- **幻象冲撞**（非弹幕，泡影独有，本作改编，取「幻象」设定）：两只半透明冷色的她在队长两侧现形，沿两条穿过队长当时位置的交叉通道（长 780、半宽 34）先后冲过去；第二只晚 0.6 秒、通道与第一条垂直。每条通道预告 1.1 秒（暗红低填充 + 泡沫边 + 流动箭头），冲速 900，碰到算一次（e.dmg × `boss/paranoia_rush_mult` 1.0，侵蚀 0.3），冲到头碎成泡。离开两条通道即可；交点处最危险。并入 4 组连段（见 §2），主动攻击 15 招。
- **单发伤害旋钮** `boss/paranoia_bullet_mult`，缺省 0.8，乘在本文新增弹幕的每发伤害上（凝视、呼号、泡影环、叠影等原招不受影响）。云端测完再定。
