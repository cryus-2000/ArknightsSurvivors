## 1. 定位与原则

**类幸存者 + 集成战略 Roguelite。** 当前阶段不扩角色、Boss、地图数量，先做出一套**能稳定产出不同 Build、以后加干员不用改底层**的框架。

设计原则（框架第 1 节）：

1. 保留《水月与深蓝之树》的名称、世界观和机制特色；敌人、干员造型原创。
2. 战斗规则完全服务于类幸存者玩法，不照搬原作数值。
3. 一个角色要能形成多种 Build；Build 靠机制联动，不靠固定套装。
4. 新干员加入时不改商店、藏品、事件、成长等公共系统。

**最终设计哲学**：角色提供 Build 起点 → 技能分支决定方向 → 藏品连接机制 → 商店修正随机 → Boss 完成质变 → 灯火制造风险 → 排异反应改变规则 → 结局决定最终挑战。

## 2. 核心循环与单局结构

移动走位 → 自动攻击 → 击杀得经验 → 升级强化 → 精英 / 箱子得藏品 → 攒源石锭 → 商店调整 Build → Boss 给核心成长 → 灯火持续施压 → Build 成型 → 最终 Boss → 结算 / 解锁。

单局约 10 分钟，**单张地图的 Vertical Slice**，暂不做节点地图。

| 阶段 | 时间 | 玩家的问题 | 当前内容 |
|---|---|---|---|
| Phase 1 Discovery | 0:00–3:30 | 这局我要怎么玩？ | 基础升级、首批藏品、1:40 第一商店、2:00 起远程怪和大群、2:30 起黑潮缩圈 ✅ |
| Phase 2 Commitment | 3:30–7:00 | 要不要继续强化这条路线？ | 3:30 第一个 Boss、5:30 第二商店、精英增加 ✅；Boss 核心奖励 ⬜ |
| Phase 3 Mastery | 7:00–10:00 | 我的 Build 已经启动了 | 7:00 第二个 Boss、8:40 第三商店、高密度 ✅；升华藏品、排异反应 ⬜ |
| Phase 4 Exam | 10:00 | Build 真的成型了吗？ | 最终 Boss「偏执泡影」✅ |

现有节奏细节（✅）：精英每 60 秒（高难度 45 秒）；补给箱每 35–50 秒，15% 是箱形恐鱼；大群每 2 分钟（Boss 在场时暂停）；普通海嗣存活 35 秒进化（软 DPS 检查）；黑潮 2:30 起每 90 秒预告并收缩，圈外掉血、流失灯火、叠神经损伤。

## 3. 角色成长（四层）

### Layer 1 基础成长 ✅
升级三选一：伞击伤害 / 范围 / 频率、触手、技力、闪避、生命、移速、拾取、自愈、减伤、护灯。只保证稳定成长，**不是 Build 本身**。

### Layer 2 水月本体 ✅
| 部分 | 设计 |
|---|---|
| 伞击（特性） | 自动扇形挥砍，扫到的全部命中，物理 |
| 闪避（特性） | 基础 25% |
| 天赋一 创伤性癔症 | 伞击后触手追击其中生命最低的敌人，60% 额外法术伤害 |
| 天赋二 反移情（精一） | 附近有半血敌人时伤害 +22%；击杀回复 1%（每秒上限） |
| 精一 Lv.10 / 精二 Lv.20 | 解锁 S2 / S3；精二三选一模组（X 分裂创伤 / Y 嗜血回响 / α 深渊拖拽） |

### Layer 3 技能 🔶
S1 唤醒（Lv.3）、S2 囚徒困境（Lv.10）、S3 镜花水月（Lv.20）按等级自动解锁、自动释放 ✅。
**要调整**：现在的进阶是线性的（进阶 I → 进阶 II）。框架要求改成**互斥分支**，选一条后后续强化只加强这条：

```text
S1 唤醒      ├─ A 伞击爆发（现「创伤扩散」方向）  └─ B 触手追击（现「深层唤醒」方向）
S2 囚徒困境  ├─ A 高速连斩（现「双重困境」方向）  └─ C 束缚控制（现「无解困境」方向）
S3 镜花水月  ├─ A 全向斩击（现「倒影」方向）      └─ E 深海幻境（低灯火强化，新）
```
（分支与流派字母对应第 4 节；具体内容在 P1 设计。）

### Layer 4 藏品（见第 6 节）

### 武器 ✅（已定：保留，收编进流派）
v0.8 的三种武器（最多 3 种、各 5 级）保留，但不当作独立的「六武器系统」扩展，而是作为流派组件，带 Tag 进入 Build Profile：

| 武器 | 归属 | Tag |
|---|---|---|
| 支援无人机（子弹 → 持续激光 → +导弹 → 双机 → 强化） | 援护 / 指挥副系统 | support、summon、ranged |
| 海嗣触须阵 | B 触手 / 猎杀，Lv.3 起兼顾 C 控制 | mizuki_tentacle、arts、control |
| 潮汐弹（反弹） | A 伞击 / 连锁清怪 | arts、on_hit、basic_attack |

无人机手感（2026-09-24 调整）：激光改为持续 0.9 秒的光束，跟随最近的敌人平滑转向，每 0.1 秒结算；导弹发射后急加速到高速并保持，目标死亡时改追导弹附近的敌人，直到命中。

## 4. Build 系统

**Tag + Trigger + Synergy Engine**，不用"集齐三件"的套装。原有的 5 个「组合」取消 ⬜。

| 流派 | 引擎 | 特点 / 弱点 | 藏品储备（见 08） |
|---|---|---|---|
| A 伞击 / 创伤 | 攻速 → 更多伞击 → 更多命中 → 创伤 / 范围 → 连锁清怪 | 清杂强、要贴脸 | 27 件，充足 |
| B 触手 / 猎杀 | 伞击触发触手 → 打低血 → 击杀 → 再触发触手 / 技力 | 伞击变成触手启动器 | 8 件，**偏少**，靠技能分支补 |
| C 控制 / 技能循环 | 束缚晕眩减速 → 对受控目标额外效果 → 击杀回技力 → 更频繁 S2/S3 | 需要启动时间 | 27 件，充足 |
| D 反移情 / 收割 | 敌人进低血 → 反移情强化 → 斩杀 → 击杀回复 → 连锁 | 有明显启动点 | 9 件，**偏少** |
| E 深蓝 / 低灯火 | 主动维持低灯火 → 换取更高收益 | 本作最有辨识度，高风险 | 9 件，**偏少**，需排异反应配合 |
| 援护 / 指挥（副系统） | 援护攻速、击杀触发、与控制 / 技力联动 | 暂不作为主流派 | 56 件 |

平衡原则：每个流派都有优势、弱点、启动时间和擅长的敌人；不允许一个流派清杂、Boss、生存、成型速度全都最强。

**判断标准**：不同的局，伤害来源占比应该明显不同（伞击主导 / 触手主导 / 技能控制主导 / 收割主导 / 低灯火主导）。如果每局都是「伞击 55%、触手 25%、技能 20%」，说明 Build 系统失败。

## 5. 援护干员 ✅

Lv.5 / 15 / 25 招募，最多 3 名，每名最高 Lv.3，原创通用造型。定位是**辅助 Build 的副系统**。

| 职业 | 作用（v0.8） |
|---|---|
| 狙击 | 远程单体，优先精英；命中流血 |
| 术师 | 火球，命中爆炸 |
| 医疗 | 每 3 秒回复水月 3% 生命（绿十字、治疗光线） |
| 辅助 | 减速光环 + 两发追踪法术 |

攻击动作按美术 V5：4 帧、第 2 帧出手。

## 6. 藏品系统

藏品负责**改变规则、连接系统**，而不是单纯「攻击 +10%」。好藏品应该增加 Trigger、改变技能行为、连接两个系统、改变资源用途或改变风险收益。

| 项目 | 状态 |
|---|---|
| 原创藏品全部删除，改用原作藏品 | ✅ 已定；代码里仍有原创藏品 🔶 |
| 262 件逐件改编、等级、流派、Tag | ✅ 见 08 |
| 首批 62 件（覆盖五条流派） | ⬜ |
| 护盾藏品 6 件（药枚为前置，已定保留前置） | ✅ v0.8；7:00 前在藏品箱和商店里更容易出现（药枚 55%、其余 35% 优先排入） |
| 等级：基础 131 / 稀有 29 / 核心 35 / 升华 13 / 遭诅古物 8 / 结局 8 | ⬜ 实装 |

成型节奏：1 件看出方向；2–3 件引擎开始工作；4–6 件流派成型；核心 / 升华带来质变。

## 8. 商店与经济

**现状 ✅**：商人 1:40 / 5:30 / 8:40 出现，最多停留 60 秒；**交易过一次、关闭商店后商人立刻离开**，避免走回去反复触发，之后等下一次出现。3 件藏品各 14、急救 6、灯油 5、刷新 3。源石锭来自箱子、恐鱼、精英、Boss。

**按框架调整 ⬜**：

| 商店 | 职责 | 商品倾向 |
|---|---|---|
| 第一商店 | Build Discovery | 基础藏品、流派起点、通用生存 |
| 第二商店 | Build Fixing | 当前 Build 相关 + 通用 + 完全随机；Soft Steering 只轻微提高相关 Tag 权重 |
| 第三商店 | Build Finalisation | 高阶联动、生存补强、Boss 准备、风险交易 |

- 固定：3 个藏品槽 + 急救 + 灯油 + 刷新；可能出现特殊交易（灯火交易、生命交易、遭诅交易、赌博交易）。
- 刷新费用逐次提高，下一个商店重置。
- 经济目标：每次商店都要做选择——不能全买，也不能什么都买不起。

## 9. 灯火与排异反应

**灯火（v0.8 已重做）✅**：满值 100，约 120 秒耗尽。

| 状态 | 框架 | 当前实现 |
|---|---|---|
| 高灯火 | 正常 | ≥70「充盈」：技力 +30%、拾取 +20% |
| 中灯火 | 环境开始异常 | ⬜ 还没有效果 |
| 低灯火 | 敌人强化 + 排异风险 | <30：敌人移速 / 伤害 ×1.2，水月受伤 ×1.3；排异 ⬜ |
| 0 灯火 | 深海危险状态 | 每秒掉 3 点生命 |

另外：灯光照到的敌人受伤 +25%；滑动者撞击、黑潮会扣灯火；灯油来自掉落和商店。
**基本规则永远是「低灯火有风险」**；E 流派不是取消惩罚，而是让风险变得值得。

**排异反应 ⬜**：不做「攻击 -10%」这种数值惩罚，而是**改变玩法**——移动方式、视野、攻击行为、防御、技能循环。部分 Build（尤其 E）可以从排异反应中获益。04 里的四种（血肉畸变、视野侵蚀、迟滞、共鸣）按这个原则重新设计。

## 11. 难度 🔶

11 级逐级解锁 ✅。框架要求高难度**优先改变决策**（敌人压力、资源压力、灯火压力、精英频率、Boss 机制容错），少用纯加血。现有等级里「暗潮（敌人生命 +15%）」「巨影（Boss 生命 +30%）」「深蓝之树（生命攻击 +20%）」偏数值，之后替换成改变决策的规则 ⬜。

## 12. 结局与局外成长 ⬜

- 结局由关键藏品 / 事件决定，只影响最终阶段：偏执泡影、伊莎玛拉、伊祖米克……结局藏品不进随机池。
- 局外成长后做：新干员、新藏品池、新结局、新难度、图鉴、美术解锁；不做「永久攻击 +100%」。

## 13. 技术架构（框架第 27–33 节）⬜

全部 **Data Driven**，禁止大量 `if player == Mizuki`。P0 要建立：

| 系统 | 作用 |
|---|---|
| Combat Event System | 统一事件总线：AttackStarted、Hit、DamageDealt、DamageTaken、EnemyKilled、SkillStarted/Ended、StatusApplied、Dodge、LightChanged、SupportAttacked、BossKilled |
| Modifier System | Stat / Trigger / Status / Spawn / Rule 五类修正 |
| Stat System | 统一计算顺序 Base → Flat → Additive% → Multiplicative → Override；任何藏品技能都不能直接改最终数值 |
| Tag System | 藏品、技能、伤害来源都带 Tag |
| Build Profile | 实时记录 Tag 权重、藏品、技能分支、灯火、援护、生存；用于商店倾向、Boss 奖励、统计 |
| 数据结构 | OperatorData / RelicData / EnemyData / BossData |

新干员只需要：OperatorData、基础攻击、技能、专属 Tag、动画特效。如果还要改公共系统，说明架构失败。

现状：`game.gd` 单文件约 5000 行，属性散落在几十个变量里，藏品效果写在 `match id` 里直接改数值，需要按 09 的方案重构。

**测试标准**：自动平衡测试要统计最终 Tag、伤害来源占比、藏品 Pick / Win Rate、成型时间、Boss 死亡率、平均灯火、援护伤害占比、死亡原因。

## 14. 表现与美术 ✅

- 像素风，美术 ×2、最近邻；深海蓝绿为主，灯火暖橙点缀。2.5D 遮挡、前景虚化、景深、掉落弹跳；大型景物阻挡移动。
- 打击感：顿帧、震屏、受击分级反馈、血条残影、低血心跳。
- 界面：标题、难度、图鉴、设置、属性面板（Tab）、结算；HUD 有灯火刻度、技能、援护、藏品、小地图、大群 / 黑潮 / Boss 演出。
- 美术 V5 已接入：援护攻击动作、Boss 移动循环。三架无人机素材已收到（v0.8 的无人机武器在用）。
- 分工：Codex 在 `codex/art` 分支出图，交到 `art/incoming/`，Claude 接入。
