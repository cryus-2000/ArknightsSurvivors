## 1. 概述

| 项目 | 内容 |
|---|---|
| 类型 | 类幸存者（Vampire Survivors like）+ 集成战略肉鸽 |
| 主题 | 《明日方舟》集成战略「水月与深蓝之树」 |
| 主角 | 水月（特种 · 伏击客），目前唯一可用干员 |
| 引擎 | Godot 4，2D 像素，美术像素 ×2 显示，2.5D 遮挡与景深 |
| 平台 | PC（Windows） |
| 一局时长 | 约 10 分钟，击败最终 Boss 即通关 |
| 操作 | WASD / 方向键移动，攻击和技能全部自动 |

**核心循环**：在深海里移动走位，水月自动挥伞清怪 → 捡经验升级，三选一强化水月 → 打精英和宝箱拿藏品、攒源石锭找商人 → 守住不断熄灭的灯火 → 撑过大群和 Boss，最后击败最终 Boss。

**设计原则**：机制致敬原作，数值按类幸存者重做；名称尽量用官方中文名；敌人、干员造型原创，不复刻官方立绘。

## 2. 一局的时间轴（已实现）

| 时间 | 事件 |
|---|---|
| 0:00 | 开局，只有骨海漂流体、底海滑动者 |
| 每 35–50 秒 | 刷一个补给箱（同时最多 3 个），15% 是箱形恐鱼 |
| 每 60 秒 | 出现一个精英（难度「猎群」及以上改为 45 秒） |
| 1:40 / 5:30 / 8:40 | 商人出现，停留 60 秒 |
| 2:00 起每 2 分钟 | 「大群来袭」：从四周包围涌来（Boss 在场时暂停） |
| 2:00 | 加入固海凿石者（远程）；精英池加入掠海漂移体 |
| 2:30 起 | 地面开始随机出现溟痕（蔓延的危险地面） |
| 3:30 | 第一个中期 Boss（从 Boss 池抽取） |
| 5:00 | 加入伊祖米克的子代；精英池加入投嗣育母 |
| 7:00 | 第二个中期 Boss（不与第一个重复） |
| 10:00 | 最终 Boss；击败即通关 |

- 刷怪速度随时间线性上升；Boss 在场时刷怪减半。同屏上限约 450。
- 普通海嗣存活 35 秒会**进化**：生命 ×1.8、体型变大、更快更痛，经验 ×2。

## 3. 水月

### 3.1 基础攻击与天赋（已实现）
| 部分 | 设计 |
|---|---|
| 伞击（特性） | 自动朝最近的敌人扇形挥伞，扫到的全部命中，物理伤害 |
| 闪避（特性） | 基础 25% 闪避 |
| 天赋一 · 创伤性癔症 | 伞击命中后，触手追击其中生命最低的敌人，造成 60% 额外伤害（法术） |
| 天赋二 · 反移情（精英化一） | 附近有半血以下敌人时伤害 +22%；击杀回复 1% 最大生命（每秒上限 5%） |

### 3.2 技能：按等级自动解锁，自动释放（已实现）
| 技能 | 解锁 | 效果 | 进阶 I / II |
|---|---|---|---|
| S1 唤醒 | Lv.3 | 挥伞数次后下一击强化：伤害 ×3、范围扩大，触手同样强化 | 创伤扩散（Lv.5，命中处范围冲击）/ 深层唤醒（Lv.9，额外 4 条触手） |
| S2 囚徒困境 | Lv.10（精英化一） | 周期进入 12 秒高速状态：挥伞频率翻倍，触手目标 +1 并束缚 | 双重困境（Lv.12，额外斩另一方向）/ 无解困境（Lv.16，触手连击、束缚传播） |
| S3 镜花水月 | Lv.20（精英化二） | 周期进入 14 秒特殊形态：范围扩大、三方向斩击、短暂晕眩 | 倒影（Lv.22，反方向复刻攻击）/ 镜花水月·深海（Lv.26，全方向、触手 +2、周身减速） |

技能进阶以「进阶卡」形式混进升级选项（每次最多一张，出现率 45%）。

### 3.3 精英化与模组（已实现）
- **Lv.10 精英化一**：解锁 S2 和天赋二，播放解锁演出。
- **Lv.20 精英化二**：解锁 S3，并三选一模组：
  - X「分裂创伤」：触手追击目标 +1
  - Y「嗜血回响」：反移情提升到 +35%，击杀回复翻倍
  - α「深渊拖拽」：触手把目标拖向水月；技能期间追击目标再 +2

### 3.4 升级成长项（已实现）
每次升级三选一，项目各有次数上限：伞击·锋（伤害）、伞击·展（范围）、伞击·迅（频率）、触手·蚀、技力、水影（闪避）、坚韧（生命）、轻盈（移速）、感知（拾取）、自愈、硬化（减伤）、护灯（灯火消耗）。

**计划中**：06 提议升级卡池混入「藏品卡」，待定。

## 4. 援护干员（已实现）

在 Lv.5 / 15 / 25 时，升级改为「招募援护干员」三选一。最多 3 名，每名最高 Lv.3。造型为原创通用干员，跟随水月。

| 职业 | 作用 |
|---|---|
| 狙击 | 远程单体射击，优先打精英和血最厚的敌人 |
| 术师 | 法术弹，命中后小范围爆炸 |
| 医疗 | 每 3 秒回复水月 3% 最大生命 |
| 辅助 | 水月身边的敌人减速 35%，并每秒受少量伤害 |

## 5. 灯火（已实现）

- 满值 100，约 150 秒自然耗尽（护灯、藏品可减缓）。
- 灯火是真实光源：场景整体偏暗，只照亮水月周围。
- **灯火低于 30**：敌人移速和伤害 ×1.2，水月受到伤害 ×1.3，音乐变化。
- **灯火为 0**：每秒失去 3 点生命。
- 补充：灯油掉落（普通怪 2%、补给箱 30%、精英必掉）、商人出售灯油。

**计划中**：受伤扣灯火（原作机制，凝固灯油、崇圣灯油依赖它）；排异反应与灯火挂钩（见第 9 节）。

## 6. 经济：源石锭、补给箱、商人（已实现）

| 来源 | 源石锭 |
|---|---|
| 补给箱 | 3–6，30% 附带灯油 |
| 箱形恐鱼（伪装的补给箱，15%） | 10 + 藏品箱 |
| 精英 | 3–5 + 藏品箱 + 大罐灯油 |
| Boss | 20 + 藏品箱 + 大量经验 |

商人一局出现 3 次，每次停留 60 秒，靠近自动打开商店：

| 商品 | 价格 |
|---|---|
| 藏品（3 件随机） | 14 |
| 急救包（回复 40% 生命） | 6 |
| 灯油（灯火 +50） | 5 |
| 刷新 | 3 |

其他掉落物：经验结晶、磁铁（吸取全屏经验）、回复包；精英和 Boss 必掉其中之一。

## 7. 藏品

### 7.1 已定方向
- **原创藏品全部删除**，改用原作「水月与深蓝之树」的藏品，保留官方名称和原意，效果换算到本作系统。
- 改编总表见 **08_relic_adaptation**：262 件中 A 原样可用 38、B 换算改编 159、C 需新机制 27、D 不适用 38。
- **首批 53 件（★）** 先做进游戏，其余 A/B 级逐步补充。
- 获取途径：精英 / Boss / 箱形恐鱼掉落的藏品箱（三选一），商人购买。

### 7.2 现状
- 代码里仍是 17 件原创藏品和 5 个原创组合（灯芯护罩、发光水母标本、涨潮螺壳等）。**接入首批原作藏品时一并替换**，避免中途藏品池为空。
- 原「组合」机制要改为致敬原作的「启示」或国王套装式的集齐加成，具体待定。

### 7.3 待定
1. C 级新机制先做哪个：护盾、排异反应、启示、结局分支
2. 负面藏品（遭诅古物）怎么获得：是否用「拿一件负面换一件超稀有」
3. 藏品稀有度与掉落权重

### 8.2 Boss（已实现）
| Boss | 登场 | 机制要点 |
|---|---|---|
| 塑路者 | 中期池 | 周期冲锋；每受击 10 次召唤碎片 |

| "偏执泡影" | 10:00 最终（结局一） | 悬浮，多目标侵蚀攻击 |

### 8.3 负面状态（已实现）
- **侵蚀**：受击后额外持续掉血。
- **神经损伤**：累积条满 100 时僵直 1 秒，并受到 10% 最大生命伤害。
- **溟痕**：蔓延的地面，站上去持续掉血并叠神经损伤。

## 10. 难度（已实现）

共 11 级，逐级叠加；通关当前最高难度解锁下一级。

标准 → 暗潮（敌人生命 +15%）→ 浊流（敌人攻击 +15%）→ 昏灯（灯火消耗 +25%）→ 猎群（精英间隔 -25%）→ 拮据（源石锭 -30%）→ 躁动（敌人移速 +10%）→ 潮涌（大群 +40%）→ 巨影（Boss 生命 +30%）→ 负伤（初始生命 -20%）→ 深蓝之树（敌人生命与攻击再 +20%，Boss 攻击 +25%）

## 11. 表现与美术

- 像素风，美术像素 ×2，最近邻采样；深海蓝绿主色，灯火暖橙点缀。
- 2.5D：场景物前后遮挡、前景虚化剪影、远景水雾景深、掉落物弹跳。
- 打击感：顿帧、震屏、受击红闪、血条残影、低血心跳、首次跌破 30% 生命时短暂慢动作。
- 界面：标题、难度选择、图鉴、设置、结算统计；HUD 有灯火、技能、援护、藏品栏、小地图、大群和 Boss 演出。
- 音频：灯火主题 BGM，全套音效。
- 美术分工：Codex 在 `codex/art` 分支制作，交到 `art/incoming/`，Claude 接入。规格见 03 / 05 / 07。
- 美术 V5（2026-09-24 接入）：援护干员攻击动作（第 2 帧出手）、9 种 Boss 与偏执泡影二阶段的移动循环。三种无人机（子弹 / 激光 / 导弹）已收到，等无人机玩法设计好再接入。
