# 303 终结技伤害现状与上调（11-07）

用户 11-07：「终结技的伤害现在是不是有点低」。协调人当晚转达：用户睡前要求不等他决策，由数值自己定档、改缺省值、配对验证。

分支 `claude/ult-dmg-audit`，基线 main a52d2abfa。

## 结论

1. **偏低的是全体，不是个别干员；偏低的是清怪和精英，不是 Boss。**
   - 次数达标：活到 8 分钟的局一局放 3.6–3.7 次（目标 3–4）。
   - 清怪不行：每次只清掉出招时屏内普通小怪的 28–40%，测试台口径是「范围内 98% 清光」。
   - 精英约 47%：被 50% 的单次上限卡住。
   - 中期 Boss 每次 17–22%，最终 Boss 每次约 6%（设计值）。
   - 终结技只占全队伤害的 3.5–4.5%。
2. **原因是 11-05 合入的三项伤害侧减负叠在一起**（f3aacda0f「后期四开关」等，见 docs/248 §8、docs/250）。近战打击感、后期特效控制、各人转平面画面这几轮都只改画面，没有动伤害。
   - P3 `shape_lv/p3_on`：终结技对小怪只在**队长**周围 300 内全额，380 外 × 0.3。
   - 清一圈 + 留余烬 `ult/rw_ring`：**作用中心**周围 300 外的小怪这次最多掉 60%。
   - 精英单次上限 `ult/rw_cap`：精英每次最多掉 50%。
   - 前两项的圆心不同：选落点 / 方向类招式，作用中心离队长 260–520，两个圈几乎不重叠，大部分命中的小怪被打到只剩 0.3 倍。维什戴尔、逻各斯、塞雷娅、斯卡蒂、艾雅法拉清屏只有 23–28%。
3. **定档 V3**：三项全关，中期 Boss 份额 `ult/boss` 0.28 → 0.36（× 1.3）。保留降频 `ult/rw_freq`，最终 Boss 份额 0.06 不动。
   - 清屏 28–29% → 87%，精英 47% → 67–70%。
   - 胜率 m0 58.3 → 56.5、m18 64.3 → 70.2，两档变化都不到 10 个点，不下变易 / 变难结论。
   - 最终 Boss 每次 5.6–5.8%，没有秒最终 Boss；Boss 战用时没有变短（偏执泡影中位 53 → 47–52 秒）。

## 1. 量法

- 遥测：`ult.gd` 新增 `stats.casts`，记每次终结技的战果，只统计，不影响玩法。
  - 内容：时刻、队长、实际掉血、小怪 / 精英 / Boss 击杀、精英掉血比例、每个 Boss 这次打掉最大生命的比例、出招时屏内小怪只数。
  - 批跑加 `--ultcasts` 才写进 BALANCE；缺省不写，金样不变。
- 现状矩阵（GCP，cloud-results/ud1107-A0 / A1b / A2b）：
  - `--preset solo`（20 名队长单人开局，自然招募）× 4 seed；
  - 高手 / 普通机器人 × m0（`--tier=0 --tide=0`）/ m18（`--tide=0 --meta=18`）；
  - 每组 320 局，脚本错误 0。
- 配对验证（cloud-results/ud1107-V0 / V3，GCP）：
  - `--preset starts` 7 编队 × 8 seed × 安慰剂 0 / 1 / 2，高手机器人；
  - 每档 168 对，按（编队, seed, 安慰剂）配对；
  - 候选值用 `--bal=` 在同一提交 8e01f8da0 上测，最终缺省值与测试值相同。
  - V1 / V2 两档因 GCP 配额满，改在 Claude 云端例行任务跑（cloud-results/ud1107-V1c-* / V2c-*），回来后补在 §4。
- 工具：`python tools/ult_dmg_audit.py --fetch --arms A0=cloud-results/ud1107-A0 --by-op A0`（现状 / 每人表）、`python tools/ult_dmg_pair.py cloud-results/ud1107-V0 cloud-results/ud1107-V3`（配对）。
- 口径：
  - 清屏 = 这次击杀的普通小怪 / 出招那一刻屏内普通小怪（上限 100%）；
  - 精英 = 罩到的精英合计被打掉最大生命的比例；
  - Boss 只算打到的那几次；
  - 时段：前期 < 4:00、中期 4:00–8:00、后期 ≥ 8:00。

## 3. 三档调法

| 档 | 改动 | 清屏 | 精英 | 胜率影响 | Boss 战 |
|---|---|---|---|---|---|
| 一 | 只关 P3（`shape_lv/p3_on` 0） | 约 55% | 约 47%（上限还在） | 现状矩阵里看不出 | 不变 |
| 二 | 三项伤害侧减负全关 | 约 86% | 约 70% | 现状矩阵 m0 +10、m18 +4（单份，只看方向） | 中期 Boss 份额 0.28 不变 |
| 三（**采用**） | 档二 + 中期 Boss 份额 × 1.3（`ult/boss` 0.36） | 87% | 67–70% | 配对 m0 −1.8、m18 +6.0（都 < 10 点） | 最终 Boss 份额不变，用时不变短 |

- 没有选「全体伤害 × 1.3 / × 1.5」：小怪伤害是按小怪自身血量算的（`ult/minion_hpk` 1.5，docs/199 §5.11），单发已经够打死；清不掉是因为被两个圈截断。乘倍率解决不了圈外截断，只会让圈内溢出。
- 精英仍有「重伤不死」保底（`ult/elite_floor` 留 10%），每次 67–70%，所以用户 11-05 说的「精英一来开个终结技全杀了」不会回来；降频保留，次数不变。

## 6. 待办 / 没做

- 安洁莉娜清屏 66%，可加 `ult/dmgk_angelina` 或放大判定，需要按人跑 `tools/ult_bench.py`。
- 中期 Boss 命中时 17–26%：在 bench 的命中口径下应接近 36%，实战里罩不到 Boss 的方向记 0，样本也少。要更「打 Boss 一大截」，可以让机器人 / 自动瞄准在 Boss 在场时优先罩 Boss（改瞄准，不改伤害）。
- 普通机器人一局只放约 1 次，4 分钟前就死了，看不出中后期的终结技表现。
