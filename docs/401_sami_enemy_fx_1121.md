# 401 · 萨米怪物攻击特效：方案与试点（2026-11-21）

> 协调人 11-21 派活（用户定）：萨米怪物 / Boss 的攻击特效，先出方案（每招一行、贴近原作），再挑 2–3 种普通怪 + 1 个 Boss 做试点并录演示。国度特效暂停，本篇不碰国度本体。
> 分支 `claude/sami-enemy-fx`（从 `claude/sami-enemy-data` 0a05d8fd1 拉出）。不碰水月；theme_parity 结果见 §6。

## 0. 结论

- **原作参照是真数据，不是凭印象**：从原作客户端热更新包里拆出全部萨米敌人的特效预制体（粒子系统的起始色、颜色曲线、尺寸、寿命、发射数、形状、贴图），每招按原作配色和结构还原。来源与工具见 §1。
- **原作萨米特效分四个色系**（§2.2）：坍缩体是「白 → 钢蓝灰 → 黑」，利刃系是「黑 + 深红」，冰雪系是「青 / 冰蓝 / 白」，王庭系是「红黑 / 金橙」。原作坍缩系特效本身就是黑色的（例如施法者的法术弹起始色是 0.02 的黑菱形），跟国度的黑烟同一套语言。
- **做法**：主形用 pixelfx 烘焙帧条（每件一条，几 KB）；火花、碎屑、余烬、暗烟用运行时像素颗粒（Noita 式，2×2 像素对齐，按出生时刻解析计算位置）。每招元素 ≤ 3 种。预警不改，沿用全游戏的洋红预警语言。
- **试点**（§4）：染污躯壳（爪击 + 受击暴冲）、歪曲施法者（黑针法术弹）、冰爆源石虫（死亡冰爆）+ 邪魔的利刃 6 招。演示 `F:\sami_enemy_fx_ref\sami_enemy_fx_pilot_v2.mp4`（§8 退回修改后的版本）（46 秒，30 帧，原速原色，静音）。
- **自检后要说清的两点**（§5）：① 演示里的怪物本体还是水月占位贴图（萨米像素帧条只在 F 盘、没接进游戏）；② 当前分支萨米地图是暗夜光照，原作的黑色主形在暗地上读不清，施法者黑针已经加了冰蓝亮边；躯壳、利刃这类黑系特效等地图提亮后要再看一遍。

## 1. 原作参照怎么来的（可复现）

- **包**：明日方舟 CN 客户端 2.7.91，热更新 `26-11-13-06-37-23-89286612`（`https://ak.hycdn.cn/assetbundle/official/Android/assets/<热更新号>/hot_update_list.json` 列清单），敌人特效在 `pkgrps/btl_pfb_fx_enemy_0 … 20.ab`（21 个，共 58 MB）；借用敌人的特效是单独的包 `battle/prefabs/effects/{snslime, icebrk, snmage, frostd}.ab`。先例与授权口径同 docs/113 §9：用户 10-15 确认（公司授权）可以下载作内部参照。**原件与导出只放 `F:\sami_enemy_fx_ref\`，不进 git、不进包。**
- **拆包**：包的块压缩是方舟自己的 LZ4 变体（标志位写的是 LZHAM，UnityPy 打不开）。`tools/sami_fx_ref/akup.py` 给 UnityPy 补了解压函数（token 高低半字节互换、匹配偏移大端），之后可以直接读 ParticleSystem / Material / Texture2D。
- **导出**：`python tools/sami_fx_ref/akfx_dump.py 'effects/(enemy_sm|snslime|icebrk|enemy_uamord|enemy_mhshep|snmage|frostd)'` → `F:\sami_enemy_fx_ref\prefabs\prefabs.json`（180 个预制体的层级、每个粒子的参数、材质贴图名）；`akfx_sum.py [过滤词]` 出逐粒子摘要。每个预制体一行的色系摘要进仓库：`tools/sami_fx_ref/digest.txt`。共享贴图在别的包里，没拉；粒子参数和专属贴图已经够判断形状和配色。
- **编号对照**：躯壳 smsbr、施法者 smwiz、构造体 smdrn、木裂战士 smwar、巨壳藤蔓 smbox、利刃 / 游荡者 smgrd、意志 smdeer、陷落 / 空洞雪祀 smsha / smsha2、纠缠 / 古老藤蔓 smgia / smgia2、木裂 smlead、克雷松 smedzi、哈兰杜汗 smkght、路加萨尔古斯 smlion、王者友伴 smhond、可汗片影 smshdw（用 smkght 的贴图）。藤蔓的 Spine 编号是 smgia，所以原作里没有叫 vine 的特效。

## 2. 通用做法

### 2.1 分层

| 层 | 做什么 | 实现 |
|---|---|---|
| 预警 | **不改**：沿用 telegraph 的扇形 / 直线 / 落点圈 / 缺口环和洋红预警语言（docs/359 §2.3 的时长口径照旧） | 现有 |
| 主形 | 刀光、迸散亮团、星闪、冲击环、蓄能团：每件一条 pixelfx 帧条，1 纹素 = 2 世界像素，15 fps | `tools/pixelfx_fx/foe/ak-sami-foe.js`（part = slash / pop / star / nova / charge），`tools/sami_fx_bake.py` 烘焙 → `game/themes/sami/fx/sfx_<键>.png` + `sami_fx.json` |
| 质感 | 拉伸火花、方块碎屑 / 余烬、暗烟：Noita 式像素颗粒，按原作颜色曲线着色 | `game/themes/sami/mech/mech_fx.gd`（运行时，不抽玩法随机数） |
| 专属弹体 | 施法者黑针、Boss 专属弹（利刃刃片等）：代码画，设 `own_draw` / `sfx_own` 让通用弹体、光学拖尾、Boss 弹拖尾都跳过 | 同上 |

一招的元素控制在 ≤ 3 种：主形 1 件 + 颗粒 1–2 种。例如躯壳爪击 = 月牙刀光 + 钢蓝拉伸火花；冰爆 = 冲击环 + 冰屑 + 灰白烟。

### 2.3 不脏的规矩

- 白只给第 0–1 帧的热芯；颗粒按原作曲线冷却变暗、变黑后消失，不在地上积灰。
- 暗烟只在出手 / 命中处冒 3–8 团，≤ 0.9 秒散完；不铺成大片，铺大片是国度的事。
- 每招总时长 ≤ 0.6 秒（蓄能类按预警时长，≤ 1.0 秒）；同屏颗粒上限 420、帧条上限 48，超了先丢最旧的。
- 不加装饰圆圈（用户 10-13 定：攻击特效去装饰圆圈），冲击环只用在原作本来就有 huan 的招（冰爆、意志冰凌命中）。

### 2.4 性能预算（网页）

- 帧条：试点 8 张共 42 KB，全量估约 60 张、≤ 350 KB（docs/369 包体预算里算进主题包）。
- 颗粒：每颗一个三角形批（world.tb_quad / tb_line / tb_circle），一次 tb_flush 提交；位置按出生时刻解析算，不逐帧积分，没有 GC。同屏 420 颗约 840 个三角形，跟一场 Boss 弹幕同一量级。
- 帧条旋转要切画布变换，不合批：限 48 条，实测同屏通常 < 10 条。
- 网页低画质档（Cfg.quality = low）：颗粒数 ×0.5、暗烟不画（全量接入时加，试点没加）。
