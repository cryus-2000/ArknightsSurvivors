# 04 · 水月技能与藏品设计（草案 v1）

参考：水月在《明日方舟》中的特性、天赋、技能（PRTS 资料），以及「水月与深蓝之树」的灯火 / 排异反应 / 启示 / 大群机制。
原则：**机制致敬，数值和名称按类幸存者重新设计**；游戏保持全自动攻击，只控制移动。

---

## 一、水月本体：从原作到本作的对应

| 原作 | 原作效果（精二专三） | 本作设计 |
|---|---|---|
| **特性**（伏击客） | 攻击范围内所有敌人受到伤害；50% 物理/法术闪避；不易被当作攻击目标 | **伞击**是范围挥砍，扫到的全部命中；自带 **25% 闪避**（闪避时身形化作水影） |
| **天赋 1 · 创伤性癔症** | 攻击时对命中目标中生命最低的敌人追加 60% 攻击力的法术伤害；模组强化后目标 +1，并能拖拽 | **伞击命中后，触手追击其中生命最低的敌人**，造成 60% 额外伤害。触手不再是独立武器，而是水月攻击的一部分，对应你说的"雨伞挥一下，然后触手攻击" |
| **天赋 2 · 反移情** | 范围内存在生命低于 50% 的敌人时攻击力 +22%；击杀敌人回复 10% 最大生命 | 附近有**半血以下敌人时伤害 +22%**；**击杀回复 1% 最大生命**（每秒最多 5%，防止刷怪无敌） |
| **技能 1 · 唤醒** | 自动回复，攻击 7 次充能一层（可存 3 层）：下次攻击 300% 伤害，天赋倍率 ×3 | **每挥 7 次伞充能一层**，最多 3 层；强化挥砍造成 300% 伤害，触手伤害 ×3 |
| **技能 2 · 囚徒困境** | 21 秒内攻击间隔大幅缩短、攻击 +30%，天赋目标 +1 并束缚 1.3 秒 | 技力充满后**自动开启 21 秒**：挥伞频率翻倍、伤害 +30%，触手目标 +1 并**束缚** 1.3 秒 |
| **技能 3 · 镜花水月** | 30 秒内攻击范围扩大、攻击 +150%，天赋目标 +2 并晕眩；命中少于 3 个敌人时自损 12% 生命 | 技力充满后**自动开启 30 秒**：挥砍范围扩大、伤害 +150%，触手目标 +2 并**晕眩**；**一次挥砍命中少于 3 个敌人，扣 12% 最大生命**（高风险高收益，逼你往怪堆里走） |

**开局选技能**：出发前在三个技能里选一个带进这一局（同原作编队时选技能）。技力随时间和攻击自动恢复，充满后自动释放。

### 精英化与升级
升级时的选项不再是"获得新武器"，改为**水月自身的成长**：

| 阶段 | 解锁 |
|---|---|
| 初始（精零） | 伞击、闪避、天赋 1（1 条触手） |
| **Lv.10 · 精英化一** | 天赋 2「反移情」；技能伤害提升 |
| **Lv.20 · 精英化二** | **模组选择**（三选一，模仿原作 X / Y / ISW-α 模组）：<br>· **X 模组「分裂创伤」**：触手追击 2 个目标<br>· **Y 模组「嗜血回响」**：反移情加成提升至 +35%，击杀回复翻倍<br>· **α 模组「深渊拖拽」**：触手把目标拖向水月，技能期间追击目标再 +2 |

其余升级项：伞击范围 / 伤害 / 频率、触手伤害、技力回复速度、闪避率，以及原来的通用属性（生命、移速、拾取……）。

**原来的潮涌、水母**：从水月本人的技能里移出，改为**藏品效果**（见下），以后也可以作为援护干员的能力。

## 二、藏品体系（参考水月肉鸽的设计思路，名称与数值均为原创）

### 1. 灯火类（与灯火值互动）
| 名称 | 效果 |
|---|---|
| 灯芯护罩 | 灯火消耗 -25% |
| 灯油壶 | 立即点满灯火，灯油效果 +50% |
| 逆光之瞳 | 灯火低于 30 时，伤害 +30%（把"暗潮"变成机会） |
| 余烬 | 击杀精英时灯火 +20 |

### 2. 战斗类（强化伞击、触手、技能）
| 名称 | 效果 |
|---|---|
| 破碎的伞骨 | 伞击挥砍角度 +40° |
| 深渊残肢 | 触手追击目标 +1 |
| 潮汐怀表 | 技力回复速度 +25% |
| 锋利鳞片 | 所有伤害 +15% |
| 发光水母标本 | 获得环绕的发光水母（原"水母"武器） |
| 涨潮螺壳 | 每 3 秒自动释放一次潮涌冲击（原"潮涌"武器） |

### 3. 生存类
深海珊瑚（生命、回复）、咸湿的围巾（减伤）、漂流瓶（拾取、经验）、水影披风（闪避 +10%）

### 4. 海嗣类（高风险高收益，致敬"大群"）
| 名称 | 效果 |
|---|---|
| 共生囊 | 海嗣进化速度加快，但进化体掉落经验 ×3 |
| 大群的低语 | "大群来袭"的规模 +50%，每次大群结束后获得一个藏品箱 |
| 吞噬之种 | 敌人吞噬同类时，水月回复 5% 生命 |

### 5. 排异反应（负面 / 双刃效果，致敬原作）
灯火**低于 30 时，每 30 秒会被施加一个随机"排异反应"**，灯火回到 60 以上时逐个消除：
| 名称 | 效果 |
|---|---|
| 血肉畸变 | 伤害 +20%，但最大生命 -20% |
| 视野侵蚀 | 灯光范围额外缩小 |
| 迟滞 | 移动速度 -15% |
| 共鸣 | 触手伤害 +50%，但每次触手攻击扣 1 点生命 |

### 6. 组合（致敬"启示"：凑齐特定藏品触发）
保留现有的 4 个组合：深海之光、涨潮、漂流者、深渊之握。之后再按新藏品增加。
