# 331 藏品去掉数量硬上限 + 攻速生效核验（11-09）

用户 11-09 定、协调人派单。依据：「肉鸽不设数量硬上限，用爆率做软限制」（记忆 no-hard-caps）。

## 1. 软上限

`relic_fx.soft(raw, knee)`：原上限 knee 以内照旧线性；超过以后按 `knee × (1 + ln(raw / knee))` 递减着继续涨，不封顶。函数在 knee 处连续、斜率为 1。
减伤类用 `relic_fx.soft_dr(raw, knee)`：超过 knee 以后按指数逼近 100%，永远到不了完全免伤。

举例（骑士戒律·新编，每 5 源石锭 +5%）：

| 源石锭 | 原值 | 现值 |
|---|---|---|
| 30 | +30% | +30% |
| 60 | +30% | +51% |
| 120 | +30% | +72% |
| 200 | +30% | +87% |

## 3. 攻速生效核验

工具 `tools/aspd_probe.py`：调用 `tests/op_dummy_test.tscn`，用新参数 `--dummy_aspd=x` 给被测干员额外 op_aspd +x。条件：同 seed、单体木桩、队长身份、E0，攻速 +0% / +30% / +60% 各打 30 秒（复核时 60 秒）。

每局记录：
- 攻击动作开始次数 atk_n
- 平均动作时长 atk_dur
- 普攻命中帧数
- 普攻秒伤、召唤物秒伤

计数方法：atk_n 在动作被压缩以后会数漏（前一个动作没播完就开始下一次，计时不往上跳），所以主指标用普攻命中帧数，召唤物出伤的干员用召唤物秒伤。

### 3.1 结果

全员出手频率都随攻速提高。+30% 时大多在 1.22–1.38 倍，+60% 时在 1.41–1.68 倍。批跑每帧 0.066 秒，出手间隔只能取它的整数倍，所以 +30% 普遍比 1.3 倍低 3%–8%。

| 干员 | 问题 | 处理 |
|---|---|---|
| 歌蕾蒂娅 | 钩索当普攻，「锚在外面时不出手」，而飞出 / 绷紧 / 拖回三段时长不随攻速变；+60% 只快了 28% | `seg_ulpianus` 钩索 lock 时三段按 op_aspd 一起缩短。复核：+30% / +60% 命中频率 1.24 / 1.46 倍 |
| 凯尔希（Mon3tr） | 秒伤随攻速忽高忽低（队友身份 35 / 22 / 36） | 打日志看撕咬间隔：0.924 → 0.726 秒（1.27 倍），频率是对的；秒伤波动来自每一下打不打得中木桩。另外加了预防：攻击间隔短于撕咬动作时，动作和出手时刻按比例压缩、帧条同倍加快（现在的攻速下不会触发，攻速翻倍以上才用得到） |
| 铃兰、维什戴尔、水月、塞雷娅、乌尔比安 | 普攻秒伤倍率偏低（1.13–1.25 / 1.37–1.46） | 命中频率正常（铃兰 1.68 / 1.68，维什戴尔 1.33 / 1.58，水月 1.28 / 1.54，塞雷娅 1.23 / 1.44，乌尔比安 1.22 / 1.41）。秒伤低是每一下的伤害随别的机制变化（多目标分摊、弹药、余震），不是出手没变快 |

动作时长：攻击周期还长于动作时，动画按原速播放，只是两次出手之间的空当变短；周期短过动作时才按 `attack_rhythm` 压缩。这正是设计口径，attack_rhythm 快检通过。
