> 10-13 后续：§3.1「自身回复随时间提高」已按用户新设计换成入队台阶（`sustain/regen_div` 设 0，旋钮保留），见 docs/83。

### 2.3 持续消耗还是尖峰：两段式

- 云端无回复输局：死前 30–60 秒那一格的生命中位 84–94%，死前 0–30 秒 55–63%；低血（< 35%）累计只有 10–13 秒。
- 本机最后一段（死前 < 30 秒的窗口）：无回复输局承伤 **3.7% / 秒**（平时 1.5%），进入这一段时的生命多在 45–70%；来源 引痕者 25%、收割者 18%、滑动者 17%、子弹 15%、溟痕 14%——是近战怪贴身围上来的一阵，不是某个招式。
- 所以是**两段式**：前 1–2 分钟每秒净掉约 0.4%，生命从满血被磨到 50–70%；然后一阵 15–30 秒、3–7% / 秒的近身压力把剩下的血打空。
  医疗队遇到同样的一阵时生命还在 95% 上下，扛得住；无回复队已经被磨掉一半，扛不住。修复的重点是**两阵之间回得上来**，而不是削某一个尖峰。

### 2.5 艾雅法拉那组输出「反常低」

不是真的低。cloud md-t2 艾雅法拉组每秒伤害 1064 对其他组 1700，是因为它几乎都死在 5:30–8:00，而每秒伤害随时间涨（敌人生命随时间涨）——早死的组平均就低。
同一时段比：本机 Ⅷ 5:00–7:30 每秒击杀 艾雅法拉组 8.9–14.7、凯尔希组 9.2–12.9、流明组 7.5–12.8；Boss1 击杀用时 41.5 秒，凯尔希组 40、流明组 43.5（云端 md-t2：40 / 42.5 / 38）。
它输在承伤（两名法术干员打引痕者没有弱点加成，§2.2），不是输出。

## 3. 方案

诊断指向「两阵之间回不上来」：自身回复整局恒定，敌人攻击随时间涨；医疗队靠治疗把生命保持在 95% 上下，无回复队在 5:00 后每秒净掉约 0.4%。
所以主修复放在**自身回复随时间增长**（所有编队都有，医疗队大多时候满血，多出来的回复多半溢出），辅以**低血时回复药剂更常掉**（只在掉血后起作用，医疗队很少触发）。
不削医疗、不做「检测到没有医疗就补偿」的开关；两项都对所有编队一视同仁，玩家能在指南 / 属性面板 / 图鉴里看到。

### 3.1 自身回复随探索时间提高（主修复）

- 规则：主控的生命回复（干员 leader 段 regen、`regen_pct`、博士「自愈」、回复类藏品）× `1 + min(t, regen_knee) / regen_div`。
- 旋钮：`balance.json sustain/regen_div = 400`、`sustain/regen_knee = 480`。倍率 0:00 ×1、4:00 ×1.6、6:00 ×1.9、8:00 起 ×2.2。`regen_div = 0` 关闭。
- 量级（最大生命 150–170 时）：维什戴尔 regen 1.1 → 6:00 约 2.1 生命 / 秒（≈1.3% / 秒），接近流明队友在 5:00–9:00 的平均治疗；不到医疗压力最大时的 2–2.4% / 秒。
- 配套：敌人攻击时间曲线 `enemy/dmg_div` 420 → 360（8:00 ×2.14 → ×2.33，+9%）。冒烟里只加回复（regen_div 300）时医疗队也跟着上去（标准 7/11 → 11/11，整体 +19 点，p = 0.016），
  超出目标；回复放缓到 400、敌人攻击略陡以后整体 +8 点（不显著），医疗队 7/11 → 9/11。思路是「回复和攻击一起随时间涨」：无回复队靠多出的自身回复抵掉多出的伤害，医疗队的治疗不随时间涨，多出来的伤害由它们自己吃。
- 代码：`run/combat.gd regen_time_mult()`，`game.gd` 回复处乘上；属性面板「生命回复」显示含倍率的实际值（`screens/stats_panel.gd`）。
- 不影响干员治疗、拾取、吸血；医疗队也吃到这份回复，但 5:00–9:00 它们的生命多在 94–99%，多出来的大半溢出。

> 2026-10-14 制作人定：本节已被 docs/83 §1 取代。`sustain/regen_div` 现为 **0**（时间成长关闭；本文定档曾为 300 / `regen_knee` 480，8:00 起 ×2.6），改为入队每人生命回复 +0.9 / 秒（`squad/regen_per_member`）；`enemy/dmg_div` 首版改 360，云端 sg 配对显示与回复成长互相抵消，10-13 回到 **420**（`balance.json enemy._dmg_div`）。

### 3.2 低血补给：回复药剂（辅助）

- 规则：主控生命 < 70% 时，小怪掉回复药剂的概率 ×2；场上道具已满（磁铁 + 药剂 ≥ `item_cap` 3）时，只要场上药剂 < 2 个仍可掉。生命 ≥ 70% 时和原来逐帧相同（同样的随机数调用）。
- 旋钮：`pickup/heal_low_hp = 0.7`、`pickup/heal_low_mult = 2.0`、`pickup/heal_low_cap = 2`；`heal_low_hp = 0` 关闭。
- 量级不大：本机试跑每局平均触发不到 1 次（低于 70% 的时间本来就短，而且死前那一阵只有 10–30 秒）。保留它是因为它只在掉血后生效、医疗队几乎不触发，和「回复药剂」这个现有系统的直觉一致；主要靠 §3.1。
- 遥测：`items.heal_low`（生命低时掉的药剂数）。

### 3.3 流明当主控（协调人 10-13 追加，医疗归本文处理）

- 问题：opr-t2 流明主控 9/32（28%），13 局死在 2:00 前后（§2.1）。不是治疗不够，是前期清不动、被贴身打死；当队友时流明很强（md-t2 流明组 82%），所以只改当主控时的受击属性。
- 改动：`characters/lumen.json leader` 生命 115 → 135、减伤 0.5 → 1.5（凯尔希主控 120 / 1.5 + Mon3tr，近卫主控 125–140）。
- 凯尔希不改：主控 Ⅷ 41% 的输局中位 7:25，属于 §2 的中期消耗，由 §3.1 一起处理；她的治疗 10-12 刚削过一半。

### 3.4 没有采用的方向

- **削引痕者**：它是 5:00 后的头号来源，但医疗队承伤里它占比一样高，削它会让医疗队一起变容易（标准医疗已 74–82%）；加了回复后剩下的输局里引痕者在死前那一阵占 35%，若云端显示无回复队仍明显偏低，再考虑削它的接触伤害（`enemies.json tracer.dmg`）。
- **削医疗**：用户要求医疗仍是好选择；凯尔希刚削过治疗。§3.1 对医疗队的边际收益小（大多溢出），目标是医疗队不变、无回复队上来。
- **医疗无人机加权**：它在卡池里常驻，问题是和精英化 / 技能卡抢位置。按编队有没有医疗调出现率属于「看得出来的补偿开关」，不做。

### 3.6 风险

- 回复类藏品与博士「自愈」吃同一个倍率，后期按 ×2.2 算；若云端看到「自愈 / 回复藏品」局明显偏易，可把倍率只乘干员 leader 段 regen。
- `enemy/dmg_div` 是全局曲线，Boss 以外的所有敌人攻击都跟着变；塞雷娅 / 水月开局（本来最稳）会略难一点。

- 低血补给单独几乎没有作用（每局触发不到 1 次），回复是主力。艾雅法拉组即使回复加到 300 也只有 3/8：它输在引痕者（§2.2），剩下的输局死前那一阵引痕者占 35%。
- 流明主控 Ⅷ 前 5 分钟（`--maxt=300`）：seed 1–8 改前 2 局死在 2:00、改后 1 局；seed 9–24 改后 2/16（云端 main 同 seed 5/16，跨平台只作参考）。
- 样本都很小（36 对的胜率区间半宽约 ±15 点），采用的这组和改前的差不显著。定数值以云端为准（§5）。
