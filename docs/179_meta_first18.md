# 179 前 18 个细胞改成「看得见」的数值（方案，未改代码）

> 10-28 用户要看。口径不变：常规档高手机器人，**无认知 30–40%、点 18 细胞（≈ 第一局的收入）后 50–60%**；结算系数仍封顶 ×1.5；保命触发保留；总量与满点不抬；「先砍回复再满点」的 meta v3 决定照旧。

## 1. 现状（查证后）

- 测试台（docs/170 §7）：10:00 快照里 18 细胞与无认知**几乎一样**——最大生命 178 / 174、输出差 ±5%、等级同为 27。
- 原因：现在 18 细胞 = **危机感Ⅰ（13）+ 攻击性Ⅰ（5）**（10-26「试验 A」，docs/109 末节）。危机感Ⅰ是护盾 + 反震 ×3，只在被打时才起作用；攻击性Ⅰ只有 +8% 伤害。玩家看属性面板几乎没变。
- 整局胜率：试验 A 后 m18 54.5%（112 局，±9），t5 定档后 m0 30.4% / m18 55.4%——**数字在区间里，但提升全靠一个看不见的触发**。这次要换成肉眼能看到的数值。

## 2. 方案：前 18 细胞换成四项直接数值（总量 587 不变）

| 节点 | 细胞 | 改后 | 现在 | 每细胞 |
|---|---|---|---|---|
| 攻击性Ⅰ | 5 | 全体伤害 **+8%**（不变） | +8% | 1.6% |
| 生存本能Ⅰ | **4**（原 5） | 最大生命 **+12%**（原 +6%） | +6% | 3% |
| 生命感悟Ⅰ | **4**（原 5） | 每秒回复 **+0.30**（原 +0.15） | +0.15 | 0.075 / 秒 |
| 自我保护Ⅰ | **5**（原 8） | 受到伤害 **-5%**（原 -3%） | -3% | 1% |
| 合计 | **18** | 一局开始就能看到：生命 174 → 约 195、受伤 ×0.95（等效生命 +18%）、回复 +0.3/秒（十分钟约 +180 生命） | | |

**推荐点顺序**：攻击性Ⅰ → 生存本能Ⅰ → 生命感悟Ⅰ → 自我保护Ⅰ → 危机感Ⅰ（13）→ 其余照旧。危机感Ⅰ从第一位挪到第五位，**价格与反震 ×3 不动**，仍是保命触发，只是不再占掉前 18 细胞。

**保证点满不变**（只前置，不加量）：生存本能共 +30%（12 / 4 / 5 / 5 / 4）；生命感悟共 +1.0（0.3 / 0.1 / 0.2 / 0.2 / 0.2，Ⅲ 的低血翻倍保留）；自我保护共 -13%（5 / 3 / 3 / 2，Ⅳ 的静守保留）。为了总价不变，Ⅱ 级相应加价：生存本能Ⅱ 9 → 10、生命感悟Ⅱ 9 → 10、自我保护Ⅱ 12 → 15。55 细胞及以上与现在逐点相同。

## 3. 预计效果

- m18：**约 50–58%**（现 54.5–55.4%，换成看得见的数值后基本持平）。依据：docs/133 §4.2 的「数值节点一半」≈ 生命 +15%、受伤 -6.5%、伤害 +10%、回复 +0.5，约 +1.5 logit；本包约它的 0.55，折 +0.8 logit，从 34% 抬到 55% 上下；再扣掉移出前 18 的护盾（单点它约 +7 点）。**112 局噪声 ±9，这个数只是起点，要云端校准。**
- m0 不变（`--meta=0` 逐局相同）、m55 不变（节点集合相同）。
- 万一偏差的调法：m18 偏低 → 生存本能Ⅰ +12% 升到 +15%、自我保护Ⅰ -5% 升到 -6%；偏高 → 回生命感悟Ⅰ +0.2。都是单个数。

2. 云端一次性例行任务：常规档、高手机器人、7 开局 × 16 seed（112 局）× `--meta=0 / 18 / 55` 三组同 seed；另加 `18` 的两个备选（上面的升 / 降），共 5 组；本地只跑 `--only meta`。
3. 验收：m0 30–40、m18 50–60、m55 与现在持平；10:00 快照最大生命 ≥ 195、受伤倍率 0.95。
