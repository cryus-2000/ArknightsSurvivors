# 226 后期渲染层三件（11-02）

docs/221 后期实战画面巡检中，渲染层这三件归本稿（界面类条目归 claude/late-ui-1102）：

1. 敌弹和 Boss 地面预警挪到友方特效之上；
2. 队长被友方特效盖住时画剪影；
3. 全队装饰粒子设峰值上限。

三件都只改画面，伤害、判定、索敌不动。
同 seed TRACE 逐行相同：seed 13、德克萨斯 + 能天使 + 拉普兰德、660 秒，与基线 c73d2ff86 比对，412 行相同。

## 1 敌方顶层（`render/foe_top`，缺省 1；0 = 回到旧层级）

新增节点 `g.foe_top`。它是 game 的子节点，挂在友方加色层 `fx_add` 之后，所以画在友方帧条和加色层之上。
挪进这一层的内容，彼此之间仍按原来的顺序画：

- 预警填充：通用 / 伊莎玛拉 / 最终 Boss / 塑路者；
- 队长剪影（§2）；
- Boss 落地迸散与弹拖尾；
- 敌弹、抛物弹、冲击波；
- 新弹亮芯；
- 命中点；
- 敌人自带危险提示；
- 精英登场；
- 队长负面状态；
- 预警轮廓；
- 主控标记。

### 实现

Godot 只允许节点在自己的绘制回调里画。为此加了一个可切换的绘制画布 `g.wcv`：平时等于 game 自己，顶层这一遍里改指向 `foe_top`。
被挪动的那些绘制函数改写成调用 `g.wcv.draw_*` 和 `UI.*(g.wcv, …)`，涉及以下文件：

- world.gd
- boss_beam.gd
- break_ring.gd
- ishar_tell_draw.gd
- paranoia_bubble.gd
- paranoia_combo_draw.gd
- saint_draw.gd
- telegraph_draw.gd
- laser_draw.gd
- vfx.gd 的贴图辅助函数

以后在这些函数里新增绘制，**一律写 `g.wcv.draw_*`**。写成 `g.draw_*` 时，开着顶层的情况下会刷「Drawing is only allowed…」报错，那一笔也画不出来。

### 量法修正

按 docs/221 §1 的原量法，改前为均 20.9% / 峰 43.6%。其中大部分是量测噪点，不是真被改色：

- GPU 粒子每次运行落点都是随机的；
- `nofriend` 没有藏 GPU 粒子和 CPU 颗粒（fx_grains）；
- `nofoe` 跳过的绘制会让画面随机流错位；
- 伤害数字带抖动。

这几样一起被算进了「敌方层」。

本稿做了以下修正，见 `tools/late_render_measure.py`：

- 开着任何 `--clutterdbg` 时，GPU 粒子改用固定种子；
- `nofriend` 时，光学颗粒层和 fx_grains 一起透明；
- 四遍都加 `nonum`；
- 敌方层掩码去掉小于 40 像素的零星连通块；
- 队长坐标按视口换算。

修正后的结果：seed 13 A 组，9:56–10:12，每秒 1 帧，1920×1080。

| | 敌方被友方改色 均 / p90 / 峰 | 队长周围被友方改色 均 / 峰 |
|---|---|---|
| 改前（同构建，三件全关） | 4.4% / 9.6% / 12.3% | 13.9% / 26.0% |
| 改后 | 3.4% / 7.2% / 11.4% | 18.1% / 29.9%（剪影本身算友方层） |

剩下的约 3% 是全屏后期造成的：亮度预算与辉光由整屏发光量决定，友方一亮，整屏亮部都会轻微变色。这不是层级问题。
光学辉光层（CanvasLayer 1，敌人发光点和颗粒）仍在顶层之上，它是加色的小颗粒，实测影响很小。

## 2 队长剪影（`render/lead_sil`，缺省 1）

在顶层这一遍里、预警填充之后，把队长本体再画一遍，并描一圈暖白边（白剪影上下左右各错开 2 世界像素）。
它只在「被盖住」时出现：

- 覆盖分的计算范围是队长周围 `lead_sil_r`（56）以内的友方世界帧条（按尺寸计分）和干员粒子（每个 0.35）；
- 覆盖分过 `lead_sil_s0`（4）开始渐显，到 `lead_sil_s1`（10）全显；
- 升降各约 0.15 秒；
- 覆盖分每 3 帧算一次。

手机同样生效。不读像素，不改状态。

### 11-03 修：「人物身上冒光」

用户截图里，队长身上平时就罩着一团偏白的光。原因是剪影两处做错了，在 87149a00c 上已复现：

1. **画法**：先画 4 份暖白剪影，透明度 0.9，上下左右各错开 2 像素；再把本体按 `_sil_a` 半透明叠上去。渐显过程中本体是半透明的，底下的白剪影透出来，整个人就发白。
2. **触发**：覆盖分把很多不算遮挡的东西也算了进去：
   - 半径只有 8 的小火花；
   - 气场光点；
   - 队长自己的标记环（lead_mark / marc）；
   - 方圆 56 以内但没压到身体的件。

   seed 13 开局 1:00 时，87% 的帧都在画剪影，所以平时就一直有。

修法：

- 描边改成深色半透明，`render/lead_sil_edge_a` 缺省 0.6，只有描边随 `_sil_a` 渐显；
- 本体一旦出现就不透明重画，和原画是同一帧、同一个颜色；
- 覆盖分只算压到身体（中心距 < 半径 × 0.8 + 14）且半径 ≥ 18（`render/lead_sil_min_r`）的友方大件；
- 火花、光点、碎片、线、火舌和队长标记都不计；
- 干员粒子只计非装饰件。

改后剪影出现的帧占比：开局从 87% 降到 4%，10 分钟后约 18%。

改前 / 改后截图在 `Claude outputs/bug_1103/`。每张上行是剪影开、下行是关，同 seed、同一帧。生成脚本：`tools/leader_sil_shots.py`。

## 3 全队装饰粒子峰值上限（`fx/team_pfx_cap`，缺省 160；0 = 关）

每名在场干员的额度是「上限 ÷ 在场人数」，`squad.update` 每帧刷新。
`character.fx` 加粒子时，若本人已到额度，就跳过新的纯装饰件。纯装饰件指 `pfx_cappable` 覆盖的种类：光点、火花、碎片、光团、线、火舌，以及不循环、不走加色层的帧条。
判定、预警、状态提示照常画。

**不降透明度**（用户 10-25：「队友特效不要降」）。随机数在调用前已经抽过，所以 TRACE 不变。

`--pfxstat` 实测（seed 13 全局 660 秒）：

- 全队同屏峰值 318 → 126；
- 被跳过的装饰件：拉普兰德 2665 个，凯尔希 6514 个；
- 德克萨斯、能天使一次都没触到上限。

## 4 帧率

`--lrab=30`：每 30 帧轮换一次「敌方顶层 + 剪影」开 / 关，在同一局里量净差。
条件：seed 13，560–700 秒，`--fixed-fps 60`，1920×1080。

| 段 | 关：中位 / 平均 / P99 | 开：中位 / 平均 / P99 |
|---|---|---|
| 8–10 分 | 23.92 / 24.80 / 38.84 ms | 24.38 / 25.05 / 38.92 ms |
| 10 分后 | 28.54 / 29.50 / 48.71 ms | 28.74 / 29.80 / 48.89 ms |

开着平均多 0.25–0.3 ms，约 1%。量测用的是 `--balance`，每帧模拟量偏大，所以绝对值偏高。

第一版有过一处漏改：Boss 状态字和菱形标记仍走 `UI.*(g, …)`，每帧报错，多花了 2 ms。已改为 `g.wcv`。
