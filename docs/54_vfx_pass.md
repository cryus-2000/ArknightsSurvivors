## 2. 改动

公共件（`render/vfx.gd` 末尾「画面特效二轮」一节）：

- `mote`：带重力 / 阻力的光尘，`vfx.update` 按游戏时间推进，`world.gd` 的特效循环里写进 `tb_quad`，随循环末尾的 `tb_flush` 一次提交（不是每粒一次 `draw_rect`）。
- `glow`：加色层（`fx_add`）上用 `light` 贴图画的柔光，`draw_add_layer → draw_glows`，先胀后淡。
- `mire_recoil`：灯标点燃时被清掉的溟痕退散动画（紫环向中心收缩 + 深色底渐隐，tb 批）。
- `vfx.on(名)` = `fx/vfx2` × 单项旋钮；`vfx.ambient_ok()` = 高画质且非触屏（常驻环境粒子）；`vfx.p2` 是运行时总开关（`--vfxab` 轮换测量用）。
- 一次性粒子按 `Cfg.fx_density()` 减半（低画质）；`g.fx` 超过 420 / 440 条时不再追加。

## 3. 性能

同局轮换开 / 关（docs/50 §9.9 的方法）：seed=1、水月、高手机器人、标准档、1920×1080 窗口（`--resolution 1920x1080`，逻辑视口 1280×720 同游戏）高画质（辉光 / 景深 / 法线 / 水下滤镜全开），`--fixed-fps 60 --realtime --perf --prof --nodeath --vfxab=60`（每 60 帧翻转 `vfx.p2`，开 / 关两桶交替计帧），本机同时有其他会话的 Godot（绝对毫秒作参考，两桶之间可直接比）。结果 `build/vfx/perf_ab.txt`：

- 8–10 分钟（溟痕最多、最密时）净增 **约 0.11 毫秒 / 帧中位**（draw_world +0.11：溟痕光尘 +0.08、加色层柔光 +0.02、其余在噪声内），P99 +0.7 在单局噪声内（同一局 720p 复跑：+0.17 / +0.3）；0–8 分钟差别在噪声内（−0.02）。远低于 ≤ 0.5 毫秒的预算。
- 事件类特效（点燃 / 升级 / 晋升 / 拾取 / 商人 / 精英）是一次性的，粒子进 `mote` 走 tb 批、柔光走加色层各一次绘制调用；溟痕光尘是唯一的常驻每帧开销（≤ 48 粒 × 4 顶点 + 每片溟痕几次三角函数），低画质 / 触屏不画。
- 头一次量时窗口被 `ARK_NO_FOCUS` 留在 1280×720（`settings.gd` 在无焦点测试局不套分辨率档），`build/vfx/perf_ab_720p.txt` 留作对照：8–10 分钟 +0.17 / 开 19.47 关 19.30。

## 7. 遗留

- `glow` 用的是灯光贴图 `light`（径向渐变），足够柔但没有形状；有 `fx_beacon_ignite` 后灯标点燃可换成帧条。
- 精英登场只在精英第一次进视野的 0.9 秒内可见；精英刷在屏外且 0.9 秒内没进视野时就看不到（走向玩家的精英一般 1–2 秒后才入画）。若要保证可见，得把登场延后到「首次入画」——需要一个按 id 的「已入画」表，本轮没做（成本不高，看反馈）。
- 商人出现多在屏外，出现特效常常看不见，靠 HUD 指示找到它时只剩灯笼暖尘；若要更显眼可在它入画时再放一次（同上「首次入画」表）。
- 灯火跌档的一压只用了 HUD 的全屏色 + 边光通道（`scr_flash`），和 Boss 换幕 / 倒下共用一个变量，同一帧碰上会被后者盖掉（Boss 事件优先，合理）。
