# 142 · Boss 分幕招式差异化设计稿（10-25 改版：看得出区别）

> 用户 10-24：「现在不同阶段的招式差别不大，需要调整。」同日用户已定最终 Boss 血量 −15%（`boss/hp_final` 2.35 → 2.0，main 9ff007bb）。
> 本稿**只写设计、不改代码**，等用户审过再实现。基线 main 9ff007bb；现状按代码盘点（不按 docs/95 的设计稿），行号相对 `game/scripts/`。
> 沿用：docs/95（每 Boss 4 招、四种预警样式、颜色口径）、docs/38（预警 §1.9、读图预算 §1.10、主控保护 §1.11、卡点 §1.3）、docs/137（Boss 闪频：不加白闪、不加连闪）、docs/76 §4（原作内容以 PRTS 为准、可查证、不编）。
> 原作出处 10-24 重新经 PRTS 取 wikitext 核过（附录 A）。原作没有对应技能名的一律标「本作拟」，不冒称原作名。

## 0. 结论

**差别小的原因不在招少，在结构**：

1. **中期 Boss 第二幕的老三招一点不变**。数据招式的二阶段强化写死只给 4 只最终 Boss（`enemies/boss_patterns.gd:24,80`）；中期 6 只（玩家打得最多）第二幕 = 老三招原样 + 1 个 D 招 + 一层很淡的着色。
2. **D 招出得少**。清膛要等一整轮装填（`saint.gd:35-40`）、炮身砸击隔一轮才有（`saint.gd:88-95`）、裂潮挂在跃击上共用冷却（`archon.gd:134`）、震撼 27 秒一次（`izumik.gd:111`）；其余 D 招都有距离门槛，还要和老招抢令牌。
3. **最终 Boss 的中间卡点大多是空的**：伊莎玛拉 33%、骑士 33% 什么都不变；泡影 66% 只把凝视冷却 ×0.9；伊祖米克 33% 只改冷却。质变全挤在一次形态切换上（落地 / 变身 / 阐释 / 重生）。
4. **出招不分幕**：每只都是「冷却到了就放」的 if/elif 链，所有冷却统一 ×0.7（`boss_ai.gd:10,223`），预警都在 0.8–1.5 秒——两幕读起来节奏一样。
5. **换幕信号一样且弱**：每次过卡点都是同一套金环 + 吼声（`run/combat.gd:987-1009`）；中期 Boss 不改 `phase`，没有横幅、不换帧条；着色系数只在 0.82–1.18。

**10-25 改版**：用户看过初稿后要求「转阶段以后攻击方式和特效之类的得能看出区别」。新加 §2.5（每幕三件套：攻击换形 + 特效套 + 转场演出）和 §3A（每只 Boss 逐幕对照）+ 8 张示意图；§3 的机制与数值、§6 的决定照旧。

**方案**：先做一层通用底座（§2：幕招表、新招保底、换幕信号、幕节奏），再给 10 只 Boss 每一幕写清「这一幕新多了什么、哪招变了质、节奏怎么变、看得见什么」（§3）。每一幕至少有一条**形状上**的变化（新招或旧招换形状 / 换组合），不只改数字。

## 2. 通用底座（先做，10 只共用）

### 2.1 幕招表

每只 Boss 的脚本按「当前第几幕」查一张表，表里写这一幕**能用哪些招、各自冷却、恢复时间倍率**，代替现在不分幕的 if/elif 链。

- 幕号 = 已过卡点数；泡影茧后、骑士重生各算单独一幕。中期 Boss 两幕，最终 Boss 三幕（+ 形态幕）。
- 写法：enemies.json 每只 Boss 加可选 `acts: [{moves, cd, recover, pattern_mods}]`；**缺省 = 现状**，没写的 Boss 行为不变。
- **数据招式的分幕强化对中期 Boss 也开放**：`boss_patterns.gd` 的 `enhanced` 不再只认 4 只最终 Boss，改读 `acts[n].pattern_mods`（圈数、弹数、波数、缺口数）。

### 2.2 新招保底

- 每幕的新招在**过卡点后 2.0 秒内必出一次**（卡点无敌 0.8 秒 + 招名副标题 0.6 秒 + 余量）；之后若 12 秒没出，下一次出招优先选它。
- 新招的距离门槛只决定「出哪种形状」，不再决定「放不放」：玩家站远时近身新招换成远距离变体，或换下一个可用的新招。

### 2.3 换幕信号（不闪）

docs/137 刚把 Boss 白闪降到每秒 ≤2.5 次，换幕信号一律**不加白闪、不加连闪**，只用单发、慢变化：

1. **幕名横幅**：中期 Boss 也出（现在只有最终 Boss 有），1.2 秒；幕名见 §3，全部本作拟，文字按 docs/76。
2. **着色加深**：着色系数从 0.82–1.18 放宽到 0.70–1.30，0.5 秒渐变过去（不是闪）。
3. **一处形态细节**：每只写在 §3「看得见」一栏；能用现有帧条 / 特效就不新画。
4. 中期 Boss 换幕也写 `phase`，让现有的单发洋红闪 + 火花生效（单发；docs/137 已量过阶段转换不是闪频来源）。

### 2.4 幕节奏

- 招与招之间的空档按幕收紧：一幕 ×1.0、二幕 ×0.85、三幕 ×0.75（中期 Boss 只有一、二幕）。
- **预警时长不缩**：只缩空档、不缩预警（docs/38 §1.9 下限照旧）。
- 新招放完固定留 1.0 秒不出招（现在令牌只留 0.6 秒），让玩家看清新招再接下一招。

## 2.5 看得出区别：每幕三件套（10-25 改版重点）

用户 10-25：「至少转阶段以后攻击方式和特效之类的得能看出区别。」所以每只 Boss 的每一幕必须同时换下面三样，缺一样不算过验收：

1. **攻击换形**：至少 1–2 招换「形状」——弹幕图形（圆泡 → 泪滴 → 鳞片）、范围形状（平行 → 交叉、单圈 → 连串、扇形 → 双扇 / 三叶）、出招动作或位移（直线冲 → 折线冲、悬浮 → 落地）。只改冷却 / 数量的不算。
2. **特效套**：一幕一套可辨认的视觉，四个槽位都要变：
   - **配色**：主色换一档（每只 Boss 的三档色写在 §3A 表头，和 `vfx.gd` `BOSS_STYLE` 的主色同一色相族，靠明度 / 饱和度 / 偏色区分，不撞别的 Boss）；
   - **预警纹样**：在 docs/95 §0.2 四种填充之上加本幕纹样（眼纹、双环、六角、锯齿、三角分形……），形状不变时也能一眼认出是第几幕；
   - **本体颗粒**：用 fx_grains 模板（docs/136）加一条本 Boss 本幕的颗粒参数（上升雾、滴落、下坠、环绕、流入、黑烟、连线流动 7 种，§5），低画质 / 关光学时不画；
   - **地面**：低亮度 0 区域纹理（裂纹、血斑、声纹、根须、绿雾、霜纹、海水裂缝、几何裂纹、焦痕、十字裂纹、潮水带），走 `world.tb_*` 合批，按 docs/38 §1.10 读图预算计数。
3. **转场演出**：过卡点那 0.8 秒无敌里放一次专属演出（残影滑开、坠地砸裂、根须猛长、长枪插地破土、碎成分形再拼回……），**单发、不闪**：不加白闪、不做连续明暗跳变（docs/137），用位移、扩散、渐亮表达；之后横幅亮幕名。

示意图（程序画的形状 + 现有帧条第 0 帧，不是游戏截图）：`tools/probes/boss_phase_sheets.py` 生成，输出 `build/boss_phase_sheets/<boss>.png`（paranoia、ishar、izumik、knight_boss、path、iberia、carmen、tide_pair 共 8 张）。白点 = 队长，灰点 = 队友。

## 5. 素材与实现

**素材**：帧条全部复用现有的（骑士冲锋形态用 `e_knight_walk_charge`，泡影落地 / 破茧、伊莎玛拉变身、伊祖米克扎根都已有），不交 Codex。新东西都程序画：

- **预警纹样**（§2.5）：眼纹、同心双环、六角、锯齿、三角分形、声波弧 6 种，加在 telegraph 绘制里，按 Boss 本幕查表；
- **地面纹理** 11 种（§2.5）：走 `world.tb_*` 合批，按读图预算计数，转场时由中心向外铺开、之后常驻低亮度；
- **本体颗粒**：fx_grains（docs/136）`TEMPLATES` 加 7 条——上升雾、滴落（落地 `spark` 冷却）、下坠、环绕、流入（从指定点流向本体）、黑烟、连线流动；Boss 每幕按表 `push(模板, 位置, 方向, 本幕色)`。fx_grains 归粒子化会话维护，加模板前先和它对一下预算（Boss 颗粒单独占一份，上限 [高 300, 中 150]）；
- **弹体换形**：泪滴、鳞片、刃片用现有弹体帧条换色或程序画，不新画帧条；
- **残影 / 柔光**：泡影残影、斥亡体残影、骑士拖尾用现有拖尾 / 半透明复画。

**实现分批**（协调人 10-25 定：先通用底座 + 中期 Boss，再最终 Boss；每批本地只跑相关 `--only` + core，截图验收用 `--bossmoves=<type>`，全量与 A/B 由协调人合入时上云）：

2. 中期 6 只（§3A.5–3A.8 + §3.5–3.8）。
3. 最终 4 只（§3A.1–3A.4 + §3.1–3.4）。
4. 云端 A/B（§4）→ 数值会话按结果调旋钮。
