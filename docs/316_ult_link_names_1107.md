## 0. 起名口径

1. 词从原作来：武器名、标志物件、档案里的说法、语音里的原话。查不到的不编。
2. 2–4 字，像一个具体的东西、一句口令或一个动作。不用「X 之 Y」，不用自造成语。
3. 连携技偏轻、偏短，听起来是「接一下」：多取作战语音里的短句（「拔刀」「闪开」「凝固吧」）。终结技可以重：多取武器名、身份、档案里的大场面（「般若」「四爪巨锚」「山谷崩塌」）。
4. 每格给 2 个候选，**粗体为推荐**。
