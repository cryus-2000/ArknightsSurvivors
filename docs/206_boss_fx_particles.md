# 206 Boss 弹与招式粒子化（特效单）

10-31 用户：Boss 弹和招式特效「现在没有粒子感」。协调人定：按 pixfx 技能做（预烘焙帧条，`tools/imagegen/pxburst.py`），不逐粒子实时画；工作量交 fx-c 出图做画面，口径与帧率会话（perf-60fps）对齐。分支基于 `claude/boss-buff-1031`。

## 1. 范围（按优先级）

| # | 对象 | 现状 | 要的效果 | 做法 |
|---|---|---|---|---|
| 1 | Boss 弹命中 / 到期 / 被消 | `render/bullet_fx.gd _die`：`_ghost` 整颗淡出 + `bul_pop` / `bul_cool` 少量程序颗粒（4–8 颗） | 迸成一小团颗粒（8–14 颗）向外散、减速、冷却变暗，不再整颗淡出 | pxburst 新烘一张小号帧条（半径约 14 px、8 帧 / 0.45 秒），按弹专属色着色；`_die` 里 Boss 弹改播帧条、去掉 `_ghost` |
| 2 | Boss 弹飞行 | 本体 + 暗外圈 + 亮芯；`_ebp` 轻摆 | 细碎光粒拖尾：每颗弹身后 2–4 颗 1–2 px 光粒，随速度拉长，0.2 秒内熄 | 不按颗实时画：烘一张「拖尾」短帧条（4 帧循环），沿速度方向拉伸 / 旋转贴在弹后；只给 Boss 弹，同屏 > 150 颗时隔颗画 |
| 3 | 激光（泡影凝视、伊莎玛拉扫射、卡门封锁线、伊祖米克扫描） | 实线 + 辉光 | 光束边缘有细碎颗粒持续飘出，收束时整条碎成颗粒 | 沿光束每 24–32 px 贴一次小帧条（错相播放）；收束帧用 #1 的帧条沿线铺 |
| 4 | 地面招式（骑士冰棱 / 冲撞落点、泡影海嗣滴落地、伊祖米克触腕圈、溟痕生成） | 圈 / 贴图 | 落地瞬间一圈尘粒 / 碎屑迸开 | 复用 `fx_px_burst1/2`（大号）按招式色着色，落地时播一次 |

## 2. 口径

- 全部用预烘焙帧条（`u.strip` 播帧 + col 着色），不新增逐粒子 GDScript 循环；颗粒 1 纹素 = 2 世界像素，与 `fx_grains` 观感一致。
- 着色用各 Boss 专属弹幕色（`g.vfx.boss_color(type)`），不弹提示、不加文字（docs/76）。
- 帧率预算：Boss 战同屏 150 弹满屏（伊祖米克场景）P50 增量 ≤ 0.5 ms；拖尾（#2）超预算就先只做 #1 / #3 / #4。量法同 docs/50 §42（同局轮换）。
- 与 perf-60fps 的预烘焙优化统一：帧条尺寸 / 帧数 / 合批方式以它的约定为准（先问它再烘）。

## 3. 验收

- 对照录像：泡影、一只中期 Boss（塑路者），带声、原速 30 帧，前半改前、后半改后；发前过 vreview（ult_fx 清单）。
- 判定、弹体大小（`boss/bullet_r_min`）、伤害都不动；同种子模拟不变（只改画面）。

## 4. 帧率实测（11-01，第九批 main cb29800ab + 本分支界面改动，桌面）

方法：`--bossacts=<Boss> --perfab=30 --fixed-fps 60`（docs/50 §42 同局轮换；`tools/probes/boss_fx_compare.py perf` 与 `build/ui_audit/bossperf.py`），
a = 新画法、b = 旧画法（`g.perf_alt`：本单四处——迸散 / 拖尾 / 光束颗粒 / 落地迸散——全关，同时关掉 10-25 的 Boss 光学颗粒 `render/boss_fx_grains`）。
再加 `--bal=render/boss_fx_grains=0` 两桶都关旧颗粒，差值就只剩本单的粒子化。本机同时有其他会话的 Godot（2–4 个），单局 P95 有 ±4 ms 噪声，按多局看。

| Boss | 新 / 旧 P50（ms） | 新 / 旧 P95（ms） | 只看本单粒子化：P95 差 |
|---|---|---|---|
| 伊祖米克（满屏 150 弹，最重） | 15.6 / 15.5；17.4 / 17.8；15.3 / 15.7 | 32.3 / 23.6（首跑）；26.5 / 27.7；22.7 / 25.9 | +1.5、+1.0（P50 +0.3 / +0.6） |
| 偏执狂（标准结局） | 15.0 / 15.8；15.1 / 15.8；16.4 / 15.6 | 33.9 / 30.0；29.9 / 26.6；27.5 / 24.2 | −0.3、−1.3 |
| 伊莎玛拉 | 12.8 / 12.2 | 24.3 / 23.4 | — |
| 骑士 | 13.9 / 13.0 | 23.7 / 24.7 | — |
| 塑路者（中期） | 10.7 / 10.2 | 19.6 / 20.8 | — |

结论：
- 本单粒子化**没有可测的退步**：伊祖米克 P50 +0.3–0.6、P95 +1.0–1.5（预算 P50 ≤ 0.5，贴线），偏执狂在噪声内；伊祖米克首跑的 P95 +8.7 两次复测没复现（−1.2、−3.2），是机器噪声。
- 偏执狂稳定多出的 P95 约 +3.2 ms 来自 10-25 的 Boss 光学颗粒（`boss_fx_grains`），关掉它两桶就一样，不是第九批引入的。用户 10-27 定「局中不要自动降特效」，不加自动降档；要压可以单独给偏执狂二阶段的颗粒发射量设上限（待定，未改）。
- 网页手机仿真（`perf_web.py --mobile --dpr 2`，带 `--mobilecap`）：`--bossacts` 在网页测量副本里跑满 1500 秒没出 BOSSACTS 结果（逐秒帧数一直约 30），同 docs/50 §42「伊卓米克未测成」，见 §4.1。
