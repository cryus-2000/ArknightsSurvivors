# 179 干员流派标签重做（设计稿，待审）

- 状态：待协调人审阅、用户确认。确认后基于 `claude/card-tags` 1d2a2eb70 开新分支实现。
- 用户原话（10-28）：「每个干员的标签可以重新设计一下吗？否则不是可以吃到很多加成，那就没有流派的意义了」。

## 0. 问题

现在藏品按宽泛特征生效，主要是这四类：近战、远程、物理、追击。

- 一名干员往往同时带三四个特征。例如拉普兰德同时算近战、远程（剑气）、物理和追击。
- 结果几乎什么流派藏品都能吃到，流派之间没有取舍。
- 卡底标签也一样，一张卡能标出整队。

## 1. 原则

1. **每名干员只归 1–2 个流派。** 流派共 7 个，沿用 163B 的划分。归属看这名干员在本作里的实际机制，以原作职业 / 分支为参考，不硬凑。
2. **流派藏品的主效果只给本流派干员。** 不再按「近战 / 远程 / 物理 / 追击」这类宽泛特征生效。
3. **宽泛的附带数值处理二选一。** 要么删掉，要么改成本流派专属。改完后不再出现「仅物伤 / 仅追击伤害」这类一人吃多条附带数值的标签；淡色口径只留给确实跨流派的少数情况。
4. **职业件不动。** 典训、突破、协议这类按职业生效的藏品照旧，它们是职业路线，不是流派。通用件（全队伤害、技力、经济、生存）也照旧。
5. **护盾反击、治疗转伤是队长侧流派。** 这两条的收益落在队长身上。干员归属只表示谁在供给这条线：星熊供给格挡，医疗供给治疗。

## 4. 待定（审阅时请拍板）

1. **追击类怎么归。** #170 / #171 / #234 / #246 按「追击」触发，追击来自拉普兰德、艾丽妮、斯卡蒂等七八人。
   - A（推荐）：并入召唤驻场，改为只看召唤物命中。
   - B：保留宽泛追击，从流派里拿掉，改标「通用」。
2. **控制时长改成「只延长控场干员施加的控制」是新的判定。** 需要记录每个控制的来源干员，有实现成本。
   - 备选：时长照旧全局生效，只把标签收窄到控场干员。
   - 我推荐只收窄标签。玩家感知差不多，不用新增来源追踪。
3. **乌尔比安要不要第二流派。** 他眩晕 / 击退多，可以加控场引爆，但会让近战扩域和控场的重叠变大。目前没加。
4. **归溟幽灵鲨的替身算不算召唤驻场。** 替身只在倒下后出现。也可以只归近战扩域。

## 5. 卡面与图鉴

- 卡底「影响」标签改为先写流派、再写在队的本流派干员，例如：「近战扩域：拉普兰德、星熊」。
  - 编队里没有本流派干员时，写「编队无近战扩域干员」。
  - 不再出现「仅物伤」类标签。代码里的淡色口径保留，只用于第 3 条原则下确实保留的跨流派附带。
- 干员图鉴、招募卡的「特性」标签改为显示流派（1–2 个）。原来「近战 / 物理 / 追击 / 控制」四列特征下放到详情。
- 藏品图鉴按流派分组。通用、职业、经济、生存各自单列。
- 文案按 docs/76：流派名固定为这七个叫法，不另起简称。

## 6. 实现要点（确认后）

1. 数据：
   - 干员 json 加 `"lanes": [...]`，取值 `multi / melee / summon / control / weak / shield / heal`。
   - 藏品效果的 scope 加 `lane:<名>`。
   - vis_growth 的对象判定从 `range_cls` 改为看流派。
2. `run/affects.gd`：加 `_by_lane`；`chips` 先出流派标签；宽泛特征只留给通用件。
3. 选卡引导（build_affinity）：沿用 163B §10 的 ×1.3 权重、上限 ×2；资格改为「编队有该流派干员」。
4. 测试：
   - vis_growth_test、card_desc_test、affects 标签检查。
   - 新加 lane_lint：每名干员 1–2 个流派；每件流派藏品主效果只有 lane 作用域。
5. 平衡：流派矩阵上云端跑。看各流派胜率是否拉开但不失衡：
   - 单流派成型胜率与混搭相比的差距。
   - 最强与最弱流派差距在 10 点以内（docs/balance-method 口径，胜率差 <10 点不下结论）。
