# 156 · 事件插图：原作 CG 像素重构调研（10-26）

> 协调人转用户（10-26）：「有哪些事件的图可以用原本游戏里面 CG 来像素重构？」
> 范围：docs/154 翻节点卡里用到的全部事件（结局线 7 件 + 安全屋 / 得偿所愿 + 普通不期而遇 9 件），以及两件二期备用（守望相助、瞥视）。
> 出处：解包数据 `roguelike_topic_table.json` 的 `rogue_2.choiceScenes.*.background`（每件事件的背景图编号），PRTS「[水月与深蓝之树/事件一览](https://prts.wiki/w/水月与深蓝之树/事件一览)」用的同一套图，文件名 `Avg_pic_rogue_2_<编号>.png`（PRTS API `prop=imageinfo` 查得尺寸与地址）。
> 原图按用户 10-15 授权只下载到主仓库 `build/event_cg/` 作内部参照，**不进 git、不进包**；像素草稿同样只放 `build/`。正式重构交 Codex（docs/104 流程）。

## 0. 结论

- **每件事件在原作里都有一张专属 CG**，全部 1600×900。docs/154 用到的 18 件全有图（其中「继承」与「悬高之葬」共用 1 号图、「引火之木」与「敬奉火焰」共用 34 号图）。
- 用在本作的位置：事件面板左侧插画框（C 版式，560×500 设计像素）。按局内粗像素观感，建议 **140×125 美术像素、×4 显示、≤ 64 色**；从 16:9 原图按 560:500 裁出主体。
- 草稿（脚本缩放 + 64 色中位切分量化，未手修）：高对比、单一主体的图（升华、点滴星火、深蓝仪式）直接就能读；人物小、暗部多的图（开端、骑士仍在）主体还在但配色被压平，正式重构要手修轮廓与点缀色（水月的蓝、骑士的蓝飘带）。
- 建议先做 **P1 七张**（结局线，每局至少见一张），再做 P2 两张（安全屋、得偿所愿：填充卡里出现最多），普通事件 P3 按需。

对比图：`build/event_cg/compare_3.png`（开端 / 升华 / 骑士仍在，左原图裁切 | 右 64 色草稿）；另 6 张版本 `build/event_cg/compare_all.png`；全部原图缩略 `build/event_cg/contact.jpg`。生成脚本 `tools/probes/event_cg_pixel_draft.py`。

## 2. 草稿观察（脚本量化，未手修）

- **升华**：白色人物与枝叶在 140×125 下仍清楚，几乎可直接当底稿。
- **开端**：洞口、风暴、两人站位都在；但人物只有约 30 像素高，水月的蓝发与外套被量化成灰紫，需要手补 3–4 个点缀色并加 1 像素描边。
- **骑士仍在**：坐骑与长枪的剪影能读，暗部糊成一片，蓝色飘带和头盔高光要手动挑出来。
- 另做的三张（`compare_all.png`）：深蓝仪式（枝条要并线）、点滴星火（最容易）、狂徒妄念（火光渐变出现色带，要重排色阶）。

## 3. 给 Codex 的单子要点（用户点头后再发）

1. 规格：140×125 美术像素、≤ 64 色、无抖动，×4 显示于事件面板插画框；手机版顶栏小图用同一张缩到 1/2。
2. 每张按本表「裁出主体」列取景，保留原作构图与配色（docs/87 §4.3 设定色优先），角色细节对照 PRTS 立绘。
3. 交付：`art/incoming/event_cg/<事件 id>.png`；三列对照（原图裁切 / 脚本草稿 / 成品）人眼先验收（docs/104）。
4. 先做 P1 七张；「继承」「相逢」原图与事件内容不符，P3 里放最后，或请用户决定改用别的图。

## 4. 接入记录（10-26，Codex 母稿 art/archive/incoming_1028/event_cg_1026/generated_v2）

- 用户不认可 140×125 直接降采样（太糊），Codex 交 1327×1185 母稿（用户已确认画面）。母稿留在仓库根 `art/incoming/`，不进包。
- 运行时用图：`game/art/event_cg/hi/<事件 id>.webp`（1120×1000，插画框 560×500 的 2×，桌面）与 `web/<事件 id>.webp`（560×500，网页）；Godot 导入为有损（`compress/mode=1`、质量 0.85）。
  Windows 预设排除 `art/event_cg/web/*`，Web 预设排除 `art/event_cg/hi/*`。「得偿所愿」直接弹藏品三选一、没有事件面板，`wish` 暂不入包（17 张）。
- 包体增量（导入后 ctex）：桌面 +2.4 MB，网页 +0.85 MB。
- 内存：打开事件面板时才 `load`，换面板 / 关面板即放掉引用。实测显存（1280×720 桌面）打开时 +5.4 MB、关面板后回到 +1.2 MB 以内（其余为界面常驻贴图波动）。
- 画法：桌面插画铺满撕纸边插画框，代替墨色底与节点图标，底部压暗带与事件名照旧；手机压暗铺满整屏当底，左上一张小图。没有对应图的事件（以后新增的）退回原墨色底。
- 自审：`tests/event_cg_shots.tscn`（6 件事件逐张截图 + 显存记录）。
