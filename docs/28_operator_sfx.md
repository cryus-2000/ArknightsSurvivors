# 28 干员专属音效

2026-09-25。每位干员一套自己的声音，替换原来所有人共用 swing / boom / roar 只改音高的做法。

## 原则
- **贴近原作印象，全部程序合成**：`game/tools/gen_sfx_ops.py`（numpy + scipy），不使用游戏原始音频。改音色 → 改对应段落 → 重跑脚本。
- **普攻 / 命中压低、技能放开**：3–4 名干员同时开火，普攻类默认 -11 dB、命中 -10 dB，并按干员限流（同一音效 0.06 秒内只响一次）；技能发动 -4 / -4 / -2 dB，是一局里少数的"高光"。
- **技能发动音统一挂在 `character.spend_sp()`**：任何干员放 S1/S2/S3（包括永久型技能、水月的状态型技能）都会自动播放 `op_<id>_s1/s2/s3`。新干员只要有文件就生效，不用改脚本。
- **缺文件自动退回通用音效**（atk→swing、hit→hit、s*→skill、big→boom、heal→oil、quake→boom），第二批干员还没配音时也不会没声音。

## 文件与调用
- 文件：`game/audio/sfx/op_<干员 id>_<类别>.wav`，类别 = `atk` 普攻出手 / `hit` 命中 / `s1` `s2` `s3` 技能发动 / `big` 大招落点 / `heal` 治疗 / `quake` 余震。
- 登记：`sfx.gd` 的 `OP_SFX`（哪些干员有哪些类别）、`OP_VOL`（默认音量）、`OP_LIMIT`（限流）、`OP_FALLBACK`。
- 调用：`Sfx.op(id, "atk", 相对音量, 音高, 音高抖动)`。干员法术弹（子弹带 `op` 字段）的命中音由 `game.gd._bullet_hit` 播放。

## 加新干员
1. `gen_sfx_ops.py` 末尾照格式加一段 `save("<id>_atk", ...)` 等并重跑；
2. `sfx.gd` 的 `OP_SFX` 登记类别；
3. 干员脚本里把普攻 / 命中处的通用音效换成 `Sfx.op(id, "atk")` / `Sfx.op(id, "hit")`。技能发动音不用接。
