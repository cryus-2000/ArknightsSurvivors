## 2. 每招拆法与三档

## 3. 实现

- `game/scripts/render/fx_pxplane.gd` 末段「流明」：事件 → 一次性件；状态件直接读玩法状态（`o.hw.lm` 的 bolts / rain_t / tower_t / beam_t，`seg_lumen` 的 `_h3_tower_on` / `_h3_beam_on` 等，运行时 `load` 取，避免和积木链循环 preload）。帧条表改成 `METAS`（斯卡蒂、流明两份，流明键加前缀 `lm_`）。
- 钩子（都只画）：`seg_lumen.gd` 光弹命中 `lm_hit`、折光 `lm_refract`、灯塔光柱 `lm_pillar`、治疗 `lm_mend` / 连线 `lm_link`、光爆 `lm_burst`；技能起手沿用 `data_operator` 的 `skill` 事件；`vis_growth.gd` 额外弹命中 `lm_xhit`（接管时不画通用弹体）；`late_shape.gd` 连锁 `lm_chain`；`skill_link.gd` `l_lumen` 出手 `lm_lfire`、灼烧光点命中 `lm_xhit`（接管时不画通用光点 / 上飘颗粒）；`combo.gd` 出手 `lm_cshot`、落点 `lm_cleanse`（接管时不画通用曳光 / 圆圈）。这些钩子都先判 `id == "lumen"` 或 `Fxr.owns`，其他干员不受影响。
- `fx_recipe.gd` 的 `FXRLOG` 调试行末尾加了游戏时间一列（找实局事件时刻用；`fx/recipe_log` 缺省关）。接管时原治疗连线、光爆放射线（`g.fx`）不生成，加色层的光弹光晕 / 守望光扇不画；手上提灯光、灯塔灯光、发光单元本体照旧。
- 帧条：`game/art/fx/pxp/pxp_lm_*.png`（51 张）+ `game/data/pxp_lumen.json`。重新生成：`python tools/pxplane_bake_lumen.py`（需要本机 pixelfx 库 `build/pixelfx`），之后 Godot `--import` 一次。平面版源 `tools/pixelfx_fx/water/ak-lumen-pp.js`；旧做法对照直接烤旧放开版原文件。
- 线状件（光弹、折光、光柱 + 地面光痕、治疗连线、守望光扇）方向任意，按美术像素格逐格画（2 世界像素一格），不旋转贴图；形状按 15 fps 节拍换。**偏离 docs/246 的一处**：光弹位置每帧走、只取整到像素格——光弹 380 像素 / 秒，按 15 fps 跳格一次跳 25 像素，会一卡一卡。
- 颜色组 `game/data/fx_pxplane/lumen.json`（颗粒 / 照地光 / 受击反应）。

## 4. 看图判断（Claude）

- **做到了的**：同斯卡蒂，视角（贴地压扁 + 立起排序）、像素格（全屏一种像素）、统一 15 fps 三条和 ② 旧做法并排一眼可见；四招样子各不相同（普攻钢蓝光弹 + 尖刺水花 / 沐雨涟漪弧 + 斜雨 / 沛霖头顶水柱 / 灯火不灭四芒灯光 + 光圈 + 结束星芒）；精二的灯塔光柱是实心一道、方向任意不歪；后期多弹在三档图里能看到，上限压住后没有叠成一片白。
- **还不够的**：
  - 第一版普攻精二命中每团都带竖光，后期多弹叠成一片白；已改成只有主弹带、同屏限团数，但精二光柱一线命中时水花仍偏密；
  - 精零命中原 ×1.3 在后期画面里太小，已提到 ×1.6，仍比原作命中「大、亮」差一点；
  - 连携技只在 8:21.4 拍到一次，那一刻正好是 Boss「圣徒伊比利亚」被击破的满屏乱场，胸口水花被盖住，主要只能读出队长周围那圈照亮边弧；没有更干净的连携技镜头（连携 v2 约 60 秒一次，8:00–8:20 之间没有）；
  - 「吃光」在暗场景里仍主要靠白芯 emit 和照地光，色层本身被压暗后偏灰；
  - 灯塔道具顶上的暖黄灯光圈是道具自身的加色光（不属攻击特效，没动），和钢蓝特效放在一起有点跳。
