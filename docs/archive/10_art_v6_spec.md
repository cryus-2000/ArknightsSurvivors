# 10 · 美术 V6 接入约定（援护移动、投射物、爆炸、激光）

> 开发方（Claude）对美术方问题的答复，2026-09-24，对应代码 v0.8.2。
> 交付方式不变：PNG 放 `art/incoming/`，横向帧条，二值透明，最近邻，外轮廓 #080E18，附 manifest。

## 1. 已定的约定

| 问题 | 结论 |
|---|---|
| 援护移动 | 采用 **48×48、6 帧、朝右绘制**，程序左右镜像。援护跟随水月时位置平滑移动，速度超过阈值播放移动循环，停下回到待机。 |
| 移动中攻击 | **边走边攻击**：攻击动作（0.5 秒）期间播放攻击帧，位置照常跟随水月，不停步（停步会掉队）。攻击帧优先于移动帧。朝向：攻击时朝目标，移动时朝移动方向，待机时朝水月。 |
| 技能表现 | **定稿**：狙击＝箭矢＋命中流血；术师＝橙色火球＋范围爆炸；医疗＝绿色治疗连线＋上升十字；辅助＝紫色追踪弹＋减速光环。 |
| 无人机升级 | **保留**：Lv.1 子弹 → Lv.2 持续激光（替换子弹，0.9 秒光束，随目标转向）→ Lv.3 激光＋追踪导弹 → Lv.4 第二架 → Lv.5 导弹 +1、攻速 +25%。 |
| 导弹爆炸 | **与火球不同**：火球＝橙红火焰团、火星；导弹＝白黄闪光核心＋金属碎片＋灰色烟团，偏机械感。 |
| 分工 | 同意建议：**飞行物、爆炸、命中用像素帧条**；**拖尾、可变长度光束（医疗连线）、可变半径光环（辅助）、流血地面、伤害判定圈由程序画**。 |
| 激光 | **需要三段素材**：起点（枪口）、可平铺中段、末端。程序沿光束方向旋转并平铺中段，长度随射程变化。 |
| 投射物方向 | **可行**：投射物一律**朝右绘制**，程序按速度方向旋转，旋转中心＝帧中心。圆形投射物（火球、紫弹、水弹）也朝右画，尾焰朝左，一样旋转。 |
| 爆炸对应伤害半径 | manifest 里给出每张爆炸图的 **`radius_px`**（最大那一帧里爆炸主体的半径，单位为美术像素）。程序缩放倍率＝伤害半径 ÷ `radius_px`，限制在 1.5–3.0 之间；同时程序在第一帧叠一圈细的判定圈，保证玩家看得出真实范围。 |

**显示倍率**：敌人、特效沿用 ×2；援护沿用现有的 ×1.4（48px 画布）；无人机沿用 ×1.0。

## 3. 程序负责（不需要画）

拖尾、医疗治疗连线（可变长度）、辅助减速光环（可变半径）、流血地面血迹、爆炸判定圈、所有投射物的旋转与缩放、激光的平铺与裁切、淡入淡出、发光叠加。

## 4. 交付后检查

- 援护移动与待机、攻击三种状态切换时脚底不跳动。
- 投射物旋转到 45°、90° 时轮廓仍可辨认。
- 爆炸图在倍率 1.5 与 3.0 时都能看。
- 激光中段平铺后看不出接缝。
