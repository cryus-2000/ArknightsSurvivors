# 32 · 编队人物美术审查（三批干员，2026-09-26）

> 范围：第二批（维什戴尔）、第三批（推进之王、斯卡蒂、塞雷娅、艾雅法拉、凯尔希、Mon3tr、铃兰）、第四批（乌尔比安、艾丽妮、归溟幽灵鲨 + 替身、Logos、流明 + 灯塔）。博士只做横向对照。
> 方法：四名审查员并行，逐帧看 @2x 帧条、量包围盒和道具坐标，并在 Godot 里跑编队混战与图鉴演示截图。
> 证据图在本机 `E:/ArknightsSurvivors/Claude outputs/art_review_0926/`（不入库），文件名见各条末尾。
> 分工照旧：§1–§2 给 Codex；§3 是 Claude 在 main 上改的代码，**不需要 Codex 处理**。

## 0. 结论

- 三批人物的原作辨识度、身高、脚底对齐整体合格；所有 @2x 都是真 96px 细节，色数与 alpha 合规。
- **最大的问题是第四批和前两批不统一**：描边只有前两批的一半粗、整体偏暗，实机里在深色海底糊成暗块（`review_D_lineup_idle0_3x.png`、`review_D_outline_compare_6x.png`）。
- 第二类问题：**一条技能动作被三个技能共用**，姿势和技能效果对不上（治疗时举盾、增益时下劈）。
- 第三类问题：代码里的炮口、手、杖尖坐标还停在 48px 时代，特效从胸口或腰上发出。这部分由 Claude 修，见 §3。

## 1. 修改意见（给 Codex）

按优先级排列。「严重」= 实机明显可见或和玩法矛盾。

### 1.1 全队 / 第四批横向

| 级别 | 问题 | 要求 |
|---|---|---|
| 严重 | 第四批五人 @2x 外描边只有 1px；第二、三批和博士是 2px（按 48px 内容 ×2） | 第四批全部 @2x 外轮廓膨胀到 2px，与前两批一致 |
| 建议 | 第四批平均明度 0.39–0.60，第三批 0.50–0.76；乌尔比安、流明、Logos 在实机里成暗块 | 提亮饰边与高光，不改配色方案 |
| 建议 | 第四批出现 R=B、G=12 的暗洋红像素（乌尔比安 839、Logos 339、幽灵鲨 275、艾丽妮 113），前两批为 0 | 清除抠图残留；乌尔比安帽带如果是有意的红色，改成立绘的红而不是品红 |
| 建议 | 艾丽妮与幽灵鲨同屏难分（米白长发 + 黑白裙）；流明与博士都是深蓝 + 青蓝 | 加强艾丽妮的粉色内衬和提灯；流明见 1.4 |

### 1.2 第二批：维什戴尔

- 建议：普攻出手帧（attack f2）武器和 f1 同位，身体只沉 2px，没有炮口后坐和身体后压。
- 建议：idle 武器斜挂背后，加银色碎白点，远看像大锯剑，读不出狙击。skill f4 → f5 武器长度几乎翻倍。
- 小问题：规格写"肩扛"，实际是腰间平射；如用户接受现状可不改。

### 1.3 第三批

**推进之王**
- 建议：attack f2 → f3 一帧之内锤子从前方穿过身体到身后；f2 像往前捅而不是抡锤。
- 小问题：锤头约 14×10px，比原作大锤小，不醒目。

**斯卡蒂**
- 建议：idle f0 帽顶比 f1–3 高约 6px，剑角在 30°–60° 间摆，发尾毛球时有时无，循环会抖（`review_A_idle_compare.png`）。
- 小问题：attack f2 剑被透视压到约 28px，像刺击；普攻实际是 160° 横扫。帽檐大块亮蓝与原作黑帽不符，请用户确认是否保留。

**塞雷娅**
- 严重：黑白灰配色贴在博士身前，实机几乎看不见（`review_A_shots2_zoom_945.png`）。加粗盾的橙边（规格本来就是"橙边方盾"）。站位由 Claude 在代码里调。
- 小问题：idle f0 少了左侧发束，循环闪一下。

**艾雅法拉**
- 建议：run f2 → f3、f4 → f5 身体前后平移约 13px，跑动一窜一窜。
- 小问题：idle f1、f2 都闭眼，一半时间在闭眼；杖身只有 2px 深色细线，实机看不见。

**凯尔希**
- **严重**：idle f1–3 头发和外套越来越碎，出现黑白碎块，f3 像残留棋盘格，脸角度也变了；实机每秒"脏 → 干净"跳一次（`review_B_kaltsit_idle_zoom.png`）。重画 f1–3。
- 建议：整体孤立噪点约 6%（水月约 1%），run、skill 也有。

**Mon3tr**
- **严重**：idle 是竖直一团（约 84×92）、run 是横向带头（约 70×58）、attack f0/f3 竖直、f2 低平，一次"移动 → 攻击 → 移动"换 4 次剪影（`review_B_mon3tr_idle_run_attack_zoom.png`）。统一成 run 那样的横向带头剪影。
- 建议：idle 看不出头和眼睛，实机像一丛带绿光的荆棘；run 的红眼辨识度好很多，idle / attack 也要有。

**铃兰**
- 建议：skill f5 收在杖放右下、闭眼，和 idle f0（杖在左上）差太多，回 idle 时跳一下。
- 小问题：包围盒宽 72–84px，四人里最宽，idle 时星环插进博士精灵。

### 1.4 第四批

**乌尔比安**
- **严重**：锚几乎看不出来。idle / run 里只露出一片月牙锚爪，锚杆和金色舵轮淹没在大衣噪点里，像尾巴或镰刀（`review_D_lineup_idle0_3x.png`）。锚要是剪影主体，舵轮保留。
- **严重**：skill 缺"后仰举锚蓄力"；锚在 f2 就消失，比出手帧 f3 早一帧。重做 f1–f2：带锚后仰，f3 出手时锚才离手。
- 小问题：大衣满是单像素噪点（生成痕迹）；"重"只靠宽度撑，体量感不够。

**艾丽妮**
- **严重**：skill f3 是水平直刺，和 attack f1 几乎一样，不是规格要求的"回身大横斩"；代码在这一帧放的是横斩和环斩特效。重做 f2–f3。
- 建议：attack f1、f3 和 skill f3 提灯消失，播放时一闪一闪。所有帧都要有提灯。
- 小问题：腰间枪在 96px 下看不见，可以不管。

**归溟幽灵鲨**
- 建议：attack f2 是把锯盘水平前推，不是"原地回旋环斩"；代码画的是绕身一圈的锯环。重做成回旋。
- 小问题：长柄只有立绘的一半长，底部尖刺和金色齿轮饰没画。
- **替身**：帧间变化像素是艾丽妮 idle 的 2–3 倍，手在胸前和嘴边来回，f3 头纱变形，要稳定下来；实机里整体偏白、脸看不清，加一点对比。

**Logos**
- 建议：@2x 有洋红抠图残留（外套和飘带边缘共 165px），实机可见粉紫杂点（`review_D_magenta_fringe_logos_skill.png`）。48px 版没有。
- 小问题：笔约 24px 黑色细杆，像指挥棒；发色比参考浅。

**流明**
- **严重**：idle、run 共 10 帧看不见提灯，被量化糊进旅行包里（`review_D_lumen_lower.png`）；普攻 f0 提灯凭空出现在手里。提灯必须挂在身侧清楚可见，这是他最主要的识别点。
- **严重**：规格"出手帧 = 灯最亮"没做到。所有帧灯玻璃同一组冷白，没有亮度变化；attack f1 与 f2 灯高度一样，看不出提灯动作。出手帧灯玻璃改为暖黄亮起，attack f1 灯放低。
- 小问题：折伞任何一帧都看不出来；run f3 整体左移 4px；skill f5 的灯比 attack f0 大一圈。

**灯塔 prop_lighthouse**
- 建议：两帧之间除灯室外还有约 1100 个像素不同，石墙纹理在随机翻动，10 秒里整座塔在蠕动（`review_D_lighthouse_diff.png`）。帧 1 只改灯室。
- 小问题：亮帧灯室只是浅奶油色，场景暗化后亮灭分不清，灯室亮帧要更亮更暖。
