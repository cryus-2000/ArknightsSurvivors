# 28 · 手柄适配

## 做法
- 新 autoload `Pad`（`scripts/pad.gd`）：把手柄输入翻译成等价的键盘事件注入（device = 7777），所有界面沿用已有的键盘操作，不需要各自再写手柄逻辑。
- 对局移动直接读 `Pad.move_vec()`（左摇杆模拟量，圆形死区 0.18；十字键优先），轻推慢走。
- 界面导航：十字键 / 左摇杆（滞回 0.55 / 0.35），长按 0.38s 后每 0.11s 连发。从对局切到菜单时如果摇杆还推着，要先松开才会导航，避免走路的推杆直接移动卡片焦点。
- `Pad.using`：最近一次输入来自手柄时为 true，这时隐藏鼠标、提示文字换成手柄按键、卡片 / 按钮用焦点高亮代替悬停；碰键盘 / 鼠标就切回。

| 选卡 / 商店 / 暂停 / 结算 / 指南 / 属性 | 确认 | 返回 / 跳过 | Ⓨ 商店刷新 | 返回 | 属性面板 | 指南翻页 |

## 其它
- 受伤按伤害比例震动，死亡时长震一下；设置里新增「手柄震动」开关（`input/pad_rumble`）。
- 设置面板的行距改成按面板高度自适应（16 行放得下）。
- 开场指南的操作页、标题「操作说明」都加了手柄一行。
- 测试：`godot --path game -- --padsim` 会按时间线模拟手柄，从标题一路走到选卡，截图到 /tmp/claude-0/pad_*.png（`tests/pad_sim.gd`，只在带参数时加载）。
