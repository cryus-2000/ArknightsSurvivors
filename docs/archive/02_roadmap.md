# 02 · 开发路线

> 按全局框架 v1.0 第 37 节重排（2026-09-24）。旧的「阶段 0–5」到 v0.8 为止已基本完成（见文末）。

## P1 · Build
1. 技能互斥分支（S1 / S2 / S3 各两条）
2. 五条基础 Build：伞击创伤、触手猎杀、控制技能循环、反移情收割、深蓝低灯火
3. 首批 62 件藏品的效果数据（含 Tag）
4. Build Synergy 调整（B / D / E 藏品偏少，靠技能分支补）
5. Boss 核心奖励：第一个 Boss 三选一，第二个 Boss 给升华

完成标准：自动测试里，不同的局伤害结构明显不同（框架第 36 节）。

## P2 · 系统
1. 商店重构：三阶段职责、Soft Steering、刷新递增、特殊交易
2. 护盾 ✅（v0.8）
3. 受伤扣灯火 🔶（v0.8 已有滑动者撞击、黑潮扣灯火，未做通用规则）
4. 排异反应（改变玩法型）
5. 遭诅古物与遭诅交易

## P3 · 内容
1. 三结局（偏执泡影 / 伊莎玛拉 / 伊祖米克）
2. Boss 打磨
3. 更多藏品
4. 局外成长

## P4 · 扩展
确认水月能稳定产生多种 Build 之后，才开始新增可玩干员。

## 暂时不做
大量新干员、传统六武器系统（v0.8 的武器待定，见 00 第 3 节）、大量新 Boss、节点地图、大量剧情事件、大规模局外成长。
