## 2. 灯火

- 灯油掉率 2% → 1.2%（难度 3 再减半），精英灯油 40 → 25；基础消耗 120s → 150s 耗尽。
- **受击熄灯**：每次受到伤害灯火 −2。
- 灯火 < 30：拾取范围 −30%、刷怪 +15%、受伤 +15%（原 +30%）、敌速 +20%（保留）。灯火 ≥ 70 的加成不变。

## 3. 成长与援护

- 卡面与实现对齐：伞击·锋 ×1.15、伞击·展 ×1.10、伞击·迅 ×0.92（上限 4）、触手·蚀改为乘法 ×1.2、硬化 −2（上限 4）、技力卡唤醒次数下限 5。
- 援护：狙击 34 → 24、术师 24 → 20、辅助 20 → 16，升级倍率 1.5 → 1.35；医疗 2.4s/5% → 3.5s/3.5%。
- 潮刃水刃基础 0.85 → 0.62；无人机子弹 10 → 8、激光 4.6 → 3.4、导弹 34 → 26。
- 藏品池抽空时给源石锭 +12，不再回满。

## 4. 压力源差异化

- 溟痕：只掉血 + 减速，不再叠神经损伤。黑潮：掉血 + 熄灯，不再叠神经损伤。神经损伤只来自滑动者 / Boss。
- 神经满条：定身 1.0s + 10% 真伤 → 定身 0.4s + 攻速减半 2.5s + 8% 真伤。
- Boss 招式与冲击波**无视闪避**（`_enemy_hit(no_dodge)`）；冲击波定身 0.8 → 0.5。
- Boss 预警跟踪段压到 ≤ 50%（狙击 0.6 / 裁决 0.55 / 凝视 0.65 / 冲撞 0.45）。

## 5. 难度表（0–10）

标准 → 暗潮（生命 +15%）→ 浊流（攻击 +15%）→ 昏灯（消耗 +25%、灯油减半）→ 猎群（精英 45s）→ 拮据（源石 −30%）→ **疾影（Boss 预警 −25%）** → **潮涌（大群 +40%，Boss 在场照常）** → **永痕（溟痕不消散）** → 负伤（初始生命 −20%）→ 深蓝之树。躁动（敌速）和巨影（Boss 生命）被规则型替换。

## 6. 架构

- `scripts/boss_ai.gd`：Boss 行为、招式冷却、预警（创建 / 更新 / 判定 / 结算 / 绘制）、伊莎玛拉之泪，从 game.gd 拆出（−430 行）。状态仍在 game.gd，通过 `g` 引用；后续 fx / 商店 / 升级 UI / autotest 按同样方式拆。
- `_new_enemy` / `_spawn_chest` 统一初始化 `coma / wind / pose / haste / air / channel / dash_t / bleed / mv_until` 等状态字段，并在生成时预计算 `tex_move / tex_feign / tex_attack`，绘制时不再每帧拼字符串。
- `--balance` 输出新增 `out`：造成伤害按来源（伞击 / 触手 / 技能 / 水刃 / 触手桩 / 触须阵 / 无人机 / 援护 / 藏品）。

## 7. 自测（`--balance`，bot 不会躲）

4 局：两局在 2:15 前死于凿石者弹幕（bot 不走位），两局撑到 10:20 截止、最终 Boss 22%–77%。伤害来源：潮刃路线 水刃 ≈ 伞击 > 援护 ≈ 无人机；群触路线 伞击 > 触手 ≈ 触手桩 > 技能 > 无人机 > 援护。援护占比从 15–25% 降到 6–12%。
