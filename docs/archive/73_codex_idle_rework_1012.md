## 要求

1. **呼吸循环**：4 帧（f0 中位 → f1 下沉 1px → f2 最低 2px（@2x 2–4px）→ f3 回升），上半身（头、躯干、手里的武器）整体随呼吸上下；脚底保持贴第 46 行（@2x 第 92 行）不动。
2. **二次运动**：头发末梢、尾巴、衣摆 / 裙摆、挂饰、武器尖端比身体晚一帧，幅度 1px（@2x 1–2px）。
   - 德克萨斯：长发末梢与尾巴轻摆，剑尖随呼吸微动。
   - 星熊：盾跟身体一起下沉 1px，长发尾端摆 1px，独角不动。
   - 能天使：光环上下浮 1px（与身体反相或滞后一帧），光翼碎片轻闪，发梢摆动。
   - 安洁莉娜：大尾巴缓慢上下摆 1–2px，杖头摆 1px，狐耳尖滞后一帧。
   - 浊心斯卡蒂：帽檐和长发末梢滞后一帧，裙摆下缘轻摆，手杖保持竖直、杖头青光每帧 ≥ 2×2px（1x）。
3. **静止部位不要闪**：脸、衣服纹样、盾面这些不该变的地方逐帧保持同一组像素，只随呼吸整体平移（参照 docs/69 C 的同一要求）。
4. **不变的**：帧数 4、fps、单帧 48×48 / 96×96、脚底锚点 (24,46) / (48,92)、朝右、`#080E18` 外描边、≤ 24 色（与本人其他三条合计）、二值透明、配色（以当前 main 为准）、剪影外框高。**skill 末帧 = idle f0 逐像素相同**——所以 idle f0 尽量保持当前 f0 不变；如果 f0 必须改，同步改 skill 末帧。
5. 只改 `_idle`，run / attack / skill 不动（除第 4 条的 skill 末帧同步）。
