## 3. 水月主题机制映射
| 原作元素 | 在本作中的设计 |
|---|---|
| 灯火 | 随时间持续下降；灯火越低视野越小，敌人越强；击杀精英、拾取"灯油"可以补充 |
| 干员职业 | 决定起手武器和成长方向：术师打范围、狙击打单体穿透、先锋机动、重装嘲讽反伤、医疗回复、辅助减速 |
| 招募 | 升级选项里可能出现"招募干员"，作为自动攻击的僚机跟随 |
| 藏品 | 局内被动道具，多件可以触发组合效果 |
| 源石锭 | 局内货币，在商店节点使用 |
| 希望 | 招募和精英化的消耗资源 |
| 海嗣 / 大群 | 敌人有"进化"：存活越久越强，或者互相吞噬、融合成精英 |
| 不期而遇 | 节点事件，文字加选项，给奖励或加代价 |
| 局外成长 | 解锁新的起始干员、分队和藏品池 |

【待定】你最喜欢水月肉鸽的哪 1–2 个机制？这些机制会优先做进去。

## 5. 美术方向：像素小人
- 规格建议：角色 32×32 或 48×48，4 方向或 2 方向（左右镜像），每个动作 4–6 帧
- 调色：统一限定色板，深海蓝绿为主，灯火用暖橙色点缀
- **关于干员形象**：我不能直接画明日方舟的角色（包括像素化的"仿立绘"版本），可行的做法有：
  1. 你自己画，或者约像素画师画干员小人，我负责素材规范、切图和接入代码（同人圈最常见的做法）
  2. 用原创角色（比如"罗德岛的新人干员"），我可以设计原创像素角色
  3. 开发期间先用我做的原创占位小人，美术随时可以替换，不影响代码
- 海嗣类敌人、地形、特效、UI：可以走原创设计，统一深海风格
