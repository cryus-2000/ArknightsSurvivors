# 70 · Codex 特效单：德克萨斯「剑雨」（2026-10-12）

按 AGENTS.md（10-11 新规则）与 docs/66 的格式：特效单由 Claude 写，Codex 只交素材（1x + @2x、manifest、handoff、预览），**不改 `game/`**。
Claude 审规格后接入；接入前游戏里用的是 Claude 程序生成的版本（`tools/gen_fx_batch3.py`，见下「现状」），Codex 版到了以后**优先用 Codex 版**，Claude 版保留在 git 历史里作回退。

## 1. 为什么要这一条

用户 10-12：「德克萨斯的剑雨特效是不是可以优化一下」。原来的剑雨是 r130 内撒 12 柄 12×32 的小短剑、播一遍就没，看着弱、便宜。
10-12 Claude 侧已经把**编排**做成通用积木 `verb.fx_rain`（docs/61 §13.5）：剑按面积密度撒、错开 0.3–0.5 秒从高处加速扎下（带残影）、落地前地面先出预兆标记、落地冲击 + 插地停留 + 焦痕；
S3「剑雨滂沱」结束的那一场更大更密、最后一圈亮环；节点「剑雨·连」的回响是淡一档的轻量版。编排参数都在 `game/data/characters/texas.json`，**换素材不用改代码**——只要三条帧条的尺寸 / 帧序 / 锚点按本单交。

参考（文字描述，原作截图只在本机 `build/ref/`，不进仓库、不要嵌进素材）：原作德克萨斯 S2「剑雨」是一片发橙红光的剑从空中成排扎进地面，剑身细长、刃口发光、剑柄深色；插地瞬间有亮闪和火星，地面留下片刻的焦痕。

## 2. 要交的素材（`art/incoming/`，文件名固定，替换现有同名文件）

三条都是**横排帧条**：1x 宽 = 帧宽 × 帧数；@2x 每帧 2 倍（同一世界尺寸，docs/25 §6 的 × `A.hires` 规则；能重画细节最好，时间不够可最近邻放大）。
**二值透明**（alpha 只有 0 / 255，项目统一规则）；半透明感靠抖动（dither）疏密；nearest 采样。帧尺寸、帧数、锚点**必须与下表一致**（游戏按 `V6_FRAMES` 与 JSON 里的帧序切帧）。

### 2.1 `fx_texas_blade`（必做）——一柄剑：下落 + 插地

| 项 | 规格 |
|---|---|
| 帧尺寸（1x） | **16 × 40** |
| 帧数 / fps | **6 帧**；0–1 下落时循环（20 fps），2–5 插地后按停留时间（S1 0.35 秒）均匀铺开，**不按 fps 播** |
| 锚点 | **(8, 38) = 剑尖落点**（1x；@2x 为 (16, 76)）。插地帧里 (8, 38) 是**地面线**：剑尖埋进地下，地面线以下不画 |
| 朝向 | 剑尖朝下、竖直（游戏里会随机 ±5° 倾斜、随机水平翻转，所以左右不要画成不对称的光影方向） |
| 帧 0–1 下落 | 整柄剑（剑身约 20 px 长、5 px 宽含描边；护手 11 px 宽；剑柄 + 柄头约 6 px）+ **上方的拖影**（剑柄上方约 10 px，越往上越暗、越稀）+ 剑身两侧**抖动的外圈辉光**；两帧之间拖影 / 辉光错一格闪动 |
| 帧 2 插地 | 剑整体下沉约 5 px（剑尖埋进地面），**刃口最亮**（白热芯 + 橙刃、外圈实心辉光），地面线两侧各溅 1 px 土 |
| 帧 3 常态 | 插着的剑，辉光回到抖动 |
| 帧 4 冷却 | 刃口转暗红、芯转橙，没有辉光 |
| 帧 5 散去 | 剑身棋盘格抖动消失（只剩一半像素、暗红） |
| 不要 | 不画地面冲击 / 地面阴影（另两条帧条负责）；不画投影 |

### 2.2 `fx_texas_rain_hit`（必做）——落点冲击

| 项 | 规格 |
|---|---|
| 帧尺寸（1x） | **32 × 24** |
| 帧数 / fps | **5 帧，24 fps**，播一遍（约 0.21 秒） |
| 锚点 | **(16, 20) = 落点**（@2x (32, 40)）；地面闪光椭圆以它为中心、透视压扁约 0.4 |
| 帧 0 | 白热闪：一根不高的白热闪柱（约 10 px）+ 地面闪光椭圆（白芯 → 热橙 → 橙）+ 四道短斜光 |
| 帧 1–3 | 扩散环（橙 → 朱红 → 暗红，越来越稀）+ 一组**火星**向外上方飞、再落下（帧间连贯）+ 帧 2 两侧一点暗色土 |
| 帧 4 | 只剩几颗暗红余烬 |
| 尺寸感 | 游戏里每柄剑的冲击按剑的大小缩放（S1 每 1x 像素约 1.4 世界像素，S3 结束约 2.3），所以别画得太满——一片冲击不要盖住一个敌人 |

### 2.3 `fx_texas_rain_mark`（建议做）——地面标记：预兆 + 焦痕

| 项 | 规格 |
|---|---|
| 帧尺寸（1x） | **24 × 12** |
| 帧数 | **6 帧**：0–2 = 落地**前**的预兆（铺在落地前 0.12 秒里），3–5 = 落地**后**的焦痕（铺在 0.3–0.6 秒里，最后四成整体淡出）。不按 fps 播 |
| 锚点 | **(12, 6) = 帧中心 = 落点**（@2x (24, 12)） |
| 帧 0–2 预兆 | 一片深色阴影椭圆由小变大（帧 0 稀疏抖动、帧 2 实心 + 朱红边），**四个橙色刻度**从外向内收（瞄准感）；颜色越来越亮 |
| 帧 3–5 焦痕 | 焦黑椭圆 + 从中心放射的**余烬裂纹**（帧 3 热橙、帧 4 暗红且断续、帧 5 只剩稀疏焦黑和一两颗暗红） |
| 层 | 画在**地面层（人物下面）**，敌人 / 干员盖在它上面 |

## 3. 色板（三条共用，≤ 16 色）

| 用途 | 参考色 |
|---|---|
| 描边 / 最暗 | `#1c1218` |
| 剑柄暗钢 | `#4a3a44` |
| 余烬暗红 | `#8c2414` |
| 朱红刃边（主色） | `#e8401c` |
| 橙 | `#ff7a2a` |
| 热橙 | `#ffb873` |
| 白热芯 | `#fff3e2` |
| 落点阴影 / 焦痕 | `#160c10` / `#3a1a16` |

- 主色是**朱红—橙**（色相约 8–25°）。**不要用洋红 / 粉 / 紫**：敌方危险预警（`world.ENEMY_TELL`、敌弹描边、新星弹）是洋红，玩家要一眼分清「这是我方的剑」。
- 也要和能天使的弹药分开（docs/25 §6.1）：能天使是白红子弹 / 琥珀橙曳光 / 冰青 / 过热白，都是小点和细线；剑雨靠**深色描边的剑形 + 朱红刃**区分，不要画成纯亮色的光条。
- 游戏是 L4 观感预设（整体压暗、提鲜），刃口在深色地面上要亮；描边保证在亮地砖（浅滩、灯火通明）上也看得清。

## 4. 接入方式（Claude 侧，供 Codex 了解尺寸怎么用）

`texas.json` 里三处 `verb.fx_rain`（docs/61 §13.5）：

| 场合 | 柄数（r130） | 剑大小（每 1x 像素 = 世界像素） | 编排 |
|---|---|---|---|
| S1「剑雨」 | 约 21 柄（密度 4 / 万平方像素） | 1.4（`scale` 0.7） | 0.4 秒内错开落下，落差 96 px，下落 0.1 秒，两道残影；一半先落在范围内的敌人身上 |
| 节点「剑雨·连」回响 | 约 11 柄 | 1.2 | 淡一档（整体透明度 0.75）、一道残影、焦痕短 |
| S3「剑雨滂沱」结束 | 约 35 柄（密度 6.5） | 1.9；冲击 ×1.2 | 0.5 秒内落完，落差 120 px；最后一柄落地时中心再来一次放大冲击 + 一圈亮环（程序画） |

剑和冲击画在上层（普通混合），标记画在地面层；整体透明度跟随特效亮度设置与后期 `fx_dim`。缺任何一条帧条：缺剑 = 整场跳过（伤害自己的扩散环照旧）；缺冲击 / 标记 = 只少那一层。
