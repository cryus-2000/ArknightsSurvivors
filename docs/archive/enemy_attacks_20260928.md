# 普通怪与精英攻击调整（2026-09-28）

后期普通怪（收割者、奠基者、引痕者、巢涌者）的主招与第二招射程适度提高；后期精英的远程攻击也获得较远射程。其第二招在出生后约一秒即可进入预警，避免进入视野后一直未出手。骨海漂流体、滑动者、注亡拟嗣、狂奔者及分形补充了轻伤害的第二招，但这些早期怪的新招到 400 秒后才启用。

特效沿用正式预警与命中绘制：寒冷攻击用浅青色，神经攻击用紫色，出手时使用对应的突刺、扫击、震爆或弹幕特效；图鉴自动列出招式与状态。奠基者晶刺和掠海漂移体贯射附短暂寒冷；收割者与引痕者的第二招附少量神经损伤；囊海爬行者震爆可造成最多 0.2 秒僵直。异常状态仅在有效命中后生效，护盾与闪避仍可阻挡；普通怪僵直全局间隔为 8 秒，Boss 战继续转为减速。280 秒后全场第二招每 0.9 秒至多起手一记，避免大群同时铺满预警。
