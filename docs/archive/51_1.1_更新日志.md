# 《方舟幸存者》1.1 更新日志
> 版本 1.1 · 依据 9f3fe18 → 0e60dd5 · 2026-09-30

## Boss

- 所有 Boss 加入阶段卡点：血条上有刻度，这一幕没打满最短时长就停在刻度上升起阶段护盾；过卡点时 Boss 短暂无敌，最终 Boss 过卡点会掉落回复与灯油。
- 每只 Boss 都多了新招式（密集弹幕、刃波、落点、锁线等），出招也更频繁；新招一律先给预警。
- 部分 Boss 会在特定时机露出「破绽」，期间受到的伤害 +40%。
- Boss 登场 2 秒后接触伤害才生效；Boss 倒下时清掉它还没结算的预警，下一波大群至少推迟 12 秒。
- Boss 招式预警至少 0.6 秒；高难度缩短预警时只压缩跟踪阶段。两只 Boss 同时在场时不会同时放大招。
- 最终 Boss 登场时场地收拢成固定大小、不再缩圈，自然溟痕停止生成并在 20 秒内退去；还没打完的中期 Boss 会撤离（不给奖励）。
- Boss 只在当前安全圈内活动，不会被击退或冲出圈外；Boss 溟痕的数量和存在时间有上限。
- 塑路者：半血后最老的碎片变成核心，12 秒内打碎可让碎片崩解并露出 3 秒破绽，否则碎片回流、下次冲撞多几段；第二幕冲撞固定 2 连。
- 接潮组：一具假死后有 8 秒倒计时，期间打倒另一具就两具一起倒下，否则复苏到 50% 生命（每具最多 2 次）；假死期间另一具会沿连线反击。
- 圣徒伊比利亚 / 卡门：弹药打空后先近身追击，再读条装填；读条时打出足够伤害或冲刺穿过它可以打断并换来 5 秒破绽，没打断则连发三条瞄准线。卡门第二幕会先换剑近战再装填；伊比利亚攻击范围缩小、裁决伤害提高。
- 偏执泡影：凝视改为多道依次亮起；主控在它附近时全队攻击速度 -10%；第一次归零会结茧 8 秒，打破外壳则复活到 40% 生命并露出 5 秒破绽，超时则同样复活但凝视永久多一道。外壳至少要约 4 秒才能打破，周围击杀海嗣也会削壳。
- 伊祖米克：学习期固定 20 秒；吸收子代改为叠强化层，不再回血；解读阶段场上有 3 根灯柱，靠近点亮后光圈内每秒回复灯火、子代减速；66% 后周期性放全场地波，要冲刺或站进点亮的灯圈躲开。
- 凋亡损伤：被伊祖米克命中会累积，满条时全队技能充能暂停最多 4 秒；冲刺可清掉一部分。
- 伊莎玛拉：一阶段为人形，不攻击也不能被选中，会治疗周围的海嗣，并靠伊莎玛拉之泪充能（主控站到泪旁边可压制）；充能满后变身为敌对形态，四种招式轮换，未被压制的泪会在变身时同时发射泪滴共鸣；过卡点后出招更快。
- 最后的骑士：66% 后场上立起冰枪桩，引它冲锋撞上会长枪脱手、露出 5 秒破绽；冲锋伤害提高，二阶段冲锋 3 次一组、之后喘气 2.5 秒；新增先标冰线再沿线追击的冲锋；命中附带冰霜减速。
- 骑士与最后的骑士体型缩小；骑士、塑路者的冲锋会按预警线冲到底，不再半路停下。
- 部件类单位（如塑路者核心）会被优先攻击；它附近倒下的海嗣也会削掉部件的生命。
- 偏执泡影：打过最后一道卡点（约 1/3 血）就坠落进入近战的第二形态，凝视提前多一道；归零时仍会结茧。
- 伊莎玛拉：敌对形态离主控太远时会带直线预警「潮涌迫近」，冲到主控面前，不会一直躲在杂兵后面。
- 最终 Boss 在场时，场上普通海嗣数量有上限，不会被杂兵墙挡住输出（精英和 Boss 召唤物不受影响）。
- 队友优先攻击射程内的 Boss。
- 修正：接潮组两具身体的大招可能同时起手；现在两具共用一个出招名额。

## 小怪与状态

- 新增 6 种海嗣：壳海狂奔者（冲到身边自爆）、浮海飘航者（发射神经弹）、钵海收割者（潜伏装睡，靠近才醒）、深溟奠基者（厚甲难击退）、深溟引痕者（前刺后狂暴）、深溟巢涌者（神经光环）。
- 移除三种非原作的自制敌人：巨骸漂流体、沉海撕裂者、潜海裂魔。
- 13 种小怪与精英新增第二招（突刺、扫击、短扇形弹幕、震爆等），都有预警；前期小怪的第二招要到 6:40 以后才会用。
- 大群改为每个威胁等级两套混编（远程后排、冲锋成群、坦克前排等），随机出现、不连续重复。
- 新事件「围猎」：约 1:30 海嗣合拢成包围圈，打出缺口突围可回复 20% 生命、灯火 +20，把圈内海嗣全部肃清可获得半级经验；高难度档的围猎更短、圈上海嗣更脆。
- 神经损伤重做：只在溟痕（含巢涌者的神经光环）里累积，离开后回落；满格时受到一次最大生命 12% 的真实伤害并眩晕 1.2 秒（冲刺可挣脱），之后 5 秒不再累积。敌人命中不再附带神经损伤，也不再降低攻击速度。
- 浮海飘航者的神经弹落地会留下一小片溟痕。
- 滑动者、骑士精英等冲刺类小怪会真正冲到主控身边，不再只冲一小段。
- 更好躲：狂奔者自爆、囊海爬行者鼓胀、收割者扇形斩的前摇加长；收割者、引痕者伤害下调，引痕者同屏最多 4 只。
- 收割者、引痕者、巢涌者、奠基者在更远处就会摆出攻击姿态，更早看得出来。
- 敌方弹幕飞行速度约 +20%。
- 圆形预警、冲击环、溟痕、自爆范围等改为按脚下的地面椭圆判定，和画面一致。

## 溟痕与灯标

- 新增引航灯标：自然溟痕出现后，每 60–75 秒在主控附近溟痕最密的地方立一座；站进光圈约 2.5 秒点燃（离开会慢慢回退）。
- 点燃后驱散周围的溟痕，30 秒内这一片不再生成自然溟痕，灯火 +5，并清空主控与光圈内队友的神经损伤；灯火暗淡时点燃较慢。
- 灯标 45 秒没被点燃会熄灭，让下一座出现；Boss 在场时也会刷出；屏幕外的灯标有方向与距离指示。
- 波涛迭起·Ⅷ：自然溟痕常驻，只有引航灯标能驱散。
- 缩圈：Boss 在场时暂停收缩，Boss 倒下后接着走；出圈后前 2 秒不掉血（灯火照常流失），主控身边会出现回圈方向箭头和倒计时。
- 黑潮边缘改画成一整圈密铺的溟痕带，内沿有一道青线标出边界。

## 操作

- 新增手动普攻：设置 → 游戏 →「普通攻击：手动」（下局生效，只管主控，队友照旧自动）；左键 / J 攻击，朝光标方向；手柄 Ⓧ / RT 攻击、右摇杆瞄准；手机有攻击按钮；按住连发。
- 乌尔比安三技能「必须开辟」由主控自己选落点：鼠标光标、按住技能键蓄距离、右摇杆或触屏拖动。
- 手动技能改为 Q / E（手柄 Ⓐ / Ⓨ）；没开手动普攻时 J 仍可放手动技能。
- 新增倍速：右上角按钮或 V 键在 1× / 1.5× / 2× 之间切换，暂停和菜单不受影响。
- 选卡时数字键可以选第 4 张及以后的卡。
- 设置面板分成声音 / 画面 / 游戏三页，Q / E（手柄 LB / RB）或点标签切换。
- 致谢与声明可用 C 键 / 手柄 Ⓨ 打开。
- 手动普攻时点倍速 / 暂停按钮不会顺带出手。
- 倒下过渡与结算淡入期间短暂屏蔽输入，防止连按误触「再次探索」或「回到标题」。
- 修正暂停 / 结算页用回车或 Ⓐ 重新开始、回到标题时出错。
- 乌尔比安三技能选落点：键盘 / 手柄按住技能键蓄距离时有提示音，松手掷出；出手中或锚未收回时按住也会先蓄力。

## 结局与文案

- 结局三、四按原作对调：深蓝之心线的最终 Boss 改为伊莎玛拉（结局三），抉择线改为伊祖米克（结局四）；已达成的结局不受影响。
- 结局名改用原作：结局一 · 平凡即是喜乐 / 结局二 · 静谧时代 / 结局三 · 息潮的代价 / 结局四 · 如星空般深蓝；预告、图鉴、尾声同步重写。
- 最终 Boss 登场后结局路线锁定，场上没开的祭坛沉入海底；错过窗口的事件不再补刷（修正结局判错）。
- 海嗣祭坛：只在主控走到身边时打开，不会被范围攻击误开；跑远了会挪到前方；存在 90 秒，最多 2 个同时在场；最终 Boss 前 10 秒会提示「即将沉没」。
- 「抉择·其三」提前到 8:00–8:30 出现；抉择事件随时可以「离开」，不拿藏品也不改结局路线。
- 拿到「再次倾听」会切回深蓝之心线；已拥有观望 / 犹疑时不再重复出现；骑士阵亡后不再出现「挣脱」。
- 付灯火代价时灯火最低降到 10，不会反而增加灯火。
- 9:00 预告后结局路线又变了会重新预告；修正结局线切换时多弹一次「结局一」。
- 灯火四档改用原作叫法：通明 / 摇曳 / 暗淡 / 寂灭。
- 流明技能与天赋改回原作名：沐雨 / 沛霖 / 灯火不灭 / 凡人之愿（效果不变）。
- 偏执泡影、塑路者、圣徒等图鉴故事按原作设定改写；倾听 / 再次倾听写全实际代价。
- 指南「溟痕与黑潮」页按新机制重写，操作页补全手动技能、手动普攻与手柄按键；图鉴新增引航灯标条目。
- 藏品、干员、敌人说明逐条对照实际效果校对，统一术语与标点。
- 图鉴：新存档只开放干员，敌人、场景道具在冒险中遭遇后收录，藏品获得后、结局达成后收录；结局藏品标为「结局」类别。

## 界面

- Boss 血条只给真正的 Boss，最多 2 条（多出来写「另有 N 个 Boss」）；新增形态点、阶段刻度、破绽倒计时和招式名；对 Boss 的伤害数字合并显示。
- Boss 在屏幕外时，边缘显示头像、方向和距离；换阶段、倒下都有演出。
- Boss 预警统一成五种样式（落点圈、直线、扇形、缺口环、必须冲刺）：跟踪中为虚线，锁定后变实线并闪白。
- Boss 机制都有画面提示：倒计时环、部件金边、圣徒装填读条、接潮假死倒计时、泡影的茧与认知负担、伊祖米克的灯柱与地波、骑士的冰枪桩等。
- 神经损伤有 HUD 量表和主控头顶电弧，满格眩晕时提示「冲刺挣脱」；血条新增「侵蚀待扣」斜纹段。
- 选人页和招募卡新增奶位标签「净化：侵蚀 · 神经损伤」「回复」，按干员技能实际能清除的状态和能否回复主控自动生成。
- 横幅改为排队显示（最多 3 条、自动去重），Boss 战时次要提示改为左侧小字；两只同名精英同时出现有专门横幅。
- 后期降噪：友方特效按密度变淡，敌方弹幕加深色外圈与洋红描边，经验结晶加深色底，伤害数字合并限量，精英标识不再被灯光遮住。
- 击杀溶解、敌人描边与经验结晶不再都是青色；巢涌者光环画在地面层并标出范围。
- 倒下过渡：约 1.7 秒灯灭、沉入深海，「探索终止」浮出后再显示结算，可跳过；最终 Boss 倒下后先播击败演出再结算。
- 标题开场重做（蓝眼泪涟漪、海滩脚印依次亮起），看过一次后只播简短版；标题可更换封面干员。
- 选难度页显示该档全部效果，未解锁的档也能翻看；选人页显示真实属性，说明放得下就全部展开，被截断的可点开「详情」。
- 结算、胜利结算、设置、开局标题卡等多处排版修正；祭坛即将沉没时方位指示会闪烁。
- 全体干员与博士的待机 / 跑步动画重画，斯卡蒂恢复蓝帽；跑步步频随移速变化，不再倒着跑，编队换边更平滑。
- 同伴骑士缩小并补上冲锋 / 刺击特效；Mon3tr 普攻与熔毁重画（三技能恢复红色）；维什戴尔炮击换新特效；逻各斯普攻改为咒文字符。
- 打击感：命中反馈按普攻 / 技能 / 暴击 / 弱点分档，暴击命中有金色火花、弱点命中有对应弱点颜色的火花；Boss 破绽期间命中有金色冲击环、短顿帧和金色「破绽」伤害数字；持续伤害不再一直闪白；冲刺收势更明显。
- 修正 Mon3tr 卡在柱子边原地发呆、博士停下时悬在半空。
- 图鉴：凯尔希与 Mon3tr 的同名动作并排展示；敌人条目列出第二招与 Boss 招式，可看演示。
- EA 版主页新增「Boss 演练」：自选 Boss、主控、成长阶段练习，不记录进度。
- 画质一键切换「高 / 低」（设置 · 画面第一项）：低档关掉辉光、景深等特效并减半粒子，适合配置较低的电脑和手机。
- 后期画面绘制优化，怪多、黑潮缩圈时帧率明显提升：8–10 分钟场面最满时，帧时间中位 29 → 19 毫秒（约 34 → 53 帧 / 秒），最慢 1% 的帧 50 → 27 毫秒（1920×1080、高画质）。
- 手动普攻模式下，开局提示和标题页操作说明改为手动的按键；标题页补上乌尔比安三技能怎么选落点。
- 所有 Boss 露出破绽时头顶都有破绽标记和倒计时。

## 音效

- Boss 大招有固定的起手 / 命中音效，每只 Boss 叠一层专属音色，换阶段有阶段音。
- Boss 专属事件音：泡影结茧 / 破茧、伊祖米克灯柱点亮与地波读秒、凋亡暂停 / 恢复、骑士撞桩与冰枪桩碎裂、卡门换剑等。
- 引航灯标点燃进度、点燃光爆与安全区结束；神经损伤满格；神经弹溟痕落地。
- 骑士冲锋 / 枪刺 / 寒冰领域；围猎预告、合拢与突围。
- 海嗣尖啸、吐射、撕咬；维什戴尔炮击音效重做。
- 倒下时新增「灯灭」音效。
- 修正开局音效连播两次、盖过音乐；伊祖米克学习阶段不再过早切到终局音乐。
- 网页版战斗配乐乐句之间不再有约 1 秒的空隙。
- 混音分优先级：同名音效短时间内合并，重要音效优先，同时响的音多时整体稍降，网页版防爆音。

## 数值与节奏

- 难度改为三档：波涛迭起 / 波涛迭起·Ⅳ / 波涛迭起·Ⅷ，通关一档解锁下一档；旧存档按已通关进度迁移。
- 8:40 以后刷怪增长放缓；中期 Boss 在场时刷怪照常，大群最多顺延 40 秒。
- Boss 出招间隔缩短。
- 商人：第二、三次来访价格 ×1.5 / ×2，每买一件其余商品涨价 20%，每次最多买 2 件藏品；商人会随缩圈留在圈内。
- 一局最多持有 15 种藏品（升级已有藏品不占位）；精英掉藏品改为 30% 概率。
- 灯油掉落减少：普通击杀 1.2% → 0.6%，精英改为 65% 概率掉落。
- 12 级以后升级所需经验逐渐增加，到 30 级约为原来的 1.95 倍。
- 国王套装改为常驻一小截加成，主控生命低于 50%（原 30%）时大幅加强。
- 极速之手改为「编队每有 1 名干员，全队攻击速度 +5%（最多 +20%）」。
- 投币玩具 / 骑士戒律·新编上限降到 +20% / +30%。
