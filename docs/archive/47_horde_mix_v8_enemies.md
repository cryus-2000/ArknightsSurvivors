# 47 大群混编与 V8 新敌人（EA 1.1）

用户要求（1.1）：「大群来袭」提升怪物种类，现在的大群太单一。Boss与怪物会话实现，数值会话核强度，云端 A/B 由测试与验收做。

## 1. 大群混编（26d1e79）

- 数据：`data/waves.json` 每个威胁等级的 `horde_mix`，每套编成是 `{name, body, extra}`。
  - `body`：主体列表，循环填满。
  - `extra`：特种，每项 `{id, pct, min, max, at}`。`pct` 是占本次大群总数的比例，四舍五入后夹在 min–max 之间；所有特种合计最多占一半。
  - `at` 是站位：`ring` 沿整圈 / `back` 后排（半径 +90，远程）/ `front` 前排（−70，慢速坦克）/ `pack` 挤在一段弧上成群冲来。
- 抽法：每次大群用 `g.rng` 从本档随机抽一套（同 seed 可复现），和上一次同名就换下一套。没写 `horde_mix` 的等级沿用旧的 `horde` 列表。数量公式不变。
- 代码：`run/spawner.gd` 的 `horde_mix()` / `horde_plan()`；telemetry 的 `hordes[].comp` 是 `{类型: 数量}`，`hordes[].mix` 是编成名。
- 测试：`tests/prot_test.gd` 的 `test_horde_mix()`。
