# 165 · 最终 Boss 完整改造与联动修正（2026-10-27）

用户授权：四个最终 Boss 各至少七种主动攻击，符合设定；补齐特效并自主处理此前全部反馈。实现分支 `codex/final-boss-complete`，基线 `main` 的 `151d572a4`。本记录覆盖旧文档中“最终 Boss 四招”“登场清掉杂兵”“泪滴需持续站住压制”等口径。

## 1. 计数与设定边界

| Boss | 主动攻击数 | 主题依据 |
|---|---:|---|
| 偏执泡影 | 7 | 认知负担、幻象与侵蚀 |
| 最后的骑士 | 8 | 长枪、冲锋、寒冰与重生 |
| 伊莎玛拉 | 7 | 人形治疗、大群合唱、泪滴与海嗣形态 |
| 伊祖米克 | 7 | 子代、学习、分享与海流 |

依据仓库原作资料 `49_原作参考` / `49c_bosses` 和现有 `142b_boss_axis`。新增招式名称与几何是本作改编，不声称为原作技能原名。主动攻击计数不包含阶段转换、无敌、受击反击、召唤物数量或同一招的强化版本；撕咬/横扫只算一招，冲锋连段也只算一招。

新增攻击通过 `final_attacks.gd` 调度，每次连段结束后至少七秒才允许下个补充攻击，原有轮转继续工作。演练与实战共用同一出招入口。无普通杂兵时，合唱、护群等攻击有本体来源的减量回退，不会永久失效。

## 2. 当前完整攻击清单

### 偏执泡影：7 招

| 攻击 | 行为与反制 |
|---|---|
| 凝视 | 多道光束依次瞄准，预警末段冻结方向；沿侧向移动避开。 |
| 叠影 | 每一个落点分别追踪当时队长位置；保留各段锁定窗口，连续移动即可拉开落点。 |
| 泡影环 | 有缺口的慢速弹环；寻找出口，不是全屏必中。 |
| 呼号 | 坠落形态的扇形喷涌；退出扇形或穿身。 |
| 追猎泡（新增） | 两枚慢速泡先追踪 1.8 秒，再按当前方向直行；侧向绕开。 |
| 幻影合围（新增） | 两侧幻象先后发动瞄准光束；分别按各自来源计算方向，打断或进入破绽可取消。 |
| 泡影收束（新增） | 周围泡群向中心合拢，保留约四分之一圆周的出口；及时向外脱离。 |

保留认知负担光环与坠落、结茧机制。第一条生命降至 1/3 时坠落；首次归零结茧，外壳被破坏后恢复至 **最大生命的 80%**，不是满血也不是 40%。复苏不会额外复制 Boss。

### 最后的骑士：8 招

| 攻击 | 行为与反制 |
|---|---|
| 冲锋 | 预警后直线突进；诱导撞柱，重生后接续多段。 |
| 冰线 | 寒冰激光封锁线路，随后寒冷追击；新绘制包含冰晶核心、边缘与残留轨迹。 |
| 长枪连刺 | 近身连续刺击，末段前刺；向侧面或身后离开。 |
| 掷枪 | 锁定后投枪；不再顺带补回部分冰柱。 |
| 长枪回旋 | 重生阶段的缺口回旋；穿过空缺，避免贴身硬吃。 |
| 踏冰裂阵（新增） | 三条分叉冰裂线路依次爆发；站进支路之间。 |
| 断潮劈击（新增） | 宽弧形冰刃向前推进；离开行进带，实际碰撞随冰刃移动。 |
| 侧踏挑枪（新增） | 无伤害侧移预告后重新瞄准挑枪；侧移本身不计为额外攻击。 |

五根冰柱按扇区分散，出生有一秒预告。**当前批全部被撞碎后才生成下一批**；单根破坏、投枪、阶段切换和旧到期逻辑都不能提前补柱。保留撞柱破绽和重生冲锋的喘息窗口。

### 伊莎玛拉：7 招

| 攻击 | 行为与反制 |
|---|---|
| 泪落 | 歌眼之间连续落击，分段显示落点；离开连线。 |
| 三线扫射 | 保留历史招式名，当前实际为四束；分别追踪与锁定，后幕包含队友分锁。 |
| 大群之歌 | 带双缺口的扩散音环，后幕多圈；连续寻找不同方向的出口。 |
| 撕咬 / 横扫 | 距离决定扇形范围，濒死强化追加第二段；不重复计数。 |
| 合唱齐射（新增） | 最多三名存活合唱海嗣作为发射来源；击杀来源会取消其读条。网被拆空时本体仅发一束。 |
| 合唱压境（新增） | 从合唱来源发出慢速前进的音波体；横向绕行或击杀来源。无合唱时减为本体一列。 |
| 深海触腕（新增） | 两条有先后顺序的侧向触腕夹击，中间与外侧留出通路。 |

人形阶段开场出现三枚泪滴，每枚最多维持一名强化海嗣，每次治疗最多新强化一名，总计最多三名。满血普通海嗣也可被强化；已有精英、Boss、宝箱、友方、部件与泪滴不会被重复强化。

强化改成真正的精英数值换算：先抵消普通刷怪的密度、后期血量、前后期微调，再施加共享精英倍率（生命 ×7、伤害 ×1.3、经验 ×10）；保留共同难度、威胁级别与其他独立状态。普通怪密度掉落权重暂置 1。强化目标带红色描边。

跑过泪滴即永久净化，无需站住；对应海嗣立即解除这份强化，保持剩余生命比例及其他增减益。净化名额不再重生。基础转化仍在最多约 18 秒内完成，未净化泪每枚额外提供 0.35/秒充能。未净化泪转为可破坏歌眼（每枚生命为 Boss 最大生命的 2.5%，不额外掉经验），同时影响开场共鸣与合唱网。击破歌眼取消其待发共鸣并解除对应强化；Boss 死亡也解除剩余强化。人形与歌眼不会继承旧敌对泪滴的接触扣血。

### 伊祖米克：7 招

| 攻击 | 行为与反制 |
|---|---|
| 潮汐坠落 | 瞄准落点连续坠落；观察锁定后移位。 |
| 解读旋涡 | 旋涡范围压力；离开持续危险区域。 |
| 分享 | 追踪后的扇形溅射；全场版本仍是同一技能的阶段强化，不另计。 |
| 震撼 | 阶段性全场压力；利用冲刺或点亮灯柱的保护范围。 |
| 护群触腕（新增） | 优先从活子代位置发动扇形触腕；无子代时改从本体发动。 |
| 迁徙潮（新增） | 两段水墙横穿场地，中间留 180 像素通道；预告显示整条行进通道和方向。 |
| 深渊涌流（新增） | 两次向内收拢的环带，中心与外侧安全；范围判定包含内半径。 |

学习期及战斗期子代均从实际战斗边缘生成，优先选择可通过的地形；初始移动速度统一为 **45 像素/秒**。保留到达本体后的吸收、结茧与灯柱反制，末幕不靠普通怪补刷维持压力。

## 3. 其余反馈

- 任意 Boss 登场都保留原有小怪，停止普通刷怪、精英、大群与威胁增援；Boss 机制召唤保持。清场队列已删除，旧 trickle 参数不能重新开启补怪。
- 瞄准型攻击按真实发射来源追踪目标，预警末段冻结至少 0.4 秒；竞技场固定形状攻击保持位置机制，不强行变为自瞄。修正接潮主教、卡门及多来源光束的方向计算。
- 拉普兰德失色效果只作用于非友方像素：单独透明遮罩复用当前动画帧，覆盖主控、队友、召唤物、博士与我方猎潮骑士。没有矩形背景保色块；低画质仍不启用失色后处理。遮罩在技能外停止更新。
- 能天使八份现有 CC0 音频做保守低通与 -2 dB 处理，保留格式、时长与采样数。主枪声 RMS 降低约 3.6–5.1 dB，技能/爆发降低约 4 dB；技能播放增益另降。三种轮换枪声共享两声部上限，技能连发共享一声部上限；技能录音存在时单枪再压低 5 dB，普通枪声优先级低于 Boss 提示。未提高 BGM 音量，未替换成来源不明录音。
