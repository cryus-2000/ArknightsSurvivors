# 170 · 伊莎玛拉二阶段连段与图案弹幕（2026-10-27）

状态：已实现，待用户视觉验收与云端同 seed 难度对照。分支 `claude/boss-ishar`（起点 `codex/boss-fx-rework` 72f41c3c7），未合入 main。

用户 10-27：每只 Boss 分别做特效、招式之间的连携、招式数量；打 Boss 要有「东方 Project 打 Boss 的感觉」。同日更正：东方只是例子，不照搬符卡制度（不做符卡名横幅、按符卡清屏）；要的是图案弹幕、规律可学、可读、有节奏和压迫感、Boss 存在感，用本作题材自己的语言表现；阶段沿用现有幕制。另：Boss 的攻击方式要有自己的特色。

本页的连段、四个新招与几何均为本作改编，不是原作技能名或原作机制。原作依据（人形治疗、泪、大群、「她不再歌唱，它为大群发声」）见 docs/49c §3。

## 1. 结构：按幕两组有限连段

二阶段三幕（卡点 66% / 33%）不变。每幕两组连段交替；每组 ≤4 段，段间收势（一、二幕 0.32 秒，三幕 0.22 秒），每段等上一段的预警与待发弹全部结束再起，最后一段放完、且她自己的弹落到 20 枚以下（最多多等 2.5 秒）后给破绽（一、二幕 2.0 秒，三幕 1.8 秒，沿用通用破绽受伤倍率），破绽不与密集弹幕重叠。两组之间才允许「潮涌迫近」。

| 幕 | 连段 | 段序 |
|---|---|---|
| 一「大群」 | 合唱连段 | 合唱环颂 → 合唱齐射 → 歌声涟漪 → 撕咬 / 横扫 |
| | 锁定连段 | 三线扫射 → 大群之声 → 深海触腕 |
| 二「濒死强化」 | 泪雨连段 | 泪雨 → 歌声涟漪 → 泪落 |
| | 抚愈连段 | 抚愈之歌 → 合唱压境 → 大群之歌 |
| 三「回声」 | 网鸣连段 | 网鸣 → 大群之声 → 撕咬 / 横扫 |
| | 终曲连段 | 合唱环颂 → 大群之歌 → 泪雨 → 三线扫射（分锁三人，之后 2 秒不出招） |

撕咬 / 横扫按距离自选（原规则）。连段名只出现在演练列表和测试里，不出横幅。

**打断与清队列**：眩晕、破绽（含潮涌迫近落地破绽）、无敌、变身保护、死亡、超时（每组 22 秒）都会清掉未出的段和待发弹，并撤掉她自己未结算的伤害预警（泪眼周期共鸣除外）；已飞出去的弹保留。过卡点转幕只清队列，`gate_pass` 原有 0.8 秒不出招保留，下一组按新幕选；不清屏、不做额外停顿。

**与原有调度的关系**：二阶段的补充招式（合唱齐射 / 合唱压境 / 深海触腕）不再由 `final_attacks` 每 5 秒独立轮换，改为连段的一段；变身时未压制泪滴的齐射、泪眼每 6 秒共鸣、三幕被拆海嗣的回声圈、召唤合唱均保持原样。`boss/ishar_combos` = 0 退回旧的固定轮转，供云端对照。

## 2. 新招（7 → 13 招）

弹体用 `g.ebullets` 的 Boss 弹（真实伤害，命中后通用无敌帧），分三档：音弹 r6 中速、大泪 r13 慢速、碎片 r5 快速。全部有出手前的青光蓄势（0.6–0.8 秒），不使用随机数。

| 招式 | 取材 | 图案与规律 | 破网关系 |
|---|---|---|---|
| 合唱环颂 | 大群合唱 | 每个合唱源（≤3 只连线海嗣）0.8 秒蓄音后每秒一圈、连发 3 圈 10 枚慢速音弹（95px/s，三幕 12 枚），各源错开 0.25 秒；首圈让主控方向正好落在两弹之间，第二圈错半格，各源再错 0.4 弧度 → 交错相位环 | 击杀源取消它剩下的圈；网空时本体两圈 |
| 泪雨 | 伊莎玛拉之泪 | 本体朝主控扇形落 5 颗大泪（三幕 7 颗，72px/s），每颗 1.6 秒后碎成 6 枚快速碎片（165px/s）；慢弹控走位，碎片考验离大泪的距离 | 每个仍在的歌眼也落 1 颗 |
| 抚愈之歌 | 人形治疗 | 2.4 秒歌声：连线常亮，同时放四瓣慢速花形弹（每 0.4 秒一层共 6 层、转 0.26 弧度，85px/s） | 歌声结束时仍连着的海嗣回满生命；眩晕 / 破绽打断，治疗取消 |
| 大群之声 | 「它为大群发声」 | 粗光束：1.8 秒预警（前 1.1 秒跟随主控、后 0.7 秒锁定），宽 92、长 900；结算 e.dmg × 0.9，之后持续 1.0 秒，留在光束里每次 × 0.45（命中后有通用无敌帧）；锁定后侧移一个身位即可躲开 | 本体发出，不受网影响；一、三幕各一次 |
| 歌声涟漪（非弹幕） | 歌声笼罩战场 | 主控脚下、移动方向前方 200、再前方偏侧 330 各一处 r105 涟漪区，1.3 / 1.55 / 1.8 秒预警后结算 e.dmg × 0.35，之后留 3 秒：站在里面每 0.5 秒 e.dmg × 0.12 并减速（移速 × 0.75）。不追人，逼主控换方向 | 本体发出；与弹幕错开（合唱连段第三段、泪雨连段第二段） |
| 网鸣 | 「它为大群发声」 | 每 1.1 秒一波，歌声团（r8、150px/s）沿每条连线流到节点海嗣，到达后从节点向外散成 4 枚音弹扇（间隔 0.5 弧度），每波扇面偏转 0.25 弧度；三波（三幕四波） | 击破节点：流向它的歌声当场消散，该节点不再散弹；网空时本体两圈保底 |

主动攻击计数口径同 docs/165（不含机制）：泪落、三线扫射、大群之歌、撕咬 / 横扫、合唱齐射、合唱压境、深海触腕 + 上表 6 招 = **13 招**，每幕 6–8 招出现在连段里。

**10-27 第二轮（用户：弹幕太密、激光太快太细、补一个大激光）**：环颂每圈 14→10 枚（三幕不再加到 16）、圈距 0.7→1.0 秒、各源错开 0.12→0.25 秒；抚愈花形五瓣→四瓣、层距 0.3→0.4 秒；网鸣每节点 5→4 枚、波距 0.9→1.1 秒、三幕不再加到四波；三线扫射预警 1.0→1.3 秒、半宽 14→20（enemies.json ishar.attack line_warn / line_width）；新增大群之声。

**10-27 第三轮（用户：光束要有蓄力与消散；要一招非弹幕的独有攻击；单发伤害下调）**：
- 光束（三线扫射、泪滴共鸣 / 共鸣、合唱齐射、大群之声）：读条期本体从 1 像素细线长到半宽 35%、亮度递增，发射口光点变大、聚光颗粒向内收；开火第一帧原有 bbeam 闪 + 0.06 秒整条白闪；结束后 0.35 秒内光束变细、断成碎段侧漂淡出，沿线颗粒散开。大群之声在 1 秒持续段结束后才消散。画面只读判定几何。
- 新增非弹幕招「歌声涟漪」（上表）。
- 伤害旋钮 `boss/ishar_combo_dmg`（缺省 0.8）：连段模式下变身后的 e.dmg 整体 × 0.8，所有招式同比下调；`boss/ishar_combos` 0 时不生效。云端测完再定。

压力控制：她同时在场的弹上限 170（同 `boss_patterns` 单体 160 量级）；单发伤害 e.dmg × 0.2–0.42，低于原有大群之歌（× 0.7）与三线扫射；连段结束的破绽比旧轮转的 0.875 秒恢复更长。本地只验证了规则与上限，**整场难度待云端同 seed 对照**（§5）。

## 9. 拉长战斗与持续压迫（10-28，协调人转用户「都按推荐做」）

起因（boss-bench 测试台）：10:00 血量 36 000、编队中位秒伤 506、单场中位 65 秒，人形约 10 秒就转化且打不到她，队长胜局结束生命中位 98%，有无 18 细胞都 92–100%。目标：单场中位 90–120 秒、一阶段真正能打、伤害靠持续压迫（不靠单发大伤害，40% 单次 / 50% 两秒保护不动）、输出占比仍 ≥35–40%、单场胜率 70–80%。

全部做成 `balance.json` boss 段旋钮（缺省即新值；回到旧行为的值写在括号里）：

| 旋钮 | 新值 | 作用 |
|---|---|---|
| `hp_x_ishar` | 1.5（1） | 血量 36 000 → 54 000 |
| `ishar_p1_hit` | 1（0） | 人形可受伤：不再标友方 / 无敌，治疗、泪滴、充能照旧；HUD 状态写「人形 · 转化充能 N%（打到 85% 血提前转化）」 |
| `ishar_p1_line` | 0.85 | 人形最多打到 85% 血，越线截回；打到血线或充能满，先到先转化 |
| `ishar_p1_scale` | 1.0（0.6） | 充能 18 → 30 秒（三泪都在约 14.6 秒）；所以强队约 15 秒打到血线，弱队等充能 |
| `ishar_web_heal` | 0.0003（0） | 每只连线海嗣每秒回她最大生命 0.03%（6 只约 97/秒，约编队秒伤的 19%），不超过本幕起点；每 1.5 秒飘一次合计数字 + 回复连线。拆网 = 停回血 |
| `ishar_web_shield` | 0.4（0） | 连线海嗣接线时带自身最大生命 40% 的潮盾 |
| `ishar_zone_linger` / `ishar_zone_tick` | 4 秒 / 0.16（3 / 0.12） | 歌声涟漪留存更久、每 0.5 秒伤害更高（持续掉血 + 减速） |
| `ishar_shot_mult` | 1.2（1） | 连段图案弹单发伤害（每发仍是 e.dmg × 0.25 量级的小伤害） |
| `ishar_combo_gap` | 0.26（0.32） | 一二幕段间收势缩短，连段衔接更紧；三幕仍 0.22 |

纸面估算：人形约 15 秒打掉 15%（8 100）；二阶段剩 45 900，按测试台二阶段有效秒伤约 650（含破绽加成）扣掉网回血约 60 → 约 78 秒；合计约 95 秒，落在 90–120。回血和护盾都按队伍火力拉开差距：火力强的队拆网快、回血少；无成长队拆不动网，回血占比更高。

输出窗口复测（`ishar_window_probe`，同 §8 口径）：一幕 70.1% / 二幕 66.5% / 三幕 45.3%，破绽 5×2.0 / 5×2.0 / 4×1.8 秒，弹峰值 90 / 42 / 120，仍高于 35–40%。

单测：`ishar_combo_test` 加人形受伤截线与提前转化、网回血封顶、连线护盾；`friendly_target_regression` 用人形当中立夹具，测试内关掉 `ishar_p1_hit`。本地只跑了 ishar_combo / ishar_p2 / friendly_target / boss_support 四项，均通过。

建议云端（boss-bench）：`hp_x_ishar` 1.3 / 1.5 / 1.7 × `ishar_web_heal` 0 / 0.0003 / 0.0005，无成长与 18 细胞各 ≥3 份；看单场用时中位、胜率、队长结束生命中位、人形阶段时长。胜率高于 80% 先加 `ishar_web_heal` / `ishar_zone_tick`，低于 70% 先降 `hp_x_ishar`。

改动文件：`data/balance.json`、`enemies/bosses/ishar.gd`、`enemies/bosses/ishar_combos.gd`、`run/ishar_encounter.gd`；共享文件只改单行：`run/spawner.gd`（人形标记）、`run/enemies.gd`（人形走遭遇模块的判断）、`screens/hud_bars.gd`（人形状态文字）；测试 `ishar_combo_test.gd`、`friendly_target_regression.gd`。
