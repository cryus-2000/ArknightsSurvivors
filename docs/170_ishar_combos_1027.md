# 170 · 伊莎玛拉二阶段连段与图案弹幕（2026-10-27）

状态：已实现，待用户视觉验收与云端同 seed 难度对照。分支 `claude/boss-ishar`（起点 `codex/boss-fx-rework` 72f41c3c7），未合入 main。

用户 10-27：每只 Boss 分别做特效、招式之间的连携、招式数量；打 Boss 要有「东方 Project 打 Boss 的感觉」。同日更正：东方只是例子，不照搬符卡制度（不做符卡名横幅、按符卡清屏）；要的是图案弹幕、规律可学、可读、有节奏和压迫感、Boss 存在感，用本作题材自己的语言表现；阶段沿用现有幕制。另：Boss 的攻击方式要有自己的特色。

本页的连段、四个新招与几何均为本作改编，不是原作技能名或原作机制。原作依据（人形治疗、泪、大群、「她不再歌唱，它为大群发声」）见 docs/49c §3。

## 1. 结构：按幕两组有限连段

二阶段三幕（卡点 66% / 33%）不变。每幕两组连段交替；每组 ≤4 段，段间收势（一、二幕 0.32 秒，三幕 0.22 秒），每段等上一段的预警与待发弹全部结束再起，结束后给破绽（一、二幕 1.6 秒，三幕 1.4 秒，沿用通用破绽受伤倍率）。两组之间才允许「潮涌迫近」。

| 幕 | 连段 | 段序 |
|---|---|---|
| 一「大群」 | 合唱连段 | 合唱环颂 → 合唱齐射 → 撕咬 / 横扫 |
| | 锁定连段 | 三线扫射 → 大群之歌 → 深海触腕 |
| 二「濒死强化」 | 泪雨连段 | 泪雨 → 泪落 → 撕咬 / 横扫 |
| | 抚愈连段 | 抚愈之歌 → 合唱压境 → 三线扫射 |
| 三「回声」 | 网鸣连段 | 网鸣 → 深海触腕 → 撕咬 / 横扫 |
| | 终曲连段 | 合唱环颂 → 大群之歌 → 泪雨 → 三线扫射（分锁三人，之后 2 秒不出招） |

撕咬 / 横扫按距离自选（原规则）。连段名只出现在演练列表和测试里，不出横幅。

**打断与清队列**：眩晕、破绽（含潮涌迫近落地破绽）、无敌、变身保护、死亡、超时（每组 22 秒）都会清掉未出的段和待发弹，并撤掉她自己未结算的伤害预警（泪眼周期共鸣除外）；已飞出去的弹保留。过卡点转幕只清队列，`gate_pass` 原有 0.8 秒不出招保留，下一组按新幕选；不清屏、不做额外停顿。

**与原有调度的关系**：二阶段的补充招式（合唱齐射 / 合唱压境 / 深海触腕）不再由 `final_attacks` 每 5 秒独立轮换，改为连段的一段；变身时未压制泪滴的齐射、泪眼每 6 秒共鸣、三幕被拆海嗣的回声圈、召唤合唱均保持原样。`boss/ishar_combos` = 0 退回旧的固定轮转，供云端对照。

## 2. 新招（7 → 11 招）

弹体用 `g.ebullets` 的 Boss 弹（真实伤害，命中后通用无敌帧），分三档：音弹 r6 中速、大泪 r13 慢速、碎片 r5 快速。全部有出手前的青光蓄势（0.6–0.8 秒），不使用随机数。

| 招式 | 取材 | 图案与规律 | 破网关系 |
|---|---|---|---|
| 合唱环颂 | 大群合唱 | 每个合唱源（≤3 只连线海嗣）0.8 秒蓄音后连发 3 圈 14 枚慢速音弹（95px/s，三幕 16 枚）；首圈让主控方向正好落在两弹之间，第二圈错半格，各源再错 0.4 弧度 → 交错相位环 | 击杀源取消它剩下的圈；网空时本体两圈 |
| 泪雨 | 伊莎玛拉之泪 | 本体朝主控扇形落 5 颗大泪（三幕 7 颗，72px/s），每颗 1.6 秒后碎成 6 枚快速碎片（165px/s）；慢弹控走位，碎片考验离大泪的距离 | 每个仍在的歌眼也落 1 颗 |
| 抚愈之歌 | 人形治疗 | 2.4 秒歌声：连线常亮，同时放五瓣慢速花形弹（每 0.3 秒一层、转 0.21 弧度，85px/s） | 歌声结束时仍连着的海嗣回满生命；眩晕 / 破绽打断，治疗取消 |
| 网鸣 | 「它为大群发声」 | 每 0.9 秒一波，歌声团（r8、150px/s）沿每条连线流到节点海嗣，到达后从节点向外散成 5 枚音弹扇（间隔 0.42 弧度），每波扇面偏转 0.18 弧度；三波（三幕四波） | 击破节点：流向它的歌声当场消散，该节点不再散弹；网空时本体两圈保底 |

主动攻击计数口径同 docs/165（不含机制）：泪落、三线扫射、大群之歌、撕咬 / 横扫、合唱齐射、合唱压境、深海触腕 + 上表 4 招 = **11 招**，每幕 6–8 招出现在连段里。

压力控制：她同时在场的弹上限 170（同 `boss_patterns` 单体 160 量级）；单发伤害 e.dmg × 0.2–0.42，低于原有大群之歌（× 0.7）与三线扫射；连段结束的破绽比旧轮转的 0.875 秒恢复更长。本地只验证了规则与上限，**整场难度待云端同 seed 对照**（§5）。

## 3. 画面

- **弹体**：`enemies.json` 新增 `bcol_core`（淡青白弹芯）与 `bcol_outline`（暗青描边），沿用 world 统一的 Boss 弹画法（发光弹芯 + 暗描边 + 专属色亮边）；三档弹按半径区分。
- **地面预警**（`render/ishar_tell_draw.gd`，新文件）：伊莎玛拉的落点圈、直线、扇形不再用光学观感的斜线填充与闪烁描边，改为暗红低填充 + 2 像素格涟漪勾边——落点圈三道断续涟漪向圆心收拢（读条）、直线两侧点列（跟踪中稀疏、锁定后加密）+ 沿线推进的水纹、扇形外弧点列 + 内弧推进；最后 0.15 秒勾边提亮，不整片白闪。范围与判定共用同一份几何。`render/ishar_tell` = 0 退回通用画法。
- **颗粒**（docs/136）：蓄势青色颗粒向源点收拢；大泪碎裂、节点散弹用颗粒迸散而不是实心环；抚愈之歌期间本体持续升起颗粒、被治疗海嗣冒颗粒。低画质 / 关光学观感不画。
- 颜色：弹为专属青绿，预警为暗红 / 洋红（只给危险）。
