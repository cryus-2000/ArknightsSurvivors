# 180 · 认知塑造前 18 细胞改为看得见的数值（方案，待用户审）

10-28 协调人转测试台发现，未改代码。基于分支 `claude/dodge-meta`：队长基础闪避已归零，受到伤害 ×0.9，闪避线为未雨绸缪Ⅰ–Ⅲ。

## 1. 问题

- 推荐点法下，18 细胞只买到 **危机感Ⅰ（13：1 层护盾 + 破碎反震）+ 攻击性Ⅰ（5：伤害 +8%）**。
- 测试台 10:00 快照里，生命 178 对 174，编队输出差 ±5%，等级都是 27。护盾只在快被打死时才起作用，整局 m0 = m18 = 33.9%（docs/158 §4）。
- 另有一组数据：分级调整定档 t5 是 30.4 / 55.4%（docs/158 §6，112 局），两组对不上，说明 m18 的差距靠运气。
- 闪避归零后，m0 和 m18 都会再降（两者都不含闪避），需要重测。

## 2. 改法：每条线把量提前给到第一级，线总量与总价不变

满点和 docs/109 §15 的四档校准都不受影响。

| 节点 | 现 价格 / 效果 | 改 价格 / 效果 | 线总量（不变） |
|---|---|---|---|
| 攻击性Ⅰ–Ⅴ | 5 / 9 / 14 / 19 / 24；+8 / 4 / 4 / 4 / 4% | **4** / 9 / 14 / 19 / **25**；**+12** / 3 / 3 / 3 / 3% | 全体伤害 +24%，71 细胞 |
| 生存本能Ⅰ–Ⅴ | 5 / 9 / 14 / 19 / 24；+6% ×5 | **4** / 9 / 14 / 19 / **25**；**+12** / 4.5 / 4.5 / 4.5 / 4.5% | 队长最大生命 +30%，71 |
| 自我保护Ⅰ–Ⅳ | 8 / 12 / 18 / 24；−3 / 3 / 3 / 4% | **5** / **13** / **19** / **25**；**−6** / 2 / 2 / 3% | 受到伤害 −13%，62 |
| 未雨绸缪Ⅰ–Ⅲ | 8 / 12 / 18；+5 / 5 / 5% | **5** / **13** / **20**；**+6** / 5 / 4% | 闪避 +15%，38 |

**新推荐点法前 18 细胞** = 攻击性Ⅰ 4 + 生存本能Ⅰ 4 + 自我保护Ⅰ 5 + 未雨绸缪Ⅰ 5。

- 局内看得见：队长生命 +12%（10:00 快照约 174 → 195），伤害 +12%，受伤 −6%，闪避 6%。
- 危机感Ⅰ（13）排到第 5 位，之后照旧是生命感悟 / 领导欲 / 好奇心 / 收藏癖。
- 首局拿到 13 细胞的玩家能点前 3 个。

## 3. 约束核对

- 结算系数仍封顶 ×1.5，生机细胞产出不动；总价 625 不变，4–6 小时寿命不变。
- 保命触发全保留：危机感反震、生存本能Ⅴ免死、自我保护Ⅳ静守、绝处逢生。只是不再排在前 18。
- 「先砍回复再满点」：生命感悟线不动，不进前 18，回复仍是满点溢出时先砍的那一项。`meta/stat_scale` 仍是 1。
- 闪避线已算进去：未雨绸缪Ⅰ提前到前 18，在 0.6 上限内。
- 存档不受影响：节点 id 不变，已点的照旧有效，只是每级的量变了。

## 4. 预计

按 docs/109 §14 的单线换算：生命 +10% ≈ +0.29 logit，受伤 −10% ≈ +0.61，伤害 +10% ≈ +0.39，护盾 1 层 ≈ +0.61，重叠系数 0.67。

| | 现 m18（护盾 + 伤害 8%） | 改 m18 |
|---|---|---|
| 估算 | ≈ +0.6 logit（实测 0 ～ +25 点，不稳） | 伤害 0.47 + 生命 0.35 + 受伤 0.37 + 闪避约 0.30 → ×0.67 ≈ **+1.0 logit** |
| 胜率（m0 按 30–35%） | — | **约 52–58%**，比 m0 高 20–25 点，落在 50–60% |

改后的量每时每刻都在起作用，不靠濒死触发，m18 的差距应当稳定，不会再出现 0 点的情况。55 细胞和满点的形状会变，需要一起重测。
