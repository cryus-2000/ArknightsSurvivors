## 0. 第二版（11-05 用户看 GIF：「凯尔希的S3应该是红色的，并且爆炸也是红色的，并且不毁重构的特效有点太不明显了」）

- **S3 整招改红**，和 Mon3tr 本体染红统一（「红色只给危险」凯尔希 S3 按用户指定破例）：起手爆柱、熔毁期间身边热流 / 脚下淡环、熔毁爪（实心重月牙 + 熔滴）全用熔毁红色组——暗血红 `#30090a / #5c100d` → `#941c12 / #cc361a` → 亮橙红 `#ff6c2e` → 暖白热芯（进 emit）；偏橙、不用敌方预警的纯红 / 玫红。照地光也换橙红（颜色组 `melt`）。
- **熔毁爆改红，大、亮、实、短**：结晶一闪（2 拍）→ 实心大爆团两拍（半径 21 美术像素 ≈ 42 世界，白热芯 → 橙红）→ 第三拍中心烧空破成火环、碎晶往外飞落；共 10 拍（0.67 秒）。冲击环、回响环、余焰淡边同改红。红色招式不撒颗粒池颗粒（颗粒池按干员一套绿色），碎晶在帧条里。
- **不毁重构加重构过程**（Mon3tr 身上，跟着走，接在三连爆后 7 拍）：12 块碎片带拖尾从外圈飞回本体 → 骨架线（脊 + 四对肋，2 像素粗）从下往上一段段亮起 → 合拢一闪（实心亮团 + 地上亮环）+ 一盏照地光 → 熄；14 拍。和治疗（骨白薄荷）完全分开。

## 2. 实现

- `game/scripts/render/fx_pxplane_kal.gd`：事件 → 件表；跟人走的件记 `kfm`（相对 Mon3tr）/ `kfl`（相对队长），每拍按对方当前位置跳格；落地件留原地。
- `fx_pxplane.gd`：METAS 加 `pxp_kaltsit.json`（前缀 `ka_`）、IDS 加凯尔希、事件 / 地面层 / 排序转 KA；`fx/px_plane = 2` 时凯尔希不接管（没有旧做法版，对照 2 = 当前游戏）。
- 钩子（全部只画）：`ob_summon._mf_claw`（kal_claw，每个方向一次）、`ob_summon.mf_draw`（接管时不画熔毁红残影 / 红雾）、`ob_summon.sm_debride`（kal_debride）、`ob_elite._el_land`（kal_pounce）、`data_operator._heal`（kal_heal，两条分支）、`skill_link` l_kaltsit（kal_link，接管时不画 LFB.ka_block）。熔毁 / 回防 / 余焰走现成的 `exec_shape` → shape 事件；三连爆的第 2 / 3 下按「0.6 秒内已有一次熔毁」认作回响。
- 颜色组 `data/fx_pxplane/kaltsit.json`（颗粒 shard / tri / ember、照地光、治疗光 heal、受击反应 flash）。
