### 5.5 两两组合表

43 块逐对列就是 20 × 21 格；按「布局类 × 本因类」压成下表，任一对能不能组合、怎么结算都由这张表加 5.3 / 5.4 两表决定（`totem.compat`）：

| 本因类 ＼ 布局 | 红（战斗时机） | 绿（路口时机） | 蓝 / 全色（任意时机） |
|---|---|---|---|
| **战斗**（歌唱、沉默、辩论） | ✅ 时机内生效；同色协语 | ❌ 灰掉（路口没有战斗） | ✅ 只在战斗类时机生效（路口时机那一份作废，面板提示） |
| **路口**（惊讶、愤怒、疑惑、爱恋、捕猎、繁衍、歇息） | ❌ 灰掉 | ✅ 改指定的卡；同色协语 | ✅ 只在路口类时机生效 |
| **经过**（朗诵、慰藉、告解、呼救、喜悦、憧憬、满足、筑巢、掠夺、迁徙） | ✅ 每个时机结束时结算一次 | ✅ 那个路口选完卡时结算 | ✅ 同左 |
| **任意**（巡视） | ✅ 只降坍缩 | ✅ 翻卡 + 降坍缩 | ✅ |

- 协语：同色（红 + 红 / 绿 + 绿 / 蓝 + 蓝），或布局是到来 / 离去。全色布局配哪色本因都触发；无色两块只能互配。
- 「多时机」布局（战士、拱门、灌木、兽类、人类、砂石、离去）配「经过」本因时，**每个时机各结算一次**（原作「每处节点各生效」）。这是稀有布局值钱的地方：人类 + 呼救 = 立即回复 30%。
- 「每个时机立即」类（呼救、满足）按布局的时机数立即结算（原作「每选择一处节点立即…」）。

## 6. 机器人（宣告规则，本作拟）

持有可组合的一对时，按顺序：
1. 生命 <40%：立刻类布局 + 回复 / 护盾 / 沉默。

## 8. 圈外寒冷与冻结（`cold`，用户 11-20 定，替代水月黑潮的圈外直接掉血）

**规则来源**：PRTS「术语释义」（11-20 查证）——**寒冷**：攻击速度 −30，持续时间内再次受到寒冷则变为冻结；**冻结**：无法移动、攻击及使用技能。原作只有「两次寒冷 → 冻结」，**没有**寒冷值、减速、冻结后免疫这些说法，下面凡是数值都是本作拟，表里逐条标。

数据：`mechanics.json cold`；敌人的加值写在 `enemies.json`（`cold_add` / `cold_aura` / `cold_pulse` / `frozen_mult`）。代码未接，萨米实装时与 `gate_drop`、`family`、`stab_taken`、双王字段、结局 flag 这几处一起开单（docs/392 §11.8）。

### 8.1 寒冷值

| 项 | 数值 / 公式 | 出处 |
|---|---|---|
| 量表 | 0–100，**每人一份**（队长 + 出击模式的队友） | 本作拟 |
| 圈外上涨 | 每秒 + 20 × (1 + 0.15 × 缩圈阶段) × (1 + min(出圈距离 ÷ 300, 1))；出圈即开始涨，没有水月的 2 秒缓冲（减速本身就是预警） | 本作拟 |
| 积满用时 | 阶段 0 圈边 5.0 秒 / 深处 2.5 秒；阶段 2 圈边 3.8 / 深处 1.9；阶段 4 圈边 3.1 / 深处 1.6 | 由上式 |
| 回圈消退 | 每秒 −50（满值 2 秒退光），不涨不降的中间态没有 | 本作拟 |
| 减速 | 移速 × (1 − 0.5 × 寒冷值 ÷ 100)，线性，满值前一刻 −50%；和冰霜等其他减速**合计封顶 −50%** | 用户定「上限约 50%」；原作寒冷减的是攻速，本作改成移速，攻速不减 |

### 8.2 冻结

| 项 | 数值 | 出处 |
|---|---|---|
| 触发 | 寒冷值到 100 | 原作是两次寒冷叠成冻结；本作换成量表满 |
| 时长 | 1.75 秒，结束时寒冷值清零 | 用户定 1.5–2 秒 |
| 冻结中 | 不能移动、不能攻击、不能放技能（三技能停转、终结技 Q 不能用）、**不能冲刺** | 前三条原作；不能冲刺用户推荐、本作定 |
| 冻结掉血 | 每秒 1.3 × (2.5 + 1.5 × 缩圈阶段) × (1 + min(出圈距离 ÷ 300, 1))，即水月黑潮同位置的 **1.3 倍**；在圈内被敌人冻住时按阶段 0、距离 0 算（3.25 / 秒） | 用户定「比水月稍高」；1.3 本作拟 |
| 解冻免疫 | 冻结结束后 3 秒内寒冷值不涨、不会再冻；3 秒后仍在圈外就从 0 重新积 | 用户定约 3 秒；原作无明文，口径同通用 `enemy/root_immune 3.0` |
| 回圈 | 冻结立即解除（冻结中被挤回圈里、或圈扩到脚下都算），之后同样 3 秒免疫 | 用户定 |

**跟水月比（队长 100 生命、在圈外一直站 10 秒，不算敌人）**：

| 缩圈阶段 / 出圈距离 | 积满 | 冻结一次掉血 | 萨米 10 秒合计（冻结次数） | 水月 10 秒合计 |
|---|---|---|---|---|
| 0 / 圈边 | 5.0 秒 | 5.7 | 5.7（1 次） | 20.0 |
| 0 / 300 | 2.5 秒 | 11.4 | 13.0（2 次） | 40.0 |
| 2 / 圈边 | 3.8 秒 | 12.5 | 12.5（1 次） | 44.0 |
| 2 / 300 | 1.9 秒 | 25.0 | 44.9（2 次） | 88.0 |
| 4 / 圈边 | 3.1 秒 | 19.3 | 19.3（1 次） | 68.0 |
| 4 / 300 | 1.6 秒 | 38.7 | 77.3（2 次） | 136.0 |

单看圈外本身扣的血，萨米只有水月的 30–55%，因为前段只减速不扣血、冻结后还有 3 秒免疫。真正的代价在冻结那 1.75 秒：不能动也不能还手，被怪群和精英围着打（破冰者 / 雪怪小队打冻结目标 ×2）。云端跑出「圈外死亡率 / 出圈秒数」后，如果出圈明显比水月划算，先调 `freeze.dps_k`（1.3），再调 `gain_out.base`（20）；免疫 3 秒不动（用户定的）。单次冻结掉血仍走 `combat.lose_hp`，受 2 秒合计上限保护。

### 8.3 队友

- 随行模式：不积寒冷、不会冻结（用户定）。
- 出击模式且人在圈外：自己一份寒冷值，涨降、冻结、免疫全同队长；冻结中原地不动、不攻击、技能停转。掉血按自身最大生命同比例（上表数值 ÷ 100 × 自身最大生命）。本作拟。
- 切回随行时寒冷值清零、冻结解除（随行本来就不结算）。本作拟。
