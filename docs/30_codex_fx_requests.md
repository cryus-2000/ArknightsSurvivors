# 30 · 给 Codex 的特效美术需求（第二批干员武器特效）

> 2026-09-25，Claude 提出。用户审查实战连拍后认为：乌尔比安的锚和他原画的武器对不上、艾丽妮是刺剑却用了弧形斩击、幽灵鲨是圆锯却用了刀光。
> 三项现在都已由 Claude **程序绘制**做了过渡版（能用，但不如手绘像素精致）；Codex 出图后，Claude 接入 `V6_FRAMES` 并替换程序绘制，缺图时仍退回程序版。

## 通用规范

- 像素密度与人物一致：**1 个美术像素 = 屏幕 2 像素**（`PX = 2`）。帧条按「游戏里 2 倍显示正好合适」的尺寸画，**不要指望程序再放大**（第三方帧条被放大到 4–6 倍、颗粒比人物粗一倍，是这次返工的原因）。
- 同时交 `@2x` 高清版（与人物帧条相同的约定）。
- 横向帧条、等宽帧、透明背景；朝向统一**朝右**（程序按攻击方向旋转 / 翻转）。
- 色板：深海主题，**不要暖黄 / 土黄 / 米白的尘土色**（战场被暖色灯光照着，浅灰浅米色会显得发黄，用户已要求删除这类效果）。高光用冷白或干员主色。
- 交付：`art/incoming/` + 各自的 manifest / 预览，照第二批（squad_batch4）的流程。

## 1. 乌尔比安：钩锚飞行体 `proj_ulpianus_anchor`

- **参考**：`op_ulpianus_attack.png` 第 3 帧高举的那把武器——黑蓝色长杆 + 一只向后弯的大钩（不是标准的 ⚓ 船锚）。
- 规格：约 **40 × 20** 像素（@1x），**2 帧**（刃口一道蓝光闪一下即可），朝右，锚尾在左（连锁链处留一个小环）。
- 配色：锚身 `#1A1F33` → `#2B3552`，刃口高光 `#6699FF`，描边近黑。
- 可选：`proj_ulpianus_chain` 锁链节平铺图，**8 × 6** 像素、1 帧（程序沿锁链方向平铺）。
- 用法：S1「必须接触」/ S3「必须开辟」掷出时沿直线飞 0.16–0.22 秒；咬地后乌尔比安顺锁链弹射过去砸下。

## 2. 艾丽妮：刺击光束 `fx_irene_thrust`

- **参考**：细剑突刺——《哈迪斯》长矛突刺、《死亡细胞》细剑：一道**细长、尖头朝前**的光束瞬间伸到最长，然后变细消失；剑尖有一个四角星闪。
- 规格：**64 × 12** 像素（@1x），**5 帧**，朝右，左端是出剑点：
  - 第 1 帧：短而亮的起手（约 1/3 长）
  - 第 2 帧：伸到最长，最宽处约 5 像素，剑尖星闪最大
  - 第 3–5 帧：逐帧变细、变短、淡出，星闪缩小消失
- 配色：外层玫瑰 `#F299CC`，内芯近白 `#FFF4FA`，星闪白。
- 用法：普攻每次两段（两道光束上下错开 4 像素、先后 0.1 秒）；游戏里按攻击长度（120）拉伸时只做 ≤ 1.1 倍的横向伸缩。

## 3. 归溟幽灵鲨：锯环 `fx_specter_saw` / `fx_specter_saw_blood`

- **参考**：她的武器是长柄上的**圆锯盘**（`op_specter_unchained_attack.png`）。普攻是贴身 360° 一圈，表现为锯盘绕身一圈的轨迹：一圈**斜向锯齿**的圆环，高速旋转、带运动残影。
- 规格：**俯视 45° 压扁的椭圆环**，约 **80 × 44** 像素（@1x，对应半径 75 的攻击范围按 2 倍显示），**6 帧**：
  - 第 1–2 帧：环从小张开到全尺寸，锯齿清晰
  - 第 3–4 帧：全尺寸，锯齿带顺时针运动模糊，前半圈（靠镜头一侧）更亮
  - 第 5–6 帧：淡出，只剩残影
- 两套配色：
  - `fx_specter_saw`：幽灵银蓝（锯身 `#8FA3BF`、齿尖冷白 `#E6F0FF`）
  - `fx_specter_saw_blood`：S3 求生之压，血红（锯身 `#8C2A38`、齿尖 `#FF8090`），齿更大一号
- 用法：每次环斩播一遍（0.24–0.3 秒）；S3 期间攻击范围 ×1.5，程序按 1.5 倍缩放（这张允许到 3 倍）。
