# 90 · Codex 美术单：B站 Toy 封面与图标（2026-10-13）

> 用户 10-13：「封面美术交给 Codex 做，让它用它的生图能力做」。
> 用途：B站 Toy 平台的作品封面（列表卡片 / 详情页头图）与图标。可用生图能力出图，再按本单要求整理、像素化或修图。

## 1. 游戏介绍（给生图用的背景）

- **名称**：方舟幸存者（Arknights Survivors），副标「水月与深蓝之树 · MIZUKI & CAERULA ARBOR」。
- **性质**：《明日方舟》同人作品，非官方、非商业、免费游玩。
- **类型**：像素风「类幸存者」肉鸽。玩家操控一名队长干员走位，编队里的干员自动攻击；一局约 10 分钟，从浅海走到深海，最后打最终 Boss。
- **题材**：取自明日方舟集成战略「水月与深蓝之树」——涨潮的深海、海嗣、深蓝之树、溟痕。
- **核心意象**：
  - **一盏灯火**：队长身边的暖光，是生命线；深海一片暗蓝，只有灯火照到的地方是暖的。
  - **灯标**：海床上可以点亮的灯塔 / 信标，点亮后把黑暗推开。
  - **深蓝之树**：远处发着冷光的巨大树状结构（标题页背景里那座由发光线条构成、倒影映在海面的巨树）。
  - **海嗣**：从暗处涌来的成群怪物，剪影状、红色眼点。
- **干员**：罗德岛干员的 Q 版像素小人（48 / 96 像素帧条风格）——水月、斯卡蒂、浊心斯卡蒂、凯尔希、维什戴尔、德克萨斯等 18 人。封面里出现干员时，用本作的 Q 版像素造型（参照 `art/incoming/op_<id>_idle@2x.png` 与标题页），不要画成原作立绘风格。

## 2. 画面风格

- **像素风**：硬边、有限色板、清晰的像素颗粒；可以有发光、雾和景深，但主体是像素画质感（不要写实厚涂、不要 3D 渲染、不要光滑矢量）。
- **色调**：深海夜色为底——深蓝 / 靛紫（约 #0a1020 → #1b1f45），冷光青（UI 主色 #36E2DC），灯火金（#F4C04E）作为唯一暖色焦点；海嗣点缀少量暗红眼点。整体「冷里一点暖」。
- **构图气质**：安静、孤独但不绝望——一小队人举着灯走在深海里，远处是巨大的发光之树，周围暗处有成群的影子。参照标题页（`game` 标题画面）与现有宣传图 `art/promo/keyart_1920x1080.png`、`art/promo/itch/cover_f/`。
- **标题字**：如需在封面上放标题，用本作标题页的「方舟 幸存者」像素 logo 风格（青色、带像素描边与小星点），文字清晰可读；也可以不放字（B站卡片下方会显示名称），**两版都要**。

## 3. 规格与交付

| 文件 | 尺寸 | 要求 |
|---|---|---|
| `art/promo/toy/toy_poster_4x3.png` | 1200×900（4:3） | 封面主图，**带标题字**；PNG，≤ 2 MB |
| `art/promo/toy/toy_poster_4x3_notext.png` | 1200×900 | 同一张不带字 |
| `art/promo/toy/toy_icon.png` | 512×512（1:1） | 图标：小尺寸也能认出——灯火 + 一名干员 Q 版头像或灯标剪影；PNG / JPEG，**≤ 512 KB** |
| `art/promo/toy/toy_poster_preview.png` | 任意 | 主图在 B站卡片尺寸（约 400×300）缩小后的效果预览 |

- 主体（灯火 / 干员 / 标题）放在画面中间 80% 的安全区内，四周可能被平台裁切或圆角。
- 缩到 400×300 时，灯火与主角仍要一眼看到，不要细碎噪点糊成一片。
- 至少出 **2 个构图方案**（例如 A：近景小队举灯 + 远处巨树；B：灯标点亮的瞬间、光圈推开海嗣），每个方案带字 / 不带字各一张，交给用户挑。

## 4. 禁止事项

- 不使用鹰角网络（Hypergryph）/ 明日方舟的官方 logo、官方立绘、官方 UI 截图或可识别的官方美术素材；不仿冒官方宣传图的版式。
- 不出现「官方」「正版」字样；如果放副标，可写「同人作品」。
- 不画血腥、暴露或其他不适合 B站全年龄区的内容。

## 5. 交付方式

只动 `art/promo/toy/`；一个提交，附 `handoff.md`（每张图的构图说明、生图提示词摘要、后期处理步骤）。交回时告诉 Claude 提交号。
