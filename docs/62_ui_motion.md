## 2. 共用规则

### 2.1 时长档

| 档 | 时长 | 用在 |
| --- | --- | --- |
| T1 微 | 120 ms | 按下反馈、悬停、闪一下、减少动态时唯一允许的淡入淡出 |
| T2 短 | 220 ms | 单个元素进出、选中切换、页签内容替换 |
| T3 中 | 380 ms | 面板进出、一组元素的整段（含错开） |
| T4 招牌 | 600 ms | 每个界面的招牌动效整段（含错开，最长不超过 900 ms） |
| T5 演出 | ≥ 1000 ms | 只给已有的演出：标题开场、开局、Boss 登场 / 击破、倒下过渡；不新增 |

错开（stagger）统一取 60 / 90 / 120 ms 三档；一组最多 5 个元素参与错开，再多的整组一起动。**玩家等不到的时间**（面板出现 → 能操作）不超过 T4。

### 2.2 缓动集合（只用这 6 条，`ui_motion.gd` 里各一个函数）

| 名 | 曲线 | 用途 |
| --- | --- | --- |
| `out_cubic` | 1 − (1 − x)³ | 缺省：进场、展开 |
| `in_out_cubic` | 对称三次 | 跨屏移动、遮罩、翻面 |
| `out_back(s)` | s 只取 1.2 / 1.4 / 1.6 | 「落位」「停住」的一点过冲；一屏最多一处用 |
| `in_quad` | x² | 下落（重力感），只用于部署落地 |
| `linear` | x | 进度条、计时、循环 |
| `steps(n)` | ⌊x·n⌋ / n | 机械感 / 钟表「嘀嗒」；像素风的硬切 |

像素风规则：位移结果取整到整像素；缩放用最近邻（贴图 `texture_filter = NEAREST`），缩放动画只在 0.6–1.5 倍之间，过程 ≤ T2，不让像素糊在中间态太久。

### 2.3 减少动态效果

设置「画面」页加一行「减少动态效果」，键名与 docs/58 共用 `Cfg.reduce_motion`（谁先实现谁加）。开启后：

- 所有位移、缩放、旋转、翻面、扫入、下落直接到终态；只保留 ≤ T1 的透明度渐变。
- 不闪烁、不抖屏、不做循环动画（灯笼呼吸、警示条、水面波纹都停在中间帧）。
- 演出类（开场、Boss 登场）已有独立开关的维持原开关；倒下过渡缩到 0.5 秒。
- 每个界面在 §3 写了自己的「减少动态」退化方式。
- 无论开不开：全屏亮度变化每秒不超过 3 次（光敏安全），闪光面积不超过屏幕 25%。

### 2.4 不碰模拟、暂停与倍速安全

- 只在界面层（`hud` 画布、面板节点、标题场景）。**不读写 `g.rng`**；要随机的（光点、气泡、墨点）用固定表或 `g.vrng`，同 seed 对局逐字段不变（docs/36 §3）。
- 计时一律用**真实时间**：`Time.get_ticks_msec()` 或 `_process(delta)` 里累计、不乘对局倍速；对局暂停（`S.PAUSE`、面板态）时界面动效照走，对局倍速（右上 1× / 2×）不影响界面动效速度。演出类沿用现有约定（Boss 登场「面板 / 暂停时停表」）。
- 无头批跑（`DisplayServer.get_name() == "headless"`）和图鉴演示里整段跳过，直接终态。
- 动效只改「怎么画」，不改状态机：面板何时出现、何时可选、选了什么，仍由 `game.gd` / `run/` 决定。

### 2.5 输入：不等动画

- 招牌动效期间，**任意确认键 / 点击 = 立即跳到终态**，不是「选中」；跳完下一次输入才算操作。翻面类（升级选卡）在牌没翻开前本来就不能选，这同时就是防误触。
- 不新增输入锁；标题页现有 `scene_transition` 的锁（≤ 330 ms）保留。
- 命中区（按钮 / 卡片 Rect）始终按**终态位置**算，鼠标、触屏、手柄焦点从第一帧就对准终态，动画只是视觉上追上去。
- 手柄 / 键盘焦点高亮与鼠标悬停用同一个效果（docs/28），触屏没有悬停：悬停效果在触屏上改为按下时的 T1 反馈。

### 2.6 性能预算

- 局内面板（选卡、商人、事件、暂停、属性）动效期间新增 GDScript 开销 ≤ 0.3 ms / 帧，用 `--perf` 同局轮换开 / 关量净差（docs/50；分块计时探针会把开销放大，不用它估收益）。
- 不新增局内 shader；矩形 / 线 / 圆走 `hud_tris.gd` 合批，贴图走 `draw_texture_rect`；动效结束后回到现有缓存层（`_layer`）。
- 标题页可以用 shader（声呐环、水面），但手机网页版（docs/22）要有不用 shader 的退化版本。

### 2.7 实现骨架（建议）

新增 `scripts/ui_motion.gd`（纯静态函数，无状态）：`prog(t0, dur, t)`、6 条缓动、`stagger(i, step)`、`rm()`（读 `Cfg.reduce_motion`，返回是否跳终态）、`skip_all()`。各界面自己存开始时刻（`ticks_msec`），在 `_draw` 里插值；不要每个界面再写一份 easeOutBack（现在 `choice_panel.gd`、`title.gd`、`boss_intro.gd` 各有一份）。

截图自测加一个开关 `--motionshot=<界面>,<秒,秒,…>`：在指定时刻连拍，用于 PR 里贴关键帧（对应 docs/36 §5 的截图开关列表）。

### 2.8 「不重复」规则

每个界面一个**主动作**（下表的「主动作」列），全游戏不复用；次要动作（淡入、错开、悬停抬起）可以共用，但不能在那个界面里唱主角。docs/58 已占用的主动作：斜色带扫入、立绘缩放进入、英文名打字机、名册卡抬起、数字跳动、出击警示条滚动、页签下划线滑动、斜切黑带转场、深海浪 / 墨迹确认擦除（§11）。本页不再用这些做主动作。

## 3. 各界面的招牌动效

格式：**触发 / 时长 / 缓动 / 分层步骤 / 传达什么 / 减少动态 / 实现 / 工时**。时长按 §2.1 档位。

### 3.1 标题菜单 · 灯标光束（主动作：旋转光锥）

> **本节已被 T5s 取代**（2026-10-14 制作人定）：标题主动作改为「磁贴从潮线下浮出」+ 选中涨潮 / 涟漪，见 docs/67 §12、docs/37 §8。下文只留作历史。

- 触发：菜单选中项变化（键盘 / 手柄 / 悬停）。
- 时长：T2 220 ms；`out_cubic`。
- 步骤：标题背景的灯标处发出一道窄光锥，从旧选项转到新选项（锥角 6°，青白，加色 25%）；光锥落定后选中行左侧菱形点亮（T1）。开场动画里的菜单逐行滑入保持不动。
- 传达：灯标照亮方向 = 你要去的地方（灯标是本作核心机制，docs/49f）。
- 减少动态：光锥直接出现在新位置，不转动。
- 实现：`title.gd` `_draw` 菜单段，`menu_beam_from / to / t0`，三角形 + 渐变走 `UI` 现有画法；网页版同样可用（无 shader）。
- 工时：1 h。

### 3.2 标题内页面切换 · 声呐环揭开（主动作：圆形扩散揭开）

- 触发：从标题进图鉴 / 设置 / Boss 演练 / 制作人员 / 操作说明（选人页的转场归 docs/58）。
- 时长：T4 600 ms；环扩散 `in_out_cubic`。
- 步骤：①按下的那一行闪一下（T1）；②以那一行为圆心，一道声呐环向外扩散，环内是新页面、环外还是旧页面，环后拖两道淡回波；③环出屏后新页面的面板按自己的进场动效出现（例如设置的档案夹展开，§3.4）。返回标题时反向：环从屏幕外收回到原来那一行。
- 传达：声呐 = HUD 左下的小地图语言，标题和局内同一套「探测」意象。
- 减少动态：退回现在的 120 ms 压暗切换。
- 实现：`screens/scene_transition.gd` 加 `switch_page_ring(origin, change)`；标题场景截一帧旧画面（`get_viewport().get_texture()`）画在环外，或用圆形遮罩 shader（网页版退化成压暗）；原 `switch_page` 留给其他调用。
- 工时：1.5 h。

### 3.3 难度选择 · 潮位上涨（主动作：水位升降）

> **本节已被 T5s 取代**（2026-10-14 制作人定）：难度页改为左竖潮位尺 = 选档器、右边修正项卡两列，水位打开时从尺底涨上来、换档 out_back(1.2)，见 docs/67 §12、docs/37 §8。下文只留作历史。

- 触发：打开难度页、左右换档。
- 时长：T3 380–600 ms（跨两档时 600）；水位 `out_back(1.2)`，颜色 `out_cubic`。
- 步骤：①▶ / ◀ 按下闪一下；②菱形里的级数上下滚动换字（旧的滑出、新的顶上来，T2）；③面板里一层半透明潮水，水面两层正弦波，水位升到所选档的刻度（标准 = 低，Ⅳ = 中，Ⅷ = 高），带一点过冲后落定；④面板右沿一列潮位刻度（≈ / Ⅳ / Ⅷ），菱形游标跟着水位走；⑤效果列表随水面「浮现」——水面经过哪一行，哪一行才显出来；⑥面板主色从青过渡到洋红（沿用现有 `col` 公式）。未解锁档：水位升到刻度下方 20 px 停住，水面变灰。
- 传达：难度 = 潮位（档名「波涛迭起」本来就是潮的意象），越高越危险。
- 减少动态：水位直接到位、水面不动，列表直接显示。
- 实现：`title.gd` `_draw_diff` 加 `diff_level_f`（显示用水位，`_process` 里按真实时间插值）与 `diff_t0`；水体用 `draw_colored_polygon`，波纹点 40 个以内。
- 工时：2 h。

### 3.4 设置 · 档案夹展开 + 抽屉换页（主动作：沿中线上下展开）

- 触发：打开设置（标题页或暂停菜单）、Q / E 换页签。
- 时长：打开 T3（中线拉开 140 ms + 上下展开 300 ms）；换页 T2；`out_cubic`。
- 步骤：①面板中线先出现一道青色细线、从中间向两端拉开；②面板沿中线上下展开（像打开档案夹）；③换页签时，整页选项作为一个整体横推（旧页整体推出、新页整体推入，**不错开**，末端 `steps(2)` 一下「咔哒」到位），区别于 docs/58 的「三行错开滑入」；④滑块数值变化时，被点亮的那一格亮一下（T1）。
- 传达：设置是「档案」，抽屉式、机械、可靠。
- 减少动态：面板直接出现；换页直接替换。
- 实现：`settings_panel.gd` 加 `open_t0`、`tab_t0 / tab_from`；展开用 `draw_set_transform` 纵向缩放面板底与边框，内容在展开到 90% 后再画；横推用列表子控件 `list.position.x`。
- 工时：2 h。

### 3.5 图鉴（非干员页）· 标本柜启辉（主动作：格子对角线依次点亮）

- 触发：打开图鉴、切换敌人 / 精英 / Boss / 道具 / 藏品 / 结局页签（干员页签按 docs/58 C4）。
- 时长：T4（每格 T1 启辉，按对角线错开 30 ms，最多 600 ms 内全部亮完）；`steps(3)`（暗 → 半亮 → 闪 → 稳）。
- 步骤：①网格格子按「行 + 列」对角线顺序依次启辉，像老式日光灯：闪一下再稳住；②详情区背光灯箱从暗到亮（T2），剪影 / 精灵在灯箱亮起后出现；③换条目时只重放详情区灯箱，不重放网格。
- 传达：图鉴是罗德岛终端里的标本柜，和 C4 终端风统一，但动作（启辉）与选人页不同。
- 减少动态：网格直接亮，灯箱 120 ms 淡入；不闪。
- 实现：`gallery.gd` 网格绘制处按 `(row + col) * 0.03` 算每格亮度；`tab_t0`、`sel_t0` 两个时间戳。**10-11 已随图鉴 C4' 实现**（`gallery._ign` / `cat_t0` / `sel_t0`）。
- 工时：1.5 h。

### 3.6 Boss 演练菜单 · 靶框锁定（主动作：四角收拢）

- 触发：选中某个 Boss / 组合行。
- 时长：T2；`out_back(1.4)`。
- 步骤：四个角括号从行外 16 px 收拢到行框上，落定时括号变红（T1）。
- 传达：演练 = 锁定目标。
- 减少动态：括号直接在位。
- 实现：`boss_trial_menu.gd` `_draw` 加 `sel_t0`。
- 工时：1 h。

### 3.7 载入中 · 涨潮进度（主动作：一波一波推进）

- 触发：出发后等待法线图预热（多数时候 < 1 秒，长的时候才看得到）。
- 时长：跟随进度；每一「波」T2，`out_back(1.2)`。
- 步骤：进度条改成一段海岸线：进度每涨一截，就有一道浪头推过去（先冲过头一点再退回到真实进度），浪头带白沫；下方一行提示文字每 3 秒换一句（从 docs/49 里挑玩法提示），T2 淡入淡出。
- 传达：等待也是「潮水在涌来」的一部分，和开局横幅同一句话的意象。
- 减少动态：普通进度条，提示文字直接替换。

## 8. 第一批实现（2026-10-11）

代码：`scripts/ui_motion.gd`（界面时钟 `advance / now`、`prog`、6 条缓动、`stagger`、`rm`、`skip_all`）、`screens/card_motion.gd`（选卡 / 商人按种类分派）、`screens/result.gd`（暂停表盘、失败结算打捞）、`screens/hud_banners.gd`（横幅字距收拢）、`run/motion_shot.gd`（测试开关，docs/36 §5「界面动效」）。

- **界面时钟**：`game.gd _process` 每帧 `UM.advance(delta)`，累计真实帧间隔（不乘对局倍速、暂停照走；`--fixed-fps` 录片时按固定步长走）。暂停 / 失败结算沿用 `g.state_age`（同为真实帧间隔累计）。不读 `g.t`、不碰 `g.rng`。
- **减少动态效果**：复用 docs/58 已加的 `Cfg.reduce_motion`（设置「游戏」页那一行，本批没有再加设置）。
- **分派**：`choice_panel.animate_cards → card_motion.update`；种类 = level（升级）/ relic（藏品）/ recruit（招募：选项全是招募卡时）/ shop / event。事件仍是旧的右侧滑入（第二批换），但已走分派。精英化没有选卡面板（`elite_show.gd` 是 state SHOW 的独立演出），本批不动。
- **升级选卡**：发牌错开 60 ms、每张 240 ms（−14° → 0°、0.6 → 1 倍，从屏幕下方中间飞到卡位）；翻面从 240 ms 起错开 70 ms、每张 180 ms；翻完描边青光 T1。3 张约 0.56 秒、4 张约 0.63 秒。
- **藏品**：错开 120 ms（§2.1 的档；§3.12 原写 130）；光柱 180 ms 冲顶、0.40 秒起 250 ms 退去，光点用固定表；卡片晚 60 ms、340 ms 自下而上从光幕里显出并上移 40 px。基础青白、稀有 / 核心 / 升华 / 结局金色、遭诅洋红；非基础 0.8 秒再脉冲一次。减少动态：非基础卡金边常亮。
- **招募**：错开 90 ms（§3.13 原写 200，4 张时会超过 T4 上限）；卡框 T1 → 部署格 → 待机帧 180 ms `in_quad` 落下 → 压扁 100 ms + 卡片轻抖 2 px 80 ms + 落地环 280 ms → 名字 / 说明 / 标签 200 ms 淡入。部署格终态留一层淡色。
- **商人**：打开 / 刷新货架时重放（买东西重建卡片不重放）；灯笼先暗 150 ms，之后每 180 ms 「一明」（110 ms）点亮一格：暖白一闪 + 顶边金线 + 一缕暖光从灯笼扫到那格；亮完灯笼缓慢呼吸。灯笼用 `fx_merchant_lantern` 覆盖帧叠在立绘上。手机版没有商人立绘框，只有货架逐格亮起。买下时的「源石锭飞向格子」没做（留第二批）。
- **横幅**：暗带与上下细线从中线展开（T2），文字从宽字距、半透明收拢到正常（T3），收拢完回到原来的单次 `draw_string`；小字版只做 T1 淡入。
- **暂停**：压暗 T2；表盘画在暂停面板右侧空处（统计行右边），描出 260 ms、刻度依次出现；洋红秒针 0.10 秒起 850 ms `out_back(1.6)` 飞转、越过 12 点弹回停住，停住外扩细环；五个按钮错开 60 ms、240 ms `steps(3)` 跳入。「继续游戏时秒针重新转起」没做（继续后状态立刻回到对局，面板不再画）。
- **失败结算**：倒下过渡结束后各行（标题 / 四行统计）错开 90 ms、300 ms 由水平正弦晃动 + 半透明 + 失焦虚影对焦变实；两个按钮 0.66 秒起 T2 淡入（原有 0.35 秒暗幕照旧）。
- **输入**（§2.5）：`game.gd _input → _motion_skip`。选卡（升级 / 藏品 / 招募）动效中任意按键 / 鼠标左右键 / 触屏 = 跳到终态，不算选择；同一帧里随之而来的模拟鼠标、手柄注入按键一并吞掉。暂停 / 失败结算只有点击 / 触屏 / Enter / 空格（手柄 Ⓐ）跳，Esc 与字母快捷键照常（暂停里 Esc 仍是继续）。商人不拦。命中区始终是终态（卡片控件不动，动画在卡片自己的绘制里用 draw_set_transform；结算按钮只偏移绘制）。

**验收（10-11）**：快检全过；键盘 / 鼠标 / 触屏 / 手柄四种输入在升级、藏品、招募、暂停、失败结算各测一遍：第一下只跳过（面板仍在、没选卡），第二下才生效；商人第一帧就能买。`--motionperf` 同局轮换（每 0.9 秒在全动效 / 减少动态间切换，各约 1000–2400 帧，关垂直同步）帧时间中位净差：升级 −0.25、藏品 +0.05、招募 −0.08、商人 +0.04、暂停 −0.02、横幅 −0.12、失败结算 +0.01 毫秒，都在 0.3 毫秒预算内（负值 = 噪声，翻面前画卡背比画正面便宜）。同 seed 批跑（seed 7、高手、到 10:00）与 main 对照：水月 TRACE + BALANCE 逐字节相同；斯卡蒂 TRACE 全同，BALANCE 只有 bot.peak / peak_min 里 g.fx 数量那一项不同——main 自己连跑两次这一项也不同（特效数量本来就不可复现），其余字段全同。实机录片 `build/motion_impl/motion_batch1.mp4`（不入库）。
