# 160 干员连携技（设计稿，10-26，只出方案、未改代码）

状态：设计稿，等用户审。分支 `claude/synergy-design`。
起因：用户要「干员之间有关系的人的连携技」。依据：docs/118（队长动作触发的响应动作，已实现）、docs/114（指挥模式）、docs/76 §4（原作关系只用可查证来源）、docs/151（自动技能门槛）。

## 0. 先说结论（供审）

1. **关系只收有 PRTS 出处的**：能落成「一对一」的有 4 组——德克萨斯 × 能天使、德克萨斯 × 拉普兰德、乌尔比安 × 斯卡蒂、归溟幽灵鲨 × 歌蕾蒂娅，外加一个「深海猎人」群体（歌蕾蒂娅 / 斯卡蒂 / 归溟幽灵鲨 / 乌尔比安 / 浊心斯卡蒂）。凯尔希、艾丽妮、流明等是「单向被点名」，列为备选，不进首批（§2.3）。20 人里 水月、塞雷娅、推进之王、星熊、安洁莉娜、艾雅法拉、逻各斯、铃兰、维什戴尔 找不到「与名单内另一人」的搭档级关系，不硬编。
2. **触发方案推荐 β「技能联动」**（§3）：一人放技能，搭档在 4 秒窗口里吃加成；不加按键、不改自动技能节奏，对战斗节奏是「小起伏」。α（同队常驻被动）只留一个纯观感 / 语音层；γ（队长手动连携）不做（理由 §3）。
3. **不让固定组合成为唯一最优**（§4）：每次连携的期望收益封顶在「搭档该分钟输出的 6–10%」；每对独立冷却 ≥ 12 秒；一队同时生效最多 2 条连携；每人最多参与 2 条；收益类型错开（伤害 / 控制 / 续航 / 技力）；上线前用同 seed 配对测「带连携对 vs 同职业无连携对」，胜率差 < 10 点不下结论。
4. 表现和台词（§6）：全部取 PRTS 原话，但本稿的原话摘录是**转述抓取，未与原页逐字比对**，落代码前必须核对（docs/76 §4）；新台词需要新切片（现有素材只有部署 / 三技能 / 战斗 / 突击回应）。

## 3. 触发方式：3 个方案

| | α 同队常驻被动 | **β 技能联动（推荐）** | γ 队长手动连携 |
|---|---|---|---|
| 怎么触发 | 两人同在编队就给小幅常驻加成 | 一人的技能（自动或手动）出手，搭档在 4 秒窗口里吃加成 / 追加一次动作 | 队长是搭档之一时，圆盘 / 键位多一个「连携」键，消耗技力或有独立冷却 |
| 对节奏 | 无起伏，只在编队界面影响选择 | 小起伏：技能错开 / 同开有不同收益，玩家感觉不到新操作 | 大起伏：多一个时机决策 |
| 利 | 零操作；最好实现；编队有话题 | 与现有自动技能、响应动作同一套框架；每次触发都有可见表现；能做出「谁先手」的差异 | 玩家有主动权，表现可以最强 |
| 弊 | **最容易变成固定最优编队**（常驻加成不看时机）；表现弱 | 机器人 / 自动技能下触发次数不均，需要数值上限和冷却；两人技能同时开时要去重 | 新增按键（手机上拥挤）；只对「队长属于搭档」有用，其余干员没有；把「手动只对队长」的口径扩大到连携 |
| 对胜率的影响 | 稳定小幅增益，易失衡 | 有上限（见 §4），可控 | 取决于玩家，机器人矩阵难测 |

### 3.1 推荐组合

- **主体 β**：全部首批连携走 β。
- **α 只做观感**：同队时编队界面有两人的连线小标和一句档案式提示（文案 docs/76），不给数值。这样编队有话题，但不会出现「必带」。
- **γ 不做**。若用户将来想要「队长连携大招」，另开一页设计，不放进本稿。

### 3.2 β 的统一规则（实现草案）

- 新触发器 `trig.on_mate_skill`（只读，不抽随机数）：本队任一干员 `spend_sp` 成功那一刻广播（出手者 id、技能序号）。
- 干员 json 新增 `blocks.synergy`（数组，一对一条）：`{ "with": "<搭档 id>", "name": "...", "cd": 12, "window": 4, "do": [...], "_doc": "...", "src": "PRTS 页面·栏目" }`；`do` 只用现有积木（`verb.buff_*`、`shape.*`、`st.*`、`verb.sp_secs`）。
- 双向对称的连携两边各写一条，可以是**不同效果**（谁先手谁受益）。
- 总开关 `balance.json synergy.on`（缺省 0，关时所有 `blocks.synergy` 不求值，TRACE 与现在逐行相同）。
- 图鉴干员页加一行「连携：搭档 · 名字 · 一句话」；入队 / 部署时头顶出连线小标。

## 4. 强度与「不成为唯一最优」的约束

| 约束 | 数值（起始，后续按云端矩阵调） |
|---|---|
| 单次收益 | 期望增益约等于搭档当时 4–6 次普攻的伤害，或等价的控制 / 技力 / 护盾量；折算到「搭档该分钟输出的 6–10%」封顶 |
| 冷却 | 每对（含两个方向合计）≥ 12 秒；窗口 4 秒（可调 3–5） |
| 同时生效上限 | 一队最多 2 条连携同时生效，取收益最高的 2 条；每名干员最多参与 2 条 |
| 收益类型错开 | 伤害（R1）、控制（R3）、技力 / 位移（R4）、群体增益（R5）……避免都是「+伤害」被一种编队吃满 |
| 不给「必选」 | 单条连携的收益要小于同槽位换上「通用强力干员」的差距（历史上医疗在固定队里有 ~93% vs 无 45–71% 的问题，见 docs/36 / 数值调整口径）；任何一对「带 − 不带」的胜率差 > 10 点就当失衡回调 |
| 同 seed | `synergy.on = 0` 逐行同；打开后只有「配对在编队」的局会变，不抽 `g.rng` 之外的随机数 |
| 测试 | 云端配对：①同职业无连携对 vs 带连携对（各 112 局高手机器人，常规档 / 无局外成长）；②6 种编队（含 / 不含连携对）的胜率矩阵；③机器人（expert / normal）都要测。判据 docs/36 §8：胜率差 < 10 点不下结论 |

## 5. 首批连携草案（β）

数值是起始值，区间表示后续调整范围；「谁放技能」= 触发方。均受 §4 的冷却 / 窗口 / 上限约束。

### 5.1 R1 德克萨斯 × 能天使「默契」

- **名字**：「默契」——德克萨斯后勤技能原名（精二），描述她与能天使同站的默契。
- **德克萨斯放技能 → 能天使**：4 秒内能天使的射击改为朝「德克萨斯当前最近目标」集火，伤害 +15–25%（对应语音「能天使，掩护我」）。
- **能天使放技能 → 德克萨斯**：4 秒内德克萨斯的普攻伤害 +10–15%，并让下一次「拔刀」命中里额外多定住 1 名敌人（利用德克萨斯本作独有的阻挡机制）。
- 类型：伤害 + 控制。收益折算约 +6–8%。
- 备注：两人本作已有「队长冲刺」响应（能天使掩护射击、德克萨斯专属冲刺），连携不重复这条，只吃技能触发。

### 5.2 R2 德克萨斯 × 拉普兰德「恩怨」

- **名字**：「恩怨」——德克萨斯后勤技能原名，同站心情 +0.3 / 订单效率 +65%：互相刺激的双面关系。
- **效果（对称）**：任一人放技能 → 另一人 4 秒内攻速 +12–18%（被激起胜负欲）；另加「落后补偿」：若上一个窗口里被激起的一方输出低于对方，窗口延长到 5–6 秒（防止一人滚雪球、另一人白吃）。
- 类型：攻速（纯输出，对应关系是「较劲」而不是「默契」）。收益折算 6–9%。
- 对比 R1：同样涉及德克萨斯，但 R1 偏控制 / 集火，R2 偏攻速；德克萨斯参与 2 条（R1 + R2）已是每人上限，R1、R2 同时在队时按 §4「最多 2 条」取优。

### 5.3 R3 乌尔比安 × 斯卡蒂「手段应当有效」

- **名字**：「手段应当有效」——乌尔比安的后勤技能原名，并对应档案「斯卡蒂的手段都是乌尔比安教的」。
- **乌尔比安放技能（钩锁 / 重砸）→ 斯卡蒂**：被钩中或被眩晕的敌人，4 秒内被斯卡蒂命中时受到的伤害 ×1.3–1.5（她「教」出的斩杀窗口）。
- **斯卡蒂放技能 → 乌尔比安**：4 秒内乌尔比安的锚击范围 +15–25%、钩住的敌人上限 +1（反向：她把群战位置让出来）。
- 类型：控制 + 伤害；收益折算 7–10%。是首批里「依赖对方技能类型」最强的一对，所以收益封顶最低。

### 5.4 R4 归溟幽灵鲨 × 歌蕾蒂娅「潮汐守望」

- **名字**：「潮汐守望」——歌蕾蒂娅后勤技能原名，同组深海猎人。
- **歌蕾蒂娅放技能（钩索拉人）→ 幽灵鲨**：被拉近的敌人，幽灵鲨的替身出手追加一次环斩（×0.6–0.9）。
- **幽灵鲨放技能 → 歌蕾蒂娅**：4 秒内歌蕾蒂娅的钩索冷却缩短 20–30%（对应「跟随歌蕾蒂娅狩猎」）。
- 类型：位移 / 节奏；收益折算 6–8%。

### 5.5 R5 深海猎人群「集群狩猎」

- **名字**：「集群狩猎」——歌蕾蒂娅后勤技能原名，列出整组深海猎人。
- **条件**：编队里有 ≥ 2 名「深海猎人」（歌蕾蒂娅 / 斯卡蒂 / 归溟幽灵鲨 / 乌尔比安 / 浊心斯卡蒂）。
- **效果**：当其中一人开始打同一名精英 / Boss 时，所有在场猎人对该目标的伤害 +5–8%，持续到目标死亡；人数越多越高（2 人 +5%、3 人 +6.5%、4 人 +8%，封顶）。
- 类型：集火；群体效果单列，不进「最多 2 条」的计数，但 R5 与 R3 / R4 不叠，同对象取高值。

### 5.6 备选（第二批，不在首批）

- R6 歌蕾蒂娅 × 乌尔比安（战争设计共通）：钩索与锚链交叉时互相缩短 1 秒技能冷却。
