# 190 残血缓冲并入认知塑造（方案，未改代码）

> 10-28 用户：「残血危机感是不是可以合入局外成长」。依据：云端 `cloud-results/low-hp-buffer`（877605fe8）：现有旋钮（国王套门槛 `relic/king_low` 0.3→0.4、满血保护 `boss/fullhp_guard_left` 0.05→0.08）对整局零影响，低血（<35%）只活约 5 秒、<20% 约 1–2 秒（m0 5.5 / 1.9，m18 4.6 / 1.3）。要拉长它得有新机制，且作为**买到的节点**而不是全局常驻。

## 1. 节点

- **名字**：「危机感Ⅲ」（沿用原作 PRTS 认知塑造的「危机感」线名，docs/76 不新编词）；局内触发时飘字「危机感」。
- **效果**：队长生命**低于 X% 时，受到的伤害降低 Y%**；每局**累计生效 ≤ T 秒**（只数生命低于 X% 的秒数，用完不再触发），避免变成无敌；回到 X% 以上不重置、不回补。
- **挂在危机感线**：链改成 危机感Ⅰ（护盾 + 反震）→ **危机感Ⅲ（新，id `sh_low`，req = sh1）**→ 危机感Ⅱ（护盾间隔 -3 秒，`sh2` 的 req 改成 `sh_low`）。UI 的节点链是每个节点只有一个后继，新节点只能插在链中间；`sh2` 的 id 不改，老存档已点的 `sh2` 照常有效。
- **画面**（要看得见、和护盾软泡泡区分）：① 缓冲生效时屏幕边缘暗角由现在的低血红换成**琥珀金**，慢呼吸（现 `hud.gd` 低血红暗角只在 <30% 才有，生效时顶掉它）；② 队长脚下一圈细琥珀环（不是泡泡，不盖在护盾上）；③ 血条旁小标「缓冲 8s」显示剩余秒数；④ 第一次触发飘字「危机感」+ 一声低沉的闷响（沿用现有 `hurt_duck` 通道，不新增音源）。

## 4. 实现要点

- **乘在 `combat.lose_hp()`**（所有主控扣血的统一入口：受击 `hurt`、黑潮、侵蚀结算、溟痕、灯火熄灭都走它）：这样侵蚀 / 溟痕这类「磨到死」的持续伤害也被减，不止命中。
- **先后顺序（别被上限吃掉）**：在 `_boss_clamp`（单发 40%、2 秒合计 `boss/leader_2s_cap`）和 `_any_clamp` 之后、`g.hp -= amount` 之前乘。理由（来自 low-hp-buffer）：① 低血（<35%）时 `leader_2s_cap`（现 0.68 最大生命）已经高过剩余血量，根本保护不到；② 若在截断**之前**乘，被截到 40% 的 Boss 大招会先被截、减伤被吃掉；放在截断**之后**，Boss 大招是 `min(上限, 原值) × (1−Y)`，减伤一定生效。
- **记账**：乘完后把这次追加进 `loss_log` / `boss_log` 的最后一条改成实扣量（否则 2 秒窗口按未减的量记，会多截后续 Boss 招式）。
- **叠加**：与国王套低血（`relic_fx.taken_mult` 的 0.667 / 0.7）、自我保护 / 静守相乘，合计乘数设下限 **0.35**（以 `dmg_taken` 属性为基准的总倍率），防多件叠出准无敌。
- **状态**：`g.lowbuf_left`（秒，开局 = T，节点点了才有）、`g.lowbuf_on`（当帧是否在生效，给 HUD）；每帧在 `update_player_feel` 里按真实生命判断并扣秒；复活 / 免死触发后不重置；不写进存档，不影响同 seed 的未点节点局（`--meta=0 / 18` 逐局不变）。
- 测试：`meta_mech_test` 加用例（低血受击被减 Y、高血不减、池子用完不再减、与 2 秒上限的先后顺序、叠加下限）；`meta_test` 总量 649 与顺序。
- 旋钮（`balance.json` `meta` 段）：`lowbuf_at`（X，0.35）、`lowbuf_cut`（Y，0.45）、`lowbuf_pool`（T，12）、`lowbuf_floor`（叠加下限，0.35）；云端按候选组 `--bal=` 直接并行试档，不用改代码。
