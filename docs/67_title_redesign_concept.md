## 1. 语言：图鉴 C4' 搬到局外

沿用 docs/58 §8 / §11 定稿的 C4'，不新造规则：

- **明暗分区**：左边暗舞台（keyart 本身就是暗场），右边浅色终端面板，**半透明**（`UI.C_L_GLASS` #E2E4E7 · 0.82，10-11 图鉴刚改的那档），透出后面的巨树 / 海面；分区是一道 3 px 警示黄斜边（倾角同职业色斜带）。
- **浅色标题块 + 警示条**：每屏左上或面板顶一个 `LPANEL` 白块（微型代码 + 中文页名），右端 22 px 黄黑警示条——图鉴左上 ARCHIVE 块的同款。
- **平行四边形**：菜单行、页签、按钮都是右倾平行四边形；选中 = 警示黄底黑字 + 左端黑块编号（`01`）+ 4 px 黑投影。
- **巨型描边英文**：舞台上一行 128–150 px 描边英文（`SURVIVORS` / `RISING TIDE` / `SETTINGS` / `CREDITS`），白 10–13 %。
- **微型代码**：`TERMINAL // MAIN MENU`、`TIER 02 / 03 // LEVEL 4`、`MOD 01`、`STATUS // LAMP 03 // SAVE OK`。
- **职业色**：只用在封面干员小牌的左色条（水月 = 特种紫）。标题不画整条斜带——keyart 是完整场景，一条 35 % 的色带会把巨树盖脏（试过）；这是与图鉴唯一的取舍。
- 选人页 **B+ 不动**（用户定），它与标题之间仍是深海浪幕转场；图鉴保持现版。

## 3. 内页（按 T1 语言）

所有内页共用 T1 的舞台：同一张左移后的 keyart 压暗到 42 %，加该页的描边英文；右侧同款半透明面板，宽度按内容取（斜边 x 位置不同）。

- **难度**（`diff_C4.png`）：面板顶三档平行四边形页签（标准 / Ⅳ / Ⅷ，未解锁档画锁码）；左舞台大号黄 `Ⅳ` + 档名 + 英文；**潮位**（docs/62 §3.3）画在舞台上：半透明潮水升到所选档刻度，右缘刻度 `≈ / Ⅳ / Ⅷ` + 黄菱形游标；面板里难度效果做成 10 张白底行卡（`MOD 01` 代码 + 中文 + 右侧大号数字，大数字规则同图鉴 `stat_big`）；主操作「出发」= 黄色平行四边形 + 左段警示条（C4' 规则：警示条只给主操作），「返回 Esc」描边平行四边形。
- **设置**（`settings_C4.png`）：页签 声音 / 画面 / 游戏（`01 / 02 / 03` 小码 + Q / E 键帽）；每行一张白底行卡，选中行 `#FFF7CE` 底 + 4 px 黄左条；音量格从方块换成 10 个小平行四边形（选中行黄、其余墨色）；右侧大号数值；「返回」钉在底部（触屏滚动沿用 a8b96dd 的 list 子控件，只换皮）。docs/62 §3.4「档案夹展开 + 抽屉换页」照用。
- **致谢与声明**（`credits_C4.png`）：今天（10-11）刚改成滚动版（17 号字 + 滚动条 + 钉住「返回」），C4' 版只是换皮：条目名放进墨色平行四边形签（黄编号），正文墨色 17 号，链接深蓝，滚动条墨色细轨 + 黄滑块。
- **操作说明 / Boss 演练**：同一外壳（左舞台描边英文 `GUIDE` / `BOSS TRIAL`，右面板内容不变），本次没出图。

## 4. 动效怎么落（`motion_T1.png`）

不新增招牌动效，只改落点（docs/62 的「一屏一个主动作」不变）：

1. **开场**（docs/37 方案 A「潮声点灯」，4.8 s / 简短版 2.5 s）：镜头下摇、脚印、海嗣睁眼、Logo 青色扫光**全部保留**；原来 3.0 s 起「副标题、菜单、页脚依次滑入」换成「终端面板从右滑入 300 ms（ease-out cubic）→ 菜单行错开 40 ms 各 200 ms 浮现」。keyart 左移 300 是静态构图，不参与动画。
2. **换选项**：黄色平行四边形 200 ms 滑到新行（同图鉴页签下划线）；docs/62 §3.1 的**灯标光束**从巨树根部打到选中行左端——T1 里光束正好从舞台跨进面板，比现版更有意义。
3. **进内页**：docs/62 §3.2 **声呐环**以选中行为圆心扩散，环内是 C4' 内页、环外是标题；因为内页和标题共用同一张舞台，环内外只有面板不同，切换很顺。进图鉴仍用斜切黑带（图鉴自己的转场），进选人仍是深海浪幕。声呐环目前还没实现（`scene_transition.switch_page` 是 120 ms 压暗），按 docs/62 §3.2 实现时直接用 T1 的行坐标做圆心。
4. **减少动态效果**：面板直接到位、黄条不滑、光束直接出现；只留 ≤ 120 ms 淡入淡出（同 docs/58 §9）。

## 5. 对 docs/37 的影响（要用户点头）

docs/37 §1 / §2 现在写明：C 版式（浅色面板、平行四边形、警示黄、警示条、`UI.C_*`）**只用于图鉴**。采用本方案要改三处：

1. §1 那句改为：「干员图鉴与**局外菜单（标题、难度、设置、致谢与声明、操作说明、Boss 演练菜单）**用 C4' 版式；干员选择用 B+；局内 HUD / 选卡 / 事件 / 商人 / 暂停不变。」
2. §2 警示黄那行：「只用于 C4' 屏（图鉴与局外菜单），不进局内、不进选人」。
3. §4「标题页：保留像素 Logo；纵向时间轴菜单 + 右下 READY TO DEPLOY」改写成所选方案；手机排版那段的「标题页 Logo 360×90、菜单行距 38、页脚挪到右下」相应改写。
4. 暂停菜单里也能打开设置：设置的 C4' 皮只在标题页用，**局内打开设置仍是暗面板**（否则局内出现浅色面板，违反「不进局内」）——`settings_panel.gd` 需要按调用方选皮，或干脆两处都保持暗色（见开放问题 2）。

## 8. 推荐

**T1 档案终端**：它和图鉴是同一套分区骨架，标题 → 图鉴 / 难度 / 设置都在「同一张暗舞台 + 一块半透明终端面板」里切换，C4' 的语言一以贯之；菜单在浅底上最好读，手机 6 行 50 px 也够点；开场下摇、Logo 扫光、灯标光束、声呐环都能原样保留，只是落点变成右侧面板。

## 9. T1′ 修订（10-11 用户：「T1目前的颜色和结构是不是有点奇怪」）

> 生成：`python tools/concept_title_ui_v2.py`（复用 v1 的截图与绘制工具）→ 主仓库 `build/title_redesign/v2/`（不入库）。**先看 `contact_sheet_v2.png`**：第 1 行标题（现状 / 旧 T1 / T1′a / T1′b），第 2 行难度（旧 C4 / A / B / A 手机），第 3 行设置 A、致谢 B、旧 T1 手机、T1′a 手机。单张：`title_T1p_a.png`、`title_T1p_b.png`、`diff_T1p_A.png`、`diff_T1p_B.png`、`settings_T1p_A.png`、`credits_T1p_B.png`、`title_T1p_a_phone.png`、`diff_T1p_A_phone.png`。

### 9.1 诊断（制作人与我一致）

1. **0.82 半透明浅色面板放错了底**：图鉴里它压在暗舞台上，读出来是干净的浅灰白；标题里它压在发光巨树和星空上，混成一块脏灰；内页面板后面还透出人物的「鬼影」。
2. **结构切掉了 keyart 最好的部分**：keyart 左移 300 + 右 1/3 面板，巨树被砍掉一截，水月和博士被挤到斜边上。
3. **图鉴的分屏是为「列表 + 详情」设计的**；标题只有 6 项菜单，右栏一半是空的，只好拿「主界面」白块和状态行去填，像后台管理页。
4. **大块警示黄 + 黄黑警示条压在灰底上**，和深海冷色调打架。

### 9.2 T1′ 做法

- **标题**：keyart 全幅、构图与现版完全一样（巨树、Logo、水月 + 博士、右下「更换封面干员」原位不动）。菜单放进左侧 420 px 的**深海蓝磨砂竖条**（背景高斯模糊 + `#081020` 约 0.66 + 1 px 青色细边，右侧 70 px 柔和投影）；Logo 缩到 0.7 放在竖条顶部。菜单行用图鉴的写法：小编号 `01` + 中文 + 宽字距小英文 + 1 px 青色分隔线；选中行 = 平行四边形高亮 + 下面一行说明，竖条细边在选中行那一段亮起（灯标光束落点，docs/62 §3.1 可直接接上）。去掉「主界面」白块、警示条、状态行；页脚只留操作提示 + 「明日方舟同人作品 · 非商业 · 致谢与声明 C」，版本号留在右下。
  - **T1′a**：选中 = 警示黄平行四边形、墨色字。全屏只有这一处黄色，等于「黄色 = 你现在选的东西」。
  - **T1′b**：选中 = 近白平行四边形 + 青色编号块、深海蓝字。全屏没有黄色，最安静，但与图鉴 / 选卡的「黄 = 选中」口径不一致。
- **内页**：面板放到**左边**——标题竖条「长宽」成内页面板，右边舞台继续露出巨树和人物（不再透鬼影，因为人物在面板外面）；面板右缘是斜边（倾角同图鉴），页头是青色短竖条 + 微型代码 + 中文页名，不再用白块 + 警示条。主操作「出发」是黄色平行四边形（不带警示条），「返回」描边。
  - **A 深色磨砂**：面板 = 背景模糊 + 深海蓝 0.85，浅色字，行卡 `#14243E` + 青色左条；舞台 keyart 压暗到 0.7。
  - **B 压暗模糊 + 近白面板**：先把整屏背景模糊并压暗到 0.45，再盖一块 `#F4F6F9` · 0.94 的面板，读出来是接近纯白的纸面，墨色字 + 青色强调；舞台成了模糊的暗色背景。
  - 难度两种都出了；**设置用 A**（局内暂停也会打开设置，A 本来就是暗色，标题和局内可以共用同一张皮，§7 开放问题 2 自然解决）；**致谢与声明用 B**（大段 17 号正文，白底读起来最轻松）。
  - 难度页的潮位（docs/62 §3.3）画在右边舞台上，刻度 `≈ / Ⅳ / Ⅷ` 贴右缘；大号档位数字用强调色（A 青 / B 深青），不再用黄色。
- **手机 740×360**：T1′a 竖条 262 宽，5 行 47 px（网页 / 手机没有「退出」），封面干员切换和页脚在右下；难度 A 面板 470 宽，档位页签 + 2 列 × 5 张行卡 + 出发 / 返回，舞台右侧保留人物和潮位。

### 9.3 推荐

**标题 T1′a + 内页 A（致谢可例外用 B）**。

- T1′a：keyart 完整保留（用户最喜欢的开场画面不受损），菜单在暗底上浅色字，可读性不输旧 T1；黄色只出现在选中项，和图鉴 / 选卡 / 选人「黄 = 选中」口径一致，比 T1′b 更好认。T1′b 作为备选——如果用户觉得黄色仍然跳，就换它，改动只是一组颜色。
- 内页 A：从标题进来时深色竖条横向展开成面板，颜色不跳，转场最顺（docs/62 §3.2 的声呐环也照样能用）；设置可以与局内暂停共用。B 很干净，但从全暗的标题跳到大块白面板，亮度跳变大，适合「读」不适合「选」，所以只建议致谢与声明用（或者全用 A，致谢正文 17 号在 A 上也够清楚，看用户口味）。
- 这样 C4′ 和图鉴的亲缘落在**平行四边形、微型代码、斜边、黄色选中**上，而不是浅色面板和警示条；docs/37 §2 「警示黄只用于 C4′ 屏」那句可以保留不改，§5 第 2 条不再需要。
- 工时比 T1 略少：不需要 keyart 左移和宽屏补画（−2 h），标题竖条比终端面板简单；其余同 §6，约 **22 h**。

### 9.4 新的开放问题

1. 选 T1′a（黄选中）还是 T1′b（白 + 青选中）？
2. 内页全用 A，还是致谢 / 操作说明这类长文页用 B？
3. 竖条透明度：现在约 0.66，能看出模糊的星空；如果要更「实」（更像图鉴深色块）可以到 0.8，代价是左侧星空基本看不到。

## 10. T4 终端首页（参考明日方舟主界面）

### 10.3 键盘 / 手柄在格子里怎么走

格子是三行：`[01]` / `[02][03]` / `[04][05][06]`。

- **↑ ↓**：换行，落到「水平位置最近」的那块：01 ↓ → 02（记住上次所在列，从 03 上去再下来回到 03）；02 ↓ → 04，03 ↓ → 06（05 只能从 04 / 06 横移到达，或从下行上来再下去时回到 05：记住上次所在列）；04 ↑ → 02，05 ↑ → 02，06 ↑ → 03；任何中号 ↑ → 01。行首 ↑ / 行尾 ↓ 不循环（或循环到 01，二选一，倾向不循环）。
- **← →**：行内移动；01 那一行只有一块，← → 不动（或 → 打开难度预览，不建议）。
- **W/S/A/D 同方向键；Tab / Shift+Tab 按 01→06 线性走一遍**（兜底，保证不用想格子也能到所有项）；ENTER / 手柄 A 确认；V 换封面干员；C 致谢；Esc 在首页 = 跳到 06 退出（不直接退）。
- 焦点永远只有一块是黄的，外加四角折线；从 T1′/现版的「上下一列」改成二维网格，是 T4 最大的交互成本，需要写一个小的网格导航表（6 项，硬编码邻接即可）。
- **手机 / 触屏**：直接点磁贴；最小的小号磁贴 0.62 倍后约 160×43，接近 44 px 触控下限，可以接受。网页 / 手机没有「退出」，底行只有两块（操作说明 / 设置）。

### 10.4 T4a（倾斜）vs T4b（平放）

- **T4a**：整组磁贴做透视，右缘上下各收 6 %、向里退 3 %，整体略向右上抬——就是原作主界面那种「立在屏幕右边、朝向人物」的感觉，最有「终端首页」的味道。代价：Godot 里要么整组画到 SubViewport 再贴到斜四边形上，要么用 `draw_set_transform_matrix` / 自定义 shader 做透视；两种都会让像素字和 1 px 细边**插值发糊**（概念图里已经能看出中文边缘发软），与全游戏「最近邻、像素锐利」的口径冲突；手机 740×360 上小号磁贴的英文基本读不出。
- **T4b**：同一套布局不倾斜，所有字和线都落在整像素上，最清楚；版式上的亲缘（大小分级磁贴 + 焦点人物 + 四角信息）已经足够让人联想到原作主界面。

## 11. T5 自有风格（10-12 用户：「能不能在T4B的基础上设计出我们自己的风格」）

概念图：`tools/concept_title_ui_v4.py` → 主仓库 `build/title_redesign/v4/`（先看 `contact_sheet_v4.png`：T4b / T5a / T5b / T5c 一行，T5a 选中图鉴 + 难度内页一行，手机一行）。只是概念图，不改游戏代码。

骨架完全沿用 T4b（右侧大小分级磁贴群 01 大 / 02–03 中 / 04–06 小、沙滩上放大的封面干员、左上 Logo + 记录条、右上图标、左下更新、页脚声明）；换掉的是从原作借来的「外观」：警示黄、平行四边形、警示斜纹、罗德岛式四角折线、平滑模糊玻璃。

### 11.1 本作识别规则（T5 定下来就写进 docs/37）

| 项 | 规则 |
|---|---|
| 颜色 | **灯火琥珀**（概念值 #FFB040，亮边 #FFDE96，深墨 #081426）只给「焦点 + 灯」：选中磁贴、灯火日志的灯、难度页的指针 / 出发描边。全屏只有这一种暖色；其余全部深海藏青（三阶 #122844 / #0B1A30 / #060E1E）+ 青（#60E0E8）。选中磁贴外有一圈**台阶式像素光晕**（模糊后量化成 3 档、按 4 px 块化），不是平滑辉光。 |
| 形状 | **像素阶梯切角**：四角各 3 级、每级 2 px（小号 2 级）；描边也是 2 px 阶梯。左上角一小段亮青描边代替原来的折角。不用平行四边形、不用斜纹。 |
| 潮线 | 每块磁贴底部一条像素波浪潮线（未选中约 7–10 % 高），**选中那块水位涨到约 22 %**，浪尖一排断续泡沫像素，图标脚下三圈压扁的像素涟漪。焦点移动 = 旧块退潮、新块涨潮（动效 0.25 s）。 |
| 质感 | 面板用 **Bayer 4×4 有序抖动**的 2–3 阶渐变（上浅下深、略带左右），格子 2 px；选中块同样是琥珀三阶抖动。不用实时模糊。 |
| 字体 | 编号、英文、难度数字（0 / IV / VIII）、数值用 **5×7 像素字**（概念图里现画的位图字；仓库 game/fonts 只有 ui.ttf / serif.ttf / ui_fallback.otf，没有像素字体），整数倍放大；中文仍是 ui.ttf 粗体，保证可读。 |
| 图标 | 16×16 像素图标（出发、图鉴、Boss、操作、设置、退出、信息、全屏、灯、漂流瓶），最近邻 2× / 3×，双色（主色 + 青点缀）。 |
| 生物 | 磁贴群外缘 / 缝隙漂两三只像素水母（伞盖带 1 格深色描边，压在巨树倒影上也认得出）+ 几点生物荧光，缓慢上下漂。 |
| 命名 | 档案条 → **灯火日志 LAMP LOG**（已解锁干员 18/18 · 最高潮位 VIII · 总局数 37），左端一盏灯，灯光用琥珀抖动往右褪进藏青；更新横幅 → **漂流瓶 DRIFT NOTE** 便笺（去饱和的海水灰旧纸、横格线、底边撕纸、瓶子图标），纸色不抢琥珀。难度 → **选择潮位 TIDE LEVEL**。 |

### 11.2 三个变体

- **T5a 适中（`title_T5a.png`，另有 `title_T5a_sel2.png` 选中图鉴、`title_T5a_phone.png`、`diff_T5a.png`）**：以上全部。优点：一眼和原作拉开（暖灯 vs 警示黄、像素切角 vs 平行四边形），又不吵；潮线 + 涨潮把「潮位 = 难度」和「灯火」两个核心概念放进了首页；抖动是贴图 / 着色器常数，比 T4b 的实时模糊还省。缺点：选中块下半截是水，主标题区可用高度少约 20 %（副标题要压在水线上方）；抖动在 1080p 以上是 2 px 格，网页缩放到非整数倍时会有轻微摩尔纹（要锁整数缩放或在着色器里按屏幕像素算）。
- **T5b 加强（`title_T5b.png`）**：磁贴做成潮位站 / 声呐面板——左缘潮位尺刻度 + 水位指针、点状声呐同心弧、扫描线、顶部深色铭牌带（TG-01…）、更粗的 3 px 抖动、更大的光晕，外加一盏吊灯挂在选中磁贴上方、跟着焦点移动。优点：最有「我们自己」的世界观感，吊灯是很好的焦点隐喻。缺点：信息密度和噪点明显变高，小号磁贴和手机上刻度 / 声呐弧糊成纹理；吊灯在第二、三行时要从上一行缝里穿下来，版式不好处理；工时最多。
- **T5c 克制（`title_T5c.png`）**：只换阶梯切角 + 琥珀 + 像素字，保留 T4b 的平滑深色磨砂、线条图标，没有潮线 / 水母 / 抖动。优点：改动最少，风险最低。缺点：像「T4b 换了个颜色」，原作味道仍然是主导，用户要的「自己的风格」不够；平滑磨砂 + 像素字混在一起，质感不统一。

### 11.3 难度内页（`diff_T5a.png`）

左侧一根竖的**潮位尺**就是选档器：三档卡片（0 波涛迭起 / IV / VIII）贴在尺子的刻度上，选中档是琥珀卡 + 指针，**尺内水位停在所选档的刻度**，水面有涟漪；上下键换档 = 水位升降。右侧「档位文件」修正项卡片同样是阶梯切角 + 抖动，底边一条细潮线；「出发」为藏青底 + 琥珀描边（主操作，但焦点仍只有一个琥珀实心块）。注：ui.ttf 缺「Ⅷ」字形（会退到 ui_fallback 并让整串中文变豆腐），所以档位数字一律用像素字 IV / VIII，不用罗马数字字符。

### 11.6 开放问题

1. **琥珀要不要全游戏替换警示黄？** 现在 UI.C_ACC 警示黄 #FFCE00 在图鉴（docs/58 C4′）、选人 B+ 等界面都在用，docs/37 的水月风格 UI 也有自己的紫。只改标题会出现「首页琥珀、进图鉴变黄」。建议：标题 + 难度 + 设置先用琥珀，图鉴 / 选人二期再统一；或者只把 C_ACC 换成琥珀（一行常量，但要逐屏看对比度）。
2. **像素字从哪来？** 自己画 5×7（无授权问题、风格可控，约 3 h），还是用开源像素字体（如 OFL 授权的像素字体，字形更全，需核授权）？
3. **潮线位置**：选中块下半截是水，标题区变矮；能否接受，还是只在未选中块保留细潮线、选中块用涨潮动画后再退回到 10 %？
4. **漂流瓶纸色**：现在是去饱和海水灰；要不要更像纸（偏米色，会成为第二种暖色）？
5. 封面干员放大 2 倍（§10 开放问题 ②）在 T5 里仍然成立，没变。

### 11.7 选中色对照（10-12 用户：「琥珀色是不是不太好看」）

琥珀渐变填充显得发浑、偏复古，和冷色深海底打架。T5a 标题（选中「集结出发」）与难度内页各出 4 种选中处理，其余完全不动：`tools/concept_title_ui_v4_sel.py` → `build/title_redesign/v4/sel/contact_sheet_sel.png`（上行标题、下行难度页；列 = 原版、S1–S4）。

| 方案 | 选中块 | 字 | 光晕 / 潮线 | 观感 |
|---|---|---|---|---|
| S1 强调黄 | UI.C_ACC #FFCE00 平涂（无渐变），亮黄 2 px 边 | 深墨 | 黄色像素光晕保留 | 干净、最醒目，和图鉴 / 选人统一；但仍是全屏最响的暖色，「原作警示黄」味道回来了 |
| S2 生物荧光 | 保持深藏青抖动底，2 px 亮青像素边 | 白字、亮青编号 | 青色光晕；潮线浪尖连成一条发光青线 | 最「深海」、最融入；焦点只靠边框和光晕区分，未选中块本来也是青边，远看 / 手机上焦点偏弱 |
| S3 淡灯金 | #F2E3B3 平涂 | 深墨 | 光晕减弱 | 比琥珀柔和不脏，仍保留「灯火」暖意；在冷底上略像旧纸，和漂流瓶便笺抢 |
| S4 反白 | #EEF3F6 近白平涂，细青 2 px 边 | 深藏青 | 很弱的青光晕 | 焦点最清楚、无暖色冲突，冷底上像一块被照亮的冰 / 屏幕；有点「系统 UI」，少一点个性 |

S2 时「灯火日志」的灯光渐变和标题字也改成冷色，暖色只留在小灯图标上；S1 / S3 / S4 灯火日志保持原样（灯本身就是灯）。难度页的指针三角与「出发」按钮边框跟随各方案的强调色。

**推荐 S4（反白 + 细青边）做焦点。** 冷底上对比最强、远看和手机上一眼认出焦点，同时整屏只剩冷色，暖色只作为「灯」的语义留在灯火日志里。若想更有氛围，可把 S2 的「潮线发青光」叠到 S4 上（选中块下半截的水线发光）。S1 只在优先「全游戏统一 C_ACC」时考虑；S3 不推荐。§11.6 第 1 条随之改为：标题 / 难度用冷色反白焦点，C_ACC 是否同步改动另议。
