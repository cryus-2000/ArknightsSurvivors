# 骑士攻击连段

状态：已实现，已录制实机预览，完整回归通过。分支 `codex/boss-fx-rework`，继承 168 的冰晶弧斩；未合入 main。用户要求把独立招式衔接，例如斩击后接冲锋。本作改编，保留原有寒冷、冰柱和重生冲锋主轴，不宣称这些连段来自原作。

## 连段表

| 起手 | 后续 |
|---|---|
| 断潮劈击 | 一阶段：冲锋 → 近身连刺；二阶段：冲锋 → 重新瞄准的再冲锋 → 近身回旋；玩家已拉开则收招 |
| 踏冰裂阵 | 一阶段二幕起接掷枪，否则接断潮劈击 → 冲锋 |
| 侧踏挑枪 | 近身接连刺／回旋；远处接冲锋 |
| 掷枪 | 冲锋 |
| 长枪回旋 | 长枪连刺 |
| 长枪连刺 | 断潮劈击 |
| 冲锋 | 一阶段近身收招；三幕追加一次再冲锋后近身收招；二阶段保持三连冲后收招 |
| 冰线 | 沿锁定冰线寒冷追击；一阶段近身收招，二阶段再接一次转向冲锋 |

每组最多 4 个命名攻击阶段（连刺自身的三刺、侧踏自身的位移与挑枪仍完整保留）。每段仍使用已有动作与正式预警管线，下一段按当时主控位置重新瞄准；冰线后的寒冷追击沿已锁定线行进。一阶段段间至少留 0.22 秒收势，二阶段 0.10 秒；二阶段冲锋预警从 0.8 秒缩至 0.6 秒，仍保留 0.4 秒固定锁向，冲锋后等待实际自冲位移结束再接招。普通冲锋沿用配置倍率；连段中的寒冷追击与再冲锋使用基础伤害 ×1.35，避免长连段每一冲都叠加最高伤害。

## 生命周期

- 正式 AI 在可选招式轮换前处理连段，防止新的独立招式插队。
- 不将每个子招再展开成新连段；二阶段旧连冲计数与冰线旧计时由当前队列接管，避免重复冲锋。
- 最后一招若为飞行弧斩，等待其自然结束再喘息，避免破绽状态提前取消弧斩。
- 每组结束进入一阶段 1.6 秒、二阶段 2.5 秒破绽。保留既有破绽受伤倍率，让玩家完成闪避后有反击机会。
- 一阶段撞柱、外部眩晕、破绽、无敌阶段、死亡、转幕／重生会清除尚未释放的预警、后续招式及新增攻击实体；已发出的普通投射物和当前冲刺惯性保留，撞柱／重生仍按原逻辑停止冲刺。冰柱批次不因此重置；二阶段仍可撞碎冰柱继续冲锋。
- 每组有 18 秒保护性上限；状态保存在敌人字典，模拟不使用额外随机数。
