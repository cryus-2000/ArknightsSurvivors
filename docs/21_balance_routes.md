# 21 · 四条精英化路线的强度核对（2026-09-25）

> 方法：云端 Godot 4.4.1 headless，`--autotest --balance --nodeath --pick_evo=<路线>`，每条 3 局跑满 10 分钟，看全程平均输出（伤害 / 秒）、击杀 / 秒与输出构成。`--nodeath` 让机器人不会死，只比较输出，不比较生存。基于 `60e9e3c`（水刃加强后）。

## 结果

| 路线 | 全程输出 / 秒（3 局） | 均值 | 击杀 / 秒 | 输出构成（第一位） |
|---|---|---|---|---|
| 潮刃 · 深渊巨斩 | 1346 / 1350 / 1238 | **1311** | 11.8 | 水刃 45–60%，伞击 20% |
| 潮刃 · 月轮 | 1224 / 1250 / 916 | **1130** | 12.0 | 水刃 50–60%，伞击 15% |
| 群触 · 巨触吞噬 | 966 / 1300 / 1596 | **1287** | 11.6 | 伞击 25%，巨触 / 触手桩 / 触须阵 各 10–20% |
| 群触 · 深海之母 | 1477 / 1111 / 1511 | **1366** | 11.7 | 触手桩 20%，触手 20%，伞击 20% |

- 四条路线均值在 1130–1366 之间，差距 ≈ 20%，单局波动本身就有 ±25%，可以认为持平。
- 击杀 / 秒全部 ≈ 11.8，说明 10 分钟时输出已经超过刷怪量，四条线都能清场。
- 月轮偏低一档（去程 + 回程各命中一次，但回程常常打空）：**回程命中伤害 +25%**（本次调整）。
- 精英化一阶段（3–5 分钟，未质变）：潮刃 139–274 / 秒，群触 120–209 / 秒，同样持平。
- 次要来源：满级无人机 150–200 / 秒，援护 60–170 / 秒，藏品被动 ≈ 130 / 秒；作为副系统占比 10–15%，合理。

## 没做的判断

- 生存差异没有比：机器人走位太笨，死亡时间的方差远大于路线差异（同一路线 186–613 秒），需要真人试玩反馈。
- 10:00 的最终 Boss 只有 20 秒可打（自动对局 620 秒截止），伊祖米克三局都没打完，不代表它过强。

## 复现

```text
godot --headless --path game -- --autotest --balance --nodeath --pick_evo=blade,blade_moon
```
`--pick_evo=<路线,质变>` 让机器人在精英化时固定选这条线（云端测试副本的钩子）。
