## A · 德克萨斯配色（详见 docs/64 §7.4 / §7.4.1）

**目标图**：`art/reference/texas_target_1012.webp`（用户 10-12 认可：「这版本的就挺好」）。以它为准。

- **头发**：深炭灰带一点紫，主色约 `#484050`，暗部约 `#282830`，少量冷灰高光；48px 下读成「黑发」。不要再用 `#4C4C68` / `#7E7A93` / `#908CA9` 这类蓝紫中间调。
- **外套、短裤、长袜、靴**：接近纯黑，约 `#1C1A22`，暗部 `#0E0D12`。这是和现状差距最大、最该改的地方——目标图的「黑」主要来自衣服。
- **保留**：白衬衫、白色企鹅物流徽章（§7.3 的 1x 白块与位置）、橙剑、橙瞳、红色腰带 / 内衬、狼耳、尾巴形状、剪影。
- **明度验收**：近黑（Y < 40，不算描边）≥ 35%；亮部（Y ≥ 160）≥ 8%。
- **交付**：`op_texas_idle / run / attack / skill` 各 1x + @2x；更新 `squad_batch5_texas_manifest.json` 的 sha256；深蓝底 @2x 预览（与目标图并排）；handoff + qa（写色表和两项明度占比）。

## B · 星熊配色（详见 docs/64 §7.5，推荐方案 V5）

- **头发**：整体压深一档，色相不变（薄荷青 170–190°）：
  `#93F9E5`→`#7DE0CE`、`#68FDE3`→`#4FD6C0`、`#3AF2DC`→`#2FC7B6`、`#26C9BD`→`#1FA39C`、`#209799`/`#259897`→`#197A80`/`#1C7C80`、`#196070`→`#134854`。
  Y ≥ 160 的部分不超过头发面积的 45%；头发平均 Y ≤ 140。不要压到墨绿。
- **甲 / 盾按部位拉开明暗**（不是整体压暗）：
  - 甲片受光面、盾面：暗钢 `#7A808C` / `#5E6370` / `#4C505C`，统一到冷蓝灰 215–230°，去掉偏紫的灰。
  - 衣服、甲缝、背光面、盾内侧阴影：`#3A3E4A` / `#2E323E` / `#22252F` / `#1F212A` / `#1A1C24` / `#14161E`（后四档进近黑）。
  - 盾面整体比身上的甲亮半档；盾沿白边 `#E7E6E7` / `#DDE4ED` / `#FEFAF3` 保留。
- **不改**：独角、肤色、眼睛、盾沿发射点 (+45, −42)、剪影。
- **明度验收**（idle@2x 去描边）：近黑 ≥ 25%；亮部 18–30%；受光变亮 ≤ 12%；HSL 明度均值 0.33–0.40。
- **交付**：`op_hoshiguma_idle / run / attack / skill` 各 1x + @2x；更新 `squad_batch5_hoshiguma_manifest.json`；预览、handoff、qa（色表 + 四项数值）。

## C · 跑步重画（详见 docs/64 §9）

**通用规格**（五人都适用）：
- 6 帧循环：f0 前脚着地 → f1 下沉（−1px）→ f2 过渡（两腿交叉，+1px）→ f3 另一只脚着地 → f4 下沉 → f5 过渡。最低限度可以是「着地 / 下沉 / 过渡」三个姿势循环两遍，但三个姿势的腿必须明显不同。
- 整个上半身随步伐上下 1–2px（@2x 2–4px），脚底仍贴第 46 行。
- 头发、尾巴、裙摆 / 下摆、武器尖端比身体晚一帧，幅度 1–2px。
- 不该动的部位（脸、衣服纹样、盾面）逐帧保持同一组像素，只随起伏整体平移；不要每帧整张重绘造成像素闪烁。
- 着地脚在着地 → 下沉 → 过渡三帧里往后移 2–4px（1x），不要钉在同一个 x。
- 只改 `_run`，idle / attack / skill 不动。

**逐人**：
- **德克萨斯**：保留目标图里的前倾弓步造型（用户认可，**不要求抬高身体**）。补上：双腿清楚交替、后脚蹬地脚跟抬起、前脚落地膝盖伸直；长发改成斜向后下方（与水平 15–30°）一束，发梢滞后摆动；剑改低持贴身侧、剑尖朝后下，随手臂摆 1–2px；尾巴滞后摆动。配色用 A。
- **星熊**：步幅小、重，但两只靴子必须在盾下 / 盾前露出（盾下缘离地 ≥ 3px）；靴子和护腿留 1px 中灰亮边，别和盾糊成一块；落地帧身体下沉 1px，盾跟着下沉并晚一帧回弹；长发尾端摆 1px。配色用 B。
- **安洁莉娜**：尾巴改为从腰后向后上方翘起（尾尖高于膝盖），随步伐摆 1–2px、与身体反相；外套下摆在跨步帧向两侧分开，两条腿和两只红鞋都要露出、前后交替；杖斜持，杖头摆 1px；长发与狐耳末梢滞后一帧。配色不改。
- **浊心斯卡蒂**：吟游诗人的轻步——步幅小（约 14–18px）、身体近直立（前倾 ≤ 10°），两只白靴在裙摆下前后交替露出；裙摆下缘与腿反相摆 1–2px；手杖大致竖直，杖头画 1–2px 小弧、比手晚一帧，杖头青光每帧 ≥ 2×2px（1x）；帽檐和发尾滞后 1px。
- **能天使（可选，最后做）**：腿和步频不动；枪随身体上下 1px，光翼碎片和发梢晚一帧摆 1px。

**验收**（Claude 用 `python tools/run_cycle_review.py` 量）：整体剪影变化 ≥ 0.035；腿部变化 ≥ 0.10；头部起伏 1.0–2.5px；相邻两帧几乎相同（< 0.005）至多 1 对。数字达标但看起来仍像滑行，以目测为准。

**交付**：每人 `op_<id>_run.png` + `@2x`；更新各自 manifest 的 sha256；每人一张 3 倍最近邻 10fps 并排预览 GIF（返修前 / 返修后，`squad_batch5_run_rework_<id>.gif`）；`squad_batch5_run_rework_qa.json`；handoff 写明每帧是哪个姿势。
