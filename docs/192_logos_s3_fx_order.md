## 2. 原作对照与出处

- **技能名与效果（原作，PRTS 干员页 <https://prts.wiki/w/逻各斯>，2026-10-28 读取）**：S1「殁亡」、S2「提喻」、S3「延异视阈」。原作 S3：手动触发、自动回复技力；攻击范围扩大、攻击力 +100%、同时攻击 3 个目标（精一起 4 个）；使攻击范围内**敌方子弹飞行速度大幅降低，并在技能结束时全部清除**。本作 S3 是「扇形咒域」改编（范围内每 0.5 秒法术伤害 + 安魂、弹幕减速、结束清弹），名字与「减速弹幕、结束清除」的核心沿用原作。
- **原作 S3 的视觉要点：PRTS 页面只有技能图标和文字，没有特效外观描述，查不到**。能依据的只有用户 9/26 提供的 8 张原作实机截图（`art/incoming/logos_fx_handoff.md` 已据此做出绕身符咒、S2 咒文带、S1 黑色咒文联系、墨蓝弹体）。**本单的外观要点一律以那批截图和已交的 `fx_logos_s3_*` / `fx_logos_glyph` / `fx_logos_script` 为准，延续同一套语言，不另编原作特效描述**；若 Codex 手里有可查证的原作 S3 范围画面，请在 handoff 里写出处。

## 4. 范围对齐与约束

- **判定范围就是这片扇形**：开口 100°、半径 = 范围 × 1.1、圆心 = 逻各斯脚底（**不是**身体中心，`o.pos`）。画面必须与判定一致：不许画出比判定更大的光晕 / 光尘（会让玩家以为在范围里）；外缘 2 美术像素边框就是判定边界，边框以外不画。
- 咒域**会转**（每秒最多 60°，朝敌人最多的方向），所以帧条**不能带固定方向的光源 / 阴影**（不要「左上受光」），上下镜像对称（沿 +x 轴）；咒文行的朝向沿半径方向，不是水平，避免转起来读不出。
- 可读性：咒域与地面怪物 / 弹幕 / 掉落叠画（画在实体之下的地面层，`draw_auras`），所以**暗、疏、低对比**，面上亮度最大的只能是边框。深色海床 `#0D1420` 上做对比检查，面上最亮像素不超过 `#4D5A9A`。
- 性能：网页端每帧一次 `draw_texture_rect_region`，3 条共 18 帧，@2x 总像素 360×528×18 = 3.4 MP，**导出后不得超过 600 KB**（二值透明 PNG + 少量色即可，docs/187 包体预算）；帧数以上表为上限。
- 与已有层的关系：绕身符咒（back / front）继续画在人物前后，咒域帧条在地面层；两者同色系，但**咒域更暗、符咒更亮**，层次靠这一点拉开。
- 不改：判定半径、开口角、持续时间、tick、减速倍率、安魂（docs/31 与 `logos.json`）。
