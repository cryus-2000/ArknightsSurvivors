# 170 剑气非线性速度（10-27）

用户 10-27 原话：「做一下剑气的速度感和力量感，也就是说非线性速度，而不是现在的线性速度」。

## 1. 覆盖范围

| 剑气 | 代码 | 改前 | 现在 |
|---|---|---|---|
| 拉普兰德 领主远掷剑气（普攻 far，4 条）、S2 狼魂追加剑气、S3 / 精二双生刃交叉剑气 | `seg_skadi.gd` shape.wave（带 `proj`） | 匀速 `blade_spd` 500 | 非线性 |

| 可见成长近战剑气（锈蚀刀片 / 老近卫军之锋，docs/163，分支 build-growth-impl 已并入本分支） | `vis_growth.gd` qi | 匀速 `qi_speed` 520 | 非线性 |
| 斯卡蒂 跃浪浪墙（没有 `proj`） | shape.wave | 匀速 | **不变**（浪墙不是剑气；积木写 `"ease": {}` 才开） |

德克萨斯本人仍没有剑气；她只在吃藏品时拿到 vis_growth 剑气。

## 2. 曲线

`game/scripts/characters/blocks/sword_ease.gd`：

- 已飞比例 `p(u) = (1 − glide)·(1 − (1 − u)^k) + glide·u`，`u` = 已飞时间 / 原匀速总时长 `T = dist / speed`
- 速度倍率 `p'(u) = (1 − glide)·k·(1 − u)^(k−1) + glide`：缺省 k 3、glide 0.2 → 出手 **2.6 倍**原速，约 u 0.42 降到原速，末段 **0.2 倍**滑行消散
- `p(0) = 0`、`p(1) = 1`：**飞行总距离、存活时间与改前完全相同**；判定宽度 / 厚度不变

碰撞：出手几帧一帧走 20+ px（原来 8 px），改为扫过「上一帧 → 这一帧」整段（shape.wave 判定盒沿方向加长 step、vis_growth 圆判定改点到线段距离），覆盖的路径与匀速相同，不会穿过小怪。匀速分支（`on` 0、浪墙）代码路径与改前逐行相同。

## 3. 力量感（只用现有画法，不加新特效体系）

- 猛冲段（速度 > 原速）：沿朝向拉长（stretch 0.35）、提亮（bright 0.45）、身后两道残影，残影间距 = 当前速度 × 22 ms（尾迹跟速度走）
- 滑行段：颜色压暗到 0.55、略变短，读作「力尽」（压颜色不压透明度：飞行中不淡出是 lappland_presentation_test 守着的既有口径）
- 猛冲段的头一下命中：顿帧 0.025 秒，走 `impact_pause` 的共享限频（0.28 模拟秒 + 真实时间 hitstop_gap），不会连成卡顿；`pause` 0 关
- `ob_fx.fx_frame` 加了可选 `stretch` 参数（缺省 1，其余调用不变）

## 4. 旋钮

`balance.json` → `sword_ease`：`on` / `k` / `glide` / `stretch` / `bright` / `ghost` / `pause`；单干员覆盖 `sword_ease/ops/<干员 id>/<键>`（如 `"ops": {"lappland": {"k": 3.5}}`）；单条积木再写 `"ease": {键: 值}` 覆盖、`"ease": 0` 关。`--bal=sword_ease/on=0` 整体退回改前。

## 7. 藏品剑气按武器分类（用户 10-27「每个人的武器类型不一样」→「根据不同的武器来，先做一下看看」）

藏品近战剑气（vis_growth qi）按武器分三类 + 通用，**只换画法与速度曲线，判定（qi_w、飞行距离）与伤害各类相同**。表在 `balance.json` `sword_ease/style`，曲线覆盖在 `sword_ease/styles/<类>`，尺寸 `vgrowth/qi_style_scale`。武器依据取自仓库里各干员已有设定（普攻形状 / docs/31）：

| 类 | 干员 | 画法 | 曲线 |
|---|---|---|---|
| blade 刀剑 | 德克萨斯（源石剑，texas.json） | 细长新月一字斩 + 白热刃芯，猛冲段拉长 1.6 倍、新月残影 | k 4 / glide 0.12：更急 |
| thrust 细剑·长柄 | 艾丽妮（细剑，docs/31）、歌蕾蒂娅（钩索） | 前尖后长的菱形突刺 + 三道破空速度线 | k 1.8 / glide 0.45：接近匀速，读作贯穿 |
| blunt 锤·盾·锚 | 推进之王（锤）、星熊 / 塞雷娅（盾）、乌尔比安（锚，docs/31） | 贴地土黄厚冲击波 + 地面压影 + 波前跳动碎石 + 身后犁沟 + 甩尘（g.vrng） | k 5 / glide 0.05：起手最猛、末段几乎停住；顿帧 0.035 |
| saw 贝壳圆锯 | 归溟幽灵鲨（docs/31「贝壳状圆锯」【资料】✓） | 旋转齿盘（10 齿 + 贝壳肋纹），转速跟飞行速度走，边缘甩火花 | k 2.2 / glide 0.35：转着往前推 |
| tentacle 水母触手 | 水月（docs/31：原作普攻是苍白水母触手抽打） | 向前抽出的波状触手，猛冲时拉直、滑行时摆开，头上一颗光点 | k 3.5 / glide 0.15：抽鞭 |
| 通用 | 新加入、还没归类的近战 | 拉普兰德剑气帧条按代表色重染 | 全局缺省 |

颜色（用户 10-27「每个人的都要做成他们自己的对应颜色」）：剑气本体一律用干员 json 的代表色 `col`，按最亮通道归一到 0.85（再高会被光学辉光吹白；色相饱和、不往白里洗；猛冲段提亮对分类剑气只取 0.35 倍，免得艾丽妮粉这类浅色被冲成白）；白只出现在刃芯 / 边缘高光，土色只用于钝器的压影、碎石、犁沟和尘（尘掺 35% 本人色）。通用类同样改用本人色。

拉普兰德 / 斯卡蒂本人的剑气不走这张表（各用自己的帧条）。10-27 用户「几个通用的再去改成特殊的」：归溟幽灵鲨、水月已从通用改为 saw / tentacle，现有吃藏品剑气的近战全部有专属样式。

同场景命中（1800 帧，on 0 → 1）：德克萨斯 70 / 2150.7 → 70 / 2150.7；推进之王 33 / 624.3 → 33 / 624.3（首中提前 3 帧）；艾丽妮 87 / 2310.3 → 87 / 2330.2（命中数同，穿透第二目标的先后变了，+0.9%）。

对照：`python tools/sword_wave_styles_rec.py` → `build/sword_wave_speed/styles_1x.mp4`（原速 5 秒）、`styles_slow.mp4`（1/3 速 15 秒），3 × 2 宫格 6 人。
