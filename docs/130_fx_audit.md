# 130 · 光学观感开启时的老特效盘点（10-24，架构）

用户问：「一些老的特效会不会和新的特效冲突，老的特效是不是可以精简」。只读盘点，未改代码；行号按 main 1d53ae52 读（2da84ab2 只动了 art.gd 行号，已按新号写）。
命中特效（白闪 / 顿帧 / 暴击弱点火花 / 伤害数字）由界面会话在 claude/hit-tiers 做三级命中模板，本文只标出现状与边界（§2.B），建议交那边定。

## 0. 结论

- **后期 pass 已经关干净**：post_fx（辉光 / 水下滤镜 / 曲线）与景深层在光学开时 `visible = false`，GPU 不再白跑（optical.gd:424-427）。真正还在白跑的是**法线光照**（高档）和**光学辉光不认「中」档**，两处是 GPU 大头。
- **重复画最多的是「假辉光」**：老代码用加色圆 / 光晕 / 十字闪模拟发光，光学着色器又按发光度做一遍真辉光。投射物尾迹圆、宝石光晕、敌弹洋红环、fx_add 柔光层都属这类，开光学时画两层，是「油腻」的来源之一。
- **击杀叠了三套**：老 CPU 火花 + 溶解帧条 + 光学碎屑；而且各怪死亡帧条还会触发 fx_burst 火星、抢掉技能火星的限频额度（真冲突，满屏时技能点缀被吃掉）。
- **分配浪费**：`hit_rings` / `hit_spokes` 缺省 0，命中圈 / 辐条只是不画，每次命中照样往 g.fx 塞字典、占 380 / 400 上限。
- 光学在「低」档自动关，所以下面所有「光学开时跳过」的老特效都要**留作低档回退**，不能直接删；真正可删的只有死代码与零效果计算。

共 **61 条**（§2）；建议精简 **15 组**（§3，按收益排序）。

## 1. 前提

- 光学开关：`optical.wanted()`（optical.gd:391-395）中 / 高档开、低档关；`g.optical_on` 每帧由 optical.gd 写，全代码只有约 20 处判断它。
- 画质档（settings.gd:558-564）：高 = 辉光 + 法线 + 景深 + 水下滤镜；中 = 关辉光、法线；低 = 四项全关。
- 降噪缺省（balance.json）：`render/declutter` 3、`render/hit_rings` 0、`render/hit_spokes` 0；满屏时 `kill_k` 0.35、`flash_a` 0.45。
- 「收益」是读代码估的量级（调用数 / 每帧遍历 / GPU 取样），没实测；动手时用同局轮换量净差（探针会放大约 2 倍）。

## 2. 逐项

状态：**白跑**（算了没人用）/ **重复**（新旧各画一遍）/ **冲突**（互相干扰或风格打架）/ **有效**（光学开时仍需要）/ **回退**（只在光学关 = 低档时需要）。
