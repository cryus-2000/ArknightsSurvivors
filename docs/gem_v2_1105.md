## 画面与玩法边界

`render/gem_v2=1`：按经验值 `<2 / 2–<5 / 5–<20 / ≥20` 四档，翠绿→亮绿→浅绿→暖金，复用现有尖晶贴图。低档不使用危险红、敌弹青、暖金。静止远处 RGB ×0.65，不降透明度；靠近/吸起 ×1.12。已有贴图亮面发光跟随各档颜色和亮度，不新增光环；新模式不画原结晶圆形底光。远处仅画面合并的堆按合计经验显示档位，实际拾取位置不变。

`render/gem_cap=1` 是独立的玩法候选：场上存活 XP 达200颗后，新 XP 并入最近的静止大结晶（值≥5），没有大结晶时并入最近静止 XP。不会并入被吸起/弹跳中的结晶；全在飞行时仍正常掉落，原400溢出保护保留。计数不含死亡对象或其他掉落。等距按现有数组顺序选择，不消耗随机数。经验总量守恒，但拾取位置/时间及后续升级可能改变，所以不宣称 cap 开启与基准 TRACE 相同。画面合并门槛仅在 cap 开启时50→30。

关掉两项时保留原画法和掉落路径；不改源石锭、灯油、箱子等。
