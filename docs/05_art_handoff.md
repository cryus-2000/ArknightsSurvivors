# 05 · 美术交接说明（给美术制作方）

## 放在哪里
所有生成的图片放进：

```
E:\ArknightsSurvivors\art\incoming\
```

- 不要直接覆盖 `game\art\px\` 里的文件。放进 incoming 后告诉 Claude，由 Claude 检查尺寸、切帧、替换进游戏、导出新版本
- 文件名必须和下表**完全一致**（小写英文 + 下划线，`.png`）
- 可以分批交付，交哪个换哪个，没交的继续用现在的占位图

## 通用规则
| 项目 | 要求 |
|---|---|
| 格式 | PNG，透明背景 |
| 风格 | 像素画；游戏内统一放大 2 倍、最近邻采样 |
| 边缘 | 不要抗锯齿、不要半透明像素（发光类特效除外） |
| 描边 | 1 像素深色外描边，推荐 `#080E18` |
| 动画 | 多帧素材做成**横向一行**的帧条，每帧同样大小，从左到右排列 |
| 色调 | 深海：底色深蓝青 `#0E2230`–`#2B5A68`；荧光青 `#54EBE0`；灯火暖橙 `#FFC46B`；海嗣紫 `#A885FF` |
| 版权 | 场景、怪物、特效、UI 全部原创；不使用《明日方舟》官方素材 |
