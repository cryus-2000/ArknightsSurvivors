# 148 · 小怪前后期微调 + 囊海爬行者三分之一血无敌自爆 + 队友只在队长冲刺时一起冲（10-25）

> 用户 10-25 原话：「后期小怪的血量稍微有点高，略微下调一点点，前期小怪的伤害和血量可以提高一点点」；「囊海爬行者设置成每过三分之一的血量就无敌然后自爆一次，自爆完之后再继续扣血」；「干员要不要设置成冲锋的时候一起冲锋，平时就跑动攻击，不自动冲锋，除非技能」。分支 `claude/trim-pocket-dash`。

## 1. 小怪前后期微调（balance.json enemy 段 `trim_*`，spawner.gd `_trim_apply`）

| 段 | 生命 | 伤害 | 说明 |
|---|---|---|---|
| 0–3:00 | ×1.08 | ×1.08 | 3:00 后 60 秒线性回到 ×1 |
| 7:00 → 8:00 | 线性降到 ×0.92 | 不动 | 8:00 后保持 |

只作用于普通怪（role ""，含大群 / 威胁小波的普通怪）；精英 / Boss / 事件 / 友方不动。叠在 `dmg_early` / `hp_late` / 密度缩放之后。关闭对照：`--bal=enemy/trim_early_hp=1 --bal=enemy/trim_early_dmg=1 --bal=enemy/trim_late_hp=1`。
与 `claude/difficulty-curve`（方案 A+B：围猎并入大群、`dmg_late_cap` 0.25）叠加：前期 +8% 与围猎并入后 0–3 分钟压力同向（偏难），后期 −8% 生命与 `dmg_late_cap` 0.25 方向相反（生命降、伤害升，总体 TTK 略短、承伤略升）；同屏上限 65 的补偿也动同一段，三者合并后需统一复测。

## 2. 囊海爬行者：三分之一血无敌自爆

- 生命降到 66%、33% 两个节点各触发一次：进入鼓胀（`burst_fuse` 1.1 秒）→ **鼓胀期间无敌**（`combat.enemy_hit` 直接挡掉，不飘字；其余直接改血的路径由 `burst_floor` 兜底，生命不低于节点，无敌期间的伤害不累计）→ 原地爆裂（`burst_r` 160，沿用）→ 恢复可受伤继续扣血。
- 一次大伤害越过节点时只掉到节点（不会一口气跳过节点）。33% 之后没有第三个节点，最后打死时和以前一样（死亡本身没有爆裂，死在鼓胀中则取消）。
- 预警沿用鼓胀帧条 + 范围圈从小到大，不闪。图鉴说明同步。
- 回归：`enemy_identity`（test_pocket 重写：节点、封顶、无敌、恢复、无第三节点、死亡取消）。演示：`tools/probes/pocket_capture.py`（gif：`pocket_burst.gif`）。

## 3. 队友：平时跑动攻击，只在队长冲刺时一起冲

盘点（只读代码；位移分三类）：

| 干员 | 类别 | 触发 | 处理 |
|---|---|---|---|
| 德克萨斯（队友短突进） | 自动突进 | 非队长、每 2 秒、敌人在 100–260 | **删除**（texas.json tick 块与 step_* 参数、图鉴说明、test_core 断言） |
| 艾丽妮 / 拉普兰德 / 推进之王 / 斯卡蒂 / 归溟幽灵鲨 / 乌尔比安 | 近战前压追怪（`blocks.follow`） | 队长 200 内有敌人，每帧向目标平滑靠近，不是冲刺 | 保留（走位，属于「跑动攻击」） |
| 全体可突击队友 | 指挥「突击」第一下冲锋 | 玩家切到突击 | 保留（指令，不在本条限制内） |
| 凯尔希（Mon3tr 扑击 / 回防） | 召唤物位移 | 目标在 80 外 / 队长受击 | 保留（召唤物，非干员本体） |
| 德克萨斯（战术快递，精一起） | 响应队长冲刺 | 队长冲刺起步 | 保留（= 跟随冲刺） |
| 推进之王（跟进锤击） | 响应队长冲刺 | 队长冲刺结束 | 保留（= 跟随冲刺） |
| 乌尔比安 S3 / 推进之王 S2 / 归溟幽灵鲨 S2 | 技能自带位移 | 技能期间 | 保留（技能） |

新增通用「跟随冲刺」（character.gd `follow`，balance.json `command/dash_follow` 1 / `dash_follow_k` 22）：队长冲刺期间，随行队友不停顿、不前压追怪，以 22/秒的速率贴编队位一起冲，冲完恢复普通随行。演示：`tools/probes/dash_follow_capture.py`（gif：`dash_follow.gif`；日志里队友与队长的相对位置冲刺中变化 ≤ 12 像素，德克萨斯不再自己上前一步）。
