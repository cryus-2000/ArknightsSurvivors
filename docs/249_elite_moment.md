# 249 成长看得见：精英化时刻 + 看得见的节点（11-05）

**结论（5 行）**
1. 两个开关都做完，缺省 0：画面 `growth/elite_show`（精英化定格 + 横幅 + 爆亮 + 常驻脚下光池），数值 `growth/visible_nodes`（普通节点攻击 +6% 换成范围 / 弹数 / 体量，精二本人一档 + 每人一条全队效果）；开关全关时同种子 TRACE 逐行一致。
2. 看得见：截图里精二一眼能认（大光池 + 亮边），精英化瞬间有横幅、光柱、爆亮；精一光池偏淡，能天使等红色系调成淡粉白后在暗地面上对比不够（§5）。
3. 数值不补偿时两档都出窗：无认知 54.8% → 66.7%、18 细胞 65.5% → 81.0%（配对 18 细胞负转胜 23 / 胜转负 10，p 0.035）。
4. 按用户 11-05「加成给多了就加强怪物」：开关开时怪物生命 ×1.08（`vis_nodes/enemy_hp`），无认知 52.4%、18 细胞 67.9%，都回到窗口，配对差不显著（19 / 21、17 / 15）；只加生命 ×1.15 会把 18 细胞压到 59.5%。
5. 补偿后后期清怪比、终结技占比几乎不变（5–9 分钟终结技击杀 14% → 13%、19% → 19%）：本版解决「成长看得见」，没有解决「后期靠终结技清屏」；后者要和 docs/248 形状档一起开、再配对测（§3.3、§8）。

分支 `claude/elite-moment`（基于 `claude/late-power-ab` 329f277ee，即 docs/243 诊断 + docs/248 形状原型）。两个开关缺省都是 0：`growth/elite_show`（画面）、`growth/visible_nodes`（数值）。开关全关时同种子 TRACE 与 329f277ee 逐行相同（§6）。

## 2. 精英化时刻（`growth/elite_show`，纯画面）

### 2.1 演出

| 环节 | 做法 | 时长 |
|---|---|---|
| 定格 | 选下精英化卡、关掉选卡面板回到战斗的那一刻，模拟停住（同顿帧：只在玩家局；平衡 / 批跑不停，不改模拟步长） | 精一 0.45 秒 / 精二 0.7 秒（`elite_show/freeze_e1` / `freeze_e2`，缺省写在代码里） |
| 横幅 | 屏幕上方一条本人颜色描边的暗条：「德克萨斯 · 精英二」+ `ELITE PROMOTION II`；精二且开了 `visible_nodes` 时下面一行全队效果（「全队技力回复 +8%」） | 0.12 秒淡入，定格结束后 0.2 秒开始淡出，0.4 秒淡完 |
| 爆亮 | 干员本体调色 ×(1 + 2.2k)，k 0.08 秒冲到 1 后指数回落；身后一团静止的本人颜色亮光、一道向上收细的光柱，脚下光池放大 35% | 约 1 秒 |
| 光点 | 精二 18 颗 / 精一 10 颗本人颜色光点从脚下升起（只用 vrng） | 0.6–1 秒 |

- 横幅文字按 docs/76 §2「精英一 / 精英二（正文）」写成「某某 · 精英二」，与现有全屏演出标题一致（任务原文写的是「精英化二」，按术语表改）。
- 横幅和普通横幅在同一带（屏高 22%）：时刻横幅在场时普通横幅只是不画、计时照走（同 Boss 名片 / 终结技切入的让位写法）。
- 不加外扩光环：没有向外扩的环，亮光和光池都是静止的。

### 2.2 常驻标识：脚下光池

- 本人颜色的椭圆光池（三层同心实心椭圆，贴地 y × 0.45），画在影子之前、本体之下。
- 精一：半径 19、透明度 0.26；精二：半径 27、透明度 0.36，外加一圈 1.5 像素亮边。不闪、不呼吸、不外扩。
- 队长脚下原来那块深色软影（docs/208 H1）在光池开着时压到 35%，不把队长的光池盖黑。
- 红色只给危险：本人颜色色相在红区（< 0.05 或 > 0.92）且饱和度 > 0.35 时向暖白调淡 70%（能天使、维什戴尔、浊心斯卡蒂的光池 / 横幅描边都是淡粉白，不是红）。
- 截图：`docs/assets/elite_moment/stages_texas.png`、`stages_exusiai.png`（§5）。

### 2.3 让位规则（与终结技、升级三选一一致）

`game.check_pending` 的顺序，本时刻插在终结技之后、全屏演出之前：

1. 终结技播放中 → 全部等播完（原规则）；
2. **精英化时刻**：有排队的就开播；定格中返回，挡住后面所有弹窗；
3. 全屏精英化演出（`show_queue`，原规则，首次完整播放）；
4. 路线选择 → 宝箱 → 升级三选一（原规则）。

- 时刻的计时只在 `state == PLAY` 时走：全屏演出期间停住，关掉后光柱收尾、横幅淡出。
- 定格结束那一帧主动调一次 `check_pending`，接着弹排在后面的全屏演出 / 选卡。
- 平衡 / 批跑模式下时刻不挡弹窗（返回 false），弹窗时刻、模拟步长与关时相同；所以 `elite_show=1` 也不改 TRACE。

- `game/scripts/run/elite_moment.gd`：队列、计时、定格判定、爆亮系数、光池 / 光柱 / 横幅绘制。
- 挂点：`character._elite_show` 入队；`game.check_pending` 让位；`game._process` 定格分支（紧跟顿帧分支）与真实时间计时；`squad.draw_shadows` 光池；`character.draw_body` 爆亮；`hud.gd` 横幅；`hud_banners.gd` 普通横幅让位；`squad.draw_leader_mark` 软影压淡。

### 3.3 与 docs/248（`growth/late_shape`）怎么合

| | docs/248 late_shape | 本文 visible_nodes |
|---|---|---|
| 管哪一段 | 精英化节点（精一 w 0.5、精二 w 1.0）+ 队伍等级门槛（Lv16 / Lv22 各 0.5）的形状档 | 4 个普通节点 + 精二 |
| 形状项 | 每档：melee 范围 + 剑气；multi 弹数 + 范围 + 穿透；summon 范围 + 召唤伤害；control 范围 + 控制时长 | 每节点只一项（范围 / 弹数 / 体量） |
| 属性项 | 无 | 去掉节点攻击 +6%；精二本人攻击 / 攻速一档 + 全队效果 |
| 形状卡 | 协同·广、扩散、连锁进卡池 | 不加卡 |
| 来源名 | `lshape:<id>` | `vnode:<id>:<prog>`、`ve2:<id>`、`vteam:<id>` |

- 不重复加码：两者管的节点不同（late_shape 只看精英化 / 等级，本文只看普通节点），流派表共用一张（`late_shape.lane`），额外弹共用一个累计器。
- 同开时：一名干员满成长 = late_shape 2.5 档 + 本文 4 个节点。按 multi 算，额外弹每次普攻 0.6×2.5 + 0.2×4 = 2.3 发——偏多，所以**同开时建议把本文 `vis_nodes/shots` 降到 0.1、late_shape `shape_lv/w_e2` 不动**（§4 只测了本文单开，同开组合未测）。
- 建议合法：普通节点 = 本文（每节点一项，替换攻击 +6%）；精英化节点 = late_shape 的形状档 + 本文的精二基础属性与全队效果；等级门槛 = late_shape。这样成长线六个节点每一个都有看得见的东西，没有一处同时拿两份形状。

- 清怪比（非终结技对普通怪伤害 ÷ 新刷怪生命）分子分母同涨约 8%，所以基本不动；终结技占比不动。**结论：本版不改变「后期靠终结技清屏」。** 加成换成了形状（范围 / 弹数），但被怪物补偿吃回去，结构没变。

### 4.3 胜率差 < 10 点不下结论

定档后两档的开 / 关差是 −2.4 / +2.4 点，都在 10 点以内、配对 p > 0.8：只能说「补偿后难度没有明显变化」，不能说更难或更易。
