# 178 卡面受益标签与文案修订（10-28）

分支 `claude/card-tags`（自 `origin/claude/integ-1028`）。起因是用户 10-28 的三张截图：

1. 「赶车夫的长鞭」主效果是近战攻击范围，卡底却标了能天使。原因是附带的「物理伤害 +8%」。
2. 「散轶诗简」编队里没有召唤物，三人却都上了标签。原因是附带的「追击与召唤物伤害 +15%」。另外卡面把维什戴尔、水月、凯尔希三人的规则全写了出来。
3. 拉普兰德的招募卡只剩「领主」两个字，其他干员也有类似情况。

## 1. 受益标签：主效果与附带数值分开（run/affects.gd）

- 可见成长的 growth 效果以前一律记成「与干员无关」，标签里只剩附带数值。现在按 vis_growth 的实际对象出标签：
  - 散射、连发：远程干员
  - 清群、剑气、增幅：近战干员
  - 召唤体型：有追击或召唤伤害的干员
  - 召唤数量：只有维什戴尔、水月（Mon3tr 不加数量）
- 藏品效果里标 `"minor": true` 的附带数值，只落到主效果没覆盖的干员身上，不算主受益：
  - 显示为淡色标签加「仅物伤 / 仅远程伤害 / 仅追击伤害」，排在最后，放不下时先收进「+N」。
  - 没人吃到主效果时，最前面写缺条件说明，如「编队无维什戴尔 / 水月」。
- 标了 minor 的效果：#58、#59 的远程伤害；#63、#64 的物理伤害；#129 的追击伤害。#56 的近战伤害 +20% 和 #130 的追击伤害 +25% 是主效果，不标。

## 2. 点名干员的卡面只写当前编队（relic_fx.squad_desc）

藏品数据里加了 `desc_squad`，目前只有 #129 用到：

| 字段 | 含义 |
|---|---|
| head | 开头 |
| ops | 每名干员一句，只拼在队干员的那几句 |
| tail | 结尾 |
| none | 编队里一个都没有时用的整句，把能吃到的追击 +15% 写在最前，这样手机一句话正好取到它 |

完整规则 `desc` 放在电脑悬停、手机「详情」和图鉴里。选卡、商店、开箱三处都改了。

编队没有召唤干员时，卡面为：「追击与召唤物伤害 +15%；增殖：本编队暂无召唤物（维什戴尔 / 水月入队后生效）。每多一层，增益递减」。

## 4. 手机详情不截断

手机卡片的「详情」框原来高度固定。现在最小字号仍放不下时把框加高：先盖住操作条，再整体上移，以面板为界。
