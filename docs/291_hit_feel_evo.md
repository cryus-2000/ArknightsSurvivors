# 291 · 打击感进化：像素近战文章对照与试点（11-07）

## 3. 试点（提交 406485760，`render/melee_impact.gd` 末段）

- 总开关 `fx/melee_evo`（缺省 0），按干员 `fx/melee_evo_op/<干员>`（texas、hoshiguma 为 1）。其余旋钮见 balance.json `_melee_evo_doc`。
- 挂点：德克萨斯走卡肉 `meat()`（局部停帧，停帧期间探出 + 扇形停在第一拍），星熊走通用包 `hit()`（全局顿帧本来就停 g.t）。
- 画在 `character.draw_body`：本体前先画扇形和残影，本体位置加 `lunge`，命中第一拍乘 `peak`。
- **时钟**：不新增任何顿帧，不改 g.t / 判定 / 位置；只用 g.t 算年龄、g.vrng 扬尘，不碰 g.rng。
- 颜色：星熊沿用打击感包本人色，德克萨斯用定稿琥珀次色 #ffac3c。

## 4. 验证

- GCP `render-melee-evo1`：同种子开 / 关 TRACE（批跑 + 玩家时钟）、德克萨斯 / 星熊 2×2 对照录像（30 帧原速、带声）。结果见 §5。

## 5. 结果

- TRACE（德克萨斯、星熊，`fx/melee_evo` 关 / 开）：批跑 301/301、玩家时钟 121/121 逐行一致（GCP `render-melee-evo1`）。
- 第一轮录像看不到效果：被这一下打死的怪被当成「没目标」跳过，前期几乎刀刀击杀，所以基本不触发；78a3811ce 修掉。
- 扇形第一版是实心平涂的一大块，像贴了张纸片：改成细月牙（外缘一格热白、内缘一格压暗、尾巴三阶渐隐，`fan_th` 0.5）。
- 星熊在 40–52 秒那段正在放技能，没有普攻，录像里看不出来；试点改成德克萨斯 + 推进之王（`melee_evo_op` 加 siege）。

## 6. 刀光以外的手法（11-07 用户「除了拉刀光以外还有什么办法可以增强打击感？」）

> 参考（公开资料，按记忆转述，没逐条再核）：Vlambeer Jan Willem Nijman「The Art of Screenshake」（顿帧 sleep、敌人击退、低音、永久残留、镜头往开火方向推）；Hollow Knight / Dead Cells / Hades 的打击感拆解（攻击方与受击方分开停、受击白闪 + 形变、方向火花）；怪物猎人（按部位与肉质换命中声和停顿长短）；吸血鬼幸存者类（同屏几百只时打击感主要靠击杀和音效，不靠单次命中）。
> 割草这一栏回答两个问题：几百只怪同屏会不会糊成一片，帧率能不能扛（逐只做的东西要有上限）。

| 手法 | 我们现状 | 适合割草吗 | 建议 |
|---|---|---|---|
| **顿帧分层**：攻击方停 / 受击方停 / 全局停 | **部分**：全局 vfx.stop（0.5 s 间隔）、德克萨斯局部卡肉（只停施放者 + 最近 4 只） | 局部停最适合：世界照走不卡节奏；全局停高频会拖慢、有间隔限制 | ★ 把局部卡肉推到全部近战（按干员调 hitstop_ms），全局停只留给重击 / 精英击杀 |
| 受击闪白 | 有（flash_*、本人色闪） | 适合，已有拥挤降噪 | 不动 |
| 受击形变挤压 | 有（squash 横 +30% 纵 −25%） | 适合 | 不动 |
| 击退（画面推开再弹回） | 有（recoil_px、melee_impact push） | 适合，判定不动 | 不动 |
| **受击硬直帧**（被打的怪停在受击姿势） | **部分**：卡肉冻结选帧只给德克萨斯 | 适合，冻结只改选帧，便宜 | ★ 随局部卡肉一起推 |
| 死亡碎裂 | 有（死亡帧条 / 溶解 + 按体型分档爆点） | 成片死亡容易糊；已有火花总量上限 | 可加「最后一击方向」：碎块朝攻击方向飞（只改方向，不加量） |
| 镜头微震 | 有（轻震 3 px / 0.12 s，重击） | 只能给重击，高频会晕（10-10 删过震屏） | 不加量 |
| **定向震**（往攻击方向推一下镜头） | 没有 | 比随机抖不晕；只给队长重击 | ★ 重击时镜头沿出手方向推 2 px 再回，替代随机抖；和 3 px 同量级 |
| 轻推拉（命中拉近一点） | 没有（终结技有冲击帧） | 割草视野要稳，不适合普攻 | 不做；只留终结技 |
| **音效分层**：起手 / 命中 / 肉感 / 重击低频 | **部分**：干员出手音 + 命中音 + 击杀材质层；肉感只有德克萨斯（flesh）；重击低频只给主控挨打 | 适合，音效有合并与满槽丢弃 | ★ 近战干员都补肉感层（原作音源可用），重击叠一层低频 |
| 按命中数调音量 / 音高 | 部分：击杀按体型调音高；一刀砍中多只不变 | 适合：一刀砍 8 只应比 1 只厚，但只播一次 | ★ 按这一下命中数加 1–3 dB、音高略降（播一次，不叠） |
| 命中火花方向 | 部分：暴击 / 弱点有火花，普通命中靠干员自己 | 方向火花比放射火花干净 | 普通命中火花一律沿出手方向的扇面（已有口径：不要规整放射） |
| 碎屑 / 体液按敌种 | 部分：击杀分甲壳 / 血肉两种声音，画面颗粒不分 | 适合，按种换颜色不加量 | 海嗣喷体液、甲壳掉碎块：只换材质，不加数量 |
| 伤害数字节奏、暴击 | 有：普通白 14 / 暴击金 22、Boss 合并、>30 条不飘白字 | 已为割草收过 | 暴击数字加 1 拍放大再缩回（弹出节奏），其余不动 |
| 输入缓冲 / 前摇后摇 | 普攻自动，没有输入；终结技 Q、冲刺有 | 主角前摇压短这条文章也讲；判定不改 | 只看 Q / 冲刺按下到出手之间有没有空拍（另查） |
| 命中闪光照地 | 有（转平面照地光、lit_k 提亮） | 灯光有预算 | 不动 |
| **慢动作**：精英 / 最后一只 | 部分：精英 / Boss 击杀 g.hitstop 0.12；终结技冲击慢放 | 割草没有「最后一只」，只适合精英、Boss、波次清场 | ★ 精英击杀从「停 0.12」改「慢放 0.25 s（0.3 倍速）再回速」，冲击帧那套回速曲线可复用 |
| 手柄震动 | 部分：只有主控受击和一处全局事件 | 适合，不影响画面 | 队长重击、精英击杀加短震（受「手柄震动」设置） |

**推荐先做（结合不能糊、不能卡、画面不脏）：**
1. 局部卡肉推到全部近战（攻击方 + 受击方分层停，世界不停）。
2. 音效补肉感层 + 按命中数加厚（只播一次，不叠满槽）。
3. 精英击杀改短暂慢放（复用终结技回速曲线）。
4. 重击定向推镜（2 px，替代随机抖，量级同已批的 3 px）。
5. 队长重击 / 精英击杀加手柄短震。

都只改画面、音效、手柄，不改判定和数值；顿帧与慢放如果走全局时钟，按 docs/53 的做法只在玩家时钟生效、批跑不消耗。

## 8. 推到全员（11-07 用户「先推到全员吧」）
