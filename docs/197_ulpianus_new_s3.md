# 197 · 乌尔比安新 S3 方案（2026-10-29，只出方案、未改代码）

协调人派活：用户 10-29 定新系统——队长终结技（Q，手动，每人新设计）+ 队友连携技（E，终末地式条件窗口）；三个技能以后一律自动，手动技能体系（目前只有乌尔比安 S3 `mode: manual`）并进终结技。乌尔比安 S3 要换，用户原话「自动瞄准会很晕，我觉得得换个技能」。

## 2. 挪走的部分（候选都不碰）

- **「钩 / 锚 + 选落点 + 冲过去」**（现 S3「必须开辟的通路」的整套手感，含 docs/129 冲锋、docs/143 像素冲锋特效、左键点场地释放）→ 整体挪给他的**队长终结技**（进第一批终结技原型）。名字、冲锋、落点眩晕都跟着走，S3 不再位移、不再瞄准。
- **「钩与锚」联动**（与歌蕾蒂娅）→ 并入新连携系统。
- 所以新 S3 的三条约束：**不位移、不瞄准、不拉队长 / 镜头**；核心意象不再是「掷锚到某处」。

## 3. 候选

### A「本性的坚守」（推荐）

取材第一天赋：受到伤害时治疗自身。本作做成一个限时姿态。

- **效果**：SP 22、持续 8 秒。期间受到的伤害 −25%；每次受击回复 1.2% 最大生命（每 0.25 秒至多一次）；每累计受击 4 次，原地抡锚撼地一圈（半径 150，锚击 150% × 技能强度，击退 140，眩晕 0.5 秒，精英减半、Boss 不晕）。
- **自动释放条件**：技力满，且 160 内 ≥ 3 名敌人或 200 内有精英 / Boss（docs/151 的「有敌才放」）；不满足就攒着。
- **和 S1 / S2 / 回复的配合**：S1 把精英拽到面前打断 + 沉默 → 正好在姿态里吃它的近身攻击，给撼地攒次数；S2 永久攻击加成直接放大撼地；回复 2.5 是底子，姿态期间按受击补，挨得越多补得越多，回复 2.5 不用再加。
- **当队长**：不移动、不瞄准，玩家照常跑，被围时自动开、减伤 + 回血 + 震开。正对 10-28「把自爆怪 / 精英拉到面前就死」那条体验。
- **当队友**：他在队伍前排时同样开（判定以他自己为中心）；受击回血 / 减伤按本作的承伤口径只作用于队长承伤（落地前要核：队友身上挨打是否计入「受击次数」，不计就改为「他身边敌人每 1 秒算一次」）；撼地照常清他身边的怪。
- **风险**：10-29 他的胜率已比其余开局高约 +9 点，A 是纯生存，要和降点别处一起做（例如 S1 沉默 1.0 → 0.8，或撼地倍率 150% → 120%），定稿前云端对照。

### B「血脉的哺养」（与天赋互换）

天赋改用「本性的坚守」（受击时回复：每秒至多一次，回复 0.8% 最大生命，代替一部分回复 2.5 → 2.0），原天赋「血脉的哺养」挪成 S3。

- **效果**：SP 22、持续 10 秒。攻击 +40%、锚击间隔 −20%；每击倒一名敌人回复 0.5% 最大生命（精英 5%）；击倒精英时持续 +2 秒（至多 +6 秒）；编队其他深海猎人（带「深海猎人」标签的歌蕾蒂娅、斯卡蒂、浊心斯卡蒂、归溟幽灵鲨）获得一半的攻击加成。
- **配合**：S1 钩精英 → S3 期间击倒精英续时间；S2 叠攻击。天赋从「击杀叠攻击」改为「受击回血」，叠层系统交给 S3。
- **当队长 / 队友**：纯自身加成，无位移、无瞄准；队友时深海猎人互相加成更明显。
- **风险**：改动面大（天赋、成长节点「精英一」的说明、S2「天赋层数上限」那条要重写）；收益偏输出，不解决「被围就死」。

### C「前路」

取材模组名「前路」（CRU-Y），意象是在前方清出一条路，但人不动。

- **效果**：SP 20、持续 10 秒。锚击改为朝前方 120° 扇形（半径 = 锚击半径 ×1.4），每次命中把敌人向前推 90（精英 ×0.4，Boss 不动），被推开的自爆怪沉默 1 秒（同 S1 的沉默状态，不会自爆）；期间自身移速 +10%。
- **方向**：当队长时 = 移动方向（停下时保持最后的方向）；当队友时 = 朝敌群最密处。只是锚击朝向，不转镜头、不位移。
- **配合**：S1 拉近 → S3 推远，一拉一推容易显得互相抵消；S2 扩大半径对扇形同样有效。
- **风险**：「朝移动方向打」会让往回跑的队长把身后的怪漏掉；而且原作资料里「前路」只有模组名，核心意象是本作推出来的，取材最薄。

## 4. 推荐与连带改动

推荐 **A「本性的坚守」**：名字是原作里还没用过的天赋，意象「挨打回血」原作可查；自动释放最自然；不重叠终结技（位移 + 选点）和连携（钩与锚）；直接回应 10-28 的死法。

不管选哪个，都要连带改：

- 回归：`ulpianus_charge`、`ulpianus_click` 两项随 S3 一起迁到终结技；`manual_all` 里乌尔比安 S3 的手动项删去；记忆「手动技能只对主控」作废，以终结技为准。
