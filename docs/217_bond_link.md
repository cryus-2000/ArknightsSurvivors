# 217 羁绊连携（连携 v2 第二期，docs/209 §2.3）

状态：**协调人 11-01 批复 8 条全收并已实现**（B7 收，出处按「流明页单向点名 + 同属审判庭」写；编队要轻提示，见 §4）。分支 `claude/bond-link-1101-de7d06`（自 `claude/integ-1101` 75a1de975）。

## 0. 一句话

队长放技能触发连携（v2 规则不变：全队共用 `link/v2_gap` 60 秒、区域没敌人不亮）时，如果队里有和队长**有原作关系**的队友，优先由他接，并且换成这对人的**专属合击**：两个人都出手（队长原地出一招，不位移；队友按自己的方式进场），画面上看得出是「这两个人一起」。开关 `link/bond`，缺省 1；0 = 完全不求值，回到 v2 的按姿态挑人。

## 1. 规则

1. **触发**：沿用 v2（`link_v2.on_skill`），不新增触发次数、不改间隔。挑人时先查羁绊：队长 × 在场队友有配对 → 该队友接，跳过姿态排序；多个配对同时满足时，群体（B8）优先，其余按「最久没接过」轮换（同 v2，不抽随机数）。接手队友不满足 v2 的可接条件（撤回中、被指令占用、不在场）时按普通 v2 挑人。
2. **双方出手**：队友部分走 v2 的进场（光柱 + 接力光）；队长部分是从队长位置**原地**发出的一击（剑气 / 弹道 / 锚链 / 灯光），队长不位移、不被打断普攻、不扣技力（玩家在操控队长）。配对是对称的：谁当队长谁原地出手，另一人进场；每对只有一套编排，按「谁是队长」换出手位置。
3. **伤害**：全部走 `skill_link._dmg`（v2 的按目标生命预算 × 倍率 × `link/v2_mult`，取和攻击力口径的较大者），记「技能连携·<合击名>·<干员>」，标签「连携」。下表「倍率」就是 `_hit16` 的 mult，和现有 20 人接法同一量级（现有单段 0.2–1.6）。两人各打一段，所以一次合击的总量约等于普通连携的 1.5–2 倍；频率不变（60 秒共用间隔），预计连携输出占比在有配对的编队里从约 1.1% 涨到 1.5–2%，不影响胜率判断口径（docs/209 §2.4）。新增旋钮 `link/bond_mult`（缺省 1.0）整体缩放，便于云端校准。
4. **协同格**：和普通连携一样 +1 格，不额外加（避免羁绊编队的连携终结技次数变多）。
5. **范围**：落点 = v2 选出的区域（`link_v2._area`），半径 = v2 区域半径；下表写的数值是相对它的倍数或绝对像素，最大不超过普通连携的 1.3 倍（层级仍是「技能 < 连携 < 终结技」）。
6. **演出**：v2 口径（不慢放、不压暗、不停顿、无冲击帧）。辨识度靠两人的干员色在同一处交汇 + HUD 左侧闪两个小头像（普通连携只闪一个）+ 合击名。合击名不做语音（台词素材要另切，见 §4）。
7. **与 docs/160 连携技（`synergy`）的关系**：那套是「任一人放技能 → 搭档 12 秒冷却的小合击」，名字取原作后勤技能名；本稿是 v2 连携的替换版，60 秒一次、更重，名字本作自拟、不与它重名。两者可以同时存在：同一时刻 synergy 已占用搭档（`squad.syn` 进行中）时，羁绊让路、按普通 v2 挑人。
