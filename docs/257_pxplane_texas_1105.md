**普攻档差（用户 11-05「把还不够的第一条改进一下」）**：第一版精零 → 精一的刀痕只差 2 格宽，主要靠钉剑看出变化；现在刀痕本身拉开：精零细、刃线亮琥珀，精一粗、白刃、地上焦痕弧、碎晶多一倍大一圈。旋斩同一规则。

**跟人走 / 翻转错位**：拔刀刀痕、旋斩、号令光柱用框架的 `fo` 偏移（绘制时按施放者当前位置重算，docs/246 §10）。另修了框架 `_draw_strip` 的水平翻转：原来用负宽矩形，GCP 的 GL 兼容渲染下整张往右错开一个帧宽（发光点却在原位），骤雨每隔一下旋斩离开人约 200 像素；改成镜像变换（提交 47e5b236c），所有干员朝左的件都受益。

**不碎**：拔刀和旋斩收刀时整道一起变薄变暗，宽度不到 1.6 格就整道消失（第一版留下一圈 1 格的白点弧，GCP 首图里看得到，已改）。

同一招元素至多 3 种：主形（刀痕 / 落剑 / 光柱 / 直线刀光 / 飞剑）、贴地件（投影 / 冲击焦痕 / 剑阵 / 余像边线）、颗粒（碎晶）；照地光不算元素。

**尺寸档**：范围成长（`late_shape` 近战每档 +12%、范围卡）会放大判定，帧条按判定半径预生成几档，游戏挑最近的一档（只整数放大）：拔刀 56 / 63 / 70，旋斩 50 / 56 / 63（美术像素）。

**原作对应**：普攻的橙色弧光与三角碎晶、S1 的橙色亮环 + 碎晶取自原作 `texas_attack_01` / `texas_skill_01`（本机回放参照）。本机回放的原作 S1 参照里只有亮环、碎晶和地面范围块，没有成形的剑；本作「剑从天而降、插地、刃光」是按技能名和本作剑雨玩法（原画面也是落剑）画的，不是照原作画面。原作 S2 是立即获得部署费用，没有攻击特效。S3、连携在本作都是改写过的玩法，没有原作画面可照。
