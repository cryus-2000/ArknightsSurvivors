**同屏封顶**：剑雨同一次至多画 10 / 13 / 16 柄（其余照常结算伤害，只是不画）；余像落剑至多 12 柄；剑气同屏至多两组（最新两次出手），每组沿路落剑至多 3 柄；拔刀同一名干员只留最新一刀 + 正在收的一刀（同斯卡蒂）；落剑落地的碎晶 / 照地光只给每组前三柄和收尾巨剑。

**不碎**：拔刀和旋斩收刀时整道一起变薄变暗，宽度不到 1.6 格就整道消失（第一版留下一圈 1 格的白点弧，GCP 首图里看得到，已改）。

同一招元素至多 3 种：主形（刀痕 / 落剑 / 光柱 / 直线刀光 / 飞剑）、贴地件（投影 / 冲击焦痕 / 剑阵 / 余像边线）、颗粒（碎晶）；照地光不算元素。

**尺寸档**：范围成长（`late_shape` 近战每档 +12%、范围卡）会放大判定，帧条按判定半径预生成几档，游戏挑最近的一档（只整数放大）：拔刀 56 / 63 / 70，旋斩 50 / 56 / 63（美术像素）。

**原作对应**：普攻的橙色弧光与三角碎晶、S1 的橙色亮环 + 碎晶取自原作 `texas_attack_01` / `texas_skill_01`（本机回放参照）。本机回放的原作 S1 参照里只有亮环、碎晶和地面范围块，没有成形的剑；本作「剑从天而降、插地、刃光」是按技能名和本作剑雨玩法（原画面也是落剑）画的，不是照原作画面。原作 S2 是立即获得部署费用，没有攻击特效。S3、连携在本作都是改写过的玩法，没有原作画面可照。

## 3. 实现

- `game/scripts/render/fx_pxplane.gd` 末段「德克萨斯」：事件 `_ev_tx` → 一次性件；落剑是一组件（`ly: rain`，画时按每柄的出手时刻展开，立起件进单位排序、冲击 / 焦痕画在地面层）；直线刀光、余像边线运行时逐格画（2 世界像素一格、15 fps 节拍换形）；钉剑跟着被钉的敌人（只读位置，按 15 fps 跳格）；剑气读 `o.vg.qi`（只读；画面计时记在剑气字典的画面专用键 `_pxd`，玩法不读）。落剑落地那一下的碎晶 / 照地光走一个画面延时表 `_txq`。
- 钩子（都只画，先判 `owns`，其他干员不受影响）：
  - `seg_texas.gd`：`tx_dash_start` 起冲 `tx_dash`；`verb.trail` 余像 `tx_trail`；`_tx_rain_emit` 剑雨落剑清单 `tx_rain`（清单就是原画面那份，`g.vrng`）；次元斩每刀 `tx_cut`、每条刀痕 `tx_scar`；接管时 `_tx_rift_grains`（刀痕沿线的光学碎屑）不撒。
  - 普攻、骤雨、回马剑走 `ob_core.exec_shape` 已有的 `shape` 钩子；剑雨 / 余像·剑雨的判定圈不逐圈画（画面由落剑表现）。
  - `skill_link.gd` pursue 出刀处 `tx_link`（接管时不画 `LFA.texas_cut` 帧条）；`combo.gd` 冲刺斩 `tx_link`（接管时不画通用拖影和光束）。
- 接管时跳过的原画面：拔刀刀光、冲刺剑光帧条、剑雨（`tx_rain` 粒子）、钉剑帧条、次元斩刀痕（`tx_scar` 粒子）和碎屑、通用剑气、连携斩痕。次元斩期间本体隐去和瞬移残影是本体画法，照旧。
- `_cuts`（命中斩痕）加了可选颜色键 `c1 / c2 / c3`，德克萨斯用琥珀；斯卡蒂、星熊不传，照旧蓝色。
- 帧条：`game/art/fx/pxp/pxp_tx_*.png`（253 张）+ `game/data/pxp_texas.json`；效果源 `tools/pixelfx_fx/melee/ak-texas-pp.js`；重新生成 `python tools/pxplane_bake.py --op texas`。`.png.import` 按现有帧条的格式生成（uid 随机，路径 md5 同 Godot 规则）。
- 颜色组 `game/data/fx_pxplane/texas.json`（只给颗粒 / 照地光 / 受击反应）。
- 看图：`tools/pxplane_shots.py --op texas`（OPS 加德克萨斯；`linkcmp` 按干员找连携事件行 `PXPLOG tx tx_link`）；原作一栏 `tools/pxplane_refcol_texas.py`（本机 PIL 拼，不开 Godot）。

## 6. 看图判断（Claude）

- **成了的**：拔刀是一道两头针尖的琥珀刀痕，和斯卡蒂的蓝月牙、星熊的钝头刀痕一眼可分；S1 剑雨的「落下 → 插地 → 刃光沿刃走 → 碎晶」在三档图里读得清，精二收尾巨剑 + 地面剑阵是明显的质变；S3 次元斩是一束细长笔直的直线刀痕交错成团（不是月牙），目标处落大剑；后期剑气是一柄能认出来的飞剑；连携十字斩在实战局里能看到。TRACE 全部逐行一致。
- **还不够的**：
  - 普攻 E0 → E1 的刀痕本身差别只在宽度和碎晶，1 倍下不明显；E1 主要靠钉剑看出变化。
  - 剑雨 E0 / E1 的剑在图鉴演示的远镜头下偏细（剑身 3–4 格），密集怪群里会被白色伤害数字盖住；精二才够醒目。
  - S3 次元斩的直线刀痕琥珀色饱和、条数多（每刀 3–4 条），后期叠上怪群可能偏「乱刃一团」，这是原玩法设计（用户 10-29 要的），没有减条数。
  - 连携镜头那一刻同屏还有队长流明的技能和德克萨斯自己的剑雨，三栏里不算干净。
  - 「跟人走」：拔刀刀痕、旋斩、号令光柱已跟着施放者当前位置（按 15 fps 跳格）；斯卡蒂会话的框架层修复出来后再合一次。
