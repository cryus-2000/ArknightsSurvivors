# 18 · 结局二「最后的骑士」：骑士如何成为同伴，又如何成为最终 Boss（设计稿）

> 2026-09-24。对应原作触发链：狂徒妄念 → 海潮的气息 → 骑士加入 + 第 5 层 Boss 换成最后的骑士 → 骑士仍在 → 骑士骨血 → 若骑士道中阵亡则退行为罗辛南特、结局回退。
> 本作没有"事件"系统，用**事件箱**（一种特殊的补给箱，打开后弹出 2–3 个选项的卡片面板，复用现有选择面板）来承载原作的随机事件。藏品用原作编号：222 海潮的气息、223 退行的罗辛南特、225 骑士骨血。

## 1. 触发链（时间轴）

| 时间 | 原作 | 本作 |
|---|---|---|
| 2:30–3:30 之间（第一个 Boss 前） | 随机事件「狂徒妄念」 | **事件箱「狂徒妄念」**必定刷一次（黑潮圈内、有提示音和方位指示）。选项：**愤怒**（灯火 −40，必得 222）/ **呼号**（掷骰：60% 得 222，失败什么都没有，灯火不扣）/ **离开**（改为普通藏品三选一） |
| 获得 222 的瞬间 | 猎潮的骑士加入 | 骑士骑着罗辛南特从画面外奔来，站到水月身边；横幅「猎潮的骑士 加入了你的旅程」；HUD 援护栏右侧多一个不占 3 个援护位的骑士格（带血条） |
| 道中 | 骑士协助战斗 | 见 §2 同伴行为 |
| 7:00 Boss 后（骑士存活时） | 随机事件「骑士仍在」 | **事件箱「骑士仍在」**：**挣脱**（得 225 骑士骨血：最终 Boss 受到伤害 +80%，水月受到伤害 +80%）/ **沉默**（无事发生，箱子变成普通藏品箱） |
| 道中骑士血量归零 | 退行为罗辛南特 | 骑士倒地（e_knight_death），获得 223 **退行的罗辛南特**（藏品：移速 +10%，作为纪念），结局回退默认；之后精英池里会出现敌对的「最后的骑士」（现在的精英版本），象征他已堕入海嗣 |
| 10:00 最终 Boss | 第 5 层 Boss 换成最后的骑士 | 骑士走到黑潮中心，寒冰重生环（fx_knight_rebirth）后变成 **Boss 最后的骑士**；结局二「最后的骑士」。没有 222 或骑士已阵亡 → 仍是偏执泡影（结局一） |

## 2. 同伴：猎潮的骑士

- 不占援护位；有生命（基础 600，随时间 +50%），会被敌人碰撞与弹幕伤害，**敌人有 30% 概率把他当目标**（分担压力，也制造他阵亡的风险）。
- 行为：跟在水月侧后方；每 4 秒选一个 320 内的目标**冲锋**（e_knight_charge，沿线伤害 45 × 全局倍率，击退，物理），冲到头后**刺击**（e_knight_attack 第 3 帧命中，前方扇形 60 伤害，附带 1.2 秒「冰霜」减速 40%）。冲锋线有紫色预警，不伤水月。
- 受击白闪；血量低于 30% 时自动退到水月身后 6 秒不出手（给玩家一个"护送"的决策：要不要为他绕路）。
- 医疗干员的治疗对骑士也生效（护送的手段）；藏品「骑士戒律·新编」(208) 对他有效。

## 3. 最终 Boss：最后的骑士

- 生命 5200（与伊祖米克同档），法术弱点，移速 60。
- 招式：**冲锋**（直线预警 → 高速突进，沿线 24 伤害 + 冰霜）；**长枪连刺**（近身三段，e_knight_attack，扇形）；**寒冰领域**（每 20 秒以自身为中心 200 半径的减速区 6 秒）。
- **二阶段**：第一次血量归零不死，播放 fx_knight_rebirth，恢复 50% 生命，移速 +20%，冲锋改为连续两次；第二次归零才播放 e_knight_death，胜利。
- 有 225 骨血：Boss 受到伤害 +80%、水月受到伤害 +80%（原作"双方防御 −80%"）。

## 4. 数据与代码落点（按 docs/14 的结构）

- `data/enemies.json`：`knight`（精英，`no_spawn` 默认 true，退行后解锁）、`knight_boss`（role boss，`phases: 2`）。
- `data/relic_effects.json`：222 `on_gain: recruit_knight`；223 stat；225 `rule: bone_blood`（伤害结算处读）。
- `data/waves.json`：`endings.knight = {name, boss: "knight_boss", requires: ["222"], forbids: ["223"]}`；`events`: 狂徒妄念（窗口 150–210 秒）、骑士仍在（420 秒后、需骑士存活）。
- 新模块 `scripts/allies/knight.gd`（同伴行为，模式同 characters/*）；Boss 招式加进 `boss_ai.gd`；事件箱走 `_spawn_chest(kind="event")` + `_show_choices`。
- 美术：V9 已齐（本体 / 移动 / 攻击 / 冲锋 / 倒地 / 重生环 / 命中冰霜）。事件箱可先用现有宝箱贴图 + 不同颜色光柱，之后补一张「海嗣祭坛」图。
