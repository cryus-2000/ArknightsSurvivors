# 109 · 局外成长：调研与方案（设计，2026-10-21）

> 起因：用户 10-12 定「难度改版暂缓，潮位阶梯等局外成长一起做」；10-16 叫停 Ⅷ 校准，原因是「更高难度现在没有奖励」。本文给出局外成长的调研、两套候选与推荐，**只是方案，不改代码**，等用户定。
> 相关：潮位阶梯 docs/71（本文 §5 改它的「只给荣誉」前提）、难度框架 docs/27、难度目标 docs/38 §8.12、原作集成战略 docs/49a（§2.2 分队、§3.8 难度、§3.9 深蓝之树）、机器人 docs/29、测试口径 docs/36 §7.5.1 / §8.2 与 docs/80、云存档 docs/89、局内记录 docs/40、文案 docs/76。

## 0. 一页结论

- **问题**：本作只有局内成长。三档难度通关后只推进 `diff_unlocked`，高难度没有任何回报；docs/71 的潮位阶梯也写的是「只给荣誉」。所以玩家没有理由去打 Ⅳ / Ⅷ，校准也就没有意义。
- **思路**：局外成长的「货币」是**探索评分**（按存活、Boss、结局、通关算分，再乘**潮位系数**）。评分累计提升「深蓝之树」等级，等级和高潮位**首通赏金**解锁**分队**（开局规则，侧向选择，不是纯数值）、外观与图鉴内容。高难度的回报 = 评分倍率 + 只能在高潮位拿到的解锁。
- **保底一项**（用户 10-21 补充，§4.8）：深蓝之树解锁「护盾 / 回复 / 灯火 / 急救」等保底，开局只带一项；护盾 = 层数上限 +1，和护盾藏品相加。潮位 0 按「不带保底」校准，潮位 4 起按「带保底」校准。
- **两套候选**
  - **A 轻量「探索记录」**（约 31 小时）：评分 → 深蓝之树 20 级 → 解锁 10 支分队 + 保底一项 + 外观 / 档案；潮位首通赏金；除保底一项外不加永久数值。现行三档就能上，潮位阶梯上线时只换系数表。
  - **B 完整「深蓝之树」**（A + 约 52 小时，合计约 83 小时）：再加「认知塑造」点数树（可重置的小幅强化，总量有上限、可整组关掉）、分队升级档、跨探索「投资」、新藏品 / 事件分批解锁、每名干员的潮位赏金。
- **推荐 A，和 docs/71 P1 一起做**；B 的认知塑造等 EA 反馈再定。理由：A 让高难度有明确回报，又几乎不改变战力，现有的难度校准（0 / 4 / 8 的 50–70 目标）不用推倒；B 的永久强化会让每一档的胜率随存档进度漂移，校准要多一个维度（§7.3）。
- **要用户定**（§10）：评分倍率与赏金的量级、分队名单、是否保留「全部内容开局可用」、docs/71「只给荣誉」改为「荣誉 + 评分倍率 + 解锁」、B 是否要做。

## 1. 同类作品调研

只记和本作决策有关的做法。原作以外的事实来自各作品的公开机制，没有逐条核对版本号的标「待核」。

### 1.1 对照表

| 作品 | 局外货币 | 买 / 解锁什么 | 难度与回报 | 优点 | 缺点 |
|---|---|---|---|---|---|
| **吸血鬼幸存者**（Vampire Survivors） | 局内拾取的金币带出局外 | **PowerUp**：力量、护甲、生命、回复、冷却、范围、移速、经验、贪婪、诅咒、复活、重抽、跳过、放逐等，每项多级；每买一件，全部 PowerUp 涨价；可全额退款，可单项关闭（待核：关闭开关的版本）。角色、地图、武器、秘术靠成就解锁 | 「诅咒」PowerUp 与超级模式 / 反转模式提高敌人强度，同时提高金币收益 | 每局都有进展，挫败感低；退款让玩家敢试 | 永久数值叠满后前期变得很无聊；难度靠玩家自己加诅咒，默认体验越玩越简单；金币刷取 |
| **土豆兄弟**（Brotato） | 无货币 | 角色靠「用某角色达成 X」解锁；新武器 / 道具随角色通关加入池子 | **危险等级 0–5**，按角色分别记：某角色通关危险 N 解锁该角色的危险 N+1 | 不加永久数值，平衡稳定；角色 × 危险等级给出清楚的长期目标 | 进度纯靠解锁，内容放完就没有目标；一开始池子小 |
| **哈迪斯**（Hades） | 暗晶（Darkness）、冥界钥匙、宝石、泰坦之血、钻石、仙馔 | **夜之镜**：每格两选一（如「死亡挑衅」复活 vs 「暗影之力」），可随时免费重置；钥匙开镜子格和武器；宝石买外观与房间改造；泰坦之血升武器形态 | **惩罚契约（热度）**：自选条目累计热度，通关新热度给一次性「赏金」（按武器分别记），发泰坦之血 / 钻石 / 仙馔 | 两选一 + 免费重置 = 侧向选择；赏金按武器 × 热度记，高难度有一次性大奖励；条目自选 | 资源种类多，教学成本高；镜子满后数值仍偏强，契约要补回来 |
| **雨中冒险 2**（Risk of Rain 2） | 月球币（跨局保留，局内也能捡） | **挑战解锁**：幸存者、技能、新物品（解锁前不进池子）；月球币在局内蔚蓝集市买月球物品 | **日蚀 1–8**：按幸存者分别记，通关 N 解锁该幸存者的 N+1；回报只有荣誉 | 解锁 = 扩充池子，不加数值；挑战引导玩家试新打法 | 物品解锁会让新手池子和老手不同，早期构筑受限；日蚀没有实际回报，很多人不打 |
| **明日方舟 · 集成战略**（以水月为例，docs/49a） | 每局结算的**探索分数** | **深蓝之树**：①生态谱系按分数升级（上限 Lv.170），奖励是游戏外资源；②**认知塑造**：花点数解锁永久增益，包括骰子升级、**分队升级**、新节点；③深蓝记录仪（藏品 / 启示 / 排异 / 结局图鉴）。**分队**（docs/49a §2.2）是开局规则：指挥、集群、后勤、矛头、四个战术分队、研究、高规格等，部分靠认知塑造解锁或升档；藏品要先在局外解锁才进池子（待核：解锁条件） | **波涛迭起 0–18**：逐级叠加；高难度的结算分数有难度加成（待核：系数）；行商「投资」把源石锭存进跨局账户（docs/49a §3.5，上限 999，待核） | 分数制：每局都有进展，难度越高进展越快；分队给出「这次怎么开局」的选择；局外增益大多是机制和资源，不是攻击力 | 本体局外层主要奖励游戏外养成，本作没有对应物；认知塑造节点多，要裁剪 |

### 1.2 结论：本作该借什么

1. **评分制，乘难度系数**（集成战略）。每局都有进展，高难度进展更快，就是「更高难度有奖励」的最直接答案。比「通关才给」友好：机器人「普通」档标准胜率约 7%（docs/71 §7 P3），普通玩家大多数局是死亡收场。
2. **首通赏金按潮位 ×（可选）干员记**（哈迪斯 + 土豆兄弟 / 雨中冒险 2 的按角色记）。docs/71 已经按干员记最高潮位，只差把「荣誉」换成「荣誉 + 一次性评分」。
3. **分队作为主要解锁物**（集成战略 §2.2）。分队是开局规则，改变整局的资源形状，正好填本作「开局只有选干员」的空白，而且是侧向选择，不是纯数值。
4. **永久数值要么不做，要么有上限、可重置、可关**（吸血鬼幸存者的教训 + 哈迪斯镜子的两选一 + 吸血鬼幸存者的退款 / 关闭）。docs/49a §5 已写「局外成长刻意不做永久攻击 +100%」。
5. **不锁已有内容**（雨中冒险 2 的反例）。本作 EA 已经发了 18 名干员、全部藏品开局可用；现在加锁等于把老玩家已有的东西收回去，新玩家开局池子变小，平衡基线（全池子）也要重测。新解锁只放新东西。

## 3. 设计约束（制作人整理，写明作为前提）

1. **高难度要有回报**，而且回报要在下一次探索就感受得到（用户 10-16 的原话是「更高难度现在没有奖励」）。
2. **难度校准的口径不变**：每档参考机器人 50–70%（含超时，按 ≥3 份独立实现的均值判，docs/38 §8.12、docs/36 §8.2）。局外成长不能让这条口径失效。
3. **不收回已有内容**（§1.2 第 5 条）。
4. **同 seed 可复现**（AGENTS.md）：局外状态影响开局时，必须是对局的显式输入，记进 `runs.jsonl` meta；测试缺省是「无局外成长」，现有基线逐局不变。
5. **不设数量硬上限**（用户 10-12）只管局内数量；局外强化的**总量上限**是平衡需要，另说（§7.3）。
6. **文案按 docs/76**：一局 = 一次探索；分队、源石锭、投资等用原作叫法（docs/49a）；效果写「对象 + 数值 + 条件」。

## 4. 方案要素

两套候选由同一组要素拼成，先逐项写清楚。

### 4.1 探索评分（局外货币）

**一局结束时算一次，计入局外累计。** 不算：Boss 演练、练习、图鉴演示、BALANCE 模式和任何带 `--` 参数的测试局（同 `Cfg.save()` 的判定，docs/71 §3）。中途退出不算（防止开局刷）；死亡和超时算。倍速照算。

| 项 | 分 | 说明 |
|---|---|---|
| 存活 | 每分钟 10，最多 100 | 按局内时间 `g.t`，10:00 封顶 |
| 中期 Boss | 每击败一个 20 | 3:30 / 7:00 两个 |
| 通关 | 60 | 击败最终 Boss，四个结局都算 |
| 结局首达 | 每个结局第一次达成 40（一次性） | 以 `endings_cleared` 为准，老存档迁移时补发（§6.3） |
| **× 潮位系数** | 见下 | 乘在以上合计上（结局首达不乘） |

潮位系数（草案，用户定量级）：`1 + 0.15 × 潮位`。

| 潮位 | 0 | 4（现 Ⅳ） | 8（现 Ⅷ） | 12 | 15 |
|---|---|---|---|---|---|
| 系数 | ×1.0 | ×1.6 | ×2.2 | ×2.8 | ×3.25 |
| 通关一局 | 200 | 320 | 440 | 560 | 650 |

- 现行三档时期，档 0 / 1 / 2 按潮位 0 / 4 / 8 取系数。
- 系数只随潮位涨、不随胜负涨：高潮位的失败也比低潮位的失败分多，但潮位要通关上一级才解锁，刷不了。
- 结算显示一行「探索评分 440（基础 200 × 潮位 8 ×2.2）」，第一次显示时附一行说明；不显示复杂明细。

### 4.2 首通赏金（高难度的一次性大奖）

- **账号赏金**：第一次通关潮位 N（任意干员）+ `100 × 潮位系数`。现行三档时期只有 0 / 4 / 8 三份。
- **干员赏金**（只在 B）：某名干员第一次通关潮位 4 / 8 / 12 / 15（4 个台阶，不是每级）各 + 60 / 90 / 120 / 150。18 人 × 4 = 72 份，给长线玩家「每名干员爬一遍」的理由（土豆兄弟 / 雨中冒险 2 的按角色记）。
- 赏金和 docs/71 的潮位徽记同一个判定点（`record_win`），结算「纪录」行下多一行「首通赏金 +260」。

### 4.3 深蓝之树等级（A、B 共用）

- 累计评分（含赏金）→ 等级 1–20。第 n 级需要 `100 + 25n` 分，满级合计 7 250 分。
- **等级不花掉评分**（集成战略生态谱系的做法）：玩家只看到一个只增不减的进度条，云存档合并也最简单（§6.2）。
- 每级给一样东西（§4.4）。界面放在图鉴旁边的新磁贴「深蓝之树」：一条竖向等级尺（复用难度页潮位尺的画法），右边列每级的奖励，已拿到的亮、下一级高亮、更高的压暗但能看内容（同 docs/71「未解锁的级也能翻过去看规则」）。

### 4.4 可解锁的内容

**分队（主要解锁物，A、B 都有）**：开局在选人之后、选潮位之前多一步「选择分队」，缺省「不选分队」（= 今天的开局）。名字用原作分队名（docs/49a §2.2），效果按本作改写；数值是草案，按 §7 的机器人矩阵定。

| 分队 | 效果（玩家看到的文字，docs/76 技术手册体） | 解锁 | 性质 |
|---|---|---|---|
| 后勤分队 | 开局源石锭 +12。第一次在行商处刷新货品免费。 | 深蓝之树 2 级 | 新手开局 |
| 指挥分队 | 队长最大生命 +20%。队友造成的伤害 -10%。 | 4 级 | 容错换输出 |
| 研究分队 | 获得的经验 +15%。开局灯火 -20。 | 6 级 | 前期提速，灯火压力 |
| 突击 / 堡垒 / 远程 / 破坏战术分队 | 招募卡只出现对应两个职业的干员（突击：近卫、先锋；堡垒：重装、辅助；远程：狙击、医疗；破坏：术师、特种）。招募这两类干员时，该干员技力 +10 秒。 | 8 / 10 / 12 / 14 级（各一支） | 引导阵容 |
| 集群分队 | 编队上限 +1。每名队友造成的伤害 -12%。 | **首通潮位 4（现 Ⅳ）** | 高难度专属 |
| 矛头分队 | 队长最大生命 -50%。全队造成的伤害 +15%。 | **首通潮位 8（现 Ⅷ）** | 高难度专属，高手开局 |
| 高规格分队 | 开局从基础藏品中三选一获得一件。行商的藏品价格 +20%。 | 16 级 | 构筑起点 |

- 职业名以本作 `class` 字段为准（近卫 / 先锋 / 重装 / 辅助 / 狙击 / 医疗 / 术师 / 特种）；分组照原作战术分队的配对（docs/49a §2.2「对应两个职业」，具体配对待核原作数据 `rogue_2_band_*`，对不上就按原作改）。
- 「集群」「矛头」只能靠高潮位首通拿到，这是高难度的**专属**回报；其余靠等级，任何难度都能慢慢拿到。
- 一次探索只选一支分队。分队和干员、潮位一起记进 `runs.jsonl` meta 与结算。

| 7 | 干员作战记录页 | 图鉴干员档案多一页：最佳潮位、各结局通关次数、最快通关 |

| 5、11、13、15、17、18、19 | 深蓝之树外观档 | 等级尺换配色 / 海沫粒子，纯装饰 |

- 不改现有功能的可用范围（标题页封面干员、图鉴等照旧），奖励只加东西。
- 「浪静风平」新手档（docs/71 §7 P3，原作简单档）不放进树里：新手档应该开局就能选。

### 4.5 认知塑造（只在 B）

集成战略「认知塑造」的本作版：深蓝之树每升一级给 1 点（满级 20 点），在一张小树上花，**可以随时免费重置**（哈迪斯镜子），**可以整组关掉**（吸血鬼幸存者）。三类节点：

| 类 | 例（草案） | 点数 | 说明 |
|---|---|---|---|
| 分队升级 | 后勤分队 Ⅱ：开局源石锭 +20；矛头分队 Ⅱ：全队伤害 +20%（生命仍 -50%） | 2 / 档，每支分队最多 2 档 | 原作「主题分队可升级 4 档」的裁剪版 |
| 开局资源 | 开局灯火 +10；首次升级多一张候选卡；每次探索一次免费重抽升级卡 | 1–3 | 资源和选择，不直接加攻击 |
| 小幅数值 | 队长最大生命 +5%；拾取范围 +10%；冲刺冷却 -5% | 2 / 项，每项 1 档 | **总量上限**：全部点满时，熟练机器人潮位 4 胜率涨幅 ≤ 8 点（§7.3） |

不做：攻击力 / 伤害的永久加成、复活次数、开局直升精英化。

### 4.6 投资（只在 B）

原作行商「投资」（docs/49a §3.5）的本作版：

- 行商界面多一个「投资」按钮：每次把 10 源石锭存进局外账户（局内这 10 锭就没了）。
- 账户记**历史累计投资额**，只增不减；按累计额给永久的「开局源石锭」：每累计 100 锭，开局 +1，最多 +15（累计 1 500）。
- 这样投资是「本局少买东西，换以后每局开局多一点」的取舍，而且账户不会被花掉，云存档取较大值就行（§6.2）。
- 「最多 +15」是平衡上限，不是数量硬上限的那种规则：它限制的是局外带进局内的源石锭，和「不设硬上限」管的局内购买数量不是一回事。

### 4.7 新内容的分批解锁（只在 B）

只对**以后新加**的内容：新藏品批次、新祭坛事件、新地图（若有）可以挂在深蓝之树等级上（比如「第四批藏品 12 件：深蓝之树 10 级起进池子」）。已有的 264 条藏品、18 名干员、四个结局链**不加锁**。新干员是否加锁见 §10 问题 3。

### 4.8 局外带入的保底能力（「保底一项」，用户 10-21 补充）

> 用户原话：「现在护盾很多时候是没有刷到。我觉得可以在局外成长中加入护盾这种」。

**护盾现状**（`game.gd` `shield` / `shield_max` / `shield_every`，`run/combat.gd shield_block`）：护盾按**层**计，一层抵挡一次伤害（整下伤害全挡，之后 0.5 秒无敌），基础每 12 秒生成一层（`shield_interval`，下限 2 秒）。`shield_max` 基础为 0，只有藏品能给：

| 类 | 藏品（`relic_effects.json`） | 稀有度 / 流派 | 商店 |
|---|---|---|---|
| 给层数 | 199 御2（+1）、118 药枚（+1，间隔 -15%）、7 特级馥郁咖啡豆（+1，间隔 -10%）、16《旧高卢地名源流考》（+2）、200 嵌体甲片（+2，最大生命 -10，间隔 -15%）、193「多功能」发夹（+1）、260 铁卫-高塔（+1，受到的伤害 -25%） | 基础 1、稀有 5、升华 1；流派 H 4 件，其余无流派 | 193、260 不进商店 |
| 依赖护盾才有用 | 15《杜林地上环游记》（间隔 -20%）、191 阿卡胡拉饭碗（补满护盾）、202「国王的护戒」（抵挡时回复 3% 最大生命）、100 皇族金胸针（破裂冲击） | 基础 2、核心 2；流派 H | 都进商店 |

所以「刷不到」有两层：给层数的 7 件里只有 1 件是基础稀有度（出现权重 60 对 26，`progression.relic_pool_ids`）；没拿到层数时，后 4 件抽到也是空卡。

**做法：深蓝之树解锁「保底」选项，开局只能带一项。** 和分队并列，开局在选分队之后多一栏「保底」，缺省「不带」。一次只带一项，是为了让战力增量有上限、能逐项测。

| 保底项 | 效果（玩家看到的文字） | 解锁 | 预估影响（待 §7.2 矩阵实测） |
|---|---|---|---|
| **护盾** | 队长护盾层数上限 +1（每 12 秒生成一层，抵挡一次伤害）。 | 深蓝之树 1 级 | 中：约相当于一件稀有护盾藏品 |
| 回复 | 队长每秒回复 0.6 生命。 | 3 级 | 小：基础回复 1.5、入队台阶每人 +0.9（`squad/regen_per_member`），+0.6 约等于半名队友 |
| 灯火 | 开局灯火 +20；灯油掉落 +10%。 | 5 级 | 小：前期多在「通明」（≥ 70）档 |
| 急救 | 每次探索一次：生命低于 25% 时，立即回复 30% 最大生命。 | 7 级 | 中：只救一次险情 |
| 补给 | 开局获得 1 件「急救包」（行商同款，回复 40% 最大生命，手动使用，按键另定）。 | 9 级 | 中（要新增手动道具，工时另计，可不做） |
| 复活 | 每次探索一次：生命归零时，以 30% 最大生命复活。本次探索的探索评分 ×0.5，不计首通赏金。 | **不建议**；若要做，放 20 级 | 大：机器人死因大多是一次被围（docs/82），一次复活预计 +15 点以上；藏品 228「时光之末」已经是升华级的同类效果 |

- **护盾与现有藏品叠加**：保底护盾就是 `shield_max` 上的一个开局 +1（同 199 御2 的写法），和藏品直接相加；生成间隔仍由藏品缩短。效果是 15 / 191 / 202 / 100 这 4 件从开局起就不是空卡，护盾流派（H）更容易成形。不做「替代」（藏品给了层数就不再给保底那层），否则拿到护盾藏品的那一刻保底等于白选。
- **要跟着改的文案**：118 药枚现在写「队长每 12 秒生成一层护盾」，带保底护盾时读起来像重复；改成「队长护盾层数上限 +1（没有护盾时获得每 12 秒一层的护盾），护盾生成间隔 -15%」，与 7 / 16 / 260 同一写法。
- **对难度的影响**：
  - 标准档（潮位 0）现在是高手机器人 66–70%（停刷后 seed 1–8 66.1%，docs/71 §5.1），已贴近 70 上沿。保底护盾预计再 +4–8 点，可能超过 70。
  - 处理：潮位 0 的目标针对新玩家，**按「不带保底」校准**；保底是给打不过标准档的玩家用的（普通机器人标准档约 7%），对他们的提升才是目的。潮位 4 起按「带最强的一项保底」校准（到这里的玩家都解锁了），即 §7.3 的两层校准，只是对象换成保底项。
  - 用户 9/30 定「标准档不收紧」（高手 55–70）：带保底超过 70 不算违规，因为口径是「不带保底」；如果用户希望带保底也在 70 以内，护盾改为「每 18 秒生成一层」（间隔 ×1.5 只作用于保底这层，要新键，+1 小时）。
- **不想做局外的话**：同一个问题也能在局内解决：「5:00 前没拿到任何给层数的藏品时，下一次藏品三选一必有一件护盾藏品」（局内保底，约 1 小时）。它不涉及存档和局外校准，但只解决「刷不到」，不解决「高难度没回报」。列在 §10 让用户比较。

## 5. 与三档难度、docs/71 潮位阶梯的关系

- **难度轴只有一条：潮位**。局外成长不新增难度选项，它给潮位加回报：评分系数（§4.1）、首通赏金（§4.2）、专属分队（§4.4）。
- **改 docs/71 的一个前提**：docs/71 §1 第 4 条「只给荣誉：通关更高的级不解锁干员、藏品、结局或任何数值」改为「荣誉 + 评分倍率 + 首通赏金 + 两支专属分队；仍不解锁干员、藏品、结局，不给局内数值」。docs/71 的阶梯表、锚点、校准方案都不用动。需要用户确认（§10 问题 1）。
- **上线顺序**
  1. 现在可以先上：docs/71 §4.4 P0（记 `diff_cleared`）+ 本文的评分记账（不显示也行），让老玩家的进度从现在开始累计，正式上线时不用估算。
  2. A 与 docs/71 P1 一起上：难度页换成潮位，结算显示评分与赏金，深蓝之树磁贴、分队选择。
  3. 分队按 §7.2 矩阵定数值后才对外开放（分队第一版可先只开后勤 / 指挥 / 研究三支）。
- **三档时期也能单独上 A**：系数按档 0 / 1 / 2 → 潮位 0 / 4 / 8；赏金只有三份；潮位阶梯上线时把系数表换成 16 级，已发的赏金按 0 / 4 / 8 记、不重发。
- **分队和潮位的交叉**：分队是开局选择，和潮位独立；校准潮位时一律「不选分队」（§7.1），分队另用自己的矩阵测，保证分队的胜率影响在 ±10 点以内（§7.2）。这样潮位的 50–70 目标在「不选分队」下成立，选分队的玩家体验略有起伏，可接受（原作的分队也是这样）。

## 6. 存档与云存档

### 6.1 新存档段 `[meta]`（`settings.cfg`）

只存**事实**，派生的东西（等级、已解锁分队）每次读档时算，不存。

| 键 | 类型 | 说明 | A | B |
|---|---|---|---|---|
| `meta_ver` | int | 1 | ✓ | ✓ |
| `score` | Dictionary | `{设备号: 累计评分}`，见 §6.2；累计评分 = 各设备之和 | ✓ | ✓ |
| `bounty` | Array | 已领的赏金，`"t4"`（账号潮位 4）、`"op:skadi:8"`（干员赏金） | ✓ | ✓ |
| `band` | String | 上次选的分队（"" = 不选） | ✓ | ✓ |
| `kit` | String | 上次带的保底项（"" = 不带），同 `band` 跟着设置合并 | ✓ | ✓ |
| `ending_bonus` | Array | 已发过「结局首达」评分的结局 id（防止和 `endings_cleared` 的迁移重复发） | ✓ | ✓ |
| `boss_beaten` | Array | 正式探索中击败过的 Boss id（Boss 演练开放范围；老存档按 `endings_cleared` 推出对应的最终 Boss，中期 Boss 从下一局起记） | ✓ | ✓ |
| `recent` | Array | 最近 20 次探索的摘要（历次探索列表，约 60 字节一条；不上云） | ✓ | ✓ |
| `invest` | Dictionary | `{设备号: 累计投资额}` | | ✓ |
| `shape` | Dictionary | 认知塑造的分配 `{节点: 档}` + `"t"`（修改时刻）+ `"off"`（整组关掉） | | ✓ |

- 等级 = 按累计评分查表；已解锁分队 = 等级 + `bounty` 里的 `t4` / `t8`。以后改等级表或解锁规则，只改查表，存档不用迁移。
- 「全部解锁」（`Cfg.unlock_all`，调试版 / 对内包）：同现行做法，只在内存放满，`_real_progress` 写回真实值（docs/71 §3）。
- 降级兼容：旧版本读不到 `[meta]` 段就当没有；`save()` 已经是「先读回原文件再逐项覆盖」，旧版本存档时不会删掉 `[meta]`（docs/89 §3.1）。

### 6.2 云存档（docs/89）

- `cloud_body()` 的 `prog` 里加一个 `meta` 对象；`CloudPack.PROG_KEYS` 加 `"meta"`。
- **合并规则全是「取并集 / 取大」**，和现有进度字段一致：
  - `score`、`invest`：按设备号逐项取大，再求和。不能整体取大（网页 A 打了 1 000、网页 B 打了 800，取大会丢 800），也不能整体相加（同一份进度每次同步都会翻倍）。设备号在第一次写 `[meta]` 时生成，存在本地。
  - `bounty`、`ending_bonus`、`boss_beaten`：并集。`recent` 只留本机，不上云（20 条约 1.2 KB，没必要占云端分片）。
  - `band`、`kit`、`shape`：跟着 `set.t` 较新的一份（同设置）；采用后按当前点数校验，超了就整组重置并提示（认知塑造可免费重置，不丢东西）。
- 体积（上云部分）：A 约 300 字节，B 约 700 字节；现在全收集约 3 KB，上限 48 KB，不是问题。
- 桌面版（itch）与网页版存档本来就不互通（docs/89 §1），本文不改。

### 6.3 老存档迁移（`meta_ver` 不存在时，一次性）

老玩家已经打过的局没有评分记录，按已知的事实补一笔「起始评分」，记在本机设备号下：

| 旧事实 | 补发 |
|---|---|
| `diff_unlocked ≥ 1`（通关过标准） | 通关一局的评分 200 + 赏金 t0（100） |
| `diff_unlocked ≥ 2`（通关过 Ⅳ） | 再 + 320 + 赏金 t4（160），**集群分队直接解锁** |
| `diff_cleared ≥ 2`（P0 补丁之后通关过 Ⅷ） | 再 + 440 + 赏金 t8（220），**矛头分队直接解锁**；补丁之前通关的认不出（同 docs/71 §4.3），要再打一次 |
| `endings_cleared` 每个 | 结局首达 40，记进 `ending_bonus` |
| 对内包 / 调试版有 `runs.jsonl` | 按 `meta.result` 与 `meta.diff` 逐局重算评分（更准），代替上面三行 |

满额补发约 1 600 分 ≈ 深蓝之树 7 级；只通关过 Ⅳ 的约 1 100 分 ≈ 5 级。EA 老玩家一进来就有几支分队可选，之前的探索不白打。

## 7. 数值风险与测试口径

### 7.1 不变量（快检里断言）

- **缺省无局外**：所有测试局（任何 `--` 参数）缺省是「不选分队、无认知塑造、无投资」，`check.py --auto` 的同 seed 结果与合入前逐局相同（`trace_base.py` 基线不用重建）。
- 新启动参数：`--band=<id>`、`--kit=<id>`、`--meta=none|full|lvN`（B：`full` = 认知塑造按「推荐分配」点满、投资满 15）；写进 `runs.jsonl` meta 和 BALANCE 行（加 `band`、`kit`、`meta` 字段），`cloud_compare.py` 配对键带上它们。
- 评分公式、等级表、迁移四种老存档、云存档合并（设备号逐项取大）各一条 prot_test / `cloud_save` 回归。

### 7.2 分队矩阵（A、B 都要跑；云端，docs/36 §7.5.1）

- 问题：每支分队相对「不选分队」把胜率挪了多少，有没有一支压倒其余。
- 跑法：`--preset starts`（7 开局）× seed 1–8，**同 seed 配对**；潮位 0 高手 + 潮位 4 熟练 两格；10 支分队（含四个战术分队）+ 基线。合计 11 × 2 × 56 = 1 232 局 ≈ 41 核时，拆 4 个 16 核一次性例行任务约 40 分钟。
- 机器人怎么用分队：分队都是开局规则，机器人照常打；战术分队已经限制招募卡，不用改机器人逻辑；高规格的开局三选一走现有自动选藏品。
- 判定（docs/80）：胜率差 < 10 点不下结论，看配对（负转胜 − 胜转负）+ 低血秒 + Boss 用时。目标：
  - 每支分队对基线的胜率差在 ±10 点内（矛头允许 ±15，它是高风险开局）。
  - 超出时按 ≥3 份独立实现（`--placebos 0,1,2`）复核，确认后只改该分队的数值。
- 结果写回本文 §11。

### 7.2a 保底项矩阵（A、B 都要跑）

- 同 §7.2 的跑法：保底 5 项（不含复活）+ 不带，潮位 0 高手、潮位 0 普通、潮位 4 熟练三格，seed 1–8 同 seed 配对：6 × 3 × 56 = 1 008 局 ≈ 34 核时。
- 多看一个指标：普通机器人标准档的胜率与存活时间（保底的目标用户），以及 `telemetry.blocks`（护盾抵挡次数）。
- 判定：潮位 0 高手带任一保底的涨幅 ≤ 10 点（超了先砍该项数值）；潮位 4 熟练选出涨幅最大的一项，作为潮位 4 起「带保底」校准的配置。

### 7.3 认知塑造的总量（只在 B）

- 风险：点满后每一档都变易，潮位的 50–70 目标对「满成长」的玩家失效；而爬到潮位 8 以上的玩家多半已经点满。
- 做法：**分两层校准**。潮位 0–3 按 `--meta=none`（新玩家）校准；潮位 4 起按 `--meta=full` 校准（到这里的玩家基本点满）。这样每一档对「到这一档的典型玩家」都在 50–70。
- 总量上限：`--meta=full` 对 `--meta=none`，熟练机器人潮位 4、8 各 112 局 × 3 份实现（672 局 ≈ 22 核时）；涨幅均值 ≤ 8 点。超了就砍小幅数值类节点。
- 代价：每改一次认知塑造，潮位 4 以上的校准要在 `full` 下重跑锚点（0 / 4 / 8 共约 336 局）。这是推荐先做 A 的主要原因。

### 7.4 节奏核对（不跑批，按公式估）

按 §4.1–§4.3 和三类玩家（胜率取 docs/38 §8.12 目标附近）估平均每局评分（失败局按平均存活 6–7 分钟、击败 1 个中期 Boss 估）：

## 9. 推荐

**推荐 A，和 docs/71 潮位阶梯 P1 同一轮做；B 的认知塑造与投资等 EA 反馈后再定。**

1. 用户的问题是「高难度没有回报」。A 用评分倍率、首通赏金、两支只能在高潮位拿到的分队直接回答了它，而且每局都有进度。
2. A 的战力变化可控：分队是侧向选择，保底一次只带一项、逐项实测；潮位 0 按「不带保底」的校准继续有效，潮位 4 / 8 在带保底下各重跑一次锚点就能恢复 Ⅷ 校准。B 的永久强化会让「同一档」的胜率随玩家存档而变，校准成本翻倍。
3. 分队补上了本作「开局只有选干员」的空白，是原作集成战略的招牌系统，又是侧向选择，最适合当解锁物。
4. A 的存档只存只增不减的事实，云存档合并规则和现有进度字段同一套，风险低；以后升级到 B 不需要迁移。
5. 顺序建议：①现在先上 docs/71 P0（`diff_cleared`）+ 评分记账（不显示，约 2 小时），老玩家的进度从现在起就算数；②A + docs/71 P1 一起开发（合计约 64 小时）；③分队矩阵跑完再对外开放全部分队，先开后勤 / 指挥 / 研究。
