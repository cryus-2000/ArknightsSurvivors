# 配乐设计与接入（v3，2026-09-26）

全部曲目程序化合成，旋律、和声、riff 原创：
- `game/tools/gen_music.py`：标题、开场引子、商人、结算短乐句与结算循环、Boss 登场 / 击破短乐句（v1.0 起未变）。
  标题曲与结算曲参考的是《海愿》的气质（慢板、留白、钢琴 + 竖琴 + 无词人声 + 弦乐涌浪），不引用其旋律。
  重新生成：`cd game/tools && python gen_music.py [title|shop|stingers|opening|boss_cues|result_loops]`（依赖 ffmpeg）。
- `game/tools/gen_music_battle.py`：**战斗三段、中期 Boss、最终 Boss**（v3：哥特暗黑摇滚 + 电子，乐句式无限循环）。
  重新生成：`cd game/tools && python gen_music_battle.py [battle boss final]`（numpy / scipy / soundfile，不需要 ffmpeg）。

## 版本沿革

- **v1.0**：深海氛围电子，37 秒循环四层。体检（2026-09-26）：80–90% 能量在 120 Hz 以下，手机 / 笔记本外放响度掉 8–10 LU；
  三段同速同调听不出推进；分层几乎常开且不对小节；危险层的心跳和低血心跳音效打架。
- **v2.0**（同日）：用户在 A 深海氛围电子 / B 电子 + 管弦两个 demo 里选 B。三段升调、分层按「强度」驱动并落在小节线上
  （强度规则与标定见下文，v3 沿用）；Master 挂 HardLimiter；预定义 Voice 总线（网页版运行时建的总线接不上输出）。
- **v3**（同日）：用户提出两点——战斗曲参考 mudeth《Machine in the Walls》（《以撒的结合：Antibirth》陵墓层）的风格；
  肉鸽音乐要无限循环。demo C（`Claude outputs/bgm_demo_c_0926`）通过后落地：
  - 风格：只借参考曲可测的风格参数，**不借任何旋律 / riff / 和弦进行**：约 144 BPM、以强力和弦为主（很少强调三音）、
    响段是长音和弦墙（每 1.5–2.5 秒换一个）、鼓偏稀（2 / 4 拍军鼓）、低频与中低频厚重、响段 / 静段交替、声场宽。
    编制：降 D 调双轨失真吉他（硬左右）、贝斯、摇滚鼓（骑镲）、管风琴、合唱、羽管键琴、主奏吉他。
  - 无限循环：从「固定长度循环」改成「8 小节一句的乐句，句尾按局势挑下一句」，同一句不紧挨着重复，顺序永远不会固定重来；
    去掉换段扫频 / 落点冲击这类「预告」音效（新段句首自带的镲就是段落感）。

### 战斗曲的段、句、层

- 段：battle1 D 小调 144 BPM（鼓最轻）/ battle2 E 小调 144 BPM（副歌加底鼓、和弦墙加八分镲、低音八度跳）/
  battle3 升 F 小调 150 BPM（最重：切分底鼓、激战层双踩）。三段都用同一套五句，只是移调、换鼓、换密度。
- 句（每句 8 小节，全部原创）：A 和弦墙（Dm–Dm–B♭–C–Dm–F–E♭–A，激战层主奏吉他长音对位）/ B 标题主旋律副歌 /
  C 灯火动机（平静层管风琴、激战层主奏吉他高八度；最适合平静）/ D 半速间奏（D5 长音 + E♭5 半音压迫、管风琴踏板）/
  E B 主题（激战层主奏 + 下方三度和声）。每句都收在 A（属）上，任何一句后面都接得上任何一句。
- 层：base 平静（贝斯长音、管风琴柔和音栓、合唱「呜」、羽管键琴琶音、管风琴旋律）/ pulse 交战（双轨节奏吉他墙、
  贝斯八分、鼓，句末第 4 拍嗵鼓过门）/ drive 激战（高八度吉他、主奏吉他、管风琴全音栓、合唱「啊」、句首镲、双踩）。
- 每个文件 = 0.1 秒静音预留 + 8 小节正文 + 1.6 秒余音（尾端淡出）。各层增益按「同名轨在五句里拼起来测」统一定，句与句之间音量一致。

## 强度（game.gd `_update_music`）

每帧打分（计时都按局内时间 `t`，暂停 / 选卡时不走，平衡批跑加速时也对）：

| 项 | 分 |
|---|---|
| 800 像素内的敌人数 ÷ 正常密度（55 + 0.25·t），超出 1 的部分 | × 1.0 |
| 场上有精英 | + 0.45 |
| 大群预警 / 到达后 15 秒 | + 1.0 |
| 安全区收缩中 | + 0.45 |
| 近 4 秒净掉血 > 12% 生命上限（当前生命低于 4 秒均值；治疗抵掉的不算） | + 0.5 |
| 威胁等级 ≥ 4 | + 0.15 |

档位：≥ 1.15 且**连续 1.5 秒** → 2 激战（过滤一闪而过的密度尖峰）；≥ 0.35 或开局 20 秒后 → 1 交战；否则 0 平静。
升档马上（sfx 落在下一个小节线），降档要这一档连续 12 秒不够格，之后每 8 秒降一档。
Boss 倒下后 12 秒压回平静层喘口气（除非局面够激战），同时清掉 Boss 前残留的大群计时。
单项里只有大群能独自拉满；精英（在场约一半时间）、缩圈、掉血都要和别的叠上才到激战。
危险层：生命 < 35%（回到 42% 以上才关）、熄灯、在安全区外。技能生效**不再**计入（几乎一直有技能在放）。
`--musiclog` 打印状态切换（`MUSIC`）与每 5 秒一行采样（`MUSICS`：敌人数、300 像素内、精英、大群、缩圈、净掉血、威胁、生命）。

### 标定记录（2026-09-26）

- 第一轮 6 局（高手 / 普通各 3）：800 像素内敌人数中位 30 秒 37、1 分 52、2 分 68、3 分 112、5 分 121、8 分 150；
  事件占比（开局 20 秒后）：精英在场 48–52%、大群 15 秒窗 26–30%、缩圈 20%、净掉血 4–5%。
- 第一版权重（正常密度 46 + 0.2·t、×1.2、门槛 1.0、保持 15 秒）：5 秒采样模拟激战 42%，但实机逐帧判定测出 55%（单局 42–69%）——
  逐帧会抓到采样漏掉的尖峰，再被保持时间拉长。于是加「连续 1.5 秒」、门槛 1.15、正常密度 55 + 0.25·t、保持 12 秒（模拟约 32%）。
- 第二版实机 5 局（`--musiclog` 按状态切换计时）：平静 6% / 交战 61% / 激战 32%（单局 28–41%），
  每局激战 5–10 次、每次中位约 21 秒——激战是一段段的高潮，不再常开。
- 注意：`--balance` 每帧跑 8 步模拟，配乐计时必须按局内时间走（`t` 的差），按帧 delta 走会让大群窗口虚长数倍。

## sfx.gd 约定（v3）

- 两种曲目：`MUSIC`（整首循环：标题 / 开场 / 商人 / 结算循环）与 `SEQ`（乐句式：战斗三段 / Boss / 最终 Boss）。
- 乐句式曲目有两组播放器（每组 = 各层 + 危险层）轮流用：当前句唱到「下一次混音开播时正好到句长」那一帧，
  在另一组里开播下一句，从「那一刻 - 句长」秒开始（先走 0.1 秒预留，正文正好接在上一句末尾）；上一句的余音在原组里响完。
  位置按第一层的 `get_playback_position() + get_time_since_last_mix()`（音频时钟），再加 `get_time_to_next_mix()` 预测开播时刻；
  拿不到播放位置（刚开播、网页版采样播放）时退回墙钟。
- 挑下一句：`SEQ_NEXT` 衔接权重（自己不接自己）× `SEQ_BIAS[强度]`（平静多给 C、激战多给 B / D / E），上上句再 ×0.4 防止来回；
  专用随机数 `music_rng`，不碰对局随机流。平静时一段从 C 句进，其余从 A 句进。
- `play_music(name)` 每帧调用，同名无副作用。切换规则：
  - 战斗换段：当前句唱完、下一句的位置直接接新段的第一句（不另加提示音）。
  - Boss 登场：旧曲 1.5 速淡出，Boss 曲第一句落在 `boss_in` 第 0.75 秒的太鼓重击上。
  - Boss 倒下回战斗：先让 `boss_down` 响 1.2 秒，战斗曲再从第一句 2 秒淡入。
  - 其余：新曲从头 1.25 秒淡入，旧曲 1.7 秒淡出。
- `set_battle(lv, danger)` / `set_final_phase(p2)`：同 v2，进层落在当前句的小节线上（提前 0.1 秒、0.1 秒淡入），危险层可按拍进，
  退层等小节线、2 秒淡出；新开播的一句直接带着当前各层音量。
- `play_overlay(name, gain_db, from)`：两个叠加播放器。Master 总线挂 HardLimiter（-0.5 dB）。

### 验证（2026-09-26）

无界面引擎录音（`AudioEffectRecord` 挂 Music 总线，140 秒走一遍平静 → 交战 → 激战 → 危险 → 换段 → Boss → 回战斗 → 最终 Boss → 二阶段）：
- 句序：battle1 C → A → B → D →（换段）battle3 A → E →（Boss）A → C → D →（回战斗）battle3 C → B →（最终）A → C → D，两组播放器正确轮换。
- 衔接：八个句界前后 0.4 秒内最低电平只比中位低 2–5 dB（没有断音）；相邻两句相对 16 分网格的偏差 1–9 毫秒（不到一个混音块）。
- 注意无界面的哑音频驱动混音速度会比实时慢 5–15%，按墙钟排程在这里会错拍，这正是位置一律按音频时钟算的原因。
