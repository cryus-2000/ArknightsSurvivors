# 配乐设计与接入（v2.0，2026-09-26）

全部曲目程序化合成，旋律、和声原创：
- `game/tools/gen_music.py`：标题、开场引子、商人、结算短乐句与结算循环、Boss 登场 / 击破短乐句（v1.0 起未变）。
  标题曲与结算曲参考的是《海愿》的气质（慢板、留白、钢琴 + 竖琴 + 无词人声 + 弦乐涌浪），不引用其旋律。
  重新生成：`cd game/tools && python gen_music.py [title|shop|stingers|opening|boss_cues|result_loops]`（依赖 ffmpeg）。
- `game/tools/gen_music_battle.py`：**战斗三段、打击乐循环、中期 Boss、最终 Boss、换段提示**（v2.0，方向 B：电子 + 管弦混合）。
  重新生成：`cd game/tools && python gen_music_battle.py [perc battle boss final cues]`（numpy / scipy / soundfile，不需要 ffmpeg；
  `battle` 要先有 `perc`，因为各段的整体增益按打击乐层一起定）。

## v2.0 改了什么（为什么）

2026-09-26 体检（v1.0 战斗曲）：
- 太闷：80–90% 能量在 120 Hz 以下；手机 / 笔记本外放（250 Hz 高通模拟）响度掉 8–10 LU，常态只剩 -31 LUFS，几乎只听得到底鼓。
  灯火将熄的 700 Hz 低通、暂停 / 升级的 1800 Hz 低通对它只差 0.1–0.2 LU，等于失效。
- 三段同速同调同音色，响度 -18.0 / -17.6 / -17.1，听不出推进；37 秒一循环、旋律 18.5 秒一遍。
- 分层几乎不动：pulse 12 秒后常开，drive 挂在「任一技能生效中」上几乎常开，且层的进出不对小节。
- 换段 / 进 Boss 不对拍；危险层（低频心跳）听不见，还和低血心跳音效两套节奏打架。
- Boss 登场响度一下跳 4–9 LU。

用户听过 demo（`Claude outputs/bgm_demo_0926`：现状 / A 深海氛围电子 / B 电子 + 管弦）后选 **B**。v2.0：
- 频谱：激战态 <120 Hz 约 37–41%，外放只掉 2.1–2.7 LU（旧版 10.8）；低音靠泛音在小喇叭上也「听得见」。
- 三段升调推进：D 小调《潮起》→ E 小调《逆流》→ 升 F 小调《灯火长明》（标题曲的调），律动由半速 → 全速 → 史诗。
- 32 小节（61 秒）一循环，四个 8 小节乐段：灯火动机 → 标题主旋律 → B 主题 → 标题主旋律高潮（第一段弦乐翻高八度）。
- 分层由「强度」驱动、落在小节线上；换段带上行扫频 + 落点冲击且对拍；Boss 曲落在登场乐句的太鼓重击上。
- 危险层改成高音颤弓小二度 + 滴答脉冲，不再有心跳（交给音效）。

## 强度（game.gd `_update_music`）

每帧打分（计时都按局内时间 `t`，暂停 / 选卡时不走，平衡批跑加速时也对）：

| 项 | 分 |
|---|---|
| 800 像素内的敌人数 ÷ 正常密度（55 + 0.25·t），超出 1 的部分 | × 1.0 |
| 场上有精英 | + 0.45 |
| 大群预警 / 到达后 15 秒 | + 1.0 |
| 安全区收缩中 | + 0.45 |
| 近 4 秒净掉血 > 12% 生命上限（当前生命低于 4 秒均值；治疗抵掉的不算） | + 0.5 |
| 威胁等级 ≥ 4 | + 0.15 |

档位：≥ 1.15 且**连续 1.5 秒** → 2 激战（过滤一闪而过的密度尖峰）；≥ 0.35 或开局 20 秒后 → 1 交战；否则 0 平静。
升档马上（sfx 落在下一个小节线），降档要这一档连续 12 秒不够格，之后每 8 秒降一档。
Boss 倒下后 12 秒压回平静层喘口气（除非局面够激战），同时清掉 Boss 前残留的大群计时。
单项里只有大群能独自拉满；精英（在场约一半时间）、缩圈、掉血都要和别的叠上才到激战。
危险层：生命 < 35%（回到 42% 以上才关）、熄灯、在安全区外。技能生效**不再**计入（几乎一直有技能在放）。
`--musiclog` 打印状态切换（`MUSIC`）与每 5 秒一行采样（`MUSICS`：敌人数、300 像素内、精英、大群、缩圈、净掉血、威胁、生命）。

### 标定记录（2026-09-26）

- 第一轮 6 局（高手 / 普通各 3）：800 像素内敌人数中位 30 秒 37、1 分 52、2 分 68、3 分 112、5 分 121、8 分 150；
  事件占比（开局 20 秒后）：精英在场 48–52%、大群 15 秒窗 26–30%、缩圈 20%、净掉血 4–5%。
- 第一版权重（正常密度 46 + 0.2·t、×1.2、门槛 1.0、保持 15 秒）：5 秒采样模拟激战 42%，但实机逐帧判定测出 55%（单局 42–69%）——
  逐帧会抓到采样漏掉的尖峰，再被保持时间拉长。于是加「连续 1.5 秒」、门槛 1.15、正常密度 55 + 0.25·t、保持 12 秒（模拟约 32%）。
- 第二版实机 5 局（`--musiclog` 按状态切换计时）：平静 6% / 交战 61% / 激战 32%（单局 28–41%），
  每局激战 5–10 次、每次中位约 21 秒——激战是一段段的高潮，不再常开。
- 注意：`--balance` 每帧跑 8 步模拟，配乐计时必须按局内时间走（`t` 的差），按帧 delta 走会让大群窗口虚长数倍。

## sfx.gd 约定

- `MUSIC` 表定义曲目组（每组若干层，同帧开播）；`TEMPO` 表里的曲目按小节线切分层。
- `play_music(name)` 每帧调用，同名无副作用。切换规则：
  - 战斗换段：等下一个小节线（至少 0.6 秒后），`cue_rise` 按时起、正好收在小节线上，`cue_hit` + 新段第 0 小节同时进，旧段 0.3 秒收掉。
  - Boss 登场：旧曲 1.5 速淡出，Boss 曲落在 `boss_in` 第 0.75 秒的太鼓重击上。
  - Boss 倒下回战斗：先让 `boss_down` 响 1.2 秒，战斗曲再从头 2 秒淡入。
  - 其余：新曲从头 1.25 秒淡入，旧曲 1.7 秒淡出。
- `set_battle(lv, danger)`：lv 0 平静 / 1 交战 / 2 激战；进层在小节线（提前 0.1 秒、0.1 秒淡入，重拍满音量），危险层可按拍进；退层等小节线、2 秒淡出。
- `set_final_phase(p2)`：最终 Boss 二阶段层，落在小节线上。
- `play_overlay(name, gain_db, from)`：两个叠加播放器，换段扫频与 Boss 登场可以同时响。
- Master 总线挂 HardLimiter（-0.5 dB），防音乐峰值 + 大量音效叠加时削顶（网页版采样播放不支持总线效果，无影响）。
