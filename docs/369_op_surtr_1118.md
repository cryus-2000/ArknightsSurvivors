## 2. 本作改编

定位：**近卫 · 主输出（法术重剑，单体斩杀刷新 + 以生命换输出的黄昏）**。直接秒伤预算 100%。

与现有四名近卫的区分：

| 干员 | 核心 | 史尔特尔不做的 |
|---|---|---|
| 艾丽妮 | 直线刺击穿透、浮空控制 | 不刺、不连控 |
| 拉普兰德 | 横扫 + 远处剑气、封印 | 没有远程形态、不封印 |
| 斯卡蒂 | 高频横扫（0.7 s） | 节奏慢（1.0 s），每剑更重 |
| 乌尔比安 | 抡锚、拖拽精英、击杀精英叠攻击 | 不位移敌人；成长来自「击倒回技力」而不是叠层 |
| **史尔特尔** | **法术伤害**（吃敌人法伤易伤 / 打物理高抗），**S1 击倒即刷新**，**S3 以队长生命换输出** | — |

### 2.1 普攻「熔剑」（本作自拟名；原作无普攻名）

- 每 1.0 秒挥大剑横斩最近的敌人一侧：扇形半径 118、半角 1.2 弧度（约 137°），击退 70；**法术伤害**（特性「术战者」，`hit_sources.kind = 法术`：吃艾雅法拉熔蚀 / 逻各斯安魂等法伤增益，打偏执泡影这类物理高抗 Boss 不吃亏）。
- 帧条契约：先借斯卡蒂帧条（占位）；原作 Attack 1.3 s（OnAttack 0.4），出手 ≈ 第 2–3 帧（按 docs/335 出手对时缩放）。

### 2.2 天赋「余烬」（精一）

- 队长受到致命伤害时生命保持 1，4 秒内不会倒下（精二 6 秒）；每 90 秒至多一次。头顶飘「余烬」。
- 本作队友不受击，所以「余烬」保护的是**队长**（她是不是队长都生效）；原作「之后强制退出战场」本作不做（队友不离场）。
- 实现：`op_surtr.gd` 覆盖 `prevent_death`（`squad.prevent_death` 本来就会逐个问干员；积木 `verb.undying` 只能放技能 do，表达不了「致命一击才触发 + 冷却」）。
- 原作另一天赋「熔火」（无视法抗）改成精一普攻（§2.4）。

### 2.3 三技能

| 技能 | 技力 / 时长 | 效果 | 积木 |
|---|---|---|---|
| S1「烈焰魔剑」 | 8 / 瞬发 | 技能动作本身斩出强化的一剑：220% 伤害、范围 ×1.2、击退加大；**这一剑击倒精英或 Boss 时立即回满技力**，只击倒普通敌人时回复 34% 技力（每剑一次） | 技能 `do` 里一个 `shape.cone`（`dur.next_n` + `attack_patch` 只接落点弹 / 弹道 / 手写段普攻，扇形普攻不消耗次数，实测魔剑一次都没出）；回技力在 `op_surtr.gd on_kill`（读 `g.hit.src`） |
| S2「熔核巨影」（精一） | 18 / 15 s | 攻击 ×1.5、挥剑范围 ×1.35；身后熔核巨影每一剑再朝主目标（Boss、精英优先）补一记 90%——原作「仅攻击到一个敌人时 ×1.4」在割草里几乎不会成立，改成「主目标额外吃一记」，单挑 Boss 时效果最接近原作 | `buff_self` + `r_mults` + `trait every_n 1` → `circle center target` |

### 2.4 精英化（docs/91 §0.2）

- **精一 · 普攻「熔火」**：大剑命中的敌人被点燃 2 秒，每秒受到攻击 8% 的法术伤害（可叠，同一敌人约 2 层；`st.burn basis atk`）。原作「无视法抗」在本作敌人身上没有对应的抗性数值（只有个别 Boss 的 `arts_taken`），改成「高温熔化」的档案设定（档案资料二）。画面新元素：被砍中的敌人身上冒小火苗。预算：+8% 左右（§5 实测）。
- **精二 · 普攻质变「巨焰剑」**（新动词：**剑锋尽头爆燃**，不在 docs/91 §0.4 表里；与推进之王直线地裂、安洁莉娜落点场不同，是挥砍弧线末端的一团爆炸）：剑身燃起熔火，每一剑在剑锋前段（约 83 处，半径 46 覆盖 37–129）再爆开一团（60% 法术伤害并点燃）。一眼可认：每一剑尾端都有一团火。

## 3. 积木落地

- 用到的积木：`shape.cone`（`r_mults`、`on_hit`；S1 技能 do 里也是一个 cone）、`trig.every_n`（`delay`）、`trig.on_hit_n`、`trig.on_skill_end`、`shape.circle`（`center: target / front / self`）、`verb.buff_self`、`verb.heal`、`verb.swap_attack`、`verb.summon` + `blocks.summons.giant`（`stay`、`on_expire`）、`st.burn`、`st.stun`、`st.launch`。
- **0 个新积木**；一个独立小脚本 `game/scripts/characters/op_surtr.gd`（继承 `data_operator.gd`，`script` 字段指向它；不进 `op_blocks` 继承链，和令 / 主题重构不冲突），做四处时序：魔剑回技力、余烬不倒、黄昏回满、黄昏流失（docs/61 §6 逃生口口径：只做时序，数值全读 `base`）。

| 需求 | 现状 | 为什么积木不够 |
|---|---|---|
| 「这一剑击倒敌人 → 回技力」 | `trig.on_kill` 不分来源（全队击杀都触发） | 要读击杀那一下的 `g.hit.src`，触发器表里没有 `src` 过滤；以后若有第二人用，再抽成 `trig.on_kill {src}` |
| 「致命一击时不倒 + 冷却」 | `verb.undying` 只在技能持续期 | 需要覆盖 `prevent_death` |
| 「队长生命按时间流失」 | `cost.hp_drain` 📝 未实现 | 一行 `lose_hp`，不值得为一人开积木 |
| 「回满生命」 | `verb.heal` 的 `pct` 校验上限 0.2 | 回满是黄昏的标志，按缺口直接 `combat.heal` |

- 已知妥协：熔火（无视法抗）→ 点燃；S2「目标数 +1 / 单体 ×1.4」→ 主目标补刀；S3 无限持续与生命上限 +5000 不做（§2.3）。
