### 3.2 说明文字（docs/76）

原作第一句多用「为……的您颁发的蚀刻章。」。docs/76 §1 规定全游戏不用「您」、不抒情，所以本作只保留这一句句式，改成「为……的小队颁发的蚀刻章。」，不写第二句背景感悟（X5）。例：

- 骑士归潮：为在「静谧时代」结局后返航的小队颁发的蚀刻章。
- 海中拾遗：为在海中拾回 50 种藏品的小队颁发的蚀刻章。
- 协同晋升：为在一次探索中让 3 名干员同时完成精英二的小队颁发的蚀刻章。

详情里的标签直接用原作叫法：「获得方式」「镀层方式」。

### 3.3 原作名词核对

本文玩家可见的原作名词：蚀刻章、蚀刻章套组、镀层、获得方式、镀层方式（都在 PRTS「光荣之路」页上）；结局名、Boss 名见 docs/76 附录 A.4。「潮位」「认知塑造」是本作已有的叫法。不用「光荣之路」作页名：本作只有蚀刻章这一类，页名仍叫「蚀刻章」（docs/213 P9）。

## 4. 方案 A「浮雕套组板」（贴原作）

示意图：A1 章面、A2 陈列页电脑、A3 手机、A4 获得提示电脑、A5 手机。

- **章面**：深蓝面 + 银色浮雕纹章，左上受光；稀有度看**尺寸 + 框材**——一星 17×19、二星 25×28（多一圈浮雕环）、三星 35×40（铜框、浅色面、深蓝纹样、外圈刻痕），均为美术像素，1280×720 下 1 美术像素 = 3 逻辑像素（同标题页青光航标精度）。镀层：框换成「潮光」青白色，框上 3 个闪点。
- **未获得**：暗色剪影——看得出外形和纹样轮廓，看不出细节，没有光泽。比现在的「空插槽」多给一点「这里差一枚什么」的信息；用户如果仍想要空插槽，A 也能退回空插槽，不影响其他部分。
- **陈列页（电脑）**：左栏套组名「深蓝之下」+ BENEATH THE BLUE + 计数 05 / 12 + 各稀有度计数 + 镀层计数；中间套组板：三星大章在左，二星 6 枚拼成蜂巢，一星 5 枚上下各一簇；右栏详情：放大章、章名、星级、说明、获得方式、进度格、镀层方式、获得日期。返回在右上带 ESC 牌（docs/213 P9）。选中用青色角框（青只给选中，docs/37 §2）。
- **陈列页（手机横屏）**：同一结构；套组名挪到顶行，章按 4 设备像素一格画（@2x），一星章图只有约 34 点宽，点击区按蜂巢格扩到 ≥ 44 点；左侧灵动岛、右侧圆角、底部横条都在安全区线以内。
- **获得提示**：左侧增益行下方，暗带从屏幕左缘展开，章从 1.25 倍分三档压入定格并扫一道光（沿用 docs/62 §3.25「嵌章入槽」的动作），文字「获得蚀刻章 / 章名 / 星级」，约 3 秒后滑出。示意图是第 0.35 秒那一帧。不挡战斗、不暂停（docs/37）。
- **跟现在的关系**：保留 Codex 蜂巢版式的思路（10-25 用户「那是设计」），换掉的是章面画法、章的大小规则（跟稀有度走）和记录栏位置。改动量中等。

## 5. 方案 B「蚀刻档案柜」（便于以后加套组）

示意图：B1 章面、B2 陈列页电脑、B3 手机、B4 获得提示电脑、B5 手机。

- **章面**：银板，纹样刻进去（深色刻槽，右下缘受光，像真的蚀刻）；所有章**同一尺寸** 27×31，稀有度看**框**——一星单框、二星双框、三星铜双框 + 六角铆钉。镀层：板面换成潮光青。比 A 更「蚀刻」，离原作的浮雕观感远一点。
- **未获得**：暗色空板 + 问号，章名灰显，条件照样能看（原作也公开条件）。
- **陈列页（电脑）**：页头「蚀刻章」+ 套组页签（现在只有「深蓝之下 05/12」一个，以后加套组往右排）+ 筛选「全部 / 已获得 / 未获得」；左边 4 × 3 网格按稀有度排序，每格章 + 章名 + 星级；右边详情卡。
- **陈列页（手机横屏）**：同结构，格子放大到 95 点宽；筛选和返回都在顶行。
- **获得提示**：右上（藏品框下方、暂停 / 倍速列左边）一张小卡：章翻正 + 扫光，「获得蚀刻章 / 章名 / 星级」，下面一排 12 格套组进度，新得的一格亮青。示意图是第 0.5 秒那一帧。
- **跟现在的关系**：蜂巢版式撤掉换成网格，等于推翻 10-25 定的版式；以后加「干员」「认知」等新套组时最省事。改动量大于 A。

## 6. 对比

| | A 浮雕套组板 | B 蚀刻档案柜 |
| --- | --- | --- |
| 像不像原作 | 章面、稀有度规则、套组板版式都对得上 | 稀有度和文字结构对得上；章面和版式是本作自己的 |
| 一眼看出稀有度 | 大小 + 框材，明显 | 只看框，小尺寸下二星 / 一星差别小 |
| 未获得 | 剪影（有轮廓） | 空板 + 问号 |
| 扩展新套组 | 每套一块板，要单独排版 | 加一个页签 |
| 手机 | 章大小不一，一星图只有约 34 点宽，点击区要按蜂巢格扩到 44 点 | 格子统一（95 点宽），最好点 |
| 与 10-25「按 Codex 排列」 | 保留蜂巢 | 推翻 |
| 工作量（代码） | 约 1 天 | 约 1.5 天 |

**我的建议：A。** 用户要的是「像原作」，A 在章面和套组板两处都贴原作，又保留了 10-25 定下的蜂巢；B 的「获得提示里带套组进度格」可以单独拿到 A 里用（加一行，不影响别的）。
