# 免打包测试版入口

双击仓库根目录的 `启动测试版.cmd`。入口先让 Godot 导入改动过的素材，再直接运行 `game/` 的当前源码；后续代码、美术或数据更新后，关闭游戏再双击同一个文件即可，不需要重新导出压缩包。需要本机安装 Godot 4.7.2；默认路径为 `E:\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe`，其他安装位置可设置 `GODOT` 环境变量为图形版 Godot 可执行文件的完整路径。

本入口是本机调试运行：难度、图鉴和结局临时全部解锁，Boss 演练可用。游戏读取的是仓库当前工作目录，所以未提交的改动也会立即生效。测试版解锁状态只在内存中，不写入正式进度。启动入口不会改动正式版的构建流程；对外正式版仍通过 `tools/export_build.py` 导出、加密和打包。请勿把源码入口当作对外发布包。

图鉴的敌人、精英、Boss 详情现在从 `enemies.json` 展示第二招或三组 Boss 招式名称；攻击演示继续调用正式 AI。Boss 演示单轮延长至 35 秒，以展示第三组招式，伊莎玛拉自动转化轮播为 50 秒。
