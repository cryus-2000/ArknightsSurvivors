## 2. 实现

- `game/scripts/run/ult_px_ir.gd`：记事件（start / pin / dash / boom / final），画地面层（纹章、裂缝）、上层（光链、斩线、爆、颗粒、收尾斩击）、冲击帧剪影、艾丽妮起手蓄力。不抽随机数，散布全按坐标哈希。
- `ult_moves_c.gd`：`_irv_start / _irv_step / _irv_shuttle / _irv_final_cut` 里，原来画图的地方开关开着时改发 `IRP.ev`。`u.hit / _once / add_cc / _lead_move / cam_hold / vfx.stop / u.impact / PF.hf_on / 音效` 一行没动。
- `ult.gd`：`draw_world_back / draw_world / _draw_hit_frame / _draw_windup` 各加一行转到 `ult_px_ir`，只在开关开着时生效。
- 纹章线稿：`game/art/fx/pxp/pxp_ult_ir_seal.png`（24 KB），由 `python tools/ult_px_irene_bake.py` 从 `fx_irv_seal@2x.png` 烤出。
- 画法 Python 版：`tools/ult_px_irene_art.py`，与 GDScript 一一对应。送审 GIF：`python tools/ult_px_irene_gif.py`。
