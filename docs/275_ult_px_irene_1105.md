### 1.0 崩解 = 怪物身体炸成自身像素粒子（原版效果，主角）

11-05 用户发原版实机截图更正：「我说的崩解是原版那个粒子特效，就是怪物炸开的这个特效」。崩解指的是斩线经过的怪物整只炸成一大片自身颜色的像素粒子，往外喷散。下面 §1.1 的地面碎石和尘墙只是配角。

- 原版来源：原画面在每次连环爆和收尾斩击时，除了引擎击杀碎屑，还放 `PF.particles(… "ult_burst" …)` 粒子团、尘和余震碎石。第一版转平面把这些都关掉了，怪物死时只剩小星爆，所以「崩解」不见了。
- 现在（开关开着时）分两层：
  1. **引擎原有的击杀碎屑**：`optical_particles.kill_burst`，按怪物贴图像素碎开，颜色就是怪物自身。每次连环爆和收尾大爆各补一次；超过 `ult/fx_kill_cap` 被静默的怪也照样碎。
  2. **怪物代表色像素喷散**：取 enemies.json 的 `ecol`，分亮 / 本色 / 暗三阶，头两拍带白芯。每只 22 颗，2 格和 1 格的像素块，沿斩线往外喷（离斩线越近越往法向），有重量、落地、停一下熄灭。
- 节奏：连环爆时每只被宣判的怪各炸一次（1 倍）；收尾大爆起爆那一拍，所有被宣判的怪沿斩线往外再炸一次（1.6 倍，颗数 1.4 倍）。
- 地面碎石从 24 块减到 12 块；尘墙从每侧 14 团减到 8 团，不透明度从 0.9 降到 0.5，不盖住怪物崩解。

### 1.1 地面碎石与尘墙（配角；11-05 用户看第一版：「斩击后的碎石和尘土比原版薄……少了原作那种崩解感」，后来更正为 §1.0 的怪物崩解）

分拍错开，不同时出现：
1. 0–0.12 秒：裂缝爆亮，从中心往两端长出。
2. 0.06 秒起：沿裂缝的地面裂成 **24 块**实心碎石，离中心越远越晚。碎石 5–8 美术像素见方，暗面 + 亮顶边，刚掀起时顶边被斩光照成亮紫。往裂缝外侧上抛，地上留影子。
3. 0.12 秒起：两侧冲起**尘墙**，每侧 14 团、每团 6 块尘，相叠成片。尘块不规则地往上翻卷、边翻边长大，顶边带一点白紫光，颜色是地面暖灰。
4. 约 0.5 秒：碎石落地、弹一下停住，三分之一碎成 3 小块，1.5 秒内淡掉。
5. 0.4–0.8 秒：尘墙塌下、往外摊开、变淡散完。

颗粒封顶：碎石 24 块（docs/270 爆发档一簇 ≤ 25）。尘墙是成片的面，不算颗粒；0.8 秒散完，不糊屏。冲击帧照旧保留。

光：沿用原画面「只留一盏 2 秒慢慢暗下去的光」，颜色改成亮紫；冲击那一下的大灯是共用演出（`ult.impact`），没动。热芯像素（斩线白芯、星爆芯、光链亮节）进光学发光层，每帧至多 240 点。

### 1.2 收尾大爆（11-05 用户看实机录像：「新版本的主要是感觉缺少最后的爆炸的冲击力」）

冲击帧（整屏白 + 黑剪影）不动。这一节加强的是冲击帧之后真正炸开的那一下，时间都是收尾斩击后的游戏秒：
1. **预备**（0–2 拍）：光点从 0.55–0.8 R 往中心吸，判定圈内压暗（0.28 的暗椭圆），留出对比。
2. **爆点**（2 拍起）：实心亮核，三层椭圆，由外到内是亮紫、淡紫、白芯，半径 0.5 R（约判定一半），亮 2 拍。同一拍：
   - 一盏照地灯，半径 240（docs/270 爆发档上限）；
   - 轻震屏 3px / 0.12 秒，走 `ult.shake`，它取正在震的较大者，打击感包同时在震时不叠加；
   - 3 帧顿帧（`vfx.stop(0.05, "ult_blast")`；批跑 / 平衡局不消耗顿帧，TRACE 不受影响）。
3. **冲击环**：压扁的厚环（5 格，白到紫），约 3.5 拍内从 0.5 R 推到判定边缘，先快后慢；环后 6–14 格的地面一闪，到边后 2 拍淡掉。
4. **崩解跟着冲击环**：碎石掀起、尘墙冲起的时刻 = 冲击环推到那一点的时刻（`_shock_at(R, d)`），从中心往外一路起，不再等冲击结束。

## 5. 模板：其余 19 人终结技照这个做

**结构**（每人一套，互不相撞）：
1. `game/scripts/run/ult_px_<id>.gd`：`static on()` 读同一个开关 `ult/px_plane`；`static ev(u, kind, d)` 记事件；`draw_back(u, w)` 画地面层，`draw_front(u, w)` 画上层，`draw_hf(u, w, fg)` 画冲击帧剪影，需要时再加 `draw_windup(u, w, caster, wk)` 画起手蓄力。
2. `ult_moves*.gd` 里这人的招式函数：在原来画图的每个调用（`u.strip / u.shape / PF.particles / PF.dust / PF.cracks / PF.rock / PF.aftershock / u.light / 链节 tiles`）外面套 `if 开关开: 发事件 else: 原画法`。玩法调用（`u.hit / _once / add_cc / _lead_move / cam_hold / vfx.stop / u.impact / PF.hf_on / 音效`）一行不动。
3. `ult.gd` 里四处转发（`draw_world_back / draw_world / _draw_hit_frame / _draw_windup`），每多一个人加一行 `if on(): of(g).draw_*()`，或者改成按施放者 id 查表。
4. 画法先在 Python 里写一遍（`tools/ult_px_<id>_art.py`），出送审 GIF 和原版对新版并排，用户点头后再逐函数移植成 GDScript，两边一一对应。

**像素规矩**（同 docs/246）：1 特效像素 = 1 美术像素，只按 g.PX 整数放大，原点对齐 2 像素格；15 fps 全局节拍；贴地层压扁 0.72。原来的大贴图（纹章、法阵等）用 `tools/ult_px_irene_bake.py` 的办法重采样到美术像素格，压扁，去掉暗填充只留线稿，再按色阶重新上色。

**崩解 = 怪物身体炸成自身像素粒子**（原版效果，所有终结技都要保留并强化，见 §1.0）：被打击的怪物整只炸成自身颜色的像素粒子，沿打击方向往外喷。做法两层：引擎原有的 `optical_particles.kill_burst`（按怪物贴图像素碎开），加上怪物代表色（ecol 三阶 + 白芯）的逐格喷散。主打击时炸一次，收尾大爆同一拍再炸一次、更大。开关开着时，绝不能把原画面里怪物炸开的粒子关掉而不补。

**地面崩解分拍**（配角，减量压暗，不盖住怪物崩解）：主打击之后按拍错开，不同时出现：
| 拍（打击后秒数） | 内容 | 画法 |
|---|---|---|
| 0–0.12 | 裂缝爆亮、从中心往外长出 | 折线 + 短分叉，白 → 本人色 → 0.8 秒后冷成暗灰，2 秒淡掉；冲击帧剪影包含主裂缝 |
| 0.06 起（离中心越远越晚） | 地面块掀起 | `slab()`：5–8 美术像素实心块，暗面 + 亮顶边（刚起时顶边被打击光照成本人色），上抛 + 往裂缝外飞，地上留影子 |
| 0.12 起 | 两侧尘墙冲起 | `plume()`：每侧十几团、每团 6 块尘，沿裂缝铺开相叠成片；边翻卷边长大，顶边带本人色光；地面暖灰 |
| 约 0.5 | 碎石落地 | 弹一下（第二段抛物线约 0.28 倍），三分之一碎成 3 小块，1.5 秒内淡掉 |
| 0.4–0.8 | 尘土塌散 | 尘块下沉、往外摊开、变淡，0.8 秒散完 |

颗粒封顶照 docs/270 爆发档：怪物喷散每只每波 ≤ 25（艾丽妮 22）；地面碎石是配角（艾丽妮 12 块），每次连爆 3 颗以内；尘墙是成片的面，不算颗粒，靠 0.8 秒散完保证不糊屏。照地光只留原画面认可过的那几盏（用户嫌短灯闪）。

**收尾大爆**（见 §1.2，崩解之前必须有）：冲击帧之后先 2 拍预备（光点吸入 + 圈内压暗），再起爆。爆点包括：实心亮核（半径约判定一半，亮 2 拍）、一盏打满的照地灯、轻震 3px / 0.12 秒、3 帧顿帧，以及一圈 3–4 拍推到判定边缘的厚冲击环（环后地面一闪）。崩解（碎石 / 尘墙）按冲击环到达的时刻往外起，不要等冲击结束。

**冲击帧怎么接**：招式照旧先 `PF.hf_on(u, a)` 再 `u.impact(c)`，冲击帧的开关、两拍时长、底色都由 `ult._draw_hit_frame` 管。开关开着时原来标了 `hf` 的图形不会再生成，剪影由 `draw_hf(u, w, fg)` 画：把这一下的主体（主刃 / 主裂缝等）按 fg 纯色重画一遍，第 1 拍黑、第 2 拍白（或招式自定 `hf_cols`）。

**验收**：
1. GCP 上 `tools/ult_rec.py --clips u_<id> --extra="--bal=ult/px_plane=1"` 出实机录像，日志查 SCRIPT ERROR。
2. `--job trace_ab`，`a=ult/px_plane=0`、`b=ult/px_plane=1`，`windowed=1`（要画画面才会走到绘制代码），extra 同 `ult_rec` 的强制放终结技参数，要求逐行一致。
