# 96 · Codex 美术单：普通怪 / 精英怪攻击特效（2026-10-14）

> 用户 10-14：「想要 codex 那里也补画一下怪物的攻击特效」，Codex 自提了优先级表，协调人对照代码里的实际攻击方式核对后定稿如下。
> 通用规格一律按 docs/93 §0（弹体 / 特效：横排帧条、1x + @2x、alpha 只有 0 / 255、弹体与实体件 1px `#080E18` 外描边、有方向的只画朝右、原点写进 manifest）。**敌方配色**按 docs/48：敌方预警 / 弹体用 红、紫、霜青、酸绿；**不用**友方的灯火金 `#F4C04E`、UI 青 `#36E2DC` 高饱和版。
> 本单只交素材，不改 `game/`。每批一个提交，附 `enemy_fx_<批号>_manifest.json`（帧数 / fps / 帧尺寸 / 原点 / 层 / 用途）、handoff、预览 GIF（深色地面底，按游戏比例 1 美术像素 = 2 屏幕像素）。
