# Claude project entrypoint

Read AGENTS.md, docs/00_index.md (document index and per-role read-first list) and docs/06_git_collaboration.md first.

You own game code, integration, testing and builds. Work in your own worktree (.claude/worktrees/<name>); the main checkout E:\ArknightsSurvivors on main is only for the coordinator's merges and releases (docs/41 §3).
Codex art work happens in the separate codex/art worktree. Receive completed art via reviewed commits, not by editing that worktree.
Since 2026-10-17 Codex may also change code on `codex/<topic>` branches per docs/106 §6; the coordinator reviews and merges those like any role-session branch.
The initial main commit already contains the five monster v2 strips and their handoff document in art/incoming/.

All player-facing text must follow docs/76_language_style.md (binding language-style rules and terminology; canon character text only from verifiable sources, PRTS first (docs/76 §4)).
