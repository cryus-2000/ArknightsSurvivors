# 配对对比（docs/80）

配对键：squad + seed + bot + diff + tier + lane + placebo；基准 A = 旧版；bootstrap 2000 次（种子 12345）。

## 配对对比

### 新版 对 旧版（B − A）

配对 28 局；配不上对：只在 A 0 局、只在 B 0 局。

| | 局数 |
|---|---|
| 两边都赢 | 7 |
| 两边都输 | 17 |
| 只 A 赢 | 4 |
| 只 B 赢 | 0 |

配对内胜率：A 39.3% → B 25.0%，差 -14.3 点，配对 bootstrap 95% 区间 [-28.6, -3.6]；McNemar 精确检验 p = 0.125。
