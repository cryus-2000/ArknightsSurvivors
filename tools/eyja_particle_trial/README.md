# 艾雅法拉熔岩弹粒子对照（独立试验）

基线：main `68568644e`。不改变游戏代码、素材、攻击或技能时序；本工具不是正式接入。

运行 `python -X utf8 tools/eyja_particle_trial/run.py --capture --bench`，输出至 `build/eyja_particle_trial_1024/review.html`。通过项目 `godot_runner` 启动静音、无焦点的屏幕外窗口，真实 Compatibility GPU 渲染。需要系统 Python 的 `imageio_ffmpeg`。捕帧时固定 60 fps；测量时不捕帧、不限制 fps。

## 对照范围

- 同一张现有 `optical_fx/fx_eyja_lava_splash@2x.png`，6 帧 / 18 fps，展示尺寸 160×112。
- A：复现 `optical_particles.gd` 中大特效配齐火星 / 余烬 / 烟的 10+10+3 模板；包括首帧最亮饱和色取样算法。生产代码大特效每三次有一次不配余烬和烟，预览固定展示配齐的一次。
- B：同样三个 GPUParticles2D、相同 23 颗、相同寿命；改为分散发射位置、熔渣重力下落与冷却、上升火星和烟灰。两边使用相同固定随机种子。
- 两边只比较通用 GPU 点缀层；未复制游戏完整光学后期、动态照明、技能自身额外 CPU 粒子、熔池或敌人。不要把 A 称作完整当前实战录像。
- 这版没有碰撞、弹跳和落地残留。熔渣只做重力轨迹和熄灭，不把俯视地面坐标冒充真实垂直物理。
- 仅粒子 / 慢放 / 时间轴 / 放大均在预览页，默认原速。

## 性能口径

960×540，Compatibility，关闭垂直同步；1 组与 12 组同时喷发，每档按 A/B/B/A 顺序运行。每次预热 2 秒、采样 6 秒；记录墙钟帧间隔的均值、P95、P99。同一硬件、同一背景与主体条；粒子数和节点数相同。

该测量包括引擎 / 提交 / 调度等待，不是纯 GPU 计时；机器存在其他会话负载，两次范围用于显示波动。独立空场景不代表整局帧率，也不能外推到 WebGL 或手机。若用户认可方向，下一步再接入一个实际技能、用整局录制和网页端性能核对。

运行器断言素材尺寸、无脚本错误、视频帧数和 PERF 输出；不需要为这一隔离视觉试验运行整套游戏回归。最终用户手感验收尚待确认。

## 2026-10-24 本机试验结果

RTX 4060 Laptop GPU，最终取色对齐版本；每格是两次运行的范围：

| 喷发组数 | 方案 | 平均帧间隔 | P95 |
|---|---|---|---|
| 1 | A | 1.08–1.24 ms | 1.93–2.28 ms |
| 1 | B | 1.12–1.27 ms | 2.03–2.75 ms |
| 12 | A | 1.49–1.61 ms | 2.51–2.73 ms |
| 12 | B | 1.40–1.44 ms | 2.42–2.62 ms |

两档没有一致的开销上升趋势，不能据此声称 B 更快；暂未发现该隔离场景中明显的额外帧耗时。没有做网页端、手机或完整实战测试。

两段 GPU 渲染录像各 150 帧，已检查主体爆发与尾段静帧。Python / 页面 JS 语法及视频文件检查通过。浏览器工具拒绝 `file://` 协议，因此未自动打开或验收页面交互，交付本地链接供用户打开；没有通过另开服务绕过限制。

## 第二批：三组材质运动对照

`python -X utf8 tools/eyja_particle_trial/batch.py` 顺序渲染并测量拉普兰德、歌蕾蒂娅、水月；总入口为输出目录的 `index.html`，艾雅法拉原预览保留。每组有完整主体 / 仅粒子两个视图，各 150 帧，播放、半速、逐帧和放大沿用第一版。

| 对照 | 沿用主体 | 新版粒子运动 |
|---|---|---|
| 拉普兰德剑气 | `fx_lappland_slash`，4 帧 / 10 fps | 预生成弧面发射点，朝挥砍方向飞散，逐渐变暗 |
| 歌蕾蒂娅水龙卷 | `fx_gladiia_tornado_loop`，6 帧 / 12 fps，示范循环 1.3 秒 | 椭圆边缘发射，切向加速度带出卷动，弱向心加速度收束 |
| 水月水母刺击 | `fx_mizuki_jelly_sting`，5 帧 / 18 fps | 周围发射，向心聚拢并轻微上浮、盘旋；柔和亮起后收暗 |

每组左右使用同一主体、相同粒子种子、三个 GPU 发射器与 23 颗上限。歌蕾蒂娅两边都用连续发射、同一结束时间，其余用一次喷发；歌蕾蒂娅的 A 是通用运动模板的连续发射对照，并不是完整原游戏技能逐像素复刻。新的空间发射点只在初始化生成，不逐帧由 CPU 更新颗粒。所有试验仍不接入正式游戏，不改变素材。

第二批每组测 12 组同时播放，A/B/B/A；结果在各子目录 `perf.json` 和预览表格中。第一批的单组数据不冒充其他三个技能的数据。网页 / 手机 / 实战验证仍未进行。

第二批已完成六段 GPU 录像、三组各四次测量；无脚本或解析错误。主体与仅粒子关键帧已检查，页面 JavaScript 语法与输出文件检查通过。平均帧间隔范围：拉普兰德 A 1.44–1.85 / B 1.39–1.62 ms；歌蕾蒂娅 A 1.60–2.07 / B 1.55–1.57 ms；水月 A 1.06–1.49 / B 1.15–1.18 ms。存在机器负载波动，不据此声称试验版更快。未自动验证浏览器交互。
