# 参考：官方「水月与深蓝之树」宣传 PV 怎么剪的（11-08 拉片）

来源：B站 明日方舟官方 BV1eW4y1v7ak（1:52，BGM《海愿》PV 版）。在浏览器里逐帧取画面（0.5 秒一格联络表 + 切点精确到 1/30 秒）、页面内解码音轨量鼓点；没有下载视频。

## 结构（片中秒）

| 段 | 时间 | 音乐 | 画面 |
|---|---|---|---|
| 片头 | 0–9 | 静音 | 鹰角 / 方舟标志 |
| 快剪段 | 9–60 | 整曲一直响，约 158 BPM，响度稳定 | 大字卡与画面交替：一个词一张卡（问题 / 人类 / 海浪 / 羽兽 / 狂风 / 海底），下一镜就是这个词说的东西 |
| 急停 | 60–65 | **硬切静音约 1 秒**，两记单音，再静 | 全黑，只有一点光 |
| 慢段 | 65–87 | 小声铺底 | 长镜头 2–9 秒一镜，暗、慢推 |
| 高潮 | 87–98 | 回到满编 | 全片唯一的亮色段，角色 / 大场面 |
| 收尾 | 98–112 | 淡出 | 标题 |

## 剪法要点

1. **音乐一整首不拼**。只有一次「故意的急停」（60 秒），之后同一首歌接着走，所以听起来是设计过的断，不是接缝。
2. **切点落在拍上**：快剪段 31 刀，约一半落在拍点 ±0.04 秒内，其余落在半拍。镜头长度大多是 2 / 4 / 6 拍（半小节 / 一小节 / 一个半小节），1 拍的闪切只出现在转场。
3. **大字卡是主干**（术曲 PV 排版）：单个词、竖排或居中、灰色纸纹 / 水墨底，一张约 1–1.5 秒，和下一镜画面成对出现；不是底部字幕条。
4. **故障转场**：电视雪花 / 横向扫描线闪 2–3 帧（10.0、17.5、22.5、37.0、47.5、87.5 秒），换场景都靠它。
5. **色调统一**：快剪段整体灰蓝去饱和，亮色和高饱和只留给高潮段。
6. **快—停—慢—爆**：快剪 50 秒后接急停和 20 秒慢段，再进高潮；对比让高潮更响。

## 对照我们 11-08 粗剪的问题

- 配乐 10 段拼接（9 处接缝）→ 听着不连贯。
- 镜头长度跟拼接段走，0.4–4 秒乱跳，没按拍子单位。
- 文字只有 4 条底部字幕条，没有大字卡的节奏主干。
- 素材颜色各段不一（金色灯标、红雾、紫色 Boss 弹幕挨着切），没有统一调色。
- 没有「急停 + 慢段」，从头到尾一样满，高潮不突出。

# 参考二：同人桌游「回声行动」宣传 PV 的开头（11-08 拉片）

来源：B站 明日方舟官方 BV1mZ4y1U7iX（1:27）。同样只在浏览器里逐帧看，没有下载。

| 时间 | 画面 |
|---|---|
| 0–8 | 联名标志 |
| 9–14 | 黑场里金色卡片在 3D 空间翻飞落下：浅景深（近处卡片虚化）、左上一盏暖光、空气里有尘埃光斑；画面中央一行很小的白字旁白 |
| 14–19 | 插画慢推 |
| 19.5–21 | 低机位贴着桌面：一排卡牌立在桌上，再一张张翻起掠过镜头 |
| 21–24 | 暗灰骰子在雾里滚过，焦点从前景移到骰子 |
| 25–28 | 俯拍发光网格棋盘、金色奖杯 / 底座在暗场里旋转 |
| 29–40 | 卡面插画做成倾斜的实体卡，镜头沿卡面平移，卡与卡之间有厚度和投影 |
| 40–45 | 俯拍整张桌面（卡、棋盘、配件） |
| 55–66 | 主视觉 + 标题 |
| 68– | 数字版玩法界面 |

**「3D 感」是怎么来的**：把游戏里的东西（卡、骰子、棋盘）当成有厚度的实物，放进暗场里打一盏光；镜头慢移，浅景深，尘埃颗粒，金边高光。节奏慢，一镜 1.5–3 秒，旁白小字压在画面中央。

**能怎么借到我们的 PV**：我们的卡（招募卡 / 升级卡 / 藏品）、灯火、干员像素帧都是现成贴图，可以在 Godot 3D 里当成有厚度的实体卡片：暗海雾里漂浮翻转、灯火作光源、浅景深 + 尘埃 / 海雪颗粒，镜头最后穿进一张卡切到实机。配乐 battle2 第 70–76 小节正好是 drop 前的断（只剩底层 + 74 一记重拍），约 11.5 秒，放这段 3D 开头，77 小节接现在的终结技钩子。

# 参考三：鹰角 PV 风格规范（11-08，pv-style 会话）

完整规范在 `docs/327_pv_style_guide_1108.md`，字卡样张脚本 `tools/promo/pv_style_typecard.py`。又拉了 6 支官方 PV（破碎日冕概念 PV、傀影、萨卡兹·二、七周年、塔露拉前瞻，加上本页的水月），要点：

- **暗**：故事段平均亮度 0.12–0.22，六到七成像素低于 0.15；亮只在高潮和白闪里，每次 ≤ 1–2 秒。看着亮的片也是灰白高调 + 一个强调色。
- **一个强调色**：平均饱和度 0.05–0.09；本作只用水月青 #5EE6E6，Boss 红只给最终 Boss。
- **遮幅**：故事段 2.39:1（傀影、水月），信息段 16:9。本作 3D 开头 / 急停用遮幅，实机全幅。
- **每镜一个焦点**：暗场一点光、逆光剪影、微距物件；运镜只有慢推 / 慢移 / 漂浮。
- **转场**：默认硬切；白闪全片 ≤ 3 次；故障闪切每次 2–3 帧；急停一次。
- **切点**：场景切换、白闪、急停、标题都踩小节线 / 重拍，快剪内部按 1 / 2 拍（萨卡兹·二快段中位镜长 0.59 秒，一半刀落在起音 ±0.08 秒）。
- **标题只在最后出一次**（傀影 112/117 秒、水月 100/112 秒、萨卡兹·二 61/63 秒）。
- **字**：故事段只用细衬线 + 极小宽字距英文；黑体只给信息卡。量出来（1080p）：水月大字卡主字 150–200 px、注释约 36 px、英文微标签 12–16 px；塔露拉中英双行字幕中文约 40 px / 英文约 30 px；水月结尾卡中文标题约 46 px、MIZUKI 约 100 px。
- **替代字体**（都是 SIL OFL 1.1）：Noto Serif SC（思源宋体同源）、Noto Sans SC（思源黑体同源）、Montserrat。仓库 game/fonts 里是子集，成片用本机 `C:/Windows/Fonts/NotoSerifSC-VF.ttf` / `NotoSansSC-VF.ttf` 全字库。
- **本作字号**：标题 Noto Serif SC 600 / 132 px / 字距 0.12 em；副标题 400 / 48 px / 0.32 em；英文标题 Montserrat Bold 30 px / 0.42 em；名字条中文 Serif 700 / 96 px + 英文底纹 Montserrat Bold 170 px（只比底色亮一档）；角落标名 Sans 700 / 32 px；字幕 Sans 500 / 36 px；英文微标签 Montserrat 13–15 px / 0.32–0.4 em。逐级表见 docs/327 §4.3。
