# PV 1108（60 秒主版 + 15 秒竖版）

成片放主仓库 `Claude outputs/pv_1108/`（不进 git）：
- `PV_1108_主版_60秒_1080p60.mp4`：1920×1080 60 帧
- `PV_1108_竖版_15秒_1080x1920.mp4`
- `PV_1108_主版_手机.mp4` / `PV_1108_竖版_手机.mp4`：手机看的压缩版（< 30 MB）

## 流程

1. 录：`python tools/gcp_render.py --branch <提交> --job custom --split --name <名> --hours 3 --git-mb 0 --cmd 'bash tools/gcp/render_jobs/pv_rec.sh <局>' …`
   - 局的参数在 `pv_runs.py`（RUNS / DEMOS），监视录帧在 `pv_rec.gd`（时间窗 / 按帧窗、强制充满终结技、刷包围圈 / 精英、直接开指挥圆盘、Boss 残血充能、音效记录）。
   - 1080p60、`--realtime`（`--rtfrom` 之前快进）、`--quality=high`、Dummy 音频；每段编成 CRF 15 的 mp4 + `.sfx.json`（这段里真正放出的音效，渲染帧号对段内帧号）。
   - 项目 CPU 配额同时只够 8 台 c2d-highcpu-8，外网 IP 每区 8 个；多出来的排队，偶尔开机失败（IN_USE_ADDRESSES），重发即可。
2. 看：`review.py <局>`（每段联络表 + 日志事件）、`strip.py <mp4> <起始帧> [张数] [间隔]`（细看一段）。素材目录用环境变量 `PV_CLIPS` 指定（11-08 E 盘满，素材放在 C 盘）。
3. 剪：改 `edit.json`（`edset.py main <id> key=值` 改一项），`python tools/promo/pv.py main|vert [输出]`；`--preview 秒,秒` 出预览拼图；`pv.py small <输入> <输出> <MB>` 出手机压缩版。
   - 配乐 `music.py`：游戏内 battle2（Suno 分层，145.99 BPM）三层相加，按小节线拼段；指挥圆盘那镜加低通。
   - 卡片 `cards.py`（登场卡 / 字幕条 / 标题卡），排版元素 `fx.py`（沿用 11-02 小样）。登场卡只用本作像素待机帧。
   - 音效：只混 Sfx.trace 的音效，干员语音（voice:）不进（无人声 PV）。
