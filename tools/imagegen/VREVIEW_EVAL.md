# 视觉预审验证（10-30，claude/vreview）

验证集（`vreview_eval.py`）：
- 负例 5 段特效录像，都是用户挑过毛病的：能天使「变光束」、凯尔希「太快突然就炸」、浊心斯卡蒂「力量感不够、爆炸像小素材拼接」、乌尔比安裂地 v1、乌尔比安放射版「像大海星」。
- 合成坏图 2 张：选卡截图贴入 `control_dur` 并放大一张卡的说明；同屏干员把第 3 人放大 1.35 倍、第 5 人抬高。
- 好图 2 组：修复后选卡 4 张、原样同屏干员。
- 分歧 2 段，**不计准确率**：乌尔比安裂地 v3（用户说「做的挺好的」）、德克萨斯剑雨（用户那轮没提意见）。用户 10-30 指出人的认可不一定准，这两段只记录模型怎么判。
- 选卡修复前的真截图（56ad8c0f2~1）在 1280×720 下看不出用户当时说的问题，所以用了合成坏图。

新口径（用户 10-30：同一贴图变角度 / 长短 / 翻转 / 截段 / 时刻复用不算拼接，只有一模一样等距成串、看得出接缝才算）重跑结果：
- 准确：用户挑过毛病的 5/5 判先改，合成坏图 2/2，好图 2/2 无误报，可计分的 9/9。
- 裂地 v3 仍判先改，但理由已经不是裂缝：「地面由大量完全相同的蓝色冰晶素材以固定间距排列」（2.6–4.4 秒）。这指的是每圈等距排开的喷发冰晶（`fx_ult_ulpianus_burst_front`，每圈按周长 / 140 等分），按新口径确实算「一模一样等距成串」。要不要改（错开间距、混变体），交用户 / 乌尔比安会话定。
- 德克萨斯剑雨不再报拼接，改报「连成一片」（1.8–3.4 秒中心剑影叠成一片），仍列分歧。

旧结论：
- 缺省用 Flash · low · 3 次表决：用户挑过的毛病全部判「先改」，界面 / 同屏类全对，单次约 0.007 美元。代价是偏严：同一素材按不同角度 / 长短复用（裂地 v3、剑雨）会被报拼接感。是否算毛病，等用户给口径；没给之前，会话按技能规矩判断是不是误报，并写明理由。
- medium 档更「宽」：分歧段放过了，但会漏掉真毛病，且花费贵 7–30 倍，不选。
- 「发白」交给本地探针（逐秒近白像素占比），模型几乎不报。
- 第一轮口径（调之前）把卡面的英文装饰小标签（OPERATOR、LEVEL UP）当成键名外露，也把剑雨缺地裂当成力量感不足；已在检查单里写明排除。验证集同时被用来调口径，有过拟合的可能，新素材上的准确率要边用边记。
- 验证总花费约 1.45 美元，其中两轮 medium 约 0.83。
