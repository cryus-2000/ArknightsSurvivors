# 干员语音素材交接

语言：普通话（简体中文）。每位当前编队干员提供部署语音、三条作战技能语音和一条额外战斗台词；另外提供 W 的短笑声。源长音轨和临时解码工具不随项目提交，项目中只保留这 66 个剪辑文件与 `voice_manifest.json`。

## 事件映射

| 文件后缀 | 原语音索引 | 建议接入事件 |
|---|---|---|
| `_entry.wav` | `CN_023`，部署 1 | 干员首次加入本局时播放一次 |
| `_skill_1.wav` | `CN_025`，作战中 1 | 干员第 1 个技能释放时 |
| `_skill_2.wav` | `CN_026`，作战中 2 | 干员第 2 个技能释放时 |
| `_skill_3.wav` | `CN_027`，作战中 3 | 干员第 3 个技能释放时 |
| `_battle.wav` | `CN_028`，作战中 4 | 低频率战斗语气；建议每名干员至少间隔 30 秒 |
| `wisadel_w_laugh.wav` | W（`char_113_cqbw`）`CN_028` | 维什戴尔专属的低频笑声事件 |

`voice_manifest.json` 记录每段的源干员、索引、原音轨区间、剪辑时长和 SHA-256。所有成品均为单声道 44.1 kHz、16-bit PCM WAV。

## 接入建议

由游戏代码单独建立 `Voice` 音频总线和语音音量；技能语音从 `Character.spend_sp()` 触发。部署时逐个排队，避免编队内多名干员同帧播报。战斗台词与 W 笑声加较长限流，优先级低于技能语音；语音资源缺失时静默跳过，不回退到战斗音效。标题页致谢需要补充原作语音素材说明，并保留非官方、非商业同人声明。
