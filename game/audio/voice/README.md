# 干员语音素材交接

语言：普通话（简体中文）。每位当前编队干员提供部署语音、三条作战技能语音和一条额外战斗台词；另外提供 W 的短笑声。源长音轨和临时解码工具不随项目提交，项目中只保留这些剪辑（2026-10-12 第五批后共 91 条：18 名干员 × 5 + W 笑声）与 `voice_manifest.json`：`masters/` 里是 WAV 母带，游戏播放同名的 OGG（见下方「格式与新语音交付」）。

## 事件映射

| 文件后缀 | 原语音索引 | 建议接入事件 |
|---|---|---|
| `_entry.ogg` | `CN_023`，部署 1 | 干员首次加入本局时播放一次 |
| `_skill_1.ogg` | `CN_025`，作战中 1 | 干员第 1 个技能释放时 |
| `_skill_2.ogg` | `CN_026`，作战中 2 | 干员第 2 个技能释放时 |
| `_skill_3.ogg` | `CN_027`，作战中 3 | 干员第 3 个技能释放时 |
| `_battle.ogg` | `CN_028`，作战中 4 | 低频率战斗语气；建议每名干员至少间隔 30 秒 |
| `wisadel_w_laugh.ogg` | W（`char_113_cqbw`）`CN_028` | 维什戴尔专属的低频笑声事件 |

`voice_manifest.json` 记录每段的源干员、索引、原音轨区间、剪辑时长、母带的 SHA-256，以及 OGG 的编码档位 `ogg_quality`。母带均为单声道 44.1 kHz、16-bit PCM WAV。

## 格式与新语音交付

游戏读 `audio/voice/<干员>_<事件>.ogg`（OGG Vorbis 单声道 44.1 kHz，`game/scripts/sfx.gd`）。WAV 母带放在 `masters/`，目录里有 `.gdignore`，Godot 不导入也不导出它们。2026-09-26 起从 WAV（导入时压成 QOA）改为 OGG，网页包里语音从 2.37 MB 降到 1.66 MB。每条的档位是逐条选的：取测得不比原来的 QOA 版本差的最小档位，详见 `game/tools/voice_ogg.py` 文件头。

交付新语音：照旧把 `<干员>_<事件>.wav` 放进本目录，并在清单里登记（`file` 写 `.wav`，附 `sha256`），然后运行 `cd game/tools && python voice_ogg.py`。脚本会把 WAV 挪进 `masters/`、生成 OGG，并更新清单；新语音默认用 0.3 档。核心契约测试（`tests/test_core.gd`）会检查清单里每条都有能加载的 OGG，并且本目录里没有遗留的 WAV（游戏不读 WAV，留下的会被静默跳过）。

## 接入建议

由游戏代码单独建立 `Voice` 音频总线和语音音量；技能语音从 `Character.spend_sp()` 触发。部署时逐个排队，避免编队内多名干员同帧播报。战斗台词与 W 笑声加较长限流，优先级低于技能语音；语音资源缺失时静默跳过，不回退到战斗音效。标题页致谢需要补充原作语音素材说明，并保留非官方、非商业同人声明。

### 现行播放规则（`game/scripts/sfx.gd` 干员语音段）

- 同一时刻只播一条；两条之间全队至少隔 `VOICE_GAP`（3 秒），同一名干员至少隔 `VOICE_OP_GAP`（15 秒），每句另有冷却 `VOICE_CD`。占线时部署语音排队，其余直接放弃。
- 不打断正在播的语音（用户 2026-09-26）。**例外（用户 2026-10-12「语音用1」，方案 A）**：技能语音（skill_1/2/3）可以打断正在说的战斗台词（battle、W 笑声）：台词 0.1 秒淡出，技能语音立即开播，全队间隔从打断时刻起算。部署语音与技能语音之间仍互不打断，战斗台词不打断任何语音；台词播完后的静默间隔里技能语音照旧放弃。核心契约测试 `test_voice_interrupt` 覆盖这几条。
