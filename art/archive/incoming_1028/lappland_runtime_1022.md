# 拉普兰德动作与新版特效接续（2026-10-22）

分支：`codex/rhythm-runtime`。本次基于 `44de7d09`（全员攻击节奏接入），未合 main。

## 核对与修正

- 交付版 `fx_lappland_slash`、`proj_lappland_sword` 的 1x / @2x 四个文件与 `lappland_gladiia_delivery_1021/effects` SHA256 全部一致；沿用已确认美术，不重画。六处封印配置均为敌人头顶灰叉，无封印脉冲。
- 剑气原来按全局时间循环四帧，导致飞行中反复消散。八处基础 / 技能 / 成长剑气统一为本地起飞帧 → 飞行保持帧 → 射程结束的独立两帧消散；伤害实体仍在原射程结束时移除。
- 剑气及末端消散改到前景层，避免被人物遮住；取消保持阶段的提前透明度衰减，避免先消失再出现。
- S3 原 1.333 秒身体循环与实际每 0.6 秒的三道剑气不对应。改由实际发射事件驱动同一 `throw` 条，身体出手帧对齐该事件；按原帧权重收势、准备下一轮。起手期间首轮不覆盖启动动作，下一轮开始接身体。
- 视觉朝向使用该轮剑气方向，不改逻辑 face。普攻不会重置事件时钟；移动使用连续且随速度变化的 run_ph；另一技能、技能结束或离场清理事件。

## 不变的玩法

普攻周期 0.8 秒、出手 0.1785714286 秒；S3 间隔 0.6 秒。倍率、范围、弹速、击退、技能持续时间、命中目标和三道共享命中表均不改。新参数只作用于画面，未调用玩法 RNG。
