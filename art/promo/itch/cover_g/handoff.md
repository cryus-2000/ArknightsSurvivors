## 后期（build_cover_g.py）
1. 按目标比例裁切（焦点见脚本 PLANS），LANCZOS 缩到成品尺寸。
2. 补光：自动找灯火（暖色最亮团）；大范围用乘法小幅提暖（不洗掉水月淡紫发 / 凯尔希绿裙的设定色），灯芯加一小团加法亮核；灯下椭圆地面光池；S 曲线对比 +18%；四角暗角 + 底边压黑；标题区上方压暗一条；暗部往 #0a1630 偏冷。
3. 像素化：BOX 缩到一半（1 像素格 = 2×2），MAXCOVERAGE 收 96 色、无抖动，最近邻放回。（中位切分 64 色会把淡紫 / 绿并进米白，已弃用。）
4. 标题：标题页 `game/art/ui/title_deep/logo_mark.png`（灯塔徽记 + 方舟幸存者，2 像素格）原格叠在原生分辨率，字面上白下青两段、深蓝描边 + 下投影 + 两级青色外光；下方金色 `ARKNIGHTS SURVIVORS`（Montserrat Bold 二值化）。没有原作 logo 或鹰角标识。
5. 缩略：成品 BOX 缩到 315 宽。
