## 规则（每次必须遵守）

1. 只改本单列出的文件；不改 `game/` 代码，不改 `fx_*` / UI / 地形。不读 docs/ 其他文档、不看 game/ 代码、不跑游戏。
2. 标「请用户确认」的不改；本单写「用户已批」的才算确认。
3. **规格**：
   - 横向等宽帧条、朝右、透明背景、二值 alpha（只有 0 / 255）。
   - **单帧尺寸 = 该 Boss 现有本体 `e_*` 的单帧尺寸**（下表逐项写明），不要自己加高加宽。
   - 1× 与 @2x 都交：@2x 宽高正好 2 倍、同一画面、像素密度加倍。
   - **描边以现有 `e_*` 为准：1× 图 1 像素、@2x 图 2 像素**，颜色 `#080E18`。第一单写成 2px 是下单写错，本单更正。
   - **锚点 (w/2, h−3)**：脚底（或身体最低点）落在画格底边上方 3 像素那一行，和现有本体完全一致（下表写了每只的脚底行），帧间不许浮动。
   - 所有帧在画格内四边留空，不贴边。
4. **体量一致**：出手、蓄力、冲刺帧的外框和像素量要和本体待机相当。**出手时不能缩小**（第一单伊莎玛拉攻击帧只有待机的一半，返修过一次）。拉伸 / 前冲帧允许外框略变，但不能整体缩放。
5. **不画特效**：刀光、枪口火光、冲击波、光环、弹药格、读条环一律由程序画。帧条里只画身体动作（剑、枪本身可以画）。
6. **无抠图残留**：交付前检查边缘没有紫色（R、B 高而 G 低）残留像素，目标 0%（第一单有 1–2%）。
7. 按下文优先级顺序做；每做完 2–4 个文件（1× 与 @2x 算一个）就提交一次，不必全做完。交付说明 ≤10 行 + manifest（尺寸、帧数、帧率、锚点、SHA-256）+ 接触表 PNG（深蓝背景、@2x 尺寸，和本体待机并排）。
8. 开工前工作树干净后 `git merge main`；不跨工作树；不 `reset --hard` / `clean`。
