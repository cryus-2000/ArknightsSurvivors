# V12 Codex 总需求单（2026-09-27，一次给全；V11 已并入第 1 组）

## 规则（每次必须遵守）
1. 只改本单列出的文件；不改 `game/` 代码，不改 `fx_*` / UI / 地形。不读 docs/ 其他文档、不看 game/ 代码、不跑游戏。
2. 标「请用户确认」的不改；本单写「用户已确认」的才算确认。
3. 规格同 V8：朝右、透明、二值 alpha、1px 深色外描边、锚点 (w/2, h−3)；1× 与 @2x 都交（@2x 同尺寸、密度加倍）。
4. 动作标准：待机 4 帧，f1–f2 头肩上移 1px、f3 回落。跑步 6 帧两步：f0 右脚着地、f1 下压、f2 交叉、f3 左脚着地、f4 下压、f5 交叉；着地脚逐帧后移；着地帧最低、交叉帧最高，起伏 1–2px；头躯干水平固定 ±2px；腰部重心 x=24（1×）/ 48（@2x），与 idle 一致；脚底线与 idle 一致；不动的部位复制上一帧像素。
5. 按组顺序做；每做完 2–4 个文件（1× 与 @2x 算一个）就提交一次，不必全做完。交付说明 ≤10 行 + manifest（尺寸、帧数、帧率、锚点、SHA-256）+ 接触表 PNG。
6. 开工前工作树干净后 `git merge main`；不跨工作树；不 `reset --hard` / `clean`。

参照：上下起伏看 `op_wisadel_run`（水平方向有抖动，别学）。干员帧条都在 `art/incoming/`，1× 待机 192×48（4 帧）、跑步 288×48（6 帧），@2x 为 384×96 / 576×96。
