# V16 Codex 需求单：itch 封面像素肖像与溟痕触须纹样（2026-10-01，待用户审；同日用户改主角为水月、人物改用原本配色）

**用途**：itch.io 页面封面 630×500 与横幅 960×400。肖像和纹样由 Codex 交分层 PNG，构图、标题、灯标、光效由我们用 `tools/promo_cover*.py` 合成（Codex 不排版、不加字）。

**风格参照**：参考《20 Minutes Till Dawn》主视觉的**限定调色和肖像密度**（背景用几种颜色画满、前面是像素手绘的人物肖像群像），**构图与色相必须有自己的识别度，不得临摹**。调色板、人物姿态、表情、头像排布全部按本单来，不照搬参考图的回眸持枪、右下一排头像、触须底纹等任何具体处理。

## 规则（同 V13–V15，每次必须遵守）

1. 只新增本单列出的文件；不改 `game/` 代码，不改已有贴图。不读 docs/ 其他文档、不看 game/ 代码、不跑游戏。
2. 标「请用户确认」的不改；本单写「用户已批」的才算确认。
3. **画法**：线稿风格的**像素手绘**，按目标尺寸逐像素画，**不是把现有 40–48 px 精灵放大**，也不是照片 / 3D 渲染后降采样。无抗锯齿、无半透明、无渐变、无抖动以外的混色。
4. **配色分两部分**（用户 10-01 定）：
   - **背景元素（溟痕触须纹样）只用下面的限定调色板**（深海蓝黑两阶 + 灰蓝），像素级逐个校验，出现表外颜色即退修；允许用两阶之间的棋盘格抖动。封面背景（海、灯标、海嗣、标题）由我们按同一套调色板合成。

     | 色 | 主阶 | 暗阶 | 用在哪里 |
     |---|---|---|---|
     | 深海蓝黑 | `#1C2E40` (28, 46, 64) | `#0B1420` (11, 20, 32) | 触须本体与暗部 |
     | 灯火暖橙 | `#F29A3A` (242, 154, 58) | `#B85A22` (184, 90, 34) | 背景只给灯火；**触须纹样里不用** |
     | 米白 / 灰蓝 | `#E8E2D0` (232, 226, 208) | `#8A9AA8` (138, 154, 168) | 触须高光只用灰蓝 |

   - **人物肖像用各干员原本的配色**（发色、衣服、瞳色、标志物颜色都按原作，不压进上面的调色板）。像素手绘，**每张肖像颜色数 ≤ 16**（不含透明）。光源统一在**右侧**：暖橙 `#F29A3A` / `#B85A22` 只作环境光，画在脸、头发、衣服朝右一侧的受光边上（1–2 像素宽），**不改角色的固有色**；暖橙像素每张 ≤ 10%。

5. **分层交付**：每张肖像交 4 个文件，尺寸与对位完全一致：
   - `<名>.png`：合成好的成品；
   - `<名>_line.png`：只有线稿（深色描边，可用角色自己的最暗色）；
   - `<名>_color.png`：只有填色（不含线和高光）；
   - `<名>_hi.png`：只有高光与暖橙受光。

   三层按 line 在上、hi 在中、color 在下叠起来，必须和成品逐像素一致。
6. 透明背景、二值 alpha；四边各留 ≥ 4 像素空白；人物外轮廓 1 像素深色线闭合（方便我们加边光）。
7. 每做完 2 张提交一次。交付说明 ≤10 行 + manifest（文件名、尺寸、各色像素数、SHA-256）+ 接触表 PNG（`#0B1420` 底，6 张并排，1× 与 ×2 各一行）。
8. 开工前工作树干净后 `git merge main`；不跨工作树；不 `reset --hard` / `clean`。

## 验收（交付后由界面与美术做）

1. **配色**：触须纹样逐像素统计，只含深海蓝黑两阶 + 灰蓝 + 透明（暖橙 = 0）；每张肖像颜色数 ≤ 16，固有色与原作一致（发色、衣服、瞳色没有被改成蓝黑 / 暖橙），暖橙只在朝右的受光边、占比 ≤ 10%。
2. **分层**：line / hi / color 叠起来与成品逐像素一致；二值 alpha；四边留空 ≥ 4；外轮廓闭合。
3. **可读性**：合成进 630×500 封面后缩到 315×250，每个角色都认得出是谁（帽子、耳朵、光环这些标志物看得清），脸上的眼睛 / 表情读得出。
4. **风格一致**：与游戏现有像素风不冲突（硬边、无抗锯齿、1 像素暗线），放在现有 `art/incoming` 角色帧条旁边看不出是另一套画法。
5. **原创性**：与参考封面并排看，构图、姿态、配色都没有临摹痕迹。
6. **平铺**：两条触须纹样左右拼接无接缝。
