# V16 Codex 需求单：itch 封面像素肖像与溟痕触须纹样（2026-10-01，待用户审）

**用途**：itch.io 页面封面 630×500 与横幅 960×400。肖像和纹样由 Codex 交分层 PNG，构图、标题、灯标、光效由我们用 `tools/promo_cover*.py` 合成（Codex 不排版、不加字）。

**风格参照**：参考《20 Minutes Till Dawn》主视觉的**限定调色和肖像密度**（几种颜色画满一张、像素手绘的人物肖像群像），**构图与色相必须有自己的识别度，不得临摹**。调色板、人物姿态、表情、头像排布全部按本单来，不照搬参考图的回眸持枪、右下一排头像、触须底纹等任何具体处理。

## 规则（同 V13–V15，每次必须遵守）

1. 只新增本单列出的文件；不改 `game/` 代码，不改已有贴图。不读 docs/ 其他文档、不看 game/ 代码、不跑游戏。
2. 标「请用户确认」的不改；本单写「用户已批」的才算确认。
3. **画法**：线稿风格的**像素手绘**，按目标尺寸逐像素画，**不是把现有 40–48 px 精灵放大**，也不是照片 / 3D 渲染后降采样。无抗锯齿、无半透明、无渐变、无抖动以外的混色。
4. **调色板只用下面 6 色**（3 个色相各 2 阶）+ 透明。像素级逐个校验，出现第 7 种颜色即退修。允许用两阶之间的棋盘格抖动表现过渡。

   | 角色 | 主阶 | 暗阶 | 用在哪里 |
   |---|---|---|---|
   | 深海蓝黑（底 / 线 / 阴影） | `#1C2E40` (28, 46, 64) | `#0B1420` (11, 20, 32) | 线稿用暗阶；衣物暗部、头发暗部、海嗣剪影 |
   | 灯火暖橙（唯一强调色） | `#F29A3A` (242, 154, 58) | `#B85A22` (184, 90, 34) | 只给「被灯照到」的受光边、眼睛、灯火相关的小物件；每张肖像暖橙像素 ≤ 15% |
   | 米白 / 灰蓝（肤色与高光） | `#E8E2D0` (232, 226, 208) | `#8A9AA8` (138, 154, 168) | 皮肤、白发、高光；灰蓝做中间调 |

5. **分层交付**：每张肖像交 4 个文件，尺寸与对位完全一致：
   - `<名>.png`：合成好的成品；
   - `<名>_line.png`：只有线稿（暗阶蓝黑）；
   - `<名>_color.png`：只有填色（不含线和高光）；
   - `<名>_hi.png`：只有高光与暖橙受光。

   三层按 line 在上、hi 在中、color 在下叠起来，必须和成品逐像素一致。
6. 透明背景、二值 alpha；四边各留 ≥ 4 像素空白；人物外轮廓 1 像素暗阶线闭合（方便我们加边光）。
7. 每做完 2 张提交一次。交付说明 ≤10 行 + manifest（文件名、尺寸、各色像素数、SHA-256）+ 接触表 PNG（`#0B1420` 底，6 张并排，1× 与 ×2 各一行）。
8. 开工前工作树干净后 `git merge main`；不跨工作树；不 `reset --hard` / `clean`。

## 我们怎么用（供参考，Codex 不做）

- 封面构图由我们排：斯卡蒂放左侧或居中，头像**弧形环绕中间的灯标**（或沿海浪线错落），不是一排；灯标、灯光和海嗣剪影由我们用现有资产合成，触须纹样铺在底部；标题位置与字体我们自定。
- 横幅 960×400 用同一组素材换排版。

## 验收（交付后由界面与美术做）

1. **调色板**：逐像素统计，只含上表 6 色 + 透明；暖橙像素占比肖像 ≤ 15%、触须纹样 = 0。
2. **分层**：line / hi / color 叠起来与成品逐像素一致；二值 alpha；四边留空 ≥ 4；外轮廓闭合。
3. **可读性**：合成进 630×500 封面后缩到 315×250，每个角色都认得出是谁（帽子、耳朵、光环这些标志物看得清），脸上的眼睛 / 表情读得出。
4. **风格一致**：与游戏现有像素风不冲突（硬边、无抗锯齿、1 像素暗线），放在现有 `art/incoming` 角色帧条旁边看不出是另一套画法。
5. **原创性**：与参考封面并排看，构图、姿态、配色都没有临摹痕迹。
6. **平铺**：两条触须纹样左右拼接无接缝。
