# V15 Codex 需求单：圣徒（卡门 / 伊比利亚）统一造型（2026-10-01，用户已批）

**本项目设定：「圣徒卡门」与「圣徒伊比利亚」是同一人物的两个强度档。** 原作依据：PRTS「圣徒卡门」「圣徒伊比利亚」两页。两页描述一字不差，武器都是手炮；伊比利亚档血、攻更高、弹药更少；机制都是「带弹远程 → 打空近战 → 装弹时自缚，被打断就眩晕」。
- 本单**取代** V13 中卡门 / 伊比利亚的全部帧条（`e_carmen_slash`、`e_iberia_attack`、`e_iberia_reload` 及其返修），见 `art/incoming/v13_acceptance.md` 相应条目。
- 现有 `e_carmen*` / `e_iberia*` 本体与移动帧条也由本单的新造型替换。

## 规则（同 V13，每次必须遵守）

1. 只改本单列出的文件；不改 `game/` 代码。不读 docs/ 其他文档、不看 game/ 代码、不跑游戏。
2. 标「请用户确认」的不改；本单写「用户已批」的才算确认。
3. **规格**：
   - 横向等宽帧条、朝右、透明背景、二值 alpha。
   - **单帧 40×48**（与现有 `e_carmen` / `e_iberia` 相同），1× 与 @2x 都交。
   - 描边 `#080E18`：**1× 1 像素、@2x 2 像素**，按外描边中位数验收。
   - **锚点 (20, 45)**：脚底在第 45 行，帧间不浮动；四边留空。
4. **体量一致**：出手、装弹、挥击帧的外框与像素量和待机相当，出手不缩小。
5. **不画特效**：炮口火光、弹道、刀光 / 挥击弧、读条环、弹药格都由程序画；只画身体、衣服和手炮本身。
6. **无抠图残留**：贴着透明区的那一圈没有紫色残留像素。
7. 每做完 2–4 个文件（1× 与 @2x 算一个）提交一次。交付说明 ≤10 行 + manifest（尺寸、帧数、帧率、锚点、SHA-256）+ 接触表 PNG（深蓝背景、@2x 尺寸，两档并排）。
8. 开工前工作树干净后 `git merge main`；不跨工作树；不 `reset --hard` / `clean`。

## 造型（两档共用）

- **年迈男性**：瘦高、背微驼、白发；正装（深色长外套 / 礼服、领巾），审判庭的庄重感。
- **武器只有一门大手炮**：粗短炮管、带击锤或后膛，单手可持、平时斜垂在身侧；**没有剑，没有长步枪**。
- 朝右站立，手炮在身体右前方（朝向前方），侧影要一眼读出「老人 + 大手炮」。
- **伊比利亚档（强化档）**：同一造型、同一姿态与帧，差别只在：
  - 配色整体更暗，偏灰黑与暗红；
  - 披一件破损斗篷（下摆撕裂，可以略微改变轮廓，但不超出画格、脚底不变）。
  - 要一眼看出「同一个人，更危险的状态」。

## 游戏里的播放时机（Boss与怪物 接入，供参考）

| 帧条 | 时机 |
|---|---|
| 待机 / 移动 | 常态 |
| `_attack` | 射击预警期间 f0 → f1，结算开火 f2，收招 f3（现有出招姿态挂点） |
| `_reload` | 装弹读条期间循环（卡门 3 秒、伊比利亚 4 秒，可被打断，打断后跪地由我们程序做） |

## 验收（交付后由 Boss与怪物 做，Codex 不跑游戏）

1. **静态**：尺寸 40×48、帧数、@2x、二值 alpha、脚底行 45、四边留空、外描边中位数 1 / 2 像素、边缘紫色残留 0、出手帧体量 ≥ 待机 85%。另外两档逐帧轮廓应基本一致，差别只在斗篷和配色。
2. **装弹动作**：逐帧变化的像素量、手臂 / 炮身位置变化要明显。V13 的装弹 4 帧轮廓完全相同，逐帧只变 4–99 像素，这次照此量化验收。
3. **实机**：同 seed `--bosstest=carmen` / `--bosstest=iberia` 前后截图对比（逐帧位置一致、只有贴图不同），加图鉴演示行。
