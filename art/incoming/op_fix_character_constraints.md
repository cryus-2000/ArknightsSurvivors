# 人物与武器一致性约束（本批及后续返修沿用）

- 以用户确认的原作立绘、武器特写和项目已确认造型为依据；生成稿不是角色设定的新依据。
- 每次检查发型、束发位置、帽饰标志、瞳色、服装层次、裤型、袜子覆盖、鞋型和武器轮廓。不得因动画姿势改造型。
- 水月：束起的浅蓝长发；海月水母帽徽恰好四瓣；宽松裤型、全黑袜，不露腿部皮肤；镭射质感折伞；伞尖为直向尖刺，并有向后的小倒刺，不是普通无倒刺尖头或弯钩。缩小到游戏实际尺寸后仍检查倒刺。
- 逻各斯与流明：头自然承托于肩颈上方，不独立前探、不耸肩驼背；跑步整体前倾，保持头颈躯干连贯。
- 朝向、帧序、出手时机和脚底锚点按 manifest。收招必须回到已确认的待机。
- 像素网格统一，透明二值，外描边 1x 1px / @2x 2px；QA 和视觉检查分别记录，机器通过不替代造型核对。
