## 0. 四节共用的约束

### 0.1 用户追加的三条总则（10-22）

1. **风格不设限，但「可演化、不可换血」**：Codex 可以提出新的美术方向，但要和现在的**干员图鉴（C4′）与选人页（B+）**差得不远——这两页是锚点：`0_anchor_codex_desktop.jpg` / `_phone.jpg`、`0_anchor_oppick_desktop.jpg` / `_phone.jpg`。可以演化配色、面板形状、装饰件；不可以换成另一种画风（例如高清矢量扁平、写实材质、二次元厚涂 UI）。四个界面要能和这两页放在同一个游戏里。
2. **去除 AI 感，保留像素感**：禁止生成式的糊边、渐变噪点、无意义的装饰纹路（看不出用途的线条 / 花纹 / 伪文字）、半透明发糊的辉光。线条、图标、面板一律按像素画：1x 设计、整数倍放大、硬边二值 alpha（需要透明的只用少档 alpha）、描边连续无断口、色块成面不散点。按 docs/104 的像素纪律验收（`tools/px_lint.py`：孤点 / 单点高光 / 描边 / 色数 / 连通体）；生成式草稿只能作参考，交付像素必须按部件在目标网格重画（docs/104 §2 第 3–4 条）。
3. **主界面必须加「寻访」入口**（与 集结出发 / 选人 / 图鉴 同级），见 §1 功能元素第 2 条。

### 交付格式与命名（docs/104 口径）

- 概念图：`ui_concept_<界面>_<desktop|phone>.png`（整屏，1280×720 / 1480×720 原尺寸 + 一张 2× 放大局部）。
- 可切素材：`ui_<界面>_<部件>@2x.png`；九宫格面板另附切线：manifest 里写 `patch_margin`（左上右下，@2x 像素）；图标给 @2x 方形尺寸（16 / 24 / 32 的 2 倍）；装饰件写原点。
- 每节一个 `ui_<界面>_manifest.json`：文件名、@2x 尺寸、原点或九宫格边距、用在哪个元素（对应本单「必须保留的功能元素」编号）、SHA-256。
- 只动 `art/incoming/`；一节一个提交；handoff 写清楚哪些是概念、哪些是可切素材、哪些需要 Claude 用程序画（例如数值条、动态光效）。

### 验收（docs/104 §4）

① **人眼先行**：用户看概念图「过 / 不过」；与现有像素立绘 / 小人 / 敌人同屏（概念图里直接放现有截图里的人物）不违和。② **数值**：素材尺寸 / 九宫格边距 / 原点与 manifest 一致，@2x 是整数倍；图标在 1x 尺寸下可读。③ **游戏内**：Claude 接入后桌面 + 手机逐屏截图对照概念图，功能元素一个不少。

## 1. 主界面（标题页 + 难度页）

现状：`1_main_title_desktop.jpg` / `1_main_title_phone.jpg`（T5a 精简版：左上像素 Logo，下面 6 块磁贴，右下「更换封面干员」，页脚一行；背景 keyart 巨树 + 博士 + 封面干员原尺寸）。

必须保留的功能元素：
1. 本作像素 Logo（`art/incoming/logo.png`，可重新排位置，不改 Logo 本身）。
2. 入口：集结出发（主）、**寻访（新增，与集结出发 / 选人 / 图鉴同级，用户 10-22 定）**、图鉴、Boss 演练（对外包隐藏）、操作说明、设置、退出（网页 / 手机隐藏）。「寻访」按钮带**凭证数量角标**：持有寻访凭证 + 招募券 + 人事调度函的总数（> 0 时显示，青色小圆角数字；0 时不显示角标、按钮照常可进去看卡池与意向）；全部干员解锁后角标改成「已满」不再提示（docs/109 §12、docs/124）。
3. 「更换封面干员」入口；封面干员原尺寸显示在 keyart 里（像素小人不放大，docs/37 §8）。
4. 页脚声明：「明日方舟同人作品 · 非商业 · 与鹰角网络无关 · 致谢与声明 C · 版本号」。
5. 难度页：难度档列表（名称、修正项）、出发 / 返回；局外成长入口（认知塑造，docs/109，可放在标题或难度页）。

动效：现主动作为「磁贴从潮线下浮出 + 选中涨潮」，重排时可换成新的招牌动作（避开 docs/62 §4 已占用的）。

## 2. 寻访界面（局外解锁）

流程、分镜与已定的演出见 **docs/124**（§9–§11：寻访界面 → 拉开作战包 → 光炸 → 剪影亮起 → 名牌 NEW → 寻访结果）；包体与开包特效已单独派单 **`art/incoming/codex_order_headhunt_handoff.md`**（不在本节重复）。本节只管**寻访界面本身与选择页**的视觉。

现状（逻辑会话的占位版）：`2_hunt_reveal_*.jpg`（占位揭晓）、`2_hunt_pick_class_*.jpg`（招募券选职业）、`2_hunt_pick_letter_*.jpg`（人事调度函选干员）、`2_hunt_wish_*.jpg`（意向干员）；设计稿样张在主仓库 `build/headhunt_design/`（`v2/v2_1.png` 寻访界面、`pick_class.png`、`pick_letter.png`）。

必须保留的功能元素：
1. 寻访界面：卡池区（未解锁干员**剪影**，意向干员居中放大，不剧透立绘）、三种券持有数（寻访凭证 / 招募券 / 人事调度函）、意向保底文案「意向干员保底 / 再寻访 N 次必定获得 ×××」+ 三格进度、规则两行（未解锁 n 名 · 不会重复 / 首次寻访必定获得医疗干员）、按钮「寻访一次」「全部使用」。

## 4. 局内面板（HUD / 升级三选一 / 商店 / 暂停）

现状：`4_hud_*.jpg`、`4_levelup_*.jpg`、`4_shop_*.jpg`、`4_pause_*.jpg`。

必须保留的功能元素：
1. **HUD**（docs/37 §4）：左上等级圆（外圈经验）+ 生命值 + 灯火（小标签头）；顶部「击杀 | 时间」+ 楼层条；右上暂停 + 藏品栏（38 / 22 像素格，最多 3 行）；右下部署卡式编队（职业、精英阶段、三枚技能格、队长紫标）+ 源石锭费用框；左下声呐；底部冲刺键牌；触屏：冲刺 / 技能 / 暂停 / 属性 / 倍速按键（玩家可拖动）、移动摇杆。局内信息密度高，**HUD 不能遮挡战场中央**。
2. **升级三选一**（docs/37 §4、docs/62 §3.11）：三张卡 272×382（手机按高度缩），卡上类别（生存 / 机动 / 协同等）、图标、名称、说明、「影响」标签片（干员色 / 全队 / 队长 / 洋红代价）；背景战场去饱和压暗；重抽 / 跳过（若有）。
3. **商店**（docs/37 §4、docs/62 §3.15）：左商人立绘框（坎诺特，10-22 新图，暖光在身前货物）+ 五张货品卡 + 价格条（源石锭绿）+ 刷新 / 离开；持有源石锭；停留倒计时；手机不画商人框、五卡横跨整屏。
4. **暂停**：标题「暂停 PAUSED」+ 按钮 继续 / 指南 / 设置 / 重新开始 / 回到标题（快捷键 Esc / G / O / R / T）；手机面板 ≤ 960 宽、按钮 60 高。

素材建议：通用九宫格面板（深 / 浅两套）、卡片框（三种稀有度 / 类别边）、标签片、按钮（主 / 次 / 危险）、小标签头、技能格框、费用框、图标集（生命 / 灯火 / 源石锭 / 击杀 / 时间 / 暂停 / 属性 / 冲刺），全部 @2x。
