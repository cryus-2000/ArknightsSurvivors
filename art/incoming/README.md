# 美术收货区

这里只放**新交付**，游戏不读这里（10-28 起，docs/189）。规则：

- 一批一个子目录：`art/incoming/<内容简称>_<月日>/`（例 `skalter_s3_1029/`），帧条、handoff、manifest、审阅图都放在里面；根目录只留本说明和 Codex 总入口单。
- 文件命名按 docs/189 §3（前缀登记表；`op_<干员id>_<动作>`、`e_<敌人id>_…`、`fx_<主人id>_…` 等）。
- 接入：负责的会话验收后复制进 `game/art/<类别>/`，跑 `python tools/asset_index.py` 更新索引，同一提交改 json / 代码；接入合入后整批 `git mv` 到 `art/archive/`。改图后要重开游戏（Godot 重新导入），不再有「丢进来就生效」的热替换。
- 旧分支（例如 codex/art 上没合的交付）里写在 `art/incoming/<名字>.png` 的图：按 `tools/asset_path_map.json` 落到新路径，`python tools/asset_paths.py <旧路径 ...>` 直接给出新路径。

规格出处：

| 内容 | 文档 |
|---|---|
| 尺度、画布、原点、各簇卡值、七条约束、两条纪律、脸部平滑 | docs/103 §3–§5 |

| 当次范围（谁、哪一版母稿、单帧还是整条、交付路径） | docs/97 当次单（只写范围，不写数值） |
| 目录与命名 | docs/189 §1–§3 |
