## 原则

1. 全部按目标尺寸**直接画 / 直接摆**，游戏里 1:1 显示，**不做运行时放大或缩小**（现在普通怪是 1x 美术 × 1.5 运行时放大，光学观感下像素大小不均；Boss 有 0.68 / 1.12 / 1.15 等非整数缩放）。
2. 只缩不放：普通怪 ≤ 干员，精英略高于干员，人形 Boss ≈ 干员（靠气场），重型 Boss 才明显大。
3. 判定半径不改（玩法不变），画面主体贴合判定圈（约判定直径 × 1.3）。

## 像素规格（重画时的硬规定）

**1 美术像素 = 2 屏幕像素**（`game.gd` `PX = 2`，与光学观感 640×360 / 2 px 格一致）；按 1x 画，交付另出最近邻 ×2 的 @2x。各档身高、画布、色数见上表。

- **原点**：脚底中心（悬浮类取投影中心），写进 manifest；画布宽可按体形放宽，高按上表。
- **描边**：1 px 外描边，暗区与轮廓底部用 `#080E18`，亮区外缘用该区最深一阶（有色描边）；无半透明（alpha 只有 0 / 255）。
- **受光**：统一左上方来光（docs/127 B5）；明暗用 2–3 阶色团，不留孤立单像素。
- **发光层**：眼睛 / 核心 / 发光器官另出一张同尺寸 `_emit` 图（只画发光像素，其余透明），光学管线读它做辉光；本体图里这些像素照常画。
- **发光颜色（10-23 用户定的颜色语言）**：敌方发光（眼睛 / 核心 / 敌方弹幕）统一用**洋红偏深红**一个色系，不再各怪各色；精英同色系更亮、多一处发光点；Boss 可有专属色但限暖色范围。青 / 青绿只给环境（孢子、地面荧光、怪死后体液），琥珀暖橙只给我方灯火，淡金白只给经验结晶与掉落，干员技能保留原作色。
- **帧数**（与现有 docs/108 契约对齐）：普通怪 待机 / 移动 4 帧、攻击 4–6 帧（带前摇）、受击 1 帧；精英 / Boss 待机 4–6、攻击 6–8 带前摇；朝向只画朝右，游戏内翻转。
- **对比稿**里「目标」列允许先用现图最近邻缩放示意，但要按上表的 1x 身高缩到整数像素再 ×2，不能出现非整数倍的模糊。
