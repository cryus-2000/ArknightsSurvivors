# Codex 动画单：终结技第二批 15 人 · 干员本体动作（2026-10-30）

设计依据：`docs/198_ultimate_combo_design.md` §4.6–4.20（招式）、§7.1（演出时间线）；原型时序 `docs/199`（分支 `claude/ult-proto`，`run/ult_moves_b.gd` / `ult_moves_c.gd`）。用户 10-29 / 10-30 对招式的订正已写进下表，与 docs/198 不同处以本单为准。
特效素材见同目录 `codex_order.md`；本单只管**干员自己的身体动作**（起手 / 放招 / 收招），以及忍冬收身的一小条。本单只写范围与验收，怎么画按 docs/104。

## 0. 口径（沿用，不重复）

- **流程**：docs/104 §3 动画线——只从已通过的 f0 / 现有待机帧出发，按部件拆层合成；禁止整图挪像素、禁止生成关键帧换脸。每人先交 **f0 + 代表帧**两张（代表帧 = 放招最大那一帧，manifest 写帧号），用户点头再出整条；15 人可并行，同一人内按表顺序串行。
- **尺度**：docs/103 + 干员画布 64（@2x 128）；武器 / 大动作出框的用 **96 画布**（@2x 192），身体仍按 64 的尺度画、脚底原点与 64 画布对齐（与现有 `op_*_attack` 192 帧条同一做法）。**只交 @2x**。
- **颜色**：以 PRTS 立绘与原作技能动画为准（docs/87 §4.3：色调 / 瞳色 / 衣服细节与立绘一致，明度范围与 24 色让位于设定色）；本地 `build/` 下 PRTS Spine 参照可用。
- **画风**：干员本体保持高清（10-23 画面方向），**不套 3 像素格**；Noita 化的光、碎屑、拖尾、余烬都在特效层，不画进身体帧条。身上的发光部位（拳上琥珀光、灯、法术光）只画实体本身的受光，不加柔光晕、不整体提亮，高光封顶不过白。
- **朝向**：只画朝右一套，程序按瞄准方向左右翻转（指上 / 下时仍用侧身）。
- **命名**：docs/189 §3，`op_<干员id>_ult[_<变体>]@2x.png`，id 写全（`eyjafjalla`、`specter_unchained`；水月新素材一律 `op_mizuki_*`）。
- **交付目录**：本目录 `art/incoming/ult_batch2_1029/`（与特效同目录，manifest 合一份或分 `manifest_anim.json` 均可）；不改 `game/`。
- **立绘切入**：沿用现有图鉴立绘（docs/198 §7.1），**不做切入专用姿势**；忍冬半身已在特效单 §1。

## 1. 交付

- 每条一张 @2x 横排帧条；`manifest.json` 写每条帧数、fps、画布、原点、帧段（起 / 循环 / 放 / 收的帧号）、代表帧号、@2x 未压缩 MiB、与本表不同之处及理由。
- 每条一段**循环预览 mp4**（原速、30 帧，黑底和本作暗色地面底各一遍，≤5 MB），身体与该干员的终结技特效同屏叠一遍（特效未交时只看身体）；整批一张总览。只给最终版，不做改前改后对照。
- 内存：单文件 @2x 未压缩 ≤ 5 MiB；**本单合计 ≤ 25 MiB**（下表合计约 19.9 MiB，17 条 / 178 帧）。

## 2. 动画要求

- **时序**：对上 docs/198 §7.1 与原型时长——起手快（2–3 帧到位），**放招那一帧姿势最大、最清楚**（冲击帧顿 0.1 秒、慢放 0.45 秒时停在这一帧附近，要经得起看），收招 2–3 帧回待机，不拖。
- **循环段**：标「循环」的段首尾无缝，长度由程序控制（持续型招式按秒循环）；末帧能接回 `op_<id>_idle` 首帧。
- **定格帧**：标「停」的是单帧，程序按需要的时长停住（歌蕾蒂娅的「收—停—爆」、逻各斯的「一词」等），这一帧要是全身蓄满的姿势，不是过渡帧。
- **对位**：握点、脚底、脸逐帧锁死（docs/104 §3.4）；武器挥出的残影不画进身体帧条（特效层出）。
- **出手点**：manifest 写放招帧的出手点坐标（拳 / 锤落点、剑尖、炮口、杖头、灯），程序以此挂特效原点。

## 4. 验收

1. Claude 先查规格（帧数、画布、原点、帧段、出手点、MiB）。
2. 人眼三层按 docs/104 §4：8 倍看连接处、与现有待机帧并排（脸、发、武器、配色不得漂移）、对 PRTS 参照。
3. 接进终结技原型（分支 `claude/ult-proto`）与对应特效同屏实机播放，录最终版给用户看。
4. 实机要改（帧段长短、出手点、姿势幅度）时 Claude 给一行「口径更新」，只改那一项。
