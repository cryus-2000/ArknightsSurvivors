# 素材单：补给箱 / 应急补给（docs/133）

背景：补给箱（可被打碎的箱子）现在会掉回血的「应急补给」，先用现有贴图占位，请 Codex 出正式素材。

| 项 | 现状（占位） | 要求 |
|---|---|---|
| 补给箱 | `e_chest`（现有宝箱图，宝箱 / 伪装箱形恐鱼共用） | 保留「箱子」读感；与精英掉落的藏品宝箱（金色）区分——补给箱是军用 / 医疗补给箱的样子，色调偏冷白 + 一道绿十字或绿色封条；静止 1 帧 + 受击闪白（程序做）+ 碎裂 4 帧（可选） |
| 应急补给（拾取物） | `pickup_heal`（回复药剂，绿色瓶子） | 一个小医疗包 / 注射剂的样子，与回复药剂（瓶子）一眼能分开；约 24×24 逻辑像素；可带 2 帧轻微悬浮高光 |
| 拾取特效 | 复用回复药剂的绿色环 + 火花 | 不用做 |

约束：按 docs/87 §4.3 色调与 docs/104 像素流程；只交 @2x；命名 `e_supply_crate`、`pickup_pack`（我这边接入时替换 `world.gd` 里 kind == "pack" 的贴图名）。
