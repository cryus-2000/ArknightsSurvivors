## 1. 信息结构（Claude 定，Codex 按此排版，不增删）

1. **顶部结果带**：胜 / 败（大字 + 描边英文 OPERATION COMPLETE / FAILED）、用时、难度档（标准 / 困难 / 极限）、本局获得——生机细胞 ×N、寻访凭证 ×N（数字跳动计数的终态）。评级留空位（未定，用占位框标「RATING」）。
2. **主体 = 作战记录**：队长 + 队友横排（每人：小人、名字、击杀 / 伤害占比条 / 参与击杀 / 释放技能次数；队长多一条「倒地次数」）；右侧关键事件轴（分钟刻度：中期 Boss 击破时刻、终局 Boss、死亡原因 / 超时）。原来按钮进入的明细全部摊开在这一屏。
3. **底栏动作**：「寻访」（有凭证时高亮并显示张数，无凭证灰）/「认知塑造」/「返回主界面」——寻访从这里进，不再叠层盖面板。
