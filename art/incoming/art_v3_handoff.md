# 地图与敌人美术 V3

本轮仅交付美术，未修改 game/。基础素材放在 art/incoming 根目录，按游戏 tex 标识命名，避免 bosses/ 子目录无法自动覆盖的问题。旧 boss.png 不再使用，上一轮造型稿保留作历史参考。

## 已覆盖敌人

20 个 ENEMIES 的 tex 标识均有对应两帧 PNG。8 个此前没有新版的敌人新绘：e_offspring、e_brood、e_tear、e_skimmer、e_mother、e_mimic、e_izumik、e_ishar。其余来自已交付造型，调整到本轮游戏尺寸。e_fractal 使用原有塑路者分形稿。

e_bishop_feign、e_archon_feign、e_immortal_feign、e_paranoia_phase2 是额外形态，需开发侧显式选择，不会只靠放文件自动切换。最后的骑士和延命塑路者当前没有 ENEMIES 对应标识，保留上一轮稿，不臆造加载名。

art_v3_manifest.json 提供所有单帧尺寸、帧数、SHA256 和来源；art_v3_audit.json 包含覆盖检查。精灵横向排列，二值透明度，nearest 采样，不使用 mipmaps。普通怪原有小尺寸画布已增大；不应再统一叠加 1.4 倍，否则会重复放大。

## 体型与接入

- 当前 PX=2，新普通怪/精英的画布约 18–34px，按现有 2 倍绘制即可先看效果。可见轮廓比画布小，具体见预览与 manifest。
- 人形 Boss 40×48；恐鱼 Boss 42×40 / 44×44；塑路者 56×56；泡影、伊祖米克 72×72；伊莎玛拉 80×80。不同种类不采用同一比例。
- 未改碰撞半径、移速、伤害。Claude 接入后应分别核对可见身体、脚底位置、碰撞圆、血条位置与攻击距离，不能将完整含触须的外接矩形当碰撞体。
- 维持现有敌人两帧切图方式。白色剪影应从新贴图重新生成，避免旧轮廓闪白错位。
- e_mimic 是显形箱形恐鱼；隐藏状态 e_chest 不在本轮重绘范围。伊莎玛拉/伊祖米克虽在数据表内，但当前结局池未启用它们；素材存在不意味着新增了关卡。
- 形态仍属于首轮像素化改编，不是原作完整动作复刻；本轮没有新增技能特效或 Boss 动作。

地形为完全不透明 PNG；景物与敌人为透明 PNG。地形不加黑色外描边。基础地砖外缘统一色，可任意拼接；区域图不是 Godot 自动地形连接规则集。

建议区域块聚簇摆放，旋转/镜像地面变体，避免按格子平均随机混合四种材质。大型景物放在区域边沿，中央保留战斗空间。柱、墙、船体按底部中心锚点，并视游戏需求做 Y 排序和遮挡淡化；是否阻挡移动由开发方决定，贴图本身不创建障碍。

map_v3_preview.png 是实际交付素材拼装的构图示意，不是 Godot 运行截图。它不包含游戏灯光、碰撞或镜头缩放。合并后基础地砖/海草/珊瑚和同名敌人可由现有覆盖逻辑读取；区域块、大景物、额外形态仍需 Claude 接入。

## 参考与生成

内置 imagegen 生成原稿，C# 做机械缩放、二值 alpha、轮廓处理及 PNG 验证。敌人参考 PRTS 同名页面与 Aceship/Arknight-Images 的公开敌人头像；源头像未作为游戏文件提交。

提示词核心：依据参考敌人的具体解剖与配色制作右向两帧待机，统一比例和基准线，透明背景、深色外描边；地图使用低对比深海蓝青底色、少量青色裂隙，单独生成古代残柱、断墙、沉船碎片和海洋植物。每个资产的源图 ID 保存在 manifest。原始生成大图不是最终像素尺寸素材。
