## 2. 动画要求

- **时序**：帧段要和 docs/198 §7.1 演出节奏对得上——起手快（2–3 帧到位），爆发帧最亮最大，收尾 2–3 帧衰减，不拖尾巴。循环段首尾帧能无缝接。
- **拼接段**：6 个拼接段每一帧的两端都要能接（不只是 f0）；manifest 写每段的参考半径 / 角度。
- **多层对位**：同一特效的 back / front / orbit 每一帧共用原点与帧号；海嗣前后层帧数不同的，manifest 写明播放映射（哪一帧对哪一帧）。
- **颗粒与碎屑**：按 v2 §1 的 Noita 口径，碎屑要有运动方向和落地，不是原地闪；粒子数量控制在单帧可读，叠多层时不糊成一片。
- **透明**：边缘像素硬边 + 少量半透明碎屑；不要大面积低透明度柔光（实机叠加后会发灰）。
- **原作素材**：巨锚、海嗣、Mon3tr 这类以原作 Spine 附件为依据的，保持关键帧阶段的做法（附件像素化、不另画形体）；剑雨继续复用游戏现有剑雨贴图。
