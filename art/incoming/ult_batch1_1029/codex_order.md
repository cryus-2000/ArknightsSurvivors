# Codex 特效单：终结技第一批 5 人（2026-10-29）

设计依据：`docs/198_ultimate_combo_design.md`（§4 各人终结技、§7 演出规格、§8 本单原表）。本单只写**范围与规格**，演出时序、伤害、范围由 Claude 在代码里做。

## 0. 交付规则（照现行口径）

- 交付目录：本目录 `art/incoming/ult_batch1_1029/`（帧条 + `manifest.json` + `handoff.md` + 审阅图），不写根目录，不改 `game/`。
- **只交 @2x**（下表帧尺寸写的是 1x 逻辑尺寸，实际出图 ×2），不交 1x。
- 分层：每个特效按 `_back`（地面层，画在角色和敌人下面）/ `_front`（主体层）/ `_orbit`（环绕层）出，同一特效的各层共用原点和帧号。
- 流程按 docs/104：先交每个特效的 **f0 关键帧**给用户看（5 人可并行，同一人内按表顺序串行），用户点头再出整条；验收三层：人眼先行，再查规格，最后进游戏看。
- 颜色：干员部分以原作技能动画与立绘为准（docs/87 §4.3：色调 / 瞳色 / 服饰细节必须与 PRTS 一致；本地 `build/` 下的 PRTS Spine 参照可用）；本作自定的部分（爆裂弹、旋转激光等）按下表色。
- 命名按 docs/189 §3：`fx_ult_<干员id>_<内容>_<层>`。
- 程序能画好的（冲击环、震屏、单条刀痕直线、锁定框外圈、镜头推拉、立绘切入条带）Claude 自己画，**不在本单**。立绘切入用现有图鉴立绘，不新画人物。

## 1. 总体气质（用户 10-29 原话：演出要夸张）

- 终结技一局只放 3–4 次，每次都是高光：比同一干员的三技能**大一档、亮一档**，前后层次分明（地面裂纹 / 光圈在 back，主体在 front，粒子与光晕环绕在 orbit）。
- 手机网页要守 30 帧：单个特效帧数控制在 4–12 帧；能平铺 / 旋转复用的就做成可平铺段（游戏内拉长、旋转、缩放），不要画整屏大图。
- Boss 战时程序会把 back 层降到 50% 透明、去掉粒子，素材**不另出淡版**。

## 3. 每人一句要点（防跑偏）

- **德克萨斯**：速度型剑士，刀痕要「快、细、锐」，斩开瞬间亮、随即收；剑雨的剑与她原作二技能一致。
- **能天使**：火力不讲道理但每发要轻，爆炸小而密，叠起来才壮观。
- **浊心斯卡蒂**：歌声与深海，光束是「歌声凝成的光」，不是机械激光；召唤物是她原作天赋里的海嗣。
- **凯尔希**：熔毁是 Mon3tr 的自爆，要有「牺牲」的重量；重构要看得出是同一只 Mon3tr 回来。
- **乌尔比安**：锚是重型武器，每一层裂地都要沉、要有碎石飞溅的重量感。
