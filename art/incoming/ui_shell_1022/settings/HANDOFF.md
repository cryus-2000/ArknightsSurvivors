# 设置页桌面样图

1280×720 画面分类样图，用户已确认本版视觉，未接入游戏。沿用寻访的左白右黑、斜切、角括号与青色强调；以固定分类索引和低对比选项行区别于难度页的宽幅选择带。

实际源文件是 `game/scripts/settings_panel.gd`，工单写在 screens 下的路径不准确。本稿核对 ROWS、TABS、CLOUD_TAB：画质只有高／低，不增加中档；示例为窗口模式。滑条为离散像素表现，实装保持原有步长与范围。未显示的画面选项继续滚动查看，不删选项。

左侧按工单分为画面／声音／操作／存档；操作承接原游戏分组的全部键，不改语义。存档分类仍仅在 Cloud.supported 时出现，本图示意支持云存档的平台。触屏隐藏 fullscreen / res_index，仅触屏显示 touch_layout；对局记录继续按测试版条件显示。恢复与覆盖保留二次确认。

全部控件值为样例。声音、操作、存档内容和局内暂停半透明底尚未出独立样图；本图不是这些状态的验收。实装不新增存档键，不进 hud.gd，不改变战斗路径。
