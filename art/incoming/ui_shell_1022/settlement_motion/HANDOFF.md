# 结算动效候选

仅供审阅；未接入游戏。以 `../settlement/settlement_desktop.png` 为唯一终态，现有角色、排版、数值均不修改。

采用一次性战报归档：标题 0–220 ms 揭示；奖励 120–500 ms 读数；四条伤害占比条从 240 ms 起错开 60 ms 填充；事件记录 300–720 ms 向下展开；评级 680–900 ms 落位。总时长 900 ms，结束后无循环、无扫光、无亮度呼吸，便于截图。计时只使用浏览器真实时间。

符合 docs/62 的 T1/T2/T3/T4 时长、out_cubic / linear 缓动、整像素位移和最近邻显示。未采用旧文档的震屏放大效果，以保持已认可的克制排版。

预览支持重播、暂停/继续、立即终态；点击画面或 Enter 跳过。减少动态或系统 prefers-reduced-motion 直接展示终态。页面控制栏不属于游戏 UI。

`counts.png` 仅是短暂读数用的透明像素字图，不是新的角色素材。最终直接绘制原图，因此终态逐像素一致。所有信息和按钮在开始即保留，未新增游戏输入锁。

既有结算样例仍有旧的“潮位 VIII”字样，本候选按已批准整图原样保留；接入时应绑定真实难度数据，不把此样例标签写入运行时。
