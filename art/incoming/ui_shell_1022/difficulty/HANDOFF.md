# 难度页桌面样图

用户要求优先继续难度与设置，覆盖之前的制作顺序。1280×720 静态候选，等待视觉审核，未接入游戏。

从用户所附原作参考吸收大编号、横向展开的选中层与退后的相邻项；保留本项目三档，不照搬原作无限滚动潮位。困难档白底扩展、黄色侧边和前置背板；标准青、极限红；锁定态斜线遮罩与解锁条件。右侧本档记录独立，避免与规则说明混在一起。

档名、系数、描述核对本分支 `game/scripts/data.gd` 的 DIFF_PRESETS。右侧 3 次、10:24 为排版示例，不是用户存档；SS 对应已批准的困难通关评级。规则只作摘要，正式交互仍应提供完整累计修正查看入口。

执行上一级 `render_difficulty_settings.py` 可重绘。仅使用 Pillow 和本地字体，不用 AI 生图；manifest 记录图像散列，layout_text_bounds 记录经边界断言的文字位置。尚无交互、手机态或引擎验证。
