# 怪物重画全形态静帧交付 · 10-23

本目录是当前审阅版本，取代父目录首批四张的颜色版本。规格依据 main `9d0bc4ec`，用户授权「继续做剩下的吧」及同步最新颜色规则。仅交付静帧候选，尚未完成动画、运行时替换或引擎验收。

## 交付内容

- 32 个形态，共 128 张 PNG：每个形态本体、独立 `_emit`，各有 1x 和精确最近邻 @2x。
- 新补 28 个形态：27 张经 built-in imagegen 重画的源图；箱形恐鱼伪装态直接复用既有 `chest.png`，同尺寸同轮廓，无敌方发光点暴露伪装。
- 首批骨海、固海、拟嗣、卡门同步新版发光颜色。骨海、固海、卡门本体像素不变；拟嗣旧红色器官在本体中改为暗蓝材质，青蓝亮色只在独立层。
- `review.html`：实际显示大小和本体／发光／合成放大对照，支持切换光层。`lineup_1.png` 至 `lineup_4.png`：全体实际大小。
- `job.json`：逐项尺寸、色板、参考和源图哈希；`manifest.json`：逐资产尺寸、原点、密度及 SHA-256；`qa.json`：独立技术检查结果。
- `generated/`、`prompts/` 保留实际生成源图与完整提示词。部分早期提示词生成于颜色更新前，且明确要求无发光本体；当前发光颜色由 `job.json` 与导出决定，历史提示词不作为现行颜色规范。

## 颜色和图层

海嗣发光为青蓝三阶 `#28586D / #408EA8 / #82CDDC`。精英使用更亮三阶 `#377087 / #65B2C7 / #A3E1EA` 并增加一处。Boss 保留参考中的材质区分，蔑死体、泡影使用低饱和骨黄专属光，斥亡体和其他海嗣为青蓝。卡门、伊比利亚、骑士为银灰标识，避免套用海嗣青蓝或危险红；卡门光点位置保持帽带侧后方。

本体始终是低饱和材质；发光层是独立 RGB 叠加，不能仅当 mask 再取本体颜色。新光点不烘焙进本体。同形态两层严格同画布、同原点、同帧序。当前没有渲染 bloom，辉光由后续游戏光学管线处理。红／洋红危险预警、敌弹，暗青灰环境属于其他资源，此单不修改。

## 尺寸与复现

除用户随后要求掠海漂移体缩小为屏幕高60px（美术30px）外，其余满足任务单目标可见高度，1 美术像素对应 2 屏幕像素。只为保持原有宽高比例放宽部分画布宽度，例如骑乘骑士；不要运行时压窄。原点写为底边 exclusive 的脚底／悬浮投影中心，动作扩展时仍需验证运动锚点。

在 codex/art 工作树运行：

```powershell

```

技术检查覆盖目标高度、画布／原点、二值 alpha、色数、透明边界、孤立 alpha 像素、精确 ×2、发光配色与本体覆盖、来源哈希、宝箱完全一致、卡门位置不变。自定义检查采用最新有色描边及颜色规则，不套用旧的全黑描边／禁止青蓝规则。
