## 现状为什么杂乱

| 来源 | 具体 |
|---|---|
| 信息密度 | 39 个节点一次全画、每节都写名字；同一条链 5 个同名节点（攻击性Ⅰ…Ⅴ）重复 5 次 |
| 层级 | 每条链 3 层标签叠在一起：分类（攻击）+ 末节规则框（处决）+ 节点名；当前节点的效果却放在离它最远的左栏 |
| 对齐 | 10 条链从底部一个根扇形散开、两侧外斜、相邻列错半格；根部 10 条长连线穿过文字；最左（调度）、最右（回复）两列被屏幕边裁掉 |
| 背景 | 碎片轮廓 + 引线 + 刻度 + 小数字常驻漂动，线条和树枝同一种细线，抢视线 |
| 颜色 | 左栏浅灰 + 右侧暗场两套明度；警示黄、亮蓝大数字、青、暖白、灰蓝共 6 种强调色 |
| 文字量 | 一屏约 60 段文字（节点名 39 + 分类 10 + 规则框 10 + 左栏） |
| 动效 | 背景碎片一直漂移自旋，静止看也不安静 |

## 三个方案（都按 战斗 / 成长 / 资源 分三组，顶栏统一：标题块 + 生机细胞 + 已塑造 x / 39 + 返回）

- **A 档案列表**（锚点：图鉴）：10 条链各一行——等级格（暖白 = 已塑造、青框 = 下一节）+ 当前总加成（「全体伤害 +16%」）+ 下一节消耗；右侧浅色面板逐节列出该链全部节点与质变规则，右下大按钮塑造。一屏读完全部进度，最省心。
- **B 整齐图谱**（保留「树」）：10 列等距排齐、不斜不扇、去背景碎片和每节名字，节点只标罗马数字，末节规则做成列顶小标签；右侧暗色详情面板（同选人右栏）。保住「一棵树往上长」的感觉。
- **C 单链聚焦**（锚点：选人）：底部一排链卡像名册（图标 + 名字 + 等级格），中间放大当前链的 3–5 节横排卡片（效果、质变规则一眼看全），右下大按钮塑造。单链信息最完整，跨链对比要靠底部卡片。

演示视频脚本相同：进入 → 依次选 攻击 / 生命 / 减伤 → 回到攻击 → 塑造「攻击性Ⅴ」（细胞 275 → 251、节点点亮）→ 切到成长组。

## 海底星空版（10-25，在照抄原作版上改）

用户：「改成那种海底星空的排列，节点可以是星座」。

- **星座**：每条认知线是一个星座，节点是星。同一条线按 Ⅰ→Ⅱ→… 用细连线连起来，到星前留一小段空。星座旁写线名，下附「已塑造 / 总数」。多程信息处理那条每颗星名字都不同，所以不写线名，星旁写全名。
- **位置**：整体沿用原作节点树的位置关系，同名节点尽量留在原位。原作里同一条线的节点散在全图，直接连成星座会横穿整张图，所以把离群的挪进本星座所在的区域，见 `layout.py` 的 STARS 注释。挪过的有：
  - 攻击性Ⅲ、自我保护Ⅳ、生存本能Ⅲ、收藏癖Ⅲ
  - 危机感Ⅰ–Ⅱ
  - 领导欲Ⅰ、Ⅳ
  - 自我审视、战利品意识
  - 交涉Ⅱ–Ⅲ
  - 生命感悟改占原作左边那条线
- **三种状态**：
  - 已塑造 = 亮星：白芯、十字星芒、青光。两头都亮的连线点亮，有光点流动。
  - 可塑造 = 黄白星：星芒一伸一缩，加黄色点环转动。
  - 余额不够 = 灰星。
  - 未解锁 = 暗星。
  - 质变节点 = 大亮星：八道星芒，伴星成团。
- **背景**（`meta_bg.gdshader`）：海面淡光（焦散波纹），满屏闪烁的发光微粒，一条斜贯的星云带；另有微粒缓缓上浮。
- **布局检查**：`layout.py` 会查星座连线是否交叉、是否擦过别的星，以及星名 / 线名是否重叠，当前 0 处。

## 自绘星座版（10-26，取代真实星座版）

用户：「每条线一个自绘星座，形状对应线的含义，按 Ⅰ→Ⅴ 一笔连下来，只写线名，不用地球星座名」。

为什么不用真实星座：
- 泰拉不是地球，希腊星座名会出戏，也查不到原作设定。
- 真实连法表达不出 Ⅰ→Ⅴ 的顺序（南十字是两根交叉线，四边形看不出起止）。
- 局外成长 v3 改阶数时，真实星座的星数对不上。

| 线 | 形状 | 一笔的走法 |
|---|---|---|
| 攻击性 | 箭 | 箭杆 Ⅰ→Ⅲ，Ⅳ 倒钩，Ⅴ 箭尖 |
| 生存本能 | 心 | Ⅰ 心尖起笔，Ⅴ 右瓣 |
| 生命感悟 | 心跳脉搏 | 回复 = 心跳，Ⅲ 是高峰 |
| 自我保护 | 盾 | Ⅳ 盾尖 |
| 领导欲 | 王冠 | Ⅳ 右峰 |
| 好奇心 | 眼睛 | 中间一颗瞳孔点缀星 |
| 多程信息处理那条 | 闪电 | 一闪的洞察 / 绝处逢生 |
| 收藏癖 | 宝石 | 两颗腰点 + 底尖 |
| 交涉 | 天平 | Ⅰ–Ⅲ 是横梁 |
| 危机感 | 警示三角 | Ⅰ 顶点，中间一道「!」 |

- **一笔的画法**：一笔按节点切段，两头都塑造才点亮。笔画可以拐过不可点的点缀星，把形状勾圆。
- **点满后**：收笔（把图形闭合的最后一笔）和辅助线（天平立柱、秤盘、宝石腰线、「!」）平时很淡，整条线点满才亮起来，图形完整。
- **以后改阶数**：在 `layout.py` 的 SHAPES 里改这条线的笔画即可。
- **布局检查**：当前剩 1 处，生存本能Ⅳ 的星名贴着右瓣的线，可读。
