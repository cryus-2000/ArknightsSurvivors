## 现状为什么杂乱

| 来源 | 具体 |
|---|---|
| 信息密度 | 39 个节点一次全画、每节都写名字；同一条链 5 个同名节点（攻击性Ⅰ…Ⅴ）重复 5 次 |
| 层级 | 每条链 3 层标签叠在一起：分类（攻击）+ 末节规则框（处决）+ 节点名；当前节点的效果却放在离它最远的左栏 |
| 对齐 | 10 条链从底部一个根扇形散开、两侧外斜、相邻列错半格；根部 10 条长连线穿过文字；最左（调度）、最右（回复）两列被屏幕边裁掉 |
| 背景 | 碎片轮廓 + 引线 + 刻度 + 小数字常驻漂动，线条和树枝同一种细线，抢视线 |
| 颜色 | 左栏浅灰 + 右侧暗场两套明度；警示黄、亮蓝大数字、青、暖白、灰蓝共 6 种强调色 |
| 文字量 | 一屏约 60 段文字（节点名 39 + 分类 10 + 规则框 10 + 左栏） |
| 动效 | 背景碎片一直漂移自旋，静止看也不安静 |

## 三个方案（都按 战斗 / 成长 / 资源 分三组，顶栏统一：标题块 + 生机细胞 + 已塑造 x / 39 + 返回）

- **A 档案列表**（锚点：图鉴）：10 条链各一行——等级格（暖白 = 已塑造、青框 = 下一节）+ 当前总加成（「全体伤害 +16%」）+ 下一节消耗；右侧浅色面板逐节列出该链全部节点与质变规则，右下大按钮塑造。一屏读完全部进度，最省心。
- **B 整齐图谱**（保留「树」）：10 列等距排齐、不斜不扇、去背景碎片和每节名字，节点只标罗马数字，末节规则做成列顶小标签；右侧暗色详情面板（同选人右栏）。保住「一棵树往上长」的感觉。
- **C 单链聚焦**（锚点：选人）：底部一排链卡像名册（图标 + 名字 + 等级格），中间放大当前链的 3–5 节横排卡片（效果、质变规则一眼看全），右下大按钮塑造。单链信息最完整，跨链对比要靠底部卡片。

演示视频脚本相同：进入 → 依次选 攻击 / 生命 / 减伤 → 回到攻击 → 塑造「攻击性Ⅴ」（细胞 275 → 251、节点点亮）→ 切到成长组。

## 10-25 下午：从头设计并实装（协调人转用户：「我相信你的前端能力，按照原作的设计」；上面 A / B / C 与网页样稿作废）

参照原作水月「认知塑造」节点树（PRTS 图，下载在主仓库外 `build/meta_ui/ref/is3_tree.png`，不进 git）+ 用户几轮的方向：深蓝之树树根、弧线内收、不对称、明日方舟界面语言。
游戏内实装在 `game/scripts/screens/meta_tree_ui.gd`，两种画风都在（`--metastyle=tree|sea`，缺省 tree），用户挑定后删掉另一种。

- **共同骨架**：树干从顶栏垂下 → 四条主根（探索 / 成长 / 战斗 / 生存）→ 10 条线各从主根分叉成一条细根，节点按弧长排在根上（越深越高阶），每条线守一条约 100 宽的竖向车道、名字放下方，主根成拱、根尖往里收；左侧探索短、右侧战斗 / 生存长（左下留给详情卡）。
  节点照原作：黑盘 + 白环 + 白色图形 + 点状外环、右下消耗；质变节点是放射条纹大盘。已塑造 = 白盘黑图 + 青光；可塑造 = 黄色点环转动呼吸；余额不够 = 灰；未解锁 = 暗。
  像素层（背景、树干、根、节点）画进低分辨率 SubViewport，一格恰好是整数个屏幕像素（720p / 1080p = 2 设计单位，900p = 2.4），任何分辨率都不糊；文字和外框画在设计坐标里。
- **tree 深蓝之树**：水下像素场景（树冠的光、光柱缓摆、海床剪影、浮游光点），树干带荧光脉络、已塑造的根有汁液流动；顶栏用寻访 / 图鉴同一家族（灰块 + 警示条 + 黄色标题签）；一屏放下全树，左缘深度刻度尺。
- **sea 原作夜海**：夜空云带 + 地平线 + 海面横纹；白色连线、进入质变节点的线上有蓝色三角；节点写「名称 + 一行效果」；居中原作式标题（徽记 + 认知塑造 + 合计生机细胞）；画布 1.5 倍，镜头跟随选中、可拖动 / 滚轮平移。
- **详情卡**：桌面左下浅色档案卡（左黄条、右上切角、组色标签、效果大字、质变标签、本线进度与合计、状态、塑造按钮，高度随内容）；手机改成贴底一条，镜头保证选中节点在底条上方。
- **操作**：↑↓ 沿本条根走、←→ 按方向找最近的节点；点选 / 再点塑造；R 推荐、X 两次重置、Esc 返回；拖动 / 滚轮平移（画布比屏幕大时）。
- **工具**：`layout.py`（布局唯一来源 → `game/data/meta_roots.json`，自带重叠检查与预览）、`icons.py`（11×11 节点图标 → `game/scripts/screens/meta_icons.gd`）。
- **截图 / 录像**：`--metashot --metastyle=… --metacells=600 --metabuy=330`；演示 `--metademo [--metademokeys=D,D,D,R,E,U,U,L]` 配 `--write-movie x.avi --fixed-fps 30`（0.5 秒从标题进入、按键序列、10 秒退出）。
